# 塊の Dancoff 係数を燃焼の初めの値で固定したときの差と時間を測る

## 問題

格子計算の燃焼は、輸送のたびに構造材の塊（案内管、計装管、支持格子の枠など）の Dancoff 係数（`lump_dancoff`）を解き直す。塊の
Dancoff 係数は、燃料の領域にピンの自己遮蔽した燃料の全断面積を置くので、燃料の組成に依り、入力が同じときだけ持ち越す ADR-0194 の
方式では持ち越せない（ADR-0194 の案 C）。VERA 2A の燃焼では、塊の区間は自己遮蔽 1,379 秒のうち 161.0 秒（輸送 1 回あたり約 2 秒。
examples/depletion/p2 の `lattice-2A.log`、xlc 0f97cea6、Slurm 461）。

燃焼の初めの値で固定すれば、この時間のほとんどが減るが、燃料の全断面積の変化が塊の影に入らなくなり、結果が変わる。その差の大きさは
測っていない。

関係する ADR: なし

## 完了の条件

塊の Dancoff 係数を燃焼の初めの値で固定した試行（入力で選べる機能として足す）で、2A などの燃焼の k∞ と数密度の差と時間を測り、
採るかを ADR に決める。
