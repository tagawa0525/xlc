# 真空の辺のある大きな格子で、1ノードの問題の均質な面の中性子束が負になる

## 問題

燃料が真空に直接面する 17×17 の集合体（VERA 2B、右の辺が真空、`examples/vera/assembly-2B-vacuum.toml`）では、
ADR-0094 の1ノードの問題の熱群の均質な面の中性子束が右の辺で負になり、ADF を作れない（エラーにする）。自己遮蔽ありで
−8.7 × 10⁻⁵、なしで −7.2 × 10⁻⁴（ノード平均 0.0110、右の辺の不均質な中性子束 0.00109、外向きの正味の流れ
6.2 × 10⁻⁴。自己遮蔽なし）。燃料ピンの 9×9（幅 11.4 cm）までは正で、21.5 cm で負になる（examples/vera/verification.md
の「真空の辺のある格子の ADF と core の1ノードの NEM」、8460d2f、2026-10-09）。均質な解は、熱群の流れ出しを、ノード平均を
保ったまま4次の多項式の勾配で運ぶので、ノードが熱中性子の拡散距離に比べて大きいと面の値が負になる。

真空の面の条件（ADR-0101 の r = J/φ_het）は輸送計算だけで決まり、この問題によらない。

関係する ADR: [ADR-0094](../adr/0094-define-adf-by-one-node-nem.md)

## 完了の条件

燃料が真空に直接面する集合体の格子を ADF の対象にするか（反射体の格子 ADR-0095 では、真空の面は反射体の外側にある）、
対象にするなら負の均質な面の中性子束をどう扱うか（ノードを分ける、ほかの展開の核を使う、など）を、文献と比べて決める。
