# 少数群定数の群境界を、輸送の前に確かめる

## 問題

格子計算の入力の `few-group` の `bounds`（燃焼の `[depletion]` の `few-group` も）が、ライブラリの群境界の一部で、降順で、ライブラリの群を
覆うかは、輸送を解いたあとの縮約（`fewgroup::homogenize` の `coarse_groups`）で初めて確かめる。誤った入力は、最初の自己遮蔽と MOC
（集合体の燃焼で 1 回 25 秒ほど）を解いてから止まる。入力の段で、ライブラリの群境界と比べれば、輸送の前に止められる。

もとは #0137 の「問題」に挙げていたもの（#0137 は ADR-0194 で閉じた）。

関係する ADR: なし

## 完了の条件

ライブラリを読んだあと、輸送の前に `few-group` の群境界を確かめ、誤りを輸送の前のエラーにする。テストで示す。
