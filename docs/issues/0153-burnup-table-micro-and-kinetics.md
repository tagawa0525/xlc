# 燃焼度の軸を持つテーブルにミクロ燃焼の断面積と動特性・冷却のデータを書く

## 問題

ADR-0187 は、燃焼度の軸を持つ分岐のテーブル（`xlc-table`）に、ミクロ燃焼（ADR-0035）の核種の均質化した数密度（燃焼度の点ごと）と
少数群の微視的断面積（状態ごと）、ADR-0033 の遅発中性子のデータと群速度の逆数（状態ごと）、冷却計算のための全核種の 1 群の微視的
断面積（燃焼度の点ごとの公称の状態）を置く場所を決めた。

ミクロ燃焼の側は ADR-0216 で、追う核種（ADR-0035 の元素の輸送する核種と、その輸送する先行核。2A で 31）、チェーンとの関係、
微視的断面積の項目と定義、線形の補正の形を決め、lattice の `[history]` の `micro` が数密度と微視的断面積をテーブルに書く。core はまだ
読まない（ノードのミクロ燃焼と線形の補正）。

ADR-0033 の遅発中性子のデータは、ライブラリが族ごとの割合と崩壊定数を持たない（crates/format/src/library.rs の形式に項目がない）ので、
ライブラリに足す決定が先に要る。冷却計算の全核種の 1 群の微視的断面積は、輸送しない核種（ライブラリにない核種）の断面積の出所を
決めなければならない。どちらも ADR-0216 に含めず、ここに残した。

関係する ADR: ADR-0187、ADR-0215、ADR-0216

## 完了の条件

- lattice の `[history]` の実行が、ADR-0187 の置き場にこれらの量を書き、core が読んで状態と燃焼度で内挿する（テストで、格子点で
  格子計算の値を返すこと）。ミクロ燃焼の数密度と微視的断面積は lattice が書く（ADR-0216）。残りは core の読みと内挿、ノードのミクロ燃焼、
  ADR-0033 のデータ
- 本番のテーブル（熱水力の ADR の後）より前に入れる（ADR-0033: 後から足すとテーブルをすべて作り直す）
