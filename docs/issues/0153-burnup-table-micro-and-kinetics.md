# 燃焼度の軸を持つテーブルにミクロ燃焼の断面積と動特性・冷却のデータを書く

## 問題

ADR-0187 は、燃焼度の軸を持つ分岐のテーブル（`xlc-table`）に、ミクロ燃焼（ADR-0035）の核種の均質化した数密度（燃焼度の点ごと）と
少数群の微視的断面積（状態ごと）、ADR-0033 の遅発中性子のデータと群速度の逆数（状態ごと）、冷却計算のための全核種の 1 群の微視的
断面積（燃焼度の点ごとの公称の状態）を置く場所を決めた。lattice はまだこれらを書かず、core も読まない。テーブルは少数群定数と
形状関数だけを持つ。

持たせる核種（基本は履歴の `transportable`）と反応の並び（チェーンの反応のうちミクロ燃焼に要るもの）は、core のミクロ燃焼
（docs/plans/m4-depletion.md の「進め方」7）を作るときに決める。遅発中性子のデータは、ライブラリが族ごとの割合と崩壊定数を
持つかを確かめてから（ADR-0186 は遅発中性子を χ に入れたが、族ごとの量をライブラリに持つかは確かめていない）。

関係する ADR: ADR-0187、ADR-0215

## 完了の条件

- lattice の `[history]` の実行が、ADR-0187 の置き場にこれらの量を書き、core が読んで状態と燃焼度で内挿する（テストで、格子点で
  格子計算の値を返すこと）
- 本番のテーブル（熱水力の ADR の後）より前に入れる（ADR-0033: 後から足すとテーブルをすべて作り直す）

## 経緯

- 2026-10-23: ADR-0187 で形式の置き場だけを決め、実装を「進め方」7 に回した
- 2026-10-29: ADR-0215 の履歴の補正の残りは、この微視的断面積と均質化した数密度でミクロ燃焼の線形の補正を引いて作るので、#0190 がこの issue を待つ
