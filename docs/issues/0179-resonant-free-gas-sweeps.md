# 重い核種の自由ガスで UFG の上方散乱のスイープの収束が遅い

## 問題

UFG の減速計算で分離共鳴を持つ核種（重い核種）も自由ガスにすると（ADR-0204 の `ufg-free-gas.heavy`）、上方散乱のスイープ（ADR-0203）が
軽い核種だけのときより遅く収束する。

- 最初のスイープは、格子点より後（低いエネルギー）の中性子束をその点の値とみなす。重い核種では、スイープ 1 回の k が参照（スイープは
  収束まで）から −114.6〜−169.9 pcm 外れ、2 回で −7.1〜−10.4、3 回で −0.1〜−0.2 pcm（#0133 の 3 状態。examples/depletion/verification.md
  「分離共鳴を持つ核種の自由ガスの散乱核（ADR-0204）」）。軽い核種だけでは 1 回で +0.8〜+0.9 pcm（ADR-0203）。共鳴の谷の中と下の中性子束を
  その点の値とみなして上方散乱の源を高く見積もることが候補で、確かめていない
- 重い核種を上限なし（`heavy = inf`）にすると、1C の 0 MWd/kg のピンセルでスイープが 50 回で収束せず `UfgError::NotConverged` で止まる。
  減速材のない U-238 だけのセルでも収束が遅い。減速材のないリング（被覆管の Zr など）の上方散乱が候補で、確かめていない
- 2A の燃料のピンセル（燃料 900 K の 1 点、`ufg-tolerance = 1e-4`。examples/depletion/issue-0274/cap-900/sweeps-inf.toml）では、上限なしの
  スイープの中性子束の相対変化が 2 回目の 0.22 から 11 回目の 3.7e-10 まで回ごとに 1 桁ほど下がり、12 回目から 50 回目まで 1.3〜2.2e-10 で
  止まって `SWEEP_TOLERANCE`（1e-10）に届かない（xlc b44eed566、2026-11-10。ADR-0243 の案 2）。遅い収束でなく、相対変化の下限が許容差の
  上にあることが候補で、どの格子点で止まるかは確かめていない。3 回の解の k は 12 回の解（`sweeps-12.toml`）より 1.2 pcm 低い

## 完了の条件

最初のスイープの前に静止した標的の解を「前のスイープ」とするか、スイープを加速して、重い核種の自由ガスがスイープ 1〜2 回と上限なしで
収束することを測り、方式を ADR に書く。
