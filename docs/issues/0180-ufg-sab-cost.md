# UFG の S(α,β) の移行の表の大きさと散乱源の手間

## 問題

ADR-0205 の S(α,β) の移行の表と散乱源は、正確さを先に作り、大きさと手間を詰めていない（ブランチ feat/ufg-sab-kernel のレビューの指摘）。

- 表の大きさ: 表は入射 317 点 × 移行 2389 点の長方形で、移行は全行で出射 0 eV に当たる −B(4) から始まる。入射が 10 eV より低い行の
  出射 0 eV 以下（値 0）を含み、lattice が使うのは出射が UFG の下限（4 eV）以上の移行だけ。H-1 の核種のステージの出力は 0.64 MB から
  21 MB になった（examples/depletion/dvc.lock、b8581b99）。表の温度の間の温度（565 K など）の lookup は、表の全体を内挿する
- 表のコピー: lattice の `solve_cell` は、セルを解くたびに表（約 6 MB）を `Thermal` にコピーしていた（2026-10-28 に借用にした。経緯）
- 散乱源の手間: `SabSource::add` は出射の格子点ごとに直列で、小区間ごとに `cumulative_at` を 2 回呼んでいた（同じ入射の行を 2 回探す。
  2026-10-28 に、入射の行を 1 度だけ探し、小区間の重みを並列に求めるようにした。経緯）。
  ADR-0205 の測定（examples/depletion/verification.md「H in H2O の S(α,β) の UFG の散乱核（ADR-0205）」、5020424b）のログの経過時間
  （`--timed` でないジョブなので目安）は、S(α,β) のある散乱核が同じ扱いの自由ガスより長い（2A-40 の `fine_flux` で 504 s と 294 s、
  1C の 5 MWd/kg の `swap_absorption` で 303 s と 173 s）
- 掃き直しの始め: `Thermal::new` は S(α,β) の上方散乱の届く格子点を、自由ガスの上限と S(α,β) の上限の大きい方に移行の最大を
  足して決めるので、自由ガスの上限が S(α,β) の上限より上（`upper = 400` の 565 K で 19.5 eV と 10 eV）だと、掃き直す格子点が
  0.57 eV ほど余分になる（S(α,β) の上限 + 移行の最大で足りる）
- 大きさに釣り合わない時間: ADR-0209 で既定にした自由ガスの速い設定と S(α,β)（`--timed` のジョブ。Slurm 563、565。xlc 73d03d37c、
  2026-10-28。examples/depletion/verification.md「集合体の燃焼」の時間の段落と「時間の内訳」）では、1 回の輸送の自己遮蔽が 2A の集合体
  （解くピン 39 本、格子点の和 370 万）で 74.4〜77.0 秒、1C のピンセルの 1 リング（1 本、88 万）で 76.3〜77.2 秒とほぼ同じ。前の既定
  （静止した標的）では 2A が 9.7 秒、1C が 8.5 秒。格子点の和が 4 倍で時間が同じなのは、固定費でなく、1C が直列の
  S(α,β) の散乱源を待ち、2A が 39 本の自由ガスの散乱源の仕事の和で決まるため（経緯の 2026-10-28。2A の残りは #0181）。2A の燃焼の自己遮蔽の和は 787.3 → 6,131.5 秒（7.8 倍）で、ADR-0209 の既定で流す
  ほかの集合体（2F〜2P、分岐）も同じ倍率がかかる見込み（確かめていない）
- 本番の形の 2A の分岐のテーブル（ブランチ feat/0278-p9-2a-production-table の examples/depletion/p9-2A、同じブランチの
  docs/issues/0278。見積もり約 47 時間で、その 86.8% が自己遮蔽）の自己遮蔽の内訳。下の「2A の本番の形のテーブルの自己遮蔽の内訳」

### 2A の本番の形のテーブルの自己遮蔽の内訳（2 回目。厳密なまま減らせる計算）

前の節の続き。近似に進む前に、結果を変えずに減らせる計算を探した（ユーザー 2026-11-12。長い計算を通す工夫や結果を減らす手でなく、
時間の大きさの理由に向き合うことを求めた）。入力は前の節の 2A-60.toml と、燃焼点だけを替えた 2A-32.toml、2A-0.5.toml。どれも
パーティション timed の排他のジョブ（32 スレッド）、2026-11-12、分岐点は main の d6db07223。Slurm 763 は main（d6db07223）、
摂動の前処理の共有（55b15c491）、下の試して捨てたピンのプールの版の 3 つ、Slurm 764 は main と直した後（09028ec25）。ログは同じ
ディレクトリの `*-s2-*`（763）と `*-s3-*`（764）で、内訳の数は debug のログ（`2A-60-s3-final-debug.log`。763 の
`2A-60-s2-pool-debug.log` はプールの版で、39 本が同時に走り段の時間が伸びるので、数と摂動の差だけを使う）から。時間はピン 1 本、
1 回目の自己遮蔽のスレッド秒（39 本の平均）。

- 自由ガスの散乱源（1 本 15.7 秒）:
  - 掃き直す格子点 20,016（24%）で、区間 2,300 万を最初のスイープで作って持ち（ADR-0213）、スイープ 3 回で積分する。核の評価
    （`Gas::correction`）4,824 万回（1 区間 2.1 回。隣と共有する端を除く）、区間とリングの組の積分は 1 スイープ 9,308 万回
  - スレッド秒: 区間の境界 0.51、2 次式の作成（核の評価）5.66、作った区間の積分 2.71、持った区間の積分（2 スイープ）8.62。1 回あたり
    核の評価 117 ns、積分 29 ns（作った区間）と 46 ns（持った区間）。回数 × 1 回の時間が段の時間に合い（5.66、2.71、8.62）、
    計算量の式（掃き直す格子点 × 核種ごとの区間 × リング × スイープ）のとおりに伸びている。持った区間の積分が 17 ns 遅いのは、
    区間の格子点を探し直す（ADR-0213 の形 C2）ことと、1 本 0.92 GB の区間を読み出すことの候補（分けて測っていない）。積分は
    リングごとに倍精度の 2 つの和（`Dd`）の逐次の演算で、ベクトル化していない
  - 核種: 116 のうち 90 が区間を作る。上限 1000 eV（分離共鳴なし）の 9 核種が積分の 33%、上限 31 eV の 81 核種が 67%。多いのは
    Np-239（4.8%）、I-135（4.5%）、O-16（4.4%）、B-11（4.2%）、B-10（4.1%）、P-31（3.9%）、C-13（3.6%）、C-12（3.5%）。燃料の
    B、C、P の 5 核種で 19%（数密度の小さい核種を自由ガスにしない案の対象。近似）。Sn などの 31 eV の核種は 1 核種 0.9% ほど
  - 核の依存: 2 次式は σs(x) × D(x)。D は核種の (質量比, kT, 上限, S(α, β) の上限) と出射の格子点（u、E）、範囲の上端だけで決まり、
    σs はピンの間引いた格子での補間。同じ核種の 5 つの燃料のリングは 1 つの核で、区間と 2 次式を 1 度作る（リングごとに作り直して
    いない）。ピンの間と自己遮蔽の呼び出しの間（状態、燃焼点、摂動）は作り直す。間引いた格子はピンの組成で違う（83,077〜83,297 点）
    ので、厳密に持ち回せるのは同じ出射の格子点の D の値（3 点）と区間だけで、σs を掛けるのはピンごと。格子点の重なりは測っていない。
    持つなら 1 つの格子で区間 2,300 万 × 40 B ほど（0.9 GB）
  - 核種をまとめる: 質量比の同じ核種は無く（同位体も質量比が違う）、核が同じ核種の組は無い。核種の区間を足して 1 つの区分的な
    2 次式にしても、区切りの和集合でほぼ同じ数の区間になり、積分は減らない
- 飛程の表（1 本 5.94 → 3.23 秒）: 表は 3 つの軸（1 本目の例で、燃料 0.256〜8.0 /cm で 25 点、被覆管 0.141〜12.2 で 33 点、減速材
  0.975〜1.069 で 4 点）の直積 3,300 組に、組ごとに 11 回（値と、5 つの燃料のリングの中心差分）の衝突確率で、36,300 回。表はピンの等価なセルの
  半径（Dancoff 係数から。39 本で 39 通り）、リングの物質の配置、軸の範囲（組成）で決まり、ピンの間も呼び出しの間も同じ表は無い。
  格子点の内挿が読むのは、直積のうち格子点の Σ がたどる曲線の周りの 4 点の組だけで、読む組だけを求めるようにした（1 回目の自己遮蔽の
  39 本の平均で 3,203 組のうち 1,631 組。ビットで同じ。求めない組の値の配列も確保したままで、1 本 18 MB ほど）。表を作るかの判定は今も直積の組で数える（読む組で数えると、表を作るセルが増えて結果が変わる。0.5 MWd/kg は

  共鳴の上を通ることとした（重い核種では自分の共鳴の散乱、軽い核種では吸収体の共鳴の E_r/α）。どちらも効きは、その核種の散乱の率
  （散乱源への寄与）と、窓に対するぼけの幅 √(A kT / E) の積に比例する（上の 1 次の式）。分離共鳴の有無で分ける今の既定は、上限の
  値（31 eV と 1000 eV）を決める基準で、自由ガスにするかを決める基準ではない。分離共鳴を持たない核種でも個数密度が 0 の P-31、
  1e−17 の B-10 は効かず、分離共鳴を持つ Sm-152 は 4〜31 eV の散乱源の 2% を持つ。寄与で選ぶ基準は、この 2 つの ADR の理由と同じ量で
  誤差を抑えるので、物理的に正しい基準になりうる。既定を変える提案: 閾値 1e−3 の `static` の項目を足し、#0133 のピンセルと 2A の
  1 状態で外す前後の k∞、群ごとの実効断面積、時間を測ってから既定を決める（決めるのは親とユーザー）
- 個数密度がちょうど 0 の核種とリングは、自由ガスの散乱源の核の評価と積分を飛ばす（ADR-0248 の「決定と理由」。0 は符号つきの 0
  しか足さないので、散乱源はビットで同じ。テストと上の md5）。2A の燃料では P-31 がすべての燃焼の領域で 0、C-12 は 60 MWd/kg の 195
  領域のうち 111 で負（輸送と自己遮蔽には 0 として渡す。ADR-0173）。上の表の個数密度の負の値は、0 に切る前の履歴の体積の平均。B-10、
  B-11 と C-12 の正の値は CRAM の誤差の水準より小さく、その扱いは #0280。飛ばした分の時間は、燃焼点で捨てる直しと分けて測っていない
  （60 MWd/kg の 1 状態は 1 燃焼点で、どちらの捨て方も上限まで格子点を捨てないので、769 の版との差 119.55 → 114.3 秒の大半は 0 の核種の
  分の見込み）
- 本番の見積もり（docs/issues/0278 の方法）: 前の節の約 38〜40 時間の、自己遮蔽を解く状態と微分の 33.4〜35.4 時間に、最終版の比 0.905〜0.917
  （60 MWd/kg は 114.3 / 126.2 = 0.906）を掛けて 30.2〜32.5 時間、再利用する状態の 4.1 時間を足して約 34〜37 時間。1 状態の入力で測った比
  なので、1 燃焼点の 114 状態の間で表を持ち越す分（3 燃焼点の入力では次の燃焼点の状態で 53〜64%）は数えていない上限
