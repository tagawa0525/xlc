# 炉外の検出器の応答

## 問題

炉外の検出器の応答を xlc で求める手段がない。#0034 で求め方を調べ、M3 では作らないと決めた（ADR-0132）。

文献の方法は、炉外の形状（バレル、中性子パッド、圧力容器、検出器の井戸）での随伴の輸送計算で空間の重み関数を作り、
炉心計算の出力分布に掛ける。M. G. Park, H. C. Shin, Trans. KNS Spring Meeting (2009)（全文を読んだ）は、2D の随伴の
輸送計算（DORT）で集合体の重み ω_2D(x, y) と軸方向の重み ω_1D(z) を作り、R = ∫ (∫ P(x, y, z) ω_2D dx dy) ω_1D(z) dz と
する。M. W. Crump, J. C. Lee, Nucl. Technol. 41(1), 87–96 (1978) と H. Tochihara et al., Nucl. Technol. 58(2),
310–317 (1982) は要旨だけ読んだ。

xlc の core は出力分布を出すので、重み関数があれば応答は和で求まる。重み関数を作るには、円筒の形状と、厚い水と鋼を
通る輸送の計算が要り、ADR-0078 で格子計算から除いた範囲になる。

関係する ADR: なし

## 完了の条件

実機のデータ（炉外の検出器の信号、ロッドスワップの影の係数など）と比べる段階で、重み関数の作り方（xlc の中で作るか、
外部の輸送計算から読むか）と入力の形を決めて ADR にし、応答を出せる。
