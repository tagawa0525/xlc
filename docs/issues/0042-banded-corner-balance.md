# 角の点のバランスの連立方程式を帯行列で解く

それを囲むノードの角の点（9 つ）とだけ結びつくので、行列は帯の幅が約 2(nx + 2) の帯行列である。17 × 17 の炉心では
未知数 648 で困らないが、集合体を 2×2 のノードに分ける（#0033）と未知数は 2450 で、密な LU は層あたり約 1.5e10 の
演算と 48 MB になる。軸方向の層が 24 あれば約 3.5e11 の演算になる。
