# UFG の 1 ピンの時間が同じ系統の方式より 2 桁大きい理由

## 問題

xlc の自己遮蔽（ピンごとの UFG の減速計算。ADR-0068）は、同じ系統の方式（STREAM の PSM。PSM-I の Table 2 で燃焼した UO2 の
1 ピン 0.233 秒）より 1 ピンあたり 2 桁遅い（#0180 の 2A の 60 MWd/kg の内訳）。項目ごとの時間と、今の UFG からの差を測って
切り分け、直せる非効率を直し、近似になるものは入力で選べる項目にして差を測る（ユーザー 2026-11-13。CLAUDE.md の「方針」の
2 桁は設計の誤り）。

関係する ADR: なし

## 完了の条件

1 ピンの時間の項目ごとの内訳と PSM との倍率、項目ごとの速くなる量と今の UFG からの差（燃料の種類ごと）を測り、既定にする
項目を決める。

## 経緯

- 2026-11-13: 自己遮蔽に速い方式を入れる提案と並べて、UFG の 1 ピンの時間の理由から先に調べると決めた（ユーザー）
