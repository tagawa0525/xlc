# UFG の 1 ピンの時間が同じ系統の方式より 2 桁大きい理由

## 問題

xlc の自己遮蔽（ピンごとの UFG の減速計算。ADR-0068）は、同じ系統の方式（STREAM の PSM）より 1 ピンあたり 2 桁遅い。項目ごとの
時間と、今の UFG からの差を測って切り分け、直せる非効率を直し、近似になるものは入力で選べる項目にして差を測る（ユーザー
2026-11-13。CLAUDE.md の「方針」の 2 桁は設計の誤り。特定の燃料の種類に合わせ込まないよう、新しいウラン燃料だけでなく燃焼の
進んだ組成、Gd、可燃性毒物と制御棒のある格子、燃料の温度を変えた状態でも差を測る）。

入力と比べるツールは examples/depletion/issue-0286/（`inputs.py` がケースと変種ごとの入力を書き、`compare.py` が時間と既定からの
差の要約の JSON を書く）。下の値の出どころは、断らない限り `timing-825.json`（Slurm 825。パーティション timed の排他のジョブ、
2026-11-13、xlc 625af643c（実行ファイルは同じコードの 6c6bf98a8 でビルドした `target/release/lattice`）、分岐点は main の
6e6abb56d。ピンセルは 1 スレッド（`RAYON_NUM_THREADS=1`）、集合体は 32 スレッド。ログは DEBUG の計数を含む）。

### 1 ピンの時間の内訳と PSM との倍率

PSM は PSM-I の Table 2（60 GWd/t の UO2 のピン、燃料 5 リング、198 核種、0.3 eV〜30 keV の等レサジー 5 万点。計算機とスレッドの
数は書かれていない）。xlc は、2A の 40 MWd/kg の組成のピンセル（`pin-uo2-40`。燃料 5 リングで一様、76 核種、格子点 8.2 万。
1 スレッド）と、2A の 60 MWd/kg の 1 状態（`2A-60`。解くピン 39 本、116 核種、リングごとに組成が違う。32 スレッドの段の和を 39 で
割ったスレッド秒）:

| 項目（PSM の欄）                                  | PSM (s) | pin-uo2-40 (s) | 2A-60 (s) | 倍率（pin-uo2-40） |
| ------------------------------------------------- | ------: | -------------: | --------: | -----------------: |
| 減速計算の解と衝突確率（PSM solution）            |   0.011 |           6.84 |     24.52 |                620 |
| うち自由ガスの散乱源                              |         |           5.47 |     16.15 |                    |
| うち S(α, β) の散乱源                             |         |           0.62 |      1.14 |                    |
| うち静止した標的の窓の積分と線形方程式            |         |           0.66 |      1.91 |                    |
| うち衝突確率（表の外の格子点を格子点ごとに）      |         |           0.09 |      5.32 |                    |
| 衝突確率の表（P^iso table）                       |   0.003 |           0.41 |      3.25 |                140 |
| 格子と核種の断面積（Nuclide grouping）            |   0.104 |           0.74 |      2.74 |                  7 |
| 群定数への縮約（XS condensation）                 |   0.115 |   分けていない |           |                    |
| 計（PSM total。xlc は上の段の和）                 |   0.233 |           7.98 |     30.52 |                 34 |
| 移行の割合の区間（ADR-0207。表が空の 1 回目だけ） |      無 |           4.58 |      8.19 |                    |

- 倍率の大半は減速計算の解（620 倍）で、その 8 割が自由ガスの散乱源。静止した標的の部分だけ（0.66 + 0.09 + 0.41 秒）でも、PSM の
  解と表の 0.014 秒の 80 倍ほど
- 演算の数で説明できる分: 自由ガスの散乱源は、核の評価 2,980 万回 × 77 ns、作った区間の積分 4,980 万回 × 13 ns、持った区間の積分
  9,970 万回 × 20 ns と区間の境界で 5.13 秒（段の 5.47 秒の 94%）。回数は掃き直す格子点 × 核種ごとの区間 × リング × スイープで、
  1 ピンの区間 1,420 万の大半は散乱への寄与の小さい核種のもの（下の `share`）。静止した標的の部分は格子点 8.2 万 × リングと核種の組
  277（燃料 5 リング × 50 核種、被覆管 23、水 4）で 2,300 万回、1 回 29 ns。PSM は核種を質量でまとめ（Nuclide grouping）、点 5 万 ×
  5 リング × まとめた組で解く
- 演算の数で説明できない分（2A-60 が pin-uo2-40 の 3.8 倍）: (1) 32 スレッドで 1 回の演算が長い。核の評価 121 ns、作った区間の積分
  35 ns、持った区間の積分 45 ns（1 スレッドの 1.6〜2.7 倍。r995 は 16 コア 32 スレッドで、候補は SMT とメモリ。分けて測っていない）。
  (2) リングごとに組成が違うので、表の外の格子点（1 ピン平均 3.12 万、37%）を格子点ごとに求める（衝突確率 5.32 秒）。(3) 核種が
  116 と多い。(4) 39 本を 32 スレッドに配る残りと逐次の区間（自己遮蔽の span 62.9 秒 × 32 = 2,013 スレッド秒に対し、段の和 1,190 と
  移行 320 スレッド秒。#0180 の「32 スレッドの使い方」）

### 項目ごとの速くなる量と今の UFG からの差

差は既定（変種 `default`）からの、k∞ の反応度 1/k(既定) − 1/k(変種)、2 群の定数（全断面積、吸収、νΣf、散乱行列）の相対の差の
最大、ピン出力の形状関数の相対の差の最大、燃料のリングごとの U-238 の UFG の範囲で縮約した 1 群の捕獲断面積の相対の差の最大
（ログの `UFG U-238 ring capture`）。時間は自己遮蔽の span の秒（集合体は 32 スレッド、ピンセルは 1 スレッド）:

| 項目                                        | ケース     | 自己遮蔽 (s) | 反応度 (pcm) |   2 群 | ピン出力 | リングの U-238 |
| ------------------------------------------- | ---------- | ------------ | -----------: | -----: | -------: | -------------: |
| `ufg-free-gas.share = 1e-3`（足した。近似） | pin-uo2    | 7.32 → 5.44  |        −0.03 | 5.4e−7 |          |         1.3e−6 |
|                                             | pin-uo2-40 | 14.0 → 7.67  |        +1.05 | 1.4e−5 |          |         4.0e−5 |
|                                             | 2A-60      | 62.9 → 36.5  |        +0.54 | 7.4e−6 |   1.3e−6 |         4.6e−5 |
| `ufg-free-gas.share = 1e-2`（足した。近似） | 2A-60      | 62.9 → 32.0  |        +0.50 | 9.4e−6 |   2.7e−6 |         1.4e−4 |

- `share`（ADR-0209 の自由ガスにする核種を、狭い共鳴の中性子束 1/(Σt E) の重みの弾性散乱の率の、リングの物質の中の割合で絞る。
  どのリングでも閾値より小さい核種を静止した標的にし、S(α, β) の核種は残す。#0180 の 3 回目の節の案）: 2A-60 の 1 ピンの
  自由ガスの散乱源は 16.15 → 3.19 秒（1e-3）、1.16 秒（1e-2）、移行の区間も 8.19 → 3.32、2.19 秒。1 状態は 77.1 → 50.0 秒（1e-3）、
  45.5 秒（1e-2）。新しい燃料のピンセルでは、被覆管の Cr、Fe、Sn の同位体と燃料の U-234、U-236 が外れて −26%。#0180 の見積もり
  （1e-3 で 0.17 pcm）より測った差（0.5〜1.0 pcm）が大きいのは、#0180 が燃料の核種だけを数え、被覆管の核種と燃料の Zr の同位体
  （40 MWd/kg で割合 1e−3 前後）を数えていないことが候補（確かめていない）
- 閾値は核種ごとの割合で、外す核種の割合の和では抑えていない（pin-uo2-40 の 1e-3 は 52 核種）。和で抑える形は作っていない
- 測っていない（Slurm 826、827 の結果で埋める）: ピンセルの 600 K、1200 K と集合体の Gd（2O）、Pyrex（2F）、制御棒（2A-rods）の差、
  `share = 1e-4`、既にある項目（静止した標的、分離共鳴を持つ核種の静止、軽い核種の 400 kT、スイープ 1、2 回、間引きの許容差
  3e−4、1e−3、飛程の表の 10 倍あたり 8 点）。MOX のピンセル（`pin-mox`）は、ライブラリ（examples/depletion/depletion.msgpack）が
  今の形式（`delayed` を持つ）より古く読めないので、作り直している（Slurm 824）

### 本番のテーブルへの効き

既定のまま（ADR-0249）の見込みは約 21〜22.5 時間（自己遮蔽を解く状態 14.85〜16.5 時間、微分の摂動の MOC 1.3 時間、再利用する
状態 4.1 時間、作り直しと検査 0.6 時間。#0180 の「自己遮蔽を省いたときの誤差」の節）。2A-60 の 1 状態の比を、自己遮蔽を解く状態に
当てた見込み:

| 選ぶ項目           | 1 状態の比 | 本番のテーブル     | 差（2A-60）                                |
| ------------------ | ---------: | ------------------ | ------------------------------------------ |
| なし（既定のまま） |      1.000 | 約 21〜22.5 時間   | 0                                          |
| `share = 1e-3`     |      0.650 | 約 15.6〜16.7 時間 | +0.54 pcm（ピンセルの 40 MWd/kg で +1.05） |
| `share = 1e-2`     |      0.590 | 約 14.8〜15.7 時間 | +0.50 pcm                                  |

60 MWd/kg は核種の最も多い燃焼点で、ほかの燃焼点の比はこれより 1 に近い見込み（新しい燃料のピンセルの自己遮蔽の比は 0.74）なので、
本番の縮みはこの見込みより小さい（測っていない）。差が 1 pcm 以内の項目は、測った範囲では `share = 1e-3` が 40 MWd/kg のピンセルで
1.05 pcm と境にあり、`share = 1e-4` の差を待つ。5 pcm 以内は `share = 1e-2` が候補で、ほかの燃料の種類の差を待つ。

### 残りの倍率

`share = 1e-3` の後の 2A-60 の 1 ピン 17.5 スレッド秒の内訳は、衝突確率 5.37、飛程の表 3.25、格子 2.31、静止した標的の部分 1.83、
自由ガス 3.19、S(α, β) 1.14、評価 0.42（ほかに 1 回目だけの移行の区間 3.32）。PSM と比べて残る大きな差と、その案（どれも確かめて
いない）:

- 衝突確率と表（8.6 秒）: PSM は孤立したペレットの表をピンの形状の種類ごとに 1 度作り、影を Carlvik の 2 項の比で補正する（近似。
  PSM-I の表の誤差は 15 pcm）。xlc はピンと自己遮蔽ごとに 3 軸の表を作り、表の外の格子点を厳密に求める。展開の上限を広げる形は
  試して捨てた（下）
- 格子（2.3 秒）: 116 核種の格子の和（118 万点）を許容差で間引く（ADR-0185）。PSM は固定の 5 万点。ピンの間で格子を共有する形は
  試していない
- 静止した標的の部分（1.8 秒）: 核種ごとの窓。PSM の質量でまとめる形（近似）は試していない
- 32 スレッドの 1 回の演算の長さ（1.6〜2.7 倍）: 分けて測っていない

関係する ADR: なし

## 完了の条件

1 ピンの時間の項目ごとの内訳と PSM との倍率、項目ごとの速くなる量と今の UFG からの差（燃料の種類ごと）を測り、既定にする
項目を決める。

## 検討して捨てた形

- 飛程の表の展開の上限を広げる（`track-table-deviation`。ADR-0182 の 0.01 を 0.03 に）: 2A-60 の表の外の格子点は 1 ピン 31,188 →
  3,267、衝突確率 5.32 → 0.91 スレッド秒になったが、広がった軸の表の組が増えて表が 3.25 → 6.31 秒になり、自己遮蔽は 62.9 → 64.9 秒
  （Slurm 828 と 825。どちらも timed、xlc 6c303b913）。k∞ は 6 桁で同じ。格子点ごとの衝突確率と表の組の費用がほぼ同じで速くならない
  ので、入力の項目を戻した
