# 部分ノードに分けたテーブルと、ホウ酸水を混ぜた物質か媒質のある格子の B-10 の微視的断面積

## 問題

ADR-0237 の「検討した案」の案 3 は、状態の `b10` がテーブルと違うときに、テーブルの冷却材の B-10 の均質化した個数密度と微視的断面積（`boron10`）で
少数群定数を補正する案で（採らなかった）、lattice は、部分ノードに分けたテーブル（`split` > 1。ADR-0108）と、ホウ酸水を成分に持つ混ぜた物質
（ADR-0128。軸方向の反射体のノズルなど）か媒質（ADR-0128）のある格子のテーブルには `boron10` を書かない形だった。案 3 を採らなかったので、
今の core はどのテーブルも ADR-0237 の ppm の換算で、`b10` の違う状態を解く。

次は、その案で書かなかった形と、書くのに要ったもの。

- 部分ノード: 部分ノードごとの領域で個数密度と微視的断面積を作る形が要る
- 混ぜた物質: 混ぜた物質の B-10 のうち、ホウ酸水の成分の分（ケースの `b10` で変わる分）だけを分ける形が要る。混ぜた物質の組成は成分の核種を
  温度ごとにまとめる（crates/lattice/src/material.rs の `mixed_nuclides`）ので、同じ温度の B-10 を持つ別の成分と区別できない
- 媒質: 媒質の状態はホウ素の軸に従い（crates/lattice/src/medium.rs の `check_medium`）、細かい群の巨視的断面積に媒質の元の格子のホウ酸水の
  B-10 を含むが、核種に分かれていないので、その分を数えられない

関係する ADR: ADR-0237

## 完了の条件

- 部分ノードに分けたテーブルと、ホウ酸水を混ぜた物質か媒質を持つ格子のテーブルが `boron10` を持ち、core が `b10` の違う状態を解ける。
  直接の格子計算と比べた差を検証の記録に書く

## 経緯

- 2026-11-07: 案 3 の実装で、使う例のない 3 つの形を外した
- 2026-11-07: 案 3 を採らず ADR-0237 の換算にしたので、閉じた
