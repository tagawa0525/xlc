# xs の散乱行列の次数の上限と、高い次数での求積の精度が確かめられていない

## 問題

xs の入力の `scattering-order`（#0014、[ADR-0076](../adr/0076-store-legendre-scattering-moments.md)）は、非負の整数ならどれでも受け付ける。2体反応の散乱行列
（crates/xs/src/multigroup/scatter.rs）は、出射の速さを `MIN_ANGULAR_PIECES` 以上に分け、各区間を 8 点の
Gauss-Legendre で積分する。区間の数は角度分布の次数で決まり、求める Legendre の次数 l には依らない。μ は出射の速さ s の
有理式なので、P_l(μ) の l が大きいと、この求積が十分正確かは確かめていない。確かめた次数は ADR-0076 の既定の 3 まで。
大きい値（20 など）を書くと、検査なしに精度の分からないライブラリを作る。また、記憶量は (次数 + 1) × 群数² に比例する。

## 完了の条件

次数ごとに、散乱行列のモーメントの求積の誤差を（厳密な式がある水素などで）測り、確かめた範囲を ADR で決める。
範囲の外は入力の検査でエラーにする。上限の値は、測った誤差に基づいて決める（根拠なしに決めない）。
