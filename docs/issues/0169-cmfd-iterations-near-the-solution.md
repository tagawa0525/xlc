# CMFD の粗メッシュの反復は、MOC が解の近くでも減らない

## 問題

MOC の反復を前の輸送の解から始めると（ADR-0195）、2A の燃焼の最初の 10 点（examples/depletion/verification.md の「集合体の燃焼」の
「時間」。008a9e03、2026-10-23、Slurm 494）で、MOC の反復は 1 輸送あたり 25 回から 11 回に減ったが、1 回の反復の時間は 0.30 秒から
0.35 秒に増えた。粗メッシュの固有値の反復（`coarse-mesh eigenvalue iterations`。2A は Gauss-Seidel）は 1 回の MOC の反復あたり平均
326 回で、平らな初期値からの最初の輸送（316 回）と変わらない。

粗メッシュの問題は、MOC の中性子束を均質化した値と k から解き始めるので、MOC が解の近くなら初めの値も解の近くにある。それでも
回数が減らない原因は確かめていない。候補: スイープによる変化が小さいと、ADR-0110 の緩め方で設定の精度（k 1e-10、中性子束 1e-8）の
近くまで解くので、残りの誤差の見積もり（`Remaining`）が Gauss-Seidel の遅い縮小率で何百回も要る。

関係する ADR: ADR-0195

## 完了の条件

粗メッシュの反復の回数を、初めの値の誤差と設定の精度に分けて測り、回数が減らない原因を確かめる。原因に合わせて、粗メッシュの
解き方（加速、精度の決め方）を ADR で決めるか、効きが小さいなら閉じる。

## 経緯

- 2026-10-23: ADR-0195 のブランチの 2A の測定で見つけた（/code-review の指摘）
- 2026-10-24: 平らな初期値からの 2A の 1 輸送（60 MWd/kg の組成、16 スレッド、xlc 040e7031、分岐点は main の f3a143d74、Slurm 514）で、MOC の
  反復ごとの粗メッシュの反復は、スイープによる中性子束の変化が 0.78 から 2.7e-5 まで 4 桁下がる 2〜17 回目で 333〜410 回とほぼ一定、変化が
  MOC の判定（1e-6）に近づいて ADR-0110 の緩め方が設定の精度で止まる 18〜24 回目で 73〜293 回だった。緩めた精度は変化に比例し、初めの値
  （MOC の中性子束を均質化した値）の誤差も変化の程度なので、精度と初めの誤差の比（k で 1e-7 / 1e-10、中性子束で 1e-6 / 1e-8 の程度）と
  Gauss-Seidel の縮小率で回数が決まり、MOC が解の近くでも減らない、が今の見立て（縮小率と初めの誤差は直接測っていない）
- 2026-10-24: 粗メッシュの Gauss-Seidel を、前の MOC の反復の粗メッシュの解（生成率 1 に規格化し直したもの）から始める版
  （trials/0163/coarse-start.patch、c9bfdeb67。収束の判定は同じ）は、土台の版（040e7031 から群の届き方の確認の変更を除き、trials/0163/lu-interleave.patch を足したもの。結果は 040e7031 とビットで同じ）と同じジョブ（Slurm 511、2026-10-23）で、粗メッシュの反復の和が 7,574 → 8,049 回（6% 増）、`coarse` が
  1.011 → 1.096 秒で、k の差は 3.5e-12。前の粗メッシュの解は、スイープで変わった今の粗メッシュの問題の解から、均質化した値より遠い。捨てた
- 回数を減らすには、粗メッシュの解き方（Gauss-Seidel の縮小率）を変える要があり、結果がビットで変わるので ADR で決める。16 スレッドの 2A の
  1 輸送（24 回の反復）で `coarse` は 1.03 秒（examples/vera/verification.md の「直列の部分（#0163）」、xlc 040e7031、Slurm 514、2026-10-24）、
  前の輸送から始める燃焼では 1 輸送 11 回の反復で約 0.5 秒（1 回の反復あたりの比から見積もった値で、測っていない）
