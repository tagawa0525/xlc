# 部分挿入のノードの z の 1 ノードの問題が、高さ 30〜46 cm のノードで収束しない

## 問題

小さな炉心（examples/depletion/branches/core-small-plant.toml。2A の 4 × 4 の 1/4、I 型の反射体、高さ 365.76 cm、バンク D を
1/4 の中心側の 1 体に入れる）の状態を燃焼度を与えて解くと（試行。trials/ に置き、残していない）、軸方向のノードの高さが 45.72 cm（8 ノード）と
30.48 cm（12 ノード）では、バンク D を 190 ステップ（先端 302.26 cm）まで入れた状態の一部が
`the one-node z problem of a partially rodded node did not converge in 10000 iterations`（crates/core/src/rods.rs の `homogeneous_faces`）で
止まった。8 ノードでは 18 状態のうち 3（燃焼度 4 MWd/kg の 1300 ppm、8 MWd/kg の 0 と 1300 ppm）、12 ノードではログに 4 件。22.86 cm（16 ノード）と
15.24 cm（24 ノード）では、190 と 140 ステップのどの状態も解けた（main 4549c690 から作ったブランチの `target/release/core`。ブランチの core の変更は燃焼の中点のホウ素の項目だけ。2026-10-29）。

VERA の炉心の計算は軸方向に 8 cm ほどのノードを使うので、Problem 9 の入力では出ない見込みだが、ノードの高さで解けるかが変わる理由は
確かめていない。候補（どれも確かめていない）:

- 収束の判定（面の中性子束の変化 / ノード平均 ≤ 1e-14）が、高いノードの面の中性子束の丸めの下限に近く、変化が判定の上で振動する
- 横方向の漏れの 2 次式と、正味の中性子流を固定した 1D の NEM の反復が、光学的に厚いノードで収束しない（反復の行列の固有値が 1 に近い）

関係する ADR: ADR-0127、ADR-0217

## 完了の条件

- 止まった状態で、反復ごとの変化の履歴を見て、振動か発散かを分ける
- 原因に応じて判定か反復を直し、高いノードの部分挿入を解けるようにするか、解けないノードの高さを入力の検査で止める
