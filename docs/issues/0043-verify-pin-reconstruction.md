# ピン出力の再構成を MOC と比べる

## 問題

ピン出力の判定の閾値は ADR-0118 で決め、反射体を含まないカラーセットでは両方の閾値の内にあった（examples/colorset/
verification.md、b848596d）。残りは、VERA 4-2D、REF1-2D、5-2D での判定。

- 2 段階の手法: ピン出力を、同じ多群定数の xlc の MOC、OpenMC（2D）、KENO と比べる。反射体に接するノードは、角の CDF
  （#0020）が決まるまで再構成できない
- 再構成だけ: 参照の細かいメッシュの拡散（examples/colorset/diffusion.py）は、外周が鏡面反射で、状態が 1 つ、燃料の集合体
  だけの、回さない炉心しか解かない。反射体、真空の辺、回した集合体を扱えるように広げる

関係する ADR: ADR-0118

## 完了の条件

VERA 4-2D、REF1-2D、5-2D の比較を検証の記録に書き、ADR-0118 の閾値で判定する。

## 経緯

- 2026-10-09: ADR-0096 を実装し、残りの検証を記録した
- 2026-10-10: 濃縮度の違う集合体（3.10% と 2.11%）の 2×2 のカラーセットで、再構成だけの誤差と 2 段階の手法の誤差を測った
  （examples/colorset/verification.md、b848596d）。再構成だけ（同じ定数の細かいメッシュの拡散との差）は RMS 0.18%、最大
  0.78%。2 段階の手法（xlc の MOC との差）は RMS 0.95%、出力 0.8 以上の最大 1.8%、k +41.5 pcm で、大部分は単一集合体の定数
  （集合体の平均で +0.54%、−0.69%）による。カラーセットの解から作った定数ではノード法の誤差は 0.3 pcm。残りは 4-2D、
  REF1-2D、5-2D との比較と、閾値の決定
- 2026-10-10: 判定の閾値を、再構成だけの誤差と 2 段階の手法の誤差に分けて決めた（ADR-0118、ユーザーの判断）。カラーセットは
  両方の閾値の内にある。残りは VERA 4-2D、REF1-2D、5-2D での判定（#0020 の後）
- 2026-10-10: 上の行の「カラーセットの解から作った定数ではノード法の誤差は 0.3 pcm」は根拠にならない（ADF をその解から
  作るので当然一致する）。NEM の誤差は、同じ定数の細かいメッシュの拡散との比較（k 0.8 pcm、集合体の平均 0.002%）で見る。
  中央の角の再構成の誤差は、不連続因子を外しても変わらない（RMS 0.179%、最大 0.773%）ので、CDF の扱いによるものではない
- 2026-10-10: 再構成だけの参照の拡散のソルバを、残りの問題を解けるように広げる必要がある（問題の節）
- 2026-10-11: 反射体の角の CDF（今の決定は ADR-0131）が入り、反射体に接するノードを再構成できるようになった。I 型の格子の f* の方法は
  MOC に対して RMS 1.867%、反射体に接する列で 4.874%（examples/reflector/verification.md、df6182db）。REF1-2D の入力（Pyrex
  の集合体を含む 3 × 3）はまだない
- 2026-10-11: ADR-0131 が角の CDF の前の決定を置き換え、真空の辺の角の点の扱いが変わった。I 型の格子の等価性は変わらず（RMS 0.080%）、
  f* の方法は RMS 1.897%、反射体に接する列で 4.946%（examples/reflector/verification.md、09533683）
- 2026-10-11: REF1-2D の仕様（北、西、南の鏡面反射を集合体の中心に置き、中央の行と列のピンを境界の線が通る。付録 I の
  KENO のピン出力は 9 × 9、17 × 9、9 × 17 の部分の集合体を含む）を、lattice の MOC も core も表せない（#0067）。REF1-2D の
  比較は #0067 の後
