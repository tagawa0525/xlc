# ピン出力の再構成を MOC と比べる

## 問題

ピン出力の再構成（ADR-0096）は、均質な裸の正方形の炉心（cos × cos）と、鏡面反射の集合体1体でだけ確かめた。
ADR-0096 の確認に挙げた次の比較が残っている。

- 均質化した定数の同じ問題を細かいメッシュの拡散で解き、均質な形を比べる（再構成だけの誤差）
- 反射体を含まない非均質な体系（濃縮度の違う集合体の 2×2 のカラーセットなど）で、全体を xlc の MOC で解いた
  ピン出力と比べる（2段階の手法の誤差。#0037 の誤差の分け方を使う）
- 4-2D、REF1-2D、5-2D のピン出力を、同じ多群定数の xlc の MOC、OpenMC（2D）、KENO と比べる。反射体に接する
  ノードは角の CDF（#0020）が決まるまで再構成できない
- 判定の閾値（案: xlc の MOC に対してピン出力の差の RMS 1%、出力 0.8 以上のピンの相対の差の最大 3%）はユーザーの
  決定が要る

関係する ADR: なし

## 完了の条件

上の比較を検証の記録に書き、閾値をユーザーと決める。

## 経緯

  （集合体の平均で +0.54%、−0.69%）による。カラーセットの解から作った定数ではノード法の誤差は 0.3 pcm。残りは 4-2D、
