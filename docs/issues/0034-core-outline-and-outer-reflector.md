# 炉心の外形に沿った境界と、燃料に接しない反射体の定数

## 問題

炉心の形の `map` の `-`（ノードを置かない位置。ADR-0105）は、NEM が直方体の外周にしか境界を置けないので、
いまはエラーにしている。直方体を反射体で埋めると、燃料に接しない位置にも反射体のノードが要るが、いまの反射体の
定数（ADR-0095）は燃料と接する辺に f* を持つので、燃料に接しないノードには使えない。ユーザーは、炉外の検出器の
応答を見るときなどに、燃料に接しない反射体（バッフルとバレルの間の水など）を扱う必要を挙げた。

炉外の検出器の応答は、一般には輸送計算で作った応答の重み関数を外周の集合体の出力にかけて求めると理解している
（記憶による。出典は未確認）。厚い水と鋼を通る拡散の近似が悪くなるため。

関係する ADR: ADR-0105、ADR-0132

## 完了の条件

- `-` に面する面の境界条件を決め（真空の比 r をどの格子計算から取るかを含む）、NEM で外形に沿った境界を解く
- 燃料に接しない反射体のノードの定数（f* でない ADF）の作り方を決めて ADR にする
- 炉外の検出器の応答の求め方を、出典を確かめて決める（ノードの拡散の延長か、応答の重み関数か）

- 2026-10-11: 角型の格子（#0029）で、反射体どうしの 2 面の ADF を 1 にする近似が、k −65.4 pcm とノード平均の最大
  +9.61% の差の原因と確認した（反射体を集合体の位置に置いて GET の ADF を使うと差が消える。examples/reflector/
  verification.md）。燃料に接しない反射体のノードの ADF の決定では、GET の ADF を持たせる案は、この
  角型の格子（隣り合う反射体の定数が同じ格子から来る）の再現で差を消した。別の格子の反射体どうしでは測っていない
- 2026-10-11: 方式を ADR-0132（proposed）に書いた。`-` に面する面には、そのノードの定数の、その辺の真空の比 r を課して
  階段の外形のまま解く（5-2D の外形では、`-` に面する面はどれも I 型か角型の格子の真空の辺に当たる）。直方体を
  反射体で埋める案は、仕様書の付録 J の Case 2（階段の水の層の外は void）と ADR-0078 の形状に合わないので採らない。
  燃料から角の点より離れた位置には反射体のノードを置かず、角型のノードは f* でない GET の ADF を持つ（#0029 と合わせる）。
  L 型の格子は形状の拡張（#0068）まで作れないので、5-2D の L 型の位置には当面 I 型の定数を置き、近似の大きさを水だけの反射体の
  小さな階段の炉心で測る。炉外の検出器の応答は、随伴の輸送計算の重み関数を出力分布に掛ける方法が文献の方法で、
  Problem 5 の比較には要らないので M3 では作らず、#0071 に分けた
- 2026-10-11: ADR-0128 の帰結が「#0034 とあわせて決める」とした、径方向の反射体の列の燃料の高さより上と下の層の
  定数は、ADR-0132 では決めていない。外形とは独立なので、別の issue にするか #0030 で扱うかを決める必要がある
- 2026-10-12: ADR-0132 を書き直した。反射体どうしの面は、ADR-0095 の 1 の根拠が見込みだけで角型の格子で崩れたので、
  燃料どうしと同じく各側の ADF を使う（格子の識別子は要らない）。径方向の反射体の列の上下の層は、バッフルのある
  高さに径方向の定数を伸ばし、ノズル、炉心板、水の高さに ADR-0128 のスラブの定数を置き、その真空の面は Marshak を
  明示する（(A1)。r-z の格子との差は #0072）
- 2026-10-12: ADR-0132 を実装して accepted にした（外形の `-` と `outline`、反射体どうしの面の各側の ADF、層の
  `vacuum = "marshak"`、f* の辺が集合体の核分裂のない層に向く面の 1）。角型の格子の炉心で外形と反射体どうしの面を
  確かめた（examples/reflector/verification.md、d6e8b9aa）。5-2D での確認は #0029、上下の層は #0072、炉外の検出器は
