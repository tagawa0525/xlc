# 炉心の外形に沿った境界と、燃料に接しない反射体の定数

## 問題

炉心の形の `map` の `-`（ノードを置かない位置。ADR-0105）は、NEM が直方体の外周にしか境界を置けないので、
いまはエラーにしている。直方体を反射体で埋めると、燃料に接しない位置にも反射体のノードが要るが、いまの反射体の
定数（ADR-0095）は燃料と接する辺に f* を持つので、燃料に接しないノードには使えない。ユーザーは、炉外の検出器の
応答を見るときなどに、燃料に接しない反射体（バッフルとバレルの間の水など）を扱う必要を挙げた。

炉外の検出器の応答は、一般には輸送計算で作った応答の重み関数を外周の集合体の出力にかけて求めると理解している
（記憶による。出典は未確認）。厚い水と鋼を通る拡散の近似が悪くなるため。

関係する ADR: ADR-0105

## 完了の条件

- `-` に面する面の境界条件を決め（真空の比 r をどの格子計算から取るかを含む）、NEM で外形に沿った境界を解く
- 燃料に接しない反射体のノードの定数（f* でない ADF）の作り方を決めて ADR にする
- 炉外の検出器の応答の求め方を、出典を確かめて決める（ノードの拡散の延長か、応答の重み関数か）
