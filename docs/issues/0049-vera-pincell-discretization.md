# VERA のピンセルの入力の方位角と間隔を選び直すか

## 問題

ADR-0111 で集合体の入力だけを方位角 30・間隔 0.03 cm にし、ピンセル（examples/vera/p1/pincell-1B.toml〜1D、方位角 64・間隔 0.02 cm）は
変えなかった。1B を間隔 4 通り（0.05〜0.02 cm）で平均すると、方位角 64 は −45.5 pcm、66 は −15.2 pcm、70 は −13.0 pcm で
（参照は方位角 256・間隔 0.005 cm。examples/vera/verification.md「集合体の入力を方位角 30・間隔 0.03 cm に」の 1B の表、35d8e30 の測定、2026-10-10）、
角の数が奇数の方が小さい。ただし 1B は間隔による幅が大きく（64 で 94 pcm、70 で 13 pcm）、入力の間隔 0.02 cm の 1 点では
64 が −26.6 pcm、70 が −10.0 pcm と、平均とは差の大きさが違う。1 つの間隔で解く入力の誤差は、方位角の数より間隔の選び方で
決まりうる。

関係する ADR: ADR-0111

## 完了の条件

- 1B〜1D で、方位角と間隔の組を、間隔によるばらつきも含めて比べ、ピンセルの入力を変えるかを ADR で決める

## 経緯

- 2026-10-10: ADR-0111 のレビューで、1B の平均では方位角 70 の方が 64 より参照に近いと分かった
