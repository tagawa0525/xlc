# 非分離共鳴の θ が J, K の表の下限（10^-3）より小さく、ライブラリを作れない

## 問題

燃焼鎖の核種の棚卸し（`crates/chain/examples/survey_neutrons.rs`、17cbe1e7、2026-10-14。docs/plans/m4-depletion.md の「核データ」）で、
VERA の燃料の温度（565、600、900、1200 K）と σ0 の 9 点の非分離共鳴の自己遮蔽が、10 評価で `β=…, θ=… is outside the J, K table`
で止まる。θ = Γ/Δ は温度とともに小さくなるので、高い温度だけで止まるものがある。止まった最初の点:

| 核種   | 止まる温度 (K) | β     | θ      |
| ------ | -------------- | ----- | ------ |
| Ne-21  | 1200           | 6.2e6 | 9.6e-4 |
| Ne-22  | 565〜1200      | 1.2e5 | 9.7e-4 |
| Te-132 | 900、1200      | 7.7e5 | 9.8e-4 |
| Nd-148 | 900、1200      | 2.4e5 | 9.8e-4 |
| Nd-150 | 565〜1200      | 1.5e5 | 5.8e-4 |
| Sm-154 | 565〜1200      | 1.3e5 | 2.0e-4 |
| Gd-160 | 565〜1200      | 1.9e8 | 2.9e-4 |
| Au-197 | 565〜1200      | 2.6e7 | 3.2e-9 |
| Cm-250 | 900、1200      | 1.4e5 | 9.3e-4 |
| Cf-252 | 1200           | 3.3e6 | 1.0e-3 |

（β と θ は、その核種で最も低い止まる温度の値）

J, K の表（crates/xs/src/resonance/line_shape.rs）は log10 θ が −3〜6、log10 β が −6〜10 で、β が表より大きいときだけ希釈の極限
J = π/(2β)、K = π/β を返す（ADR-0107）。θ が小さい共鳴（自然幅がドップラー幅より十分狭い）では、線形状の最大値は
ψ(0, θ) ≈ (√π/2) θ なので、希釈の極限の相対の誤差は ψ の最大値/β の程度になる。上の β ≈ 1e5、θ ≈ 1e-3 では約 7e-9 で、
希釈の極限を使ってよいとしている 1e-10（ADR-0107）を超えるので、希釈の極限への切り替えだけでは足りない。

関係する ADR: なし

## 完了の条件

θ が 10^-3 より小さい点でも、許容誤差（ADR-0107）の中で J, K を求める（表を小さい θ へ延ばすか、θ → 0 の線形状（ドップラーの
ガウス形）の漸近形を使うか。決めるときに比べる）。単体テストと、上の 10 評価が棚卸しの道具で読めることで確かめる。
