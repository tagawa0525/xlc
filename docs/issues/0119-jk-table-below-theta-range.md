# 非分離共鳴の θ が J, K の表の下限（10^-3）より小さく、ライブラリを作れない

## 問題

燃焼チェーンの核種の棚卸し（`crates/xs/examples/survey_neutrons.rs`、65ccbd82、2026-10-14。docs/plans/m4-depletion.md の「核データ」）で、
565 K の非分離共鳴の自己遮蔽が、5 評価で `β=…, θ=… is outside the J, K table` で止まる:

| 核種   | β（止まった点） | θ      |
| ------ | --------------- | ------ |
| Ne-22  | 8.9e9           | 8.7e-4 |
| Nd-150 | 6.6e8           | 9.2e-4 |
| Sm-154 | 4.6e8           | 2.5e-4 |
| Gd-160 | 3.8e8           | 3.1e-4 |
| Au-197 | 2.6e7           | 3.2e-9 |

J, K の表（crates/xs/src/resonance/line_shape.rs）は log10 θ が −3〜6、log10 β が −6〜10 で、β が表より大きいときだけ希釈の極限
J = π/(2β)、K = π/β を返す（ADR-0107）。θ = Γ/Δ が 10^-3 より小さい（自然幅がドップラー幅より十分狭い）共鳴では、線形状の
最大値は ψ(0, θ) ≈ (√π/2) θ なので、ψ/β は β が表の範囲の中でも 1e-10 よりずっと小さく、希釈の極限がそのまま成り立つ
（相対の誤差は ψ の最大値/β の程度で、上の 5 件では 1e-12 以下の見込み。確かめていない）。

関係する ADR: なし

## 完了の条件

希釈の極限に切り替える条件を、β の大きさでなく ψ の最大値/β（≤ 1e-10）で決め、θ が表より小さく ψ/β が小さい点で J, K を
返す。θ が表より小さく ψ/β が小さくない点（使う評価にはない）はエラーのままにする。単体テストと、上の 5 評価が棚卸しのツールで
読めることで確かめる。
