# LAW=7 の余弦の範囲が −1〜1 に足りない分布を、通すか止めるか（積分の和の検査の要否）

## 問題

- xs は MF6 の LAW=7 を、表の余弦の範囲で積分する（ADR-0271）。余弦が 2 つ未満か −1〜1 の外ならエラーにし、範囲が −1〜1 より狭い分布は
  そのまま通す（`law7_cosines_over_part_of_the_range_integrate_what_is_given`）
- ENDF-102 の 6.2.9 は、余弦と出射エネルギーが「出射の粒子に開いた範囲の全部を覆う」ことを求める。開いた範囲は、重心が中性子より速い
  しきい値の近くでは前方の円錐 μ_min〜1 になりうる（運動学からの推論で、評価で確かめていない）。しきい値から離れると −1〜1 の全部が開き、
  そこで範囲が足りない分布は評価の誤りで、積分の和が 1 に足りず中性子を黙って失う
- #0311 のレビューで、2 周目は「−1〜1 を覆わない分布が黙って通る」、3 周目は「−1〜1 を求めるのは 6.2.9 より狭く、正しい前方の円錐を止める」、
  4 周目は再び「範囲の足りない分布が黙って中性子を失う」と、同じ点の指摘が往復した。4 つの版の LAW=7（Be-9）の余弦はすべて −1〜1 なので、
  今の評価の結果はどちらでも変わらない
- 候補: (a) 入射エネルギーごとに ∫ g dE' が 1 から許容誤差の外なら止める（LAW=1 の表にも規格化の検査は無い）、(b) 運動学の μ_min を求めて
  余弦の範囲と比べる、(c) 今のまま通す

関係する ADR: [ADR-0271](../adr/0271-group-mf6-law6-and-law7-by-endf-102.md)
