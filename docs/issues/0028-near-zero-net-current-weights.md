# 正味の中性子流がほぼ 0 のノードの、中性子流の重みの拡散係数

## 問題

非反射の格子の核分裂のあるノードの拡散係数は、領域の中性子流をノードの正味の中性子流の向きへ射影した重みで
outflow の輸送断面積を平均して作る（ADR-0104）。正味の中性子流が厳密に 0 ならエラーにするが、対称な位置のノード
（カラーセットの内側など）では正味の中性子流が丸め誤差の程度で 0 でなく、向きが丸め誤差で決まり、重みが打ち消して
（Σw/Σ|w| ≪ 1）D が意味を持たないまま作られる。1つの物質のノードでは重みによらないが、物質が混ざるノードでは
D が誤る。打ち消しの程度はログ（debug）に出している。

関係する ADR: なし

## 完了の条件

打ち消しの程度か、正味の中性子流の大きさ（MOC の収束の許容差との比など）で、重みが定まらないノードを判定する方法を
決め、そのノードで何を使うか（エラーにする、B1 にする、など）を決める。カラーセット（4-2D）で確かめる。

## 経緯

- 2026-10-09: ADR-0104 の実装で、反射体の定数の格子の無限媒質のノードのテストで気づいた（ユーザーの方針で issue にした）
