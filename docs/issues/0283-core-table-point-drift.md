# ミクロ燃焼なしの core の k が、テーブルの点で格子計算の燃焼の履歴からずれる

## 問題

- #0279 の「段 5 の結果」の core（examples/depletion/issue-0279/core-micro/）で、ミクロ燃焼なしの core の k が、テーブルの燃焼度の点で
  格子計算の燃焼の履歴（examples/depletion/p2/lattice-2A.msgpack、md5 c028d773）の k∞ からずれる（値は #0279 の「段 5 の結果」）。ADR-0221 の
  時点の同じ比較（examples/depletion/verification.md の「core のミクロ燃焼（2A の集合体 1 体）」の「結果」）は 0.1 pcm より小さかった
- ずれは core の前の、テーブルを作る格子計算で既にある: table-d0.msgpack の状態の k∞ と履歴の k∞ の差は 17 点で −13.299〜−2.307 pcm
  （core の k との差と同じ。下の「切り分け」の table_history_k.py、xlc b9c947223、2026-11-13）。燃焼度 0 は組成が入力のままでも −2.855 pcm ある
- 原因は不具合でなく、履歴とテーブルを解いた自己遮蔽の既定の違い: 履歴（examples/depletion/p2/dvc.lock の `lattice@2A`。bin/lattice
  md5 598a45ce、ライブラリ md5 a96f4f23、2026-11-07）は自由ガスの上限が分離共鳴を持つ核種も持たない核種も 400 kT の既定で解かれ、
  テーブルは ADR-0243（分離共鳴を持つ核種 31 eV）と ADR-0246（持たない核種 1000 eV）の後の既定で解かれた。履歴のステージは
  2 つの既定の変更の後に作り直していない（ライブラリと bin の deps が changed のまま。作り直しと、同じ食い違いを止める仕組みは #0284）

関係する ADR: なし

## 切り分け

入力は examples/depletion/issue-0283/（table-d0.toml の格子と公称の 1 状態で、燃焼度の点を履歴の 0、20、60 MWd/kg にしたもの）。

(1/k_履歴 − 1/k_テーブル) × 1e5 pcm。xlc ee78f32f3（Slurm 816〜819）と d8fd4171b（Slurm 820、821）、分岐点 30b87d8c3、2026-11-13。

- caps-400、caps-400-library-a96f4f23、bin-598a45ce のテーブルはバイトで同じ（md5 452770a0）。ライブラリの温度の点（ADR-0239）と、
  2026-11-07 から分岐点までの、上限の既定のほかの lattice の変更は、この 3 点の k を変えない
- 寄与（400 kT の両方から、片方を今の既定にした差）: 持たない核種の上限（ADR-0246）が −13.39、−20.34、−29.48 pcm、分離共鳴を持つ核種の
  上限（ADR-0243）が +10.58、+12.88、+16.24 pcm。和は −2.81、−7.46、−13.24 pcm で、両方を今の既定にした差から 400 kT の差を引いた
  −2.82、−7.46、−13.23 pcm と 0.01 pcm 以内で同じ（2 つの効きはほぼ足し合わさる）
- 段 5 のテーブル（891165ae5 の bin、追う 31 核種、17 点）と now.toml（分岐点の bin、追う核種なし、3 点）は、60 MWd/kg で 0.014 pcm 違う
  （−13.299 と −13.313）。候補は 2 つの bin の間の lattice の変更と、入力の違い（追う核種、燃焼度の点の数）で、確かめていない
