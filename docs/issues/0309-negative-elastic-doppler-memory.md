# 負の 0 K の断面積で、ドップラー拡がりの格子が止まらず、メモリを使い尽くす

## 問題

- 0 K の断面積に負の値があると、ドップラー拡がりの格子（`doppler::grid` と `split`）は、両端がどちらも負の区間を、中点が両端の間に
  入らなくなるまで分け続ける（両端の比の判定 `b > 3a` が、a < 0 では常に成り立つ）。分ける深さに上限は無い（`grid` の注釈）
  - 測定（xlc f6360d711 の xs、2026-11-20）: VIII.1 の Fe-54 の `xs nuclide`（温度 565 K の 1 点、メモリの上限 6 GiB）は、0 K の
    再構成（`reconstruct` の span、0.9 秒）を終えたあと、`unresolved_shielding` の span に入る前（`ColdParts::at` の `broaden`）で
    上限の 6 GiB に達し、約 120 秒で止められた。同じ入力の VIII.0 の Fe-54 は 12.9 秒、最大常駐 80 MiB で終わる
  - 何が増えるか: `grid` の格子の点。Fe-54 で広げる反応は 18（MT2、5、102、600〜607、800〜806）で、点ごとに約 176 バイト
    （エネルギー 8、`Vec` の見出し 24、値 18 × 8）。本番の 77.6 GB（Slurm 989）は約 4.4 億点にあたる（バイト数からの見積もり。点の数は
    数えていない）
  - 負の値の出どころ: VIII.1 の Fe-54 の分離共鳴（R 行列、1e-5 eV〜1.036 MeV）の MF3 の弾性散乱のバックグラウンドが負
    （5.45 keV で −1.5e-4 b など、206 点）で、共鳴の弾性散乱との和が 3491.6〜3516.6 eV の 74 点で負になる（最小 −7.3e-5 b）。
    VIII.0 の Fe-54 のバックグラウンドに負の値は無い
- 4 つの版の中性子のファイルの全部（1939 ファイル）の 0 K の再構成で負の値の残る評価（xlc f6360d711、2026-11-20。燃焼のライブラリの
  65 核種に入るのは VIII.1 の Fe-54 だけ）:
  - 分離共鳴の範囲の弾性散乱の和が負（ADR-0267 で 0 にする）: VIII.1 の Fe-54、Ni-60（5.05〜5.06 keV の 70 点、最小 −9.0e-6 b）、
    VII.0 と VII.1 の Ar-40（978 keV の 15 点、最小 −3.0e-2 b）、Gd-152（33 eV〜2.2 keV の 657 点、最小 −8.4e-3 b）、Dy-160
    （333 eV〜1.9 keV の 455 点、最小 −6.1e-3 b）
  - 広げる範囲の負の値（ADR-0267 でエラーにする）: VII.0 の Cl-35（分離共鳴の無い MF3 の弾性散乱が 1e-5〜1.23e-5 eV で負、最小
    −2218 b）、VII.0 の Co-58（MF3 の捕獲のバックグラウンドが −8.2e4 b から始まり、MLBW の捕獲との和が 8.5〜9.5 eV の 42 点で負、
    最小 −3742 b）。4 つの版の中性子の評価のすべての `xs nuclide`（565 K の 1 点）では、この 2 つが 0 K の再構成の検査
    （`pointwise.rs` の `reject_negative_broadened`）で止まる（examples/depletion/verification.md の「中性子の評価のすべての `xs nuclide`」）
  - 広げる上限より上の負の値（ADR-0267 では扱わず、群定数に負のまま入る）: VII.0 の Y-89 の MT91（1.7〜4.1 MeV の 56 点、最小
    −0.26 b）、VIII.1 の Ni-60 の MF3 の弾性散乱（分離共鳴の上端 800 keV の右の値 −1.06e-12 b）
  - 再現: 0 K の再構成（`ColdParts::read` と `at(0.0)`）の表から負の値を数える。ほかに 10 ファイルが MF2 の読み込みで止まる（#0305 の
    3 つ、荷電粒子の対、シフト因子、VIII.1 の Pu-239 の核分裂の対）
- 広げる上限より上の負の値を、エラーにするか、群定数でどう扱うかが決まっていない
- 広げる範囲の負の値の評価（VII.0 の Cl-35、Co-58）を、全核種を処理する（#0292）ときにどう扱うか（評価の誤りとして輸送しない、
  負の値を直す方法を決める）が決まっていない
- 0 K の再構成の検査（ADR-0267）は、上限より上の拡がりの積分の窓（数百 eV）の負の値と、再構成を通らずに `broaden` を呼ぶ例
  （`compare_njoy_broadr`）を見ない。窓の負の値は VIII.1 の Ni-60 の 800 keV の右の値（−1.06e-12 b）だけで、1200 K の `xs nuclide` は
  終わる（xlc 20e70134 の bin、2026-11-20）。格子の側で止めるには `broaden` と `ColdParts::at` をエラーを返す形にする（ADR-0267 の案 E）

関係する ADR: ADR-0267

## 完了の条件

- [x] VIII.1 の Fe-54 の `xs nuclide` が、VIII.0 の Fe-54 と同じ桁のメモリで終わる（ADR-0267）
- [ ] 広げる上限より上の負の値（Y-89 の MT91 など）の扱いと、窓の値を格子の側で止めるか（ADR-0267 の案 E）を決める
- [ ] 広げる範囲の負の値でエラーになる VII.0 の Cl-35、Co-58 の扱いを決める

## 経緯

- 2026-11-20: 版ごとのライブラリ（#0303）の VIII.1 の Fe-54 が、常駐のメモリ 77.6 GB で止められ（Slurm 989）、起こした
- 2026-11-20: 原因を負の 0 K の弾性散乱と格子の判定と測り、分離共鳴の弾性散乱の和を 0 にし、広げる範囲の負の値をエラーにした（ADR-0267）
- 2026-11-20: 4 つの版の中性子の評価のすべてを `xs nuclide` に通し（#0292）、VII.0 の Cl-35、Co-58 が ADR-0267 のエラーで止まることを確かめた
