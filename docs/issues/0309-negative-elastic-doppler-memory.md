# 負の 0 K の断面積で、ドップラー拡がりの格子が止まらず、メモリを使い尽くす

## 問題

- 0 K の断面積に負の値があると、ドップラー拡がりの格子（`doppler::grid` と `split`）は、両端がどちらも負の区間を、中点が両端の間に
  入らなくなるまで分け続ける（両端の比の判定 `b > 3a` が、a < 0 では常に成り立つ）。分ける深さに上限は無い（`grid` の注釈）
  - 測定（xlc f6360d711 の xs、2026-11-20）: VIII.1 の Fe-54 の `xs nuclide`（温度 565 K の 1 点、メモリの上限 6 GiB）は、0 K の
    再構成（`reconstruct` の span、0.9 秒）を終えたあと、`unresolved_shielding` の span に入る前（`ColdParts::at` の `broaden`）で
    上限の 6 GiB に達し、約 120 秒で止められた。同じ入力の VIII.0 の Fe-54 は 12.9 秒、最大常駐 80 MiB で終わる
  - 何が増えるか: `grid` の格子の点。Fe-54 で広げる反応は 18（MT2、5、102、600〜607、800〜806）で、点ごとに約 176 バイト
    （エネルギー 8、`Vec` の見出し 24、値 18 × 8）。本番の 77.6 GB（Slurm 989）は約 4.4 億点にあたる（バイト数からの見積もり。点の数は
    数えていない）
  - 負の値の出どころ: VIII.1 の Fe-54 の分離共鳴（R 行列、1e-5 eV〜1.036 MeV）の MF3 の弾性散乱のバックグラウンドが負
    （5.45 keV で −1.5e-4 b など、206 点）で、共鳴の弾性散乱との和が 3491.6〜3516.6 eV の 74 点で負になる（最小 −7.3e-5 b）。
    VIII.0 の Fe-54 のバックグラウンドに負の値は無い
- 0 K の再構成で負の値の残る評価（4 つの版の中性子のファイルの全部。xlc f6360d711 で前の担当が数え、ADR-0267 の後に 769cb5f1 で
  数え直した。一覧、誤りの種類、宣言、NJOY との差は examples/depletion/verification.md の「版ごとのライブラリの負の 0 K の断面積の宣言」）:
  - 分離共鳴の範囲の弾性散乱の和が負（ADR-0267 で宣言なしで 0 にする）: VIII.1 の Fe-54、Ni-60、VII.0 と VII.1 の Ar-40、Gd-152、Dy-160
  - そのほか（ADR-0267 の「変更」の後は、入力の `negative-to-zero` の宣言が無ければ止まる）: VII.0 の Cl-35 の弾性散乱、Co-58 の捕獲、
    Y-89 の MT91、VIII.1 の Ni-60 の 800 keV の右の弾性散乱。前は、広げる上限より上の Y-89 と Ni-60 は群定数に負のまま入っていた
  - 数えていない: MF2 の荷電粒子の対で止まる 5 ファイル（VII.1、VIII.0、VIII.1 の Cl-35 と VIII.0、VIII.1 の Ca-40。#0264 で読めるように
    なったら、同じ数え方で数え直す）
  - 再現: 0 K の再構成（`ColdParts::read`、宣言なし）が返すエラーを数える。負の値の残る反応はどれも 1 つの文に並ぶ
- 0 K の再構成の検査は、全部の反応の全部のエネルギーの表の点を見るので、拡がりの積分の窓の負の値も止める。再構成を通らずに `broaden` を
  呼ぶ `compare_njoy_broadr` は、NJOY の 0 K の PENDF に負の値があれば止める。格子の側で止める ADR-0267 の案 E は要らない

関係する ADR: ADR-0267

## 完了の条件

- [x] VIII.1 の Fe-54 の `xs nuclide` が、VIII.0 の Fe-54 と同じ桁のメモリで終わる（ADR-0267）
- [x] 広げる上限より上の負の値（Y-89 の MT91 など）の扱いと、窓の値を格子の側で止めるか（ADR-0267 の案 E）を決める（ADR-0267 の「変更」）
- [x] 広げる範囲の負の値でエラーになる VII.0 の Cl-35、Co-58 の扱いを決める: `xs nuclide` が、宣言した入力で終わる（examples/depletion/verification.md の「版ごとのライブラリの負の 0 K の
  断面積の宣言」）

## 検討して捨てた形

- Y-89 の MT91 を 0 にするだけで弾性散乱から引かない: 全断面積が部分反応の和なので、1.7〜4.1 MeV で負の MT91 の分（最大 0.257 b、
  全断面積の約 6%）だけ評価の MT1 より大きくなる。VII.1 は MT1 を変えずに弾性散乱を減らしたので、`take-from` で同じ直し方にした
- 後の版の値で置き換える宣言: VII.1 の Co-58 は共鳴パラメータごと評価し直した別の評価で、負の範囲だけを置き換えると 2 つの評価を
  継ぎ合わせる。Cl-35 は 0 にした 2 点が群の値に 1.2e-5 しか効かず、Y-89 は `take-from` で VII.1 と同じになるので、置き換えの機能は
  足さなかった
- NJOY と同じく、0 K の負の値を残して広げ、広げた後に切る: 負の断面積を広げた値に意味が無く、広げない反応（Y-89 の MT91）は群定数に
  負のまま入る。格子の判定が止まらなくなる入力も残る（ADR-0267 の案 D と同じ理由）
- 丸めの大きさの負の値（VIII.1 の Ni-60 の −1.06e-12 b）をしきい値で宣言なしに 0 にする: その点の全断面積に対する比（1.4e-10）や ENDF の
  有効数字からの目安は物理では決まらず、4 つの版で当たるのは 1 つだけなので、宣言を求めた
- ADR-0272 の `corrections` に実数の欄を足して MF3 の値を書き換える: Co-58 の負の値は MF3 の値でなく MLBW の捕獲との和で、MF3 の
  バックグラウンド（1e-5〜73 eV で負）を書き換えると評価者の打ち消しを消す。テープの欄では書けない

## 経緯

- 2026-11-20: 版ごとのライブラリ（#0303）の VIII.1 の Fe-54 が、常駐のメモリ 77.6 GB で止められ（Slurm 989）、起こした
- 2026-11-20: 原因を負の 0 K の弾性散乱と格子の判定と測り、分離共鳴の弾性散乱の和を 0 にし、広げる範囲の負の値をエラーにした（ADR-0267）
- 2026-11-20: 4 つの版の中性子の評価のすべてを `xs nuclide` に通し（#0292）、VII.0 の Cl-35、Co-58 が ADR-0267 のエラーで止まることを確かめた
- 2026-11-20: 4 つの版の全部の核種を流す求め（ユーザー 2026-11-20、別のセッションが伝えたもの）のため、負の値の検査を全部のエネルギーに
  広げ、入力の `negative-to-zero` で宣言した範囲だけを 0 にするようにして閉じた（ADR-0267 の「変更」）
