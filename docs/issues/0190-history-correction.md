# 履歴の変数と履歴の分岐の補正を lattice と core に入れる

## 問題

ADR-0215 は、ADR-0035 の履歴の補正を、燃焼度で重みを付けた平均の履歴の変数（減速材の密度、制御棒の挿入、Pyrex の挿入）と、
変数ごとに 1 本の履歴の分岐から作る、ミクロ燃焼で追わない核種の分（残り）の少数群定数で行うと決めた。lattice はまだ残りを
書かず、core は履歴の変数を持たない。残りはミクロ燃焼の微視的断面積と均質化した数密度（#0153）を引いて作るので、#0153 が先に要る。

関係する ADR: ADR-0215、ADR-0216、ADR-0218、ADR-0221

## 完了の条件

- `xlc-table` に ADR-0215 の `histories` を書き、core がノードごとの履歴の変数を燃焼のステップで進めて、残りを足す
- ADR-0215 の「確認」のテストが通る
- ADR-0215 の「確認」の測定: 途中で条件を変えた燃焼で、燃焼度で重みを付けた平均（重み 1）の線形の補正の誤差を測る。Pyrex を
  抜いた後を燃焼し直した格子計算で、Pyrex の履歴の変数の線形の補正の誤差を測る。lattice は履歴の途中の組成から条件を変えて
  燃焼を続けられないので、その入力を足す
- #0153 で選んだ追う核種と σᵢ で作った R（ミクロ燃焼の線形化の誤差を含む）の大きさと、連続の軸の瞬時の状態への依存を測る
  （examples/depletion/verification.md の「履歴の効き（2A）」は、輸送で解いた追わない核種の分だけで、R ではない）

  書き足す。変数は減速材の密度、制御棒の値は `out` だけ。core は `histories` を持つテーブルをエラーで止める（足す側を作るまで）。
