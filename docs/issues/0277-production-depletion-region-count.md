# 本番のテーブルの燃焼の領域の数と、測っていない条件

## 問題

ADR-0245 は、本番のテーブルの燃料を MOC の 5 リングのまま 5 つの燃焼の領域で燃焼させ、方位には分けないと決めた。その決定の
根拠の外に、次が残る（値は ADR-0245 の「検討した案」と、そこが指す examples/depletion/verification.md の「ペレットを径方向に
分けた燃焼（#0275）」と「燃料のピンを方位の扇形の組にも分けた燃焼（#0276）」）:

- 5 領域に残る領域の数の効き: ピンセルの 8 領域 − 4 領域は 60 MWd/kg までに収束していない（ADR-0245 の案 Z8）。8 領域の値は
  MOC の 8 リングと格子点ごとの飛程の離散化で、本番の離散化（5 リング、飛程の表）の 5 領域と同じ条件で比べた値は無い。
  離散化の差（1 領域どうし）が分け方の差と同じ大きさにあり、領域の数を増やすには離散化も一緒に決める
- 集合体での効き: 60 MWd/kg までの径方向の効きは、ピンセルと 3 × 3 の格子でしか測っていない（集合体は最初の 0.1 MWd/kg の
  1 点だけ。ADR-0245 の案 Z5）。3 × 3 の格子（`guide`）は案内管の割合が 1/9 で、2A の集合体の 25/289 より高い。作り直す 2A の
  テーブルの履歴と比べられる 1 領域の履歴（p9-product の Slurm 728）は、重い核種の自由ガスの上限が ADR-0243 の前で、条件が
  2 つ違う
- 方位に分けない誤差のうち、扇形の組成の違いが自己遮蔽を変える分（ADR-0244 の案 B1 で落とした分）は測っていない。測る正しい
  経路（2 次元の UFG の減速計算）は無い
- Gd 入りの燃料と Pyrex のある種類の格子: 同じ分け方を当てるかは測っていない。p2 の 2O、2P の Gd 燃料はリングごとに 8 つの物質で
  燃焼させている（docs/issues/0275 の表）。Problem 9 の種類ごとの格子の入力を作るときに決める

関係する ADR: ADR-0244、ADR-0245

## 完了の条件

本番の離散化で領域の数を増やした（と、それに伴って離散化を変えた）ときの k∞ の差を測り、5 領域のままでよいか、増やすなら
離散化と領域の数をどうするかを決める。Gd 入りの燃料と Pyrex のある種類の格子の燃焼の領域の分け方を、その入力を作るときに決める。

## 経緯
