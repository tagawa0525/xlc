# core の NEM で、両側が反射の1ノードの方向の展開係数が発散する

## 問題

core の NEM は、3次・4次の係数 a3、a4 を前の反復の a1、a2 から求める（`xlc_numeric::nem::outflow`）。ある方向の
ノードが1つで両側の面が反射（正味の中性子流 0、β = 1）だと、面の条件が a1 + a3/2 と 3a2 + a4/5 を決め、除去が拡散の項
D/h² よりずっと大きいノードでは a3 ≈ 10 a1、a4 ≈ 35 a2 なので、前の反復の誤差が約 −5 倍（奇の成分）と −2.3 倍
（偶の成分）になり、群の間の結合でさらに増える。丸め誤差から始まって増える。その方向の正味の漏れは o − o = 0 の
ままなので、値が有限のうちは解に効かない。

再現: x に 10 cm × 6 ノード（中性子束 0）、y に 20 cm × 1、z に 300 cm × 1 ノード（反射）の2群の問題で、z の展開係数は
50 回の反復で 7e47、200 回で 1e245 になり、400 回で NaN になって k も NaN になる（2026-10-09、main の 8de0b1b と
同じ計算の core で、テストに一時的に足した反復で確かめた）。軸方向に1層の 2D の炉心は z がこの形で、収束に
約 400 回より多くの反復が要ると止まる。

[ADR-0094](../adr/0094-define-adf-by-one-node-nem.md) の1ノードの問題は両側の正味の中性子流を決めるので、同じ理由で
(a1, a3) と (a2, a4) を同時に解いた。

関係する ADR: なし

## 完了の条件

core の NEM で a3、a4 を、1ノードの問題と同じく a1、a2 と同時に解く（入射の部分中性子流から出射を求める形は保てる）
か、別の方法で発散を止め、上の再現の問題が収束することをテストで確かめる。ADR-0094 の1ノードの問題と core が
同じ計算を共有できるかもあわせて決める。

## 経緯

- 2026-10-09: ADR-0094 の実装で、細かいノードの参照の解の y の面の中性子束が ±0.4（ノード平均の 100 倍）になって
  いたことから分かった
