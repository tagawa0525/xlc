# 燃料の温度が高いほど OpenMC との k の差が小さくなる

## 問題

出典は examples/vera/verification-endfb70.md の「燃料の温度による変化（1B と 1D）」（xlc は d6cc90d9、OpenMC の ENDF/B-VII.0 は 53be609d、
上限の試行は 45e0a205、2026-11-20）。値はそこに書き、ここには未解決の点だけを並べる。

- 1B（燃料 600 K）から 1D（1200 K）への xlc − OpenMC の変化は、核データの版（ENDF/B-VII.0 と VIII.0）によらず同じ大きさで、手法の差である。
  その約 3/4 は、自己遮蔽の減速計算で分離共鳴を持つ核種を自由ガスにする上限の違い（xlc は 31 eV、OpenMC は 400 kT。ADR-0243）による。
  どちらの上限の温度の変化が正しいかは決まっていない（ADR-0243 の案 7 の、共鳴の形を入れた散乱核の参照が無い。#0293 の 9）
- 同じ上限（400 kT）にしても、変化の残りが統計誤差の約 3 倍ある。原因は確かめていない。候補:
  - #0152 に残る UFG の範囲の差の候補（H in H2O の 4〜10 eV の束縛、等価なセル）が燃料の温度で変わること（測っていない）
  - 群ごと・核種ごとの吸収の差には分けていないので、ほかの範囲（非分離共鳴、熱群）にあるかも分からない
- KENO-VI（ENDF/B-VII.0）の温度の変化は、xlc の既定（31 eV）と統計誤差の中で合い、OpenMC（400 kT）と合わない。KENO-VI の共鳴の散乱の扱い
  （自由ガスの範囲、DBRC）は確かめていない（入力は公開されていない）
- 集合体（2B → 2D）の傾きは、今のライブラリと上限では再測定していない（examples/vera/verification.md の「OpenMC との比較」は 05714cea の値）

関係する ADR: ADR-0243

## 完了の条件

次のどちらか。

- 共鳴の形を入れた散乱核の参照（OpenMC の `resonance_scattering`。0 K の弾性散乱の断面積がライブラリに要る。ADR-0204 の案 R2）で 1B と 1D を
  解き、31 eV と 400 kT のどちらの温度の変化が近いかを決めて、既定を ADR-0243 に照らして確かめる
- 同じ上限で残る変化を、燃料の核種ごと・群ごとの吸収の差（`compare_fuel_xs.py`、`compare_balance.py`）に分け、原因を特定して直すか、
  定量化して記録する

## 検討して捨てた形

- 核データの版が原因という見方: ENDF/B-VII.0 を NJOY で処理した OpenMC でも 1B から 1D の変化は VIII.0 と同じ（差は 4 ± 11 pcm）で、
  版では説明できない（上の出典）
- 標的を静止として扱うこと（ADR-0070）が原因という見方: 今の既定は自由ガス（ADR-0209）で、上限を OpenMC と同じにすると変化の約 3/4 が消える。
  残りに効くかは分けていない

## 経緯

- 2026-10-12: ADR-0133 の測り直し（#0070）で、温度による差の傾きが残ることが分かった。2G の AIC の調査（#0082）で起こした
- 2026-11-20: ブランチ fix/0131-endfb70-keno-offset で、ENDF/B-VII.0 の OpenMC（1B、1D）と、上限を 400 kT にした xlc の試行から、版でなく手法の差で、
  その約 3/4 が上限の違いと分かった
