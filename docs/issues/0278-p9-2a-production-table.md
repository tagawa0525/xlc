# Problem 9 の本番の形の 2A の分岐のテーブル

## 問題

炉心の燃焼を最小の入力で縦に通すために、ADR-0239 の格子点で本番の形の 2A のテーブルを作る。入力とステージは
examples/depletion/p9-2A（`branch-2A`。未実行）。

関係する ADR: ADR-0239、ADR-0249、ADR-0251、ADR-0252

- 形: ADR-0239 の格子点（ホウ素 6 点、減速材 7 点、燃料 7 点）を、ADR-0200 の既定の 2 軸の組すべての部分格子（114 状態。うち
  自己遮蔽を解く公称のホウ素の減速材と燃料の組が 49、ホウ素を変えて自己遮蔽を再利用する状態が 65。ADR-0201）で、ADR-0199 の
  27 燃焼点のすべてで解く。ミクロ燃焼の微視的断面積と Pu-240 の数密度の微分（ADR-0216、ADR-0221）を持つ
- 公称でない状態の燃焼点: 間引かずにすべての燃焼点で解く（親のセッションの依頼）。ADR-0200 の「分岐を解く燃焼点」は、間引く点を
  間引いた点の誤差を測ってから入力で決めるとし、制御棒のない 2A で測ったのは小さな分岐だけ（10 点で 0.67 pcm）。本番の大きさの
  分岐の間引きの誤差は測っておらず（#0176 の「公称でない状態を解く燃焼点の間引き」）、すべての点で解いたテーブルはその測定にも
  使える。ADR-0239 の帰結の見積もりは 10 燃焼点の見込みの値
- 燃焼の履歴は p9-product の `lattice-2A` の出力（ADR-0239 の公称の状態、5 つの燃焼の領域（ADR-0245）、40 点）を deps にして読み、
  作り直さない。p9-product の dvc.yaml に足さないのは、p9-product が #0176 の交差の項の真値（直積、4 燃焼点）を測る置き場で、
  本番のテーブルと目的と比べるツールが違うため
- 持たないもの:
  - 制御棒の軸: Problem 5 の装荷（examples/vera/p5/hzp/core-hzp-assemblies.toml）では、Pyrex のない 3.1% の集合体は反射体に面する
    位置（`31-I`、`31-corner`、`31-rcca-I`）だけにあり、制御棒の位置の `31-rcca-I` も反射体に面する格子のテーブルを使う。2A の
    テーブルを制御棒の位置に置くのは時間を測る縦の通し（examples/depletion/p9-timing、branches の小さな炉心）だけなので、縦の通しは
    制御棒を引き抜いた状態で始める。制御棒の軸を足すと、制御棒を入れた組をすべての燃焼点で解く分（ADR-0239 の帰結の見積もり）が増える
  - 履歴の分岐（ADR-0215）: 本番の経路（lattice の入力で選ぶ）は #0190 に残る
- 時間の見積もり（今）: ADR-0249 で微分の摂動の自己遮蔽を状態の組成に固定する既定にした後は、約 21〜22.5 時間（#0180 の「許容する
  誤差ごとの時間」の後の段落。自己遮蔽を解く状態 14.85〜16.5 時間、微分の摂動 1,274 回 × 3.7 秒 = 約 1.3 時間、再利用する状態 4.1 時間、作り直しと
  その検査の約 0.6 時間（測っていない））。
  #0180 の高速化の前の見積もりは次の項。ADR-0251 の既定（`ufg-free-gas.share` の閾値 1e-4 の格子点ごとの散乱の割合の最大）では約 18.2〜19.7 時間の
  見込み（自己遮蔽を解く状態に 2A の 60 MWd/kg の 1 状態の経過時間の外さない経路からの比 0.81〜0.83 を当てた値。#0286 の「本番のテーブルへの
  効き」。ほかの燃焼点の比は測っておらず、静止した標的にする核種は燃焼度の低い点ほど多いので、縮みは見込みより大きくも小さくもなりうる）。
  ADR-0252 の既定（UFG の等価なセルの衝突確率の求積 6 点）を足すと約 16.4〜17.7 時間の見込み（その見込みの自己遮蔽を解く状態の分に、2A-60 の 6 点を足した
  1 状態の比 0.855 を掛けた値。ADR-0251 の既定と 6 点を合わせた 2A-60 は測っていない。ADR-0252 の帰結）
- 時間の見積もり: 排他のジョブ 1 本で約 47 時間（170,700 秒）。CLAUDE.md の「方針」の問題の大きさに釣り合わない時間の項は商用コードの
  桁と比べるが、同じ大きさのテーブルの商用コードの時間は確かめていない。1 集合体の 1 種に 2 日かかるので、流す前に内訳（次の項）を
  出した。直すのは別の作業。公称でない状態を 10 燃焼点だけで解けば約 18 時間（燃焼点あたりの時間の平均から数えた見込みで、点の
  選び方で変わる）。値の出どころ:
  - 短い入力（examples/depletion/p9-2A/short-check/branch-2A-short.toml。7 状態 × 燃焼点 0、0.5、60 MWd/kg）を Slurm 755（区分
    decision、パーティション timed の排他のジョブ、xlc 37d1b0a3a（分岐点 8cb7b88c0）、2026-11-12）で流し、全体は 1,250.1 秒
    （ログの `branches ... total_seconds`）。1 状態の時間（ログの `lattice state=` の `seconds`。数密度の微分の輸送を含む）は次のとおり:

    | 燃焼点 (MWd/kg) | 自己遮蔽を解く状態（4 の平均） | うち数密度の微分（`derivative`） | 自己遮蔽を再利用する状態（3 の平均） |
    | --------------- | ------------------------------ | -------------------------------- | ------------------------------------ |
    | 0               | 47.4 秒                        | 解かない（Pu-240 が 0）          | 5.6 秒                               |
    | 0.5             | 119.0 秒                       | 60.8 秒                          | 8.1 秒                               |
    | 60              | 127.0 秒                       | 62.3 秒                          | 9.7 秒                               |

  - 本番は燃焼点ごとに、自己遮蔽を解く状態 49 と再利用する状態 65。自己遮蔽を解く状態の、微分を除いた時間は p9-product の Slurm 752
    （同じ格子点の直積。49 の温度の組の平均で、燃焼点 0、0.5、32、60 MWd/kg が 41.3、58.0、60.6、64.0 秒。パーティション main だが
    止められていない（`Suspended` 0））から、0.5〜60 MWd/kg は燃焼度で線形に内挿し、0.1 と 0.25 MWd/kg は 0.5 MWd/kg の値に置いた
    （燃焼度 0 の 41.3 秒は核分裂生成物のない組成の値で、0.1 MWd/kg から Xe と Sm を持つため）。燃焼度 0 は 752 の 41.3 秒を使い、755 の
    47.4 秒は使わない（755 は 2 つの温度の 4 状態で、最初の状態は MOC が平らな初期値から 25 回の反復）。微分と再利用する状態は 755 の値を
    0.5〜60 MWd/kg で燃焼度で線形に内挿し（0.1 と 0.25 は 0.5 の値）、27 点で足した。内訳は、自己遮蔽を解く状態 21.6 時間、その数密度の微分 21.7 時間、再利用する状態 4.1 時間。公称の状態は燃焼点ごとに 1 状態で
    約 0.9 時間、残りは分岐。数密度の微分を持たなければ約 23.5 時間（同じ方法。再利用する状態は 752 の 3.8〜4.0 秒）
  - ADR-0239 の帰結の見積もり（燃料だけの集合体で 5.22 時間）は、1 状態 27.0 秒、公称でない状態を 10 燃焼点、微分なしの値。
    今の 1 状態は微分なしで 58〜64 秒（燃焼した点）で、5 つの燃焼の領域と軽い核種の 1000 eV の比（下の「前提の確認」）を掛けた
    27.0 × 1.34 × 1.23 = 44.5 秒より長い。残りの差の原因は確かめていない
  - 前提の確認: 自己遮蔽の時間の比は、燃焼の最初の 1 段（輸送 3 回）の `shielding` の和で、5 領域 / 1 領域が 119.45 / 89.34 = 1.34
    （全体の `total_seconds` では 141.67 / 110.80 = 1.28。examples/depletion/p9-product/short-check の 2 つのログ、Slurm 745、746）、
    1000 eV / 400 kT が 152.49 / 123.78 = 1.23（examples/depletion/issue-0274/light-cap の 2 つのログ、Slurm 751）
- 時間の内訳（Slurm 755 のログの span の `time.busy` の和）: 全体 1,250.1 秒のうち、自己遮蔽 1,085.2 秒（86.8%。20 回。うち子の
  span の `lumps` 40.2 秒、`dancoff` 18.8 秒、`mix` 7.6 秒で、子の span の外の残りが約 1,018 秒。残りはピンごとの UFG の計算と
  みるが、span を分けていないので確かめていない）、MOC 133.4 秒
  （10.7%。35 回）、そのほか約 31 秒（2.5%。ライブラリと履歴の読み込み約 5 秒、B1、均質化、チェックポイント）。自己遮蔽の 20 回は、
  状態の 12 回と数密度の微分の摂動の 8 回（ADR-0221 の決定の「摂動の輸送の自己遮蔽」で、摂動の組成で解き直す）。燃焼の履歴
  （p9-product の Slurm 752 の `lattice-2A`。この表では作り直さない）は 4,818.3 秒のうち自己遮蔽 4,411.4 秒（91.6%）、MOC 306.9 秒、
  燃焼（反応率、行列、CRAM）85.2 秒（1.8%）。自己遮蔽の手間の候補は #0180（掃き直しの範囲が ADR-0246 の 1000 eV で広がった分）、
  #0179（重い核種の自由ガスのスイープの回数）、#0187（32 スレッドの自己遮蔽）に挙がっている。挙がっていない候補: 数密度の微分の
  摂動の自己遮蔽の解き直し（見積もりの 21.7 時間の大半。ADR-0221 は解き直さない分の誤差を −12.49〜+4.45 pcm として解き直すと決めた）と、
  自己遮蔽を再利用するのがホウ素の軸だけであること（ADR-0201。減速材と燃料の温度の 49 の組はすべて解く）。どれも測っていない
- 記憶: Slurm 755 の MaxRSS は 49.5 GB（7 状態）、p9-product の Slurm 752 は 79.4 GB（燃焼と直積の分岐の 2 つのステージのどちらかは
  確かめていない）。搭載量は 86 GB で、114 状態と微分の自己遮蔽を持つ本番の記憶は測っていない
- 止められたとき: パーティション main の排他のジョブは、timed のジョブに止められても SUSPEND で、やり直さずに続きから走る（スキル
  slurm-run の「時間を記録するジョブ（--timed）」）

## 完了の条件

テーブルを作り、炉心の燃焼の縦の通しで読めることを確かめる。今の縦の通しの入力（examples/depletion/p9-timing の core-p9.toml は
制御棒のバンク D を 192 に入れ、すべての燃料の層に 2A のテーブルを置く）は、制御棒の軸のないテーブルを読むと core が止まるので、
制御棒を引き抜いた状態の入力に替えるか、テーブルに制御棒の軸を足すかを決める。
