# 反射体の列の上下の層の定数を r-z の格子と比べる

## 問題

Problem 5 の 3D の炉心の、径方向の反射体の位置の列のうち、ノズル、炉心板、上下の水の高さの層には、ADR-0132 の (A1)
で、ADR-0128 のスラブのその高さの層の定数を置く。スラブの定数は径方向の辺に真空の比 r を持たないので、その層の
真空の面（直方体の外周と外形）は Marshak の条件（r = 1/2）にすることを炉心の形の層に明示する（`vacuum = "marshak"`）。
スラブの定数は、集合体の列（燃料の媒質）の上下で作ったもので、反射体の輪の位置の径方向の中性子束の形も表さない。

原理で最も正確なのは、r-z の 2D の格子（格子の x を炉心の z、y を径方向にとり、集合体の媒質と反射体の輪（バッフルの
ある高さはバッフルと水、ノズルと炉心板の高さはその帯、上下は水）を並べ、径方向の外側を真空にする）で、反射体の列の
ノードごとに定数を作る (C) である。z と径方向の ADF、外側の r、燃料に向く f* が一つの格子からそろう。ADR-0128 の
「各ノードは格子のすべての行にわたる」を外す格子計算の拡張が要る。

仕様書の Problem 4（3 × 3 の集合体）は径方向の外周がすべて鏡面反射で（仕様書の Problem 4 の節）、反射体の列を持たない
ので、この比較には使えない。

関係する ADR: ADR-0132

## 完了の条件

Problem 5（3D）、または反射体の輪のある小さな 3D の炉心（燃料の 2 × 2 と I 型と角型の輪など）を、(A1) の core と
OpenMC（同じ多群でなく連続エネルギーなら、その差を分けて）で比べ、反射体の列の上下の層の近似の効きを、k と、
上下の端の燃料の集合体出力とピン出力で測る。r と ADF を 1 の側に振った感度（たとえば上下の層の外側の面を中性子束
ゼロにした解と反射にした解の差）も並べ、近似が効きうる範囲を示す。

判定: 上下の層の近似の効きが、5-2D と Problem 5 の比較の閾値（ADR-0118 の手法で決めるもの）に対して小さい
（たとえば k で閾値の 1/5 未満、上下の端の集合体出力で 0.2% 未満）なら (A1) のまま閉じる。大きければ (C) の r-z の
格子を作る ADR を書く。
