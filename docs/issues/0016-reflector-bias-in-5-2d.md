# 5-2D の出力分布の比較に、バレルなどを除いた分の偏りが入る

## 問題

[ADR-0078](../adr/0078-put-baffle-in-reflector.md) は、炉心の外の構造をバッフルと周りの水までとし、バレル、中性子パッド、圧力容器を除く。VERA の仕様書の
表 J-1 では、その違い（Case 2 と Case 1）は k で −4.5 pcm だが、集合体出力の最大の差が −0.57%、ピン出力の最大の差が
絶対値で 1.01%、出力 0.8 未満のピンの相対で −5.07% ある。5-2D の出力分布を KENO の値（実際の反射体）と比べると、この
差が偏りとして入る。

関係する ADR: [ADR-0078](../adr/0078-put-baffle-in-reflector.md)

## 完了の条件

5-2D の出力分布の比較で、バレルなどを入れるか、表 J-1 の差を偏りとして差し引いて比べるか、OpenMC の参照解を同じ
反射体で作って比べるかを決め、ADR にする。

## 経緯

- 2026-10-08: ADR のレビューで、表 J-1 の出力分布の差が判断に入っていないことが分かった
