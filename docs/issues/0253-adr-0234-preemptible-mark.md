# ADR-0234 の検討した案の時間に、割り込まれうるジョブの印が無い

## 問題

CLAUDE.md の「計算」の節は、ADR の「検討した案」に `--timed` でないジョブの時間と作業中の版で出した値を目安として書くとき、
コミット（ジョブのコメントの `commit=<hash>[-dirty]`。無ければ実行した版の説明）と、割り込まれうるジョブで時間を記録に使わない
ことを添えるとする。

ADR-0234 の「検討した案」の冒頭の段落は、Slurm 708、709、710 の時間を「目安」とし、版（708 は 056790e5c、709 は作業中の版
（コミットしていない）、710 は 7f9977c14 と同じコード）と「パーティション main」を書いているが、割り込まれうるジョブで時間を
記録に使わないことは書いていない。どのジョブも `commit=` を付ける前（nixfiles の PR #627、2026-11-06 21:19 のマージ）に投げた。

`sacct -j 708,709,710 -X --format=JobID,State,Partition,Suspended` では、3 本とも main で `Suspended` は 00:00:00 だった
（一時停止はされていない）。

ADR-0234 は accepted で、「検討した案」は凍結する部分なので（docs/adr/README.md の「運用」）、その段落には足せない。

関係する ADR: なし

## 完了の条件

ADR-0234 の凍結しない節（「## 補足」など）に、708〜710 が割り込まれうるパーティション main のジョブで、時間を記録に使わないことを
足すか、足さない理由を書いて閉じる。

## 経緯
