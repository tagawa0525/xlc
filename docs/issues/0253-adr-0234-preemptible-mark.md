# ADR-0234 の検討した案の時間に、割り込まれうるジョブの印が無い

## 問題

docs/adr/README.md の「書き方」の、ADR の「検討した案」の目安の時間の例外が添えさせるもの（出した版と、記録に使わない目安で
あること）に対して、ADR-0234 に残る点:

- 「検討した案」の冒頭の段落は、Slurm 708、709、710（`sacct` でどれもパーティション main、`Suspended` は 00:00:00。ログの
  TIME 行は 3 本とも `preemptible:`）の時間を「区分 trial の Slurm のジョブ（パーティション main。待ち行列にほかのジョブは無かった）
  で解いた目安」として引き、パーティションと目安であることは書いているが、割り込まれうるジョブであることは書いていない
- 版は、708 を 056790e5c、709 を「作業中の版（コミットしていない）」、710 を「7f9977c14 と同じコード」と書く。3 本のジョブの
  コメント（`sacct` の SubmitLine の `--comment`）にはブランチ perf/0156-nem-threads と worktree のパスがあり、`commit=` は無い
  （`commit=` を付ける前に投げた）。そのブランチと reflog は本体のリポジトリに無く、ジョブの記録から版を決められない。709 は
  元のコミットも書いていない
- 「決定と理由」は、「検討した案」の 710 の時間から出した「16 スレッドでも 6 % しか縮まない」と、709 と 710 の時間から出した
  「32 スレッドが速くならずばらつきが大きい」を理由に使う（秒の値と Slurm の番号は「検討した案」にだけある）
- 「検討した案」と「決定と理由」は凍結する部分なので（docs/adr/README.md の「運用」）、そこには足せない

関係する ADR: なし

## 完了の条件

ADR-0234 の凍結しない節（「## 補足」など）に、上の点を足すか、足さない理由を書いて閉じる（#0254 の、確定した ADR に当てるかの点の
決定による）。
