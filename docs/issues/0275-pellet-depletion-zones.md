# ペレットを径方向に分けて燃焼させる効果（本番のテーブル）

## 問題

- 本番に向けた 2A のテーブルの履歴（examples/depletion/p9-product/lattice-2A.toml）は、燃料を MOC の 5 リングに切るが物質は 1 つで、
  燃焼の領域はピンの対称操作の組ごとに 1 つ（ADR-0173 の「決定と理由」の 1 項目め）。外側から先に燃える分布（周辺の Pu の蓄積）を
  組成として持たず、各リングの反応率を体積で平均した 1 つの組成を燃焼させる。分けると k∞ と組成がどれだけ動くかは、ピンセルの 40 点
  （60 MWd/kg まで）で測っていない。分けるかを決めるのは親とユーザーで、分けるとテーブルの作り直しになる
- 1C の既存の結果（examples/depletion/verification.md の「格子計算の燃焼」の比較の JSON `compare-1C-rings1.json`、
  `compare-1C-rings4.json`。xlc は 54ab434f、2026-11-03、Slurm 660。OpenMC は 4e9cc7f7（分岐点は main の 2ce95c95）、2026-10-16、Slurm 409）で、xlc の 4 リング − 1 リングの k∞ は 0、0.1、0.5、1、2、3、5 MWd/kg で +17.1、+16.5、+18.3、+20.4、+22.5、+22.2、
  +18.1 pcm で、0 の点からの動きは 5 MWd/kg までに −0.6〜+5.4 pcm。2 本の入力は物質の分け方のほかに MOC のリングの数（5 と 8）と
  飛程の求め方（表と格子点ごと）が違う。0 の点の +17.1 pcm の候補はリングの数と飛程の求め方で（下の 2A のピンセルでは
  0 の点の k∞ が単位の数によらず同じ。1C は条件と xlc の版が違い、確かめていない）、2 つには分けていない。
  OpenMC の同じ差は −52〜+41 pcm（合成の標準偏差 25〜30 pcm）で、燃焼の効きを区別できない。60 MWd/kg までの効きは測っていない
- 既存の比較が燃料をいくつの単位で燃焼させるか（2026-11-11 に入力とスクリプトを開いて確かめた）は、下の表のとおり。
  2A の集合体は、xlc と OpenMC の両方が UO2 燃料をピンごとに 1 単位で燃焼させる同じ模型なので、単位の数そのものは両者の差を直接は作らない。
  残る候補は、1 単位の扱いの違い（xlc はリングの中性子束で反応率を体積の平均にした 1 つの組成、OpenMC は燃料の帯 1 つの tally）で、
  大きさは確かめていない

## 完了の条件

2A の燃料のピンのピンセルで、燃焼の単位 1、4、8（8 リング）と、本番の離散化の 1 と 5 の k∞ と平均の組成の差、2 つ以上の単位の
リングの Pu-239 の分布（最も外と最も内の比）を 60 MWd/kg まで測り、本番のテーブルで燃料を分けるかの推しと時間の増えを示す（分けるかは親とユーザーが決める）。
