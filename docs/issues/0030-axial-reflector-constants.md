# 軸方向の反射体の定数

## 問題

ADR-0095 は、軸方向の反射体（下: 炉心板、ボトムノズル、端栓とギャップ。上: プレナム、端栓、トップノズル、炉心板、
水）の定数を、均質化した燃料と層ごとの均質な物質を並べた 1D の平板の格子計算で作り、燃料と接する面は燃料側の ADF で
割って持つと決めている。まだない。

- 均質化した燃料の物質（単一集合体の計算から、ライブラリの群で中性子束の重みで均質化したもの）を格子計算の物質に
  する入力
- 1D の平板（横の辺を鏡面反射にした長方形のセルの列）のノードを軸方向の層に分ける入力。いまのノードの均質化
  （`few-group` の `nodes`）で作れるが、軸方向の ADF と J/φ を core の z の面に渡す形がない（core は z の面の ADF を 1、
  z の `vacuum` をエラーにする。ADR-0101）
- 外側の 50 cm の水の真空の面は、径方向の反射体と同じく、ANM（ADR-0102）と Koebke の等価理論の D（ADR-0104）で扱う
- 上の層の吸収体を層の断面で体積で混ぜる近似（ADR-0128）の大きさが分かっていない。Problem 5 の全引き抜きで、上の層の
  制御棒の値を棒なしに替えた k の差を測り、KENO との差に比べて無視できなければ、棒のセルを中性子束で均質化した媒質を
  混ぜる形を ADR にする

関係する ADR: [ADR-0128](../adr/0128-make-axial-reflector-constants-in-a-full-height-slab.md)

## 完了の条件

軸方向の反射体の定数を作り、core の z の面で使い、Problem 3 を OpenMC（3D）と KENO の値と比べる（ADR-0095 の確認）。
