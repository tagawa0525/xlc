# 熱水力の繰り返しの収束が遅い（Problem 6 で 33 回）

## 問題

Problem 6（examples/vera/p6/core-6.toml。熱水力のフィードバックの Picard の繰り返し、ADR-0229 の案 I1）は、許容 1e-5 に 33 回の
固有値計算で収束した（Slurm 701、38ab78f0、2026-11-06。examples/vera/p6/core-6.log の `thermal-hydraulics iteration`）。
ノードの出力の変化の最大は、1〜5 回目に 1 回ごとに約 1/3 になり（0.886、0.151、0.0480、0.0151、0.00491）、7 回目からは 1 回ごとに
約 0.82 倍でしか減らない（7 回目 1.64e-3 → 33 回目 9.26e-6）。k は上下に振れながら近づく（7 と 8 回目の差 1.03e-6、32 と 33 回目の差 9.7e-10）。

ADR-0229 の案 I2 は、繰り返しが振動したら緩和を入力の項目として足すとした。1 回の固有値計算は約 0.18 秒（core-6.log の `core seconds` 5.91 秒 / 33。割り込まれうる main のジョブの時間で、目安）で、単一集合体では
時間は問題にならないが、全炉心（Problem 7、9）と燃焼のステップごとの繰り返しでは回数がそのまま時間に掛かる。

遅いモードが何か（軸方向の出力と燃料の温度のモードか、減速材の密度のモードか）は確かめていない。

関係する ADR: ADR-0230

## 完了の条件

遅いモードの原因を測り、緩和（入力の項目。ADR-0229 の案 I2）か別の加速で回数を減らすか、減らさない理由を書く。
