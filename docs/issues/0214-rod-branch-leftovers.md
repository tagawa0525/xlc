# 制御棒のブランチの残り（examples/core の再実行、カラーセットと平板の軸の付け分け）

## 問題

この issue は、#0093 の制御棒のブランチ（ADR-0224）と、その上の #0213（ADR-0225、ADR-0227）で残したもの。

- examples/core の `dvc.lock` は、ステージを替えた（値ごとの 3 つの格子計算と rod_table.py の結合 → 1 つの格子計算）後に
  再実行していないので、新しい `lattice` の記載が無い（古い `lattice@out`、`lattice@aic`、`lattice@b4c`、`table` の記載は、rod_table.py を
  消したときに消した。#0213）。`scripts/dvc-checkout.py` は `table-rods.msgpack` を戻さない。examples/core のステージは main の時点（f86d7fda）ですでに
  bin の変更で 57 本すべてが changed で（`scripts/count-changed-stages.py examples/core/dvc.yaml`）、`rods.msgpack` は今の
  ライブラリの形式で読めない。記録（examples/core/verification.md）の数値は ADR-0209 の前のもの
- ノードごとの出力と制御棒のブランチを組む入力は、ADR-0227 で、置き換えるセルを含むノードのテーブルだけが軸を持つ形にし、径方向の
  反射体の格子（平板でなく、燃料のノードが 1 つ）だけを通した（#0213）。カラーセット（反射体でないノードが 2 つ以上。どのノードにも
  置き換えるセルがある格子を含む）と平板（#0030）は、まだエラーにする
- 残りの形を通すときに決めること: カラーセットの、置き換えるセルを含まないノード（棒の入らない集合体）の定数を、どの値の状態から
  作るか（ADR-0227 の規則では軸を持たず、棒のない値の状態になる。隣の集合体の棒の影響を入れるかは決めていない）。平板の燃料の
  媒質のノードは ADR-0224 で「決めていない」としたが、ADR-0128 の「制御棒の値の定数は、その層全体に棒があり、燃料には棒がない
  平板から作る」からは棒の入らないノードとも読め、ADR-0227 の規則でも、置き換えるセルを含まなければ軸を持たない。#0030 で決める

関係する ADR: ADR-0224、ADR-0225、ADR-0227

## 完了の条件

examples/core を今の bin とライブラリで再実行して `dvc.lock` と記録を書き直す（読む作業が来たとき）。カラーセットと平板の制御棒の
ブランチの形を、それを要る入力を作るときに決めて入れる（平板は #0030）。
