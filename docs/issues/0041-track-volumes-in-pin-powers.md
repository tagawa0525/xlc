# 格子計算のピン出力がトラックから推定した体積で平均している

## 問題

格子計算の `pin-powers`（`power::cell_fission_rates`）は、セルの核分裂率を領域の中性子束 × トラックから推定した体積
（`Solution::volumes`）で足す。ピン出力の再構成の形状関数（ADR-0096）は解析的な体積で平均する。VERA 2B の集合体1体
（トラック間隔 0.05 cm、方位角 32）を鏡面反射で置いた core の再構成のピン出力（平らな均質な解なので、形状関数の
核分裂率そのもの）と、同じ回の格子計算の `pin-powers` は、最大 0.17% 違い、ピンごとに対称なばらつきの形をしていた
（2026-10-09、feat/pin-reconstruction）。

MOC の領域平均の中性子束は、トラックの寄与の和をトラックの体積で割ったものなので、トラックの体積の誤差の多くを打ち
消す。反応率の積分は、それに解析的な体積を掛けるほうが正確と見込む。トラックの体積のずれは測っていない。

関係する ADR: なし

## 完了の条件

- 2B の格子で、領域ごとのトラックの体積と解析的な体積の差を測り、0.17% の差がそれで説明できるかを確かめる
- 格子計算のピン出力を解析的な体積で平均するか、トラックの長さを解析的な体積に合わせて補正するか（MOC で使われる
  方法。先行事例を調べる）を ADR で決める。補正するなら、均質化の体積（`fewgroup::constants`）も同じ扱いにする
- OpenMC との比較（examples/vera）を測り直す

## 経緯

- 2026-10-09: ピン出力の再構成の確認で、形状関数と格子計算のピン出力の差として見つかった
