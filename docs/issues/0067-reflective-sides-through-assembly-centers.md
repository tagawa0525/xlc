# 集合体の中心を通る鏡面反射の辺（半分の集合体）を lattice と core で解く

## 問題

VERA REF1-2D は、北、西、南の鏡面反射の境界を集合体の中心に置く（仕様書の Problem #REF1-2D、105 ページの
Geometry）。付録 I の KENO のピン出力は、B-8 と B-10 が 9 × 9、A-8 と A-10 が 17 × 9、B-9 が 9 × 17、A-9 が 17 × 17 で、
B-8 の 1 行目が集合体の中央の行（計装管と案内管の並び）、1 列目が中央の列である。境界の線は中央の行と列のピンの中心を
通り、その行と列のピンは半分（B-8 と B-10 の角では 4 分の 1）が体系の中にある。体系は東西 10.75 + 21.5 + 21.5 cm、
南北 10.75 + 21.5 + 10.75 cm になる。

xlc はこの形状を表せない。

- lattice: ピンのセルはピッチの正方形の枠に丸ごと置く（`crates/lattice/src/geometry.rs` の `GeometryError::PinSlot`。
  ADR-0108 の背景の「格子計算の形状はセルを丸ごとしか扱わない」）。辺がピンの中心を通るセルを置けない
- core: 炉心の形の `pitch` は 1 つで、装荷図の位置はどれも同じ幅（ADR-0105）。半分の幅のノードを置けない。集合体を
  n × n に分ける `radial-nodes`（ADR-0108）は、反射体のある炉心ではエラーにしている
- 丸ごとの集合体の問題に直す道: 西の鏡映で開くと、東西は反射体、A、B、A、反射体（両側が真空）の有限の体系になる。
  南北は両側が鏡映なので、開くと 8、9、10、9（上下を返したもの）の繰り返しになり、周期境界が要る。周期境界は
  lattice にも core にもない

候補（どれも確かめていない。選んだら ADR にする）:

- lattice に、鏡面反射の辺がセルの中心を通る切ったセル（半分、4 分の 1）を足し（ADR-0108 は、集合体を分ける
  ために同じ形状を、形状と MOC の変更が大きいとして採らなかった）、core に半分の幅のノード（集合体の
  定数を使い、外側の辺が鏡面反射）とその再構成を足す。ピン出力は、切ったセルの核分裂率を体系の中の面積で割れば
  KENO の値（丸ごとのピンの値）と比べられる
- core では、ADR-0108 の `split = 2` の部分ノード（中央の行と列のピンを半分に分けた 4 分の 1 の集合体。分けたセルを
  面積で 1 つに戻す）のうち体系の中にあるものだけを置く道もある。反射体の層を分けるには Kim らの反復が要る（ADR-0108）
- lattice の MOC と core の NEM に周期境界を足し、東西を開いた 5 × 4 の丸ごとの集合体の体系（面積は元の 4 倍。
  東西の鏡映の対称性を使うには B の中心を通る鏡面反射が要るので、使えない）として解く。core には周期境界の NEM の面と、周期の辺の角の CDF（ADR-0131 は扱わない）も要る

5-2D は全炉心で解く（ADR-0090）ので、この機能は要らない。

REF1-2D の入力を作るときの注意: 仕様書（106 ページ）によれば、KENO の計算は燃料とバッフルの隙間を 0.142 cm、バッフルの
厚さを 2.858 cm にした（1.13 節の値は 0.19 cm と 2.85 cm）。examples/reflector の I 型の格子は 1.13 節の値で作っている。
KENO の値と比べるときに、どちらの寸法で解くかを決める必要がある。

REF1-2D の比較は、ADR-0118 の 2 段階の手法の閾値で判定し、反射体に接する列の RMS と最大を別に記録する（ADR-0131 の
確認の節）。core の燃料と反射体にどの定数を使うかは決めていない。

REF1-2D を確認に挙げた ADR-0095、ADR-0098、ADR-0131 の比較は、この issue の後になる。#0020（角の不連続因子）と #0021（中性子流の重み）の
REF1-2D の比較も、完了の条件から外したので、この issue の後に行う。

関係する ADR: なし

## 完了の条件

半分の集合体の扱いを決めて ADR にし、REF1-2D の体系（半分の集合体を含む 3 × 3）を lattice の MOC と core で解いて
ピン出力を出せる。KENO と比べるバッフルの寸法（上の注意）を決める。REF1-2D の比較（#0043 から移したもの）を検証の
記録に書き、ADR-0118 の閾値で判定する。
