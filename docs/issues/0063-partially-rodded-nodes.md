# 制御棒の部分挿入のノードを軸方向の 1D の解で扱う

## 問題

core は制御棒を扱えない。分岐のテーブルに制御棒の離散の軸がなく（ADR-0097 は置き場所だけ決めている）、炉心の入力に
制御棒の型、位置、バンクがなく、ケースにバンクの位置がない。制御棒の先端や棒の中の材料の境界がノードの途中に
あるときの扱いは ADR-0127 で決めた: 軸方向の 1D の細かいメッシュの解の中性子束を重みに区間の定数を混ぜ、z の面に
不連続因子を付ける。

- テーブル: 制御棒の離散の軸（値は材料ごと。VERA は AIC と B4C）を、形式、格子計算の分岐、core の内挿に入れる
- 全引き抜きでも棒は燃料の上の軸方向の反射体の層にあるので、その層の定数（#0030。平板の格子計算は ADR-0128 で済み）
  にも制御棒の軸が要る。上の層のテーブルの制御棒の値の作り方は ADR-0128 の「制御棒の軸」で、この issue の分岐の
  実装と同時か後に入れる。それまでは、棒が燃料の層の外に出る問題を解けない（エラー）
- VERA の棒の区間の並びには、吸収体の上の棒のプレナム（10.7 cm、SS304 の被覆管と He。仕様書の表 8）を入れる。
  全挿入で 377.711〜388.411 cm にあり、上の軸方向の反射体の層に入るので、制御棒なしの値（案内管の中の水）にしない。
  端栓（約 1.9 cm）の軸方向の位置は仕様書から読み取れないので、区間の並びに入れるかは VERA の入力を書くときに決める
- 1D の問題の細かいメッシュの幅は、収束を測って決め、ADR-0127 を accepted にするときに書く

関係する ADR: ADR-0127

## 完了の条件

ADR-0127 を実装し、確認の節の比較（Problem 4 の、メッシュを境界で分けた計算との比較と KENO-VI との比較、Problem 5 の
バンクの価値）を検証の記録に書いて、ADR-0127 を accepted にする。

## 経緯

- 2026-10-11: 文献の比較で方式を ADR-0127（proposed）に決め、実装のために起こした
- 2026-10-11: 軸方向の反射体の定数（ADR-0128）が core の z の面で使えるようになったので、#0030 を待たない。上の層の
  制御棒の軸は、#0030 がこの issue を待つ
- 2026-10-12: ADR-0127 を実装した。分岐のテーブルの制御棒の離散の軸（値の名前。`out` は棒なし）、core の区間ごとの値の
  選択、炉心の形の `[rods]` と状態の `banks`、部分挿入のノードの 1D の細かいメッシュの重みと z の面の不連続因子。
  VERA 2G、2H の定数の燃料の列で、メッシュを先端で分けた参照に対し k の差 4.3 pcm 以内、出力の差 0.7% 以内（体積の
  重みは −2971 pcm まで）、微分価値にカスプが残らないことを確かめ（examples/core/verification.md、83b0e0f8）、細かい
  メッシュの幅を 0.5 cm に決めて ADR-0127 を accepted にした。格子計算の制御棒の分岐は #0093、上の層の制御棒の軸と
  核分裂のない層の部分挿入は #0030、Problem 4 と 5 の KENO と実測値との比較は #0098 に分けた
