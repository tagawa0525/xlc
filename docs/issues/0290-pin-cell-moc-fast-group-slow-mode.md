# ピンセルと小さな格子の MOC の反復が、高速群の k のずれで遅い

## 問題

2A の燃料のピン 1 本（examples/depletion/issue-0289/moc-pin.toml。新しい燃料、外周はすべて鏡面反射）を平らな初期値から解くと、MOC の
反復が 100 回かかる。同じ燃料の 3×3（中央に案内管。moc-three.toml）は 38 回、2A の集合体（moc-assembly-base.toml）は 25 回。
ピンセルと 3×3 は手元（8 スレッド）、xlc a3808255a（分岐点は main の ec65c16fc）、2026-11-17。ログは同じ場所の `.log`（`.dvc` で追跡。
反復、#0289 の trace の中性子束の変化の分け方、粗メッシュの固有値の行の抜粋）。

- ピンセルでは、CMFD の後の粗メッシュの k が 0.245、0.281、0.408、0.539、0.656、… と 10 回ほどかけて 1.24 に近づき、その後も k の変化が
  反復ごとに約 0.88 倍で減る。終わりの反復の中性子束の最大の変化は、群 0（最も高い群）のセルの平均（#0289 の trace の「セルの平均」）。
  3×3 では k の変化が約 0.67 倍で減り、終わりの反復の最大の変化は同じく群 0 のセルの平均
- CMFD で鏡面反射の外周の面の正味の中性子流（今のスイープで出ていく分と、前のスイープで出て戻ってきた分の差。収束すると 0）を 0 に
  すると（a3808255a の入力の項目。今は無い）、ピンセルは 100 → 75 回、3×3 は 38 → 32 回に減り、ピンセルの最初の粗メッシュの k が
  1.2506 になる。止めた k は、ピンセルで 1.24046280 → 1.24046295（差 1.5e-7）、3×3 で 1.25281003 → 1.25281009。0 にした後の
  ピンセルの終わりの反復は、群 0 のセルの中の形の変化が残り、ゆっくり減る（30 回目 2.2e-4、50 回目 7.0e-5、70 回目 1.3e-6）。
  2A の集合体は 25 回で同じ、2A の燃焼の履歴の状態から解く小さな入力では反復が増えた（#0289 の「熱群の遅い成分」の候補ごとの切り分けの表）
- 原因は確かめていない。候補: 外周の面の流れの遅れ（前のスイープで出ていった角度中性子束を次のスイープの入ってくる値にする）を CMFD が
  漏れと読むこと、光学的に薄い高速群で、鏡面反射で戻る角度中性子束の誤差がスイープごとに少ししか減らないこと（CMFD はセルと群ごとの
  比でしか直さない）

ピンセルと小さな格子は単体テスト、燃焼の検証のピン、VERA の Problem 1 で解く。それらの時間の内訳での重さは測っていない。

関係する ADR: なし

## 完了の条件

- [ ] 原因に合わせて、鏡面反射の面の扱いか CMFD の組み方を ADR で決めるか、効きが小さいなら閉じる（2A の集合体の反復を増やさないこと）
