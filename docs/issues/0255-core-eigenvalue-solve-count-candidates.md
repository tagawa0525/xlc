# core の固有値計算の回数を減らす残りの候補（NEM の中の Xe の置き換え、燃焼でない探索と熱水力の初期値）

## 問題

閉じた #0156 に先送りされ、測っても決めてもいない候補が 2 つ残る。

- NEM の外側の反復の中で Xe を置き換える（ADR-0219 の案 F3）: ADR-0219 の検討した案は「固有値計算 1 回分の費用で済むが、部分挿入のノードの定数を
  外側の反復ごとに作り直す仕組み（ADR-0127 の `Refresh`）の中で、区間ごとの線形の補正を作り直すことになり、変える範囲が大きい」とし、帰結で速さの
  issue に残した。その後、平衡 Xe の解き直しとホウ素の探索は同時の反復になった（ADR-0219 の「## 変更」の 2026-11-06）。全炉心で場合 3 を出力のステップに
  した燃焼（examples/depletion/verification.md の「固有値計算の複数のスレッド（小さな炉心と全炉心）」の「全炉心（Problem 9 の形）」、29563b884、Slurm 711 の timed、
  2026-11-06）で、平衡 Xe の解の固有値計算は 8〜12 回、平衡 Xe の解き直しは 7〜8 回
- 燃焼でない臨界ホウ素の探索（`solve_state`）と熱水力の繰り返し（`solve_thermal`）を前の解から始める: ADR-0231 の帰結は「今も固有値計算ごとに平らな
  初期値から解く。同じ形で前の解から始められるが、examples/vera の結果（許容の中で丸めの桁）が変わるので、この ADR の範囲の外」とした。CMFD（ADR-0232）と
  複数のスレッド（ADR-0234）の後に、これらの時間は測っていない

関係する ADR: ADR-0219、ADR-0231

## 完了の条件

それぞれ、固有値計算の回数と時間を今の形と比べて、入れるかを決める。
