# 冷却計算の断面積が全核種を覆うことを確かめ、格子計算の燃焼でも輸送しない核種の反応を数える

## 問題

- テーブルの冷却計算の 1 群の微視的断面積（ADR-0238）の核種は、履歴の輸送する核種と、ライブラリの放射化の核種（xs の入力で
  `activation = true` とした核種）。lattice はチェーンを読まないので、チェーンが反応か核分裂を持つ核種がすべて入っているかを
  確かめない。2A のライブラリ（examples/depletion/p2/xs.toml）は、チェーンの反応を持つ核種がすべて入るように挙げた（ADR-0238 の
  「背景」の前提）。冷却計算を作るときに、core がチェーンと照らす形がない
- 2A のライブラリの放射化の核種から、xs が処理できない 10 核種を除いた（examples/depletion/p2/xs.toml の説明）。Cl-35 と Ca-40 は分離共鳴
  （R 行列の制限形）の荷電粒子の対を xs が扱わない。Tm-169、W-182〜186、Pt-193、Pb-207 は、MF8 が挙げた生成物の状態の経路の和が
  チェーンの反応（MT16、103、107）の断面積を xs の許容より超える群がある（Pt-193 と Pb-207 は 1e-20 b の桁で、反応が 0 に近い群の相対の
  許容で止まる）。2026-11-07 に手元で 465 核種を処理して出たエラー。これらの核種の冷却計算の断面積はテーブルにない
- ENDF/B-VIII.0 の中性子のデータのない核種は、チェーンで崩壊だけを持ち、断面積を持たない。安定か半減期 30 日を超えるものは
  73 核種（He-4、C-14、Co-60、Ag-108m など。2026-11-07 に examples/depletion/chain.msgpack を数えた）。別の放射化のライブラリで反応を
  足すか（ADR-0238 の案 A4）を決めていない
- 格子計算の燃焼（ADR-0173）は、ライブラリにない核種を崩壊だけで追い、放射化の断面積を使わない。冷却計算の燃焼のやり直しは
  放射化の核種の反応を数えるので、公称の条件でやり直した数密度は、履歴の数密度とその反応の分だけ違う（大きさは測っていない）

関係する ADR: ADR-0238

## 完了の条件

- core の冷却計算が、チェーンが反応か核分裂を持つ核種のうちテーブルにないものをエラーにする
- xs が処理できない 10 核種の放射化の断面積を作る（荷電粒子の対、生成物の状態の経路の和の扱い）
- 中性子のデータのない長寿命の核種の扱いを決める
- 格子計算の燃焼が放射化の断面積で輸送しない核種の反応を数えるかを決める（数えるなら ADR にする）
