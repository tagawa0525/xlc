# 冷却計算の断面積が全核種を覆うことを確かめ、格子計算の燃焼でも輸送しない核種の反応を数える

## 問題

- テーブルの冷却計算の 1 群の微視的断面積（ADR-0238）の核種は、履歴の輸送する核種と、ライブラリの放射化の核種（xs の入力で
  `activation = true` とした核種）。lattice はチェーンを読まないので、チェーンが反応か核分裂を持つ核種がすべて入っているかを
  確かめない。2A のライブラリ（examples/depletion/p2/xs.toml）は、チェーンの反応を持つ核種がすべて入るように挙げた（ADR-0238 の
  「背景」の前提）。冷却計算を作るときに、core がチェーンと照らす形がない
- 2A のライブラリの放射化の核種から、xs が処理できない 10 核種を除いた（examples/depletion/p2/xs.toml の説明）。Cl-35 と Ca-40 は分離共鳴
  （R 行列の制限形）の荷電粒子の対を xs が扱わなかった（ADR-0273 で扱うようになった）。Tm-169、W-182〜186、Pt-193、Pb-207 は、MF8 が挙げた生成物の状態の経路の和が
  チェーンの反応（MT16、103、107）の断面積を xs の許容より超える群があった（2026-11-07 に手元で 465 核種を処理して出たエラー）。原因は
  評価の側の不整合で、xs は経路を反応に縮めて警告するようにした（ADR-0172 の「変更」。下の「経路の和の超過の原因」）。8 核種と Cl-35、Ca-40 を 2A の
  ライブラリの放射化の核種に戻すのは残る（ライブラリの作り直しになるので、本番の版の決定の後。examples/depletion/p2/xs.toml の
  除いた理由の注釈も、そのときに直す）。これらと Cl-35、Ca-40 の冷却計算の
  断面積はテーブルにない
- 4 つの版の中性子のファイルを読み込みと形式の検査（`xs check`、ADR-0266）に通すと、荷電粒子の対で止まっていたのは VII.1、VIII.0、VIII.1 の
  Cl-35 と VIII.0、VIII.1 の Ca-40（VII.0 と VII.1 の Ca-40、VII.0 の Cl-35 は LRF=7 でない）。Coulomb の透過因子（ADR-0273）で、5 評価は
  600 K の 1 点の `xs nuclide` を終了コード 0 で通る（examples/depletion/verification.md の「版ごとのライブラリの分離共鳴の R 行列の制限形の
  荷電粒子の粒子対」）。VII.0 の Cl-35 は MF3 の弾性散乱が負で止まる（#0309）。Ca-40 の (n,p)、(n,α) は、NJOY RECONR が障壁の下で透過因子を
  近似するので NJOY と桁で違う（xs は厳密な値のまま警告する）。経路の和の検査は群の平均の値で
  決まるので `xs check` は確かめず、600 K の 1 点の `xs nuclide` の標本では VIII.0 の Tm-169、W-182、W-186、Pt-193、Pb-207 が止まった
  （examples/depletion/verification.md の「中性子のファイルの読み込みの走査」。ADR-0172 の「変更」の後は通る）
- 2A のテーブル（examples/depletion/verification.md の「動特性と冷却計算のデータ（2A）」）の冷却計算の断面積に H-1 がない。燃料の燃焼の
  領域の温度 565 K がライブラリの H-1 の温度の点（S(α,β) の 550、573.6、600 K）になく、履歴が H-1 を輸送しない（燃料の H-1 は (n,p) でできる
  微量）。輸送しない核種で放射化の核種でもないので、冷却計算の断面積から抜ける。原因は、輸送する核種を決める `has_data_at`
  （crates/lattice/src/depletion.rs）が温度の一致だけを見て、S(α,β) の核種の温度の内挿を使わないこと。`Library::lookup`
  （crates/format/src/library.rs）は、S(α,β) の核種で分離共鳴を持たない H-1 の 565 K を 550 と 573.6 K の間で内挿して受ける（2026-11-07 に
  コードとライブラリの H-1 の `thermal_scattering` と `resolved` で確かめた）
- ENDF/B-VIII.0 の中性子のデータのない核種は、チェーンで崩壊だけを持ち、断面積を持たない。安定か半減期 30 日を超えるものは
  73 核種（He-4、C-14、Co-60、Ag-108m など。2026-11-07 に examples/depletion/chain.msgpack を数えた）。別の放射化のライブラリで反応を
  足すか（ADR-0238 の案 A4）を決めていない
- 格子計算の燃焼（ADR-0173）は、ライブラリにない核種を崩壊だけで追い、放射化の断面積を使わない。冷却計算の燃焼のやり直しは
  放射化の核種の反応を数えるので、基準条件でやり直した数密度は、履歴の数密度とその反応の分だけ違う（大きさは測っていない）
- 点が 1 つの軸が入力の物質と違う値のとき、基準条件 x₀ は履歴の輸送と違う状態で、冷却計算の断面積はその状態で黙って作られる（ADR-0238 の
  決定は x₀ と書く）。止めるか、許す理由を書くかを決めていない（#0265 から）

## 経路の和の超過の原因

2026-11-20 に main（939755093）の `xs nuclide` を 600 K の 1 点で 4 つの版の対象の核種に通し、止まった群の値（反応、経路の和、
相対の超過）を出し、評価のファイルの MF3（部分の MT の和を含む）と MF9、MF10 の表を xs と別のスクリプトで点ごとに比べた。
VII.0 に Tm-169、W-185、Pt-193 のファイルは無く、VII.0 の W-182〜186 と VIII.1 の Pb-207 は MF8 が状態を挙げないので止まらない。

| W-184 16   | VII.1、VIII.0、VIII.1 | 6.07〜10 MeV   | 0.2022    | 0.2065       | 2.2e-2     | 10 MeV で 3.1e-2                                                                  |
| W-185 107  | VIII.0、VIII.1        | 6.07〜10 MeV   | 2.188e-6  | 2.265e-6     | 3.5e-2     | 9 MeV で 8.5e-2                                                                   |
| W-186 16   | VII.1、VIII.0、VIII.1 | 6.07〜10 MeV   | 0.2605    | 0.2689       | 3.2e-2     | 8 MeV で 5.1e-2                                                                   |
| Pt-193 103 | VIII.0                | 0.30〜0.50 MeV | 2.467e-18 | 2.476e-18    | 3.7e-3     | 400 keV で 9.3e-3（MF9 の多重度の和が 1.0093）                                    |
| Pt-193 107 | VIII.1                | 1.43〜2.24 keV | 1.285e-5  | 1.370e-5     | 6.6e-2     | 330 eV で 75（MF3 は 1/v、MF10 はほぼ一定）                                       |
| Pb-207 103 | VII.0、VII.1、VIII.0  | 1.35〜2.23 MeV | 8.557e-18 | 8.619e-18    | 7.2e-3     | 1.998 MeV で 8.1e-3（MF10 の基底状態が MF3 と同じ値で、LFS 2 がその上に足される） |

群の値は VIII.0 のもの（VIII.1 の Pt-193 を除く。ほかの版の同じ核種は同じ値）。どれも評価の表の点で経路の和が MF3 を超え、xs の
読み込みや和の取り方の誤りではない。Pt-193 と Pb-207 は、反応が 1e-18 b の桁の群で相対の超過が許容 1e-3 を超えたもので、浮動
小数点の丸めではないので、絶対の床では直さなかった（ADR-0172 の「変更」）。

縮めた後（xlc 2e714a80b、2026-11-20。600 K の 1 点、手元で 1 スレッドずつ 8 並列）は、上の 27 の評価（4 つの版の対象の核種のファイルの
すべて）の `xs nuclide` が終了コード 0 で終わり、MF8 が状態を挙げる 22 の評価が、表の点の最大の超過を上の右の列のとおり警告する。
これまで通っていた評価の出力は、examples/depletion の本番の入力（`xs.toml`、4 温度）の U-238、Zr-90、Fe-58、Np-237、Am-241、
Am-243 で main（939755093）と比べ、U-238、Zr-90、Np-237 はバイトが同じ。Am-241 と Am-243 の MT102（MF9）は相対で 4.2e-16 以下、
Am-243 の MT16 と Fe-58 の MT103（MF10）は最も高い群だけで 6.4e-8 と 7.4e-7 変わった。どれも、評価の値の有効数字（ENDF の 11 文字の
欄）の丸めで経路の和が反応をわずかに超える所（Fe-58 の MT103 は 9 MeV で 1.9e-6）を縮めた分で、許容誤差の内なので警告しない。

関係する ADR: ADR-0172、ADR-0238、ADR-0273

## 完了の条件

- core の冷却計算が、チェーンが反応か核分裂を持つ核種のうちテーブルにないものをエラーにする
- Cl-35 と Ca-40（荷電粒子の対。xs は ADR-0273 で処理する）と、経路の和で外した 8 核種（Tm-169、W-182〜186、Pt-193、Pb-207）を
  2A のライブラリの放射化の核種に戻す（本番の版の決定の後）
- 輸送する核種の判定（`has_data_at`）を `Library::lookup` と同じにし、冷却計算の断面積に H-1 が入る
- 中性子のデータのない長寿命の核種の扱いを決める
- 格子計算の燃焼が放射化の断面積で輸送しない核種の反応を数えるかを決める（数えるなら ADR にする）
- 点が 1 つの軸が入力の物質と違うときの基準条件 x₀ を、止めるか、許す理由を書く

## 経緯

- 2026-11-07: ADR-0238 でテーブルに冷却計算の断面積を入れたときに、残りをここに分けた
