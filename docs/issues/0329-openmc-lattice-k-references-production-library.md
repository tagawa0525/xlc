# 本番の核データの版の OpenMC で、2D の格子の k の参照解を作る

## 問題

- ADR-0175 の「決定と理由」は、2D の格子（今のステージは 1B〜1D、2A〜2K、2Q）の k の手法の差を、本番の核データの版の OpenMC の参照解と
  比べて見ると決めた。今ある参照解は VIII.0 のもの（examples/vera/verification.md の「参照解」）で、本番の版を変えると（ADR-0264。#0303）
  比べられなくなる
- 作り直しの見積もり（15 本で約 39 時間）と、その置き方は ADR-0175 の「帰結」にある。見積もりは標準のタリーの組を持つ 1B、1D、2B の実績からの比例で、
  ほかの集合体の時間は測っていない。その版の OpenMC のライブラリを NJOY で作る時間も測っていない
- 3A と 3B は、本番の版を変えた後は KENO-VI との比較で、約 100〜180 pcm の不確かさを受け入れている（ADR-0175 の「決定と理由」）。r995 に時間があれば、本番の版の
  OpenMC で流すことを考える（ユーザー 2026-11-25。1 本の見積もりは ADR-0175 の「帰結」）

関係する ADR: ADR-0175
