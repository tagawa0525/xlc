# UFG の自由ガスの核の評価の手間

## 問題

ADR-0209 の既定（自由ガスの速い設定 `{ upper = 400, cells = 2, sweeps = 3, heavy = 400, sab = true }`）では、自己遮蔽の時間の大半が自由ガスの核の
D の散乱源（`Thermal::source` の区間の積分）になる。#0180 で S(α,β) の散乱源を並列にした後の 2A の集合体の燃焼の最初の自己遮蔽は 78.4 秒
（前の既定で 9.7 秒）で、39 本の解くピンの `slowing` の和 609.8 秒のうち自由ガスの散乱源が 543.3 秒（examples/depletion/verification.md
「UFG の自己遮蔽の時間の内訳（#0180）」、d2d90202、Slurm 568）。ピンは並列に解くので、2A の時間はこの仕事の和で決まる。2A の燃焼（輸送 81 回）の
ジョブは ADR-0209 の前の 18 分 58 秒から 1 時間 47 分 59 秒になり、自己遮蔽をそのまま 1 回 78 秒とすると、#0180 の後もほぼ同じ見込み（確かめていない）。

自由ガスの散乱源の仕事は、熱中性子のスイープの格子点の数 × スイープの回数 × 自由ガスの核種の数 × 区間の数に比例する。`heavy = 400` で
燃料のすべての分離共鳴を持つ核種（燃焼の入力は 81 核種、数密度が 0 の核種も含む）が自由ガスになるので、核種の数が効く（1C の新しい燃料の
32 核種のピンセルは手元で 1 回の減速計算が 5 秒ほど、燃焼の 81 核種のピンは自己遮蔽 1 回 47.7 秒）。

手間の内訳（1C の 0 MWd/kg のピンセル `issue-0133/pin-1C-0.toml` に ADR-0209 の既定を明示したもの、1 スレッド、手元の perf の flat な
プロファイル、d2d90202 の相当、2026-10-28。時間を記録するジョブではない）:

- `erfcx`（`free_gas::kernel` の erf と erfcx）が全体の 39%。ほとんどが x ≥ 2.5 の 40 段の連分数で、連分数を呼ぶ引数の 78% が
  2.5 ≤ x < 6（手元の計数）。この範囲では連分数の段を減らせない（x = 2.5 で 40 段が倍精度に要る）
- 指数関数（`exp`、`expm1`）が 10% ほど、`kernel` の本体と区間の積分（`Thermal::source` のクロージャ、`Prefix::moments`）が 10% ほど

関係する ADR: ADR-0211、ADR-0213、ADR-0214

## 完了の条件

自由ガスの散乱源の時間を、2A の燃焼のジョブが ADR-0209 の前（19 分）の 2 倍以内になる大きさまで減らす方法を決め、`--timed` のジョブで
測る。erf と erfcx は ADR-0211 で xlc-numeric に 1 つにしたので、xs と lattice は同じ値を使う（変えればライブラリも作り直す）。

次の手（構造的）: 中性子束に依らない部分（下の経緯の 2026-10-28 の「中性子束に依らない部分」）を 1 度だけ求めて持つ形を ADR で決めて
実装する。見込みは 2 つを合わせて 1.82 倍（2A の自己遮蔽の和 3,290.9 → 約 1,810 秒）で、完了の条件の目安（約 1,800 秒、1.83 倍）と同じ
大きさ。進めるかはユーザーの判断（2026-10-28）。試行の入力、計測のパッチ、ログは examples/depletion/issue-0181/。
