# 等価理論の補正に隠れない検証の進め方

## 問題

ADF や SPH などの等価理論の補正は、補正を作った体系では参照を再現するように作る。補正を作った体系で比べて
一致しても、コードの実力を確かめたことにならない。ユーザーは、補正がコードの実力を覆い隠すので、検証をどう
進めるのがよいかを問うた。

いまの検証にも、このような比べ方がある。

- 分岐のテーブルを格子点の上で内挿した core の k が、格子計算の k に一致する（ADR-0097）。作り方が一貫していることの
  確認で、精度の確認ではない。実力を見るのは格子点の間での比較
- 反射体の定数（ADR-0095）は、作った1次元の体系では一致して当然。L 字や角の反射体（#0029）のように、作ったときと
  違う形で試すのが、周りの集合体の影響の検証になる

関係する ADR: なし

## 方針の案

非均質の全炉心の参照（OpenMC、または xlc 自身の2次元全炉心の MOC）に対して、次の3つを比べて誤差を分ける。

1. 参照の解から直接作った均質化定数と ADF を使う core: ノード法そのものの誤差（NEM の空間の離散化など）。
   一般化等価理論では、参照の解から作った定数と ADF でノード法は参照を厳密に再現する（K. Smith, Prog. Nucl.
   Energy 17, 1986）
2. 単一集合体の格子計算から作った定数を使う core: 周りの集合体の影響を無視した誤差。ここが実力
3. 2. から ADF または SPH を外した計算: 補正がどれだけ効いているか。補正の量が大きいほど、隠れている誤差が大きい

参照に xlc 自身の MOC を使うと、ライブラリと輸送計算の誤差が両方に同じように入るので、均質化による誤差だけを
取り出せる。OpenMC との比較は格子計算の精度の検証として別の段にする。

補正を合わせていない量でも比べる。ADF は集合体の平均の反応率と境界の面の中性子束に合わせるので、誤差が打ち
消し合いにくい次の量を見る。

- 再構成したピン出力（ADR-0096）
- 温度係数、ホウ素価値、制御棒の価値などの差の量
- 非均質の強い境界（UO₂ と MOX、ガドリニア入りの燃料、反射体との境）

ベンチマークの候補は次のとおり。

- 2×2 のカラーセット（燃料の種類の違う集合体を市松に並べたもの）
- C5G7（非均質の参照の解がある）
- VERA の Problem 5 の2次元と3次元
- BEAVRS（実機の測定値）

たまったら、それらを参照する入口のページを作る。

## 懸念

- 1. には、参照の解から集合体ごとの定数と境界の面の中性子束を作る道具が要る。OpenMC で面の中性子束を
  どう集計するかを調べる。xlc の MOC を参照にするなら、全炉心の2次元の MOC の計算を回せるかも確かめる
- #0033（集合体を 2×2 のノードに分ける）でも同じ分け方を使う
