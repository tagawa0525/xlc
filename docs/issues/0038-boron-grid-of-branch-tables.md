# 分岐のテーブルのホウ素の格子点の範囲と間隔

## 問題

ADR-0097 はホウ素の格子点の数を測ってから決めることにした。VERA 2B のテーブル（900、1300、1700 ppm）で、格子点の
間隔 400 ppm の中点（1100 と 1500 ppm、565 K）を直接の格子計算と比べると、内挿の k は反応度で 5.00 と 4.82 pcm
大きい（examples/branches/verification.md）。温度の向き（間隔 15 K の中点に近い 560 と 570 K）の差は 0.5 pcm 以下。
core は少数群定数を ppm で線形に内挿する。B-10 の個数密度は ppm に比例するので、誤差は、スペクトルが変わることで
少数群定数がホウ素濃度に対して非線形になることから来る。中点の差が両側で同じ向き（内挿の k が大きい）なので、
曲がり方は範囲の中で同じ向きと見る。

決まっていないことは次の3つ。

- 範囲: いまの 900〜1700 ppm では、サイクルの末期（0 ppm 近く）や高温零出力の初期（2000 ppm を超えることがある）を
  覆えない。範囲の外はエラーにする（ADR-0097）ので、実際のサイクルを扱うには範囲を広げる必要がある
- 間隔: 少数群定数がなめらかなら誤差は間隔の2乗に比例するので、200 ppm なら中点で約 1.2 pcm。範囲を 0〜2400 ppm にすると、
  間隔 400 ppm で7点（状態は 63）、200 ppm で13点（状態は 117）
- 許す誤差: 5 pcm はホウ素価値で割ると約 0.6 ppm に当たる。どこまで許すかの基準をまだ決めていない

関係する ADR: なし

## 懸念

- 減速材温度係数はホウ素濃度で大きく変わる（900 ppm で −1.1、1700 ppm で +15.5 pcm/K）。範囲を広げると、この
  交差の項が線形の内挿で表せるかを、広げた範囲の中点でも確かめる必要がある
- 状態の数は格子計算の時間に比例する（1 状態平均 256 秒。#0039）
- 天然と違う B-10 の割合を天然相当の ppm に直す案（#0036）では、換算後の値がこの範囲に入る必要がある

## 完了の条件

- 許す内挿の誤差と、ホウ素の格子点の範囲と間隔を ADR で決める（先行事例の出典つき）
- 決めた格子で、範囲の端の近くと中点の状態を直接の格子計算と比べ、検証の記録に書く
