# ミクロ燃焼の追う核種の先行核のクロージャを確かめる

## 問題

ADR-0216 の「追う核種」は、追う核種を ADR-0035 の元素の輸送する核種と、それへチェーンの崩壊か輸送する核種の反応で流れ込む輸送する核種
（先行核）の和にし、この選び方の規則を「チェーンを読む core が確かめる」とした。core が持つのはテーブル（追う核種の名前と微視的断面積）と
チェーンで、どの核種を格子計算の燃焼が輸送したか（履歴の `transportable`。ライブラリにあり、燃焼の温度のデータがある核種）を知らない。
チェーンだけでは、先行核が輸送する核種かを決められないので、core は規則のうち次だけを確かめる（crates/core/src/micro.rs の
`MicroChain::new`）: 追う核種がチェーンにあり重ならない、テーブルの反応の並び（MT と経路の数）がチェーンと同じ、テーブルで核分裂する
核種がチェーンの収率を持つ。

輸送する先行核を追う核種から落としたテーブルは、core では補助の核種（崩壊だけ）として解かれ、その核種の反応が抜ける。格子計算の燃焼は
その反応を解くので、公称の条件でも N̄ᵢ⁰ から外れる。

関係する ADR: ADR-0216

## 完了の条件

次のどれかで、規則に外れる追う核種の並びをエラーにする:

- lattice が `[history]` の `micro` を書くときに、履歴の `transportable` とチェーンでクロージャを確かめる（`[history]` はチェーンのファイルを
  読まず、ライブラリのチェーンの反応だけを使う（crates/lattice/src/history.rs）ので、収率と崩壊のためにチェーンを読むようにする）
- テーブルの `micro` に履歴の `transportable` の名前を持たせ、core が確かめる（形式の項目を足すので、ADR-0216 の後から足すとテーブルを
  作り直す。ADR-0033、#0153）

  入れて残した
