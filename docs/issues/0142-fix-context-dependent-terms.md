# 辞書で直せない文脈で変わる語を直す

## 問題

崩れた日本語の語のうち、1 つの語に機械的に直せるものは辞書（nixfiles の ADR-0014）に入れ、履歴ごと直す（#0141）。
文脈で直す語が変わるものは辞書に入れられないので、今のファイルだけを LLM で直す。対象（ユーザーの指示、2026-10-21）:

- 組: 同値類、対、集合、セット、組み合わせ のどれかに
- 段階: 計算の流れ（DVC の stage）は「ステージ」。「2 段階の手法」「段階的」は残す
- 枠: 辞書（支持格子）で直らない残り
- 流す: ジョブは「投入する」か「実行する」
- 手元: 計算機の文脈は「ローカル」。所蔵の意味は残す
- 種: 乱数は「シード」（助数詞の「7 種」は残す。辞書は「乱数の種」の固定句だけを直す）
- 起動し直す: 「再起動」にはしない
- 世代（OpenMC のバッチ）: 辞書は「捨てる世代」「数える世代」の固定句だけを非アクティブ/アクティブバッチにするので、
  同じ段落に残る「1 世代あたり」「数える 20 世代」などを文脈で直す（docs/plans/m4-depletion.md の時間の見積もりなど）
- 調査の表の 1 のうち辞書に入れなかった語: 縦切り、当てにならない、数え直し、引き直す、取り直し（件数が少ない）

下の調査の表の「2. 文脈で変わる」と「3. xlc の用語」が候補の一覧。「1. 辞書に入れる」は、上に挙げた語を除いて
2026-10-21 に辞書に入れた。表の判断はユーザーが決める前のもので、次の点は表でなく辞書と上の一覧が正しい:
起動し直すは再起動にしない。捨てる世代・数える世代は非アクティブ・アクティブバッチ（世代ではない）。釣り合いは
「中性子の釣り合い」を中性子収支、ほかをバランスに分けた。段階（DVC の段階 → ステージ）と枠（支持格子の 8 形）は
辞書に入れ、残りをこの issue で直す。
このファイルは、直す対象の語を例として含むので、.textlintignore で検査から外す（履歴の書き換え #0141 の除くパスにも
渡す）。

関係する ADR: なし

### 5. 辞書に入れるときの注意

- 活用のある語（走らせる、燃やす、測り直す、再実行の 3 語、起動し直す、使い回す）は、prh の 1 規則に 1 活用で書く。
  先に長い句（「走らせ直す」→「再実行する」）を当て、次に短い語（「走らせる」→「実行する」）を当てる順にする
- 「鎖」は「連鎖」「鎖状」を lookbehind・lookahead で除く。「燃焼鎖」→「燃焼チェーン」は「鎖」→「チェーン」で自然に出る
- 「写し」は名詞だけ（後ろが「の」「が」「を」「は」「で」「）」など）。「写して」「写す」は止めない
- 「閉包」は xlc と nixfiles の両方で Nix の closure だけ。数学の閉包を将来書くなら外す規則が要る
- nixfiles 側で件数の多い語: 投げる 83、走らせる 83、走る 75、ローカル 91（既に定着語で書いている）、手元 44、流す 37、前付け 30、包み 24、置き場 22。
  同じ辞書が両方に効くので、「走らせる → 実行する」「前付け → フロントマター」「包み → ラッパー」は nixfiles の履歴も変える
- コミットの本文は大半が英語で、日本語の行は 634 行。履歴の書き換えで変わるのは主に文書とソースのコメント
