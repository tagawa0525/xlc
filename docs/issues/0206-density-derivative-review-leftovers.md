# 数密度の微分（ADR-0221）の N̄ᵢ = 0 の点とレビューの残り

## 問題

ADR-0221 の実装（ブランチ feat/0221-micro-density-derivative）のレビューで見つかったもの。

- N̄ᵢ = 0 の点の微分: lattice は、均質化した数密度 N̄ᵢ が 0 の燃焼度の点で摂動を解かず σᵢ（ADR-0216 の案 Z1）を微分にする（相対の摂動が
  解けないため）。格子全体の微分は、ほかの核種と物質の少数群定数がその核種で変わる分を含み、N = 0 でも消えない。
  examples/depletion/micro の `table-nominal.msgpack`（md5 fde256d9、lattice eda0ff9f）の Pu-240 は、燃焼度 0 の値（σᵢ）が全断面積 291.92、
  175.64 barn、νΣf 2.19、0.10 barn に対し、0.1 MWd/kg（N̄ = 5.28e-10）の微分が 112.21、164.79 barn と −30.46、−54.19 barn で、0.25 MWd/kg の
  113.25、156.61 barn に続く。燃焼度 0 の点は σᵢ との差が大きく、core の燃焼度の内挿は 0 と次の点の間でこの 2 つを混ぜる。2A の Pu-240 では
  0→0.1 MWd/kg の数密度の差が小さく、効きは小さい（測っていない）。0 から生まれる Xe-135 と Sm-149 を微分の核種にするなら、燃焼度 0 の点の
  微分が 0→0.1 MWd/kg の組の予測を変えうるので、ADR-0221 の「Xe-135 と Sm-149 を足しても 0→0.1 の予測は変わらない」は成り立たない。
  候補: N̄ᵢ = 0 の点は絶対の摂動（例: 燃焼の領域に一様に、選んだ燃焼度の点の N̄ᵢ の最大の ε 倍）で解く。決めていない
- 低い燃焼度の点の打ち切りの誤差: 摂動の輸送と状態の輸送は MOC の既定の判定（k 1e-7、中性子束 1e-6）で解くので、εN̄ᵢσ / Σ がそれに近い点
  （Pu-240 の 1 MWd/kg まで）の微分は打ち切りの誤差を含みうる。同じテーブルと ε = 0.05 のテーブル（md5 f072e501）で、0.25 MWd/kg の速い群の
  全断面積の微分は 113.25 と 117.83 barn、0.1 MWd/kg の熱群は 164.79 と 173.82 barn で、ε に比例しない。5 MWd/kg より後の組の ε の差も
  11→12 MWd/kg が +4.62 pcm と前後（+3.84、+3.67 pcm）より大きい。ADR-0221 の D2c の「差が ε に比例するなら」の外挿は、この分を分けていない。
  候補: 摂動の輸送と状態の輸送を細かい判定で解く、εN̄ᵢσ / Σ の下限を置く
- 記録の表のツール（examples/verification_tables.py の `micro_linearization_derivative`）は、列の見出しの ε（0.1 と 0.05）を表の登録に
  書き、JSON は ε も置き換えた組成のテーブルも持たないので、別の ε や別の置き換えた組成で作った JSON でも同じ見出しで描く。
  候補: compare_linearization.py が JSON に置き換えた組成のテーブルの md5 を並べて表のツールが 2 つの JSON で同じことを確かめる、テーブルに ε を書く

- 重複と無駄（レビューの 2 周目）: crates/core/src/rods.rs の `mix_micro` は、微分の混ぜ方を微視的断面積の `by_group` と散乱の平均の
  コピーで書き、`held` は型を変えるためだけに作る（clippy の `expect_used` で `expect` を使えない）。crates/lattice/src/history.rs の
  `perturbed` は、1 核種を変えるために燃焼の領域の全核種の数密度を状態と参照ごとに複製する。どちらも結果は変えない

関係する ADR: ADR-0221

## 完了の条件

- N̄ᵢ = 0 の点の微分の扱いを決め（ADR-0221 を直すか新しい ADR）、Xe-135 と Sm-149 を微分の核種にして 0→0.1 MWd/kg の組を測る
- 微分の打ち切りの誤差の大きさを、判定を細かくした輸送と比べて測る
- 表のツールが ε と置き換えた組成の食い違いを止める
