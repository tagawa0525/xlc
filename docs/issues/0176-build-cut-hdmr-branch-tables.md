# 燃焼度の軸を持つブランチのテーブルを部分格子で作り、残りの誤差を測る

## 問題

ADR-0200 は、燃焼度の軸を持つブランチのテーブルを、基準条件と 1 軸ずつの分岐と 2 軸の組の部分格子（cut-HDMR の 2 次）で作り、
制御棒を入れた格子を同じ形の別の組にし、ブランチ条件を燃焼点の一部だけで解くと決めた（proposed）。実装と、決定の前提のうち
測っていないものが残っている。

関係する ADR: ADR-0200、ADR-0239、ADR-0242、ADR-0253

- 実装（済み。ADR-0200 の「形式と入力」と「確認」）: `xlc-table` の点の集合の形式、lattice の部分格子の状態とブランチ条件の燃焼点、
  core の cut-HDMR の組み立てと、基準条件との差の燃焼度の内挿
- ブランチ条件を解く燃焼点の間引き: 2A（毒物のない燃料）の 17 点のテーブルの、制御棒のない小さな分岐（ホウ素 −300 ppm、燃料 +35 K）
  でしか測っていない（10 点で 0.67 pcm）。制御棒を入れた状態の差（2A でも数千 pcm）と、本番の大きさの分岐と、Gd（2O、2P）と Pyrex（2F）の
  燃え尽きの近くで、差の内挿の誤差を測る。測るまで、それらの組はすべての燃焼点で解く（ADR-0200）。制御棒のない 2A は 15 点、Gd 燃料の
  集合体の制御棒のない組は公称 35 点と公称でない 19 点に決めた（下の 2026-11-17 と 2026-11-19）

    解く。変えた軸ごとに燃焼点の数を変える）。燃焼点を減らす方向はよいとして、すべての燃焼点にすべての瞬時ブランチが要るのかという

## 完了の条件

燃焼点の間引き（制御棒を入れた組、本番の大きさの分岐、Pyrex。Gd の制御棒のない組は ADR-0253 で決めた）と、HFP の範囲の 3 次の項と M×F の誤差を測って記録に書く（目安を
超えれば、入力の `subgrids` か `off-nominal-burnup` で持つ組か燃焼点を増やす）。ADR-0239 の格子点の間の内挿の誤差は 2A の直積の
テーブルで測って記録し、内挿の方式を ADR-0242 で決めた（実装した core の内挿で本番の間隔の誤差を測り、熱水力のないケースの減速材の軸の誤差をそのケースの格子点で
測る）。実装と ADR-0200 の「確認」のテストは済んだ。
