# ENDF/B-VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告を確かめ、本番の核データの版を決める

## 問題

本番の核データ（ENDF/B-VIII.0。ADR-0020）が軽水炉の燃焼で反応度を低く見積もるという報告があり、版を決め直す。文献の内容、VERA の参照解の版、
4 つの版の案の比較、候補（VII.0）は ADR-0264（proposed）にある。ここには未解決の点だけを並べる。

- VII.0 が、燃焼の反応度で VII.1 と同じ側にいるか。読んだ文献に VII.0 を燃焼で比べた記述が無い
- VIII.0 と VII.1 の差の燃焼度への依り方が、2 つの資料で食い違う（燃焼とともに広がるか、初めからほぼ一定か。ADR-0264 の背景）。実測と比べる
  Problem 9 のサイクル 1 は 16.939 GWd/MT まで（docs/plans/m4-depletion.md）なので、この範囲での大きさを xlc で測る
- VII.0、VII.1、VIII.1 の中性子のファイルを、燃焼チェーンの全核種で xs が読めるか。1B の主な 16 核種は VII.1 と VIII.1 で読めた
  （ADR-0264 の背景）。ADR-0167 は、VIII.1 が使いうる共鳴の表現に未対応のものがあると書いている
- 核分裂収率と崩壊データの版ごとの違いが、値の違いか書き方の違いか。数値で比べるツールが無い
- 読めていない文献が 3 つある（ADR-0264 の背景。U-238 の共鳴領域の捕獲を原因に置く IAEA の報告を含む）
- 版を替える費用: xlc のライブラリ、燃焼チェーン（崩壊と収率のファイルから作る。ADR-0164。収率の重みは VIII.0 で測った。ADR-0183）、
  燃焼の履歴、テーブルに加えて、OpenMC の参照解（燃焼を含む）を同じ版で作り直す
- k の手法の差を何と比べて見るか（#0302）と、出力の規格化（#0293 の項目 3。核分裂の Q 値は版で変わる。examples/depletion/verification.md の
  「出力の規格化を OpenMC の燃焼で確かめる（項目 3）」）は、本番の版と合わせて決める

関係する ADR: ADR-0262、ADR-0263（版ごとの燃焼チェーン）、ADR-0264（本番の版の候補）

## 完了の条件

- [ ] 読めていない 3 つの文献を読む（読めなければ、その旨を ADR-0264 に書く）
- [ ] VII.0、VII.1、VIII.1 の中性子のファイルを、燃焼チェーンの全核種で xs が読めるかを試す
- [ ] 核分裂収率と崩壊データの版ごとの違いを、数値（収率、半減期、分岐比、崩壊のエネルギー）で比べるツールを作る
- [ ] 1 つのピンセルの燃焼で、4 つの版の反応度の差を、Problem 9 の範囲（約 17 MWd/kg）と 60 MWd/kg までの燃焼度ごとに測る
- [ ] ADR-0264 を確定する（本番の作り直しの前）
