# ENDF/B-VIII.0 は軽水炉の燃焼で反応度を低く見積もると報告されていて、本番の核データの版を決め直す必要がある

## 問題

本番の核データは ENDF/B-VIII.0（ADR-0020）で、燃焼の検証は同じ VIII.0 の OpenMC と比べている。この比較には核データそのものの偏りは
表れない（xlc と参照の両方に同じように入る）。偏りが表れるのは、実機の炉心追跡（臨界ホウ素濃度）と比べるときである。

文献の報告（2026-11-20 に検索の結果の要約で読んだ。論文の本文は開いていない）:

- ORNL（Kim、Wieselquist、J. Nucl. Eng. 2(4), 2021、<https://www.mdpi.com/2673-4362/2/4/26/html>）: PWR の燃焼で、VIII.0 は VII.1 に比べて
  反応度を低く見積もり、差は燃焼とともに広がる。ORNL の CSEWG 2020 の資料では 60 MWd/kgU で約 600 pcm（Serpent）。効く核種は
  Pu-239、U-235、O-16、U-238。発電所のデータとの比較でも過小評価が見えるとしている
- IAEA（Trkov ら）: 原因の中心を U-238 の共鳴領域の捕獲の評価に置く
- Studsvik（Ferrer、Wemple、CSEWG 2023 の資料）: VIII 系は k∞ と全炉心の k-eff を低く見積もる傾向があり、Pu-239 を JENDL-4 の評価に
  替えると VII.1 に近づく
- ENDF/B-VIII.1 の論文（arXiv 2511.03564）: 燃焼に伴う反応度の低下のベンチマークで 2σ 以内に入り、高い燃焼度で改善した

決まっていないこと、確かめていないこと:

- 本番の版をどれにするか: VIII.1 に移る、VII.0（検証用ライブラリが既にある。ADR-0175）にする、VIII.0 のまま偏りを知ったうえで続ける
- xlc が VIII.1 の評価を読めるか（ADR-0167 は、VIII.1 が使いうる共鳴の表現に未対応のものがあると書いている）
- VII.0 が VII.1 と同じ燃焼の傾向かどうか（報告の比較の相手は VII.1）
- xlc の VIII.0 のライブラリで、報告の大きさ（60 MWd/kgU で約 600 pcm）が再現するか
- 版を替える費用: xlc のライブラリ、燃焼の履歴、テーブルに加えて、OpenMC の参照解（燃焼を含む）を同じ版で作り直す（手法の検証は
  同じ核データで比べる。ADR-0031、ADR-0175）

関係する ADR: ADR-0020

## 完了の条件

- [ ] 文献の値を本文で確かめる
- [ ] xlc が VIII.1 の評価を読めるかを、VERA の 1B の核種で試す
- [ ] 1 つのピンセルの燃焼で、版（VIII.0、VIII.1 か VII.0）による反応度の差を燃焼度ごとに測る
- [ ] 本番の版を決め、ADR-0020 の「## 変更」か新しい ADR に書く。本番の作り直しの前に決める
