# ENDF/B-VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告を確かめ、本番の核データの版を決める

## 問題

本番の核データは ENDF/B-VIII.0（ADR-0020）で、燃焼の検証は同じ VIII.0 の OpenMC と比べている。この比較には核データそのものの偏りは
表れない（xlc と参照の両方に同じように入る）。偏りが表れるのは、実機の炉心追跡（Problem 9 の臨界ホウ素濃度）と比べるときである。

文献の報告（2026-11-20 に本文を開いて読んだ。PDF は `references/papers/`、URL と sha256 は docs/specs.sha256）:

- ORNL（Kim、Wieselquist、J. Nucl. Eng. 2(4), 2021。`kim-wieselquist-2021-endfb80-vs-71-lwr.pdf` の 3.1.3 節）: VERA の燃焼ベンチマーク問題を
  Serpent で解き、VIII.0 は VII.1 より高い燃焼度で k を低く見積もる。60 MWd/kgU での差は k で約 400 pcm、反応度で 650 pcm。燃焼度 0 では
  U-238（+230 pcm）、U-235（−210 pcm）、O-16（−120 pcm）が打ち消し合い、燃焼が進むと Pu-239 の寄与が負に伸び、U-238 も 40 MWd/kgU より上で
  負になる
- ENDF/B-VIII.1 の公開論文（`endfb81-2025-arxiv-2511.03564.pdf` の XIV.D）: VII.1 を基準に置く（産業界で日常の炉心管理に使われ、運転中の炉の
  測定と最もよく合うとする）。VIII.0 は VII.1 に対して約 −500 pcm の振れがあり、調整なしには産業界が受け入れられないとする。VIII.1 は、
  Serpent の TMI-1 のピンセルで燃焼の初めに VII.1 より約 300 pcm 低く、30 MWd/kg で VII.1 に近づく。燃焼に伴う反応度の低下の VII.1 との差は
  ほぼ一定になったとする。実測に基づくベンチマーク（IRPhE/DUKE）では VII.1 が 1σ 付近、VIII.0 と VIII.1 が 2σ 以内。CASMO5（Studsvik）では、
  途中の版（β1）が 0〜20 MWd/kg で VII.1 より最大 600 pcm 低く、原因は Pu-239 の評価で、最終版は VII.1 の性能を実質的に回復したとする
  （臨界実験と燃焼の間の妥協と書く）。核分裂あたりのエネルギーの仮定が反応度の傾きに最も強く効くという記述は XIV.D.4（下の出力の規格化の項）
- Studsvik（Ferrer、Wemple、Mini-CSEWG 2023。`ferrer-wemple-mini-csewg-e8r1-casmo5.pdf`）: CASMO5 の既定のライブラリは VII.1（E7R1）で、VII.0 の
  ライブラリも持つ。β1 の Pu-239 を JENDL-4 の評価に替えると VII.1 に近づく
- ORNL（Procop、CSEWG 2026 年 1 月。`procop-csewg2026-snf-validation.pdf`）: 使用済燃料の核種の量の計算と実測の比で、U-235 は VIII.0 が高い
  燃焼度で 6% の過小評価、Pu-239 は 3 つの版（VII.1、VIII.0、VIII.1）でおおむね一致。VIII.1 の U-235 は図だけで、本文の文字からは読めない
- 読んだ 4 つの資料に、VII.0 を燃焼で比べた記述は無い
- 読めていないもの: IAEA の INDC(NDS)-0893（U-238 の共鳴領域の捕獲を原因に置くとされる。取得が HTML になった）、VERA の問題 1〜5 を VII.0 と VII.1 で
  解いた UNIST の MCS の論文（同じ）、VERA の 2B、2P の燃焼を VII.1 の MCNP で解いた論文（未取得）

VERA の参照解の版（2026-11-20 に確かめた）:

- 仕様書（`references/vera/spec.txt`）の問題 1〜5 の参照解は KENO-VI の ENDF/B-VII.0 で、付録に VI.8 の結果がある。VII.1 の参照解は無い
- 仕様書の外では、問題 6、7 の MC21 の解が VII.1（`mc21-ctf-vera-problems-6-7.pdf` の本文）。VERA の燃焼ベンチマークを VII.1 の Serpent で
  解いた結果が上の ORNL の論文にある（数値の表があるかは確かめていない）
- 問題 9 の参照は実測の臨界ホウ素濃度で、版に依らない

今夜の試行（2026-11-20、手元の実行。ステージではない）:

- 中性子のファイルの読み込み: examples/vera/xs.toml の `endf-directory` だけを VIII.1、VII.1 のディレクトリに替え、main 5e67e41e7 の `bin/xs nuclide` で
  1B の主な 16 核種（U-234、U-235、U-236、U-238、O-16、H-1、B-10、B-11、Zr-90、Zr-91、Zr-92、Zr-94、Zr-96、Fe-56、Cr-52、Sn-120。熱散乱は VIII.0 の
  まま）を処理し、どちらの版も 16 核種とも終了コード 0 で終わった。VII.0 と VIII.0 は 60 核種のライブラリがある（ADR-0175）。Pu と核分裂生成物は
  どの新しい版でも試していない
- 核分裂収率と崩壊データの版ごとの違い（物質ごとに MF8 の行の列 1〜66 が同じかを比べた。文字の一致で、数値の比較ではない）: 収率の 31 核種は、
  VII.1 と VIII.0 が 31 とも同じ、VII.0 と VII.1 は Pu-239 だけが違い、VIII.0 と VIII.1 は 31 とも違う。崩壊データは、VII.0 と VII.1 に共通の
  3,723 核種のうち同じものが 1、VII.1 と VIII.0 の 3,821 核種のうち違うものが 97、VIII.0 と VIII.1 では 10。違いが値か書き方かは確かめていない
  （数値で比べるツールは作っていない）

決まっていないこと、確かめていないこと:

- 報告の偏りが xlc の本番に効く大きさかどうか。報告の値は 60 MWd/kgU のもので、実測と比べる Problem 9 のサイクル 1 は 16.939 GWd/MT まで
  （docs/plans/m4-depletion.md）。差は燃焼とともに広がるとされるので、この範囲での大きさは別に見る
- 本番の版をどれにするか（候補）: VII.0、VII.1、VIII.1、VIII.0 のまま。親の推奨は VII.0（数値の表とピン出力の揃った公式の参照解が VII.0 で、
  本番と検証が 1 つの版で済む。ユーザーも、VII.1 の VERA の参照解が無いなら VII.0 を選ぶと述べた（ユーザー 2026-11-20）。VII.0 が燃焼の
  反応度で VII.1 と同じ側にいるかを測ってから決める）
- xlc が VIII.1 の評価を読めるか（ADR-0167 は、VIII.1 が使いうる共鳴の表現に未対応のものがあると書いている）。燃焼には燃焼チェーンの
  全核種が要るので、新しい燃料の核種だけでは分からない
- VII 系の手持ち: VII.0 は検証用ライブラリ（ADR-0175）があるが、VERA の格子の核種だけで、燃焼チェーンの全核種のライブラリは無い。
  崩壊、核分裂収率、中性子のファイルは VII.0、VII.1、VIII.1 も固定し、燃焼チェーンは 4 つの版から作れる（docs/environment.md、
  「経緯」）。報告の比較の相手は VII.1 で、VII.0 が同じ傾向かは確かめていない。VII.1 のライブラリは無い
- 版を替える費用: xlc のライブラリ、燃焼チェーン（崩壊と収率のファイルから作る。ADR-0164。収率の重みは VIII.0 で測った。ADR-0183）、
  燃焼の履歴、テーブルに加えて、OpenMC の参照解（燃焼を含む）を同じ版で作り直す（手法の検証は同じ核データで比べる。ADR-0175）
- k の手法の差を何と比べて見るか（#0302）は、本番の版で選択肢が変わるので、合わせて決める
- 出力の規格化（#0293 の項目 3）も版に依る。チェーンの核分裂の Q（MF3 MT18 の QI）は、VIII.1 で U-235 が VIII.0 より +0.35%、VII.1 で Pu-239 が
  +0.16% 違い、捕獲のエネルギーの割合は捕獲の断面積で変わる（examples/depletion/verification.md の「出力の規格化を OpenMC の燃焼で確かめる
  （項目 3）」）。ENDF/B-VIII.1 の論文の XIV.D.4 は、核分裂あたりのエネルギーの仮定が燃焼に伴う反応度の傾きに最も強く効くと書く。版の燃焼の
  反応度の差を測るときと文献と比べるときは、規格化の定義をそろえる

関係する ADR: [ADR-0262](../adr/0262-apply-natural-evaluations-to-listed-isotopes.md)（版ごとのチェーンの天然の元素の評価）、[ADR-0263](../adr/0263-list-isomers-with-unknown-excitation.md)（VII.0 の Nb-88m の負の ELIS）。本番の版を決めた決定は「問題」の冒頭に挙げた
