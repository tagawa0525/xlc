# ENDF/B-VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告を確かめ、本番の核データの版を決める

## 問題

本番の核データ（ENDF/B-VIII.0。ADR-0020）が軽水炉の燃焼で反応度を低く見積もるという報告があり、版を決め直す。文献の内容、VERA の参照解の版、
4 つの版の案の比較、候補（VII.0）は ADR-0264（proposed）にある。ここには未解決の点だけを並べる。

- VII.0 が、燃焼の反応度で VII.1 と同じ側にいるか。読んだ文献に VII.0 を燃焼で比べた記述が無い
- VIII.0 と VII.1 の差の燃焼度への依り方は体系で違う（ADR-0264 の背景）。実測と比べる Problem 9 のサイクル 1 は 16.939 GWd/MT まで
  （docs/plans/m4-depletion.md）なので、この範囲での大きさを xlc で測る
- 基準に置かれる VII.1 も、高い燃焼度で k を低く見積もるとされる（ADR-0264 の背景）。どの版が実測に近いかは、Problem 9 の臨界ホウ素濃度と
  比べるまで分からない
- VII.0、VII.1、VIII.1 の中性子のファイルを、燃焼チェーンの全核種で xs が読めるか。1B の主な 16 核種は VII.1 と VIII.1 で読めた
  （ADR-0264 の背景）。ADR-0167 は、VIII.1 が使いうる共鳴の表現に未対応のものがあると書いている。分離共鳴の SLBW などの読めない
  形式と、それで止まる核種（燃焼のライブラリの 65 核種では VII.0 が 7、VII.1 が 2）は #0305
- 版ごとのピンセルの燃焼の入力とステージ（examples/depletion/dvc.yaml の lattice-1C-version、比べるのは compare-depletion-versions。
  ライブラリは examples/depletion/endfb70、endfb71、endfb81 の dvc.yaml）はあるが、VII.0 と VII.1 のライブラリは #0305 で作れず、4 つの版の燃焼は
  まだ解いていない
- 核分裂収率と崩壊データの版ごとの値の違い（examples/depletion/verification.md の「版ごとの燃焼チェーン」）が、燃焼の反応度にどれだけ
  効くか。VIII.0 の崩壊データと収率を VII.1 に替えても影響は無いという報告はあるが、VII.0 については無い（ADR-0264 の背景）
- 読めていない文献が 3 つある（ADR-0264 の背景。U-238 の共鳴領域の捕獲を原因に置く IAEA の報告を含む）
- k の手法の差を何と比べて見るか（#0302）と、出力の規格化（#0293 の項目 3。核分裂の Q 値は版で変わる。examples/depletion/verification.md の
  「出力の規格化を OpenMC の燃焼で確かめる（項目 3）」）は、本番の版と合わせて決める

関係する ADR: ADR-0262、ADR-0263（版ごとの燃焼チェーン）、ADR-0264（本番の版の候補）

## 完了の条件

- [ ] 読めていない 3 つの文献を読む（読めなければ、その旨を ADR-0264 に書く）
- [ ] VII.0、VII.1、VIII.1 の中性子のファイルを、燃焼チェーンの全核種で xs が読めるかを試す
- [x] 核分裂収率と崩壊データの版ごとの違いを、数値（収率、半減期、分岐比、崩壊のエネルギー）で比べるツールを作る
- [ ] 1 つのピンセルの燃焼で、4 つの版の反応度の差を、Problem 9 の範囲（約 17 MWd/kg）と 60 MWd/kg までの燃焼度ごとに測る
- [ ] ADR-0264 を確定する（本番の作り直しの前）

- 2026-11-20: #0131 の結果から本番の版をユーザーに尋ねたとき、ユーザーが VIII の燃焼の問題の報告があるかを問い、文献を検索して起こした
- 2026-11-20: 燃焼チェーンを VII.1、VIII.0、VIII.1 から作れるようにした（複数の物質のテープ、天然の元素の評価は ADR-0262、ファイルの固定は docs/environment.md、入力は examples/depletion/endfb71、endfb81）。VII.0 は decay の Nb-88m の負の励起エネルギーで止まる。核種の数、反応を持つ核種、核分裂する核種、警告の数は、VII.1 が 3,820、423、85、115、VIII.0 が 3,820、555、88、124（main のチェーンと同じバイト）、VIII.1 が 3,820、556、88、125（`bin/chain` は 920b9f156、2026-11-20。手元の実行で、ステージではない）
- 2026-11-20: 燃焼チェーンを VII.0 からも作れるようにした（Nb-88m の負の励起エネルギーは ADR-0263、入力は examples/depletion/endfb70）。VII.0 の核種の数、反応を持つ核種、核分裂する核種、警告の数は 3,837、398、65、108 で、ほかの 3 つの版の数とバイトは上と同じ（`bin/chain` は 3d591ebbf、2026-11-20。手元の実行で、ステージではない）
- 2026-11-20: 文献を本文で読み直し、VERA の参照解の版と、VII.1 と VIII.1 の読み込みを確かめて、候補を VII.0 とする ADR-0264 を書いた
- 2026-11-20: 版ごとのチェーンを DVC のステージにし、核分裂収率と崩壊データを値で比べるツール（examples/depletion/compare_chain_versions.py）で
