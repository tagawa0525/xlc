# ENDF/B-VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告を確かめ、本番の核データの版を決める

## 問題

本番の核データ（ENDF/B-VIII.0。ADR-0020）が軽水炉の燃焼で反応度を低く見積もるという報告があり、版を決め直す。文献の内容、VERA の参照解の版、
4 つの版の案の比較、候補（VII.0）は ADR-0264（proposed）にある。ここには未解決の点だけを並べる。

- VII.0 が、燃焼の反応度で VII.1 と同じ側にいるか。読んだ文献に VII.0 を燃焼で比べた記述が無い。1C のピンセルの xlc の燃焼の版ごとの差は
  examples/depletion/verification.md の「版ごとのピンセルの燃焼」（ADR-0264 の背景の表）、全核種を輸送した U、MOX、Gd のセルの差は同じ記録の
  「核データの 4 つの版の、全核種を輸送した燃焼の差（試行）」。VII.0 の差が燃焼とともに負に広がる分は、全核種の U のセルの項で Pu-238、Pu-239、
  Tc-99、Pu-242 が大きいが、項は生成の差を含み、評価の差の大きさとは読めない。ADR-0264 の「VII.0 と VII.1 の差が VII.1 と VIII.0 の差より十分小さい」
  という条件は、全核種の MOX のセルの 30、60 MWd/kg で成り立たない（ADR-0264 の「決定と理由」の 2 つ目の項）。案 B（VII.0）と案 C（VII.1）の
  比べ直しの材料は ADR-0264 の「検討した案」にあり、どちらにするかはユーザーが判断する
- 同じ記録で、VIII.1 と VII.1 の k の差は、同じ 1C のピンを Shift で解いた VIII.1 の論文の値と 30 MWd/kg と 60 MWd/kg で向きが同じで大きさが
  近いが、燃焼度 0 で負に大きい（VIII.0 も同じ）。候補は同じ節にあり、どれも確かめていない
- VIII.0 と VII.1 の差の燃焼度への依り方は体系で違う（ADR-0264 の背景）。実測と比べる Problem 9 のサイクル 1 は 16.939 GWd/MT まで
  （docs/plans/m4-depletion.md）。1C のピンセルの 17 MWd/kg の差は examples/depletion/verification.md の「版ごとのピンセルの燃焼」にある。
  集合体と炉心での大きさは測っていない
- 基準に置かれる VII.1 も、高い燃焼度で k を低く見積もるとされる（ADR-0264 の背景）。どの版が実測に近いかは、Problem 9 の臨界ホウ素濃度と
  比べるまで分からない
- 4 つの版の中性子のファイルの全評価は、565 K の 1 点の `xs nuclide` を、評価の誤りを入力で宣言した後はどれも通る（examples/depletion/verification.md の
  「中性子の評価のすべての `xs nuclide`」。宣言の要る評価の版ごとの数と、NJOY との差が残る点は ADR-0264 の「検討した案」の表）。本番の温度
  （燃焼のライブラリの 4 温度、#0292 の 13 温度）で止まるかと、通った評価のうち修正の前の xs で流したものが今の main でも通るかは
  確かめていない（ADR-0264 の背景の走査の限界）
- 核分裂収率と崩壊データの版ごとの値の違い（examples/depletion/verification.md の「版ごとの燃焼チェーン」）が、燃焼の反応度にどれだけ
  効くか。VIII.0 の崩壊データと収率を VII.1 に替えても影響は無いという報告はあるが、VII.0 については無い（ADR-0264 の背景）
- 読めていない文献が 3 つある（ADR-0264 の背景。U-238 の共鳴領域の捕獲を原因に置く IAEA の報告を含む）
- k の手法の差を何と比べて見るか（#0302）と、出力の規格化（#0293 の項目 3。核分裂の Q 値は版で変わる。examples/depletion/verification.md の
  「出力の規格化を OpenMC の燃焼で確かめる（項目 3）」）は、本番の版と合わせて決める

関係する ADR: ADR-0262、ADR-0263（版ごとの燃焼チェーン）、ADR-0264（本番の版の候補）
