# UFG の 4〜10 eV の燃料の中性子束の傾きが OpenMC と違う

## 問題

1C のピンセルに 2A の 40 MWd/kg の組成を置いた 1 状態（#0133 の 2026-10-23）で、UFG の等価なセルの燃料の格子点ごとの中性子束
（`fine_flux` の例）を OpenMC の燃料の細かい tally（1 桁に 500 区間）と 27 群（4〜9.877 eV）の中で規格化して比べると、xlc は U-238 の
6.67 eV の共鳴より下（4.0〜5.8 eV）で −0.6〜−1.5%、上（6.8〜9.9 eV）で +0.9〜+1.3% と傾く（`issue-0133/fine_compare.py`、12 区間）。
4 区間に分けると、2A-40 の OpenMC の 3 本（シードの違い）で下の 2 区間 −0.9〜−1.2%、上の 2 区間 +0.8〜+1.2% で、本数の間の差は 0.3%
以下。2A の 0 MWd/kg の組成（新しい燃料）でも −0.7、−1.3、+0.8、+1.2% と同じ。26 群（9.877〜15.97 eV）は −0.3〜+0.3%、25 群（20.9 eV の
共鳴）は下の 2 区間で −0.3〜−0.7%、上の 2 区間で +0.3〜+0.5%、24 群（36.7 eV）は最初の区間（27.8〜32 eV）だけ −0.3〜−0.5% でほかは
−0.1〜+0.3%（どれも 4 本で同じ向き）。

この傾きで、27 群に共鳴を持つ薄い核種の群の捕獲が xlc で小さい。OpenMC の区間の断面積を xlc と OpenMC の細かい中性子束で群平均した
比は U-236 −1.7%、Nd-145 −1.5%、Ag-109 −1.3%、Tc-99 −1.2%、U-238 +0.8%、Sm-152 +1.3% で、群の断面積の差（U-236 の 27 群 −1.68%、
Tc-99、Ag-109、Nd-145 −0.8〜−1.1%（UFG の範囲の計））と同じ向き。U-236 の 27 群は新しい燃料（数密度 3.3e-6 で無限希釈に近い）でも
−1.98% なので、核種自身の自己遮蔽でなく燃料の中性子束の形による。点の断面積は xlc と OpenMC で合う（1/E の重みと σ0 = 50 b の
NR の重みの群平均で 0.004% 以内。`issue-0133/dilute.py`、`shape.py`）。

k への寄与（燃料の核種の吸収と核分裂を UFG の範囲（14〜27 群）で OpenMC の値に置き換えた k の変化の符号を変えたもの）は、U-235、
U-238、Pu-239、Pu-241、Xe-135、Sm-149 を除く核種で、新しい燃料 +2.4 pcm、2A の 40 MWd/kg の組成で +14.1 pcm（OpenMC の本数の平均）。
U-238 の UFG の範囲は −89.9、−57.0 pcm（群の断面積は +0.3%）で、同じ原因かは確かめていない。

候補（確かめていない）:

- H を UFG で静止した自由原子として扱う（ADR-0070）。OpenMC は 10 eV より下で S(α,β)、その上で自由ガス（ADR-0133）
- U-238 などの重い核種を静止した標的として扱う（ADR-0070）。OpenMC は 400 kT（900 K で 31 eV）より下で自由ガス。24 群の大半は 31 eV より
  上で、その上の区間の差は小さいので、24 群の 27.8〜32 eV の −0.3〜−0.5% とは矛盾しないが、27 群と 25 群の傾きの大きさをこれで
  説明できるかは確かめていない
- 等価なセル（ADR-0068）の、共鳴の谷の深さの誤差。27 群の U-238、U-235、Pu-239 の共鳴の谷の近くで xlc の中性子束が +2〜+4% 高い区間がある

関係する ADR: ADR-0202、ADR-0203、ADR-0204、ADR-0205、ADR-0206、ADR-0207、ADR-0208、ADR-0209

## 完了の条件

候補を切り分け（散乱核を変えた UFG の試作か、OpenMC の側で H の S(α,β) の上限や重い核種の扱いを変えた参照）、傾きの原因を数値で
示し、直すなら ADR で決める。
