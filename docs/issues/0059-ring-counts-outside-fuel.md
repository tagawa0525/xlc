# 燃料の外の領域（吸収体、Pyrex、案内管の中の水）のリングの数を決める

## 問題

VERA の集合体の入力（examples/vera/p2/）で、燃料のリングの数は ADR-0077 と ADR-0111 で決めているが、燃料の外の領域の
リングの数（Pyrex の環 2、制御棒の吸収体 5、SS304 の被覆管と案内管の間の水 1 など）は ADR で決めていない。

2G と 2H で、方位角 30・間隔 0.03 cm のまま吸収体のリングを 5 から 10、20、40 にすると k は 2G で +4.7、+6.4、+7.1 pcm、2H で
+6.7、+9.2、+10.0 pcm と単調に増え、収束に向かう。5 リングは収束した値より 2G で約 8 pcm、2H で約 10 pcm 低いと見込む。
SS304 の被覆管と案内管の間の水を 1 から 3 リングにすると +6.6、+6.2 pcm 動き（2E では +4.4 pcm）、3 より多くして確かめて
いない（examples/vera/verification.md の「吸収体による差の変化」、000c8b7e、2026-10-11）。間隔を変えずにリングだけを
変えるので、トラック間隔の振れはこの差に入らない。

関係する ADR: なし

## 完了の条件

燃料の外の領域のリングの数を、リングの数による k とピン出力の変化から ADR で決める。2I の計装管の中のリング（シンブルの
中の真空、SS304、シンブルと計装管の間の水）への k とピン出力の依存も確かめる。

## 経緯

  2G と 2H の検証とは別の決定なので issue にした。リングによる差（5 リングで約 8〜10 pcm）は、
  2G と 2H の記録の結論（吸収体による差の変化）を変えない
- 2026-10-11: 2 回目の /code-review で、間隔を固定したリングの変化には間隔の振れが入らないと指摘された。0.03 cm のまま
  40 リングを 2G と 2H で解き、単調に増えて収束に向かうことを確かめた（000c8b7e）
- 2026-10-11: 2I の入力で、計装管のシンブルの中の真空と SS304 を 1 リング、シンブルと計装管の間の水を 2 リングにした。計装管の
  中の水は、2E-empty の 3 リング（0.559 cm まで）から、2I では 2 リング（0.382〜0.559 cm）になる。これも ADR で決めておらず、
  リングによる差は測っていない。2I の 2E-empty からの変化（−3 pcm。examples/vera/verification.md の「吸収体による差の変化」、
  41394f44）の判定の範囲にこの差は入っていない
- 2026-10-13: AIC の棒を ADR-0142 で遮蔽し直したあとの測り直し（c33c5135 の 2G と 2H、入力は 1019fbb7 と 15eb680f の trials/rings/）。

  5 から 10、20、40 で +6.7、+9.2、+10.0 pcm。外側を薄くした分け方を足しても収束した値は 2G で約 0.84970、2H で約 0.78962 で、
  5 リングは 2G で約 −9 pcm、2H で約 −10 pcm。SS304 の被覆管と案内管の間の水を 1 から 2、3、5 リングにすると 2G は +5.5、+6.5、
  +7.3 pcm、2H は +5.2、+6.2、+6.9 pcm。2G の 40 リングは 1 本が 2.5 時間を超えたので打ち切った（未測定）。リングの数による
  ピン出力と反応率の収束は未測定。ADR は書かない（判定の範囲内。2G の 2E-empty からの変化 +18 pcm に約 +9 pcm を足しても 24 pcm 付近）
