# 燃料の外の領域（吸収体、Pyrex、案内管の中の水）のリングの数を決める

## 問題

VERA の集合体の入力（examples/vera/p2/）で、燃料のリングの数は ADR-0077 と ADR-0111 で決めているが、燃料の外の領域の
リングの数（Pyrex の環 2、制御棒の吸収体 5、SS304 の被覆管と案内管の間の水 1 など）は ADR で決めていない。

2G と 2H で、方位角 30・間隔 0.03 cm のまま吸収体のリングを 5 から 10、20 にすると k は 2G で +4.7、+6.4 pcm、2H で +6.7、
+9.2 pcm、水を 1 から 3 リングにすると +6.6、+6.2 pcm 動く（examples/vera/verification.md の「吸収体による差の変化」、
c0662d26、2026-10-11）。同じ設定で間隔を 0.02〜0.05 cm で変えた k の幅（2G 66.5 pcm、2H 33.1 pcm）の中にあり、リングの
収束はこの測定では区別できない。

関係する ADR: なし

## 完了の条件

トラックの離散化の誤差と分けてリングの収束を測り（トラックを細かくした設定でリングを変えるなど）、燃料の外の領域の
リングの数を ADR で決める。

## 経緯

- 2026-10-11: 2G と 2H の /code-review で、制御棒の吸収体の 5 リングに決めた ADR がないと挙がった。重い計算は V&V に載せる
  数値にだけ使う方針なので、測り直さずに issue にした
