# 格子計算の燃焼の 1C の OpenMC との差の切り分け

## 問題

VERA 1C のピンセルの燃焼（ADR-0173。examples/depletion/verification.md の「格子計算の燃焼」）で、OpenMC のライブラリにも
Pm-147、Pm-148、Pm-149、Am-242m、Eu-151 を入れて両方が 54 核種を輸送した今の結果では、k∞ の差の 0 の点からの変化が 1 リングで
+9〜+147 pcm と燃焼度とともに増え、5 MWd/kg で ADR-0032 の ±100 pcm を超える（4 リングは +8〜+74 pcm）。下の項目の数値は
5 核種が OpenMC になかった測定（ADR-0173 の本文と同じ）のもので、1 と 3 は今の結果で再測定していない。2 は今の結果でも
+0.7〜+0.9% 残る。4 は 2 MWd/kg の外れた点が消えた。1 リングの増加の原因は切り分けていない。

1. I-135 −0.9%、Cs-133 −0.5%、Rh-103 −1.6%、Nd-149 と Pm-149 −0.5% が燃焼度によらずほぼ一定。核分裂の数は 0.005% 以内で
   合うので、収率の重みの違いが候補: xlc は ADR-0164 の区間（500 keV と 14 MeV の幾何平均 2.65 MeV で分ける）で U-238 などに
   14 MeV の収率を使い、OpenMC の `cutoff`（`fission_yield_mode="cutoff"`）は 112.5 eV より上をすべて 500 keV の収率にする
2. Sm-149 が +0.9%（先行核は −0.5% なので、xlc の Sm-149 の捕獲率が約 1.4% 小さい計算になる）。0.0973 eV の共鳴の熱群での
   縮約が候補
3. Pm-148m が +27%（5 MWd/kg）。Pm-148m の捕獲率か収率の扱いが候補
4. 4 リングの 2 MWd/kg の点の k の差の変化が +120 pcm で、前後から外れる。OpenMC の 4 リングと 1 リングの k の差が −35〜+62 pcm
   にばらつくので、OpenMC の燃焼で反応率の統計誤差が組成に入る揺らぎが候補

関係する ADR: ADR-0173

## 方針の案

- 1: OpenMC の収率を xlc と同じ区間の重みにする（`AveragedFissionYieldHelper` か、自前の helper）か、xlc の区間を OpenMC の
  `cutoff` に合わせた試行で、I-135 と Cs-133 の差が消えるかを見る
- 2、3: 均質な無限媒質（examples/vera の `homogeneous_medium.py`）で Sm-149、Pm-148m の微視的断面積を比べる
- 4: OpenMC の燃焼を種を変えて数本流し、点ごとの k の揺らぎを測る

## 完了の条件

4 つの差と 1 リングの k∞ の差の増加の原因を、測った数値で説明するか直す。

## 経緯

- 2026-10-15: ADR-0173 の実装の検証（ブランチ feat/lattice-depletion-rates）で見つけた。最初のステップの終わりの U-239、Np-239、
  Pu-239 の +4.7% と Xe-135 の +2.5% は、xlc が数密度 0 の核種に反応率を与えていなかった（OpenMC は与える）ためで、同じブランチで
  直して +0.2% と −0.15% になった（コードレビューの指摘。7bc96cb8）
- 2026-10-21: OpenMC のライブラリに 5 核種を足して 1C を再実行した（ブランチ chore/rerun-after-adr-0177）。1 リングの k∞ の差が
  燃焼度とともに増える（5 MWd/kg で +138 pcm）ので、完了の条件に 1 リングの増加の原因を加える
- 2026-10-22: 4 つの項目と k∞ の差の増加を測って切り分けた（ブランチ fix/0133-depletion-1c-differences。試行の入力とスクリプトは trials/0133 に置いて f40cf2de でコミットした。検証の記録には書かない。
  xlc は 01d8aa2e7 と 567003b57 の `bin/lattice`、OpenMC は今の参照解 `openmc-1C-rings1` の結果と、その組成で解き直した短い実行）
  - 収率の重み（項目 1、3）: `[depletion]` に `yield-cutoff`（OpenMC の `FissionYieldCutoffHelper` と同じ点の選び方）を足し、
    境界 112.47 eV で 1 リングを解き直した。境界を含む群（75.5〜148.7 eV）の核分裂率はレサジーの幅の比で分ける（OpenMC は連続エネルギー）。核分裂のない領域の重みは、OpenMC の熱の点でなく、`Chain::zero_rates` と同じ最初の点に置く（核分裂率が 0 なら燃焼行列に効かないので、xlc の 2 つの重みで同じ約束にした。レビューで熱の点の版から直した）（既定の区間のままの実行は今の記録と全桁で一致）。5 MWd/kg の相対差は I-135 −0.95 → +0.02%、
    Cs-133 −0.48 → 0.00%、Rh-103 −1.57 → +0.20%、Nd-149 −0.52 → +0.10%、Pm-149 −0.61 → +0.01%、Pm-147 −0.79 → +0.13%、
    Pm-148m +27.1 → +0.93%（0.1 MWd/kg は +443 → −0.12%）。どれも燃焼度によらず消える。区間の重みでは、2.65 MeV より上の核分裂
    （U-238 の核分裂の 51%、全核分裂の 4.2%。5 MWd/kg の組成の OpenMC の tally）が 14 MeV の収率を取る。Pm-148m の独立収率は
    14 MeV で熱の約 1000 倍（U-235）なので、この 4% が Pm-148m を 5 倍にしていた（どちらのチェーンも Pm-147 (n,γ) の準安定状態への
    分岐を持たないので、Pm-148m は収率だけでできる）。差は収率の重みで説明できる。どちらの重みが物理的に正しいかは決めていない
  - Sm-149、Xe-135（項目 2）: cutoff の重みでは Sm-149 +1.47%、Xe-135 +0.60%（区間の重みでは +0.81%、−0.11%。収率の差が
    打ち消していた）。OpenMC の 5 MWd/kg の組成（輸送する 54 核種）の 1C のピンセルを、xlc（`balance` と `fuel_xs` の例）と
    OpenMC（燃料の 69 群の tally、20 万粒子 × 100 世代）で解き、燃料の 1 群の捕獲断面積を比べると、xlc は Sm-149 −1.41%
    （断面積 −0.62%、中性子束のスペクトル −0.80%）、Xe-135 −0.79%（−0.15%、−0.64%）、Pm-149 −1.96%、Pm-148m −1.21%
    （OpenMC の統計誤差は 0.03%）。同じ比べで Pm-148 は −7.3%（Pm-147 は +0.06%）。断面積の差は 0.067〜0.22 eV の群（WIMS 54〜58 群）の群定数が −0.3〜−1.6% 小さいこと
    （群の中の重み）、スペクトルの差は同じ群の燃料の中性子束の割合が xlc で 0.4〜1.4% 小さいことによる。熱群（0.625 eV 以下）の
    中性子束の割合は新しい燃料でも xlc が 0.70% 小さく（0.11883 と 0.11967）、燃焼によらない。捕獲が 1.4% 小さければ、平衡に近い
    Sm-149 は約 1.1%（出力あたりの中性子束が U-235 の核分裂断面積の差 −0.32% で増える分を引く）多くなり、+1.47% とほぼ合う。
    Pm-148m の +0.93% も捕獲 −1.2% で説明がつく。熱群の中性子束の形の差の原因は確かめていない（候補: 減速材の H-1 の熱中性子散乱、
    燃料の熱群の群定数）
  - 1 リングの k∞ の差の増加（項目 4 を含む）: 同じ組成で比べると、xlc の k の差は組成の差（xlc の k を自分の組成と OpenMC の組成で
    解いた差）と、同じ組成の輸送の差に分かれる。組成の差は 0 の点から 5 MWd/kg まで −0.4、+5、+5、+5、+9、+14、+25 pcm（cutoff の
    重みでは −0.4、−18、−21、−22、−19、−15、−6 pcm）。同じ組成を OpenMC で解き直すと（seed を変えた単独の実行）、xlc − OpenMC は
    0、2、3、5 MWd/kg で −15 ± 19、+58 ± 22、+45 ± 23、+23 ± 14 pcm（5 MWd/kg は 2 本の平均。1.08622 ± 0.00019 と
    1.08611 ± 0.00020）。OpenMC の燃焼の 5 MWd/kg の k（1.08527 ± 0.00020）は、同じ組成の単独の実行より 90 ± 24 pcm 小さく、
    2、3 MWd/kg では +15、−27 pcm で合う。5 MWd/kg の +138 pcm（変化 +147 pcm）は、組成 +25、輸送 +23、OpenMC の燃焼の k が
    単独の実行より小さい分 +90 に分かれる。最後の分が統計の揺らぎ（3.7σ。世代間の相関で σ は過小評価されうる）か、燃焼の最後の
    輸送に固有のものかは確かめていない。4 リングとの違いもこの揺らぎの大きさの中にある（今の結果の OpenMC の 4 リングと 1 リングの k の差は
    −52〜+41 pcm。「問題」の −35〜+62 pcm は 5 核種を足す前の測定、合成の σ は約 27 pcm）。同じ組成の輸送の差は、新しい燃料の −15 pcm から燃えた組成の +23〜+58 pcm へ約 50 pcm
    動く（生成 1 あたりの吸収の差を物質と範囲に分けると、5 MWd/kg と 0 の点の差は燃料の 0.625 eV 以下 −22、4〜9118 eV −20、
    9118 eV より上 +18（(n,2n) の増倍を差し引いた値）、×1e-5。9118 eV より下の核種では Pu-239 −43.5、Xe-135 −14.6、Sm-149 −6.3）
- 2026-10-22 の測定で残ること: (1) 収率の重みをどちらにするか（区間か cutoff か。ADR で決める）、(2) 燃料の熱群の中性子束の形と
  0.067〜0.22 eV の群定数の重み（Sm-149、Xe-135 の捕獲 −0.8〜−1.4%）、(3) OpenMC の燃焼の 5 MWd/kg の k が単独の実行より
  90 ± 24 pcm 小さいこと（OpenMC の燃焼を種を変えて流せば分かる）、(4) Pm-148 の 1 群の捕獲断面積が xlc で −7.3%（数密度への
  影響は崩壊が支配するので −0.46% に留まる。原因は確かめていない）
