# 燃料のピンを方位の扇形ごとに燃焼させる効果を測る

## 問題

- 燃焼の領域は、燃料の物質と、自己遮蔽の対称操作で移り合うセルの組の対ごとに 1 つ（ADR-0173 の「決定と理由」の 1 項目め）で、
  ピンの中の方位の偏り（案内管や水ギャップの側で熱中性子束が高く、その側から先に燃える）を組成として持たない。径方向は物質の
  名前をリングごとに変えれば分けられ（#0275 で効きを測った）、方位方向には分ける入力が無かった。本番に向けた 2A のテーブルの
  履歴（examples/depletion/p9-product/lattice-2A.toml）を作り直す前に、方位にも分けるか（4 か 8）を決める材料が要る
  （ユーザーの指摘と順序の決定は「経緯」）
- 方位に分ける効きは測っていない。k∞ とピンの平均の出力への効きは径方向より小さいという見込みは、親の見積もりで、計算も文献も
  確かめていない
- 分けたときの自己遮蔽の扱い（ADR-0244）は、扇形の組成の違いをリングの扇形の平均の組成で遮蔽する近似で、その誤差は測っていない
- `[history]`（燃焼点からの分岐。ADR-0187）は、扇形に分けた履歴を読まない（エラーで止める）。本番のテーブルで分けると決めたら、
  分岐でも扇形ごとの組成で解く経路が要る

### 調べた結果（2026-11-11）

- 入力: セルの `sectors`（1、4、8）は MOC の領域を扇形に切るだけで、物質は `zones` の帯ごと（扇形には同じ物質の名前が並ぶ。
  crates/lattice/src/input.rs の `geometry_replacing`）。扇形ごとに物質を書く口は無く、書けても対称操作で移り合うピンの扇形は
  向きが違う（同じセルの種類に同じ名前を並べると、対称操作の確認で格子が対称でなくなる）ので、径方向の R1（物質の名前で分ける）は
  方位方向に使えない
- 燃焼の領域（crates/lattice/src/depletion.rs の `depletion_regions`）は（組の代表のセル、物質）で領域をまとめ、扇形を区別しない。
  対称操作の像は領域ごとの対応（`symmetry::Image::regions`）を持つので、扇形の組（移り合う扇形の集まり）はそこから作れる
- 自己遮蔽（crates/lattice/src/shielding.rs の `shield_fuel_reusing`）は、燃料のリングの扇形がすべて同じ物質であることを求める
  （`SelfShieldingError::MixedFuel`）。UFG の減速計算は円筒の等価なセルをリングで解き、扇形を表せない（`solve_equivalent_cell` も
  リングの扇形が同じ物質であることを求める）。等価原理（Carlvik の 2 項）はピンの燃料を 1 つの塊で扱う。扇形ごとの組成を減速計算で
  解くには 2 次元の UFG の減速計算が要り、作り直しになる（数日以上。手間は見積もっていない）
- 自己遮蔽の結果から、微視的断面積と SPH 因子のまま数密度だけを替えて物質を作り直す口（`remix_depleted`。ADR-0197 の
  `step-start`）が既にあり、扇形の組成の物質はこれで作れる。足したのは ADR-0244 の形（入力の `[depletion]` の `sectors`、扇形の組の
  燃焼の領域、リングの扇形の平均の組成での遮蔽と扇形ごとの物質の作り直し）で、1 日の規模
- open の issue と ADR の「候補」「後回し」「確かめていない」の行に、方位・扇形・azimuthal で燃焼を分ける話は無かった
  （`grep` で docs/issues と docs/adr。扇形が出るのは自己遮蔽の塊と対称性の #0051、#0054、#0055 で、燃焼の領域とは別）

### 測る入力と時間（2026-11-11）

- 入力は examples/depletion/issue-0276/（`sector_zones.py write` が書く 8 本。格子とケースの中身は同じスクリプトの docstring）。
  格子は中央が案内管の 3 × 3（`guide`）と、燃料だけの 3 × 3 の周りに 0.04 cm の水の余白を付けたもの（`gap`。集合体の角、辺、内の
  ピン）で、どちらも p9-product/lattice-2A.toml の公称の状態と 40 点の燃焼度。ケースは燃焼の単位 1 つ（`rings1`。今の本番）、径方向の
  5 単位（`rings5`）、5 単位を 4 つと 8 つの扇形の組に分けたもの（`rings5-sectors4`、`rings5-sectors8`）で、MOC の扇形はどれも 8 つ
- 最初の 2 点（輸送 5 回）の時間（Slurm 736。区分 decision、パーティション timed の排他のジョブ、32 スレッド、2026-11-11。xlc は
  257c4722（分岐点は main の 3948bff8）の `target/release/lattice`。輸送ごとの自己遮蔽、MOC、反応率、行列、CRAM の時間の和（履歴の
  `seconds` の和）で、括弧の中は全体（同じ行の `total_seconds`。和に起動の約 4 秒を足したもの）。
  examples/depletion/issue-0276/logs/short-*.log の最後の行）:

| ----- | ----------------- | ----------------- | ----------------- | ----------------- | ---------------------------------- |
| guide | 19.40 s (23.56 s) | 22.73 s (26.74 s) | 23.91 s (27.96 s) | 24.26 s (28.29 s) | 2、10、25、40                      |
| gap   | 22.48 s (26.51 s) | 27.44 s (31.48 s) | 29.19 s (33.22 s) | 29.11 s (33.17 s) | 3、15、30、45                      |

- 方位に分けた時間の増え（rings5 に対する和の比）は、4 つで 1.052（guide）、1.064（gap）、8 つで 1.067、1.061。0 の点の k∞ は分けても
  4e-13 以内で同じ（`short-*.msgpack`。追跡しない）
- 40 点（輸送 81 回）の見積もり: #0275 のピンセルの本番の離散化では、40 点の `seconds` の和が 2 点の和の 16.6 倍（1 単位）と 17.2 倍
  （5 単位）だった（examples/depletion/issue-0133/pellet-zones/zones-1-p9.log、zones-5-p9.log の最後の行と、#0275 の 2 点の時間）。
  17.2 倍を当てると 1 本 7〜10 分、8 本の和で約 66 分

### 40 点の結果（2026-11-11）

- 40 点（60 MWd/kg まで）の 8 本を測った（examples/depletion/verification.md の「燃料のピンを方位の扇形の組にも分けた燃焼（#0276）」。
  xlc は 28283d5a（分岐点は main の 3948bff8）、2026-11-11、Slurm 737〜744（区分 decision、パーティション main）。比べたのは 6ea1df01 の
  `sector_zones.py compare` で、要約は同じ置き場の `summary.json`）。値はすべての燃焼点から
- 方位の効き（`rings5-sectors*` − `rings5`）は 1 pcm 未満で、0 の点（差は 1e-7 pcm 未満）の後のどの燃焼点でも分けると k∞ が下がる: `guide` で Δk の最小 −0.58 pcm（4 つ、
  16 MWd/kg）と −0.76 pcm（8 つ、18 MWd/kg）、Δρ の絶対値の最大 0.67 pcm と 0.89 pcm、`gap` で Δk の最小 −0.08 pcm と −0.11 pcm、Δρ 0.11 pcm と
  0.16 pcm。ピン出力の差は rms 0.001% 以下、最大 0.002% 以下。8 つ − 4 つは Δk で 0.20 pcm 以内
- 扇形の組の間の組成の差: 最も外のリングの U-235 の (最大 − 最小) / 平均は 60 MWd/kg で、`guide` の案内管に辺で接するピンで 7.437%（4 つ）と
  10.942%（8 つ）、角で接するピンで 4.136% と 4.145%、`gap` の集合体の角のピンで 3.403% と 3.411%、辺のピンで 1.785% と 2.702%。案内管と
  水ギャップの側の扇形の組で U-235 が少ない。組成の差の割に k∞ が動かない
- 方位の効きの値は、扇形の組成の違いをリングの扇形の平均の組成で自己遮蔽する近似（ADR-0244 の案 B1）の下のもので、この近似の
  誤差は測っていない
- 径方向の効き（`rings5` − `rings1`）は格子で向きと大きさが違う: `guide` は Δk の最大 +36.24 pcm（36 MWd/kg）、Δρ の最大 +44.84 pcm
  （38 MWd/kg）で、60 MWd/kg で +2.60 pcm。`gap` は Δk の最大 +15.67 pcm（36 MWd/kg）、52 MWd/kg から負で 60 MWd/kg で −21.90 pcm（Δρ
  −32.05 pcm）。#0275 のピンセル（本番の離散化の 5 単位 − 1 単位）は Δk の最大 +35.92 pcm、Δρ の最大 +43.73 pcm（40 MWd/kg）で、
  60 MWd/kg で +16.04 pcm。ピン出力の差は rms の最大 0.024%（`guide`）と 0.046%（`gap`）。格子とピンセルで違う原因は確かめていない
- 完了の条件の問いへの答え:
  - (i) 方位に分けたときの差は 60 MWd/kg までに、Δρ の絶対値の最大 0.89 pcm、Δk の絶対値の最大 0.76 pcm（`guide` の 8 つ）、ピン出力の差の最大 0.002%。
    分岐のテーブルで落とす項ごとの目安 |Δρ| ≤ 5 pcm（ADR-0200）の約 1/6、格子計算の精度の目標の k ±100 pcm とピン出力 rms 0.2%
    （ADR-0032）の 1% に満たない
  - (ii) 径方向の効き（同じ格子で Δρ の絶対値の最大 44.84 pcm と 32.05 pcm）の 1/50（`guide`）と 1/200（`gap`）ほどで、径方向の効きは ADR-0200 の
    目安の 6〜9 倍
  - (iii) 推しは、本番のテーブルで方位に分けないこと（径方向の分け方は #0275 で決める）。軸は正確さ > 実行速度 > 保守の容易さ
    （CLAUDE.md の「方針」）で、分けて得る k∞ の差は ADR-0200 の目安より小さく、正確さの得が測れる大きさに無い。時間は 3 × 3 の格子で
    1.05〜1.07 倍（Slurm 736、最初の 2 点、`rings5` に対する比。測ったのは 257c4722 で、28283d5a が足した自己遮蔽のたびの確認（まとめた
    物質の作り直しをもう 1 回）を含まず、その分の時間は測っていない）で、分けると分岐（`[history]`）に扇形ごとの物質を作り直す経路が要る
    （ADR-0244）。ただし、上の値は ADR-0244 の案 B1 の下のもので、扇形の組成の差（U-235 で最大 10.942%）が自己遮蔽を変える分は
    入っていない。測る正しい経路（案 B3、2 次元の UFG の減速計算）は無い。格子は案内管が集合体より密（1/9 と 25/289）で、集合体で同じ大きさかは
    確かめていない

関係する ADR: ADR-0244、ADR-0245

## 完了の条件

案内管の隣の燃料のピンを含む最小の格子（と、表せれば集合体の角と水ギャップの側）で、径方向の分け方を同じにしたまま、方位に
分けない場合と 4 つ、8 つに分けた場合の k∞ とピンの出力の差を 60 MWd/kg まで測り、径方向の効き（#0275）と比べて、本番のテーブルで
分けるかの推しと時間の増えを示す（分けるかは親とユーザーが決める）。
