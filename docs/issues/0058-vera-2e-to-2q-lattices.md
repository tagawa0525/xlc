# VERA 2E〜2K と 2Q の格子計算を、同じ核データの OpenMC と比べる

## 問題

M3 の計画（docs/plans/m3-core-hzp.md の「検証」）は、新しい物質の格子計算を VERA 2E〜2K と 2Q で確かめる。仕様書
（references/vera/spec.txt、CASL-U-2012-0131-004 の表 P2-1〜P2-5、表 6〜10、図 5）の中身と、xlc で解くのに要るもの:

| 問題 | 中身（燃料 600 K、ホウ素 1300 ppm、減速材 0.743 g/cc）                               | KENO の k（ENDF/B-VII.0） | xlc で要るもの                                                                                                                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2E   | Pyrex の棒 12 本（図 5）                                                             | 1.069627 ± 0.000024       | Pyrex と SS304 の核種（B、O、Si、C、P、Cr、Mn、Fe、Ni）をライブラリに足す。セルは同心円で表せる                                                                                                                                                                                 |
| 2F   | Pyrex の棒 24 本                                                                     | 0.976018 ± 0.000026       | 2E と同じ                                                                                                                                                                                                                                                                       |
| 2G   | AIC の制御棒 24 本（Ag、In、Cd。半径 0.382 cm、SS304 の被覆管）                      | 0.847695 ± 0.000025       | Ag、In、Cd をライブラリに足す。共鳴の強い吸収体の塊の自己遮蔽（ADR-0086）がそのまま使えるかを確かめる。光学的に非常に厚いので、k がトラック間隔に対して不規則に動くか（ADR-0111）を測る                                                                                         |
| 2H   | B4C の制御棒 24 本（半径 0.373 cm）                                                  | 0.788221 ± 0.000025       | 2G と同じく、光学的に厚い吸収体の測定                                                                                                                                                                                                                                           |
| 2I   | 計装管のシンブル（SS304、内側 0.258 cm、外側 0.382 cm、中は真空）                    | 1.179916 ± 0.000024       | セルは同心円で表せる                                                                                                                                                                                                                                                            |
| 2J   | 計装管のシンブルと Pyrex の棒 24 本                                                  | 0.975193 ± 0.000025       | 2F と 2I の組み合わせ                                                                                                                                                                                                                                                           |
| 2K   | 濃縮度 3.6% と 3.1% の燃料（図 P2-2）と Pyrex の棒 24 本                             | 1.020063 ± 0.000025       | 2 種類の燃料の物質。ピンの組（自己遮蔽）は物質の像で決まる（ADR-0112）                                                                                                                                                                                                          |
| 2Q   | Zircaloy の支持格子（各セルに外周の箱として 1/289 ずつ）。燃料、被覆管、減速材 565 K | 1.171940 ± 0.000016       | 565 K の S(α,β) の内挿（ADR-0080）と 565 K の核種をライブラリに足す。支持格子はセルの枠（`frame`）で表せる。OpenMC の側も 565 K のデータ（非燃料の核種と H in H2O の S(α,β)。NJOY の熱中性子散乱のデータは 550 K と 600 K だけ）が要り、参照の作り方を決める必要がある（#0017） |

KENO の値は核データが違う（ENDF/B-VII.0）ので、主に比べるのは同じ核データ（ENDF/B-VIII.0）の OpenMC（連続エネルギー）である。
OpenMC のモデル（examples/vera/openmc_model.py）と核種の処理（openmc_library.py）も、問題ごとに広げる。

関係する ADR: なし

## 完了の条件

- 2E〜2K と 2Q を xlc と OpenMC で解き、k とピンの核分裂率の差を examples/vera/verification.md に書く（差が大きければ、
  誤差の内訳を調べて記録する）
- 2G と 2H で、k のトラック間隔への依存を測る（ADR-0111 の結果の節の見直し）

## 経緯

- 2026-10-10: 仕様書を読み、問題ごとに要るものを表にした。2E から順に進める（ブランチ feat/vera-2e）
- 2026-10-10: 2E を解いた（examples/vera/verification.md の「OpenMC との比較」、1b5dd218）。xlc 1.072883、OpenMC 1.070288 ±
  0.000047（+260 pcm）、ピン出力 rms 0.09%、最大 +0.31%。2E-empty（Pyrex の棒を抜いたもの）で分けると、減速材の密度で
  −14 pcm、Pyrex の棒で +13 pcm と、どちらも小さい。Pyrex の棒のセルのリングは収束している（k 4.4 pcm、ピン 0.005% 以内）。
  OpenMC と KENO-VI のピン出力は 2E で rms 0.071%、最大 +0.163% と 2B〜2D より開く（原因は確かめていない）
- 2026-10-10: 2F（Pyrex の棒 24 本）を解いた（examples/vera/verification.md の「OpenMC との比較」、d6593b9f）。xlc 0.979760、OpenMC
  0.976885 ± 0.000050（+288 pcm）、ピン出力 rms 0.11%、最大 −0.33%。2E-empty を基準にした Pyrex の棒による変化は 12 本で +13 pcm、
  24 本で +41 pcm（統計誤差の約 6 倍）で、差を正の向きに広げる（本数に比例するかは統計誤差で区別できない。原因は確かめていない）。OpenMC と KENO-VI の
  ピン出力は rms 0.091%、最大 −0.196%（2E の 0.071% よりさらに開く）
- 2026-10-11: 2G（AIC の制御棒 24 本）と 2H（B4C の制御棒 24 本）を解いた（examples/vera/verification.md の「OpenMC との比較」、
  83f37240）。xlc 0.849258、OpenMC 0.848986 ± 0.000050（2G、+27 pcm）、xlc 0.791907、OpenMC 0.788440 ± 0.000049（2H、+347 pcm）。
  ピン出力は rms 0.13%、0.14%、最大 −0.41%、+0.41%。2E-empty（+247 pcm）を基準にした吸収体による変化は、Pyrex 24 本 +41 pcm、
  AIC −220 pcm、B4C +100 pcm（統計誤差は独立として約 7 pcm）。B-10 の吸収体は正、AIC は負の向きで、原因は確かめていない（候補は
  B-10 の群定数と、AIC の共鳴の自己遮蔽。#0007）。OpenMC と KENO-VI の k の差は 2G で +129 pcm、2H で +22 pcm、ピン出力は rms
  0.119%、0.088%。トラック間隔への依存（方位角 30 で 0.02〜0.05 cm の 7 点、方位角 128・間隔 0.01 cm との差）は、吸収体なしの
  2E-empty で幅 7 pcm、2F で 29 pcm、2G で 67 pcm、2H で 33 pcm と吸収体で広がる。ADR-0111 の設定（0.03 cm）の誤差は 2G で −31 pcm、
  2H で −14 pcm で、吸収体による変化より 1 桁小さい
