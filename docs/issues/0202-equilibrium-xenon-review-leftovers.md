# 平衡 Xe の燃焼（ADR-0219）のレビューの残り

## 問題

ブランチ fix/0200-step-instability-after-power-change のレビューの 1〜3 周目（/code-review high）で、小さな炉心の燃焼では再現しない次の指摘を残した。

- `crates/core/src/depletion.rs` の `anderson` は、残差の差の正規方程式 ΔFᵀΔF γ = ΔFᵀf を LU で解き、LU が特異とみなすとき（ピボットがちょうど 0）
  だけ単純な反復に戻る。残差の差がほぼ平行だと条件数が大きく、γ が大きくなって負の数密度を 0 に切り、反復が 50 回の上限で止まりうる。QR や
  古い列を落とす形、条件数の検査が候補（1〜3 周目）。小さな炉心の燃焼では 1 回の解あたり 5〜6 回で 1e-6 以下に入った
- 同じ: 固定点の許容 1e-6（置き換える値の相対の変化）は、解き直すたびに平らな初期値から解く固有値計算の誤差（反復の判定 1e-7 /（1 − 優勢比））と
  臨界ホウ素の探索の許容（k で 1e-6）の揺らぎに近い。優勢比の大きい全炉心で揺らぎが許容を超えると、50 回で止まる（1、2 周目）
- 同じ: 残差の尺度は最初の平衡の値で、その値が 0 の項は尺度 1（数密度の絶対値の 1e-6）になる。平衡にする核種は核分裂のあるノードで正なので、
  今の燃焼では起きない（3 周目）
- 速さ（#0156 と一緒に）: Anderson の反復はすべての位置のすべての解く核種を並べる（変わるのは平衡にする数個だけ）。`MicroChain::equilibrium` は
  ノードごと、反復ごとに燃焼行列の項をすべて作り、平衡にする核種の行だけを使う。中点の最後の反復の反応率を修正子でもう一度求める。反復ごとに
  臨界ホウ素の探索を入力の範囲から始め直す（2、3 周目）
- `examples/depletion/compare_core_steps.py` の `summarize` は、方式の名前の順の最初（平衡 Xe があれば `equilibrium`）の分割 1 を基準のサイクルに
  する。点の鍵と炉心の平均の燃焼度は方式によらないので、値は変わらない（3 周目）
- 平衡の解は、組成を持つのに状態の並びでミクロ燃焼の使い方のない位置を、最初の解の後に「the equilibrium changed the micro depleted sites」で
  止める。状態ごとのミクロ燃焼する位置は `MicroNodes::new` が同じことを確かめるので、届かない（3 周目）

関係する ADR: ADR-0219
