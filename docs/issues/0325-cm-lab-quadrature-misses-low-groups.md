# 重心系の分布を実験室系の群に振り分ける積分が、Ec の幅を分けず低い群の値を誤る

## 問題

- crates/xs/src/multigroup/outgoing.rs の `laboratory_group_integrals` は、重心系の出射エネルギー E' の線形化した区間を 16 等分し、
  それぞれに 4 点の Gauss-Legendre を当てて、E' ごとの実験室系の一様な範囲 [(√E' − √Ec)², (√E' + √Ec)²] を群に振り分ける。
  群ごとの割合は、その範囲の端が群境界を横切る E' = (√B ± √Ec)²（B は群境界）で折れるが、積分はそこで区間を分けない。
  E' の区間が Ec（重心の運動による中性子 1 個あたりのエネルギー E/(A+1)²。数十〜数百 eV）より十分に広いと、Ec の程度の
  実験室系のエネルギーの群に入る分を誤る
- MF6 の LAW=1 の重心系の分布（MF6 MT18 の核分裂の χ と、散乱行列のほかの反応）が、すべてこの積分を通る

関係する ADR: ADR-0186、ADR-0082

## 完了の条件

- [x] 折れ目 (√B ± √Ec)² で区間を分ける（または閉じた式で積分する）形にし、既存の核種の散乱行列と χ の変わる大きさを測って記録に書く（examples/depletion/verification.md の
  「重心系の分布の実験室系の群への振り分け」）

## 検討して捨てた形

- 線形化した区間ごとに、すべての群境界の折れ目 u = √B ± c、c − √B（u = √E'、c = √Ec）で区間を分け、それぞれに u について 4 点の Gauss-Legendre を
  当てる形（ブランチの 0f79e95f）: 被積分関数は折れ目の間で u の 4 次以下なので厳密だが、E' = 0 から始まる区間に境界ごとに 3 つの折れ目が入り、点ごとに
  全群を探すので、ENDF/B-VIII.0 の U-238 の 600 K の `xs nuclide` が main の 1.5 倍の時間（経過時間、手元、4 スレッド。89 秒が 137 秒）になった。境界ごとに
  その境界より下に出る量を積分すれば、折れ目はその境界の分だけになり、値は丸めの差（行の和の 3e-17）を除いて同じ
- 境界ごとにその境界より下に出る量を積分し、群をその差で求める形（ブランチの dda28787。U-238 の `cycles:u` は main の 1.02 倍）: 実験室系の範囲の
  届かない群に、どちらの符号もありうる丸めの値が残り（199 群、1〜3 MeV の 30 区間、Ec = 1 keV のテスト
  `center_of_mass_groups_out_of_reach_stay_exactly_zero` が、届かない群の 0 でない値で落ちた）、
  負の χ は媒質の検査で止まる。区間ごとに届く群だけを、その群の 2 つの境界の折れ目で分けて積分する今の形にした（届かない群はちょうど 0、
  負にならない。U-238 の値は差の形と行の和の 9e-17 で同じ）
- 折れ目で分けて E' について 8 点の Gauss-Legendre にする形（#0312 の試し。コミットしていない）: E' では被積分関数が多項式にならず、厳密でない
- GROUPR と同じく、実験室系の分布を格子に作ってから群に振り分ける形: GROUPR の許容（1 %）の格子は χ の差の和で 8e-4 の程度の誤差を持ち
  （記録の同じ節）、細かくすると点が増える。閉じた形で厳密に積分できるので採らない

## 経緯

- 2026-11-20: #0312 で MF6 MT18 の χ を NJOY と比べたとき、Pa-233 の低い群の値が区間の分け方で変わることから見つけた。直すと
  既存の核種の出力が変わるので、#0312 とは分けた
- 2026-11-21: 区間ごとに届く群を、その群の境界の折れ目で分けて厳密に積分する形にした。GROUPR の `cm2lab` の許容を 1e-4 にしたビルドとの比較で、MF6 MT18 の χ の NJOY との差が GROUPR の格子によることを確かめて閉じた
