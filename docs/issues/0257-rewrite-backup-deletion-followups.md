# 履歴の書き換えの控えを消した後の文書の残り

## 問題

ブランチ docs/0249-close-cmfd-leftovers（#0249 を閉じた）のレビュー（medium、1 周目）の non-blocking の指摘。2 度目の履歴の書き換え（#0141）の作業ディレクトリ
`~/.local/share/history-rewrite/xlc-2026-10-21/` は 2026-11-07 に消した（#0077 の経緯）。

- ADR-0210 の決定と理由（凍結する部分）と #0145 の問題の節と 2026-10-22 の経緯は、書き換える前の版を同じ場所の `original.git` で引くが、消したことを
  書いていない（ADR-0210 は「## 補足」、#0145 は経緯に書ける）
- #0077 の完了の条件は、`original.git` を消した後の gc が、2 度目の書き換えの前の履歴の最後のコピーを消しうることを書いていない（GitHub の
  xlc-history-backup は 1 度目の書き換えの前の履歴。2 度目の前の履歴がほかに無いかは確かめていない）
- #0077 と #0249 の経緯は、消すと決めた問い（「履歴の書き換えの控えのコピー（#0249）を残すか消すか」の親の問い）が、作業ディレクトリの全体
  （`original.git`、`commit-map` を含む）を指していたかを書いていない
- #0249 の 2026-11-07 の経緯の最後の行（「上のとおり、…閉じる」）は、字下げが 2 文字で入れ子の項の直後にあるので、Markdown では最後の入れ子の項の
  続きに描かれる
- #0249 の `resolution` は #0077 を直したコミット 59377e09e だけを指し、ADR-0232 の補足（9ec26a3db）とタグの付け直しは経緯にだけある
- タグ archive/feat-core-cmfd を注釈つきに付け直したことは、追跡するファイルでは #0249 の経緯にだけあり、docs/branches.md は書いていない
- #0077 の完了の条件に、作業ディレクトリを消した事実の文が入り、問題の節と経緯と重なる。案 S1 と `xlc-cmfd` に取り込んだ要約は、#0077 の 2 つの
  経緯と #0249 の経緯の 3 か所にある
