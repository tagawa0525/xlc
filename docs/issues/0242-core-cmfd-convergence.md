# core の CMFD の外側の反復の縮小率と粗メッシュの固有値問題の解き方

## 問題

core の NEM を CMFD で加速した（ADR-0232）後も、外側の反復の縮小率は 0.6〜0.85 ほど残る。ADR-0232 の検討した案の測定（ブランチ perf/0076-core-cmfd の
作業中の版、手元、2026-11-06）で、均質な 18 × 18 × 18 の直方体（22 cm のノード、中性子束 0 の外周）を許容 k 1e-13、中性子束 1e-12 まで解くと外側の
反復は 113 回、1 次元の平板（18 ノード）でも 89〜106 回、CMFD が何もしない 1 つのノードの平板（1 群、中性子束 0 の両端）でも 21 回かかった。
全炉心の BOC の固有値計算 1 回（Problem 9 の形）は外側の反復 53 回。スイープの数（1〜3 回）と向き、D̃ の大きさ（0〜1 倍）、部分中性子流の更新の形を
変えても大きく変わらなかった。

1 回の外側の反復の時間は、粗メッシュの固有値問題（ブロック Gauss-Seidel のべき乗法を、NEM の許容とスイープによる変化に比例した精度で）が NEM の
スイープと同じ程度を占める（BOC の全体で粗メッシュの反復は 6,000 回ほど）。

原因の候補（確かめていない）:

- ノードの中の形（展開係数と部分中性子流の和と差）の誤差で、ノードの平均だけを直す CMFD が除かないもの。2 ノードの NEM の問題で面の量を CMFD の解から
  決める形（K. S. Smith の非線形の反復）と比べる
- 粗メッシュの固有値問題: Wielandt のシフトと内側の連立方程式の Krylov 法（BiCGSTAB など）、Chebyshev の外挿、軸方向の線の緩和

関係する ADR: ADR-0232

## 完了の条件

外側の反復の縮小率が残る原因を最小の問題で確かめ、直せるなら直す。粗メッシュの固有値問題の解き方を比べ、全炉心の 1 回の固有値計算の時間の内訳を
記録する。

## 経緯

- 2026-11-06: ADR-0232 の実装で、加速した反復の回数と粗メッシュの反復の時間を測って残した
