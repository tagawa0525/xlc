# 自己遮蔽のピンと塊の組を、MOC と同じ確かめ方の対称操作で作る

## 問題

MOC の 1/4 対称性（ADR-0113）は、移り合う領域が同じ物質（同じ参照）であることを求める。自己遮蔽には、入力が対称でも
移り合う部分を別々に解く経路が 2 つあり、そのときは別の物質になって、MOC が `AsymmetricMaterial` で止まる:

- (a) 扇形で分けた構造材の塊（リングを丸ごと含まないまとまり。たとえば扇形で分かれた四隅）は、`shield_lumps` が
  セルごとの黒体として遮蔽し、組でまとめない（crates/lattice/src/shielding.rs の、リングを丸ごと含むかの判定）
- (b) `symmetry::cell_orbits` は、どれか 1 つのセルで扇形ごとに物質が違うと（リングごとの物質が決まらないと）、8 つの操作を
  すべて外し、どのピンも組にしない

関係する ADR: ADR-0112, ADR-0113

## 懸念

- 別々に解いた部分の値は丸めの程度で違いうるので、値で比べて同じとみなす扱い（ADR-0113 で採らなかった）には戻さない

## 完了の条件

- 自己遮蔽のピンと塊の組を、MOC と同じ確かめ方で成り立つと分かった対称操作（全 8 操作ではなく、成り立つ操作だけ）で作り、扇形で分けた塊も
  組にする。扇形で物質が違うセルがあっても、そのセルを動かさない操作や、扇形を扇形に移す操作は認める
- 入力が 1/4 対称な格子で、自己遮蔽のあとの MOC が `symmetry = "quarter"` で止まらないことをテストで示す
