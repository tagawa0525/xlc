# MOC の鏡面反射の上の辺で、ノードごとの正味の中性子流が 0 にならない

## 問題

反射体の I 型の格子（`examples/reflector/reflector-I.toml`、右が真空、ほかは鏡面反射）を集合体と反射体のノードに分けると、
上の辺の外向きの正味の中性子流が、集合体のノードで +1.44 × 10⁻⁶、反射体のノードで −1.44 × 10⁻⁶（高速群。熱群は ±5 × 10⁻⁸）に
なる。辺全体では打ち消し、下の辺は 10⁻¹¹ 程度で 0 になる。集合体のノードの x の正味の中性子流（0.0114）に比べて 1.3 × 10⁻⁴ で、
1ノードの問題の横方向の漏れとしては無視できる。反射体を2つに分けた格子でも、内側の反射体のノードで −1.4 × 10⁻⁵ になる
（examples/reflector/verification.md、a1fe39d、2026-10-09）。

I 型の反射体の GET の等価性（core の k が MOC から +1.5 pcm、ノード平均が 10⁻⁴ 以内）の残る差は、この流れによる。core の
上下の面は正味の中性子流が厳密に 0 で、参照のノードのバランスと y の漏れの分（x の漏れの 1.4 × 10⁻⁴）だけ食い違う。MOC の
許容差（k と中性子束）を 1000 分の 1 にしても、この流れは変わらなかったので、収束の誤差ではない（examples/reflector/verification.md、
f6839b5、2026-10-09）。

鏡面反射の辺では、出ていくトラックの角度中性子束が同じ点から入るトラックにつながるので、どの部分でも正味の中性子流は
収束の許容差の程度で 0 になるはずである。上の辺だけで起きる理由（入ってくる側の値が前の反復のスイープのもので CMFD の比を
かけていないこと、トラックの端の点がセルの境に当たるときの面の割り当て、など）は調べていない。候補: 格子の幅
（43 cm）とトラックの配置から、上の辺でトラックの端の点がノードの境（x = 0）にちょうど当たると、出ていくトラックの最後の
区間と、つながる入るトラックの最後の区間が x = 0 の左右の別のセルにあり、出る流れと入る流れが別の面に数えられる。

関係する ADR: なし

## 完了の条件

原因を特定し、許容差の程度で 0 になるようにするか、0 にならない理由と大きさの上限を記録する。

- 2026-10-09: I 型の反射体の等価性の残る差（+1.5 pcm）の原因と分かった。許容差によらない
