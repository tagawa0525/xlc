# 熱水力のフィードバック（Problem 6〜9）の ADR と実装

## 問題

VERA の Problem 6〜9 は HFP で、仕様書（CASL-U-2012-0131-004、Problem 9 の節、85 ページ）は「Thermal-hydraulic feedback is required
for at-power conditions」とし、燃料の温度を、温度、照射、燃焼度とともに変わる燃料棒のモデルで求めることを求める。Problem 9 の入力は
定格の流量 131.7 Mlbs/hr（バイパスの 9% を除いた値で、サイクルを通じて一定）、圧力 2250 psia（表 P9-1）と、ステップごとの入口の温度
（表 P9-2、554.9〜558.8 °F）で、熱水力の物性は与えない（Problem 6 の MATERIAL PROPERTIES。docs/plans/m4-depletion.md の「熱水力のフィードバック」）。

起こした時点（2026-11-05）の xlc には熱水力のモデルが無く、決める ADR も無かった（初期のマイルストーンで扱わないと決めた ADR は、
[ADR-0229](../adr/0229-couple-assembly-channels-and-fuel-rods-to-core.md) が置き換えた）。core はケースの状態ごとに減速材の温度と燃料の温度を 1 つずつ持ち、炉心のすべてのノードで同じ値を使う
（crates/core/src/input.rs の `CaseState`、crates/core/src/state.rs の `State`。減速材の密度はテーブルの格子点の組で決まる）。
熱水力のあるケースのノードごとの状態は ADR-0229 で入った（「残り」）。
分岐のテーブルの温度の格子点は、M3 の HZP のテーブルが 550〜580 K（ADR-0097）、燃焼の分岐の入力の燃料の温度が 565 と 600 K
（examples/depletion/branches の `fuel = { temperature = [565, 600] }`）で、HFP の燃料の温度と減速材の密度の範囲を持たない。

これを待つもの（docs/plans/m4-depletion.md の「進め方」）:

- 6: 本番の分岐のテーブルの軸の格子点（HFP の範囲）。ADR-0033 のデータ（#0153）はその前に入れる。HFP の範囲の 3 次の項と M×F の誤差の
  測定（#0176）
- 7: core の燃焼の入口の温度（ADR-0218 は、熱水力の ADR の後まで状態の減速材の温度で書く形にとどめた）
- 9: Problem 9 の燃焼と臨界ホウ素濃度の比較

関係する ADR: ADR-0229、ADR-0230、ADR-0239

## 完了の条件

- 計画の「熱水力のフィードバック」の「ADR で決める」の項目（M4 で入れるか、流路の粒度、燃料の温度のモデル（熱伝導度の燃焼度依存、
  ギャップのコンダクタンス））を ADR で決める
- core がノードごとの減速材の温度と密度、燃料の温度を熱水力の解から求め、テーブルをノードごとの状態で内挿して、出力との繰り返しを
  解く。燃焼のステップの入口の温度からノードの状態を求める（ADR-0218 が後に回したもの）。Problem 6 か 7 の入力で解ける

## 残り

ADR-0229 で決め、core の状態の解（燃焼でないケース）に実装した（ブランチ feat/0228-thermal-hydraulics）。完了の条件のうち次が残る:

- 済み（2026-11-06、ブランチ feat/0228-problem-6）: Problem 6 の入力。ライブラリに HFP の温度の点を足し、分岐のテーブルの格子点を決め
  （ADR-0230）、examples/vera/p6 で解いた（examples/vera/verification.md の「Problem 6 の 3D の HFP の集合体」。k 1.167684、出口
  600.495 K、燃料の実効温度 604.7〜1012.7 K）。繰り返しの回数は #0232
- `micro` のない燃焼のケースの出力の割合（ADR-0218 の案 M1）を、熱水力のある燃焼で開くか: 熱出力を通して固有値計算に効くが、今は書けば
  エラーで、どのステップも定格の熱出力で解く（ADR-0229 の帰結）
- HFP の燃料の温度の燃焼: 燃焼の分岐のテーブルの燃料の温度の格子点は、作り直す前の p2 のライブラリでは、燃焼の履歴が輸送する B-10 の温度の点（565、600 K）までしか
  作れず、熱水力のある燃焼の試行は定格の 3 % の熱出力にとどまる（examples/depletion/verification.md の「熱水力のある燃焼（小さな炉心と全炉心）」）。
  HFP の範囲は計画の「進め方」6 の本番のテーブル
  - 2026-11-08: ADR-0239（proposed）で Problem 9 のテーブルの格子点（燃料 560〜1350 K、減速材 560〜615 K、ホウ素 0〜1625 ppm）を決め、
    p2 のライブラリの入力に温度の点を足した（ブランチ feat/production-burnup-table-grid）。ライブラリの作り直しとテーブルの作成は残る
  - 2026-11-10: p2 のライブラリを作り直した（Slurm 727。前からある温度の表が変わらないことは ADR-0239 の確認）。テーブルの作成は残る
- ギャップのコンダクタンスの機構のモデル（ADR-0229 の案 H2）: 熱膨張、再配置、ガスの熱伝導、輻射の式の出典（FRAPCON-3.4 の説明、
  NUREG/CR-7022 Vol. 1）を手に入れてから
- 燃料の実効温度（体積平均と Rowlands）のどちらが、格子計算で燃料のリングごとに温度を変えた参照に近いか（ADR-0229 の案 E3）

## 経緯

  解に実装した。Problem 6 はライブラリの温度の点が足りず解けない（「残り」）

- 2026-11-07: 燃焼のステップの熱水力（ADR-0229 の「燃焼のステップ」）と、ノードの熱水力の状態からの減速材の密度の履歴の変数（ADR-0215）を
  入れ、小さな炉心と全炉心の試行で解いた（ブランチ feat/0228-depletion-thermal-hydraulics。B-10 の温度の点で燃料の格子点が 600 K までに限られた）

  feat/production-burnup-table-grid）
- 2026-11-11: 集合体の間の流量の再配分（ADR-0229 の案 G3）は行わないと決め、「残り」から外した（ユーザー 2026-11-11）。VERA の仕様書に
  損失係数と流路の寸法の仕様が無い。比べる相手になる集合体ごとの流量の測定値があるかは確かめていない。
  全炉心への効きは確かめていない。Problem 9 の臨界ホウ素濃度の比較で、流量の配分のほかに説明の無い差が出たら、新しい issue で見直す
