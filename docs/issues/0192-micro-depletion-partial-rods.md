# 部分挿入のノードのミクロ燃焼

## 問題

core のミクロ燃焼（ADR-0216、#0153）は、追う核種の反応率をテーブルの微視的断面積 × ノードの少数群の中性子束で作る。制御棒の先端が
ノードの中にある部分挿入のノード（ADR-0127）は、区間ごとに別の制御棒の値の微視的断面積を持つが、NEM の解はノード平均の中性子束しか
持たない。区間の長さで σ を平均すると、区間の中性子束が一様という仮定（ADR-0127 が少数群定数で採らなかった体積の重み）になる。
いまの core は、核分裂のある部分挿入のノードのミクロ燃焼をエラーにする（crates/core/src/depletion.rs の `MicroNodes::new`）。
線形の補正は区間ごとの定数に足してから混ぜるので、このエラーは反応率のためだけ。

Problem 9 のサイクルの燃焼は D バンクを部分挿入で運転するので、炉心の燃焼の前に要る。

関係する ADR: ADR-0216

## 完了の条件

- 部分挿入のノードの追う核種の反応率の作り方（ADR-0127 の細かいメッシュの区間の中性子束で重みを付けるなど）を決め、core が解く

- 2026-10-29: core のミクロ燃焼（feat/0153-core-micro-depletion）で、部分挿入のノードをエラーにして残した
