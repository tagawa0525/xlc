# 分岐の状態ごとの格子計算の時間

## 問題

VERA 2B の分岐のテーブル（examples/branches、27 状態）は、1 状態あたり平均 256 秒（253〜273 秒）、全体で
1 時間 55 分かかった（32 スレッド）。そのうち MOC は約 59 秒で、残りの約 200 秒は燃料の自己遮蔽と見るが、自己遮蔽にはトレースの区間がなく、
測っていない。ホウ素の格子点を増やす（#0038）と状態の数は 63〜117 になり、燃焼の点ごとに分岐を作ればさらに
燃焼の点の数を掛けた回数になる。

関係する ADR: ADR-0109, ADR-0110, ADR-0112, ADR-0113, ADR-0156

## 懸念

- 自己遮蔽は状態ごとに解き直している。燃料の温度と減速材の密度・ホウ素濃度は、どれも燃料の共鳴の遮蔽に効く
  （バックグラウンドの断面積とダンコフ係数を通じて）ので、状態の間で使い回すと誤差を持ち込む。速くするなら、
  まず自己遮蔽の中の時間の内訳を測ってから、遮蔽の結果を変えない方法（並列化など）を探す

## 完了の条件

- 自己遮蔽にトレースの区間を足し、1 状態の時間の内訳を測って記録する
- 内訳から、速くする方法を決めるか、このままでよいと判断する

## 経緯

- 2026-10-09: VERA 2B の分岐のテーブルの確認で、1 状態平均 256 秒のうち MOC 以外が約 200 秒と分かった
- 2026-10-09: ユーザーが、集合体1体の格子計算に数分かかるのは遅すぎる（秒の単位と思っていた）と指摘した。perf で
  examples/split/assembly-1.toml の1状態（255 秒、32 スレッド）を測ると、約 77% が自己遮蔽の UFG の減速計算の中の、
  円筒の等価なセルの衝突確率（`cp::Cylinder::tracks` と、その中の指数関数と Bickley 関数の表の補間）で、MOC のスイープは
  約 10%（61 秒）だった。衝突確率はポイントワイズのエネルギー点ごと、代表のピンごとに求め直していて、弦は小区間あたり
  16 点の Gauss の求積、弦ごとに区間の対を回り、弦ごとにメモリを確保している
- 2026-10-10: ユーザーは、自己遮蔽は UFG のまま工夫で速くする方針とした。代表のピンは 39 本（燃料ピン 264 本）、UFG の
  点は 342,106 点、ピンあたり約 5.1 秒。表の範囲を超えた Bickley 関数の項の打ち切りと、弦の区間の境界の対ごとの Ki3 の
  評価で、自己遮蔽は 204 秒から 182 秒になった。弦の求積を 8 点にすると 118 秒になるが、求積の基準（1e-9）を満たさない
  ので見送った（#0044）。残る時間の大半は、エネルギー点ごとに衝突確率を求め直すことで、全断面積の少数の組の衝突確率から
  内挿する案を ADR にして試す
- 2026-10-10: その後、ピンの間の並列（自己遮蔽 121 秒）と Zen 5 向けのコンパイル（ADR-0109）で、2B の 1 状態は 167 秒になった。
  MOC（方位角 32、自己遮蔽なし）の内訳は、平衡 3.4 秒、スイープ 19.7 秒、合計 3.1 秒、組み立て 1.9 秒、CMFD 27.9 秒で、
  CMFD は呼び出しごとに 179〜1070 回反復していた。CMFD をスイープの変化に比例した精度で解き（ADR-0110）、核分裂源を
  スペクトルごとの項で持つようにして、MOC は 56.5 秒から 39.4 秒になった（MOC の反復は 24 回のまま、少数群定数の差は
  2.9e-8 以下）。perf で CMFD は全体の 2% 未満になったので、Wielandt のシフトや赤黒の順序の並列化は入れない。残る MOC の
  時間は、スイープ 60%、tally の合計 14%、指数関数 12%、memset 10%
- 2026-10-10: 1/4 対称性で、代表のトラックだけをスイープし、領域と CMFD のセルの状態も代表の分だけ持つようにした（ADR-0113）。
  2B（方位角 30・間隔 0.03 cm）の MOC は 44.6 秒から 14.0 秒になり、平衡値、スイープ、tally の和、中性子束の更新、CMFD の
  どれも約 1/4 になった。CMFD は、全体を解くときの壁時計の時間で反復の約 1/4（反復あたり 0.43 秒）を占めていた（上の
  「perf で 2% 未満」は全スレッドの CPU 時間の割合）。代表と像は状態ごとに作り直している（反復の外の時間が約 0.3 秒増える）
- 2026-10-10: モジュール式のレイトレーシングは今は入れない（#0056）。2B（方位角 30・間隔 0.03 cm、ADR-0111、対称性なし）で
  トラッキングのデータは約 110 MB（Vec の容量で約 153 MB）で、最大 RSS（自己遮蔽ありで 11.3 GB、なしで 9.0 GB）の
  約 1.4〜1.7%。残りの内訳は調べていない（候補: MOC の状態の配列、スレッドごとの方向の配列の pool、断面積の
  ライブラリ）。MOC だけで IPC 2.25、L1 のデータキャッシュが L1 の外から埋まるうち DRAM からは 19%（帯域で律速されて
  いるかは確かめていない）
- 2026-10-10: 成り立つ対称操作をすべて自動で使うようにした（ADR-0112）。2B は 1/8 で、MOC は全体の 44.2 秒から 8.4 秒、1 状態は
  2 分 35 秒から 1 分 59 秒（examples/vera/verification.md「成り立つ対称操作をすべて使う」、8f93b318）。残りの約 110 秒は
  自己遮蔽で、ピンはすでに 1/8 の組の代表だけを解いている。対称操作の確かめ（像と区間の長さ。2B で約 1 秒）は、格子のプログラムで
  解く前に一度だけ行い、自己遮蔽と MOC に渡して分岐の状態の間で使い回す（状態ごとには物質の参照の確認だけ）。自動の MOC は
  7.4 秒（7b200853）
- 2026-10-10: 検証の記録を今の姿に書き直した（#0057）。上の経緯が引く節は、examples/vera/verification.md の「対称性」に
  まとめた。2B（1/8）の今の値は MOC 7.4 秒、1 状態 1 分 59 秒（64e069de）
- 2026-10-13: 自己遮蔽に tracing の区間（`RUST_LOG=xlc_lattice=debug` で Dancoff 係数、ピンごとの Carlvik の反復、UFG、SPH、
  塊の遮蔽と、UFG の中のポイントワイズの断面積の補間、衝突確率、減速の反復の壁時計の時間）を足した（4ae0c84f）。2A の
  1 状態（排他のジョブ 286、16 スレッド、分岐点 bf7d2439）で、自己遮蔽 119 秒のうち Dancoff 係数 2.2 秒、塊の遮蔽 2.2 秒、残りが
  ピン 39 本。ピンの中の段の割合は、ピンの間も並列だとほかのピンの盗んだ仕事が衝突確率の時間に入るので、1B を 1 スレッドで
  測った（排他のジョブ 299、4ae0c84f）: UFG 46.1 秒のうち衝突確率 44.6 秒、逐次の減速の反復 1.30 秒、ポイントワイズの断面積の
  補間 0.13 秒（97%、3%、0.3%）。39 本 × 46.1 秒 / 16 スレッドは 112 秒で、測った 119 秒に近く、ピンの間とエネルギー点の間の
  並列はほぼ飽和していると見る（1B と 2A のピンの手間の違いと負荷の偏りは分けていない）。32 スレッド（SMT）では自己遮蔽 107 秒、MOC 8.4 秒（ジョブ 286）。1B の 1 スレッドの perf（bf7d2439、手元）では、
  走行全体のサンプルの約 55% が弦の区間の対の計算（`Cylinder::tracks`）、約 26% が Ki3 の表の補間、約 9% が指数関数（libm。MOC の
  分を含む）で、弦ごとの
  メモリ確保は 1% 未満だった
- 2026-10-13: 出力を変えない高速化を 3 つ入れた（Ki3 の値を弦の境界の対の行ごとに 1 回で求める、Hermite 補間の係数を表に
  持つ、減速の反復の作業用の配列を使い回す。79c22dd2、ee965d7d、d19c47eb）。1B と 2A の媒質とピン出力はバイト単位で同じ。
  2A の 1 状態は 105 秒、自己遮蔽 95.2 秒（d19c47eb、分岐点 bf7d2439、排他のジョブ 288。examples/vera/verification.md）。
  1B の 1 スレッドの UFG は 46.1 秒から 38.1 秒（衝突確率 37.0 秒、減速の反復 0.99 秒。7a1d620a、排他のジョブ 299）。同じ日の 4ae0c84f の
  119 秒（ジョブ 286。手元の 1 スレッドの走行と重なった）からの差で、目標の 10〜20 秒台には届かない。SMT を自己遮蔽だけに使う

- 2026-10-13: 衝突確率を物質ごとの全断面積の格子の表から内挿する案を試した（ブランチ perf/0039-cp-table、ADR-0156 に
  proposed で記録）。10 倍あたり 16 点で 2A の自己遮蔽は 12.9 秒、2Q は 13.6 秒、k はログの 6 桁で変わらず、ピン出力の差は
  1e-7 以下。Dancoff 係数の近いピンをまとめる案は採らない（ADR-0156）。採るかはユーザーが決める。同じ試行の格子点ごとの
  走行（da796a34 の既定）で、2Q の自己遮蔽は 165 秒、塊の遮蔽は 2A と同じ 2.2 秒で、2Q が 2A より長いのは塊の遮蔽ではない。
  原因の候補は、枠のリングを足した等価なセル（リングは 9 で 2A の 8 より 1 つ多い）の衝突確率だが、確かめていない（ピンの UFG の区間の
  衝突確率の時間はほかのピンの盗んだ仕事を含むので、2Q と 2A の比べには使えない）
