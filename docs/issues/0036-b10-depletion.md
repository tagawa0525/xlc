# 一次冷却材の B-10 の割合が燃焼で減る効果

## 問題

- B-10 の割合を core が燃焼で追うか（一次冷却材の B-10 は (n,α) で減り、補給するホウ酸で一部は戻る）。追うなら、B-10 の吸収率と、
  冷却材の量、抽出と補給を表すモデルが要り、炉心の燃焼（M3 の範囲の外）のあとになる。追った割合（またはノードの B-10 の個数密度）から、ADR-0237 と同じ換算で ppm を作って引くのが候補

関係する ADR: ADR-0237

## 完了の条件

- B-10 の割合を core が燃焼で追うかを決める。追うなら、その形を ADR で決めて実装する

## 検討して捨てた形

- テーブルに冷却材の B-10 の微視的断面積を持たせ、core が個数密度の差を補正する形: 直接の格子計算との差が、ppm の換算より大きかった
  （ADR-0237 の「検討した案」の案 3）

## 経緯

- 2026-10-09: ユーザーが、燃焼で B-10 の割合が減る効果を扱えるようにしておくよう求めた（実務では B-10 の割合を測る必要があるので
  使う場面は多くない。急がない）
- 2026-11-07: B-10 の微視的断面積の補正（ADR-0237 の「検討した案」の案 3）を実装して測り、ppm の換算より差が大きかったので、ユーザーが換算（ADR-0237）に替えた
