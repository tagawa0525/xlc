# 一次冷却材の B-10 の割合が燃焼で減る効果

## 問題

一次冷却材のホウ素の B-10 は (n,α) で減るので、サイクルの途中で B-10 の原子分率が天然の値（19.9 at% 前後）より
下がる。補給するホウ酸で一部は戻る。同じ ppm でも B-10 の個数密度が減るので、臨界ホウ素濃度とホウ素価値が
変わる。

いまは B-10 の割合をテーブルごとに1つとし、ケースの `[state]` の `b10` がテーブルと違えばエラーにする
（ADR-0097）。測った B-10 の割合を与える入力の場所（`[state]` の `b10`）はあるが、天然と違う値では計算できない。
ユーザーは、実務では B-10 の割合を測る必要があるので使う場面は多くないが、扱えるようにしておくよう求めた。
急がない。

関係する ADR: なし

## 方針の案

1. 天然相当のホウ素濃度に直す: ケースの (ppm, b10) を、テーブルの b10 で B-10 の個数密度が同じになる ppm に
   直して内挿する。ppm は質量の割合なので、ホウ素の平均の原子質量 M(b10) も変わる（ADR-0106）。
   ppm' = ppm · (b10 / M(b10)) · (M(b10ₜ) / b10ₜ)。B-11 の熱中性子の吸収断面積は B-10 より6桁ほど小さいので、B-11 の個数密度の
   ずれは無視できると見込むが、確かめる。格子計算を増やさない
2. B-10 の割合をテーブルの軸にする: ホウ素の効果は B-10 の個数密度でほぼ決まるので、軸を足すのは 1. に比べて
   状態の数（いまの 27 の 3 倍など）に見合わないと考える

1. を推す。採るなら ADR-0097 の「B-10 の割合が違えばエラー」を新しい ADR で置き換える。

B-10 の割合を誰が与えるかは別に決める。

- 入力で与える（測った値）: `[state]` の `b10` をそのまま使う。1. だけで足りる
- core が追う: B-10 の吸収率と、冷却材の量、抽出と補給を表すモデルが要る。炉心の燃焼（M3 の範囲の外）の
  あとになる

## 懸念

- 濃縮ホウ酸（B-10 を天然より多くしたもの）を使う炉もあるので、天然より大きい b10 も受ける。1. はどちらの向きにも
  使える
- 換算した ppm' がテーブルの範囲の外に出ればエラーにする（いまの範囲の外の扱いと同じ）。b10 が下がると ppm' は
  下がるので、テーブルの下限は換算後の値で決まる
- 先行事例（炉心計算コードの B-10 の燃焼の扱い）はまだ調べていない。調べて ADR に出典を書く

## 完了の条件

- 換算の方法を ADR で決める（先行事例の出典つき）
- b10 が天然と違う状態（たとえば 0.18 と 0.30）で、直接の格子計算の k と、換算してテーブルを内挿した core の k を
  比べ、差を検証の記録に書く
