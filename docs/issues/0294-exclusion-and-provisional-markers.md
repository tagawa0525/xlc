# 除外と仮の前提を、issue の番号と状態で機械的に検査する

## 問題

核種、ファイル、検査を「外して通す」対処と、仮に置いた組や値が、理由の解消の後も、測られないまま本番の形の入力に残った
（一覧は #0293。例: #0127 が閉じた後も examples/depletion/p2/xs.toml だけ 5 核種が外れたまま、語の検査から外した 555 ファイル）。
`scripts/check-exclusions.py`（pre-commit の hook `exclusions` と scripts/run-rust-docs-tests.sh）が、次の印に issue の番号を求め、閉じた issue だけを指す印を止める:
`.textlintignore` の項目、Rust の `#[ignore]`、無条件の Python の skip、例の入力の注釈の「確かめていない」「暫定」「仮の」「仮に」「仮置き」「未確認」、
すぐ前後に issue を引く除外の語（外す、除いた など）の注釈。残っている点:

- 印の無い仮の前提は検査に掛からない。入力の注釈の除外の語は、すぐ前後に issue の番号が無い行を止めない（一般の語として使う。
  2026-11-19 の main で、試行を除く例の入力の注釈のうち、issue を引かない「外す」「外した」「外して」の 4 行は、どれも
  examples/colorset の「不連続因子を外した定数」だった）。仮に置くときに印を書くことは検査で強制できない
- ADR と計画の「測っていない」「候補」「後回し」のまま本番の入力が拠っている決定（#0293 の形 (d)、(e)）は見ない
- ADR と計画の上の点のうち、新しい ADR に「根拠の測定（何で測ったか。燃料の種類、状態、燃焼度）」と「参照と共有する前提（比較が
  検出しない前提）」の欄を求める検査は、数値計算に固有なので、共通の design-records でなく xlc の側で作る（ユーザー 2026-11-19 の
  発言の要約）。#0293 の形 (b)、(c) に当たる。対象は計算の方式、既定、核種や点の組を決める ADR で、ツールや文書の ADR は除く
  線引きが要る。置き場の候補（確かめていない）: docs/adr/README.md の形と、新しい ADR だけを見る scripts/ の検査と hook
- 条件つきの skip（`skipUnless`。参照のファイルが無いとき）、テストの本文の中の skip、DVC の未実行のステージは数えない。除外の語と
  issue の番号が行をまたいで折り返した注釈も集めない（仮の前提の印も、同じ行の issue だけを見る）
- 本番の形の計算を投げる前の一覧（`scripts/check-exclusions.py --list`）は、投げる手順（スキル topic-start の「計算を投げる直前」）から
  呼ばれていない
- 誤差の見積もりを上から作る計画（核データから炉心計算までの近似と前提を並べ、独立な手段で大きさを見積もり、大きい順に片付ける。
  材料は #0293）と、前提を共有しない参照（核種を絞らない計算、公開のベンチマーク）は、まだ計画（docs/plans/）に無い

関係する ADR: なし

## 完了の条件

- [ ] 上の残りの点ごとに、検査に足すか、足さない理由を書く
- [ ] 計算の方式と既定を決める新しい ADR に、根拠の測定と、参照と共有する前提の欄を求める検査を xlc に作る
- [ ] 誤差の見積もりの計画と、前提を共有しない参照を持つかを、ユーザーが決める

## 経緯

- 2026-11-19: ユーザーが、手抜きの後始末が次々に出てくる進め方を誤りと指摘した。同じ日に、根拠の無い前提（微分の核種、追う核種、
  輸送する核種）と、理由の消えた除外（#0127 の 5 核種、語の検査から外した入力）が続けて見つかった。振り返りで、除外と仮の前提を
  検査に掛ける形にした
