# 真空の辺の GET の等価性: P1 の関係と、大きなノードの負の均質な面の中性子束

## 問題

ADR-0094 の ADF（不均質な面の中性子束 / 1ノードの NEM の均質な面の中性子束）を入れた core の NEM は、真空の辺の
ある格子を、その格子の MOC の k から +1510〜+3803 pcm ずれて解く（VERA 2B の燃料ピンの 3×3、5×5、9×9、右の辺が
真空。examples/vera/verification.md の「真空の辺のある格子の ADF と core の1ノードの NEM」、491dba3、2026-10-09）。
core の真空の面の条件（ADR-0099）は不均質な中性子束に P1 の関係 φ_het = 2J を課すが、MOC の真空の辺では
φ_het/(2J) = 0.87〜0.95 である。右の辺の ADF を 2J / 均質な面の中性子束にすると、3つとも MOC の k に 10⁻⁶ で一致する。

また、17×17 の集合体（21.5 cm）に真空の辺があると、1ノードの問題の熱群の均質な面の中性子束が負になり、ADF を
作れない（ADR-0094 のとおりエラー）。

関係する ADR: [ADR-0094](../adr/0094-define-adf-by-one-node-nem.md)、[ADR-0101](../adr/0101-impose-transport-current-ratio-at-vacuum-faces.md)

## 完了の条件

真空の面で等価性を保つ方法（例: 真空の辺の面の因子を 2J / 均質な面の中性子束と定義する、core の真空の面の条件に
格子計算の φ_het/(2J) を持たせる、MPACT などの扱い）を文献と比べて決め、ADR にする。燃料が真空に直接面する
集合体の格子を ADF の対象にするか（反射体の格子 ADR-0095 では真空の面は反射体の外側）もあわせて決める。
上の比較で core の k が MOC の k を再現することを確かめる。

## 経緯

  した。17×17 の集合体の負の均質な面の中性子束は r によらないので #0027 に分けた
- 2026-10-09: ADR-0101 を実装した。格子計算は真空の辺の r を少数群定数に書き、core の `vacuum` は J = r f φ を課す。
  n = 3、5、9 の core の k は MOC と 0.0015、0.0025、0.0044 pcm で一致した（examples/vera/verification.md の
  「真空の辺の比 J/φ を入れた core の1ノードの NEM」、0f8e102）。燃料が真空に面する集合体を ADF の対象にするかは #0027
