# MOC の収束の判定が、残りの誤差を判定より小さく見積もる問題がある

## 問題

MOC の反復は、k と中性子束の反復ごとの変化の縮小率から残りの誤差を見積もり（`moc::Remaining`）、k 1e-7、中性子束 1e-6
（`moc::Options` の既定）を下回れば止める。燃焼の単体テストの 1 本のピンセル（`history::tests` の `history()`。k は 0.08 程度で、
平らな初期値から 43 回の反復）では、止めた解の k と、判定を 5 桁細かくした解の k の差が −6.3e-7（燃焼度 0）、−6.0e-7（0.5）、
−5.4e-7（2.0）で、判定 1e-7 の 5〜6 倍あった（perf/moc-warm-start のブランチ、37f6fd8b の時点の手元の一時のテスト、2026-10-23。
コミットしていない）。同じ問題を前の輸送の解から始めた解（ADR-0195）の差は −6.3e-7、+1.5e-7、+1.0e-7。

止めた解の誤差が判定を超える原因は確かめていない。候補: 縮小率が反復ごとに揺れ、その比から見積もった ρ/(1 − ρ) が小さく出る。CMFD を
緩めて解く（ADR-0110）誤差が変化に入る。

関係する ADR: ADR-0195

## 完了の条件

集合体の問題（2A など）でも同じ大きさのずれがあるかを、判定を細かくした解と比べて測る。ずれが判定を超えるなら、原因を確かめ、
判定の見積もりを直すか、判定の意味（残りの誤差の上限でなく見積もり）を ADR に書く。
