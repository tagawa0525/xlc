# MOC の部分和を方位角ごとに持つ記憶量を、入れ物の数を固定して減らすか

## 問題

MOC のスイープは、部分和の入れ物（領域と群ごとの和など）を方位角ごとに持ち、方位角の順に足す（[ADR-0064](../adr/0064-sum-sweeps-per-azimuth.md)）。
記憶量は方位角の数に比例し、非等方散乱のモーメント（[ADR-0075](../adr/0075-solve-moc-with-anisotropic-scattering.md)）の数だけさらに増える。

ブランチ refactor/tally-slots（a45f7dd8）は、入れ物を固定の 16 個にし、方位角 a を a mod 16 番目に入れる。足す順は
入れ物の順に固定なので、結果はスレッドの数によらない。ユーザーは 16 という数の根拠を疑問視したが、今の問題では方位角ごとに
持っても記憶量は問題にならなかったので、マージせずに残している。

関係する ADR: [ADR-0064](../adr/0064-sum-sweeps-per-azimuth.md)

## 完了の条件

記憶量が問題になる問題（方位角や群、モーメントの多いもの）が出たら、方位角ごとに持つ場合の記憶量を測り、入れ物の数の
決め方（固定の数か、スレッドの数によらない別の決め方か）を ADR にする。それまでブランチは残す。

## 経緯

- 2026-10-12: マージしないで残す理由をメモリから issue に移した
