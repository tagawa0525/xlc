# 平衡 Xe の固定点が有限でない組成を黙って通すことと、同時の反復の整理

## 問題

crates/core/src/depletion.rs の `equilibrate`（ADR-0219 の平衡 Xe の固定点）は、ホウ素の成分の次の濃度が有限でなければエラーにするが、組成の
平衡の値は確かめない。残差の `fold(0.0, f64::max)` は NaN の成分を捨て（`f64::max` は NaN でない側を返す）、Anderson の加速（`anderson`）は負の値を
0 にする `v.max(0.0)` で NaN も 0 にする。解の反応率が NaN を含み `MicroChain::equilibrium` が NaN の Xe と I を返すと、NaN を除いた残差が許容の中なら
NaN を含む組成を収束として返し、そうでなければ加速の γ が NaN になって組成のすべての成分が 0 になって続く。入れ子の形（`xenon-boron = "nested"`）と
ホウ素を探さない状態にもある、同時の反復の前からの形。NaN の反応率が出る入力は見つけていない（再現していない）。

同じ箇所の整理（どれも挙動を変えない）:

- 次の濃度の検査のコメント「NaN を通すと黙って範囲の下端で解く」は、加速の履歴がないときだけ正しい。履歴があれば γ がすべて NaN になり、組成も 0 になる
- `joint_scale` の使い回しは、効きを固定した後の尺度が変わらないので、末尾の書き換えの枝は値を変えない。最初に 1 度だけ作る形のほうが短い
- crates/core/src/search.rs の `find` の `ends` は多くても範囲の 2 つの端で、Vec と `max_by` でなく、根の位置で場合を分けて直接書ける
- `next.pop().ok_or_else(...)` のエラーには到達しない（`anderson` は最後の組と同じ長さを返す）。長さの食い違いを示す形か、到達しないことを書く形にする

関係する ADR: なし

## 完了の条件

`equilibrate` が評価の組成とホウ素の成分の全体を有限か確かめ、有限でなければエラーにする（テストで、NaN の平衡の値を返す評価がエラーになる）。
上の整理を済ませる。
