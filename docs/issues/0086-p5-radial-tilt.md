# 5-2D の集合体出力が KENO-VI より平らになる（中心で −5%、外周で +10%）

## 問題

VERA 5A-2D を全炉心（ADR-0090）で、単一集合体の定数と I 型・角型の反射体の定数（f\* の方法。ADR-0095、ADR-0132）で
解くと、k は KENO-VI より +235 pcm 大きい。集合体出力は中心で低く、外周で高い（H8 で −4.5%、G8 で −6.8%、B12 で +10.4%。
193 体の RMS は 4.1%。examples/vera/verification.md の「Problem 5-2D の炉心の計算」、1c115833、2026-10-12）。5B-2D と 5C-2D も同じ形
（RMS 4.8%）。KENO-VI の参照（付録 J の Case 1）と xlc の反射体（Case 2 の形）の違いは、表 J-1 では集合体出力の最大の差が
−0.57% で、この大きさを説明しない。

分かっていること:

- 外周の集合体の定数を作る格子では、f\* の方法が k を大きく外す。5-2D の I 型の格子で燃料のノードを単一集合体の定数にすると
  +580 pcm、角型の格子では +1640 pcm になる（定数を作った格子の定数を使うと、6 桁で一致する）。燃料のノードの定数が、
  反射体の隣では単一集合体と違う（高速群の吸収 −1.5%、拡散係数 +4%。反射体に面する辺の ADF は、高速群で 0.955 で、単一集合体では
  0.994。584c741b の examples/vera/p5 の `lattice/reflector-I-fuel.msgpack` と `lattice/31.msgpack`、2026-10-12）
- 3 × 3 の集合体と反射体の輪を MOC で解いた最小の入力では、core の k は +689 pcm、集合体出力の RMS は 1.0%（中心 +1.4%、
  角 −1.3%。同じ記録、1c115833、2026-10-12）で、5-2D とは逆に中心が高い。3 × 3 には反射体から離れた集合体がないので、大きな炉心
  の傾きは、この入力では見えない
- 反射体のない 2 × 2 のカラーセット（examples/colorset/verification.md の「測った値」、02a2cd43、2026-10-10）では、単一
  集合体の定数の集合体の平均の差は 0.54%。炉心の内側の集合体の定数と NEM の誤差は、この程度と見込む（15 × 15 の炉心では
  確かめていない）
- L 型の位置に置く I 型の定数の向き（#0029）で、隣の集合体の出力は最大 4.4% 変わる。全体の傾きの形は向きによらない

原因の候補（どれも確かめていない）:

- f\* の方法（単一集合体の燃料の定数と、反射体の定数の組み合わせ）では、燃料から見て反射体の反射が強くなり、炉心が
  平らになること
- 核データの版の違い（xlc は ENDF/B-VIII.0、KENO-VI は VII.0）。k と制御棒の価値の差にも入る。OpenMC（VIII.0）と比べれば
  分けられる

確かめようとして止まったこと:

- 5 × 5 の集合体と反射体の輪を、自己遮蔽ありの MOC で解く入力は、メモリが 82 GB を超えて止まった（3 × 3 では 37 GB。
  f392a65a の examples/vera/p5/p5_inputs.py の `medium`、2026-10-12）
- 同じ入力を自己遮蔽なしで解くと（f5f9fa3d の trials/p5/nss/）、角型の格子が止まった。2 辺が真空の角の点 8 で、均質な
  角の中性子束の大きさが熱群で負になった（`corner point 8: the homogeneous corner flux scale [2.078, -0.0563] is not positive`。
  #0065 と同じ種類）

関係する ADR: なし

## 完了の条件

5-2D の OpenMC の参照解（#0073）と集合体出力とピン出力を比べる段階（`compare_p5.py openmc`）を examples/vera/p5/dvc.yaml に
足し、傾きの大きさを確かめて、原因が f\* の方法かどうかを切り分ける。f\* の方法が原因なら、反射体の隣の燃料の定数の作り方
（反射体の格子の燃料のノードの定数を使うか、補正するか）を ADR で決める。
