# 履歴からの分岐で、分岐の状態ごとの Dancoff 係数を燃焼度の点をまたいで使う

## 問題

燃料のピンの Dancoff 係数は、入力が直前に解いたときと同じ間だけ持ち越す（ADR-0194）。履歴からの分岐（ADR-0187）の状態は燃焼度が
いちばん遅く変わるので、減速材やホウ素の分岐があると、続く状態の燃料でない物質が毎回違い、燃焼度の点ごとに同じ分岐の状態の係数を
解き直す（燃料の温度だけの分岐では持ち越せる）。見た入力ごとに結果を持てば（ADR-0194 の案 D）、分岐の状態の数だけ解けばよい。
効きは測っていない（分岐の状態 1 つの Dancoff 係数は 2A で約 2 秒）。

関係する ADR: なし

## 完了の条件

分岐の状態の数と順序の要件を確かめ、見た入力ごとに持つか、今のままにするかを決める。持つなら、テストで解く回数を示し、時間を測る。
