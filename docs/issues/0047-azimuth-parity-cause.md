# 方位角の (0, π/2) の角の数が奇数だと k の誤差が小さい原因

## 問題

VERA 2B と 1B を方位角の数と間隔を変えて解くと、(0, π/2) の角の数（方位角の数の半分）が奇数のとき、多くは近い数の偶数より
k の差が小さい（examples/vera/verification.md の「方位角の数と間隔（自己遮蔽あり）」、35d8e30）。2B では方位角 18 で −5 pcm、16 と 20 で
−94 と −69 pcm。ただし例外がある: 2B の方位角 22 と 26 は 18 や 30 ほど小さくなく、64 では奇偶の差が見えない。1B では
奇数の 15 のうち 11 だけで成り立ち、方位角 18、50、54、58 では成り立たない。正方形の格子（幅と高さが同じ）では、奇数の
ときは補正後もちょうど 45° の方位角が入る（ADR-0043 の補正で nx = ny）が、それがなぜ効くのかは確かめていない。
VERA の集合体の入力は、この規則を使って方位角 30 にした（ADR-0111）。

関係する ADR: ADR-0111

## 懸念

- 原因が分からないまま奇数を選ぶと、体系（燃料の配置、ギャップ、反射体）が変わったときに効くかが分からない。幅と高さの
  違う格子（ADR-0083）では、奇数でも真ん中の角は 45° にならない
- 単純な見積もりでは逆になる: 角度中性子束が 45° に尖りを持つなら、中点則の誤差は尖りが区間の境目にある偶数の方が小さい

## 確かめ方の案

- スイープの方位角ごとの寄与（k や燃料の吸収率への方位角ごとの tally）を、45° を含む細かい組（方位角 130 など、角の数が奇数）で
  見て、45° の近くの角度分布の形（尖り、跳び）を調べる
- 重みの付け方（補正後の角の中点で区切る）を変えたときに偶数の誤差が変わるかを見る
- 例外（2B の 22 と 26、1B の 18、50、54、58）が、間隔の1点の値やばらつきで説明できるかを、間隔を増やして確かめる

## 完了の条件

- 原因を説明して記録するか、説明できないなら、奇数を選ぶ根拠を検証の範囲（どの体系で確かめたか）に限って記録する

## 経緯

- 2026-10-10: ユーザーの依頼（2 の冪でない方位角の数の検討）で見つけた
- 2026-10-10: 2B で奇数の効果が出ていて、外れても隣の偶数の誤差で済む方位角 30 を集合体の入力に選んだ（ADR-0111）
