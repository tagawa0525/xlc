# 方位角の (0, π/2) の角の数が奇数だと k の誤差が小さい原因

## 問題

VERA 2B と 1B を方位角の数と間隔を変えて解くと、(0, π/2) の角の数（方位角の数の半分）が奇数のとき、近い数の偶数より k の
差が小さい（examples/vera/verification.md の「方位角の数の奇偶と間隔の平均」）。2B では方位角 18 で −5 pcm、16 と 20 で
−94 と −69 pcm。奇数のときは補正後もちょうど 45° の方位角が入るが、それがなぜ効くのかは確かめていない。

関係する ADR: なし

## 懸念

- 原因が分からないまま奇数を選ぶと、体系（燃料の配置、ギャップ、反射体）が変わったときに効くかが分からない
- 単純な見積もりでは逆になる: 角度中性子束が 45° に尖りを持つなら、中点則の誤差は尖りが区間の境目にある偶数の方が小さい

## 確かめ方の案

- スイープの方位角ごとの寄与（k や燃料の吸収率への方位角ごとの tally）を、方位角 128 の細かい組で見て、45° の近くの角度分布の
  形（尖り、跳び）を調べる
- 重みの付け方（補正後の角の中点で区切る）を変えたときに偶数の誤差が変わるかを見る
- 45° を含まない奇数の組（中点則でない求積）があれば比べる

## 完了の条件

- 原因を説明して記録するか、説明できないなら、奇数を選ぶ根拠を検証の範囲（どの体系で確かめたか）に限って記録する

## 経緯

- 2026-10-10: ユーザーの依頼（2 の冪でない方位角の数の検討）で見つけた
