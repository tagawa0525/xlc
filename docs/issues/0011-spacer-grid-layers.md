# 支持格子の層の少数群定数の作り方

## 問題

炉心計算では支持格子の高さを軸方向の層として持つ計画で、その層の定数の作り方を決めていない。先行事例
（CASMO-4/SIMULATE-3 の Palo Verde の手法）は、格子計算で支持格子を燃料の高さ全体に薄めて混ぜ、位置どおりの
支持格子は炉心計算の側で扱う。xlc は枠を入れた格子計算ができるので、層の定数を直接作れる。枠による燃料の
自己遮蔽の変化の大きさは測っていない。目安として、等価なセルに枠のリングを入れると 1B の k が +210 pcm 動いた
（枠による変化の OpenMC との差が −170 → +40 pcm。examples/vera/verification.md）。

関係する ADR: [ADR-0085](../adr/0085-branch-on-core-states.md)

## 完了の条件

M3 の計画（docs/plans/m3-core-hzp.md）の進め方の 5（状態の分岐。[ADR-0085](../adr/0085-branch-on-core-states.md)）と 6（炉心の軸方向の層）で、層の定数を枠を入れた
格子計算から作るか、普通の集合体の定数に補正を足すかを、先行事例と VERA 3〜5 の参照解（KENO は支持格子を
位置どおりに置く）で比べて決める。あわせて、枠による燃料の自己遮蔽の変化を
測る（枠のない格子の燃料の断面積を、枠のある格子に入れた場合と比べる）。
