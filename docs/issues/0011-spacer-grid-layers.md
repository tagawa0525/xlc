# 支持格子の層の少数群定数の作り方

## 問題

炉心計算では支持格子の高さを軸方向の層として持つ計画で、その層の定数の作り方を決めていない。先行事例
（CASMO-4/SIMULATE-3 の Palo Verde の手法）は、格子計算で支持格子を燃料の高さ全体に薄めて混ぜ、位置どおりの
支持格子は炉心計算の側で扱う。xlc は支持格子を入れた格子計算ができるので、層の定数を直接作れる。支持格子による燃料の
自己遮蔽の変化は、無限格子で約 200 pcm（1B）。

## 完了の条件

段階5で、層の定数を支持格子を入れた格子計算から作るか、普通の集合体の定数に補正を足すかを、先行事例と VERA 3〜5 の
参照解（KENO は支持格子を位置どおりに置く）で比べて決める。
