# 非反射の格子の拡散係数の、中性子流の重みの定義

## 問題

非反射の格子（反射体）の拡散係数を、inflow の輸送断面積 Σtr,g = Σt,g − Σ_g' Σs1(g'→g) φ1_g' / φ1_g で作る案がある。
MOC の φ1 は、領域ごとの符号つきのベクトルの成分（x と y の球面調和関数のモーメント）で、散乱の次数が 1 以上のときだけ
ある。成分どうしが打ち消す領域や、φ1_g が 0 に近い群では、比と、φ1 による均質化の重みが定まらない。反射体の隣では、
高速群の中性子流が燃料から外へ、熱群の中性子流が反射体から燃料へ向かい、群によって向きが変わる。

関係する ADR: [ADR-0098](../adr/0098-derive-diffusion-coefficients-from-b1-and-currents.md)、[ADR-0104](../adr/0104-weight-transport-cross-sections-by-currents.md)

## 完了の条件

スカラーの重みの定義（例: ノードの面の正味の中性子流の群のスペクトル、ノードの正味の中性子流の向きへの射影、STREAM のような
近似のバックリングでの 1D の P_N の計算）を文献と比べて決め、正味の中性子流が 0 に近いノードでの扱い（エラーにするか、
別の定義にするか）を含めて ADR にする。REF1-2D を、同じ多群定数の xlc の MOC と比べて確かめる。

## 経緯

- 2026-10-08: ステップ 5 の ADR のレビューで、φ1 の比と重みが定まらない場合があると指摘された
- 2026-10-09: 重みを、領域の中性子流をノードの正味の中性子流の向きへ射影した符号つきの値にした（ADR-0104。outflow の
  Σtr を中性子流で重みづけ）。反射体の I 型の格子で高速群の D は 1.448 cm になったが、熱群は打ち消しが大きく（0.21）、
  1ノードの均質な解が負のまま。熱群の扱いと、正味の中性子流がほぼ 0 のノードの判定はまだ
- 2026-10-09: 核分裂のないノード（反射体）の D は Koebke の等価理論の D にした（ADR-0104）。I 型の格子で反射体のノードの
  均質な解は両方の面で正になり、x の2つの面の不連続因子がそろった。燃料のノードは中性子流の重みのまま。正味の中性子流が
  ほぼ 0 のノードの判定は #0028
