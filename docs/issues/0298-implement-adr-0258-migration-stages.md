# ADR-0258 の移行の段（正規形の hook、-s の経路、付け直しのコマンド、形式の検査、パスの付け替え）を実装する

## 問題

ADR-0258 は決定だけを書いてマージした。決定と理由の「移行の順」の段は、どれも未着手である。段の中身、順、段ごとに直す
ADR とスキルは ADR-0258 の「移行の順」に、段ごとに通すことは「確認」にある（ここにコピーしない）。

- 段 1: 正規形を書き直す pre-commit の hook
- 段 2: `scripts/dvc-repro.py` の `-s` の経路（段 3 より先）
- 段 3: rebase の後の付け直しのコマンド
- 段 4: changed の扱いをスキルと計画に書く
- 段 5: 形式を変える修正の検査
- 段 6: パスだけを動かしたときに lock を書き換えるツール（examples の下の整理が使う）

関係する ADR: ADR-0258

## 完了の条件

段 1〜6 がそれぞれのブランチで main に入り、ADR-0258 の帰結の「実装は決定に追いついていない」の項が今の姿に直っている。

## 経緯

- 2026-11-19: ADR-0258 を accepted にしたときに、実装の残りとして起こした
