# ADR-0258 の移行の段（正規形の hook、-s の経路、付け直しのコマンド、形式の検査、パスの付け替え）を実装する

## 問題

ADR-0258（proposed）は決定だけを書いた。決定と理由の「移行の順」の段は、どれも未着手である。段 6 は examples の下の整理より前に要るので、最初に着手する。段の中身、順、段ごとに直す
ADR とスキルは ADR-0258 の「移行の順」に、段ごとに通すことは「確認」にある（ここにコピーしない）。

- 段 1: 正規形を書き直す pre-commit の hook
- 段 2: `scripts/dvc-repro.py` の `-s` の経路（段 3 より先）
- 段 3: rebase の後の付け直しのコマンド
- 段 4: changed の扱いをスキルと計画に書く
- 段 5: 形式を変える修正の検査。Python のツールが読む出力（ピン出力、比較のツールが読む履歴とテーブル）を検査に入れるか
  （Python の読み手に読むだけの入口を作るか）は決まっていない
- 段 6: パスだけを動かしたときに lock を書き換えるツール（examples の下の整理が使う）。試行（`trials/`）の出力を examples に
  移すときに再計算にしない形は決まっていない（候補は ADR-0258 の決定と理由の「パスだけを動かしたときの lock」）
