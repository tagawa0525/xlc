# ADR-0258 の移行の段（正規形の hook、-s の経路、付け直しのコマンド、形式の検査）と ADR-0260 のパスのツールを実装する

## 問題

ADR-0258 と ADR-0260 は決定だけを書いた。ADR-0258 の決定と理由の「移行の順」の段 1〜5 と、ADR-0260 の「移行」のツールは、どれも
未着手である。段の中身、段ごとに直す ADR とスキルは ADR-0258 の「移行の順」と ADR-0260 の「移行」に、通すことはそれぞれの
「確認」にある（ここにコピーしない）。着手の順に並べる。段の番号は ADR-0258 のものである。

- パスのツール（ADR-0260）: ファイルを動かしたときに、中身のハッシュで同じファイルかを判定して lock のパスを書き換えるツール。
  examples の下の整理（ADR-0259）より前に要るので、最初に着手する。ADR-0260 は proposed で、このツールのブランチで実装に合わせて直し、accepted にする。試行
  （`trials/`）の出力を examples に移すときに再計算にしない形は決まっておらず、この段で ADR-0259 と合わせて決める
- 段 1: 正規形を書き直す pre-commit の hook
- 段 2: `scripts/dvc-repro.py` の `-s` の経路（段 3 より先）
- 段 3: rebase の後の付け直しのコマンド
- 段 4: changed の扱いをスキルと計画に書く
- 段 5: 形式を変える修正の検査。最後に回す（検査が無くても、読めない出力はエラーで止まる。ADR-0258 の「形式を変える修正の
  検査」の位置づけの項）。Python のツールが読む出力（ピン出力、比較のツールが読む履歴とテーブル）を検査に入れるか
  （Python の読み手に読むだけの入口を作るか）は決まっていない

関係する ADR: ADR-0258、ADR-0260
