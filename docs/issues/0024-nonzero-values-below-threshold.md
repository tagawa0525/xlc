# 運動学のしきい値より下の 0 でない値の扱いを決める

## 問題

[ADR-0100](../adr/0100-move-tables-to-kinematic-thresholds.md) は、実験室系のしきい値 E_th より下から始まる表を E_th から始める。E_th より下に 0 でない値を持つ
表が、VERA、M1、M3 のライブラリの 61 ファイルで 21 反応ある。

- O-16 の MT103、MT600: 最初の点が E_th の 2.1 eV 下で 5e-11 b
- Fe-54 の MT606〜633 の 13 反応: 最初の点が E_th の 0.5 eV 以内で 2.6e-11 b 以下
- Ti-46 の MT52、MT55、Ti-47 の MT4、MT51、MT57、Ti-50 の MT52: 最初の点（0）の次の点が E_th の 5.3 eV 以内で 1.5e-7 b 以下

どれもしきい値の 2.6e-6 以内、その反応の最大値の 2e-6 以下で、しきい値の書き方の違い（|Q| と E_th、丸め）の範囲にある。
いまは、最初の点の値なら E_th に置き（O-16、Fe-54。NJOY と同じく 0 からの段差になる）、2点目以降なら捨てる（Ti）。
「E_th で 0 にして立ち上げる」を厳密に当てはめると、この 21 反応は値を変えるかエラーにする必要があり、エラーにすると
VERA のライブラリ（O-16、Fe-54）を作れない。

関係する ADR: [ADR-0100](../adr/0100-move-tables-to-kinematic-thresholds.md)

## 完了の条件

E_th より下の 0 でない値を、いまのまま（NJOY と同じ）にするか、E_th で 0 にするか、エラーにするかを決め、ADR にする。
