# 自己遮蔽のピンの組で、軸を入れ替える操作のブロックの像を比べていない

## 問題

`symmetry::cell_orbits`（自己遮蔽で移り合うピンを同じ組にする）は、軸を入れ替える操作（90° と 270° の回転、対角線と
反対角線の鏡映）で、セルの幅と高さは入れ替えて比べるが、セルの種類はそのまま比べる。均質な長方形を nx × ny に分けた
`Cell::Block { nx, ny }` の、軸を入れ替える操作による像は `Block { nx: ny, ny: nx }` なので、nx ≠ ny のブロックが像の位置にも
同じ `Block { nx, ny }` として置かれていると、小さな長方形の並びが移り合わないのに操作を認めうる。ブロックは物質がセルの
中で一様なときだけ組に入れる（リングごとの物質の確認）ので物質は同じだが、領域の形が違う。

MOC の 1/4 対称性（ADR-0113）は軸を入れ替えない操作だけを使い、像のブロックの種類も入れ替えて比べる
（`symmetry::images`）。ブランチ feat/quarter-symmetry で、この比べ方を `cell_orbits` と共通にしたところ、`cell_orbits` の
挙動まで変わった（2026-10-10 のコードレビュー）。そのブランチでは main と同じ挙動に戻し、ここに残した。

関係する ADR: なし

## 完了の条件

- 軸を入れ替える操作で、ブロックの nx と ny を入れ替えて像のセルの種類と比べるようにし、nx ≠ ny のブロックを置いた格子で
  誤って操作を認めないことをテストで示す

## 経緯

- 2026-10-10: feat/quarter-symmetry のコードレビューで、`cell_orbits` の挙動の変化として見つかった
