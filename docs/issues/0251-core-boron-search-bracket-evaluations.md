# core の燃焼の臨界ホウ素の探索の範囲の両端の評価

## 問題

core の燃焼の臨界ホウ素の探索は、状態の `search` の範囲をすべての探索に使い、探索ごとに範囲の両端の 2 回を解いて目標を挟むことを確かめてから
Illinois 法で進める（ADR-0191 の案 B1、ADR-0145）。前の点のホウ素の周りに範囲を動かす形（ADR-0191 の案 B2）と、前の点のホウ素を最初の評価点にする形
（案 B3）は、全炉心の燃焼の時間で探索の回数が効くと分かってから測って決めることになっていた（ADR-0191 の帰結）。

全炉心で場合 3 を出力のステップにした燃焼（examples/depletion/verification.md の「固有値計算の複数のスレッド（小さな炉心と全炉心）」の「全炉心（Problem 9 の形）」、
29563b884、Slurm 711 の timed、16 スレッド、2026-11-06）で、探索は 3 回で、どれも 5 回の評価（範囲は 1100〜1300 ppm。p5 の反射体と非燃料の層のテーブルのホウ素の軸が 1100〜1400 ppm なので狭めた。同じ記録の
「全炉心の燃焼の時間の内訳（Problem 9 の形）」の「ホウ素」の項。本番の広い範囲では両端の後の割線の回数が増えうる）（span `search` の中の span `constants` の数。
`examples/depletion/p9-timing/trial-0234/core-p9.log`）。span `search` の和は 30.6 s で全体 106.2 s の 28.9 %。ホウ素を探す 3 回の解の固有値計算は 12、11、11 回で、
探索の後は Xe とホウ素の同時の反復（ADR-0219 の「## 変更」の 2026-11-06）が解き直す。

縮め方の候補（どれも測っていない）: 案 B2、案 B3、#0156 の 2026-11-06 の同時の反復の項の「探索の範囲の両端の評価…を、前の点のホウ素と効きから始める形で減らす
（ADR-0145 の範囲の両端で挟むことを確かめる形を変える。測っていない）」。
ADR-0191 は、案 B2 の幅の外に出たときの規則が ADR-0145 の採らなかった黙った既定にあたること、案 B3 は囲い込みを保つのに片側をもう 1 回解くので回数が
案 B1 と変わらない見込み（確かめていない）を挙げている。

関係する ADR: ADR-0191

## 完了の条件

全炉心の燃焼（Problem 9 の形）で、範囲の両端の評価を減らす形を、固有値計算の回数と時間、臨界ホウ素の差で今の形と比べて決める。

  減らす）と、#0202 の速さの項のうち探索を入力の範囲から始め直すことの残り（最初の解き直しの探索の範囲の両端）を移した。探索の回数と評価の数は Slurm 711 のログから数えた
