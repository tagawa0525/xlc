# UFG のエネルギーの格子を自動で決める

## 問題

自己遮蔽の UFG の減速計算（ADR-0068）のエネルギーの格子は、セルの全核種のポイントワイズの断面積の格子の和に、散乱の窓に最低 16 点が
入るよう点を足したもの。点の数は核種の数で決まり、どこに点が要るかの精度の基準で決めていない。ユーザーは、群構造
（格子）を自動的に決める方法があれば取り入れたいとした（2026-10-10）。

試作（コミットしていない。VERA 1B のピンセル、342,106 点）で、リングごとの巨視的な断面積（核種ごとの全、散乱、核分裂）
を線形補間で許容差以内に再現できる点を間引くと、許容差 1e-4 で 95,222 点、自己遮蔽 4.9 秒が 2.1 秒、k の差 +0.5 pcm、
吸収断面積の差 1.2e-5 だった。ただし許容差 1e-5（153,384 点）でも吸収断面積が 1.3e-5 動き、いまの格子そのものが点の
配置について収束していない（#0002）。精度の基準になる収束した格子が先に要る。

関係する ADR: なし

## 方針の案

- 断面積の表現から決める: リングごとの巨視的な断面積を許容差で線形に表せる点だけを残す（上の試作。NJOY の RECONR の
  許容差と同じ考え方）。点の数は核種の数でなく、効く共鳴の数で決まる（#0045 にも効く）
- 解の誤差から決める: 格子で解いた中性子束（あるいは使う量である群の実効断面積）の誤差を、区間を二分した格子の解と
  比べて見積もり（step doubling）、許容差を超える区間だけ細かくし、下回る区間は粗くする。使う量を目標にした
  （goal-oriented）細分も候補
- 共鳴のパラメータから決める: 共鳴ごとに、その巨視的な寄与がリングの全断面積に対して閾値を超えるものだけ、幅 Γ に
  比例した間隔で点を置く

SCALE の CENTRM がエネルギーの格子をどう決めているかなど、先行事例は確かめていない。決めるときに調べて出典を書く。

## 完了の条件

収束した格子（#0002）を基準とし、上の案の点の数、時間、少数群定数と k の差を VERA 1B と 2B で測って、方法を ADR で
決める。
