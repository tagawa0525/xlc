# 燃焼の輸送ごとに組成によらない自己遮蔽の前処理をやり直す

## 問題

格子計算の燃焼（ADR-0173）は輸送のたびに `shield_fuel_with` を呼び直す。そのうち、燃焼で変わらないものも毎回求め直している:

- Dancoff 係数（燃料を黒体とし、燃焼させない物質の全断面積から求める。燃料の組成によらない）
- 燃焼させない物質（被覆管、減速材、構造材）の無限希釈の混合と、構造材の塊の遮蔽
- `region_rates` が MOC の領域ごと・核種ごと・反応ごとに引くライブラリの経路の断面積（`Library::lookup` の名前の探索と、
  経路の無限希釈の値の複製。熱中性子散乱の核種を内挿の温度で引くと温度のデータ全体を作り直す）

- 等価原理の反復の背景断面積を、核種ごとに全核種の和から求め直す（核種の数の 2 乗 × 群。燃焼では輸送できる核種がすべて入る）
- 対称性で移り合うピンに、代表のピンの結果（`PinShielding` の核種の群定数と散乱行列など）を複製する（リングごとの実効断面積だけは
  共有する）。燃焼の反応率は、MOC の領域ごとにピンの一覧を線形に探す
- 少数群定数の群境界は、最初の輸送のあとに確かめる（入力の段で、ライブラリの群境界との一致を確かめていない）

自己遮蔽は時間の 72〜98%（examples/depletion/verification.md の「格子計算の燃焼」）。このうちこれらの前処理は 3% ほどだった
（経緯の 2026-10-22）。反応率と規格化は 2A の 1 ステップで 1%。

関係する ADR: ADR-0173、ADR-0194

## 完了の条件

自己遮蔽の区間（Dancoff、等価原理、UFG、塊）の時間の内訳を集合体の燃焼で測り、組成によらない部分を燃焼の初めに 1 度だけ求めるか、
効かないことを確かめて閉じる。

## 測定（2026-10-22）

自己遮蔽の時間の内訳を、VERA 2A の燃焼 1 ステップで測った（#0045 の核種ごとの点の数と、核種ごとの自己遮蔽の必要性の目安は #0045 の「測定（2026-10-22）」）。コミットは cd1e64506（計測の span は 74acf3755 から。1 スレッドの測定は 74acf3755、16 スレッドは cd1e64506。分岐点は main の b5066b8f2）、日付は 2026-10-22。入力は examples/depletion/p2/lattice-2A.toml の `burnup` を `[0.1]` にしたもの（輸送 3 回、輸送する核種 89、燃焼の領域 39）で、ログは 74acf3755〜cd1e64506 では既定の info でピンごとの区間も出た（その後ピンごとの区間は debug にした。ピンごとの時間は `RUST_LOG=info,xlc_lattice::shielding=debug,xlc_lattice::ufg=debug` で出る）。区間の時間は、ログの `close time.busy`（その区間に入っていたスレッドの時間の合計）。1 スレッド（`RAYON_NUM_THREADS=1`。排他でない測定なので割合だけを使う）と、排他の Slurm の 16 スレッド（ジョブ 428）で測った

16 スレッドの `pin` の `time.busy` の合計は輸送ごとに 786、798、899 秒で、16 で割ると 49、50、56 秒。経過時間の 63〜78 秒との
差は、代表のピン 39 本を 16 スレッドに配る粒度（39 本は 3 周分で、16 × 3 = 48 に対し 81%）の可能性がある（確かめていない）。
1 スレッドの全体 3,311 秒 / 16 = 207 秒で、`seconds.shielding`（204 秒）とほぼ一致した

- 組成によらない前処理は、Dancoff 係数 2.7%、混合 0.0%、無限希釈の物質 0.0%、複製 0.1% で、合わせて 2.8%。塊を
  燃焼の初めに 1 度だけ求めても足して 5.6%（塊が燃料の組成を入力に取らないことは確かめていない）。ライブラリの引き直し
  （`region_rates` の `Library::lookup`）を含む反応率と規格化は 1 スレッドで 3 回の輸送に 2.3 秒（`seconds.rates`）で、自己遮蔽の
  0.07%。この issue の案の前処理を全部再利用しても、時間は最大でも 5.6% 減る（1.06 倍）
- 時間のほとんどは、代表のピンの UFG の減速計算（燃料のピン 117 回分の `ufg` の時間 3,066 秒）。段ごとの割合（`UFG slowing down`
  の行の時間）は、1 スレッドで 格子 0.2%、飛程の表の作成 10.2%、ポイントワイズの断面積の評価 7.8%、衝突確率 7.7%、減速計算
  （格子点ごとの核種 × リングのスイープ）74.1%（16 スレッドは 0.3%、10.4%、8.1%、12.3%、68.9%。ほかのピンの仕事を盗む分が衝突確率に
  入る）。核種のデータの引き（`lookup`）は 0.0%。ピン 1 本の UFG は 1 スレッドで 26.6 秒（点の数 1,266,012、核種 90）、
  新しい燃料（5 核種）は 3.35 秒（344,958 点、核種 31）で、7.9 倍。点の数 × 核種の数の比は 10.6 倍
- 結論の候補: 自己遮蔽の時間は前処理でなく UFG の減速計算の点の数 × 核種の数で決まる。前処理の再利用（この issue）は
  最大で 1.06 倍にしかならないので、効くのは #0045（点の数と核種の数を減らす）と #0046（点の間引き）。この issue を閉じるかは、
  ユーザーの判断に残す
- 計測のコードは自己遮蔽の span と、UFG の `UFG slowing down` の行（点の数、段ごとの時間）、自己遮蔽の `fuel pins and their
  symmetry representatives` の行（解いたピンの点の数の最小、最大、合計）。ログの `RUST_LOG=info,xlc_lattice::shielding=debug,xlc_lattice::ufg=debug` で
  核種ごとの点の数も出る。結果は変更前（b5066b8f2 のビルド）とビットで同じ: 履歴 `lattice-2A.msgpack` が実行時間 `seconds` を除いて
  同じ（1 スレッド、16 スレッドの両方）
