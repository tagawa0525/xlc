# core のノードの出力を核分裂のエネルギーで重みづける

## 問題

ADR-0190 の core の燃焼は、ノードの出力の割合をノードの核分裂率 Σf φ V の割合とする。格子計算の燃焼（ADR-0173）は、出力を核種ごとの
核分裂の Q 値（MF3 MT18 の QI）で重みをつけた Σ N σf φ Q で規格化し、燃焼度の軸（ADR-0187）はその定義の燃焼度である。Q は核種で違い
（examples/depletion/chain.msgpack、main 437a5e51: U-235 193.41 MeV、U-238 197.79 MeV、Pu-239 198.58 MeV、Pu-241 201.98 MeV）、
Pu の多い燃焼の進んだノードと新しい燃料のノードが並ぶ炉心では、核分裂率の割合とエネルギーの割合が数 % まで違いうる（見積もり。
測っていない）。集合体 1 体の一様な出力では、割合はどちらでも 1 なので差が出ない。

テーブルは核分裂のエネルギーの断面積（κΣf）を持たない。

関係する ADR: ADR-0190

## 完了の条件

lattice がテーブルの状態ごとに κΣf（Q で重みをつけた核分裂の断面積）を書き、core がノードの出力の割合をそれで求める。差の大きさを
小さな炉心（燃焼度の違う集合体を並べたもの）で測り、検証の記録に書く。Problem 9 の燃焼（docs/plans/m4-depletion.md の「進め方」9）の前に行う。

## 経緯

- 2026-10-23: ADR-0190 の最初の縦切りで、テーブルに κΣf がないため核分裂率の割合で進め、この issue に残した
