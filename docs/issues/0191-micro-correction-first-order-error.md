# ミクロ燃焼の線形の補正の 1 次の誤差（効きの約 13%）の原因を分け、補正の形を見直す

## 問題

ADR-0216 の線形の補正 Σᵢ σᵢ (Nᵢ − N̄ᵢ⁰) は、2A の隣り合う燃焼度の点の組で、追う 31 核種の組成の差の輸送の効きの 88.41〜113.43% を再現し、
誤差は −95.20〜+171.91 pcm（examples/depletion/verification.md の「ミクロ燃焼の線形の補正（2A）」。比較は 6d8179c1、2026-10-29）。
5 MWd/kg より後の誤差は、効きに対する割合が燃焼度の近い組でほぼ同じ（15→16 MWd/kg と 16→18 MWd/kg でどちらも約 13%）で、数密度の差の
1 乗に比例する。σᵢ を固定した線形化の 2 次の項ではなく、σᵢ が数密度の差の効きを表していない 1 次の差とみられる。

候補（どれも確かめていない）:

- 共鳴の自己遮蔽の数密度への依存: Σ = N σ(N) の dΣ/dN = σ + N dσ/dN の第 2 項。U-238、Pu-240 などの共鳴の核種で、数密度が増えると実効断面積が
  下がる。誤差の向き（Pu が増える組で、減る向きの効きを大きく見積もる）と合う
- 数密度の差の空間の分布（燃料のリングとピン）が、σᵢ の重みにした数密度そのものの分布と違うこと

炉心のノードの履歴の差（「履歴の効き（2A）」の追う核種の分は、60 MWd/kg の密度の履歴で履歴の効き +4903.8 pcm の 97.1〜103.5%）に同じ
割合が当てはまれば、ADR-0215 の残り R に数百 pcm が入り、R を瞬時の状態に依らないとした ADR-0215 の案 C3 の前提が変わりうる（当てはまるかは
確かめていない）。

関係する ADR: ADR-0216

## 完了の条件

- 候補を分けて測る（例: 1 核種だけを置き換えた組成、自己遮蔽を前の点のまま固定した計算、リングごとの数密度の差を一様にした組成）
- 原因に応じて、補正の形（自己遮蔽の数密度への依存の項を足す、σ の重みを変える、R に任せる）を ADR-0216 か新しい ADR で決める
- 炉心の履歴の差の大きさ（履歴の分岐の組成の差）で同じ誤差を測り、ADR-0215 の R の扱い（#0190）に反映する
