# ミクロ燃焼の線形の補正の 1 次の誤差（効きの約 13%）の原因を分け、補正の形を見直す

## 問題

ADR-0216 の線形の補正 Σᵢ σᵢ (Nᵢ − N̄ᵢ⁰) は、2A の隣り合う燃焼度の点の組で、追う 31 核種の組成の差の輸送の効きの 88.41〜113.43% を再現し、
誤差（線形の効き − 輸送の効き。反応度）は −171.91〜+95.20 pcm（examples/depletion/verification.md の「ミクロ燃焼の線形の補正（2A）」。
比較は 78c7819a、2026-10-29）。5 MWd/kg より後の組の誤差は負（線形の補正が反応度の減りを大きく見積もる）で、効きに対する割合が燃焼度の
近い組でほぼ同じ（15→16 MWd/kg と 16→18 MWd/kg でどちらも約 13%）なので、数密度の差の 1 乗に比例する。σᵢ を固定した線形化の 2 次の
項ではなく、σᵢ が数密度の差の効きを表していない 1 次の差とみられる。5 MWd/kg より前の組の誤差は正（0→0.1 MWd/kg で +95.20 pcm）。

候補（どれも確かめていない）:

- 組成の変化による中性子束の重みの変化: 少数群の断面積 Σ_G = Σ_g Σ_g φ_g / Σ_g φ_g の φ_g（少数群の中のスペクトルと、領域の間の分布）は
  ΔN の 1 次で変わり、追わない核種と減速材を含むすべての核種の少数群の σ を変える。重みを固定した線形の補正はこれを表さない
- 共鳴の自己遮蔽の数密度への依存: Σ = N σ(N) の dΣ/dN = σ + N dσ/dN の第 2 項。U-238、Pu-240 などの共鳴の核種で、数密度が増えると実効断面積が
  下がる。ほかの核種の数密度による遮蔽の変化（dσᵢ/dNⱼ。Pu による U-238 の遮蔽など）も同じ 1 次の項。早い組と遅い組で誤差の向きが
  変わることをこの候補で説明できるかは、核種ごとに分けないと分からない
- 数密度の差の空間の分布（燃料のリングとピン）が、σᵢ の重みにした数密度そのものの分布と違うこと

既に挙がっている群の重みの issue（#0148 の高速群、#0151 の熱群）は、ライブラリの細かい群の中の重みが OpenMC と違うことで、ここの
少数群の重みの組成への依存とは別。

誤差の輸送の効きに対する割合（誤差 / 輸送の効き。効きはどの組も負なので、誤差が負の組で正）は燃焼度で変わる（5 MWd/kg より後は 0.61%（5→6 MWd/kg）から 13.43%（16→18 MWd/kg）まで上がり、56→60 MWd/kg で
3.74%。5 MWd/kg より前は逆の符号で、絶対値の最大は −11.59%（1→1.5 MWd/kg）。linearization.json から）。炉心のノードの履歴の差にこの割合が当てはまるかは
確かめていない（履歴の差は燃焼のステップの差より大きく、2 次の項は測った割合に入っていない）。測った最大の割合のまま当てはめると、
「履歴の効き（2A）」の 60 MWd/kg の追う核種の分（そこでの追う核種は 26 核種で、ADR-0216 の 31 核種のうち Cm-242、Cm-244、Eu-153、I-135、
Pm-148m は追わない核種の側に入っている）（履歴の効きと逆向きのうち大きい方。密度の履歴は逆向きの
+5256.3 pcm、制御棒の履歴は +28123.8 pcm。制御棒の Δρ は k が小さいので 1/(k k′) で大きい）に 13.43% を掛けて、ADR-0215 の残り R に
密度の履歴で約 710 pcm、制御棒の履歴で約 3,800 pcm が入りうる（56→60 MWd/kg の 3.74% なら約 200 pcm と約 1,050 pcm）。R を瞬時の状態に依らないとした ADR-0215 の案 C3 の
前提が変わりうる。

関係する ADR: ADR-0216

## 完了の条件

- 候補を分けて測る（例: 少数群の重みを固定した細かい群の補正との比較、1 核種だけを置き換えた組成、自己遮蔽を前の点のまま固定した計算、
  リングごとの数密度の差を一様にした組成）
- 原因に応じて、補正の形（スペクトルの変化の項を足す、自己遮蔽の数密度への依存の項を足す、σ の重みを変える、R に任せる）を ADR-0216 か新しい ADR で決める
- 炉心の履歴の差の大きさ（履歴の分岐の組成の差）で同じ誤差を測り、ADR-0215 の R の扱い（#0190）に反映する
