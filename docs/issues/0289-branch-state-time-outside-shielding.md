# 分岐のテーブルの状態ごとの、自己遮蔽の外の時間（微分の輸送計算と出力）

## 問題

本番の形の 2A の分岐のテーブルの 1 燃焼点（#0285 の「本番の形の 1 燃焼点のテーブルの時間（2A の 60 MWd/kg）」。114 状態、Slurm 874）では、
状態ごとに自己遮蔽の外で、状態の MOC（約 3.3 秒）のほかに、Pu-240 の数密度の微分（ADR-0221、ADR-0249）の MOC が約 3.1 秒、どちらの
MOC にも自己遮蔽にも入らない区間が約 2.2 秒かかる。27 燃焼点のテーブル（#0278）では、状態の数 × 27 で効く。

測定は、同じ入力を 4 状態（ホウ素 0 と 650 ppm、減速材 580 と 600 K、燃料 900 K。自己遮蔽を解く 2 状態と再利用する 2 状態）に縮めた
examples/depletion/issue-0289/small.toml（パスだけを直して trials/ から移した）で、どれも区分 timed の排他のジョブ（32 スレッド）、分岐点は
main の 12281ea00、2026-11-17。ログは同じ場所の `.log`（`.dvc` で追跡）。区間は `RUST_LOG=info,lattice=debug` の debug の区間
（`output:` の下）の `time.busy`。

関係する ADR: なし

### 自己遮蔽の外の約 2.2 秒の内訳

xlc b4c6e032f（区間を足しただけで、結果は main と同じ）、Slurm 922、small.log。1 状態の秒（4 状態の範囲）:

| 区間                                                    |         秒 | 扱い                         |
| ------------------------------------------------------- | ---------: | ---------------------------- |
| 状態の少数群定数（`fewgroup`。B1 を含む）               | 0.28〜0.30 | 直していない（下の「残り」） |
| κΣf（`kappa_fission`）                                  |       0.04 |                              |
| 状態の微視的断面積 31 核種（`micro`）                   | 0.18〜0.19 | 直した                       |
| 状態の組成で作り直す確かめ（ADR-0249 の `check_remix`） | 0.54〜0.58 | 直した（残りは下）           |
| 摂動の組成で燃焼の領域の物質を作り直す（`remix`）       | 0.56〜0.59 | 直した（残りは下）           |
| 摂動の少数群定数（`derivative_fewgroup`。B1 を含む）    | 0.28〜0.29 | 直していない                 |
| 摂動の微視的断面積（`derivative_micro`）                | 0.18〜0.19 | 直した                       |
| 動特性のデータ（`kinetics`）                            |       0.02 |                              |
| MOC の 2 回の用意（反復の前）とチェックポイント         |     約 0.1 |                              |

和は約 2.2 秒で、Slurm 874 の残りの区間（2.15〜2.22 秒）と合う。燃焼点ごとの公称の状態だけは、冷却計算の断面積（ADR-0238）が
約 2.0 秒を足す（1 燃焼点に 1 回）。

直したもの（xlc 40d1ad833）: 作り直しの物質（燃焼の領域の物質ごと）と微視的断面積（核種ごと）を並列に作る。物質と核種の中の足す順は変えず、
テーブルの md5 は直す前と同じ（7a8a8028…、Slurm 923 で同じジョブの中で直す前の b4c6e032f と続けて流した。small-old.log、small-new.log）。
同じジョブの中で、`micro` と `derivative_micro` は 0.18〜0.19 → 0.02 秒、`check_remix` は 0.51〜0.65 → 0.21〜0.22 秒、`remix` は
0.52〜0.65 → 0.22〜0.23 秒、公称でない 3 状態の出力の区間の全体は 5.35〜5.71 → 4.33〜4.48 秒（1 状態 1.0〜1.2 秒減）。本番の 114 状態
では 1 燃焼点で約 115〜135 秒（Slurm 874 の 2,349 秒の約 5%）、27 燃焼点で約 0.9〜1.0 時間の見込み（本番の形では測っていない）。

残り（直していない、または原因を確かめていない）:

- `check_remix` と `remix` の並列にした後の 0.21〜0.23 秒ずつ: 物質の複製と比較を減らしても変わらなかった（「検討して捨てた形」）ので、
  残りの候補は、`remix_varied` の並列の前の 1 スレッドの部分（領域ごとの、物質の持ち主と共有の確認のループ）と、物質ごとの群定数の作り方の
  中（核種ごとの `shielded_nuclide_with` の散乱行列の割り当てなど）で、確かめていない。同じ前の部分の SPH 因子（`physical_flux`）は、同じ
  ものを求める `micro` の全体が 0.02 秒なので、それより短い。並列で 2.3〜2.9 倍にしか速くならない理由も確かめていない
- 燃焼のステップの作り直し（`depletion::remix_depleted`。ADR-0197）は、同じ形の物質ごとの作り直しを 1 スレッドで行う。分岐のテーブルの
  時間に入らないので、この issue では直していない（燃焼の時間は測っていない）
- `micro` の `region_members`（自己遮蔽の配列を共有する領域のまとめ）は核種ごとに作り直す。まとめ方は核種によらないが、並列にした後の
  `micro` は 0.02 秒で、直していない
- `check_remix` は ADR-0249 の決定で状態ごとに 1 度行う確認で、省くか自己遮蔽を解いた状態だけにするには ADR-0249 を直す決定が要る
  （効きは上の 0.21〜0.22 秒 × 状態の数）
- 少数群定数の 0.28〜0.30 秒 × 2 は、領域 × 細かい群 × 散乱行列の行の和（`fewgroup::constants`）と B1 で、内訳は測っていない。領域を並列に
  足すと足す順が変わり、結果が丸めの桁で変わる

### 微分の輸送計算の 13 反復

微分の MOC は状態の収束した解（`Start`）から始める（main.rs の `solve_direct` が `solve_symmetric_from` に状態の `converged` を渡す）。CMFD の加速
も収束の判定（k 1e-7、中性子束 1e-6、`moc::Options` の既定と `Remaining` の見積もり）も、状態の MOC と同じ。1 反復は 0.24〜0.25 秒で、状態の
MOC と同じ。

Slurm 922 の small.log の `iteration=` の行（4 状態とも 13 反復で同じ形）。自己遮蔽を解く 2 番目の状態の、反復ごとの中性子束の最大の相対変化は
0.150、2.5e-2、2.9e-3、8.5e-4、1.7e-4、5.3e-5、1.3e-5、4.1e-6、2.7e-6、1.0e-6、5.8e-7、3.4e-7、1.9e-7、k の変化は 1 回目に −6.4e-3、2 回目から
1e-5 以下。最大の変化の場所（`xlc_lattice::moc=trace` の `largest flux change`。Slurm 924 の、small.toml の出力の名前だけを変えた入力。下の「検討して捨てた形」の版で、テーブルの md5 は同じ。ログは 45 MB で残していない）:

- 1 回目は燃料の領域の群 36（0 始まりの WIMS 69 群の番号。Pu-240 の 1.06 eV の共鳴の群と見られるが、群の境界は確かめていない）で、
  摂動（数密度の 1.1 倍。ADR-0221 の `perturbation = 0.1`）による共鳴の群の中性子束のくぼみの変化
- 2〜7 回目は群 36〜46、8〜13 回目はおもに群 68（最も低い群）。状態の MOC の終わりの反復も群 68 で、上の列の 8 回目からの縮小率は 0.39〜0.66
- 判定は、中性子束は 12 回目に入るが、k の変化が 11 回目（−7.6e-9）より 12 回目（+4.8e-8）で大きく、縮小率の見積もりが無限になって、13 回目で止まる

見立て: 13 反復は、摂動が 1 回目に起こす最大 15% の変化（共鳴の群）を、熱群の遅いモード（縮小率 0.4〜0.6 の、状態の MOC と同じもの）の
減り方で判定まで下げる回数。初期値は既に状態の解で、加速も効いているので、判定と摂動の大きさを変えずに縮めるには、初期値を摂動の解に
近づけるか、遅いモードの縮小率を変える要がある。どれも直していない（下の候補は、どれも結果が丸めより大きく変わり、決定が要る）:

- 摂動の判定を緩める: 中性子束 1e-5、k 1e-6 なら、変化の列から 8〜9 回目で止まる見込みで、4〜5 反復（約 1.0〜1.2 秒 / 状態）減る。微分は
  2 つの解の差を 0.1 N で割るので、解の相対誤差は、σ に対する微分の誤差では約 10 倍になる。判定の既定は ADR で決める。差を測るには、判定を入力で
  選べる形が要る（今は `Options::default()` で、入力にない）
- 摂動の初期値を、前の状態の摂動の解の差（前の状態の摂動の解 − 前の状態の解）を今の状態の解に足した外挿にする: 1 回目の変化が前の状態との
  差の分に縮めば 2〜4 反復（0.5〜1.0 秒 / 状態）減る見込み（確かめていない）。チェックポイントから続けた実行が同じ結果になるには、前の
  状態の摂動の解もチェックポイントに要る（ADR-0196、ADR-0195 の決め直し）
- 摂動を小さくする（ε = 0.1 → 0.01 なら 1 回目の変化が約 1/10 で 2〜3 反復減る見込み）: 差分の誤差と判定の誤差のバランスが変わる。ε は
  ADR-0221 で決めた（ε = 0.1 と 0.05 の差を測ってある）
- 遅いモードの縮小率: 状態の MOC と共通で、熱群の上方散乱と CMFD の粗メッシュ（ピンセル）の問題。粗メッシュの反復の回数は #0169、
  判定の見積もりが誤差を小さく見る問題は #0160 にある。微分は 2 つの解の差なので、#0160 のずれ（判定の 5〜6 倍）は微分では約 10 倍で効く
- 一般化摂動論（#0279、ADR-0247）は、核種ごとの摂動の輸送を使わない別の方式で、この候補と別に進む

## 検討して捨てた形

- 作り直しの物質の一覧を、すべての物質を複製してから燃焼の領域の物質を差し替える形でなく、残す物質だけを複製する形にし、`check_remix` の
  物質の比較を並列にした: Slurm 924 の同じジョブの中で、`check_remix` 0.21〜0.23 秒、`remix` 0.22〜0.23 秒で、並列にしただけの版（Slurm
  923 の 0.21〜0.22 と 0.22〜0.23 秒）と変わらなかった（テーブルの md5 は同じ）。複製と比較は残りの時間の原因でなかった
