# 集合体を径方向に分割するノード（2×2 など）

## 問題

炉心の装荷図（ADR-0105）は、径方向のノードを集合体1体に1つとしている。ADF は1ノードの問題で定義しているので
（ADR-0103）、集合体を 2×2 などに分けると、集合体の中の面の ADF と、外周の面の ADF の意味が1ノードのときと
変わる。PARCS などは集合体を 2×2 に分けることが多い（記憶による）。燃焼（M4）では、集合体の中の燃焼度の傾きを
ノードごとに持つには分割が要る。

関係する ADR: なし

## 完了の条件

分割したノードの ADF の定義（1ノードの等価性を分割したノードに広げる方法）を決めて ADR にし、装荷図の入力に
分割数を加える。1ノードとの差を VERA の Problem 4 か 5 で測る。

## 経緯

- 2026-10-09: 装荷図の形式（ADR-0105）を決めるときに、ノードを集合体1体に1つとして後に回した
