# セルの角をちょうど通るトラックが、丸めの程度の区間で隣のセルを経由したと数えられる

## 問題

セルの角をちょうど通るトラックは、角のまわりのどれかのセルに、丸めの程度（1e-16 cm 程度）の区間を残す。粗メッシュの面の
tally（面の中性子束と正味の流れ）は、その区間のセルを経由して隣へ移ったと数えるので、角を通る移動が、丸めで選ばれた片側の
面だけを通ったことになる。対称な格子を全体で解いても、鏡像の位置にある面の値が揃わない（1/4 対称の実装の試験の格子で、
ある面が 1.06、その鏡像の面が 0.50）。1/4 対称（ブランチ feat/quarter-symmetry）で全体の解と比べる妨げになった。

関係する ADR: なし

## 完了の条件

- 角をちょうど通る直線が、隣のセルに丸めの程度の区間を残さず、対称な格子の面の量が対称になる

## 経緯

- 2026-10-10: ブランチ feat/quarter-symmetry の実装中に見つけた
- 2026-10-10: 原因は、区間を作るとき（`Lattice::segments` とブロックのセル）に、縦と横の線を横切る t が丸めで少し
  ずれ、その間に極小の区間ができることだった。t の計算の丸め誤差の上限を求め、差がその和以下の交点を同じ角とみて
  まとめた（693e368）。区間を使う側（スイープ、面の長さの推定、トラックの端のセル）は変えていない。VERA の出力は変わらない:
  lattice-9x9-vacuum.toml（方位角 32・間隔 0.05 cm、ADR-0111）と assembly-2B.toml（方位角 30・間隔 0.03 cm、ADR-0111。
  自己遮蔽なし）の少数群定数・ADF とピンの核分裂率のファイルは、修正の前（368e8d1）と後（65698f3）でバイト単位で同じ。
  （どちらのトラックもセルの角をちょうど通らないとみる。確かめてはいない）
