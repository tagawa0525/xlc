# 自己遮蔽の速い方式を新しい機能として入れる

## 問題

本番の形の 2A の分岐のテーブル（#0278）は約 21〜22.5 時間の見込みで、そのうち自己遮蔽を解く状態が約 14.85〜16.5 時間を占める
（#0180 の「自己遮蔽を省いたときの誤差」の最後の段落。MOC と出力を含む）。自己遮蔽を解く回数は燃焼点
27 × 減速材と燃料の温度の組 49 = 1,323 回で、状態と燃焼点の数に比例して増える。2A の 60 MWd/kg の 1 状態だけの入力では、状態の
自己遮蔽は 57.8 秒（Slurm 815、xlc 0d839a956。examples/depletion/issue-0180/branch/2A-60-zeroing-after-815.log。同じログの 48.2 秒は
微分の摂動の自己遮蔽）。同じ方式のまま省く試みは、燃焼点の間引き（8 点で最大 22.8 pcm）と状態の軸（減速材を公称にすると、密度
−4.2% と +3.6% の状態で −118.4〜+89.7 pcm。ADR-0201 の案 M）で、誤差の基準を作れなかった（#0180）。

自己遮蔽は、今の UFG を詰めるより、手法の違う速い方式を新しい機能として入れ、今の UFG を参照解として扱うほうがよいのではないか、と
ユーザーが提案した（ユーザー 2026-11-13）。CLAUDE.md の「方針」の「自己遮蔽は UFG のまま、物理的に正しい改善で速くし」（ユーザー
2026-10-12）を見直す話で、CLAUDE.md は方式が決まるまで変えない。候補は、特定の燃料の種類（典型は標準のウラン燃料の未燃焼）だけで
精度のよい設定にせず、燃料の種類（ウラン、Gd、MOX、可燃性毒物、制御棒）、燃焼度、温度の分布、リングごとの自己遮蔽（リム効果）、
共鳴の重なりを軸に評価する（ユーザー 2026-11-13）。

推奨と検討した案は ADR-0250（proposed）。この issue は、既にある記録の一覧、文献の比較、PSM との照合、段階の計画を持つ。

目標（ADR-0032 の ±100 pcm の全体）の中で自己遮蔽の近似に使える分より大きい。同じ系統の中で作りを PSM に寄せる案（自由ガスを
U-238 の補正に替える、固定の格子、孤立したペレットの CP の表と影の補正、質量で核種をまとめる）は、それぞれ近似で、xlc の UFG からの
差を測っていない。項目ごとに差と時間を小さい入力で測る段を、段階の計画の別の筋に置いた（ADR-0250 の方式とは別。行うかはユーザーが
決める）。

## 完了の条件

ADR-0250 の方式（または段 1 の測定で代わりに選んだ方式）を入力で選べる機能として作り、段 1〜3 の測定を記録して、本番のテーブルの
既定にするかをユーザーが決める。

### 段階の計画

1. 状態の変化の誤差を最小の入力で測る（決めるための測定）。ADR-0250 の比の計算（等価原理。ADR-0074 の計算を UFG の範囲の群にも
   当てる）を入力で選べる形で作り（ADR-0201 の `[branches] shielding` の新しい値。既定は変えない）、`"every-state"` と比べる。基準の状態の取り方は
   ADR-0250 の (F1)（燃焼点と燃料の温度の点ごと）と (F2)（燃焼点ごとに公称の 1 つ）の両方で測る。入力は、1 燃焼点の分岐（#0180 の
   reuse と fuels の入力の形）で、燃料は 2A（3.1% のウラン）、2O と 2P（Gd）、2F（Pyrex）、2M（IFBA）、2N（WABA）、2G（AIC を入れた
   格子）、MOX のピンセル、燃焼度は 0、20、60 MWd/kg（毒物のある集合体は履歴のある点）。状態は ADR-0239 の減速材の 7 点と燃料の温度の
   7 点の、端と中（各 3 点）。温度の分布は、2A の燃料のピンセルに燃料のリングごとに違う温度（PSM-II の SNU のベンチマークの形）を
   与えた入力でも比べる（本番の入力は 5 つのリングに同じ温度を当てる。ADR-0245）。比べる量は k∞、少数群定数、ピン出力、燃料の温度係数と減速材の密度係数の比、リングごとの U-238 と
   Pu-239 の捕獲、Gd-155 と Gd-157 の吸収。判定の値は ADR-0200 の 5 pcm と、係数の比の 1%（どちらも、比がどこまで変化を再現すれば
   入るかは測っていない。ADR-0250 の「決定と理由」）。ADR-0250 の「比が決めない量」（燃料のリングの移行、等価なセルの被覆管と減速材の
   リング）は、候補ごとに分けて誤差を測り、作り方を決める。基準の SPH 因子を使う近似も、状態ごとに解いた SPH 因子に替えた差を分けて測る。時間は timed のジョブで、比の状態の 1 回の秒（比の計算を含む）と、
   基準の UFG の秒。今は流せない燃料と、流すのに要る作業:
   - 2N: 燃焼の履歴（examples/depletion/p2 の lattice-2N.toml）はあるが、1 回の自己遮蔽が 2A の約 3 倍（#0180。ADR-0201 の背景の
     静止した標的の頃は 59.2 / 9.7 = 6.1 倍）で、#0180 の Slurm 822 は 45 分の上限に入らなかった。1 燃焼点の自己遮蔽 12 回（every-state
     9 回と (F1) の基準 3 回）は、2A の 57.8 秒の 3〜6.1 倍で約 35〜71 分の見込み（MOC と比の状態を除く）。ジョブの上限を燃焼点の
     数に合わせて取る
   - MOX のピンセル: 燃焼の履歴（examples/depletion/lattice-mox1-rings1）はライブラリが今の形式より古く読めず、p2 のライブラリでは
     履歴の輸送する核種と 900 K のデータの核種が違って分岐が止まる（#0180 の燃料の種類の項）。燃焼度 0 は履歴を読まない分岐で作れる
     見込みで、使うライブラリが MOX の燃料の核種を ADR-0239 の温度の点で持つかは確かめていない。燃焼した点は、ライブラリを今の形式で
     作り直して履歴を再実行する作業が要り、時間は見積もっていない
2. 段 1 の結果で、比で求める軸を決める（ADR-0250 の (F1) の減速材の軸だけか、(F2) の燃料の温度の軸も含めるか）。比が段 1 の判定の
   値を満たさない燃料か軸があれば、その状態は今の UFG で解く（入力で選ぶ。黙って切り替えない）
3. 本番の形の 2A のテーブル（#0278）を新しい方式で作り、UFG のテーブルと全状態で比べる。毒物のある集合体 1 種でも同じ比較をする。
   時間とテーブルの差を記録し、既定にするかをユーザーが決める
4. （段 2 で今の UFG で解く状態が多く残り、時間が縮まないときだけ）PSM の形の軽い UFG を比の計算に使う（σ_eq の代わり）: 固定の格子、
   静止した標的と U-238 の共鳴の上方散乱の補正、孤立したペレットの CP の表と影の補正。比だけに使うので、絶対値の誤差（文献で
   モンテカルロと約 100 pcm）は基準の UFG が持つ。下の別の筋の測定の結果を使い、別の筋を行っていなければ、段 4 の前に
   その測定のうち比に使う項目を行うかをユーザーに諮る
5. 燃焼の履歴の中点（ADR-0197 の step-start）と燃焼点の間（#0180 の shielding-burnup）にも比の計算を当てるかを、段 1〜3 の後に
   測って決める

別の筋（ADR-0250 の方式とは別。行うかはユーザーが決める）: 同じ系統の中で作りを PSM に寄せる案（「PSM と xlc の今の方式の照合」の
結び）を、項目ごとに分けて、今の UFG からの差（k∞、群ごとの実効断面積）と時間を小さい入力（#0133 のピンセルと 2A の 1 状態）で測る。
項目は、固定の格子（ライブラリに 1 つ、ADR-0185 の間引きの代わり）、孤立したペレットの衝突確率の表と影の補正（等価なセルの厳密な
CP の代わり）、質量で核種をまとめる（核種ごとの核の代わり）、自由ガスの範囲（静止した標的と U-238 の共鳴の上方散乱の補正、
または #0180 の 3 回目の節の寄与の閾値）。どれも近似なので、入力で選べる項目として足し、既定は今のまま（CLAUDE.md の「方針」）。段 4 は
この測定の結果を使う
