# ピンセルと集合体の燃焼の検証のライブラリを 1 つにする

## 問題

ピンセルの燃焼の検証（examples/depletion。1C）と、集合体の燃焼の検証（examples/depletion/p2。ADR-0178）は、多群ライブラリ
（xs.toml）と OpenMC のライブラリ（openmc-library.toml）が別で、核種ごとの段階を 2 組持つ。ピンセルのライブラリを変えると、ピンセルの
輸送する核種（鎖の核種のうちライブラリにあるもの。ADR-0173）が変わって比較が古くなり、OpenMC の `openmc-1C`（重い段階）の deps
も変わるため、集合体のライブラリは別にした。核種と評価は同じで（Gd-155 などの鎖の核種は両方にある）、温度の組だけが違う
（ピンセル 565〜1200 K、集合体 565 と 600 K）。そのため核種ごとの NJOY と xs の処理が重複し、片方に核種を足したときにもう片方を直し忘れる
危険がある。

関係する ADR: ADR-0178

## 完了の条件

ピンセルの検証（M4-5）がマージされたあとに、ライブラリを 1 組にする（温度の和集合の核種を 1 組の段階で作る）。ピンセルの比較を
1 度流し直す（輸送する核種は、Gd などが鎖の核種として増えるので変わる）。流し直しの費用（`openmc-1C`）と、1 組にする利点を比べて決める。

## 経緯

- 2026-10-15: ADR-0178 で集合体のライブラリを別にした
