# CRAM の誤差より小さい個数密度を輸送と自己遮蔽に渡している

## 問題

- 燃焼の解の個数密度のうち、CRAM の近似の誤差（領域の最大の 1e-15 倍ほど。ADR-0161）より小さい値を、正のものは値のまま輸送と
  自己遮蔽に渡している。負のものは ADR-0173 のとおり 0 にして渡し（`depletion::region_material`。燃焼の輸送と履歴からの分岐で
  同じ。ADR-0187）、領域の最大の 1e-12 倍より大きな負の値はエラーで止める（`depletion::check_negative`）。負の値が輸送に渡る
  経路は無い
- 大きさ（examples/depletion/p9-product/lattice-2A.msgpack、md5 f455243f。燃料の 195 の燃焼の領域。2026-11-12 に履歴を読んで数えた）:
  - 履歴の 3820 核種のうち、どこかの領域で負の核種は 0.5、32、60 MWd/kg で 305、343、371。負の値の大きさは、その領域の最大の
    個数密度の 4.5e-19、6.8e-20、7.3e-20 倍以下（最大は 60 MWd/kg の C-12）で、CRAM の誤差の水準より 4 桁ほど小さい
  - C-12 は 60 MWd/kg で 111 の領域が負（0 にして渡す）、84 の領域が正で、値は −3.4e-21〜2.9e-21 /(b cm)。正と負が同じ大きさで
    並ぶので、正の値も近似の誤差と区別できない
  - B-10 と B-11 はすべての領域で正（60 MWd/kg で 7.0e-18〜9.2e-18 と 4.6e-21〜4.9e-21）で、燃焼度とともに増える。生成の経路
    （3 体核分裂の収率、チェーンの反応）は確かめていない。P-31 はすべての領域で 0
- 効き: 自由ガスの散乱源は、個数密度がちょうど 0 の核種とリングを飛ばす（ADR-0248 の帰結）が、近似の誤差の水準の正の値の核種は
  核を評価し、積分する。2A の 60 MWd/kg では、燃料の B-10、B-11、C-12 の区間とリングの積分が自由ガスの散乱源の積分の 11.8%
  （4.1%、4.2%、3.5%。#0180 の「3 回目」の節の表の、飛ばす直しの前の値。C-12 は 0 の領域のリングを飛ばすので、直しの後はそれより
  少ない）を使い、散乱源への寄与は 1e−16 以下
- CLAUDE.md の「方針」（怪しい状態は推測せずエラーで止める）に照らすと、近似の誤差と区別できない値を物理の量として扱っている。
  一方で、0 に切る閾値は既定値の決定（ADR が要る）で、閾値をまたぐ核種で結果が燃焼度について滑らかでなくなりうる
- 案（決めていない）:
  - 今のまま（値のまま渡す）
  - 輸送と自己遮蔽に渡すとき、領域の最大の個数密度の ε 倍（CRAM の誤差の水準の 1e-15 など）より小さい正の値も 0 にする
    （ADR-0173 の負の値と同じ扱いを、正の側に広げる）。状態には値のまま持つ。自由ガスの散乱源は、0 の核種を飛ばす直しで減る
  - 近似の誤差より小さい値をエラーにする: 燃焼の解の正しい出力を止めるので、採らない見込み
関係する ADR: なし

## 完了の条件

正の小さい値を 0 にするかを決め（決めるなら閾値を ADR に）、0 にするなら 2A の 1 状態で、輸送の k∞ と群定数の差と、自己遮蔽の
時間を測る。

  ブランチ perf/0180-free-gas-kernel-reuse で個数密度の出どころを調べた（負の値は 0 にして渡していた）
