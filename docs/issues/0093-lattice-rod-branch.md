# 格子計算の分岐に制御棒の軸を入れる

## 問題

分岐のテーブルは制御棒の離散の軸 `rod`（値の名前の列。`out` は棒のない状態）を持てるようになり、core は部分挿入の
区間ごとに値を選ぶ（ADR-0097、ADR-0127。#0063）。しかし格子計算は制御棒の分岐を作れない。制御棒を入れた集合体は、
案内管に棒を入れた別の格子計算の入力（examples/vera/p2 の 2G、2H）で、軸のないテーブルを出す。

それまでのつなぎとして、examples/core/rod_table.py が、連続の軸の同じ 2 つ以上の格子計算の出力のテーブルを、制御棒の
軸の値ごとに並べて 1 つのテーブルにする（連続の軸が違えばエラー）。ADR-0097 は制御棒を、基準の形状（制御棒のない
集合体）に対する変更として同じ格子計算の分岐にすると決めており（M4 で、制御棒の分岐を基準の燃焼の組成から瞬時に変えた
状態として計算するため）、別の格子計算を結合する形は燃焼のある問題では使えない。

関係する ADR: ADR-0127（分岐の形の決定と上の層の制御棒の軸は、本文の ADR）

## 完了の条件

格子計算の入力で、制御棒の分岐（案内管に入れる棒の材料ごとのセル）を基準の形状に対する変更として書け、テーブルに
制御棒の軸が入る。examples/core の結合のスクリプトを、この分岐の出力に置き換えて消す。軸方向の反射体の上の層の
制御棒の値（ADR-0128 の「制御棒の軸」。#0030）も、この分岐の書き方にそろえる。

## 経緯

- 2026-10-12: #0063 で core が制御棒の軸を選べるようになったが、格子計算に触らずに進めたので、分岐を作る部分を分けた
