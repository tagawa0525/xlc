# 対称な位置の構造材の塊の Dancoff 係数と平均弦長が、約 1% 食い違う

## 問題

2 × 2 の格子（ピッチ 1.26 cm、左上と右下が燃料のピン、右上と左下が、内径 0.65 cm のリングが四隅に分かれた Zr の
セル。鏡面反射、方位角 16、間隔 0.02 cm）で、塊をセルごとに遮蔽すると（main の扱い）、180° 回転で移り合う
隅（右上のセルの右上の隅と、左下のセルの左下の隅）の Dancoff 係数が 0.24353 と 0.24630、平均弦長が 0.39754 と
0.39867 cm になった（shielding のテスト `pieces_split_by_sectors_are_grouped_by_images` を、修正の前の実装の
7673ccc で走らせた出力。2026-10-10）。トラックは 180° 回転と対角線の鏡映で正確に移り合う
（`symmetry::images` が通る）ので、離散化の差ではない。

平均弦長は、塊の体積を、黒体でない領域から塊に入る回数の重みの和で割る（`moc::dancoff::lump_dancoff`）。ピンのセルの
中の区切り（扇形の境界、格子の線）は、角を通るトラックに丸めの程度の区間を残す（#0051 で直していないもの）。扇形の
境界はセルの角を通るので、隅の塊の近くで、黒体でない丸めの程度の区間が塊と塊の間に入ると、入る回数を余計に数える
疑いがある。確かめていない。

ブランチ fix/0054-shielding-orbits の修正（像どうしの塊を 1 つの黒体にする）では、組の値はこの食い違いの平均になり、
対称性は保たれる。

関係する ADR: なし
