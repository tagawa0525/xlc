# 拡げた格子で、全断面積に対して小さい反応が粗く表される

## 問題

ドップラー拡がり（crates/xs/src/doppler.rs）は、拡げる範囲の格子を NJOY broadn と同じ規則で、選んだ節と収束の判定で
細かくした点だけで作り直し、節でない 0 K の点を落とす。収束の判定は、全反応の和に対して 1e-6 未満の反応を見ず
（`NEGLIGIBLE`）、小さい反応には積分の誤差の判定（errint）で errmax（許容誤差の 10 倍）までの差を許す。そのため、全断面積に
対して小さい反応は、拡げた後の格子が粗くなり、0 K の形を失う。

M3 の新しい核種の 565 K の無限希釈の捕獲を NJOY（RECONR、BROADR、GROUPR）と比べると、C-13 で 3.1e-2（17 群、
2.2〜3.5 keV）、C-12 で 5.9e-3（12 群）、Ti-50 で 3.2e-3（13 群）違う（examples/m3-nuclides/verification.md）。
0 K では 6e-5、2e-5、9e-4 で一致し、xlc の拡げ方（SIGMA1）は、NJOY の 0 K の PENDF から拡げれば BROADR と 1e-6 で一致する（C-13）。
C-13 の 565 K の捕獲は 1.5、2、4 keV の点だけになり、0 K の 1/√E に近い形を 2〜4 keV で線形に補間して、3 keV で約 5%
大きい。NJOY は RECONR で全反応を共通の格子（C-13 で 1362 点）に載せてから拡げるので、xlc の部分反応ごとの格子
（全断面積 907 点）より節の候補が多く、同じ規則でも細かく残る。

C-13（天然の C の 1.1%）の捕獲は 1e-5 b 程度で、C-12 と Ti-50 の捕獲も全断面積の 1e-5〜1e-4 なので、格子計算への
影響は小さいと見込むが、測っていない。

関係する ADR: なし

## 完了の条件

小さい反応も拡げた後に許容誤差の範囲で表されるようにする（節でない 0 K の点を残す、反応ごとに格子を判定する、など）か、
影響が無視できることを示して閉じる。NJOY と同じ規則を外す場合は、[ADR-0046](../adr/0046-broaden-with-sigma1.md) の格子の作り方を置き換える ADR にする。
