# 黒い燃料での円筒の衝突確率の弦の求積の精度

## 問題

円筒のセルの衝突確率（crates/lattice/src/cp.rs）は、弦の高さ y を、リングの境界の特異点に合わせて分けた小区間ごとに
16 点の Gauss–Legendre で積分する。小区間あたり 64 点との中性子束（外の水に線源）の相対差を測ると、燃料の全断面積が
30 /cm（テスト `quadrature_converges` の場合）で 1e-9 以下だが、300 /cm では 5.8e-8、8 点では 1.1e-5 だった
（2026-10-10、#0039 の測定）。小区間の幅を増やす比を 2 から 1.5 にしても誤差は変わらず、特異点の扱いではなく、黒い燃料の
中で減衰が急なこと（リングに接する弦の近く、y の幅 ~1/(8rΣ²) の範囲で弦の長さが平均自由行程を横切る）による。UFG の
共鳴のピークでは燃料の全断面積が数千 /cm になるので、その点の衝突確率の精度は 1e-9 に届いていない可能性がある。

関係する ADR: なし

## 完了の条件

- 共鳴のピークの全断面積（1e3〜1e4 /cm）で、衝突確率と中性子束の求積の誤差を測る
- 接する弦の近くに向けて点を細かくする求積（t の小区間を幾何級数で分けるなど）を試し、少ない点で精度を保てるかを
  確かめる。保てれば、速さ（#0039）にも効く。決めたら ADR にする

## 経緯

  選んだ。調べる中で、黒い燃料では 16 点でも 1e-9 に届かないことが分かった
