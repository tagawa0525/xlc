# 5-2D の外周の Pyrex のある集合体の出力が低く、3 × 3 の中心の集合体が高い

## 問題

外周の燃料に反射体の格子の燃料のノードの定数を置く（ADR-0153）と、5A-2D の OpenMC（同じ ENDF/B-VIII.0）との差は k −5.7 pcm、
集合体出力の RMS 1.66% になった（examples/vera/verification.md の「Problem 5-2D の炉心の計算」、ad997b4d と ea7115d1、
2026-10-12）。残る差のうち、L 型の近似（#0029、#0068）で説明のつかないものが 2 つある。

- Pyrex のある外周の集合体（I 型の位置の 31-p12 の A08 と H15、31-p8 の A10 と対称の位置）の出力が低い: A08 −3.4%、H15
  −2.9%、A10 −1.8%。A08 は、すべての位置が単一集合体の定数（ADR-0153 の前）で +1.7%、A08 だけが単一集合体の定数のまま
  ほかの外周を替えた試行（65fb2b43 の trials/p5-0086 の `5A-IC`）で +0.8% で、その種類の I 型の格子の定数で符号が変わった。
  Pyrex のある燃料に面する反射体の位置に、その燃料の格子の反射体の定数を置くと、A08 は −4.1% で、差は小さくならない（18a270bd の trials/p5-0086/pairing.py）。A08 と H15 は対角の鏡映で移り合い、xlc の値は同じで、差の
  違い（0.5%）は OpenMC の参照解の非対称（#0099）から来る
- 3 × 3 の集合体と反射体の輪では、k は MOC に +11.6 pcm まで近づいたが、中心の集合体（単一集合体の定数）の出力が +3.4%
  高い（`compare-small-E.out`、ad997b4d）。外周の燃料の定数を単一集合体のものにしていたときは +1.4% だった

原因の候補（どれも確かめていない）:

- I 型の格子は、燃料の横の 2 辺を鏡面反射にし、外周に同じ種類の集合体が並ぶ形を表す。5-2D の Pyrex のある外周の集合体の
  横は、Pyrex のない 3.10% の集合体で、この形と違う
- 外周の 2 列目より内側の燃料も、反射体の影響でスペクトルが無限格子と違う（ADR-0153 の帰結）。3 × 3 の中心は反射体から
  1 体の距離にある
- 反射体の格子の燃料のノードの ADF は、隣が同じ集合体（鏡面反射）の辺で作られ、炉心の内側の燃料（単一集合体の ADF）と
  組むと、面の ADF の比が環境の違う 2 つの格子から来る

関係する ADR: ADR-0153

## 完了の条件

Pyrex のある外周の集合体の出力の差と、3 × 3 の中心の差の原因を、入力の試行で切り分ける（例: 横の 2 辺に Pyrex のない
集合体を並べた格子、3 × 3 の MOC の中心の集合体のノードの定数）。原因に応じて、外周の定数の作り方を直すか、差の大きさを
記録して閉じる。
