# 燃料のリングごとの物質で飛程の表が大きくなる

## 問題

格子計算の燃焼をリングごとに行うと（ADR-0173 の案 R1）、1 つのピンの燃料のリングがそれぞれ別の物質になる。UFG の減速計算の
飛程の表（ADR-0156）は、セルの物質ごとの ln Σ の軸の直積なので、物質が 1 つ増えるごとに表の格子点が軸の点の数（10 倍あたり
16 点で数十）倍に増える。燃料 3 リングと被覆管、水のピンセル（crates/lattice/src/shielding/tests.rs の `ring_fuel`）で、表の
格子点は 91,125 になり、UFG の格子点 7,599 を超えて `UfgError::TableTooLarge` で止まる。いまはリングごとに燃焼させる入力に
`track-table = false`（格子点ごとに衝突確率を求める）を書く。2A の 1 状態で、格子点ごとに求めると自己遮蔽は表の約 7 倍
（95.2 秒と 12.9 秒。ADR-0156 の表）。

燃料のリングの組成は互いに近く（同じ核種の並び、燃焼で少しずつ違う数密度）、リングの全断面積はほぼ一緒に動く。

また、組成の違うリングのピンでは、構造材の塊の Dancoff 係数（`shield_lumps`）に使う燃料の全断面積を、ピンの体積平均の組成で
求める（リングごとの値を使っていない）。

関係する ADR: ADR-0173, ADR-0182

## 方針の案

- 燃料のリングの全断面積を、リングの平均（1 つの軸）と、平均からの比（リングごとに群の中でほぼ一定）で表し、表の軸を燃料 1 つに
  保つ。比の変化による誤差を、格子点ごとの計算と比べて測る
- 衝突確率を点ごとに求めない方式（#0039）
- 燃料のリングの数（燃焼の領域の数）を、Gd の燃料で測って決めるとき（計画の「格子計算の燃焼」）に、あわせて決める

## 完了の条件

リングごとに燃焼させる集合体を、表を使う時間の水準（格子点ごとの数分の 1）で解け、格子点ごとの計算との差を測ってある。

## 経緯

- 2026-10-14: 格子計算の燃焼（ADR-0173、ブランチ feat/lattice-depletion）で、リングごとの物質を自己遮蔽できるようにしたときに
  見つけた
