# 共鳴の線形化の中点の検査が変曲点で止まり、許容誤差の 2 倍を超える点が残る

## 問題

- 分離共鳴の線形化（crates/xs/src/pointwise.rs の `refine`）は、区間の中点 1 点で線形補間の誤差が許容誤差（1e-3）以下なら二分をやめる。
  中点で線形補間が合っても、中点から離れた所で許容誤差を超えたまま区間が残りうる（候補は、共鳴の裾の変曲点が中点の近くにある区間。
  確かめていない）
- ENDF/B-VIII.1 の Cu-63（R 行列の制限形のシフト因子。#0310）では、0 K の再構成を NJOY RECONR の PENDF の点で比べると、6 点で全断面積が
  許容誤差の 2 倍を超える。同じ点で線形化しない R 行列の値は NJOY と 1e-6 以内で一致するので、差は格子から来る（数値は
  examples/depletion/verification.md の「版ごとのライブラリの分離共鳴の R 行列の制限形のシフト因子とバックグラウンド」）。23101.4 eV の
  準位では、ピークの左の 23100.689 eV と 23101.097 eV の格子点（0.41 eV）の間で全断面積が 31.7 b から 42.2 b に上がり、その間の NJOY の点で
  線形補間が 2.2e-3 ずれる
- これまでの比較（Fe-54、Fe-57、Pu-239 の LRF=7、SLBW の記録など）では 2 倍を超える点は無く、どの評価で、どれだけ起きるかは数えていない

関係する ADR: なし

## 完了の条件

- [ ] 中点 1 点の検査が止まる区間の誤差を測り、検査の点を足すか（例: 4 分の 1 の点）、格子点の置き方を変えるかを決めて直す。
  既存の評価の出力が変わるので、変わる核種と差の大きさを記録に書く
