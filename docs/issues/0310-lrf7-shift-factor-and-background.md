# R 行列の制限形（LRF=7）のシフト因子とバックグラウンドの R 行列を読めない（ENDF/B-VIII.1 の Cu-63、Sr-88）

## 問題

- xs は LRF=7 のシフト因子（SHF≠0）とバックグラウンドの R 行列（KBK≠0）、位相シフトの指定（KPS≠0）をエラーにする（ADR-0055）。
  4 つの版（VII.0、VII.1、VIII.0、VIII.1）の中性子の全評価の LRF=7 の 28 評価の制御の値と粒子対をファイルから数えると（2026-11-20、
  #0308 のとき）、これで止まるのは次の 2 つ（荷電粒子の粒子対を持つ Cl-35 と Ca-40 は #0264、VII.1 の Cl-35 のシフト因子はそれと同じ評価）
  - VIII.1 の Cu-63: 弾性散乱の粒子対が SHF=1。VIII.0 の Cu-63 は SHF=0 で読める
  - VIII.1 の Sr-88: spin group が KBK=1、2 と KPS=2 を持つ
- どちらも版ごとのピンセルの燃焼（#0303）の 65 核種には入っていない。VIII.1 で放射化の核種（2A のライブラリの examples/depletion/p2/xs.toml
  の形）を作るときに止まる。`xs nuclide` で止まることは確かめていない（ファイルの値から xs のコードの検査に照らした）

関係する ADR: なし
