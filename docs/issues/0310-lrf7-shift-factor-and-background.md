# R 行列の制限形（LRF=7）のシフト因子とバックグラウンドの R 行列を読めない（ENDF/B-VIII.1 の Cu-63、Sr-88）

## 問題

- xs は LRF=7 のシフト因子（SHF≠0）とバックグラウンドの R 行列（KBK≠0）をエラーにしていた（ADR-0055）。4 つの版（VII.0、VII.1、VIII.0、
  VIII.1）の中性子の全評価の MF2 を走査すると（2026-11-20）、LRF=7 の 28 評価のうち、これで止まるのは次の 3 つ。KPS≠0（位相シフトの指定）、
  LBK=1、3 のバックグラウンドを持つ評価は無い
  - VIII.1 の Cu-63: 弾性散乱の粒子対が SHF=1（p 波のチャネルの BND=−1）。VIII.0 の Cu-63 は SHF=0
  - VIII.1 の Sr-88: 7 つの spin group がどれも KBK=1（中性子のチャネルに LBK=2、SAMMY の対数の形）、KPS=0
  - VII.1 の Cl-35: 3 つの粒子対がどれも SHF=−1（ENDF-102 の 2005 年版の「計算しない」）
- どれも版ごとのピンセルの燃焼（#0303）の 65 核種には入っていない。4 つの版の全核種を xs で処理できるようにする（ユーザー 2026-11-20）ので、
  要る

関係する ADR: ADR-0055

## 完了の条件

- [x] VIII.1 で Cu-63 と Sr-88 が要るかを決め、要るなら ENDF-102 の D.1.7 の式（シフト因子、バックグラウンドの R 行列）で読み、NJOY RECONR と比べる
  （ADR-0055 の「変更」、examples/depletion/verification.md の「版ごとのライブラリの分離共鳴の R 行列の制限形のシフト因子とバックグラウンド」）

## 経緯

- 2026-11-20: #0308 で LRF=7 の評価の粒子対と制御の値を数えて見つけ、起こした
- 2026-11-20: シフト因子と LBK=2 のバックグラウンドを入れ（ADR-0055 の「変更」）、NJOY と比べて閉じた。VII.1 の Cl-35 は、シフト因子の次の
  荷電粒子の粒子対で止まる（#0264）。比べた Cu-63 の線形化の格子の隙間は #0318
