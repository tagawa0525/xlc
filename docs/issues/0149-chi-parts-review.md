# ADR-0186 のレビューで残した χ の成分と LF=5 の整理

## 問題

ADR-0186 の実装（ブランチ feat/0133-fission-spectrum）のコードレビューの 2 周目で、ENDF/B-VIII.0 のライブラリの出力を変えない
指摘を残した。どれも xs のコードを変えるとライブラリ（examples/depletion/depletion.msgpack。作り直しに約 2 時間）のステージが
changed になるので、このブランチでは直していない。

1. LF=5 の g(x) は、x = 0 で正の値から始まることを読み込みで求める。割合の分母（(E − U)/θ までの g の積分）が正であるための条件
   としては厳しい: U < 0 なら (−U)/θ までの積分が正であれば足り、g(0) = 0 の蒸発の形（g ∝ x e^(−x)）の lin-lin の表も分母は正。
   ENDF/B-VIII.0 の MF5 MT455（U-232〜Cm-245 の 21 核種、各 6 族）は、どれも θ = 1、U = −3e7、g(0) > 0 で、今の条件で読める
2. 遅発中性子の分布があるとき、χ は ν_p（MT456）と ν_d（MT455）で重み付けし、νσf の ν は MT452 を使う。MT452 と MT455 + MT456 が
   合うかは確かめていない（U-235 の 1e-5 eV は 2.42985 と 2.414 + 0.01585 で一致）。合わない評価で warn を出すかを決めていない
3. `multigroup/outgoing.rs` の `Theta`（一定か表）と `Cumulative`（不完全ガンマ関数か表）は別の enum で、有効な組は 2 つ（表の g と
   一定の θ、ガンマ関数と表の θ）だけ。1 つの enum にすれば、無効な組と `breakpoints` の組の照合がなくなる
4. θ が一定で E − U が θ × (g の表の最後の x) を超えると（ENDF/B-VIII.0 の遅発中性子は常にそう）、群の割合は E によらないのに、
   `accumulate` は求積点ごとに群の数の探索を繰り返す。`Cumulative::table` の区分線形の積分は、同じファイルの
   `outgoing_group_integrals` と同じ積分の手書き
5. VERA の参照のスクリプト（`examples/vera/openmc_balance.py`、`openmc_homogeneous.py`）の tally は群 1 の上端が 10 MeV のままで、
   10 MeV より上の中性子束と生成を数えない（xlc は 10 MeV より上に生まれた中性子を群 1 に入れる）。#0133 のスクリプトは群 1 の上端を
   広げた（ADR-0186 の背景）。均質な無限媒質の balance では、U-238 の生成の 0.71% 以下がこの差に当たる（#0148）

関係する ADR: ADR-0186

## 完了の条件

1〜4 は、次に xs のライブラリを作り直す変更と一緒に直すか、直さない理由を書く。5 は、VERA の参照解を作り直すときに群 1 の上端を
広げるかを決める。

## 経緯

- 2026-10-23: ADR-0186 のコードレビューの 2 周目で見つけ、ライブラリの出力を変えないので分けた
