# L 型と角型の反射体の格子と、core での反射体の定数の置き方

## 問題

ADR-0095 は、5-2D と Problem 5 の外周が階段の形なので、I 型（燃料と 1 面で接する）に加えて、L 型（燃料 3 体と
反射体 1 つ）と角型（燃料 1 体と反射体 3 つ）の 2 × 2 の格子で反射体の定数を作ると決めている。I 型と角型の格子、
core で反射体の定数を回して置く扱い、外形の面と反射体どうしの面の扱い（ADR-0132）は入った。角型の格子の定数を、
定数を作った体系のまま core に置くと、MOC の k を +0.0013 pcm で再現する（ADR-0132 の表）。残りは次の 2 つ。

- L 型の格子: 今の rectilinear の格子では、仕様の寸法で作れない（#0068）。それまで、5-2D の L 型の位置（A-12、B-14、
  D-15 と鏡映の位置）には I 型の定数を置く（ADR-0132）。L 型の反射体の右と上の面は、炉心ではいつも別の反射体のノードに
  接するので、格子の外周の右と上を鏡面反射にする案がある（真空にすると燃料の辺が真空に面する）。これは ADR-0095 の
  「反射体の外側の辺は真空」を L 型について置き換えるので、格子を作るときに、真空と鏡面反射の両方で反射体の f\*、C\*、
  定数の差を測って ADR に書く（辺の区間ごとの境界は、その ADR の検討した案に書く）
- 5-2D での近似の大きさ。examples/vera/verification.md の「Problem 5-2D の炉心の計算」で測った（炉心は 1c115833、2026-10-12）:
  - L 型の位置の I 型の定数: f\* の辺をどちらの燃料に向けても、5A-2D の k は変わらない（6 桁）。集合体出力は最大 4.4%、
    ピン出力は最大 66%（L 型の位置に角の点で接するピン）違う
  - 角型の位置に隣る I 型の位置には、角型の格子の右と上の定数か、I 型の定数を置ける。どちらを置くかで、5A-2D の k は
    4.8 pcm、集合体出力は最大 0.95% 違う。3 × 3 の集合体の MOC には I 型のほうが近く（ピン RMS 2.05% と 3.20%）、KENO-VI の
    集合体出力には角型の格子のほうが近い（RMS 4.07% と 4.31%）。どちらの差も f\* の方法の誤差（#0086）より小さく、
    区別できない。そのため置き方は決めていない（5-2D の入力では角型の格子の右と上を置く）
  - 代表の燃料を選ぶ近似（ADR-0095。反射体の格子の燃料は 3.10% で、Pyrex の棒なし）と、違う格子から来た反射体が出会う角の
    点の CDF（反射体のノードの CDF は、それぞれの格子の値のまま。ADR-0131）の影響は、まだ測っていない。f\* の方法の
    誤差（#0086）を切り分けてから測る

関係する ADR: なし

## 完了の条件

- L 型の格子の外周の境界を ADR で決めて定数を作り（#0068 のあと）、5-2D の L 型の位置に置いて解き直す
- 5-2D で、角型の位置に隣る I 型の位置の置き方を決める。代表の燃料を選ぶ近似と、反射体どうしの角の点の CDF の影響を
  測って記録する

## 経緯

- 2026-10-09: ADR-0095 の I 型を実装したときに残した
- 2026-10-11: 角型の格子と、反射体の定数を装荷図の回転（ADR-0105）で置く core の扱いを入れた（feat/0029-reflector-shapes）。
  反射体の印（`reflector`）は、燃料と 1 辺で接することを求めず、燃料に角の点だけで接するノードにも付ける
- 2026-10-11: L 型の格子は、バッフルとピンの列の境が合わず作れないと分かった（#0068）
- 2026-10-12: #0034 で、反射体どうしの面に各側の ADF を使うことにした（ADR-0132。ADR-0095 の「1 にする」を置き換えた）
- 2026-10-12: #0034 で、L 型の格子ができるまで、5-2D の L 型の位置には I 型の定数を置くと決めた（ADR-0132）
- 2026-10-12: #0034 で、角型の位置に隣る I 型の位置に、角型の格子の右と上の定数を置けることを確かめた（ADR-0132 の帰結）
- 2026-10-12: 5-2D を全炉心で解き、上の近似の大きさを測った（feat/p5-2d）
- 2026-10-12: 階段の外形の炉心では、燃料の列に向きの違う反射体のノード（セルの数が違う）が並び、core のピン出力の表が
  作れなかった。表の列と行のセルを核分裂のあるノードから取り、反射体を 0 で埋めるようにした。途中で試して捨てた版:
  (1) セルの大きさを層ごとに決める版は、ある層で列が反射体だけになると、その層の列の幅が反射体のものになり、層の表の
  形がそろわない（core の `layers_take_the_cells_of_the_fuel_in_any_layer` の形）。(2) 反射体だけの列どうしが分け合う
  セル（`halves`）をエラーにする版は、両側とも 0 で表から落ちる列で計算を止めるだけなので、合わせを飛ばすようにした
