# L 型と角型の反射体の格子と、core での反射体の定数の置き方

## 問題

ADR-0095 は、5-2D と Problem 5 の階段の形の外周のために、I 型に加えて L 型（燃料3体と反射体1つ）と角型（燃料1体と
反射体3つ）の 2×2 の格子で反射体の定数を作ると決めている。格子計算のノードごとの均質化と f* は I 型で入れたが
（examples/reflector）、次がまだない。

- L 型と角型の格子の入力（バッフルを階段に沿って角で折る形）。角型の定数は燃料と角だけで接するノードから取るので、
  燃料と1辺も接しない反射体のノードになり、いまの `reflector` の印（反射体でないノードと接する辺を持つこと）と
  合わない
- core の、反射体のノードどうしの面の ADF を 1 とする扱い
- core で、反射体の定数を炉心の位置（東西南北と角）に合わせて回す扱い。core の装荷図の入力（#0031）とあわせて
  使う（装荷図の形式は M3 の進め方の 6）

関係する ADR: なし

## 完了の条件

L 型と角型の格子で反射体の定数を作り、core の装荷図で回して置き、5-2D で ADR-0095 の確認（反射体のノードどうしの
ADF を 1 とする近似と、代表の燃料を選ぶ近似の影響）を測る。

## 経緯

- 2026-10-09: ADR-0095 の I 型を実装したときに残した
