# L 型と角型の反射体の格子と、core での反射体の定数の置き方

## 問題

ADR-0095 は、5-2D と Problem 5 の外周が階段の形なので、I 型（燃料と 1 面で接する）に加えて、L 型（燃料 3 体と
反射体 1 つ）と角型（燃料 1 体と反射体 3 つ）の 2 × 2 の格子で反射体の定数を作ると決めている。I 型と角型の格子、
core で反射体の定数を回して置く扱い、外形の面と反射体どうしの面の扱い（ADR-0132）は入った。角型の格子の定数を、
定数を作った体系のまま core に置くと、MOC の k を +0.0013 pcm で再現する（ADR-0132 の表）。残りは次の 2 つ。

- L 型の格子: 今の rectilinear の格子では、仕様の寸法で作れない（#0068）。それまで、5-2D の L 型の位置（A-12、B-14、
  D-15 と鏡映の位置）には I 型の定数を置く（ADR-0132）。L 型の反射体の右と上の面は、炉心ではいつも別の反射体のノードに
  接するので、格子の外周の右と上を鏡面反射にする案がある（真空にすると燃料の辺が真空に面する）。これは ADR-0095 の
  「反射体の外側の辺は真空」を L 型について置き換えるので、格子を作るときに、真空と鏡面反射の両方で反射体の f\*、C\*、
  定数の差を測って ADR に書く（辺の区間ごとの境界は、その ADR の検討した案に書く）
- 5-2D での近似の大きさ。examples/vera/verification.md の「Problem 5-2D の炉心の計算」で測った（外周の燃料に反射体の格子の
  燃料のノードの定数を置いた ADR-0153 の入力。炉心は ad997b4d、OpenMC との比較は ea7115d1、2026-10-12）:
  - L 型の位置の I 型の定数: f\* の辺をどちらの燃料に向けても、5A-2D の k は変わらない（6 桁）。集合体出力は最大 4.8%、
    ピン出力は最大 55%（L 型の位置に角の点で接するピン）違う。OpenMC との集合体出力の最大の差（+4.6%）は、この L 型の位置の
    隣にあり、向きを変えると鏡映の位置に移る
  - 角型の位置に隣る I 型の位置には、角型の格子の右と上の定数か、I 型の定数を置ける。どちらを置くかで、5A-2D の k は
    4.4 pcm、集合体出力は最大 0.95% 違う。3 × 3 の集合体の MOC には、角型の格子の右と上の定数のほうが k とピンで近く
    （+11.6 pcm と +78.2 pcm、ピン RMS 1.86% と 2.05%）、集合体の RMS は I 型が近い（1.42% と 1.74%）。OpenMC の 5A-2D の
    集合体出力には角型の格子のほうがわずかに近い（RMS 1.66% と 1.71%）。置き方は決めていない（5-2D の入力では角型の格子の
    右と上を置く）
  - 代表の燃料を選ぶ近似（反射体のノードの定数は 3.10%、Pyrex なしの格子のもの。ADR-0084、ADR-0153）: Pyrex のある燃料に面する
    反射体の位置にその燃料の格子の反射体の定数を置いても、5A-2D の OpenMC との差は k −5.7 から −9.2 pcm、集合体 RMS 1.66% から
    1.73% で、小さい（18a270bd の trials/p5-0086/pairing.py）
  - 違う格子から来た反射体が出会う角の点の CDF（反射体のノードの CDF は、それぞれの格子の値のまま。ADR-0131）の影響は、
    まだ測っていない

関係する ADR: なし

## 完了の条件

- L 型の格子の外周の境界を ADR で決めて定数を作り（#0068 のあと）、5-2D の L 型の位置に置いて解き直す
- 5-2D で、角型の位置に隣る I 型の位置の置き方を決める。反射体どうしの角の点の CDF の影響を測って記録する

  作れなかった。表の列と行のセルを核分裂のあるノードから取り、反射体を 0 で埋めるようにした。途中で試して捨てた版:

  形がそろわない（core の `layers_take_the_cells_of_the_fuel_in_any_layer` の形）。(2) 反射体だけの列どうしが分け合う
  セル（`halves`）をエラーにする版は、両側とも 0 で表から落ちる列で計算を止めるだけなので、合わせを飛ばすようにした
- 2026-10-12: 外周の燃料の定数を反射体の格子のものにした（ADR-0153。#0086）。近似の大きさを測り直し、代表の燃料を選ぶ近似を測った
