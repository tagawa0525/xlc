# L 型と角型の反射体の格子と、core での反射体の定数の置き方

## 問題

ADR-0095 は、5-2D と Problem 5 の階段の形の外周のために、I 型に加えて L 型（燃料3体と反射体1つ）と角型（燃料1体と
反射体3つ）の 2×2 の格子で反射体の定数を作ると決めている。格子計算のノードごとの均質化と f* は I 型で入れたが
（examples/reflector）、次がまだない。

- L 型と角型の格子の入力（バッフルを階段に沿って角で折る形）。角型の定数は燃料と角だけで接するノードから取るので、
  燃料と1辺も接しない反射体のノードになり、いまの `reflector` の印（反射体でないノードと接する辺を持つこと）と
  合わない
- core の、反射体のノードどうしの面の ADF を 1 とする扱い
- core で、反射体の定数を炉心の位置（東西南北と角）に合わせて回す扱い。core の装荷図の入力（#0031）とあわせて
  使う（装荷図の形式は M3 の進め方の 6）

関係する ADR: なし

## 完了の条件

L 型と角型の格子で反射体の定数を作り、core の装荷図で回して置き、5-2D で ADR-0095 の確認（反射体のノードどうしの
ADF を 1 とする近似と、代表の燃料を選ぶ近似の影響）を測る。

## 経緯

- 2026-10-09: ADR-0095 の I 型を実装したときに残した
- 2026-10-11: 角型と core の部分を入れた（feat/0029-reflector-shapes）。
  - 反射体の印（`reflector`）は「反射体のノード: 燃料と接する辺は f*、燃料のノードに接する角の点は C*（ADR-0131）」
    とし、燃料と 1 辺で接することを求めない。角型の右上のノード（燃料に角の点だけで接する）にも印を付け、反射体
    どうしの辺は f*でない GET の ADF、燃料に接する角の点だけ C* を持つ。ADR-0095 と ADR-0131 の決定の範囲なので
    ADR は足さない
  - core は、炉心の形の反射体の位置に置いた物質どうしの x と y の面の ADF を両側とも 1 にする（ADR-0095）。核分裂の
    有無で見分けると、反射体を複数の GET のノードに分けた問題（core のテスト
    `get_adfs_reproduce_fuel_and_a_wide_reflector`、ADR-0108 の次の段階の部分ノード）の ADF まで 1 にするので、
    位置で見分ける。z の面は対象外
  - 反射体の定数を炉心の位置に合わせて回す扱いは、装荷図の回転（ADR-0105。`rotated`、`turn_pins`）のままで足りた。
    L 型の反射体と燃料 3 体を 4 つの向きに置いたテスト（core の
    `reflector_sites_turned_with_the_core_keep_k_and_pins`）で、k とピン出力が向きによらない
  - 反射体の位置どうしの面の ADF は 1 にしたが、反射体のノードだけが接する角の点の CDF は、それぞれの格子の値のまま
    （ADR-0131 の「反射体どうしの角は CDF をそのまま持つ」）。違う格子から来た反射体が出会う角の点（5-2D の I 型と
    角型の境など）で、面と角の扱いがそろっていない。その角の点に燃料のノードは接しないが、角の点の釣り合いは炉心
    全体で 1 つの連立方程式なので、反射体のノードの展開を通じて燃料に接する角の点と燃料の端のピン出力にも効きうる。
    大きさは 5-2D で ADR-0095 の確認とあわせて測る（確かめていない）
  - 角型の格子の定数で core を解いた結果と、反射体どうしの面の ADF を 1 とする近似の差は
    examples/reflector/verification.md の「角型の格子の定数を作った体系の再現」
  - 2026-10-11: 反射体 3 つを集合体の位置に置く入力（`core-corner-get.toml`）で、反射体どうしの 2 面を格子の
    GET の ADF にすると、k −65.4 pcm、右上の反射体のノード平均 +9.61%/+3.22% の差が消えた（k は MOC と 6 桁で一致、
    ノード平均は 10⁻⁶ 未満）。差の原因は ADF を 1 にする近似と確認した（コードは変えず、入力だけ。13464fdd）。
    ピン出力 RMS は 0.105% から 0.072% になるが、残りの原因（ピンの出力の再構成とみる）は確かめていない
  - L 型の格子は、いまの rectilinear の格子でバッフルとピンの列が合わず作れない（#0068）。外周の境界は、右と上を
    辺全体で鏡面反射にする（反射体の右と上の面は、炉心ではいつも別の反射体のノードに接する。真空にすると燃料の辺が
    真空に面する）。ADR-0095 の「反射体の外側の辺は真空」を L 型について置き換えるので、L 型の格子を作るときに
    真空と鏡面反射の両方で反射体の f*、C*、定数の差を測って ADR に書く（辺の区間ごとの境界は、その ADR の検討した案に
    書く）
  - 5-2D の L 型の位置（A-12、B-14、D-15）には、L 型の定数ができるまで I 型の定数（反射体の外側が真空）を置いて
    解く案がある。その近似の影響は 5-2D で測る（代表の燃料を選ぶ近似の影響を測るのと同じ扱い）。採るかは #0034 の
    ADR で決める。5-2D での ADR-0095 の確認は #0034 のあとにする
- 2026-10-12: ADR-0132 で、反射体どうしの面の ADF を 1 とする扱い（ADR-0095）をやめ、各側の ADF を使うことにした。
  5-2D の L 型の位置には L 型の格子ができるまで I 型の定数を置くと決め、その近似の大きさはここで 5-2D で測る。
  角型の格子の MOC と比べると、右と上に I 型の格子の反射体の定数を置いた炉心は、どちらの規則でも右上のピンが約
  +16% 違い（examples/reflector/verification.md の「外形の面と、反射体どうしの面の ADF」）、誤差は I 型の定数を角型の隣に置く
  ことから来る。5-2D の角型の位置に隣る I 型の位置（R-11 など）の環境は、角型の格子の右と上のノード（燃料と反対の
  辺が真空、下が鏡面反射で I 型の列が続く）と同じなので、そこに角型の格子の右と上の定数を置く入力も 5-2D で比べる
- 2026-10-12: 5-2D を全炉心で解いた（feat/p5-2d。examples/vera/verification.md の「Problem 5-2D の炉心の計算」）。
  L 型の位置の I 型の定数は、f\* の辺を炉心の中心のまわりの回転で同じ向き（北東と南西の象限で x の向きの燃料）に置いた。
  向きを入れ替えると、5A-2D の k は変わらず（6 桁）、集合体出力は最大 4.4%、ピン出力は最大 66%（L 型の位置に角の点で
  接するピン）違う。L 型の格子（#0068）までの近似の不確かさとして記録した。角型の位置に隣る I 型の位置に角型の格子の
  右と上の定数を置くか、I 型の定数を置くかは、5A-2D で k が 4.8 pcm、集合体出力が最大 0.95% 違う。3 × 3 の集合体の MOC
  には I 型のほうが近く（ピン RMS 2.05% と 3.20%）、KENO-VI の集合体出力には角型の格子のほうが近い（RMS 4.07% と
  4.31%）。どちらの差も f\* の方法の誤差（#0086）より小さく、区別できないので、置き方は決めていない。5-2D の入力は角型の
  格子の右と上の定数を置く。ADR-0095 の確認のうち、代表の燃料を選ぶ近似の影響は、f\* の方法の誤差を切り分けてから測る（#0086）
