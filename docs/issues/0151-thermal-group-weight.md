# 熱群の群定数の重みがセルのスペクトルと違う

## 問題

ライブラリの群定数は、0.1 eV より下を NJOY の iwt=4 の重み関数の熱の部分（E exp(−E/0.0253 eV)。ADR-0039）で、0.1〜4 eV を
1/E を重みにした減速計算の σ0 の表（ADR-0072）で群平均し、格子計算はそれを等価原理（ADR-0074）で引く。PWR の燃料の中の中性子束は
減速材 600 K の硬いスペクトルなので、群の中の重みが違う。

1C のピンセルに 2A の 40 MWd/kg の組成を置いた 1 状態（#0133 の 2026-10-23。OpenMC は燃料の細かいエネルギーの tally）で、燃料の
U-238 の捕獲の群の断面積の xlc/OpenMC − 1 は 57〜68 群（0.005〜0.1 eV）で +0.12〜+0.58% で、点の断面積を重み関数と OpenMC の
細かい中性子束で群平均した比（+0.02〜+0.59%）と群ごとに合う（57 群 +0.45 と +0.47%、68 群 +0.58 と +0.59%。
`issue-0133/thermal_weight.py`）。Pu-239 は 0.14〜0.25 eV の 3 群で +0.39〜+0.83%（重み関数の予測 +0.40〜+1.21%）、0.32〜0.5 eV の
3 群で −0.09〜−0.60%（予測 +1.07〜+2.61%。σ0 の表の遮蔽が入るので重みだけでは決まらない）。

燃料の核種の吸収と核分裂を 0.625 eV より下で OpenMC の値に置き換えた k の変化（`swap_absorption` の例。k の差への寄与はその符号を
変えたもの）は、新しい燃料（1C の 0 MWd/kg）で +24.9 pcm（U-235 +41.3、U-238 −16.4）、2A の 40 MWd/kg の組成で +32.8 pcm（U-235 +10.6、
U-238 −9.4、Pu-239 と Pu-241 +34.3、Xe-135 と Sm-149 +6.2（全範囲）、ほかの核種 −8.9）。減速材と被覆管は置き換えていない（減速材の
0.1 eV より下の吸収断面積の差の 1 次の見積もりは −8.7 pcm）。

関係する ADR: なし（重み関数は ADR-0039、0.1〜4 eV の σ0 の表は ADR-0072 と ADR-0074）

## 方針の案

- A. 減速計算を熱中性子の範囲まで延ばし、セルのスペクトルで熱群を縮約する（#0001 の A。SCALE CENTRM は既定で 0.001 eV〜20 keV）
- B. 熱の範囲に細かい群のライブラリを持ち、ピンセルの 1 次元の輸送で縮約する（#0001 の B）
- 重み関数の Maxwell 分布の温度を変える案は、合わせる定数になるので採らない

## 完了の条件

方式の決定（#0001）とあわせて決め、1C のピンセル（新しい燃料と 2A の 40 MWd/kg の組成）で、熱群の核種ごとの群の断面積の差と、
置き換えで測る k の寄与がどれだけ残るかを測る。
