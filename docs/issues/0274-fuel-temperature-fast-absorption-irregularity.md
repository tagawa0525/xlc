# 燃料の温度の格子点の間で、高速群の吸収が √T の滑らかな曲線から外れる

## 問題

関係する ADR: ADR-0239、ADR-0242、ADR-0243

- Problem 9 の 2A の直積のテーブル（Slurm 728 の examples/depletion/p9-product/table-2A.msgpack、md5 c171a770。今のそのパスと記録は作り直した Slurm 747 のもので、下の「2A の直積のテーブルの作り直し」）で、燃料の温度の内側の格子点を、
  その点を除いた格子点から内挿した誤差は、内挿の変数（√T、温度、ln T）と方式（線形、3 次 Hermite、4 点のラグランジュ、自然 3 次
  スプライン）のどの組でも、どれかの格子点で目安の 5 pcm を大きく超えた（xlc 4922a278、2026-11-10。値は ADR-0242 の「検討した案」の表）。格子点ごとの符号は、√T と ln T のすべての方式と、温度の線形を除く方式で同じ（600 K と
  1050 K が正、750、900、1200 K が負）で、ホウ素の軸と減速材の軸（密度について）の誤差が 3 次 Hermite で目安に入るのと違い、次数を上げても小さくならない
- 2 群の定数を、燃料の温度の 7 点ごとに √T の 3 次式で最小 2 乗に当てはめた残差（平均の値で割った値。ホウ素 6 点 × 減速材 7 点 ×
  燃焼度 4 点の 168 組。examples/depletion/issue-0274/fuel_residuals.py を同じテーブル（md5 c171a770）に実行した値、xlc 7037f68c（ブランチ feat/state-axis-interpolation、分岐点は main の 074410bc）、2026-11-10）は、高速群の吸収で 600 K が
  +10.4〜+14.6e-5、1050 K が +15.2〜+21.7e-5、1200 K が −13.6〜−18.6e-5 で、168 組のすべてで符号が同じ。熱群の吸収と νΣf は ±0.1e-5
  以下、高速群の νΣf は −9.8〜+12.6e-5。状態ごとの揺らぎでなく、燃料の温度の点ごとに決まった外れである
- 外れの原因は、UFG の減速計算で分離共鳴を持つ核種を自由ガスにする上限（`ufg-free-gas.heavy` の 400 kT。ADR-0204 が足した上限を ADR-0209 が既定にしたもので、ADR-0243 の前の既定。今の既定は ADR-0243 の 31 eV）で
  ある。下の切り分けの段ごとの結果のとおり、同じライブラリで重い核種の自由ガスを外す（静止した標的）か上限をなくすと外れは消え、
  400 kT と静止した標的の差は、上限（核種の kT の倍数で、燃料の温度とともに動く）が U-238 の 20.872 eV と 36.683 eV の共鳴を
  越えるところで段になる。燃料の温度を 900 K に固定して上限だけを動かすと、上限が U-238 の共鳴を越えるたびに、共鳴の前後 1〜2 eV で
  反応度が上下に振れたあと、越える前と違う値に落ち着く（切り分けの 5。66.03 eV でも段がある）。800 kT が 66.03 eV の共鳴を越える
  ところに燃料の温度の 7 点の残差で外れが見えない（切り分けの 3）理由は確かめていない。560〜1350 K で 400 kT が越える U-238 の捕獲の極大（560 K のポイントワイズの捕獲の極大。
  以下の共鳴の位置も同じ。`resonance_crossings.py`）は 7 つで、極大が 100 b を超えるのは 605.5 K で越える 20.872 eV（5,201 b）と
  1064.2 K で越える 36.683 eV（4,126 b）の 2 つ（ほかの 5 つは 5.7 b 以下）。格子点の 600 K と 1050 K はその手前、750 K と 1200 K は
  それを越えた後になる
- 修正方法は ADR-0243 で決めた: 重い核種の上限を温度によらない入射エネルギーにできる入力（`heavy = { energy = <eV> }`）を足し、既定を
  31 eV にした（今までの 400 kT は `heavy = 400` で選べる）。比べた候補と測った値は下の「修正の候補の測定」
- 参照の OpenMC 0.15.2 も同じ 400 kT（`FREE_GAS_THRESHOLD`。ADR-0204 の背景）で止めるので、OpenMC の燃料の温度の分岐にも同じ形の
  外れがありうる（確かめていない）
- ADR-0230 の確認（Problem 6 のテーブル、ライブラリは examples/vera/xs.toml）で 900〜1200 K の区間の内挿の誤差が √T からの見込みより
  大きかったのも、400 kT が 1064.2 K で 36.683 eV の共鳴を越えるためと見込む（Problem 6 のテーブルでは確かめていない）
- 原因を直した後の 2A の直積のテーブル（31 eV。燃料は ADR-0245 の 5 つの燃焼の領域）では、燃料の温度の格子点の外れは消え、
  高速群の吸収の残差は ±5.1e-5 以内、1 点を除いた内挿の誤差は √T の線形で最大 7.71 pcm になった（下の「2A の直積のテーブルの
  作り直し」）。燃料の温度の軸の内挿の方式（ADR-0242 は原因が分かるまで今の √T の線形のまま）は、その値からの推しを同じ節に書いた。
  決めるのは ADR-0242
- 燃料の温度への依存の物理のモデル（高速群の共鳴吸収は √T、熱群は T の 1 次）から導いた当てはめと内挿の式を同じテーブルで比べると、
  格子点の値には、168 組のすべての状態で同じ符号の、温度の点ごとの片寄り（k∞ で格子点ごとの最大 0.4〜3.4 pcm）が残り、1 点を除いた
  誤差の大半はこの片寄りである（下の「燃料の温度への依存のモデルと当てはめの式」）。片寄りの原因は確かめていない

### 燃料の温度への依存のモデルと当てはめの式

compare_grid_interpolation.py の `schemes` と同じ測り方で、内挿の方式の値は記録の「内挿の変数と方式の候補」の燃料の表と一致した。

物理のモデル:

- 高速群の共鳴吸収: 孤立した共鳴の実効共鳴積分は、狭い共鳴の近似で J(ξ, β)（ξ = Γ/Γ_D ∝ T^-1/2、β = σ0/σ_peak）に比例し、温度は
  ξ だけを通して入る。`doppler_exponents.py` で dJ/dT ∝ T^-n の局所のべき n（900 K）を、U-238 の 6.674、20.87、36.68 eV の共鳴
  （ENDF/B-VIII.0 の幅で ξ(900 K) = 0.26、0.20、0.25）で求めると、強く遮蔽された β = 1e-4 で −0.06〜−0.05（J は T の 1 次）、
  β = 0.01 で 0.35〜0.43、β = 0.1 で 0.77〜0.86、β = 1 で 1.18〜1.25 で、希釈が進むと 3/2 に近づく（ξ → 0、β → ∞ の極限。テスト）。
  560→1350 K の J の相対変化は β = 0.01、0.1 で 15〜20 % と最も大きく、β = 1e-4 で 0.4〜0.7 %、β = 1 で 3.6〜4.1 % なので、
  共鳴の和では中くらいの遮蔽（n が 1/2 の前後）が主になる。強い遮蔽ほど T の 1 次に近く、希釈ほど T^-3/2 に近い（n = 1/2 は J が
  √T の 1 次、n = 1 は ln T の 1 次）
- 燃料の棒の測定: Hellstrand、Blomberg、Hörner（Nucl. Sci. Eng. 8, 497, 1960）は、U と UO2 の棒の共鳴積分の温度係数を測り、共鳴積分を
  温度の関数の 1 次で表した（抄録の式は画像で、√T の 1 次とは読めなかった。確かめていない）。Spano（Nucl. Sci. Eng. 19, 172, 1964）は、
  SPERT I の酸化物の炉心の出力の逸走の実験に、√T の依存が対数の依存より合うとした（抄録）
- 熱群: 燃料の温度は、低い共鳴の Doppler（Pu-239 の 0.296 eV は ξ(900 K) = 4.9 で、n は β によらず 0〜0.19 と T の 1 次に近い。
  Pu-240 の 1.056 eV は 0.625 eV より上で高速群）と、燃料の核種の熱運動（自由ガス）による熱中性子のスペクトルの変化を通して熱群に効く。
  後者が T の 1 次になることは確かめていない
- このモデルの基底は 1、√T、T で（√T の 2 次式と同じ）、全範囲の曲がりには希釈の側の T^-1/2 の項が次に効く

ままにする。

- 根拠: 主な項（高速群の吸収、p = 0.505〜0.555）が √T の 1 次なので、√T を変数にすると局所の曲がりが最も小さい（線形の形の誤差の
  見込みが √T で 1.55〜1.58、T で 8.08〜8.11、ln T で 10.64〜10.67 pcm）。熱群の T の項は √T の 2 次で、3 次 Hermite（各点の傾きを
  3 点の放物線の微分にする形）はモデルの a + b√T + cT を厳密に再現する（テスト）。残る形の誤差（4 つ目の項の分）は 7 点で
  0.10〜0.12 pcm。傾きが格子点で連続で、燃料の温度の係数（Doppler 係数）が格子点で跳ばない
- 残る誤差: 温度の点ごとの片寄り（k∞ で格子点ごとの最大 0.4〜3.4 pcm、1200 K が最大）。どの内挿にも入り、方式では減らない。1 点を
  除いた誤差 5.28 pcm の大半はこれ
- 格子点は減らさない: 4 点の √T の 3 次 Hermite の測った誤差は 6.02 pcm で目安を超え、見込み（1.54〜1.65 pcm）だけでは決められない。
  減らすなら ln T の 3 次 Hermite が候補で、区間の中点の状態で確かめる
- 代わりの案: √T の 4 点のラグランジュは見込みも 1 点を除いた誤差も小さいが、傾きが格子点で跳ぶ。ln T の 3 次 Hermite は 7 点で
  見込みが同じ桁（0.06〜0.08 pcm）だが、モデルの主な項を 1 次にする変数でない

ほかの炉心解析コードが燃料の温度の軸をどう表しているか:

- PARCS（PMAXS）: 断面積を基準の状態からの偏微分で表し、燃料の温度の項は Δ√T_F と ∂Σ/∂√T_F（DONJON5 の利用者の手引き IGE-344、
  124 ページの PMAXS の式。出典は GenPMAXS の手引き。GenPMAXS の手引きそのものは開けていない）。DONJON の点動特性の `SQDERIV` は、
  反応度を局所の値の平方根の変化の関数にし、燃料の温度の Doppler に使う（IGE-344 の 6.1.1 節）
- MPACT: 共鳴積分の表の温度の軸を √T で持つ（CASL-X-2015-1013-000 の 65 ページ、`%rtemp` が「Square root temperatures for ri」）。共鳴の
  ない核種と群の断面積は温度の線形で内挿する（MPACT の理論の手引き ORNL/SPR-2021/2330 の 71、72 ページ）。少数群の表の燃料の温度の軸は
  確かめていない
- STREAM/RAST-K: ライブラリの温度の内挿は、ほとんどの核種で √T の隣の 2 点の線形（H-in-H2O の熱散乱だけ 3 点のラグランジュ）で、
  断面積がほとんどの核種で √T の 1 次になるため（Choe ほか、Transactions of the KNS、2020 年春）。炉心の燃料の温度の内挿の次数は書かれて
  いない
- PARCS の BWR の分岐（NUREG/CR-7164、ORNL/TM-2012/518 の 8.2 節）: 燃料の温度の分岐は 500、950、1500 K の 3 点で、燃料の温度の反応度
  帰還の計算に足りるとした
- NESTLE: 断面積を実効的な燃料の温度などの Taylor 級数で表す（RSICC の抄録）。変数が √T かは確かめていない
- CASMO/SIMULATE、SCALE/Polaris、APOLLO/CRONOS: 手引きを開けず、確かめていない

## 完了の条件

高速群の吸収の外れの原因（ライブラリの核種と温度、または lattice の処理）を特定し、直すか、直せない理由と大きさを記録して、燃料の
温度の軸の内挿の方式を決める（ADR-0242 の燃料の温度の軸）。

## 経緯
