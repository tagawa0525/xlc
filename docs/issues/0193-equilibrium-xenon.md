# 平衡 Xe のケースの入力と解き方

## 問題

ADR-0216 の案 E1 は、平衡 Xe（Problem 7）を、ミクロ燃焼と同じ σ と収率で I-135 と Xe-135 の生成と消滅が釣り合う数密度を core が
解いて求めると決めた。core のミクロ燃焼（#0153）は燃焼のケース（`[depletion]`）の中だけにあり、燃焼のないケースの状態（`[state.<名前>]`）は
ノードの組成を持たない。平衡 Xe のケースは次を決めないと入力の形が決まらないので、ミクロ燃焼のブランチでは入れなかった:

- 組成の出所: 新しい燃料（テーブルの燃焼度 0 の数密度）か、燃焼の履歴の点のノードの組成か
- Xe 以外の追う核種の補正: 平衡 Xe のケースで、Xe-135 と I-135 だけを公称の履歴の数密度から変えるか
- 解き方: ノードの中性子束と平衡の数密度の固定点（臨界ホウ素の探索の中か外か。ADR-0145、ADR-0191）
- 燃焼のケースで平衡 Xe を選べるようにするか（燃焼のステップは Xe を時間で追うので要らないはず）

関係する ADR: ADR-0216、ADR-0218、ADR-0219

## 完了の条件

- 入力の形と固定点の解き方を決め（ADR）、Problem 7 の平衡 Xe の状態を解ける

## 経緯

- 2026-10-29: core のミクロ燃焼（feat/0153-core-micro-depletion）の入力は `[depletion] micro = { chain = … }` だけにし、平衡 Xe の項目は
  受けない（`MicroEntry` は知らない項目をエラーにする）
- 2026-10-29: core の燃焼に崩壊だけのステップ（`decay-days`）と出力の割合が入った（ADR-0218）。燃焼のステップは Xe-135 と I-135 を時間で追い、
  停止の間は崩壊で進めるので、燃焼のケースに平衡 Xe は要らない（この issue の 4 つ目の問いは「選べるようにしない」の見込み）。平衡 Xe の
  入力（Problem 7）は崩壊だけのステップと別で、この issue に残る
- 2026-10-29: 小さな炉心の燃焼（examples/depletion/verification.md の「ステップの大きさの誤差と中点の臨界ホウ素（小さな炉心）」）で、制御棒を抜いた後と
  停止の後に、ステップを 16 個に分けてもステップの大きさの誤差が縮まず、停止の後は軸方向の出力の偏りが点ごとに互い違いに振れた（#0200）。
  原因が Xe を時間で追う中点の形なら、燃焼のケースで平衡 Xe を選べるようにしない見込み（上の 4 つ目の問い）を見直す
- 2026-10-30: 上の 4 つ目の問いの見込み（燃焼のケースに平衡 Xe は要らない）は外れた。小さな炉心の燃焼で Xe を時間で追うと、細かいステップで
  軸方向の振動が育ち、ステップの幅で値が変わる（#0200）。燃焼のケースは `micro` の `xenon = "equilibrium"` で、中点と出力のステップの終わりの点の
  Xe-135 と I-135 を解の平衡にする（ADR-0219。ノードの平衡の式は `MicroChain::equilibrium`、固定点は Anderson の加速）。残るのは燃焼のない
  ケースの状態（Problem 7）の入力と組成の出所で、解き方は ADR-0219 の固定点を使える
