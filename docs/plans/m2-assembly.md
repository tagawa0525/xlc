# M2 集合体計算

## 目的

M1 までの格子計算は、無限希釈の断面積でピンセルを1つ解くだけである。M2 では、17×17 の PWR 燃料集合体を
2D MOC で解き、燃料の共鳴の自己遮蔽を入れる。集合体の均質化した2群定数と、ピンごとの出力分布を出す。

## 検証の対象

- C5G7（2D）: 7群の巨視的断面積が与えられたベンチマーク。自己遮蔽を含まないので、MOC の形状・トラッキング・
  真空境界・反復解法だけを検証できる
- VERA Problem 1B〜1D（ピンセル）と 2B〜2D（17×17 集合体、毒物なし）: 減速材と被覆管は 600 K、
  燃料は 600, 900, 1200 K。この温度はすべて M1 のライブラリにある。565 K の 1A, 2A は、
  H in H2O の S(α,β) に 565 K がないので対象にしない
- 参照解は OpenMC で手元に作る。ENDF/B-VIII.0 から手元の NJOY で連続エネルギーのデータを作り、
  同じ組成・同じ温度で計算する。核データの違いを除き、手法の誤差だけを取り出すためである。
  VERA の公開値（KENO-VI、ENDF/B-VII.0）とも比べるが、核データの差を含むので参考とする
- OpenMC は検証にだけ使う外部ツールとし（全体計画のとおり）、ソースから `references/` にビルドする

## 決めたこと

### 材料

- 被覆管は Zircaloy-4 の組成どおりに Zr, Sn, Fe, Cr を含める。VERA と同じ組成で比べるため、
  M1 で後回しにした Sn（10 同位体）, Fe, Cr を核データ処理に追加する。Hf は個数密度が 1e-6 /(barn cm)
  未満と微量なので除く（OpenMC の参照解も同じ組成にする）
- ペレットと被覆管のギャップの He は、VERA の仕様どおり無視して真空とする
- 減速材は VERA の 1300 ppm のホウ素を含む

### 形状とトラッキング

- 形状は正方格子に並べたセル（同心円で区切ったピンセル、または均質なセル）と、集合体の外周の水ギャップとする。
  ピンセルの領域は、同心円のリングに加えて方位角方向に分割できるようにする。平坦線源の近似の誤差を
  領域の細分で収束させて確かめるため
- トラッキングは、ピンセルで使っている cyclic tracking を集合体全体に広げる（全体で1組のトラック）。
  モジュール単位のトラッキングは、メモリが問題になるまで使わない
- 外周の境界条件は鏡面反射と真空（C5G7 のため）とする

### 反復の加速

- MOC の固有値計算を、ピンセル単位の粗メッシュによる CMFD で加速する。ピンセルで 400 回程度かかる
  べき乗法を 17×17 集合体と 69 群でそのまま回すと、計算時間が実用にならないため
- トラックのスイープはスレッドで並列化する（標準ライブラリの `std::thread::scope`）

### 自己遮蔽

- 等価原理とする（全体計画のとおり）。燃料の各核種の背景断面積 σ0 を、他の核種の断面積と、
  Dancoff 係数を入れた燃料の脱出断面積（Carlvik の2項有理近似）から求め、ライブラリの σ0 ごとの
  断面積を補間する。σ0 は他の核種の遮蔽された断面積に依存するので、反復で求める
- Dancoff 係数は、燃料を黒体にした固定源の MOC を集合体全体で解き、ピンごとに求める。
  全体計画ではピンセルの衝突確率法としていたが、無限に並んだ同じピンを仮定するので、案内管の隣や
  集合体の端でのピンごとの違いが出ない。集合体の MOC はすでにあるので、それを使う
- 自己遮蔽は燃料の核種にだけ適用し、被覆管と減速材は無限希釈とする。1本のピンの中では σ0 を一様とし、
  ペレット内の半径方向の分布（リム効果）は燃焼を扱う M4 で検討する。共鳴の干渉効果は扱わない。
  これらの近似の影響は、OpenMC との比較で確かめる

### 出力

- 集合体を均質化した2群定数（ピンセルと同じ形式）と、ピンごとの核分裂率の分布を出す。
  ADF とピン出力の再構成用のデータは、炉心側で使う M3 で加える

## 進め方

1. 一般の正方格子の形状、集合体全体のトラッキング、真空境界と、巨視的断面積の入力。C5G7 で検証する
2. CMFD による加速とスレッドによる並列化
3. Zircaloy-4 の核種（Sn, Fe, Cr）の核データ処理
4. OpenMC の準備と、VERA Problem 1B〜1D, 2B〜2D の参照解
5. 自己遮蔽（Dancoff 係数、σ0 の反復、断面積の補間）。VERA Problem 1B〜1D で検証する
6. 17×17 集合体の入力、ピンごとの出力分布、集合体の2群定数。VERA Problem 2B〜2D で検証する
