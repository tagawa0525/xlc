# M2 集合体計算

## 目的

M1 までの格子計算は、無限希釈の断面積でピンセルを1つ解くだけである。M2 では、17×17 の PWR 燃料集合体を
2D MOC で解き、燃料の共鳴の自己遮蔽を入れる。集合体の均質化した2群定数と、ピンごとの出力分布を出す。

## 検証の対象

- C5G7（2D）: 7群の巨視的断面積が与えられたベンチマーク。自己遮蔽を含まないので、MOC の形状・トラッキング・
  真空境界・反復解法だけを検証できる
- VERA Problem 1B〜1D（ピンセル）と 2B〜2D（17×17 集合体、毒物なし）: 減速材と被覆管は 600 K、
  燃料は 600, 900, 1200 K。この温度はすべて M1 のライブラリにある。565 K の 1A, 2A は、
  H in H2O の S(α,β) に 565 K がないので対象にしない
- 参照解は OpenMC で手元に作る。ENDF/B-VIII.0 から手元の NJOY で連続エネルギーのデータを作り、
  同じ組成・同じ温度で計算する。核データの違いを除き、手法の誤差だけを取り出すためである。
  VERA の公開値（KENO-VI、ENDF/B-VII.0）とも比べるが、核データの差を含むので参考とする
- OpenMC は検証にだけ使う外部ツールとし（全体計画のとおり）、ソースから `references/` にビルドする

## 決めたこと

### 材料

- 被覆管は Zircaloy-4 の組成どおりに Zr, Sn, Fe, Cr を含める。VERA と同じ組成で比べるため、
  M1 で後回しにした Sn（10 同位体）, Fe, Cr を核データ処理に追加する。Hf は個数密度が 1e-6 /(barn cm)
  未満と微量なので除く（OpenMC の参照解も同じ組成にする）
- 追加する核種で新しく必要になる ENDF の形式に対応する（全体計画のとおり、対象核種で使われる形式から順に）。
  - Fe-54 と Fe-57 の分離共鳴は R-matrix limited 形式（LRF=7）なので、NJOY RECONR と同じ式で実装する。
    除くと VERA と同じ組成で比べられなくなるため
  - Cr と Sn-120 は離散準位の非弾性散乱（MT51〜90）の出射分布を MF6 の LAW=2, 3 で持つ。
    MF3 だけの離散準位と同じく、Q 値による2体の運動学（重心系で等方）で扱う。LAW=3 は重心系で等方なので厳密で、
    LAW=2 の角度分布を無視するのは、散乱を P0 で扱う M0 からの近似と同じである
- ペレットと被覆管のギャップの He は、VERA の仕様どおり無視して真空とする
- 減速材は VERA の 1300 ppm のホウ素を含む

### 形状とトラッキング

- 形状は正方格子に並べたセル（同心円で区切ったピンセル、または均質なセル）と、集合体の外周の水ギャップとする。
  ピンセルの領域は、同心円のリングに加えて方位角方向に分割できるようにする。平坦線源の近似の誤差を
  領域の細分で収束させて確かめるため
- トラッキングは、ピンセルで使っている cyclic tracking を集合体全体に広げる（全体で1組のトラック）。
  モジュール単位のトラッキングは、メモリが問題になるまで使わない
- 外周の境界条件は鏡面反射と真空（C5G7 のため）とする

### 反復の加速

- MOC の固有値計算を、ピンセル単位の粗メッシュによる CMFD で加速する。ピンセルで 400 回程度かかる
  べき乗法を 17×17 集合体と 69 群でそのまま回すと、計算時間が実用にならないため
- 従来の CMFD は、C5G7 の反射体（熱群の水で Σt h ≈ 4）で振動して収束しない（MPACT でも同じ。
  Li ら, PHYSOR 2020）。拡散係数に θ(Σt h) h を足す optimally diffusive CMFD（Zhu ら, Ann. Nucl.
  Energy 95, 2016 の当てはめ）とする。C5G7 で比べた反復回数は、θ = 1/4（partial current CMFD 相当）が
  15（水のセルを 4×4 に分けると 48）、θ の当てはめが 21（45）、比の線形補間による更新（lpCMFD）が
  25（37）。差の線形補間は中性子束が負になった。式と係数が論文で決まっていて、中性子束が正に
  保たれる平らな更新を選ぶ。細かい分割で反復が足を引っ張るようになったら lpCMFD を見直す
- CMFD の後は、領域の中性子束に加えて、トラックの端の角度中性子束もセルごとの比で更新する。
  境界の角度中性子束は 0 でなく等方な値から始める（0 だと鏡面反射の辺でも漏れがあるように見える）
- トラックのスイープはスレッドで並列化する（rayon）。領域ごとの和は方位角ごとに持ち、方位角の順に足す。
  結果がスレッドの数や仕事の分け方によらず、ビット単位で同じになるようにするため。方位角ごとの
  トラックの長さの和はほぼ等しいので、仕事の量も揃う
- 減衰 1 - exp(-τ) は区間・極角・群ごとに前もって計算した表から読む。スイープはこの表の読み込みで
  メモリの転送速度に頭打ちになるが、その場で exp を計算する方法（2.7 倍遅い）や補間表（2 倍遅い）より
  速いため（C5G7 の小さな版、16 スレッドで比較）。表は区間の数 × 群の数に比例し、17×17 集合体・69 群で
  数 GB になる。メモリが問題になったら見直す
- スレッド数の既定は物理コアの数とする。メモリの転送速度で頭打ちになるスイープでは、1つのコアを2つの
  スレッドで分ける（SMT）とかえって遅くなるため

### Zircaloy-4 の核データ

- 天然の同位体を1つずつ処理して、足りない機能を洗い出した。Fe-54, 57 の分離共鳴の R-matrix limited
  形式（LRF=7）、Cr の MF6 の LAW=3 と対応点の補間（INT=12）、Sn-120 の MF6 の LAW=2、Fe-58 の
  非分離共鳴の LRF=1 の自己遮蔽が要る。Zr と Sn の他の同位体、Fe-56 はそのまま処理できる
- MF6 の LAW=2, 3（2体反応）は、MF4 の離散準位と同じく Q 値の重心系等方の2体反応とする
  （角度分布は使わない。弾性散乱と同じ近似）
- 出射分布の入射エネルギーの補間則は ENDF のとおりに扱う。単位基底（INT=21〜25）は出射エネルギーの
  範囲を正規化して補間する。ふつうの線形（INT=2）は、NJOY は散乱源を滑らかにするため単位基底に
  置き換えるが、ここではファイルの指定どおりにする。対応点（INT=11〜15）は、隣り合う分布の点の数が
  違うと定義できないので、NJOY と同じく単位基底に切り替える（Cr はどの反応もこれに当たる）
- 非分離共鳴の LRF=1 は、LRF=2 と同じ形（パラメータをエネルギーに線形補間）に読み替えて、同じ自己遮蔽の
  計算を使う。Fe-58 は ENDF が非分離共鳴に定めない l=3 の系列を持つ。NJOY（UNRESR, RECONR, PURR）は
  l≥2 を l=2 の透過因子と位相シフトで計算してしまう（UNRESR では l=3 を l=2 にすると7桁一致した）が、
  ここでは分離共鳴と同じ l=3 の剛体球の式を使い、仕様外であることを warn で知らせる。NJOY の値とは
  350 keV で全断面積が 1.5%、捕獲が 42% 違うが、Zircaloy-4 の中の Fe-58 はごくわずかなので影響はない
- 分離共鳴の R-matrix limited 形式（LRF=7）は、Fe-54, 57 が使う範囲だけを扱う: Reich-Moore（KRM=3）、
  幅で与えるパラメータ（IFG=0）、背景の R 行列と位相シフトの指定なし（KBK=0, KPS=0）、電荷のない中性子の
  粒子対（剛体球の透過因子、シフト因子なし）と、消去する捕獲のチャネル。それ以外はエラーにする
  - 捕獲のチャネルは粒子対の中身（光子、MT=102）で見分ける。NJOY は1番目の粒子対を捕獲とみなすが、
    ENDF は順序を定めていない。捕獲の幅は共鳴エネルギーの虚部（E_λ − iΓγ/2）に入れる
  - 断面積は、開いた中性子のチャネルの X = (I − iK)⁻¹K（K = P^½ R P^½）から求める。閾値より下の
    非弾性のチャネルは閉じているので除く。弾性散乱・捕獲・準位ごとの非弾性散乱（MT51〜）を、
    MF3 の背景に足す（NJOY RECONR と同じ）
  - 幅から換算幅への換算は ENDF のとおり、共鳴エネルギーでの透過因子（負の共鳴は |E_λ|）を使う。
    共鳴エネルギーで閉じているチャネルに幅があれば、定義できないのでエラーにする
  - 検証は NJOY RECONR の 0 K のポイントワイズの断面積と比べる。Fe-54, 57 の MT1, 2, 102, 51 は許容誤差（0.1%）の
    中で一致した（Fe-54 の MT51 の閾値のすぐ上の1点だけ、NJOY が閾値を7桁目で1つ上げるために 0.5% 違う）
- 以上で、Zircaloy-4 の天然の同位体（Zr, Sn, Fe, Cr の 23 核種）をすべて処理できる

### 自己遮蔽

- 共鳴の自己遮蔽は、ピンごとの超微細群（UFG）の減速計算で直接求める。調べた方式のうち、評価済みデータだけから
  決まり、λ（IR）や確率テーブルのフィットのような経験的な補正を持たず、計算時間も実用的なもの（MPACT の WSA/CPM、
  nTRACER の PSM、SCALE の CENTRM と同じ系統）
  - 集合体の黒体の燃料の MOC でピンごとの Dancoff 係数を求め、Dancoff 係数が一致するよう外径を決めた円筒の
    等価なセルを作る（燃料、ギャップ、被覆管、減速材のリング）
  - そのセルを、多リングの衝突確率法と、全核種の弾性散乱による減速（重心系で等方、標的は静止）で解く。
    範囲は UFG の重みのライブラリと同じ（熱中性子の区切りから分離共鳴の上端まで）。セルの中の全核種（燃料、
    被覆管の Zr など）の共鳴自身の散乱、共鳴の干渉、リングごとの分布と温度が、近似なしに入る
  - リングごとの中性子束で群定数に縮約する。スカラー中性子束の重みの群定数を MOC で使う誤差（角度の扱いの違い。
    文献では約 −200 pcm）は、同じセルを多群で解いた反応率が UFG と一致するよう求めた SPH 因子で直す
  - ライブラリには、共鳴核種の温度ごとのドップラー拡がりのポイントワイズの断面積（UFG の範囲の全断面積・弾性散乱・捕獲・
    核分裂）を加える
  - UFG の範囲の外（分離共鳴の上端より上の非分離共鳴など）は、ライブラリの σ0 ごとの群定数を、等価なセルの
    Dancoff 係数による等価原理（Carlvik の2項有理近似）の σ0 で補間して使う（σ0 の格子点の間は ln σ0 に線形、
    格子の外はエラー）。この範囲の共鳴は狭く、NR 近似と等価原理がよく成り立つ
  - 検証の参照解として、集合体全体を UFG の MOC で直接解くツールを作る（等価なセルの誤差を、案内管や集合体の端の
    そばのピンで測る）。OpenMC とは、中性子束の重みの群定数と直接比べる（反応率から逆算した σ0 には、上の角度の
    扱いの誤差が混ざる）
- ライブラリの σ0 ごとの群定数の重みは、分離共鳴の範囲で UFG の減速計算から作る（UFG の範囲の外の等価原理と、
  核データの検証に使う）。Bondarenko の重み 1/(σt + σ0)（NR 近似）は、吸収体自身の共鳴散乱を中性子束を減らす
  ものとして扱うため、U-238 の低い共鳴（散乱でのエネルギーの損失が共鳴の幅と同じ程度）で遮蔽を強く見積もる
  （均質な媒質で 21〜25 群の吸収が −9〜−30%。examples/vera/README.md）。NJOY GROUPR の flux calculator と同じく、
  吸収体と背景の減速材の無限の均質な混合物で、背景の散乱は重み関数 w(E) どおりの滑らかなスペクトルを与えるとし、
  吸収体の弾性散乱による減速を積分形の減速方程式 φ(E)(σt(E) + σ0) = σ0 w(E) + ∫ σs(E') φ(E') / ((1 − α)E') dE'
  で解く。手で調整する補正の数表を持たず、評価済みデータだけから決まるので、群構造を変えてもライブラリを
  作り直すだけで済む
  - 計算する範囲は、重み関数の熱中性子の区切り（0.1 eV）以上で最も低い群の境界から、分離共鳴の範囲の上端以下で
    最も高い群の境界まで。群の中で重みの式が切り替わらないので、両者の規格化は群平均に効かない。熱中性子の
    領域では標的の熱運動が効き、静止した標的の減速計算は成り立たないので、その下の中性子束は σ0 によらない
    重み関数とする（NJOY と同じ。燃料の中の熱中性子束のへこみは輸送計算で扱う）。上は Bondarenko の重みのまま
  - 分離共鳴の範囲を持たない核種は Bondarenko の重みのまま
  - 検証は NJOY GROUPR の flux calculator（重み関数の番号を負にする。1e-3 以内で一致）と、OpenMC の均質な無限媒質
  - ライブラリの各核種は、分離共鳴の s 波の散乱半径 a からポテンシャル散乱 4π a² を持つ（Reich-Moore と MLBW は
    l=0 の APL、0 なら AP。R-matrix limited は弾性散乱の l=0 のチャネルの APE）
- 試して採らなかった方式（どちらも方法そのものの限界で、文献でも同じ向きと大きさの誤差が報告されている。
  Gibson の MIT 博士論文 2016 の Table 9.72 と 6.7〜6.8）
  - 等価原理だけで σ0 を求める方式（ピンごと・群ごとの Dancoff 係数と Carlvik の2項有理近似）: UFG の重みの
    ライブラリと組み合わせると、U-238 の共鳴吸収を +4〜6% 多く見積もった（VERA 1B で −1887 pcm。NR の重みの
    ライブラリのときは誤差が打ち消し合って +232 pcm だった）。燃料の中の散乱源を平坦とすることと、有理近似による
  - ESSM（ブランチ `feat/essm` に比較用に残す。main にはマージしない）: NR 近似の固定源の MOC
    Ω·∇ψ + Σ_i (Σa,i + Σp,i) ψ = Σ_i Σp,i / 4π の、ピンの燃料の平均の中性子束 φ から Σb = Σa φ / (1 − φ) とし、
    σ0,R = (Σb − N_R σp,R + Σ_{j≠R} N_j σa,j) / N_R でライブラリを引く（均質な媒質では厳密）。VERA 1B では
    U-238 の σ0 が約 52 b になり（Carlvik は約 46 b）、k が −3080 pcm だった。脱出を群で平均した吸収（燃料は
    光学的に薄い）で評価するが、実際の共鳴吸収の大半は燃料がほぼ黒体になる共鳴のピークで起きるため、脱出を
    大きく見積もる

### 出力

- 集合体を均質化した2群定数（ピンセルと同じ形式）と、ピンごとの核分裂率の分布を出す。
  ADF とピン出力の再構成用のデータは、炉心側で使う M3 で加える

## 進め方

1. 一般の正方格子の形状、集合体全体のトラッキング、真空境界と、巨視的断面積の入力。C5G7 で検証する
2. 全体計画の「ファイルの約束事」への移行（入力を TOML、データファイルを MessagePack、エラーを thiserror と anyhow に）。
   コードが増える前に済ませる
3. CMFD による加速とスレッドによる並列化
4. Zircaloy-4 の核種（Sn, Fe, Cr）の核データ処理（R-matrix limited 形式、MF6 の LAW=2, 3）
5. OpenMC の準備と、VERA Problem 1B〜1D, 2B〜2D の参照解
6. 自己遮蔽（ピンごとの UFG の減速計算、SPH 因子、集合体の UFG の参照解）。VERA Problem 1B〜1D で検証する
7. 17×17 集合体の入力、ピンごとの出力分布、集合体の2群定数。VERA Problem 2B〜2D で検証する
