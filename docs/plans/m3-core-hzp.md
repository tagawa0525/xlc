# M3 炉心 HZP

## 目的

M2 までで、燃料と案内管だけの 17×17 集合体を格子計算で解ける。M3 では、零出力（HZP）の炉心を 3D NEM で解くのに
要る機能を、xs・lattice・core にわたって揃える。対象は VERA Problem 3〜5 の炉心（Pyrex、制御棒、支持格子、
ノズル、炉心板、バッフル、反射体）である。検証は機能ごとに付けるが、進め方の軸は機能の実装とする。

## 決めたこと

### 範囲

- 物質は VERA Problem 3〜5 に要るものに限る: Pyrex、AIC（Ag-In-Cd）、B4C、SS304、Inconel、支持格子、
  シンブルプラグ、計装用シンブル。可燃性毒物（Gd、IFBA、WABA）は燃焼が本題なので M4 で扱う
- 新しい核種は C、Si、P、Ti、Mn、Ni、Ag、Cd、In（同位体ごと）。ENDF/B-VIII.0 の共鳴とエネルギー分布の形式は
  見出しを調べた範囲（2026-10-08）では対応済みのものだけなので、形式を増やす作業は見込まない。実際に処理して
  足りない形式が出たら、そのとき対応する
- 炉心の外の構造は、バッフルと周りの水までを反射体の定数に入れ、バレル、中性子パッド、圧力容器は除く。
  仕様書の付録 J（表 J-1）で、5-2D のバッフルより外の構造の違いは k で数 pcm にとどまり、円筒や扇形の形状を
  格子計算に加える手間に見合わないため
- ENDF/B-VIII.0 には天然の C がなく C-12 と C-13 だけなので、VERA の天然の C の個数密度は天然の存在比で
  2 つに分ける
- 熱水力のフィードバックは扱わない（全体計画のとおり）。燃料・被覆管・減速材の温度は入力で与える

### 565 K の熱中性子散乱

- HZP は 565 K だが、H in H2O の S(α,β) は 550 K と 573.6 K にしかない。xs は両方の温度の熱中性子の散乱行列を
  ライブラリに持ち、lattice が物質の温度で群定数を温度について線形に内挿する。参照解の OpenMC も温度の内挿の
  モードで解く。OpenMC はこのモードで、両側の温度の S(α,β) を温度（kT）の比で確率的に選ぶ（src/thermal.cpp）ので、
  期待値は同じ線形の内挿になり、扱いがそろう。S(α,β) を持たない核種は、xs も OpenMC のライブラリも計算する温度
  （565 K、等温温度係数の 560 K と 570 K）そのもので作り、内挿するのは S(α,β) だけにする
- KENO の値は、仕様書が S(α,β) の温度を補正した値（550 K と 600 K の内挿、または k の補正）を使う。どちらも
  565 K の S(α,β) を内挿で作ったものに当たるため
- S(α,β) の表そのものを温度で内挿する方法は、NJOY にも OpenMC にもないので、参照解と同じ扱いにできない

### 核データ

- MF4 の角度分布（重心系・実験室系、Legendre・表・混合）を xs で読み、散乱行列の P1 以上に入れる。2体の反応に
  加え、エネルギー分布を MF5 で持つ連続的な放出（MT16、17、22、28、91 など。Ag、Cd、In、P、C で使われる）も、
  MF4 の角度分布で P1 以上を入れる。
  M2 では重心系で等方として運動学の分だけを入れており、k の差（断面積の側）の候補の一つで、新しい核種
  （C、Si、Ni、Mn など）の弾性散乱も強い非等方を持つため
- MF6 の角度のデータ（LAW=1 の Kalbach-Mann と Legendre、LAW=2 の Legendre）は入れず、MF6 の中性子の P1 以上は
  0 のままとする（2026-10-08 に、対象の核種で調べて決めた）。角度のデータを持つ MF6 の中性子は、重心系の
  Kalbach-Mann（O-16、B-11、U-234、U-236 の (n,2n) や連続の非弾性散乱、構造材の MT5）と、実験室系の Legendre
  （Si-28 の MT91）だけで、WIMS 69 群の上端 10 MeV より下に入るのは O-16 の (n,nα)（8 MeV 以上）、
  Si-28 の MT91（9.5 MeV 以上）と、微量の U-234, U-236 の反応だけである。重心系で等方な放出（U-235、U-238、Zr
  など）の実験室系の P1 も、重い核では重心の速さが小さくわずか。PWR への影響は無視できる大きさと見込み、
  入射エネルギーの間の単位基底の補間に角度を通す手間に見合わない

### 格子計算

- セルの形を増やす: 中実の棒（シンブルプラグ）、セルの外周の枠（支持格子。VERA と同じく質量を等体積の枠にする）、
  ピンでない長方形の領域（バッフル、反射体の水）。集合体の外の反射体を解くため、格子の幅が場所で違ってよいようにする
  - 格子は、列ごとの幅と行ごとの高さを持つ長方形の格子に一般化する。ピンセルは幅と高さがそのピッチに等しいマスに
    置き、ほかのマスには均質な長方形のセル（小さな長方形に分けられる）を置く。バッフル（2.85 cm）のように
    ピンのピッチに合わない厚さを、近似なしで表すため
  - 集合体の周りの余白（水のギャップ）は特別な領域をやめ、薄い行と列として表す。余白と反射体を同じ仕組みで扱い、
    形状の場合分けを減らすため
  - トラッキングは長方形の範囲の cyclic tracking にし、CMFD の粗メッシュのセルは格子のセルとする（余白の薄いセルで
    加速が乱れるなら、隣のセルと合わせる）
- 出力に、集合体の面ごとの不連続因子（ADF）、ピン出力の再構成用の形状関数、反射体の少数群定数を加える。
  反射体の定数は、燃料の集合体と反射体を並べた格子計算から作る
- 状態の分岐: ホウ素濃度、減速材の温度（と密度）、燃料の温度、制御棒の有無、支持格子の有無を分岐として計算し、
  少数群定数のテーブルにする。燃料の温度を入れるのは、等温温度係数が燃料のドップラーの効果を含むため。
  テーブルは MessagePack で書く。燃焼度の軸を持つ大きな分岐テーブルの形式（HDF5 への移行を含む）は、全体計画の
  とおり M4 で設計し直す。M3 のテーブルは計算し直せば作れるので、作り直しは重くない
- 燃料のピンの UFG の外にある、分離共鳴を持つ核種の領域（支持格子の枠、案内管と計装管の被覆管など）も
  自己遮蔽する。無限希釈のままでは、枠の Zircaloy の吸収を k で約 380 pcm 多く見積もった（1B、OpenMC と比較）。
  全体計画のとおり Bondarenko の表を等価原理の σ0 で引く。領域を黒体にした MOC で、黒体（セルの中で接する、分離共鳴を
  持つ核種の組が同じ物質の領域）の Dancoff 係数と平均弦長（等方な中性子束 1 での入射率 R_iso から
  l̄ = V / R_iso）を求め、黒体の中の物質ごとに燃料と同じ Carlvik の2項有理近似を使う。隣のセルとつながる枠のように、
  露出した面が一部だけの塊にも使えるため。同時に黒体にするのは、核種の組が同じ物質の領域（共鳴が同じエネルギーにあり
  影を作る）で、燃料は SPH 因子を掛けない実効断面積、ほかは無限希釈の全断面積とする（燃料のピンの Dancoff 係数と
  同じ）。組が一部だけ重なる物質（Zircaloy とステンレスの Fe など）の影は入れない。核種ごとに黒体を分けるのが
  正確だが、組の数だけ MOC を解くので、必要になったところで見直す。黒体の中で密度の違う物質（囲まれた薄い層など）も、
  黒体の Dancoff 係数と平均弦長で遮蔽する近似とする
- 影の計算（燃料のピンの Dancoff 係数、等価なセルの外半径、構造材の塊の Dancoff 係数）で、黒体でない物質の
  全断面積は無限希釈の群平均とする。Dancoff 係数は黒体が吸収するエネルギーでの透過なので、原理的には UFG の範囲の
  群で、黒体の吸収率で重みづけした平均 Σ_m,g = ∫ Σt,m g du / ∫ g du（g = Σa,A / (Σt,A + 1/l̄_A)、A は黒体）が
  正しい。これを実装して VERA と比べると、群ごとの差が打ち消し合い、k は数 pcm しか動かなかった
  （examples/vera/README.md）。一方で、燃料の物質ごとに Dancoff 係数の MOC を解くことになり、燃料の物質がピンごとに
  分かれる M4 の燃焼では集合体1つで数百回になる。ポイントワイズの断面積の積分のコードも増えるので、効果に見合わないと判断した。
  この近似の前提は、黒体でない物質の共鳴の大部分が、黒体の共鳴と同じエネルギーにないこと。制御棒の AIC
  （Ag-109 の 5.2 eV の共鳴が U-238 の 6.67 eV の共鳴に近い）は崩れる候補なので、制御棒を入れたところで、
  吸収率の重みの実装（ブランチ feat/dancoff-potential に残す）で再測定する。
  MPACT（ORNL/SPR-2021/2330 の式 9.17–9.18）、HELIOS 系、SCALE/Polaris が使うポテンシャル散乱（λΣp）は、
  上の平均の、共鳴が重ならない極限にあたる。採らないのは、吸収率の重みの平均より Zircaloy を透明にしすぎ、
  共鳴の重なる物質の影も落とすため
- AIC と B4C は光学的に非常に厚い。M2 で、そのような領域では k がトラック間隔に対して不規則に動くことがわかって
  いる（docs/plans/m2-assembly.md）。制御棒のセルを入れたところで影響を測り、必要ならトラックの置き方を見直す

### 炉心計算

- 集合体ごとに違う少数群定数（装荷図）と、軸方向の層（燃料、支持格子、プレナム、ノズル、炉心板、上下の水）を
  入力で与える。ノードの定数は状態（ホウ素濃度、温度、制御棒）でテーブルを内挿する
- NEM に ADF を入れ、CMFD で固有値の反復を加速する（全体計画のとおり、粗メッシュのソルバは lattice と共通の
  クレートのものを使う）
- 制御棒の先端がノードの途中にあるときの扱い（カスピング）と、ピン出力の再構成の方法は、実装の前に文献で
  比べて決める
- 炉心は全体を解く。Problem 5 の制御棒バンク SC と SD は 1/8 対称でなく、鏡面反射の 1/4 炉心では別の配置を
  解くことになるため（仕様書。KENO は 1/4 炉心で解いて −53/−39 pcm を補正している）。NEM なら全炉心でも計算は軽い

### 検証

- 新しい物質の格子計算: VERA 2E〜2K と 2Q（KENO の値）と、同じ核データの OpenMC（連続エネルギー）
- ADF、反射体の定数、NEM: 2D の 4-2D（カラーセット）、REF1-2D（反射体）、5-2D（1/4 炉心）。参照解は OpenMC（2D）と
  KENO の値
- 3D の炉心: Problem 3、4 は OpenMC（3D）と KENO の値。Problem 5（全炉心の零出力試験）は、仕様書の実測値（臨界
  ホウ素濃度、制御棒バンクの価値、等温温度係数）と KENO の値で比べる。3D の全炉心の OpenMC は計算時間が大きいので
  作らない

## 進め方

1. データファイルの型と MessagePack の読み書き、Gauss-Legendre と Legendre 多項式を、形式のクレートと共通の
   計算のクレートに移す（全体計画のとおり、段階の間を渡る型が増える前に行う）
2. 新しい核種の処理と、MF4・MF6 の角度分布の散乱行列への反映
3. 熱中性子の散乱行列の複数の温度と、lattice での温度の内挿
4. セルの形の追加（中実の棒、支持格子の枠、長方形の領域、場所で違う格子の幅）
5. 格子計算の出力（ADF、ピン出力の形状関数、反射体の定数）と状態の分岐のテーブル
6. core: 装荷図と軸方向の層、テーブルの内挿、ADF を入れた NEM、CMFD（粗メッシュのソルバを共通のクレートに切り出す）
7. core: 制御棒の部分挿入、ピン出力の再構成
8. Problem 3〜5 の入力と、炉心の結果のまとめ
