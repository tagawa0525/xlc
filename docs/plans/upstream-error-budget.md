# 本番の結果の誤差を上流から見積もる順

この計画は新しい決定を加えない。数値は書かず、記録と issue を指す。

## 目的

本番の形の結果（Problem 9 に向けた燃焼のテーブルと炉心計算、VERA の検証の数値）の誤差を、核データから炉心計算まで上流から
順に見積もり、大きい順に片付ける。

起こした理由: open の issue が約 200 件たまり、issue が「書けば済み」の出口になって、片付ける作業が計画に入っていなかった
（ユーザー 2026-11-19 の指摘の要約）。同じ日に、本番の結果が拠る測られていない前提を #0293 に一覧にした。この計画は、#0293 の
26 項目と、2026-11-19 の issue の棚卸しで結果に効くとした issue を 1 つの順に並べる。

## 範囲

- 入れるもの: #0293 の 26 項目と「調べ直していない 3 項目」、結果に効く（本番の形の結果の正しさに関わる）open の issue、
  レビューの残りの issue のうち結果に効く指摘
- 入れないもの: 速度、ツール、文書、整理の issue（下の「結果に効かない issue」に番号だけを並べる）。複数の燃料で測り終えた前提
  （#0293 の「確かめてあるもの」）

## 進め方の決まり

上流の項目が「測った」か「許容と認めた」になるまで、本番の形の計算（ライブラリ、燃焼の履歴、テーブル、参照解の作り直し）を
投げない。「許容と認めた」は、測った値を添えてユーザーが認めたものだけにする。上流は、表の順で前の段にあるもの。

作り直しを 1 回で済ませるため、「作り直しの前」の列が「要」の項目は、本番の作り直しの前に「測った」か「許容と認めた」にする
（片付けないと、直したときに作り直しが 2 回になる）。「迷う」は、原因の側によって要るかが変わるもの。

状態は、測った、許容と認めた、測定中（今の担当のブランチがある。ブランチ feat/0279-off-history-comparison は、格子計算が輸送する核種と
ミクロ燃焼で追う核種の範囲を測る新しい issue をそのブランチに持つ）、未測定、のどれか。一部の燃料や集合体だけで測ったものは
未測定とし、測った範囲を「大きさ」の列で指す。
