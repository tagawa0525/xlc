# ADR-0101: 炉心の NEM の真空の面は、格子計算の真空の辺の比 r = J/φ を不均質な中性子束に課し、Marshak の条件は入力で明示したときだけ使う

## 背景

[ADR-0099](0099-couple-core-nodes-by-get-with-vacuum-boundary.md) は、炉心の NEM の面の条件を一般化等価理論（GET）の形で部分中性子流に入れ、外周の真空の面に、
不均質な中性子束 f φ への Marshak の条件（不均質な入射の部分中性子流 0。f φ/4 − J/2 = 0）を課した。これは不均質な面の
中性子束と正味の中性子流の間に P1 の関係 φ_het = 2J を置く。格子計算（MOC）の真空の辺は入射の角度中性子束を 0 とするだけ
で、出ていく角度分布は等方でない。VERA 2B の燃料ピンの n × n の格子（右の辺が真空）では、MOC の右の辺の
φ_het/(2J) は 0.87〜0.95 で、ADR-0094 の ADF を入れた core の1ノードの NEM の k は MOC から +1510〜+3803 pcm ずれた
（examples/vera/verification.md の「真空の辺のある格子の ADF と core の1ノードの NEM」、bc531c7、2026-10-09。#0026）。
右の辺の ADF だけを 2J / 均質な面の中性子束に置き換えると、k は 10⁻⁶ で一致した。

- 定数を作った体系では、core が参照（格子計算の MOC）の k、ノード平均の反応率、面の正味の中性子流を再現すること（GET）
- ADF は GET の定義（不均質な面の中性子束 / 均質な面の中性子束）のまま、どこの面でも同じ意味で使えること
- 黙った既定値を持たず、足りない値はエラーにすること

## 検討した案

- 均質な中性子束 φ に Marshak の条件を課し、外周の面の ADF を使わない: ブランチ `feat/core-adf` で試した（bf9ed9d、
  2026-10-08）。格子計算の真空の境界は不均質な解に課すので、外周の面の ADF が 1 でなければ GET の等価性が崩れる
  （ADR-0099 で採らなかった）
- 不均質な中性子束 f φ に Marshak の条件を課す（ADR-0099）: P1 の関係 φ_het = 2J の分だけ等価性が崩れる（上の
  +1510〜+3803 pcm）
- 真空の辺の ADF を 2J / 均質な面の中性子束と定義し直す: 定数を作った体系では k を再現するが、ADF が辺によって違う
  量になる。同じ辺が core の内側の面に来たとき（隣のノードとの面の条件）に意味を持たない
- 真空の辺の均質な中性子束に対する比 J/φ_hom（= r f）を持つ: core の条件は下と同じになるが、1ノードの NEM の解に
  よる量で、ADF と別に持つ意味がない。r は輸送計算だけで決まり、均質な解の性質（ノードが大きいと均質な面の
  中性子束が負になる。#0027）によらない
- 格子計算の真空の辺の、外向きの正味の中性子流 J と不均質な面の中性子束 φ_het の比 r = J/φ_het（辺にわたる平均の比）
  を、辺と群ごとに少数群定数に持ち、core の真空の面の条件を J = r f φ にする（採用）。Marshak の条件は r = 1/2 の
  場合で、P1 の関係を置くことに当たる

## 決定と理由

### 真空の面の条件

- 格子計算は、真空の辺ごと・少数群ごとに r = J/φ_het を出す。J は MOC の辺の正味の中性子流（`currents`。細かい群の
  和）、φ_het は辺の上の不均質な中性子束（`sides`。細かい群の和）で、どちらも辺にわたる平均である。真空の辺では入射の
  角度中性子束が 0 なので 0 < r ≤ 1（出ていく角度中性子束の μ の平均）。範囲の外はエラーにする
- 少数群定数は r を辺（左、右、上、下）ごとに持ち、真空でない辺（鏡面反射）には持たない。持つ辺は格子計算の真空の辺と
  一致する
- core の外周の面に `vacuum` を選ぶと、その面のノードの物質の、その面に当たる辺の r を使い、不均質な中性子束 f φ と
  正味の中性子流 J に J = r f φ を課す。φ = 2(o + i)、J = o − i から、入射は i = β o、β = (1 − 2 r f)/(1 + 2 r f)。
  定数を作った体系の1ノードでは、f φ は MOC の不均質な面の中性子束になり（ADR-0094 の ADF）、J = r φ_het が MOC の
  正味の中性子流に一致する
- 物質がその辺の r を持たなければエラーにする。z の面は、2次元の格子計算が軸方向の r を出さないので、`vacuum` を
  エラーにする
- 外周がすべて鏡面反射の格子の定数（単一集合体）は r を持たない。そうした定数で外周に真空の面を置くときは、入力で
  `marshak` を選ぶ。`marshak` は r = 1/2（ADR-0099 の条件 β = (1 − f)/(1 + f)、外挿距離 2D/f）で、P1 の関係を
  置くことを入力で明示する。z の面の真空も `marshak` で書く
- r を少数群定数に持つのは、ADF と同じく格子計算の結果で、状態の分岐のテーブルに入れる量になるためである。core が
  格子計算の不均質な中性子束と正味の中性子流を読んで作る形にしない（ADR-0094 の「同じ量を core で計算する」と同じ理由）

### ADR-0099 から引き継ぐもの

[ADR-0099](0099-couple-core-nodes-by-get-with-vacuum-boundary.md) のうち次の決定はそのまま有効で、ここに書き直して含む（ADR の運用。docs/adr/README.md）。変えるのは
真空の面の条件だけである。

- 面の条件は GET（K. S. Smith, Prog. Nucl. Energy 17, 303 (1986)）のとおり、ADF f をかけた不均質な中性子束 f φ と正味の
  中性子流を連続にする。自分の側の ADF を f、隣を f'、出ていく部分中性子流を o、o' とすると、入射は
  i = ((f' − f) o + 2 f' o')/(f + f')。外周の境界と同じ i = β o + 外からの入射 の形で、ノードのバランス式と同時に解く
- 径方向の ADF は少数群定数の辺ごとの値（−x が左、+x が右、−y が下、+y が上）で、軸方向の面は 1 とする（2次元の
  格子計算は軸方向に一様で、軸方向の ADF を出さない）。ADF は少数群定数の必須の値なので、欠けたり正でなかったり
  すればエラーにする。r の辺の対応も ADF と同じ
- 反射（J = 0、β = 1）と中性子束 0（f φ = 0 は φ = 0 と同じ、β = −1）は、GET の条件にしても f によらない
- 横方向の漏れの2次式では、真空（`vacuum` と `marshak`）の面での漏れを、ノードの漏れ × 面の中性子束 / ノード平均と
  する。真空の面のノード平均が正でなければエラーにする
- アルベドの境界は core にない。必要になったら決める

## 確認

- 少数群定数: r の往復、辺の数、群の数、範囲（0 < r ≤ 1、有限）の検査
- core: r = 1/2 の `vacuum` は `marshak` と同じ解（1群の裸の平板の解析解 tan(Bl/2) = f/(2DB) と相対 1e-8）、
  r を変えた裸の平板の解析解（J = r f φ から tan(Bl/2) = r f/(DB)）、r のない物質の `vacuum` と z の
  `vacuum` はエラー。ADR-0099 の確認（ADF の面の条件、2領域の平板と辺の対応の解析解、真空の角の収束）は `marshak` で
  引き継ぐ
- GET の等価性（core の NEM の細かいノードの解を参照にした1ノードの問題）: 参照の真空の面は `marshak`、粗いノードの
  問題は参照から作った r で `vacuum`
- lattice: 真空の辺の r が MOC の辺の正味の中性子流 / 不均質な面の中性子束、鏡面反射の辺は r を持たない
- MOC との比較（examples/vera/verification.md）: VERA 2B の燃料ピンの n × n（n = 3、5、9、右の辺が真空）を core の
  1ノードの NEM で解き、MOC の k を数 pcm 以内で再現する

## 結果

- 定数を作った体系では、真空の辺のある格子でも core が MOC の k を再現する。別の体系（隣の集合体や反射体が違う）では、
  r と ADF の両方が定数を作った体系の値なので、その違いの分だけ誤差が残る
- 燃料が真空に面する 17×17 の集合体では、1ノードの問題の熱群の均質な面の中性子束が負になり ADF を作れない。これは
  r によらず、#0027 で扱う
- 単一集合体の定数（外周が鏡面反射）で裸の炉心を解くには `marshak` が要る。反射体の定数（ADR-0095）は、反射体の外側の
  真空の辺で r を持つ
- 軸方向の真空の面は `marshak` だけで、軸方向の反射体の定数を決めるときに見直す
