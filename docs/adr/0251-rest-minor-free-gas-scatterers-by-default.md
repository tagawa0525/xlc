# ADR-0251: 自己遮蔽の自由ガスの散乱から、散乱の割合が 1e-4 より小さい核種を既定で外し、外さない経路は入力で選ぶ

## 背景

自己遮蔽（ピンごとの UFG の減速計算。ADR-0068）の既定は、S(α, β) の H を除くすべての核種を、ADR-0243 と ADR-0246 の上限より下の
入射で温度 T の自由ガスの散乱核で散乱させる（ADR-0209）。#0286 の 1 ピンの時間の内訳では、減速計算の解の 8 割が自由ガスの散乱源で、
その区間の大半は散乱への寄与の小さい核種のものだった。

入力の項目 `ufg-free-gas.share`（#0286 で足した）は、自由ガスにする核種を散乱の割合で絞る。核種の割合は、その核種の弾性散乱の
反応率を、リングの物質の全体の弾性散乱の反応率で割ったもので、どちらも狭い共鳴の中性子束 1/(Σt E)（Σt はリングの物質の全断面積）を
重みに、その核種の自由ガスの核を使う入射エネルギーの範囲（ADR-0243、ADR-0246 の上限より下）でレサジーについて積分する。どのリングでも
割合が閾値より小さい核種は、自由ガスの代わりに静止した標的（ADR-0070）の散乱核で散乱させる（その核種の散乱で中性子が上方へ
移らなくなる）。S(α, β) の移行を使う核種は外さない。割合は自己遮蔽ごとに、その組成と温度で求める。

## 決定の要因

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。速度のための近似は入力の項目として足し、既定は物理的に正しい方法、
  参照が既定にできなければ参照からの差を測った速い設定（ADR-0209）
- 差の目安は、既に既定にある近似（スイープ 3 回、間引きの許容差）より 1 桁以上小さいこと。k∞ で 0.1 pcm の桁、断面積で相対 1e-5 の桁
- 特定の燃料の種類（未燃焼の標準のウラン燃料など）に合わせ込んだ設定にしない。燃焼した燃料、Gd、MOX でも精度を保つかを確かめてから
  既定にする（ユーザー 2026-11-13）
- 本番の 2A のテーブル（#0278）の時間（既定のまま約 21〜22.5 時間。ADR-0249 の帰結）

## 検討した案

差と時間は #0286 の「項目ごとの速くなる量と今の UFG からの差」（examples/depletion/issue-0286/diff-826-835.json と timing-825.json、
Slurm 825〜835、xlc 625af643c と d821124bf、2026-11-13）。差の最大は、新しいウラン燃料のピンセル（600、900、1200 K）、2A の
40 MWd/kg の組成のピンセル、MOX-1 のピンセル、2A の 60 MWd/kg、Gd の 2O の 10 MWd/kg、Pyrex の 2F の 10 MWd/kg、制御棒を入れて
燃焼させた 2A の 20 MWd/kg の 9 ケースの最大。時間は 2A の 60 MWd/kg の 1 状態の自己遮蔽（32 スレッドの排他のジョブ）。

| 案                   | k∞ の反応度の差の最大 | 2 群の定数の相対の差の最大 | U-238 のリングの捕獲 | 自己遮蔽（2A-60） |
| -------------------- | --------------------: | -------------------------: | -------------------: | ----------------: |
| 外さない（今の既定） |                     0 |                          0 |                    0 |            62.9 s |
| 閾値 1e-4            |              0.03 pcm |                     4.3e−7 |               1.7e−6 |            41.7 s |
| 閾値 1e-3            |              1.05 pcm |                     1.4e−5 |               4.6e−5 |            36.5 s |
| 閾値 1e-2            |              0.50 pcm |                     4.0e−5 |               1.4e−4 |            32.0 s |

- 案 0（外さない。ADR-0209 の今の既定）: 厳密な経路。時間は上のとおり
- 案 4（閾値 1e-4）: 9 ケースの差は k∞ で 0.1 pcm、断面積で 1e-5 の目安の中。自己遮蔽 −34%
- 案 3（閾値 1e-3）: k∞ の差が燃焼した組成で 1 pcm（2A の 40 MWd/kg の組成のピンセル）、断面積の差が 1e-5 を超える。自己遮蔽 −42%。
  既定のスイープ 3 回の近似（−3.0〜−11.9 pcm）よりは小さいが、目安の 0.1 pcm を超える
- 案 2（閾値 1e-2）: 差は閾値に単調でなく（2A の 40 MWd/kg の組成のピンセルで 1e-3 の +1.05 pcm に対し +0.11 pcm）、2 群の定数の差は
  1e-3 の 3 倍。外す核種の効きが打ち消し合った値で、ほかの燃料でも小さい保証がない
- 外す核種の割合の和で閾値を決める形（#0286 の「閾値は核種ごとの割合」）: 作っていない。案 4 の差が目安の中なので要らない

## 決定と理由

案 4 にする。`ufg-free-gas.share` の既定を 1e-4 にし、`share = false` で外さない経路（案 0）を選べるようにする（ADR-0209 の
「決定と理由」の `ufg-free-gas` の既定の行を「## 変更」で直す）。

- CLAUDE.md の「方針」の速度の近似の項のうち、参照からの差を測った速い設定に当たる。案 0 は入力で選べ、案 4 の誤差を測る参照になる
- k∞ の差は、燃焼した燃料、Gd、Pyrex、IFBA、MOX、燃焼の計算（0〜60 MWd/kg）、燃料の温度と減速材の分岐、微分の摂動で 0.065 pcm
  以下で目安の中。少数群定数と数密度の差も 1e-5 の目安の中。ミクロ燃焼の微視的断面積は、静止した標的にした核種の自分の共鳴の
  捕獲で 3 核種が相対 1e-5 を超える（U-234 の 7.5e−5 など。「帰結」）。目安の中に入るのは案 4 だけで、既定の近似のどれより 1 桁以上小さい
- 本番の 2A のテーブルは約 18〜19.5 時間の見込み（帰結）

### 帰結

差の出どころは examples/depletion/issue-0286/coverage-848-854.json（`compare_coverage.py` が coverage/ の出力から書く。Slurm 848 は
ピンセルの燃焼、分岐、微分、854 は集合体の分岐。どちらも `-c 16` の排他でないジョブ、2026-11-13、xlc d06b44cc1（rebase の後は
e13284908）、分岐点は main の dafce36d2）。差は `share = 1e-4` と `share = false` の差で、k∞ は 1/k(false) − 1/k(1e-4):

| ケース                                            | k∞ の差の最大 | 少数群定数 | 数密度（11 核種） | 微視的断面積（31 核種） |
| ------------------------------------------------- | ------------: | ---------: | ----------------: | ----------------------: |
| ウラン燃料のピンセルの燃焼（0〜60 MWd/kg、12 点） |     0.065 pcm |     1.5e−6 |            1.9e−6 |                         |
| MOX-1 のピンセルの燃焼（同じ）                    |     0.030 pcm |     1.1e−6 |            1.3e−6 |                         |
| ウラン燃料の分岐（0、20、40、60 MWd/kg × 4 状態） |     0.050 pcm |     5.7e−7 |                   |        2.0e−5（Cm-244） |
| MOX-1 の分岐（同じ）                              |     0.035 pcm |     3.6e−7 |                   |         7.5e−5（U-234） |
| 微分を解き直す経路（60 MWd/kg、ウラン燃料と MOX） |     0.034 pcm |     4.3e−7 |                   |                  3.5e−6 |
| 2A の 60 MWd/kg（4 状態）                         |     0.045 pcm |     5.8e−7 |                   |                  3.8e−6 |
| Gd の 2O、2P（10、40 MWd/kg）                     |     0.010 pcm |     2.2e−7 |                   |                  2.5e−6 |
| Pyrex の 2F、IFBA の 2M（40 MWd/kg）              |     0.011 pcm |     1.5e−7 |                   |                  2.3e−6 |

- 燃料の温度の分岐（900 → 1200 K）と減速材の分岐の反応度の変化の差は 0.015 pcm 以下（変化そのものは +3〜−1,227 pcm）。リングの
  U-238 の捕獲の差は 4.1e−6 以下。ピン出力の形状関数の差は #0286 の 9 ケースの集合体で 2.7e−7 以下（ピンセルは 1 本で差が無い）
- 相対 1e-5 を超えた微視的断面積は、静止した標的にした核種の、自分の低い共鳴（U-234 の 5.2 eV、Cm-244 の 7.7 eV）の捕獲（1 群の
  速い群）: MOX の 40 MWd/kg の燃料 900 K の状態の U-234 が +7.5e−5（1200 K の状態では割合が 1e-4 を超えて自由ガスに残り −5e−6）、
  同じ状態の U-236 が −1.5e−5（U-236 は自由ガスのまま。5.45 eV の共鳴が U-234 と重なる）、ウラン燃料の 20 MWd/kg の Cm-244 が +2.0e−5。
  閾値をまたぐ核種は、燃料の温度の軸でも微視的断面積に段を作る（U-234 の 900 K と 1200 K の捕獲の差が約 8e−5 ずれる）。k∞ と
  反応度の変化への効きは上の差の中
- ピンセルの燃焼で静止した標的にする核種は、燃焼とともに減るだけで戻らない（ウラン燃料で 0.25 MWd/kg の 69 から 60 MWd/kg の 42、
  MOX で 65 から 41）。ウラン燃料の Pu-239 は 0.25 MWd/kg（最初のステップの中点）だけ、Pu-240 は 2 MWd/kg まで、Pu-241 は 5 MWd/kg
  まで、MOX の U-236 は 10 MWd/kg まで、U-234 は 40 MWd/kg まで静止した標的で、外れる点の前後で k∞ と数密度に段は見えない（k∞ の
  差の最大は 5 MWd/kg の 0.065 pcm で、10 MWd/kg で 0.004 pcm）。U-235、U-238、O-16、H-1 はどのケースでも自由ガスに残り、Xe-135 は
  燃焼したどの状態でも静止した標的になる
- 解き直す微分の経路（`derivative-shielding = "solved"`）でも、外す核種の入れ替わりで微分に段は出なかった（微分を含む微視的
  断面積の差 3.5e−6 以下）
- 本番の 2A のテーブル（#0278）は、自己遮蔽を解く状態に 2A-60 の 1 状態の比を当てて約 18〜19.5 時間（既定のまま約 21〜22.5 時間）。
  比は、同時のピンの移行の重複を直した後（#0286 の Slurm 847、850）の 0.80〜0.81（55.5 → 44.5 秒など）で、直す前の 0.717 は
  本番では 1 度しか作らない移行の区間を含んでいた
- 既定の変更で値が変わるのは、UFG の自由ガスで解く lattice のステージ（`bin/lattice` を deps に持つ 205 ステージのうち、
  `share = false` を書かない入力のもの）。どれも main で既に `bin/lattice` が `dvc.lock` と違い changed なので、このブランチで
  changed になるステージは増えない。作り直す時間は数えていない
- 測っていない: 燃焼した MOX の集合体（履歴が無い）、Gd の集合体の燃料の温度の分岐（ライブラリの H-1 に燃料の温度の格子点が無く
  解けない）、2O、2P、2F、2M の燃焼した状態のピン出力（テーブルに形状関数を書いていない）、制御棒を入れた集合体の燃焼の計算
