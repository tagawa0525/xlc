# ADR-0251: 自己遮蔽の自由ガスの散乱で、どの格子点でも散乱の割合が 1e-4 より小さい核種を既定で静止した標的にし、外さない経路は入力で選ぶ

## 背景

自己遮蔽（ピンごとの UFG の減速計算。ADR-0068）の既定は、S(α, β) の H を除くすべての核種を、ADR-0243 と ADR-0246 の上限より下の
入射で温度 T の自由ガスの散乱核で散乱させる（ADR-0209）。#0286 の 1 ピンの時間の内訳では、減速計算の解の 8 割が自由ガスの散乱源で、
その区間の大半は散乱への寄与の小さい核種のものだった。

入力の項目 `ufg-free-gas.share`（#0286 で足した）は、自由ガスにする核種を散乱の割合で絞る。どのリングでも割合が閾値より小さい核種は、
自由ガスの代わりに静止した標的（ADR-0070）の散乱核で散乱させる（その核種の散乱で中性子が上方へ移らなくなる。核種を計算から除くの
ではなく、吸収と共鳴の断面積は変わらない）。S(α, β) の移行を使う核種は外さない。割合は自己遮蔽ごとに、その組成と温度で、その核種の
自由ガスの核を使う入射エネルギーの範囲（ADR-0243、ADR-0246 の上限より下）で求める。割合の測り方は 2 つある:

- レサジーの積分の比: 狭い共鳴の中性子束 1/(Σt E)（Σt はリングの物質の全断面積）を重みに、その核種の弾性散乱の反応率をリングの物質の
  全体の弾性散乱の反応率で割ったもの（∫ N σs / Σt du ÷ ∫ Σs / Σt du）
- 格子点ごとの比の最大: 範囲の格子点ごとの N σs / Σs（その格子点の散乱源のうち、その核種の散乱から来る割合）の最大

閾値 1e-4 のレサジーの積分の比（#0286 の最初の形）は、燃焼した燃料の分岐で、静止した標的にした重い核種自身の捕獲を相対 1e-5 の目安より
動かした。差は、その核種を静止した標的にした状態だけに、その核種の UFG の範囲の低い共鳴（U-234 の 5.2 eV、Cm-244 の 7.7 eV）の捕獲
（2 群の速い群）に出た（examples/depletion/issue-0286/coverage-848-854.json の燃焼点ごとの微視的断面積の差と、ログの静止した標的の
一覧）。MOX の 40 MWd/kg の U-234 は、燃料 900 K の状態では割合 9.99e−5（閾値のすぐ下）で静止した標的になり捕獲が +7.5e−5 動き、1200 K の
状態では割合が 1e-4 を超えて自由ガスに残り −5e−6 だった（20 MWd/kg は割合 5.9e−5 で +4.2e−5）。ウラン燃料の 20 MWd/kg の Cm-244（割合 2.6e−5）も同じで、静止した標的にした
20 MWd/kg だけ +2.0e−5、自由ガスに残した 40 MWd/kg では 1e-7 の桁だった。共鳴の幅の狭い薄い核種は、共鳴の中ではその格子点の散乱源の
多くを自分の散乱で占めうるが、範囲の全体の積分では割合が薄まり、閾値を下回る。同じ状態の U-236 の −1.5e−5 は、U-236 が自由ガスの
まま、U-234 を静止した標的にした状態だけに出た（5.45 eV の共鳴が U-234 の 5.2 eV の近くにある。経路は確かめていない）。

## 決定の要因

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。速度のための近似は入力の項目として足し、既定は物理的に正しい方法、
  参照が既定にできなければ参照からの差を測った速い設定（ADR-0209）
- 差の目安は、既に既定にある近似（スイープ 3 回、間引きの許容差）より 1 桁以上小さいこと。k∞ で 0.1 pcm の桁、断面積で相対 1e-5 の桁。
  ミクロ燃焼の核種の微視的断面積も同じ目安で見る（静止した標的にする核種そのものの断面積の差。ユーザー 2026-11-13）
- 特定の燃料の種類（未燃焼の標準のウラン燃料など）に合わせ込んだ設定にしない。燃焼した燃料、Gd、MOX でも精度を保つかを確かめてから
  既定にする（ユーザー 2026-11-13）。説明できない定数を入れない
- 本番の 2A のテーブル（#0278）の時間（既定のまま約 21〜22.5 時間。ADR-0249 の帰結）

  標的は 0 MWd/kg の 10 種から 20〜60 MWd/kg の 36〜39 種）。測ったどの燃料と燃焼度でも目安を超えた核種は無く、k∞、少数群定数、燃料の温度と減速材の反応度の変化
  （案 A の 0.015 pcm 以下に対し 0.0029 pcm 以下）の差も案 A の 5〜10 分の 1。ピンセルの分岐で燃料の温度の軸で選び方の入れ替わる核種は Gd-158（ウラン燃料の 20 MWd/kg）だけで、その捕獲の段は 3e−7
- 共鳴のエネルギー、kT、質量で核種を選ぶ形（共鳴の Doppler の幅 √(4 E kT / A) と共鳴の幅を比べ、上方散乱が効く共鳴を持つ核種を残す）:
  作っていない。効くかは共鳴の中の散乱の幅の割合と希釈で決まり、それを分ける閾値は説明できない定数になる。共鳴の幅はライブラリの
  ポイントワイズの断面積に無い（分離共鳴のパラメータを持たない）。案 C は同じ効き（共鳴の中で自分の散乱が占める割合）を断面積から
  直接測る
- 外す核種の割合の和で閾値を決める形（#0286 の「閾値は核種ごとの割合」）: 作っていない。案 C の差が目安の中なので要らない

## 決定と理由

案 C にする。`ufg-free-gas.share` の既定を、閾値 1e-4 の格子点ごとの比の最大（`share = { threshold = 1e-4, measure = "point" }`。
数だけを書けば閾値で、測り方は既定のまま）にし、`share = false` で外さない経路を選べるようにする。レサジーの積分の比
（`measure = "lethargy"`）とアクチニドを残す形（`keep-actinides = true`）は入力で選べる。ADR-0209 の「決定と理由」の `ufg-free-gas` の
既定の行を「## 変更」で直す。

- CLAUDE.md の「方針」の速度の近似の項のうち、参照からの差を測った速い設定に当たる。外さない経路は入力で選べ、案 C の誤差を測る参照になる
- 測った燃料と燃焼度のどれでも、k∞ の差は 0.0077 pcm 以下、少数群定数は 1.3e−7 以下、微視的断面積は 2.5e−6 以下で、目安の中。既定の
  近似のどれより 1 桁以上小さい
- 静止した標的の核の誤差を、どのエネルギーでも散乱源の割合で抑える形で、燃料の種類と核種の種類によらない。案 B はアクチニドだけを
  残し、同じ原因の核分裂生成物を抑えない
- 自己遮蔽の span は案 A の 1.025 倍（2A-60 で 35.8 → 36.7 秒）で、外さない経路の 0.78 倍。1 状態の経過時間は案 A の 1.016 倍
  （48.9 → 49.7 秒）で、外さない経路の 0.83 倍（59.8 秒。どれも Slurm 856）。燃焼した MOX の集合体の 60 MWd/kg の 1 状態では、自己遮蔽が
  外さない経路の 0.72 倍（37.3 → 26.8 秒）、1 状態が 0.79 倍（50.2 → 39.6 秒。Slurm 861、timed の排他、32 スレッド、xlc 4e54ffdf6、
  2026-11-14。timing-861.json）

### 帰結

- 本番の 2A のテーブル（#0278）は約 18.2〜19.7 時間の見込み（既定のまま約 21〜22.5 時間）。自己遮蔽を解く状態（14.85〜16.5 時間）に、
  2A-60 の 1 状態の経過時間の外さない経路からの比 0.81〜0.83 を当てた（同時のピンの移行の重複を直した後（#0286 の Slurm 847、850）の
  案 A の比 0.80〜0.81 に、案 C の案 A からの 1 状態の比 1.016 を掛けた 0.81〜0.82 と、Slurm 856 の案 C と外さない経路の直接の比 0.83）。
  比はどれも 1 状態の経過時間どうし（自己遮蔽の span の比 1.025 は掛けない）。60 MWd/kg の 1 状態の比を全燃焼点に当てた値で、ほかの燃焼点の比は測っていない（ピンセルの燃焼では、
  静止した標的にする核種は燃焼度の低い点ほど多く（案 A で 0.25 MWd/kg の 69 種から 60 MWd/kg の 42 種）、縮みは見込みより大きくも
  小さくもなりうる）
- 既定の変更で値が変わるのは、UFG の自由ガスで解く lattice のステージ（`bin/lattice` を deps に持つステージのうち、`share = false` を
  書かない入力のもの）。どれも main で既に `bin/lattice` が `dvc.lock` と違い changed なので、このブランチで changed になるステージは
  増えない。作り直す時間は数えていない
- 案 A で測った燃焼の計算（ピンセルの 0〜60 MWd/kg）、微分を解き直す経路、Pyrex の 2F、IFBA の 2M、Gd の 2P は案 C で再測定していない。
  案 C は案 A の静止した標的のうち一部を自由ガスに残す（格子点ごとの比の最大は積分の比以上）ので、差は案 A の値（燃焼の k∞ 0.065 pcm、
  数密度 1.9e−6、微分を含む微視的断面積 3.5e−6、2F、2M、2P の微視的断面積 2.5e−6 以下）より小さい見込みで、確かめていない
- 測っていない: Gd の集合体の燃料の温度の分岐（ライブラリの H-1 に燃料の温度の格子点が無く
  解けない）、2O、2P、2F、2M の燃焼した状態のピン出力（テーブルに形状関数を書いていない）、制御棒を入れた集合体の燃焼の計算、
  ペレットの中で組成が違う MOX の集合体（mox-assembly の履歴は燃焼の領域がピンに 1 つ）、MOX の集合体の燃焼の計算（差が積み重なる形）
