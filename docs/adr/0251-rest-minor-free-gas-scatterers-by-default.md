# ADR-0251: 自己遮蔽の自由ガスの散乱から、散乱の割合が 1e-4 より小さい核種を既定で外し、外さない経路は入力で選ぶ

## 背景

自己遮蔽（ピンごとの UFG の減速計算。ADR-0068）の既定は、S(α, β) の H を除くすべての核種を、ADR-0243 と ADR-0246 の上限より下の
入射で温度 T の自由ガスの散乱核で散乱させる（ADR-0209）。#0286 の 1 ピンの時間の内訳では、減速計算の解の 8 割が自由ガスの散乱源で、
その区間の大半は散乱への寄与の小さい核種のものだった。

入力の項目 `ufg-free-gas.share`（#0286 で足した）は、自由ガスにする核種を散乱の割合で絞る。核種の割合は、その核種の弾性散乱の
反応率を、リングの物質の全体の弾性散乱の反応率で割ったもので、どちらも狭い共鳴の中性子束 1/(Σt E)（Σt はリングの物質の全断面積）を
重みに、その核種の自由ガスの核を使う入射エネルギーの範囲（ADR-0243、ADR-0246 の上限より下）でレサジーについて積分する。どのリングでも
割合が閾値より小さい核種は、自由ガスの代わりに静止した標的（ADR-0070）の散乱核で散乱させる（その核種の散乱で中性子が上方へ
移らなくなる）。S(α, β) の移行を使う核種は外さない。割合は自己遮蔽ごとに、その組成と温度で求める。

## 決定の要因

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。速度のための近似は入力の項目として足し、既定は物理的に正しい方法、
  参照が既定にできなければ参照からの差を測った速い設定（ADR-0209）
- 差の目安は、既に既定にある近似（スイープ 3 回、間引きの許容差）より 1 桁以上小さいこと。k∞ で 0.1 pcm の桁、断面積で相対 1e-5 の桁
- 特定の燃料の種類（未燃焼の標準のウラン燃料など）に合わせ込んだ設定にしない。燃焼した燃料、Gd、MOX でも精度を保つかを確かめてから
  既定にする（ユーザー 2026-11-13）
- 本番の 2A のテーブル（#0278）の時間（既定のまま約 21〜22.5 時間。ADR-0249 の帰結）

## 検討した案

差と時間は #0286 の「項目ごとの速くなる量と今の UFG からの差」（examples/depletion/issue-0286/diff-826-835.json と timing-825.json、
Slurm 825〜835、xlc 625af643c と d821124bf、2026-11-13）。差の最大は、新しいウラン燃料のピンセル（600、900、1200 K）、2A の
40 MWd/kg の組成のピンセル、MOX-1 のピンセル、2A の 60 MWd/kg、Gd の 2O の 10 MWd/kg、Pyrex の 2F の 10 MWd/kg、制御棒を入れて
燃焼させた 2A の 20 MWd/kg の 9 ケースの最大。時間は 2A の 60 MWd/kg の 1 状態の自己遮蔽（32 スレッドの排他のジョブ）。

| 案                   | k∞ の反応度の差の最大 | 2 群の定数の相対の差の最大 | U-238 のリングの捕獲 | 自己遮蔽（2A-60） |
| -------------------- | --------------------: | -------------------------: | -------------------: | ----------------: |
| 外さない（今の既定） |                     0 |                          0 |                    0 |            62.9 s |
| 閾値 1e-4            |              0.03 pcm |                     4.3e−7 |               1.7e−6 |            41.7 s |
| 閾値 1e-3            |              1.05 pcm |                     1.4e−5 |               4.6e−5 |            36.5 s |
| 閾値 1e-2            |              0.50 pcm |                     4.0e−5 |               1.4e−4 |            32.0 s |

- 案 0（外さない。ADR-0209 の今の既定）: 厳密な経路。時間は上のとおり
- 案 4（閾値 1e-4）: 9 ケースの差は k∞ で 0.1 pcm、断面積で 1e-5 の目安の中。自己遮蔽 −34%
- 案 3（閾値 1e-3）: k∞ の差が燃焼した組成で 1 pcm（2A の 40 MWd/kg の組成のピンセル）、断面積の差が 1e-5 を超える。自己遮蔽 −42%。
  既定のスイープ 3 回の近似（−3.0〜−11.9 pcm）よりは小さいが、目安の 0.1 pcm を超える
- 案 2（閾値 1e-2）: 差は閾値に単調でなく（2A の 40 MWd/kg の組成のピンセルで 1e-3 の +1.05 pcm に対し +0.11 pcm）、2 群の定数の差は
  1e-3 の 3 倍。外す核種の効きが打ち消し合った値で、ほかの燃料でも小さい保証がない
- 外す核種の割合の和で閾値を決める形（#0286 の「閾値は核種ごとの割合」）: 作っていない。案 4 の差が目安の中なので要らない

## 決定と理由

案 4 にする。`ufg-free-gas.share` の既定を 1e-4 にし、`share = false` で外さない経路（案 0）を選べるようにする（ADR-0209 の
「決定と理由」の `ufg-free-gas` の既定の行を「## 変更」で直す）。

- CLAUDE.md の「方針」の速度の近似の項のうち、参照からの差を測った速い設定に当たる。案 0 は入力で選べ、案 4 の誤差を測る参照になる
- 差は、燃焼した燃料、Gd、Pyrex、IFBA、MOX、燃焼の計算、燃料の温度と減速材の分岐、微視的断面積で目安の中（「確認」）。目安の中に
  入るのは案 4 だけで、既定の近似のどれより 1 桁以上小さい
- 本番の 2A のテーブルは約 17〜18 時間の見込み（帰結）
