# ADR-0133: H in H2O の S(α,β) は評価済みデータの上限まで使い、表の外を短時間衝突近似で補い、その上の H の弾性散乱の移行を自由ガスの核で作る

## 背景

[ADR-0052](0052-scatter-h-in-h2o-by-sab.md) は H in H2O の熱中性子散乱を S(α,β) で扱い、その上限を 4 eV（WIMS 69 群の熱群の上限）とした。
[ADR-0081](0081-use-mf4-angular-distributions.md) は、4 eV 以上の弾性散乱を静止した標的との 2 体反応とした。VERA 1B の k は OpenMC より +295 pcm 高く（#0005）、
均質な無限媒質で H-1 の 27 群（4〜9.877 eV）と 14〜26 群の、群から出る移行が xlc の方が大きいことが原因の大半だった
（examples/vera/verification.md「反応率の比較」、2c7ac7e3、2026-10-11）。参照解の OpenMC は次のとおり扱う（#0005 の一次情報の確認）。

- c_H_in_H2O は `ThermalScattering.from_njoy`（OpenMC 0.15.2）で作る。THERMR と ACER の上限は MF7 MT4 の B(4) = 10.00008 eV で、
  HDF5 の表の上限は 10.0 eV（src/material.cpp は、これより上で S(α,β) を使わない）
- THERMR（NJOY2016 thermr.f90 の `sig`）は、α が表の上限を超えるとき、β が表の外のとき、α A ≥ 30 か β ≥ 30 で補間に使う
  格子点の S が 0 のときに、短時間衝突近似（SCT。MF7 の有効温度を使う）で S を補う。ENDF/B-VIII.0 の H in H2O の表は
  α ≤ 1581、β ≤ 395.26 で、600 K の 70374 個の格子点のうち 19464 個が S = 0
- S(α,β) の上限より上では、H-1 は質量比が 1 未満なので、どのエネルギーでも自由ガス（物質の温度、断面積一定）として
  扱い、重心系の角度分布は MF4 から取る（src/physics.cpp の `sample_target_velocity` は、質量比が 1 より大きい核種だけを
  400 kT 以上で静止させる）

判断の軸:

- 参照解（OpenMC と、そのデータを作る THERMR）と同じ条件にすること
- 評価済みデータと物理の原理で決まり、合わせるための係数を持たないこと。NJOY が誤っていそうなところは真似ない
- 選べる扱いを入力で選べること（[ADR-0122](0122-run-trials-from-committed-inputs.md)）。既定値はこの ADR で決めたものだけにすること

## 検討した案

S(α,β) の上限:

- 4 eV（ADR-0052）: 上のとおり、4〜10 eV で参照解と扱いが違う。1B のピンセルで k の差 +292.6 ± 4.4 pcm（1/A。#0005）
- 10 eV 以下で最も高い群の境界（WIMS 69 群で 9.877 eV）: 群の中で扱いが変わらない。9.877〜10.00008 eV は参照解と違う
- 評価済みデータの上限 B(4)（採用）

表の外（α が表の上限を超える区間と、S = 0 の格子点に接する区間）:

- 0 とする（ADR-0052 の実装）: 上限を 9.877 eV にした試算で、H の S(α,β) の散乱断面積が 8 eV より上で小さく（9 eV で −7.5%、
  9.8 eV で −15%）、27 群の行の和が OpenMC の 1/E 平均より 1.7% 小さかった（#0005、7d628d88）
- 表の外と、S = 0 の格子点に接するすべての区間を SCT で補う: 参照解と違う。α A < 30 かつ β < 30 の S = 0 は、表の中の
  物理的に小さい値で、SCT の前提（短い衝突時間、大きな運動量の移行）が成り立たない
- THERMR と同じ条件の SCT（採用）

S(α,β) の上限より上の H の弾性散乱の移行:

- 静止した標的との 2 体反応（ADR-0081）: 熱運動を落とす。24〜26 群の H の群から出る割合が 0.13〜0.47% 大きく、k を
  H-1・U-235 で +16.8、H-1・U-235・U-238 で +54.4、1B のピンセルで +38 pcm 動かす（#0005 の (d)、7d628d88）
- どのエネルギーでも自由ガスの核（参照解と同じ範囲）: xlc の自由ガスの核は重心系で等方なので、MF4 の非等方を落とす。
  H-1 の MF4 の P1 の係数は 10 eV で −1.2e-8、1 keV で −1.2e-6 とエネルギーにほぼ比例して増え、MeV の群では無視できない
- 自由ガスの核に MF4 の重心系の角度分布を入れる（参照解と同じ）: 標的の速度と重心系の角度の 3 重の積分が要る。上の 2 つを
  切り替えて落とすもの（熱運動の効果と MF4 の非等方）は、切り替えるエネルギーでどちらも小さい（「決定と理由」）
- 自由ガスの核を、熱運動の効果と MF4 の非等方の効果が同じ程度になるエネルギーまで使い、その上は 2 体反応と MF4（採用）

表の中の S の補間:

- THERMR と同じく ln S を 3 点の 2 次式で補間する（thermr.f90 の `terpq`。隣の点との差が 2 を超える区間は線形）: 参照解と
  そろうが、評価済みデータが指定する補間則と違う。600 K の H in H2O の散乱断面積は、同じ表と同じ SCT で、ENDF の補間則より
  3.6 eV で 0.17%、5〜9 eV で 0.22〜0.25% 大きく、1.1 eV で 0.04%、0.05 eV で −0.15% 違う（examples/m1/sab_interpolation.py、
  f93cb849、2026-10-11）
- ENDF の補間則（ln S を α と β について線形。採用）

試して採らなかったもの（#0005。どれも上限を 9.877 eV にし、(a) の SCT を入れた上での試算。7d628d88）:

- (b) UFG のポイントワイズの断面積の H の 4〜9.877 eV を、自由原子の弾性散乱でなく S(α,β) の散乱断面積にする: k は 1 pcm
  以内しか動かない（4〜10 eV で S(α,β) と自由原子の断面積の差が 0.3% 以内のため）。UFG の減速の散乱核は静止標的
  （[ADR-0070](0070-treat-targets-at-rest.md)）のままなので、断面積だけを S(α,β) にしても扱いはそろわない
- (c) 14〜27 群の H-1、U-235、U-238 の行の、群から出る部分を、静止標的・重心系で等方とした割合の UFG の中性子束の重みと
  1/E の重みの比で直す: H-1・U-235 で 0.1 pcm、H-1・U-235・U-238 で −31.5 pcm 動いて OpenMC から離れる（核種ごとには向きが
  逆）。H-1 の 27 群は S(α,β) の範囲で、仮定が合わない

## 決定と理由

S(α,β) を持つ核種の熱領域の扱いを、xs の入力（xs.toml）の核種ごとの項目で選べるようにし、既定値を次のとおりとする。
項目は `thermal` を指定した核種にだけ書ける。

| 項目             | 値                                      | 既定          |
| ---------------- | --------------------------------------- | ------------- |
| `sab-upper`      | `"evaluated"`（MF7 MT4 の B(4)）か eV   | `"evaluated"` |
| `sab-outside`    | `"sct"`（THERMR と同じ条件）か `"zero"` | `"sct"`       |
| `free-gas-upper` | eV（S(α,β) の上限以上）                 | 9118          |

- S(α,β) の上限: 評価済みデータの上限 B(4) とする。評価者が S(α,β) を与えた範囲で、参照解と同じ（10.0 eV との差 8e-5 eV は
  群の中の幅の 2e-5 で、無視できる）。群の境界に合わせる理由はない。xs は群の中で扱いが変わる点を積分の区切りにし、
  全断面積の補正（行の和と弾性散乱の差）は群ごとに足す。eV で与える上限は B(4) を超えてはならない（超えればエラー）
- 表の外: THERMR の `sig` と同じ条件で SCT を使う。α が表の上限を超えるとき（その部分の α の区間）と β が表の上限を
  超えるときと、ln S を補間する区間の両端の格子点のどれかで S = 0 のうち α A ≥ 30 か β ≥ 30 のところ（α, β は表の
  kT0 = 0.0253 eV で測る）。SCT の S は、物質の温度の α, β と、MF7 の有効温度 T_eff で
  S = exp(−(α − |β|)² T/(4α T_eff) − |β|/2)/√(4π α T_eff/T)（THERMR の `sig` の 170 番）。MF7 MT4 の有効温度は、表の外を
  SCT で補うための量で（ENDF-6 の書式の手引き ENDF-102 の 7.4 節。原本は手元になく、THERMR がこの量を SCT の有効温度として
  読むことで確かめた）、表の外の扱いは評価済みデータで決まる。表の中の S = 0 の扱いは書式が決めておらず、参照解に合わせる。`"zero"` は表の外を 0 とし、表が上限までの下方散乱と、表の β の上限までの上方散乱を
  覆うことを確かめる（ADR-0052 の実装。覆わなければエラー）
- 表の中の補間は、ENDF の補間則（ln S を α と β について線形）に従う。補間則を指定したのは評価済みデータなので、THERMR の
  2 次の補間（「検討した案」）を真似ず、違うことを `tracing::warn!` で知らせる
- S(α,β) の上限から `free-gas-upper` まで、H の弾性散乱の移行を、物質の温度の自由ガスの核（断面積一定）を温度に拡げた
  弾性散乱断面積で規格化して作る（S(α,β) を持たない核種の 4 eV 未満と同じ形）。それより上は静止した標的との 2 体反応と
  MF4 の角度分布（ADR-0081）。自由ガスの核の重心系は等方で、MF4 を落とす。2 体反応は熱運動を落とす。熱運動による移行の
  変化は kT/E ほどで下がり、MF4 の P1 の係数は E にほぼ比例して上がるので、両者が同じ程度になるエネルギーで切り替えると、
  落とす効果は最も小さい。H-1 だけの 600 K のライブラリを、自由ガスの上限を S(α,β) の上限（自由ガスなし）と 1 MeV にして
  作り、行を比べた（examples/vera/free-gas-upper、e0029fbd、2026-10-11）。群から出る割合の差は、熱運動の効果の大きい 10 eV〜
  1 keV で −2.1e-3〜−4.9e-6 と E とともに小さくなり、2.2〜5.5 keV の −3.2e-6〜−3.5e-6 を底に、MF4 を落とす効果で 5.5 keV より
  上で大きくなる（0.5〜0.82 MeV で −2.0e-4）。平均の余弦の差は、熱運動で負（0.91〜1.4 keV で −8.1e-5）、MF4 を落とす効果で正
  （0.5〜0.82 MeV で +1.7e-4）で、15 keV の近くで符号が変わる。両方の差の大きい方が最も小さい
  WIMS 69 群の 9.118〜15.03 keV の群（7.1e-6）の下の境界 9118 eV を上限とする。この値の前後（5.5〜15 keV）のどこで切り替えても、
  落とす効果は行で 1.1e-5 以下
- 自由ガスの核の P1 以上は、e^(−β/2) と S(α,β) = e^(−(α²+β²)/(4α))/√(4πα) を別に計算すると、E/kT が約 1400 を超える下方
  散乱で e^(−β/2) が桁あふれする（#0005）。指数をまとめた e^(−β/2) S = e^(−(α+β)²/(4α))/√(4πα) で計算する。SCT も同じく
  e^(−β/2) を指数に入れてから計算する
- UFG のポイントワイズの断面積の H は自由原子のまま、UFG の範囲の下限は 4 eV のままとする（上の (b)）
- S(α,β) を使う核種（H in H2O の H）のほかは、ADR-0052 のとおり熱領域を自由ガスで扱う（ENDF/B-VIII.0 に O in H2O はない）。
  その上限は 4 eV のまま（ADR-0081）。O-16 などを OpenMC と同じく 400 kT まで自由ガスにしても、k は 1B のピンセルで −2.6〜
  −4.5 pcm しか動かなかった（#0005、6e06516f）

ADR-0052 のうち、次はそのまま有効である。

- H in H2O は ENDF の S(α,β)（MF7 の非干渉性非弾性散乱）から散乱行列を作る。S(α,β) の範囲では MF3 の弾性散乱断面積を
  使わず、核そのものが断面積を与える
- 酸素は ENDF/B-VIII.0 に O in H2O がないので、自由ガスのままとする
- S(α,β) の温度の選び方と 565 K の扱いは [ADR-0080](0080-interpolate-sab-in-temperature.md)

ADR-0081 のうち、次はそのまま有効である（弾性散乱の項だけを上のとおり変える）。

- MF4 の角度分布（重心系・実験室系、Legendre・表・混合）を xs で読み、散乱行列に入れる。2 体の反応では、角度分布は出射
  エネルギーも変えるので、P0 の行にも効く
- 弾性散乱: S(α,β) を持たない核種は、4 eV 以上を静止した標的との 2 体反応と MF4 の角度分布、4 eV 未満を自由ガス模型で
  扱う。S(α,β) を持つ核種は上のとおり。MF6 に MT2 があっても、2 体反応と自由ガス（と S(α,β)）で扱う
- 離散準位の非弾性散乱: Q 値による 2 体反応で、MF4 の角度分布を使う。角度分布がなければ重心系で等方とする。MF6 の
  LAW=2, 3 で与えられる準位は [ADR-0082](0082-leave-out-mf6-angular-data.md)
- 連続的な中性子放出反応（MT91, (n,2n) など）: MF6 LAW=1 のエネルギー分布と多重度を使う。重心系で与えられた分布は、
  重心系で等方として実験室系に変換する。MF6 の角度のデータは使わない（ADR-0082）
- エネルギー分布を MF5 で持つ連続的な放出（MT16、17、22、28、91 など）: MF4 の実験室系の角度分布で P1 以上を入れる。
  出射エネルギーと角度は独立とする。重心系の MF4 は、等方なら P1 以上を 0 とし、非等方ならエラーにする

## 確認

テスト: 自由ガスの核の P1 以上が E/kT の大きいところで有限で静止した標的に近づく（`moments_far_above_kt_approach_the_target_at_rest`）、
表の外と S = 0 の格子点を THERMR の条件で短時間衝突近似で補う（`short_collision_time_fills_alpha_above_the_table`、
`short_collision_time_uses_the_effective_temperature`、`short_collision_time_fills_zeros_only_at_large_alpha_or_beta`）、
S(α,β) の上限から自由ガスの上限まで自由ガスで、行の和が弾性散乱断面積（`free_gas_continues_above_the_sab_cutoff`）、
入力の上限の確かめ（`sab_limits_follow_the_input`、`accepts_the_thermal_scattering_limits`、`rejects_bad_thermal_scattering_limits`）。
ADR-0052 と ADR-0081 から引き継ぐテストはそのまま（`reads_incoherent_inelastic_scattering`、`sab_matrix_satisfies_detailed_balance`、
`sab_ignores_mf3_elastic_below_cutoff`、`elastic_angles_move_the_outgoing_energies` など）。

NJOY THERMR との比較（examples/m1/verification.md「S(α,β) の熱中性子散乱（THERMR）」、a5652e6b、2026-10-11）: 293.6 K、上限
10.00008 eV で、行の和の差は最大 2.1e-3、行の形の差は最大 1.1e-2（上限 4 eV で比べた ADR-0052 のときと同じ）。600 K の
4〜9.877 eV の −2.9e-3 の大半は補間の違い（「検討した案」）。

OpenMC との比較（examples/vera/verification.md「均質な無限媒質」「k の差の内訳」。xlc は a5652e6b、OpenMC は 25bcc092、
2026-10-11）。k の差は xlc − OpenMC の、正味の吸収からの 1/A（括弧は k の推定値）で、pcm:

| 体系                    | ADR-0133 の前 | ADR-0133                       |
| ----------------------- | ------------- | ------------------------------ |
| 均質、H-1・U-235        | +63.6 ± 2.3   | −10.6 ± 2.3（−10.3 ± 10.9）    |
| 均質、H-1・U-235・U-238 | +283.2 ± 16.5 | −46.7 ± 16.5（−73.7 ± 23.2）   |
| 均質、O-16 を足す       | +362.5 ± 18.0 | +33.1 ± 18.0（−8.2 ± 23.9）    |
| 均質、すべての核種      | +412.5 ± 16.1 | +115.6 ± 16.1（+130.2 ± 21.3） |
| 1B のピンセル           | +292.6 ± 4.4  | +57.4 ± 4.4（+60.0 ± 6.3）     |

H-1（ピンセルでは水）の 27 群（4〜9.877 eV）の、群から出る移行の比（xlc / OpenMC − 1）は、+1.9〜+2.5% から −0.6〜0.0%
（1B のピンセルの水で +2.40% から −0.05%）になった。どの体系も、OpenMC の 1/A と k の推定値は統計誤差の中で合い、xlc の k と 1/A は 6 桁
まで同じ（バランスが閉じる）。

## 帰結

- 4 eV 未満では静止した自由原子の散乱核が成り立たないので、UFG の範囲の下限は 4 eV のまま（[ADR-0073](0073-store-pointwise-data-in-library.md)）。4 eV〜
  S(α,β) の上限の UFG は、自由原子の断面積と静止標的の散乱核で解く（ADR-0070）
- U-238 の弾性散乱だけ、最も高い群で NJOY と 2e-3 違う（#0009。ADR-0081 から）
- 残る差（均質なすべての核種の媒質で +116 ± 16、1B で +57 ± 4 pcm）の候補（確かめていない）: H（水）の 14〜26 群の、群から
  出る移行が U-238 の強い共鳴の群で 0.3〜0.8% 大きいこと（散乱行列の群の中の重みと共鳴のくぼみのあるスペクトルの違い。1B で
  置き換えると −47 pcm）、O-16 と被覆管の核種を足したときに増える分（UFG の減速計算の散乱核の側）。#0005
- 4〜10 eV の H in H2O の散乱断面積は、THERMR の補間との違いで、参照解より約 0.2% 小さいまま残る（`tracing::warn!` で知らせる）
- 自由ガスの範囲が広がり、散乱行列の 14〜26 群にも上方散乱が入るので、SPH の固定源問題は範囲の中の上方散乱を反復する
- 1C、1D、集合体（2A〜2Q）と、`thermal` を使う他の例（m1、mox、reflector、branches）の記録は、ADR-0133 の前のライブラリの
  値のまま。測り直しは #0070
