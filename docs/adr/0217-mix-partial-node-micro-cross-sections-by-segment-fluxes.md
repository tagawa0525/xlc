# ADR-0217: 部分挿入のノードのミクロ燃焼は、追う核種の微視的断面積を ADR-0127 の区間の中性子束の積分で混ぜる

## 背景

core のミクロ燃焼（[ADR-0216](0216-tabulate-micro-depletion-cross-sections-per-state.md)）は、追う核種の反応率を、テーブルの微視的断面積 σᵢ（状態と燃焼度で内挿した値）×
ノードの少数群の中性子束で作り、その大きさを追う核種の核分裂の出力がノードの出力密度になるように決める。制御棒の先端や棒の中の材料の
境界がノードの中にある部分挿入のノード（[ADR-0127](0127-weight-partially-rodded-nodes-by-axial-fine-mesh-flux.md)）は、制御棒の状態が一様な区間ごとに、層のテーブルを区間の制御棒の値で引いた
定数を持ち、NEM はそれを軸方向の 1D の細かいメッシュの解の区間の中性子束の積分 w_s,G（区間 s、少数群 G）で混ぜた定数で解く。
NEM の解はノード平均の中性子束 φ̄_G しか持たないので、区間ごとの σᵢ,s をどう 1 つの反応率にするかが決まっておらず、core は核分裂の
ある部分挿入のノードのミクロ燃焼をエラーにしている（ADR-0216 の帰結、#0192）。線形の補正 Σᵢ σᵢ,s (Nᵢ − N̄ᵢ⁰) は、区間ごとの定数に
足してから混ぜる（ADR-0216 の実装のまま。区間のテーブルの使い方がノードの位置を持つ）。

Problem 9 のサイクルの燃焼は D バンクを部分挿入で運転するので、炉心の燃焼の前に要る。

判断の軸:

- ADR-0127 との整合: 混ぜた少数群定数の中の追う核種の分（Σᵢ Nᵢ σᵢ）と、ミクロ燃焼の反応率が同じ重みであること（違えば、NEM が解く
  吸収と、燃焼が消す原子の数が食い違う）
- 挿入の割合が 0 と 1 に近づくと、棒のないノードと棒の入ったノードの燃焼に連続につながること（先端の位置に対して滑らか）
- 誤差が、線形の補正の誤差（ADR-0216 の「確認」の測定で輸送の効きの 88〜113%。#0191）より小さいこと
- ノードごとに 1 つの燃焼度と組成を持つ形（[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md)、ADR-0216）を変えないこと

## 検討した案

- 案 M1: ADR-0127 の区間の中性子束の積分 w_s,G で σᵢ を混ぜる（採用）: σ̄ᵢ,G = Σ_s w_s,G σᵢ,s,G / Σ_s w_s,G。反応率は σ̄ᵢ,G × φ̄_G。
  混ぜた定数と同じ重みの線形の平均なので、区間の定数が Σᵢ Nᵢ σᵢ,s を含むとき、混ぜた定数の中の追う核種の分は Σᵢ Nᵢ σ̄ᵢ になり、
  NEM が解く吸収とミクロ燃焼の反応率が同じ重みになる。線形の補正を区間に足してから混ぜる今の形と、混ぜた σ̄ᵢ で補正する形も一致する
  （同じ理由）。区間の境界がノードの面に近づくと、その区間の重みが 0 に近づき、σ̄ᵢ は隣の状態の σᵢ に連続につながる（ADR-0127 の
  「決定と理由」の 2 項と同じ）
- 案 M2: 区間の長さで σᵢ を平均する（区間の中性子束が一様という仮定）: ADR-0127 が少数群定数で採らなかった体積の重みで、棒の入った
  区間の中性子束が低い分、棒の入った区間の σᵢ を大きく数える。少数群定数（中性子束の重み）と重みが違うので、NEM が解く吸収と
  燃焼の反応率が食い違う。ADR-0127 の燃料の列の例で、少数群定数を体積の重みで混ぜた k の差は −14〜−2971 pcm、粗いノードの核分裂率の差は
  5.5〜393%（中性子束の重みは 4.3 pcm、0.7% 以内。examples/core/verification.md、f131a5b8）で、反応率の重みにも同じ程度の差が入りうる
  （ミクロ燃焼の反応率では測っていない）。ケースの `[partial-rods]` の `weighting = "volume"`（比べるためだけの体積の重み）では、
  少数群定数が長さで混ぜるので、案 M1 の重みも、区間の中性子束をノード平均で一様とした積分（長さ × ノード平均の中性子束）になる
- 案 M3: ノードを区間で分けて、区間ごとに組成を持って燃焼させる: 区間はバンクの位置で決まり、棒が動くたびに変わるので、組成は区間
  でなく、ノードの中の軸方向の位置の関数として持つことになる（ADR-0127 が「ノードを先端で分ける」案を採らなかった理由の (4) と同じ）。
  燃焼度とテーブルの N̄ᵢ⁰(u) はノードごとに 1 つ（ADR-0190、ADR-0216）なので、区間ごとの組成とノードの燃焼度で引く N̄ᵢ⁰ の対応が
  崩れ、NEM が解くノードの定数にも区間の組成ごとの補正を入れ直すことになる。ノードの中の組成の軸方向の分布を追う必要は測られていない

## 決定と理由

部分挿入のノードのミクロ燃焼は、区間ごとの微視的断面積（その区間のテーブルの使い方の状態とノードの燃焼度で内挿した値）を、
そのノードの少数群定数を混ぜた重み（ADR-0127 の中性子束の重みでは、定数を最後に作った外側の反復の、区間の細かいメッシュの中性子束の
積分。体積の重みでは区間の中性子束をノード平均で一様とした積分、つまり区間の長さ × ノード平均の中性子束。群ごとに正規化して
混ぜるので、少数群定数は長さで混ぜたものと同じ）で混ぜ、ノード平均の中性子束と掛けて反応率にする（案 M1）。少数群定数と同じ重みで、NEM が解く
吸収と燃焼の反応率が整合し、挿入の割合の極限で一様なノードに連続につながる。

- 混ぜる項目（ADR-0216 の項目ごと）: `total`、`nu_fission`、`fission` と経路ごとの断面積 `reactions` は群の重みで、散乱行列 `scatter`
  は入射の群の重みで混ぜる（少数群定数と同じ。crates/core/src/rods.rs の `mix`）。`thermal_fission`（収率の境界より下の核分裂の割合）は、
  区間のその核種の核分裂率 Σ_G σf,ᵢ,s,G w_s,G で混ぜる（割合は率の比なので、率で混ぜると熱の核分裂率の和を保つ。重みが中性子束の積分なので、
  体積の重みでもスペクトルが入る）。核分裂の有無（`thermal_fission` の有無）が区間で違う核種と、核分裂率の和が正でない核種はエラー
- 公称の数密度 N̄ᵢ⁰ は燃焼度だけの関数で、区間は同じ層のテーブルなので同じ値になる。違えばエラー（推測で一方を選ばない）
- 線形の補正は、今のとおり区間の定数に足してから混ぜる（案 M1 の重みが少数群定数と同じなので、混ぜた σ̄ᵢ で補正する形と同じ）
- ノードの燃焼度と組成は 1 つのまま（ADR-0190、ADR-0216）

## 確認

- 混ぜ方（crates/core/src/rods/tests.rs）: `mixed_micro_cross_sections_take_the_weights_of_the_mixed_constants`（区間の定数が同じ下地に
  Σᵢ Nᵢ σᵢ,s を足したものなら、混ぜた定数は下地に Σᵢ Nᵢ σ̄ᵢ を足したものと相対 1e-13 で同じ。収率の境界より下の割合は熱の核分裂率の和を
  保つ）、`mixing_micro_cross_sections_needs_matching_segments`、`rodded_solutions_return_the_weights_of_their_mixed_constants`（返す重みで
  区間の定数を混ぜると、解いた混ぜた定数と、中性子束の重みはビットで、体積の重みは相対 1e-15 で同じ。体積の重みは区間の長さ ×
  ノード平均の中性子束）
- 燃焼（crates/core/src/depletion/tests.rs）: `partial_node_micro_depletion_approaches_the_uniform_nodes_at_the_insertion_limits`（集合体 1 体の
  2 つのノードの上のノードで、挿入の割合を 0 と 1 から 1e-3、1e-4 離すと、上のノードの捕獲の割合（消えた U-235 あたりの U-236。ノードの出力に
  よらず微視的断面積で決まる）の、棒のないノードと棒の入ったノードの燃焼との相対差は割合のおよそ 1 次で縮み（1e-4 で 1e-4 未満）、最後の
  点の k の差も 1/5 より小さくなる。k と数密度そのものは、ADR-0127 の z の面の不連続因子が 1 からずれる分で、棒の入った側の極限に
  割合 1e-4 で燃焼の前の k に 0.7 pcm、最後の点の出力の割合に 1.7e-5 の差を残す）、`partial_node_micro_rates_weigh_the_rodded_segment_by_its_flux`（半分の挿入で、
  捕獲の割合は棒のないノード < 中性子束の重み < 体積の重み）、`partial_node_micro_depletion_is_monotonic_in_the_insertion`
- 2A の集合体 1 体（examples/depletion/verification.md）: #0196 の後

## 帰結

- core の部分挿入のノードを解く関数（`rods::solve_rodded`）は、混ぜた定数とともに、混ぜた重みをノードごとに返す。ミクロ燃焼は、その
  ノードの点か中点の解の重みで σᵢ を混ぜる
- 核分裂のある部分挿入のノードのミクロ燃焼は、エラーでなく解く。核分裂のない層の部分挿入は、今のまま ADR-0127 がエラーにする（#0030）
- 残る近似: 区間ごとの反応率の違い（棒のある区間とない区間の燃焼の差）は、ノードの中で 1 つの組成に混ぜる。棒が長く同じ位置に
  あると、ノードの中の組成の軸方向の分布が育つが、それは追わない（案 M3）
- 2A の集合体 1 体での確かめは、制御棒を入れた組の微視的断面積つきのテーブルが要り、その格子計算は #0196（履歴からの分岐の
  微視的断面積が、制御棒を入れた格子で履歴の MOC の領域の番号を引く）で止まっている
