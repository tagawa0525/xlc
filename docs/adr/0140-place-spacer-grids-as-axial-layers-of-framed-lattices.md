# ADR-0140: 支持格子は、枠を入れた2Dの単一集合体の格子計算の定数を、炉心の軸方向の層として位置どおりに置く

## 背景

VERA Problem 3〜5 の燃料の高さには、支持格子が 8 つある（仕様書の表 3: 端の 2 つは Inconel-718、1017 g、高さ 3.866 cm、
中間の 6 つは Zircaloy-4、875 g、3.810 cm）。KENO-VI の参照解は、質量を 289 のセルに等しく分けてセルの外周の箱にし、
位置どおりに置く（2Q と同じ）。炉心の計算で、支持格子の高さの定数をどう作り、どこに置くかを決めていない（#0011）。
軸方向の反射体の平板（ADR-0128）は燃料の中の支持格子を入れず、#0011 に任せている。

判断の軸:

- 原理で決まり、手で合わせる係数を持たないこと
- 参照解（KENO-VI、OpenMC）の置き方と比べられること（表 P3-5 の 49 層は、支持格子の高さをそれぞれ 1 つの層にする）
- 入力と段階の数が、問題の数に比べて増えすぎないこと

## 検討した案

- 枠を入れた 2D の単一集合体の格子計算（ADR-0083 の枠のセル、ADR-0086 の構造材の塊の自己遮蔽）で支持格子の高さの
  少数群定数を作り、炉心の設計の軸方向の層として支持格子の位置に置く: 支持格子による燃料の自己遮蔽の変化と、枠の中の
  中性子束のくぼみを格子計算が直接扱う。層の境界が支持格子の上下の端に来るので、炉心の軸方向のノードはその境界を
  含む。支持格子の種類と挿入物の組み合わせごとに格子計算が 1 つ増える
- 支持格子の質量を燃料の高さ全体に薄めて混ぜた格子計算の定数を、燃料の全体に使う（#0011 の経緯にある CASMO-4/SIMULATE-3
  の Palo Verde の扱いの格子計算の側）: 格子計算は 1 つで済むが、支持格子の位置の軸方向の出力のくぼみ（表 P3-5 で
  支持格子の層は隣の層より 3〜5% 低い）を表さない。位置どおりの効果は炉心の計算の側で補正が要り、その補正の量は
  格子計算の外から決めることになる
- 支持格子のない定数に、支持格子の高さで断面積の差分（枠を入れた格子との差）を足す: 結果は 1 つ目と同じ定数になり、
  差分のための形式が増えるだけである

## 決定と理由

1 つ目の案にする。xlc は枠を入れた格子計算ができ（2Q の確認）、支持格子の高さの定数を直接作れるので、薄めた定数と
補正を持つ理由がない。

- 支持格子の高さの格子計算は、支持格子のない格子計算と同じ入力に、すべてのセルの `frame`（厚さは質量 / 密度 / 高さ /
  289 の面積を、ピッチ p の正方形の外周の帯 4pt − 4t² で表すもの）を足したものにする。Inconel-718 の枠は
  0.022452 cm、Zircaloy-4 の枠は 0.024512 cm
- 炉心の設計では、支持格子の上下の端を層の境界にし、その層に支持格子の格子計算の定数を置く。2D の格子計算の定数の
  z の ADF は 1 なので（ADR-0128）、支持格子の層と隣の燃料の層の面の条件は、均質な中性子束の連続になる
- 挿入物（Pyrex の棒、その端栓とプレナム）の端が支持格子の高さにあれば、支持格子と挿入物の組み合わせごとに格子計算を
  作る（3B の下の端の支持格子の高さは、案内管が空、Pyrex の棒の下の端栓、毒物の 3 つに分かれる）
- 軸方向の反射体の平板の燃料には支持格子を入れない（ADR-0128 のまま）。上の端の支持格子（プレナムの高さ）は、平板の
  層の物質に体積で混ぜる（ADR-0128）

## 確認

VERA Problem 3A と 3B の炉心の解を KENO-VI（表 P3-4、P3-5、付録 D）と比べた（examples/vera/verification.md の
「Problem 3 の炉心の計算」、a0951e05、2026-10-13）。k の差は 3A で +84 pcm、3B で +193 pcm。中間の支持格子の層の軸方向の
出力の相対差は 3A で −0.6〜0%、3B で −0.5〜−0.3% で、隣の層と同じ程度（支持格子の高さのくぼみを再現する）。下の端の
支持格子の層（燃料の下端）は 3A で −6.1%、3B で −4.2% と大きく、原因の候補（燃料の端の f*の方法の誤差、平板の
燃料に支持格子を入れないので、下の反射体の f* が炉心の隣の層（Inconel-718 の支持格子）と違う燃料で作られること、
平板の物質の自己遮蔽なし、核データの版）は確かめていない。OpenMC との比較は #0073 の本番の後

## 帰結

- 支持格子の層の定数は、隣の燃料の層と同じ単一集合体のスペクトルで作る。軸方向に隣の層との間の中性子の行き来による
  スペクトルの変化は、炉心の計算の 2 群の拡散が扱う範囲に限られる
- 支持格子の高さの層は 3.8 cm 程度と薄い。炉心の軸方向のノードはその境界を含めて切る
- 支持格子の位置どおりの格子計算と、薄めた格子計算の比較（#0011 の完了の条件のうち、先行事例との比較）は行っていない
