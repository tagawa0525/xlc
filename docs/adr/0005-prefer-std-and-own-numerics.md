# ADR-0005: 依存クレートは標準ライブラリを優先し、数値計算は自前で実装する

## 背景

全体計画の最初の版で、外部のクレートへの依存の方針を決める必要があった。

## 検討した案

- 標準ライブラリを優先し、数値計算は自前で実装する（採用）

## 決定と理由

依存クレートは標準ライブラリを優先する。数値計算（固有値計算、疎行列の反復解法、指数行列）は問題に特化している
ため、自前で実装する。

## 確認

方針で、確かめるテストはない。

## 結果

同じ日に、事実上の標準のクレートを使う方針に改めた（[ADR-0006](0006-use-de-facto-crates.md)）。自前で書いたコードの保守の方が、定番のクレートへの
依存より重いため。
