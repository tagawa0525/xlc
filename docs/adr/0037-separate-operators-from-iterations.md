# ADR-0037: core の NEM と CMFD は、演算子と固有値の反復を分けておく

## 背景

M4 の後に動特性を加える。過渡計算の時間刻みは、即発の核分裂を含む固定源の問題になる。

## 検討した案

- 固有値の反復に演算子を組み込む: 過渡計算で別のソルバが要る
- 演算子と固有値の反復を分ける（採用）

## 決定と理由

core の NEM と CMFD は、演算子と固有値の反復を分けておく。過渡計算の時間刻みは即発の核分裂を含む固定源の問題で、
臨界の近くでは固有値問題と同じく反復の収束が遅いので、同じ CMFD で解くため。

## 確認

構造の約束事で、まだ確かめるテストはない。

## 帰結

粗メッシュのソルバは共通のクレートに置く（[ADR-0003](0003-extract-shared-computation-on-second-use.md)）。
