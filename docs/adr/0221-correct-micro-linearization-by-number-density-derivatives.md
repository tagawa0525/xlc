# ADR-0221: ミクロ燃焼の線形の補正の係数に、自分の数密度による少数群定数の変化を含める

## 背景

[ADR-0216](0216-tabulate-micro-depletion-cross-sections-per-state.md) の線形の補正 Σᵢ σᵢ (Nᵢ − N̄ᵢ⁰) は、2A の隣り合う燃焼度の点の 40 組で、追う 31 核種の組成の差の
輸送の効きの 88.41〜113.43% を再現し、誤差は −171.91〜+95.20 pcm（[#0191](../issues/0191-micro-correction-first-order-error.md)）。誤差を #0191 の 3 つの候補に分けた
（examples/depletion/verification.md の「ミクロ燃焼の線形の補正の誤差の分け方（2A）」。lattice は 8b5e3e65、比較は 5da05e13、2026-10-30）:

- 少数群の重み（自己遮蔽と数密度の差の空間の分布を前の点に固定しても残る、細かい群の中性子束の変化の分）が、誤差の 98.4〜140.2%
  （5 MWd/kg より後の組）と 86.1〜108.6%（前の組）。自己遮蔽の分は −12.49〜+4.45 pcm、空間の分布の分は +0.13〜+11.34 pcm で、5 MWd/kg より
  後の 28 組のうち 23 組では互いに逆の符号
- 5 MWd/kg より後の組の少数群の重みの分は、Pu-240 の数密度の差だけの組成（ほかの核種は前の点、自己遮蔽と空間の分布は固定）の線形の
  補正の誤差と、最大 7.96 pcm の差で同じ（16→18 MWd/kg で −171.72 と −172.58 pcm）。Pu-240 の数密度の +15.02% に対して、Pu-240 の高速群
  （0.625 eV 以上）の σ_t が −5.50% 変わる（熱群は −0.03%）。多群ライブラリの群の構造は 0.95〜1.15 eV を 8 群に分け、UFG の範囲は 4 eV より上
  なので、Pu-240 の 1.06 eV の共鳴の自己遮蔽は、実効断面積でなく MOC の細かい群の中性子束のくぼみとして入る。少数群の σ̄ᵢ が自分の数密度で
  変わる 1 次の項 N̄ᵢ ∂σ̄ᵢ/∂Nᵢ を、σᵢ を固定した補正は表さない（くぼみの大きさは測っていない。測ったのは群の構造と σ_t の変化で、仕組みは候補）。Pu-240 だけの組成の誤差は、Pu-240 の σ の項（16→18 MWd/kg で −248.09 pcm）と、
  それに伴うほかの核種と燃焼させない物質の項（+76.35 pcm）の和で、5 MWd/kg より後の組ではほかの項が Pu-240 の項の 21〜87% を打ち消す
- 5 MWd/kg より前の組では、1→4 MWd/kg の組の少数群の重みの分の 7〜8 割が Pu-240 だけの組成の誤差で、その内訳は Pu-240 の σ の項
  （−2.00〜−19.90 pcm）でなく、ほかの核種と燃焼させない物質の項（+16.59〜+30.67 pcm）。Pu-240 の数密度の差がほかの核種の少数群の σ を
  変える分で、仕組みは確かめていない。燃焼度 0→0.1 MWd/kg の誤差 +95.20 pcm は、
  少数群の重みの分 +103.39 pcm（主な項は U-235 の σ の変化の項 +228.31 pcm）と自己遮蔽 −8.32、空間の分布 +0.13 pcm の和で、Pu-240 によらない
  （Pu-240 だけの組成の誤差は +0.09 pcm）。少数群の重みの分は、Xe-135 と Sm-149 が 0 から生まれて熱群のスペクトルが変わる分が
  候補（確かめていない）

ADR-0215 の残り R は、同じ σᵢ の線形の補正を引いて作るので、この誤差は R に入る。炉心のノードの履歴の差の Pu-240 の相対差（「履歴の効き（2A）」の
2A-density で +2.44〜+5.90%、2A-rods で +10.83〜+24.14%）は、測った組の差と同じ桁（同じ割合が入るかは確かめていない）。

## 決定の要因

- 線形の補正が、輸送で解いた追う核種の分を再現すること（ADR-0216 の判断の軸。再現しない分は R に入り、ADR-0215 の判断の軸は 1 項 5 pcm）
- lattice のテーブルの時間（状態ごとの輸送の回数に比例する）
- 後からテーブルに項目を足すと、本番のテーブルをすべて作り直す（ADR-0033、#0153）

## 検討した案

- 案 D0（今の σᵢ のまま）: 誤差は 5 MWd/kg より後の組で輸送の効きの約 13% まで
- 案 D1（追う核種ごとの数密度の微分）: 追う核種 i ごとに、状態の組成の Nᵢ だけを変えた摂動の輸送を解き、少数群定数（total、scatter、
  nu_fission。すべての核種と物質の分）の変化を ΔNᵢ で割った ∂Σ/∂Nᵢ をテーブルに持ち、線形の補正の係数を σᵢ からそれに替える。Pu-240 の
  分は、Pu-240 の σ の変化の項と、ほかの核種と燃焼させない物質の項（Pu-240 だけの組成の誤差の内訳で、16→18 MWd/kg で −248.09 と
  +76.35 pcm、1→4 MWd/kg の組では後の項が大きい）の両方を含む。31 核種では状態ごとに輸送 31 回を足し、テーブルの時間が約 32 倍
- 案 D2（選んだ核種だけ D1）: 入力で挙げた核種（2A の測定では Pu-240）だけ D1 の微分を持ち、ほかの核種は σᵢ のまま。状態ごとに輸送 1 回を
  足し、テーブルの時間が約 2 倍。測った組の誤差から Pu-240 だけの組成の誤差を引いた残りは、5 MWd/kg より後の組で −0.23〜+14.65 pcm
  （micro/split.json から。D2 がその組成の誤差をちょうど打ち消すとした見込みで、確かめていない）。0→0.1 MWd/kg の組は減らない
- 案 D2c（D2 を中心差分で）: 状態ごとに数密度を ±ε 変えた輸送を 2 回解き、差分の誤差を ε² にする。テーブルの時間は微分のない
  テーブルの約 3 倍（D2 の前進差分は約 2 倍）。前進差分の割合の感度（「確認」）は、ε = 0.1 と 0.05 の誤差の差が 5 MWd/kg より後の組で
  +1.44〜+6.26 pcm で、16→18、18→20、20→22 MWd/kg の 3 組が決めた目安の 5 pcm を超えた（examples/depletion/verification.md の「ミクロ燃焼の
  線形の補正（2A）」の「数密度の微分の係数（ADR-0221）」）。差はどの組も同じ符号で、差分の誤差が ε に比例するなら、ε = 0.1 の前進差分の
  微分との差は差のほぼ 2 倍（16→18 で約 12.5 pcm。外挿で、中心差分は解いていない）。前進差分のまま実装し、中心差分を採るかは決めていない
- 案 D3（一般化摂動）: 少数群定数ごとの一般化随伴を解き、すべての核種の ∂Σ/∂Nᵢ を一度に求める。2 群の total、scatter、nu_fission の
  8 項目で随伴 8 本ほど。今の MOC に一般化随伴の解き方がなく、実装が大きい
- 案 D4（Pu-240 の 1 eV の共鳴を UFG の範囲に入れる）: 共鳴の自己遮蔽が実効断面積に移り、誤差は自己遮蔽の分に移るが、σᵢ を固定した補正が
  数密度への依存を表さないことは変わらないので、補正の誤差は減らない見込み（確かめていない）
- 案 D5（R に任せる。ADR-0215）: R は履歴の分岐の自分の条件で、履歴の変数の差に比例させて足す（ADR-0215 の案 C3）。この誤差は Pu-240 の
  数密度の差に比例し、Pu-240 の差は履歴の変数の組み合わせと燃焼度の内挿の誤差（#0191 の経緯の core のミクロ燃焼）でも生まれるので、
  1 つの変数に比例させた R では表せない場合がある

## 決定と理由

（proposed）案 D2 を採る。入力で挙げた核種（`[history]` に項目を足す。2A では Pu-240）について、状態ごとに数密度を変えた摂動の輸送を
1 回解き、少数群定数の数密度の微分 ∂Σ/∂Nᵢ をテーブルの `micro` に持つ。core の線形の補正と ADR-0215 の R の第 3 項は、その核種の係数を
σᵢ から ∂Σ/∂Nᵢ に替える（ミクロ燃焼の反応率は σᵢ のまま）。

- 測った誤差の 5 MWd/kg より後の分は、Pu-240 の 1 核種の自分の数密度への依存でほぼ決まる（背景）。輸送 1 回の微分は、Pu-240 の σ の
  変化と、それに伴うほかの核種と物質の少数群定数の変化（5 MWd/kg より後の組で Pu-240 の項の 21〜87% を打ち消し、前の組では Pu-240 だけの組成の誤差の 100〜1031% で、Pu-240 の σ の項が逆の符号で一部を打ち消す）をまとめて表す
- D1 と D3 はすべての核種を表すが、時間（D1）と実装（D3）の費用が大きく、測った誤差の大半は 1 核種で決まる
- 微分の核種を入力で選ぶので、ほかの集合体（Gd 燃料、MOX）で別の核種が効けば、テーブルの項目の形を変えずに足せる

実装の前に詰めた 4 項は、次のとおり親のセッションが決めた（ユーザーは、実装の順と未決事項の判断を親のセッションに任せた（ユーザー 2026-10-30 の判断の要約））:

- 摂動の大きさと差分の形: 前進差分。微分の核種 i の数密度を、燃焼の領域のすべてで同じ割合 ε（相対）だけ増やし、
  ∂Σ_G/∂N̄ᵢ = (Σ_G(摂動) − Σ_G(状態)) / (ε N̄ᵢ)（少数群定数の全断面積、νΣf、Σf、散乱行列。すべての核種と燃焼させない物質の分を含む
  格子全体の均質化。N̄ᵢ は ADR-0216 の均質化した数密度）。ε の既定は 0.1（2A の測った組の Pu-240 の差 +15.02%（16→18 MWd/kg）と、
  炉心の履歴の差 +2.44〜+24.14%（背景）と同じ桁）で、入力で変えられる。N̄ᵢ = 0 の燃焼度の点（燃焼度 0 の Pu-240）は、相対の摂動が解けないので
  摂動を解かず σᵢ（ADR-0216 の案 Z1）のまま。決めたときは「Σ = N σ̄(N) の dΣ/dN は N = 0 で σ̄(0)」を理由にしたが、格子全体の微分は
  ほかの核種と物質の少数群定数がその核種で変わる分を含み、N = 0 でも消えない（「確認」。Pu-240 の燃焼度 0 の σ_t 291.92 barn に対し、
  0.1 MWd/kg の微分は 112.21 barn）。この点の扱いは #0206 で決める。前進差分の割合の感度（「確認」）が 5 MWd/kg より後の組で 5 pcm を超えたら、
  中心差分（状態ごとに輸送 2 回）を「検討した案」に数値と一緒に書き、どちらを採るかを決める
- 摂動の輸送の自己遮蔽: 摂動の組成で解き直す（燃料の実効断面積、UFG の範囲の移行、SPH 因子）。どの状態で解くかは `[branches]` の
  `shielding`（ADR-0201）に従い、摂動の組成を公称の組成と同じに扱う（参照から作る状態は、参照の組成も同じ核種を同じ割合で変えた
  摂動の参照で自己遮蔽を解き、ホウ素の軸の物質だけを状態の組成で作り直す）。解き直さなければ、自己遮蔽の分（−12.49〜+4.45 pcm。
  ADR-0215 の目安 5 pcm と同じ桁）が D2 の残りに入る。#0191 の測定用の `shielding-file` を与えた分岐は、自己遮蔽をその履歴の組成に
  固定するので、摂動の参照もその組成のまま
- 解く状態: 公称だけでなく、σᵢ と同じく状態ごと（ADR-0216 と同じ置き場、テーブルの `points` の点ごと）。ADR-0200 で解く格子点だけなので、
  公称でない状態の分は off-nominal の燃焼点だけ増える
- 0→0.1 MWd/kg の組の Xe-135 と Sm-149: 測らない。予測の係数は点 k − 1（燃焼度 0）のもので、燃焼度 0 の Xe-135 と Sm-149 は N̄ᵢ = 0
  なので、上の規則で微分は σᵢ のまま。今の実装では微分の核種に足しても 0→0.1 の組の線形の予測は変わらない（σᵢ の係数の +95.20 pcm の
  まま）。N̄ᵢ = 0 の点の微分は σᵢ と違う（上）ので、D2 で 0→0.1 の誤差を扱えるかは、その点の扱いを決めてから測る（#0206）。0→0.1 の誤差は
  #0191 の候補に残す

### 帰結

- lattice の `[history]` に `derivative`（数密度の微分を持つ核種。`micro` の部分集合で、重ならない名前。省略すると作らない）と
  `perturbation`（摂動の割合 ε。正の有限の値。省略すると 0.1。`derivative` のない入力に書けばエラー）を足した
  （crates/lattice/src/input.rs、crates/lattice/src/history.rs の `HistoryBranches::add_derivatives`）
- テーブルの形式（crates/format の `xlc-table` の `micro`）: 核種ごとの `MicroNuclide` に `derivative`（`total`、`nu_fission`、`fission`、
  `scatter`。単位は σᵢ と同じ barn）を足した。微分を持たない核種はキーを書かず、微分のないテーブルは前とバイトで同じ。微分を持つ核種は
  どの状態でも持ち、群の数と有限の値を確かめる（負の値は持てる）。本番のテーブルはまだない（#0153）
- core（crates/core/src/micro.rs の `correct`）は、微分を持つ核種の全断面積、吸収（微分の全断面積から微分の散乱の行の和を引いたもの）、
  νΣf、Σf、散乱行列の係数を微分に替える。反応率（燃焼行列と出力の規格化）は σᵢ のまま。微分は σᵢ と同じ重みで状態と燃焼度で内挿し
  （crates/core/src/state.rs）、部分挿入のノードでは少数群定数と同じ区間の重みで混ぜる（crates/core/src/rods.rs。ADR-0217）
- テーブルの時間が、挙げた核種 1 つごとに状態の輸送 1 回分（と摂動の参照の自己遮蔽）増える。2A の 1 状態の分岐（`micro/nominal.toml`、41 点）で、
  摂動の輸送（自己遮蔽、MOC、均質化）は 1 状態あたり平均 26.9 秒（ログの `derivative` の 40 行）、状態の輸送を含めた状態ごとの時間は平均
  54.6 秒、全体は 19 分 29 秒（微分なし、Slurm 591）から 37 分 24 秒（Slurm 617）。4 状態の分岐（`branches/branch-2A-micro.toml`、ホウ素の軸の
  参照を再利用する）で、摂動の輸送は平均 16.0 秒（64 回）、全体は 19 分 29 秒（Slurm 592）から 36 分 27 秒（Slurm 619）。どれも割り込まれうる
  ジョブなので目安
- 摂動の組成の自己遮蔽は、微分の核種ごとに別の `BranchShielder` が持つ（公称の状態の参照と混ぜないため）。ホウ素の軸の参照を今の燃焼度の点で
  核種の数だけ余分に持ち、燃焼した燃料の自己遮蔽の記憶（#0045）がその分増える（測っていない）
- ADR-0215 の R の第 3 項も同じ係数を使う（#0190）

  `density_derivatives_are_the_micro_cross_sections_where_the_nuclide_is_absent`（N̄ᵢ = 0 は解かず σᵢ）、
  `density_derivatives_change_with_the_perturbation_like_forward_differences`（ε を 0.02、0.04、0.08 にした微分の変わり方の比が 2 ± 0.2）、
  crates/core の `corrections_take_the_density_derivatives_of_the_nuclides_that_hold_them`、
  `rates_take_the_micro_cross_sections_whatever_the_density_derivatives`、`density_derivatives_take_the_weights_of_the_few_group_constants`、
  `mixed_density_derivatives_take_the_weights_of_the_mixed_constants`
- 「ミクロ燃焼の線形の補正（2A）」の 40 組を Pu-240 の微分の係数で再測定した（examples/depletion/verification.md の「数密度の微分の係数
  （ADR-0221）」。lattice は eda0ff9f、2026-10-30、Slurm 617、618、620）。5 MWd/kg より後の組の誤差は、σᵢ の係数の −171.91〜−3.79 pcm から
  −6.25〜+20.77 pcm になった（絶対値の最大が 171.91 から 20.77 pcm。16→18 MWd/kg は −171.91 → +0.67 pcm）。見込みの −0.23〜+14.65 pcm より
  幅が広く、22→36 MWd/kg で +10.05〜+20.77 pcm と正に残る（σᵢ のままの核種の 1 次の項と Pu-240 の 2 次の項が候補。確かめていない。#0191）。
  5 MWd/kg より前の組は +7.18〜+23.69 pcm（0→0.1 を除く）から −6.51〜+10.12 pcm になり、0→0.1 MWd/kg は +95.20 pcm のまま。
  nominal と置き換えた組成の k の出力は、微分を足す前の測定とバイトで同じ（摂動の輸送は状態の解に入らない）
- 前進差分の割合の感度: ε = 0.05 で同じ組を再測定し、誤差の差は 5 MWd/kg より後の組で +1.44〜+6.26 pcm、前の組で 0.00〜+2.17 pcm。
  5 pcm を超えた組があるので、中心差分を「検討した案」の D2c に書いた。どちらを採るかは決めていない
- Xe-135 と Sm-149 の微分（決定と理由の 4 項目）は、今の N̄ᵢ = 0 の規則では 0→0.1 MWd/kg の組の予測を変えないので測らなかった
- N̄ᵢ = 0 の点: 燃焼度 0 の Pu-240 の係数（σᵢ）は全断面積 291.92、175.64 barn、νΣf 2.19、0.10 barn で、0.1 MWd/kg（N̄ = 5.28e-10）の微分の
  112.21、164.79 barn と −30.46、−54.19 barn、0.25 MWd/kg の 113.25、156.61 barn と違う（`micro/table-nominal.msgpack`、md5 fde256d9）。
