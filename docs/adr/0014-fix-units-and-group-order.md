# ADR-0014: 単位と群の並びを全体で一つに決める

## 背景

段階間のファイルと入力ファイルで、単位と群の並びがそろっていないと、受け渡しで誤る。

## 検討した案

計画には、ほかの単位系を比べた記録はない。

## 決定と理由

- 単位: エネルギーは eV、微視的断面積は barn、長さは cm、温度は K、個数密度は 1/(barn cm)、巨視的断面積は 1/cm
- 群は高いエネルギーから順に並べる（群 0 が最も高い）

## 確認

約束事で、確かめるテストはない（群境界の並びは `bounds_and_sigma0_must_be_descending` で検査する）。

## 結果

なし。
