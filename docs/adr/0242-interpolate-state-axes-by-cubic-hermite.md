# ADR-0242: core はホウ素の軸と、熱水力のあるケースの減速材の軸を密度について、3 次 Hermite で内挿する

## 背景

core は分岐のテーブルの連続の軸（ホウ素、減速材の温度、燃料の温度）を、軸の内挿の変数について隣の 2 点の線形で内挿する
（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)。ホウ素は ppm、減速材は温度、燃料は √T。cut-HDMR の各項の部分格子の中も同じ。[ADR-0200](0200-tabulate-burnup-branches-by-cut-hdmr.md) の「core の内挿」、
crates/core/src/state.rs の `bracket`）。減速材の格子点の状態は IF97 の密度を持ち、軸は温度で内挿する（[ADR-0229](0229-couple-assembly-channels-and-fuel-rods-to-core.md) の案 T1。
ADR-0229 は「T1 の差が結果に効くと分かったら見直す」とした）。

[ADR-0239](0239-tabulate-p9-burnup-branches-on-hfp-grid.md)（proposed）の格子点で、この式の格子点の間の誤差を 2A の直積のテーブルで測ると、内側の格子点を両隣から内挿した誤差は
燃料の 900 K を除くすべての格子点で目安の 5 pcm を超え、本番の間隔の見込みも 60 MWd/kg で減速材のすべての区間などで目安を超えた
（examples/depletion/verification.md の「Problem 9 の格子点の直積（2A）」の「格子点の間の内挿の誤差」）。ADR-0239 の判断の軸は、
格子点の間隔を詰めるかを、この測定の後に決めるとしていた。この ADR は、誤差を目安に入れる方法を軸ごとに決める。

判断の軸:

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。目安は ADR-0200 の |Δρ| ≤ 5 pcm
- 格子点で格子計算の値を返すこと（ADR-0097 の性質）。値が格子点の値の線形結合で、少数群定数のすべての項目に同じ重みを当てられること
  （ADR-0192 と同じ。core の cut-HDMR の組み立てが、軸ごとの格子点と重みの組の積で項を作るため）。範囲の外はエラーで、外挿しない
- 費用: テーブルの格子計算の時間、ライブラリの作り直しの時間、core の内挿の計算量、形式の変更で読めなくなる出力と作り直す時間

## 検討した案

比べ方: 2A の直積のテーブル（ADR-0239 の格子点。Slurm 728 の table-2A.msgpack）で、軸ごとに内挿の変数と方式を変え、内側の格子点の
状態を、その点を除いたその軸の格子点から内挿し、格子点の状態の k∞ と比べた（examples/depletion/compare_grid_interpolation.py、
ステージ `grid-2A`、xlc 4922a278、2026-11-10。テーブルは md5 c171a770 で、燃料は 1 つの物質、重い核種の自由ガスの上限は ADR-0243 の前の
400 kT）。examples/depletion/verification.md の「Problem 9 の格子点の直積（2A）」の「内挿の変数と方式の候補」は、燃料を 5 つの燃焼の領域にし
（ADR-0245）、上限を 31 eV（ADR-0243）にして作り直したテーブル（Slurm 747）の値で、ホウ素と減速材の行の変わりは 0.5 pcm 以内、燃料の行は
格子点ごとの外れが消えて小さくなった（#0274 の「2A の直積のテーブルの作り直し」）。下の表は 728 の値。除いた点の両隣の間隔は本番の約 2 倍なので、測った誤差は本番の間隔の誤差より大きい側の値とみる（確かめていない。下の「確認」）。
値は内側の格子点と 4 つの燃焼点の |Δρ| の最大（pcm）:

| 軸     | 内挿の変数 | 線形  | 3 次 Hermite | 4 点のラグランジュ | 自然 3 次スプライン |
| ------ | ---------- | ----- | ------------ | ------------------ | ------------------- |
| ホウ素 | ppm        | 22.44 | 0.50         | 0.02               | 7.44                |
| 減速材 | 温度       | 93.27 | 29.52        | 15.31              | 52.18               |
| 減速材 | 密度       | 22.80 | 3.24         | 4.14               | 6.33                |
| 燃料   | √T         | 28.11 | 26.36        | 34.33              | 23.36               |
| 燃料   | 温度       | 47.29 | 30.56        | 36.18              | 20.51               |
| 燃料   | ln T       | 45.85 | 25.61        | 31.81              | 27.94               |

3 次 Hermite は各点の傾きを、その点と両隣（端では端の 3 点）の放物線の微分にしたもので、core の燃焼度の軸（ADR-0192）と同じ形
（燃焼度 0 の扱いは無い）。ADR-0192 が比べた方式のうち、PCHIP と Akima は傾きが値に依り、項目ごとに重みが変わるので除き、3 点の
ラグランジュは区間の中点で使う点が切り替わって値が不連続になる（ADR-0192 の案 Q）ので除いた。

### 方法

- 案 G（格子点の間隔を詰める。ADR-0239 の判断の軸が挙げた方法）: 線形の誤差は間隔の 2 乗に比例するとみて（確かめていない）、減速材の
  600〜610 K の見込み 45.37 pcm（60 MWd/kg）を 5 pcm に入れるには間隔を約 1/3（約 3.3 K）にする。ADR-0239 の「費用」の表で、間隔を 5 K に
  するだけで集合体 1 種のテーブルが 5.22 時間から 8.15 時間になり、ライブラリに減速材の物質の核種の温度の点を足して作り直す（ADR-0239 の
  作り直しは Slurm 727 で 2 時間 1 分）。燃料は、格子点ごとの外れ（下の案 V）が間隔を詰めても残る見込みで（#0274。確かめていない）、
  詰める効きが分からない
- 案 V（内挿の変数を変える）: 減速材を密度（ADR-0229 の案 T2）にすると、線形でも最大が 93.27 から 22.80 pcm になる。2 乗の比で本番の
  間隔に縮めると約 5.7 pcm で（確かめていない）、目安の近くに残る。燃料は温度と ln T のどちらも √T より小さくならない
- 案 O（内挿の次数を上げる）: ホウ素は 3 次 Hermite で 0.50 pcm、4 点のラグランジュで 0.02 pcm。減速材は温度のままでは 3 次 Hermite で 29.52 pcm、
  4 点のラグランジュで 15.31 pcm で目安を超える。燃料は、どの方式も、√T、温度、ln T のどれでも 20 pcm を超え、√T と ln T のすべての方式と
  温度の線形を除く方式で格子点ごとの符号が同じ（600、1050 K が正、750、900、1200 K が負）。高速群の吸収が、燃料の温度の格子点ごとに、
  168 の状態のすべてで同じ符号に √T の滑らかな曲線から外れる（#0274）。次数を上げても小さくならないのは、この外れのためとみている
  （確かめていない）
- 案 VO（軸ごとに組み合わせる。採用）: ホウ素は ppm の 3 次 Hermite（0.50 pcm）、減速材は熱水力のあるケースで密度の 3 次 Hermite（3.24 pcm。熱水力の
  ないケースは下の「熱水力のないケースの減速材の軸」）。燃料は案を選べない

### 3 次 Hermite と 4 点のラグランジュ

- 3 次 Hermite（採用）: 値と傾きが格子点で連続で、温度とホウ素の係数（k の微分）が格子点で跳ばない。減速材の密度で 3.24 pcm と、4 点の
  ラグランジュの 4.14 pcm より小さい。core の燃焼度の軸の重み（crates/core/src/state.rs の `burnup_terms` と `slope`）と同じ式で、2 次の
  関数を厳密に再現する
- 4 点のラグランジュ: ホウ素では 0.02 pcm と最も小さいが、傾きが格子点で跳ぶ。減速材の密度の 610 K で −4.14 pcm と、目安の近く。
  減速材の温度では 15.31 pcm と、温度で測った方式の中で最も小さい（熱水力のないケースに採る。下の「熱水力のないケースの減速材の軸」）
- 自然 3 次スプライン: 値が軸のすべての点に依り（ADR-0192 の案 S と同じ）、ホウ素の端に近い 325、1300 ppm で 6.01〜7.44 pcm

### 熱水力のないケースの減速材の軸

core の状態は熱水力のないケースで減速材の密度を持たず（crates/core/src/state.rs の `moderator_density` が格子点の組から内挿する）、
密度を内挿の変数にするには格子点の間のノードの密度が要る。熱水力のあるケースでは、ノードの密度は熱水力の圧力の IF97 の値で、core は
テーブルの格子点の密度が同じ IF97 の値であることを確かめる（ADR-0229 の案 T1 の検査）。

- 案 N1: 熱水力のあるケースだけ密度で内挿し、ないケースは温度のまま（採用）。熱水力のないケースの状態は温度で決まり、格子点の間の
  密度の出どころが無い。温度で内挿する方式は、上の表で 4 点のラグランジュが最も小さい（15.31 pcm）が、どの方式も目安を超える
- 案 N2: テーブルに圧力を持たせ、熱水力のないケースも IF97 の密度で内挿する: 形式が変わり、今のテーブル（VERA の Problem 5、6 など）が
  読めなくなる。熱水力のないケースの格子点の密度は IF97 でないもの（examples/depletion/verification.md の「分岐の自己遮蔽（ADR-0201）」の 565 K、0.743 g/cc など）もある

### 燃料の温度の軸の物理のモデル

燃料の温度への依存は、高速群の共鳴吸収が √T の 1 次（Doppler の共鳴積分の相関）、熱群が T の 1 次に近く、作り直したテーブル（Slurm 747）でも
状態ごとの a + b T^p の p がそれぞれ 0.505〜0.555 と 0.905〜1.250 になる（#0274 の「燃料の温度への依存のモデルと当てはめの式」。値はそこ）。
そのモデルから比べた案:

- 案 F1（√T の 3 次 Hermite で内挿する）: モデルの a + b√T + cT（√T の 2 次式）を厳密に再現し、4 項の当てはめの曲線を真値とみた本番の
  間隔の中点の形の誤差が目安の 1/20 以下。1 点を除いた誤差の大半は、どの方式にも入る温度の点ごとの片寄りで、方式の優劣を決めない
- 案 F2（全部の格子点への最小 2 乗の当てはめ。基底は 1 と √T、それに T か ln T を足した 3 項と、1、√T、T に T^-1/2、ln T、T^1.5 の
  どれかを足した 4 項）: 値は格子点の値の線形結合（射影の行）で、項目ごとに同じ重みを当てられるが、格子点で格子計算の値を返さない
  （判断の軸の ADR-0097 の性質）。1 点を除いた誤差は、4 項で √T の 3 次 Hermite と同じ大きさで、√T の 4 点のラグランジュより大きく、3 項
  では全範囲で形が合わない
- 案 F3（格子点を 4 点か 3 点に減らす）: 測った誤差が 3 点でどの方式も目安を超え、4 点では √T の 3 次 Hermite で目安を超える。4 点の見込みは
  ln T の 3 次 Hermite が小さく、区間の中点の状態で確かめていない

## 決定と理由

core の分岐のテーブルの内挿を、軸ごとに次にする（案 VO、案 N1）:

- ホウ素: ppm について 3 次 Hermite（各点の傾きを、その点と両隣、端では端の 3 点を通る放物線の微分にする。ADR-0192 の燃焼度の軸と同じ
  形で、燃焼度 0 の扱いは無い）
- 減速材: 熱水力のあるケースは、ノードの密度（熱水力の圧力の IF97 の値）について、格子点の密度で同じ 3 次 Hermite（ADR-0229 の案 T2）。
  熱水力のないケースは温度について 4 点のラグランジュ（区間の 2 点とその外側の 1 点ずつ、端の区間は端の 4 点。点が 3 つ以下の軸は
  3 次 Hermite と同じ式）
- 燃料: 今の √T の線形のまま。格子点ごとの外れの原因（#0274）が分かってから決める
- ADR-0239 の格子点は変えない（間隔を詰めない）

2 点の軸は線形、3 点の軸は 3 点の放物線（3 次 Hermite の傾きの式で、どの点も端の 3 点を使う）になる。点が 1 つの軸は今のとおり
その値でだけ引ける。

理由: ホウ素と、熱水力のあるケースの減速材は、格子点を足さずに、本番の約 2 倍の間隔で測った誤差が目安の 5 pcm に入る（0.50 と 3.24 pcm）。案 G は格子計算と
ライブラリの費用が大きいうえ、減速材の線形の誤差を目安に入れるには間隔を約 1/3 にする見込みで、燃料は詰めても外れが残りうる。
3 次 Hermite は、減速材の密度で、燃焼点の最大が 4 点のラグランジュより小さく（3.24 と 4.14 pcm。0 と 0.5 MWd/kg では 4 点のラグランジュの方が
小さい）、傾きが連続で、core に同じ式がある。熱水力のあるケースで密度で内挿すると、定数を引く変数が
ノードの密度（減速材の密度の履歴の変数と同じ IF97 の値）になり、温度で引いたときの密度の食い違い（#0263 の熱水力の燃焼の側）が無くなる。
熱水力のないケースに密度の出どころは無いので、温度のままにし、温度で測った方式のうち最も小さい 4 点のラグランジュ（15.31 pcm。3 次
Hermite は 29.52 pcm）にする（目安に入る方式が無いので、正確さを、傾きの連続と式の共通より先にする。4 点のラグランジュは格子点で
傾きが連続でない）。目安には入らない（帰結）。
ホウ素と熱水力のあるケースの減速材は、3 次 Hermite と 4 点のラグランジュのどちらも目安に入るので、傾きの連続と式の共通で 3 次 Hermite に
する（ホウ素は 4 点のラグランジュの方が小さい（0.02 pcm）が、どちらも目安の 1/10 以下）。燃料は、内挿の変数と方式のどの組も目安に入らず（組ごとの最大は 20.51〜47.29 pcm）、
格子点ごとの外れ（#0274。原因は確かめていない）と方式の誤差を分けられないので、外れの原因が分かるまで方式を選ばない。

### 帰結

- 実装（core の重みの関数と、減速材の軸の変数の選び方。lattice とテーブルの形式は変えない）は次の依頼で行う。実装するときに、ADR-0097 の
  決定（多重線形）と ADR-0200 の「core の内挿」の各項の多重線形、ADR-0229 の案 T1（熱水力のあるケース）を、それぞれの「## 変更」で
  この ADR に合わせる
- 重みの数: 1 つの軸の項が 2 点から最大 4 点になり、2 軸の部分格子の項の角は最大 4 から 16 になる。燃焼の全炉心の短い計算で、少数群
  定数の内挿とミクロ燃焼の補正は全体 106.2 s のうち 9.7 s（[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の帰結、examples/depletion/verification.md の「全炉心（Problem 9 の形）」、29563b884、Slurm 711、timed、2026-11-06）で、角の数に比例するとすれば
  上限で約 4 倍（約 +29 s）。内訳は測っていない（#0250）
- 重みは負になりうる（3 次 Hermite と 4 点のラグランジュの外側の点）。core の負の重みの示唆（`causes`）は今は燃焼度の軸と cut-HDMR の組み立てだけを見るので、
  状態の軸の負の重みの扱いは実装で決める
- bin/core が変わるので、core を使うステージ（examples/vera の Problem 5、6 など、examples/depletion の core の燃焼）が changed になり、結果が
  変わる。記録は実行したコミットのまま残し、再実行は読む作業が来たときにする（CLAUDE.md の「計算」）。テーブルの形式は変わらないので、
  読めなくなる出力は無い
- 燃料の温度の軸は、測った格子点の誤差が 28.11 pcm（線形、1050 K、60 MWd/kg）のまま残る。#0274 で原因を調べる（原因は ADR-0243 で直し、作り直したテーブルの Slurm 747 では線形で 7.71 pcm（1200 K、60 MWd/kg）。方式の推しは #0274）
- 熱水力のないケースの減速材の軸は、測った格子点の誤差が 15.31 pcm（4 点のラグランジュ、610 K、60 MWd/kg）で目安を超えたまま残る。
  Problem 9 は熱水力のあるケースで、熱水力のないケース（HZP の確認など）の本番の誤差の大きさは、そのケースの格子点で測る（#0176 の
  「格子点の間の内挿の誤差」の残り）
- 残るもの: 本番の間隔の誤差、軸の端の区間（ホウ素 0〜325、1300〜1625 ppm、減速材 560〜570、610〜615 K）、2 つ以上の軸が格子点の間に
  ある状態、2A 以外の集合体の種類、燃焼度の 4 点の間（下の「確認」）

### 確認

- 候補の比べ方のテスト（examples/depletion/test_compare_grid_interpolation.py）: 3 次 Hermite が 2 次の関数を、4 点のラグランジュが 3 次の
  関数を厳密に再現すること、自然 3 次スプラインが scipy の自然境界の 3 次スプラインと同じ値になること、密度と ln T の変数がその変数の
  1 次の関数を厳密に再現すること、線形の方式の値が core の式の値（`centers`）と同じこと、点の足りない方式、知らない軸と変数と方式、密度の無い軸の密度、0 以下の点を持つ軸の
  ln、温度とともに下がらない密度を止めること
- 測った値: 上の「検討した案」の表（Slurm 728 のテーブル、xlc 4922a278、分岐点 074410bc、2026-11-10。作り直したテーブルの値は examples/depletion/verification.md の「内挿の変数と方式の候補」、xlc 8d6c3ffc、分岐点 3a52e2c9、2026-11-11）
- 測っていないこと: 本番の間隔の誤差。除いた点の両隣は本番の約 2 倍の間隔で、3 次 Hermite の誤差は間隔の 3 乗の桁で小さくなる見込み
  （確かめていない）。測るには、ホウ素と減速材の区間の中点の状態（減速材はライブラリにその温度の点が要る。ADR-0239 の背景）を解き、
  実装した core の内挿と比べる。2 つ以上の軸が格子点の間にある状態と、2A 以外の集合体の種類も同じ形で測る
