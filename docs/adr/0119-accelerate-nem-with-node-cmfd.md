# ADR-0119: 炉心の NEM を、ノードを粗メッシュとし NEM の正味の流れで補正する CMFD で加速する

## 背景

炉心の固有値は非線形 CMFD で加速すると決めた（[ADR-0028](0028-accelerate-core-with-nonlinear-cmfd.md)）が、粗メッシュの
単位、補正の求め方、不連続因子と外周の扱い、許容誤差、既定値は決めていない。粗メッシュの固有値問題のソルバは、core が
使う時点で lattice と共通のクレートに切り出す（[ADR-0003](0003-extract-shared-computation-on-second-use.md)）。

- 加速の有無で、解が NEM の判定の範囲で同じになること
- 反復の回数が減ること
- lattice の CMFD の結果を変えずに、固有値問題のソルバを共有すること

## 検討した案

- 粗メッシュの単位
  - 案 A（採用）: NEM のノードをそのまま粗メッシュのセルにする。ノードは集合体か、それを分けた大きさ（ADR-0108）で、
    すでに粗い。未知数はノードの数 × 群の数
  - 案 B: 複数のノードをまとめた粗いメッシュ。均質化の手順が加わり、NEM のノードの間の流れを粗い面にまとめる必要がある。
    今の問題の大きさ（Problem 5 でも数千ノード × 2 群）では、案 A の連立方程式で足りる
- 補正の求め方
  - 案 C（採用）: NEM の全体のスイープで求まった面の正味の流れ J から、面ごとに D̂ を決める（lattice の MOC の CMFD と同じ形）。
    NEM が高次の解き方、CMFD が加速の役になる
  - 案 D: 2 ノードの NEM の問題で D̂ を決める（Smith の非線形反復）。xlc の NEM は部分中性子流でつないだ全体のスイープで、
    面の流れはすでに求まっているので、2 ノードの問題を別に組み立てる必要がない
- 不連続因子と外周
  - 案 E（採用）: 有限差分の結合係数 D̃ に ADF と外周の条件を入れる（下）。D̂ は D̃ からのずれだけを補うので小さく、
    反復が安定する
  - 案 F: D̃ を ADF なしの拡散係数で作り、ADF の効果をすべて D̂ に入れる。収束した解は同じだが、ADF の大きい面
    （反射体との面）で D̂ が大きくなり、粗メッシュの行列の対角優位が崩れうる

## 決定と理由

- **粗メッシュ**: NEM のノード（案 A）。CMFD の未知数はノード × 群の平均中性子束
- **結合**: 方向 d の面で接するノード n（- 側）と m（+ 側）の群 g について、面の正の向きの正味の流れを
  J = D̃ (f_n φ_n − f_m φ_m) + D̂ (φ_n + φ_m) と書く。f はそれぞれの側の ADF（`Core::adf`、f* を含む）。
  D̃ は、ノードの中を平坦な中性子束とした有限差分で、a = 2 D_n / h_n、b = 2 D_m / h_m として
  D̃ = a b / (a f_m + b f_n)（面で f φ_s が連続、J = a (φ_n − φ_s,n) = b (φ_s,m − φ_m) から）。D̂ は、NEM の今の
  解で J と φ に合うように決める
- **外周**: 外向きの正味の流れを J = (D̃_b + D̂_b) φ_n とする。反射は 0。中性子束ゼロは D̃_b = a。真空は、
  J = r f φ_s と J = a (φ_n − φ_s) から D̃_b = a r f / (a + r f)（r は真空の辺の比、Marshak は 1/2。ADR-0101）
- **更新**: CMFD の解とノードの平均中性子束の比で、ノードの平均中性子束、展開係数、出ていく部分中性子流をノードと群ごとに
  かける（NEM の方程式は線形なので、ノードの量を同じ比で変えてよい）
- **固有値問題のソルバ**: lattice の CMFD のうち、形状に依存しない部分（ブロック Gauss-Seidel のべき乗法、核分裂の
  スペクトルの項、収束の見積もり）を `xlc_numeric::cmfd` に移し、lattice と core が使う。結合係数の作り方は各段階に残す
- **許容誤差**: CMFD の判定は、NEM の判定より小さく（k 1e-10、中性子束 1e-9）し、NEM の反復による変化が NEM の判定の
  何倍あるかに比例して緩めて解く（ADR-0110 と同じ考え方）。CMFD の判定は正の有限で NEM の判定以下であること
- **既定**: 加速あり（`Acceleration::Cmfd` の既定の許容誤差）。加速なしは検証用に選べる

## 確認

実装のブランチで、テストの名前と結果に置き換える。

- 加速の有無で、k とノードの中性子束が NEM の判定以内で一致し、反復が減る（均質な直方体、ADF のある 2 領域、反射体と
  真空の外周、集合体を分割したノード）
- lattice の結果が、切り出しの前後でバイト単位で同じ（VERA 2B）
- 既存の炉心の例で、加速の有無の k、反復、時間

## 結果

- ADR-0028 の決定を実装する
