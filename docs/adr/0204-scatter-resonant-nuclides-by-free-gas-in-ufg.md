# ADR-0204: UFG の減速計算で、分離共鳴を持つ核種の散乱核も、入力で選べば 400 kT より下で温度 T の自由ガスの核にする

## 背景

[ADR-0203](0203-scatter-light-nuclides-by-free-gas-in-ufg.md) は、UFG の減速計算で分離共鳴を持たない核種（ライブラリの `resolved` が nil。以下、軽い核種）の散乱核を、
入力で選べば温度 T の断面積一定の自由ガスの核にした。分離共鳴を持つ核種（U、Pu、核分裂生成物、被覆管の Zr など。以下、重い核種）は
静止した標的のまま残した（[ADR-0070](0070-treat-targets-at-rest.md)）。

参照解の OpenMC 0.15.2 は、質量比が 1 より大きい核種を、入射エネルギーが核種の kT の 400 倍（`FREE_GAS_THRESHOLD`、`include/openmc/physics.h`）
より下で断面積一定の自由ガス（CXS。`sample_target_velocity` の `ResScatMethod::cxs`）、その上で静止した標的として扱う。分離共鳴の上方散乱の
扱い（DBRC、RVS）は `resonance_scattering` の要素があるときだけ有効で（`settings.cpp` の `res_scat_on {false}`）、#0133 の参照の入力
（`references/openmc/pin-transfer-1C/*/model.xml`、`pin-rates-1C/*/model.xml`）にその要素はない。400 kT は 565 K で 19.5 eV、600 K で 20.7 eV、
900 K で 31.0 eV。

ADR-0203 の後の #0152 の 27 群の燃料の中性子束の傾きと、新しい燃料から 2A の 40 MWd/kg の組成（2A-40）への k の差の増え +73.1 pcm には、
重い核種の熱運動が候補に残った。

判断の軸（依頼、2026-10-24）: 正確さ > 速度 > 保守。厳密な方法（参照）と、誤差を測った速い方法を作る。既定は静止した標的のままにし、既定の
切り替えはユーザーが、H の束縛（ADR-0203 の案 K3）とまとめて決める。説明できない定数や補正は入れない。

## 検討した案

### 重い核種の散乱核

- 案 R1: 軽い核種と同じ断面積一定の自由ガスの核（ADR-0203 の案 K1 と案 Q2）を、重い核種にも、その kT の倍数の上限より下で使う（採用）。
  衝突の率はポイントワイズの温度に拡げた弾性散乱断面積で、出射は断面積一定の核で決める。OpenMC の CXS と同じ扱い
- 案 R2: 共鳴の形を入れた厳密な散乱核（DBRC、RVS、Ouisloumen-Sanchez の核）。0 K の弾性散乱のポイントワイズの断面積がライブラリに要る
  （[ADR-0073](0073-store-pointwise-data-in-library.md) のライブラリは温度に拡げた断面積だけを持つ）。この ADR では作らない。費用:
  - ライブラリの形式（ADR-0073）に、分離共鳴を持つ核種の 0 K の弾性散乱の格子と値を足し、xs のすべての核種のステージを作り直す（65 核種で
    38 分の実績。CLAUDE.md の「計算」、Slurm 473）。ライブラリの大きさの増えは確かめていない
  - 散乱核の評価は、格子点と区間の点ごとに、0 K の断面積の格子の上で標的の速度について積分する（Doppler の幅の中の 0 K の格子点の数だけ
    手間が増える）。区間の機構（案 Q2）は、核が入射のエネルギーごとに断面積の形を持つので、そのままは使えない
  - 比べる参照も、OpenMC を `resonance_scattering` つきで再実行する（1C のピンセルの 1 回の輸送で 409〜417 s の実行。「時間の内訳」の節）
- 重い核種を静止した標的のまま残す（ADR-0203 の扱い）

### 上限

- 重い核種の上限を、軽い核種の上限（`upper`）と別の入力の項目にする（採用）。OpenMC と同じ「重い核種は 400 kT、H は上限なし」に近い組
  （軽い核種は上限なしで、重い核種だけ 400 kT。OpenMC は O-16 も 400 kT で止める。軽い核種を 400 kT で止めた差は、H を含めて ADR-0203 の測定で 4.1 pcm 以内）を参照にできる
- 1 つの上限を両方に使い、重い核種は `heavy = true` で選ぶ: 軽い核種を上限なしにした参照に重い核種の 400 kT を組めない
- 重い核種の上限なし（`heavy = inf`）: 入力では選べるが、1C の 0 MWd/kg で上方散乱のスイープが 50 回で収束しなかった（下の測定）

### 速い方法

ADR-0203 の案 F1〜F3（400 kT の上限、区間の細かさ 2、スイープの回数の固定）を、重い核種にもそのまま使う。スイープ 1 回は重い核種で大きく
外れる（下の測定）。最初のスイープは格子点より後の中性子束をその点の値とみなすので、重い核種の上方散乱が共鳴の谷の中の中性子束を高く
見積もることが候補で、確かめていない。最初のスイープの前に静止した標的の解を「前のスイープ」として使えば、1 回で足りる見込みがあるが、
作っておらず測っていない（#0179）。

## 決定と理由

入力の項目 `ufg-free-gas` に `heavy`（重い核種の自由ガスの核を使う入射エネルギーの上限。核種の kT の倍数で、`inf` は上限なし。省略すると
重い核種は静止した標的）を足す。`heavy` を書くと、重い核種にも案 R1 を使う。核、区間の機構、スイープは軽い核種と共有し、`upper` は軽い
核種だけの上限になる。既定（`ufg-scattering` の省略）と、`heavy` を書かない `"free-gas"` の結果はビットで変わらない。

案 R1 の解き方の確認: U-238 に似た共鳴（6.67 eV の捕獲と散乱）と静止した減速材の無限媒質で、U-238 を自由ガスにしたときの群の捕獲の
変化が、散乱核を等間隔の格子の上で直接に求積した解の変化と 4% 以内で合う（変化は −7.6e−4。静止した標的どうしの差は 1e−3 で、減速計算の
窓の格子の離散化による）。

測定（examples/depletion/verification.md の「分離共鳴を持つ核種の自由ガスの散乱核（ADR-0204）」。xlc は 4f6f40a3、1C の 0 MWd/kg の
`fine_flux` は 261c2950、2026-10-24）:

- 重い核種の 400 kT の自由ガスで、k は軽い核種だけのときから 1C の 0 MWd/kg で +15.3、2A-40 で +9.7 pcm 動き（軽い核種は上限なしでも
  400 kT まででも同じ差。1C の 5 MWd/kg は軽い核種も 400 kT までの組だけを流し、+14.1 pcm）、
  新しい燃料から 2A-40 への k の差の増えは +73.1 から +67.5 pcm（−5.6）になる。k の差（xlc − OpenMC）は正の側に開く（新しい燃料で
  +20.6 → +35.9 pcm）
- 動くのは主に U-238 の 25 群（15.97〜27.7 eV。20.9 eV の共鳴）で、吸収の置き換えの寄与は −22.4 → +0.9（新しい燃料）、−30.0 → −13.4 pcm
  （2A-40）。27 群（6.67 eV）は +4.0 → −4.0、−3.5 → −10.1 pcm と逆の側に動き、27 群の燃料の中性子束の傾きはほぼ変わらない（新しい燃料の
  4 区間で −0.48、−0.52、+0.34、+0.69% が −0.45、−0.54、+0.28、+0.72%）。#0152 の 27 群の傾きの残りは、重い核種の熱運動では説明できない
- 区間の細かさ 8 は 4 と 0.1 pcm 以内。速い方法（どの核種も 400 kT まで、細かさ 2）は、どの核種も 400 kT までの参照から、スイープ 1 回で
  −114.6〜−169.9 pcm、2 回で −7.1〜−10.4 pcm、3 回で −0.1〜−0.2 pcm
- 時間は測っていない（測定のジョブは `--timed` でなく、その時間は記録に使えない）

既定の案（決めるのはユーザー。ADR-0203 の既定の案と組む）: `heavy = 400` をスイープ 3 回と組む。スイープ 1 回（ADR-0203 の既定の案）は
重い核種では使えない。重い核種の熱運動は k の差を OpenMC から遠ざける側に動かすが、OpenMC と同じ扱いにする分で、残る差はほかの候補
（H の束縛、等価なセル）として読む。

## 帰結

- 既定の静止した標的と、`heavy` を書かない `"free-gas"` は、自己遮蔽の結果がビットで変わらない（`fine_flux` の出力の md5 が、2A-40 の
  静止した標的で ADR-0203 の記録の出力と、1C の 0 MWd/kg の ADR-0203 の 400 kT と速い方法で main の実行ファイルの出力と同じ）
- 重い核種の上限なし（`heavy = inf`）は、1C の 0 MWd/kg で上方散乱のスイープが 50 回で収束せず止まる。上限なしの参照は、スイープの加速か
  初期値（静止した標的の解）が要る（#0179）
- スイープ 1 回の速い方法は重い核種で使えず、重い核種を入れるとスイープ 3 回が要る（1 回で足りる初期値は #0179）。上限より上の出射では、
  重い核種の区間を作らず、D に掛ける σs も上限から下の格子点だけで持つ（`Gas::idle`、`first_below`。結果はビットで同じ）。時間は `--timed` で測っていない
- 残る UFG の範囲の差の候補: H in H2O の 4〜10 eV の束縛（ADR-0203 の案 K3）、分離共鳴の上方散乱（案 R2）、等価なセル。#0152 に書く
