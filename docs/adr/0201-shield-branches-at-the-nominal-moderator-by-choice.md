# ADR-0201: 履歴からの分岐の自己遮蔽を、入力で選べば燃焼度の点と燃料の温度の点ごとに公称のホウ素と減速材で 1 度だけ解く

## 背景

燃焼度の軸を持つ分岐のテーブル（[ADR-0187](0187-tabulate-burnup-branches-from-history.md)）は、燃焼の履歴の燃焼点の組成を固定し、`[branches]` の状態（ホウ素、減速材の
温度と密度、燃料の温度。[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)）ごとに 1 回輸送する。輸送のたびに自己遮蔽を解き直し、自己遮蔽は 1 回の輸送の 7〜9 割を占める
（examples/depletion/verification.md の「集合体の燃焼」の「時間」: 1 回の輸送の自己遮蔽は 2A 9.7 秒、2O 12.5 秒、2N 59.2 秒、MOC は 3.2〜4.1 秒）。分岐のテーブルが
商用の格子コードより 2 桁遅い原因の 1 つである（ユーザーの指摘、2026-10-24）。

同じ燃焼点の状態は燃料の組成が同じで、ホウ素と減速材の軸が燃料の自己遮蔽に効くのは、Dancoff 係数（減速材の全断面積）と、等価なセルの
減速計算の減速材のリングを通してだけである。燃料の温度の軸は燃料の共鳴の Doppler 拡がりを変えるので、燃料の自己遮蔽に直接効く。
制御棒と支持格子の分岐は、ADR-0187 のとおり別の格子の入力で同じ履歴を読んで作るので、その入力の公称の状態が参照になる。

判断の軸:

- 近似は入力で選べる項目にし、誤差を測って記録する（ユーザー、2026-10-23）。既定は状態ごとに解き直す原理どおりの方式のままにし、既定を
  切り替えるかは誤差を見てユーザーが決める
- 既定の候補にするのは、状態ごとに解き直したテーブルとの k∞ の差が、燃焼度の内挿の目安 ±10 pcm（[ADR-0192](0192-interpolate-burnup-by-cubic-hermite.md)）と同程度以下のとき
- shielding.rs の自己遮蔽の手順は変えず、公開された結果（核種ごとの実効断面積、SPH 因子を戻す `physical_flux`）で組む
  （[ADR-0197](0197-shield-depletion-at-the-step-start-by-choice.md) の案 M1 と同じ理由）

## 検討した案

参照の取り方:

- 案 R1: 燃焼度の点と燃料の温度の格子点ごとに、ホウ素と減速材の軸が変える物質を入力のもの（公称）にした参照の状態で 1 度解く（採用）。
  燃料の温度を変えた状態はその温度で解き直す。公称の減速材が軸の格子点でなければ、参照の自己遮蔽は表に入らない状態の分だけ増える
  （燃焼度の点ごとに燃料の温度の点の数）
- 案 R2: 燃焼度の点ごとに公称の状態（燃料の温度も公称）で 1 度だけ解き、燃料の温度を変えた状態は状態ごとに解き直す: 燃料の温度の
  点が 3 なら、27 状態の自己遮蔽が R1 の 3 回に対して 19 回になる。燃料の温度ごとの参照を持つ R1 と比べて、近似の中身（ホウ素と
  減速材の影響を捨てる）は同じ
- 案 R3: 燃料の温度も参照から作る（Doppler の効く群の実効断面積を自己遮蔽因子で別の温度に移す）: 燃料の温度係数そのものを
  近似することになり、誤差が分岐のテーブルの主な量に入る

作り直す物質と作り方:

- 案 M1: 参照の自己遮蔽の物質を使い、ホウ素と減速材の軸に挙げた物質（`varied`）の領域だけを、状態の組成と温度で作り直す（採用）。
  自己遮蔽しなかった物質（無限希釈の減速材）は `Material::mix`。自己遮蔽した物質（燃料のピンの等価なセルの被覆管と減速材のリング、
  構造材の塊）は、領域の核種ごとの実効断面積から群定数（`shielded_nuclide`）を作り、状態の数密度で混ぜ（`Material::from_nuclides`）、
  参照の SPH 因子を掛ける。温度が公称と同じ物質は参照の実効断面積そのもの、違う物質は状態の温度の無限希釈の値に、参照の実効断面積と
  公称の温度の無限希釈の値の比（自己遮蔽因子）を掛けたもの（`carry_shielding`）。参照の組成にない核種（公称のホウ素が 0 で、状態に
  ホウ素がある）は状態の温度の無限希釈の値
- 案 M2: 燃料の物質だけを参照から取り、ほかの物質は状態の入力から無限希釈で作る: 等価なセルの減速計算で縮約した減速材と被覆管の
  リングの群定数と SPH 因子が消え、燃料のリングに掛けた SPH 因子との組（リングの間の反応率を保つ）が崩れる。公称の状態でも、解き直した
  物質と一致しない
- 案 M3: 温度が違っても参照の実効断面積をそのまま使う: 減速材の軸の温度の変化が、核種の群定数の全断面積と反応の断面積に入らない
  （散乱行列だけが状態の温度になる）
- 案 M4: 自己遮蔽の関数に「Dancoff 係数と減速計算を固定して組成を替える」口を足す: shielding.rs を変える。M1 は公開された結果だけで
  同じことができる。代わりに、M1 は自己遮蔽の物質の作り方を history.rs で再実装するので、作り方を変えるときは両方を合わせる（下のビットの
  確認が食い違いを止める）

## 決定と理由

R1 と M1 にし、入力で選ぶ。

- `[branches]` の `shielding`: `"every-state"`（状態ごとに解き直す。既定）か `"nominal-moderator"`（R1、M1）。ほかの値はエラー。
  `"nominal-moderator"` は `[history]` と組む（燃料の組成が状態によらないのは履歴からの分岐で、燃焼させた物質はホウ素と減速材の軸に
  挙がらない）。`[history]` のない入力ではエラー
- 参照の物質（`Branches::reference`）は、燃料の温度の軸（最後の軸）だけを状態の格子点にし、ほかは入力の物質のまま。ホウ素と減速材の
  軸に挙げた物質が作り直す物質（`Branches::varied`）
- `BranchShielder` が状態を順に解き、今の燃焼度の点の参照の自己遮蔽を燃料の温度の点ごとに持つ。燃料の組成によらない前処理（Dancoff
  係数）は ADR-0194 のとおり持ち越す。状態の物質が参照の物質と同じなら、参照の自己遮蔽をそのまま使う
- 作り直しの前提（自己遮蔽の物質が、領域の実効断面積と組成から作った群定数に SPH 因子を掛けたもの）は、参照を解くたびに、公称の組成で
  作り直した物質が参照の自己遮蔽の物質とビットで同じことで確認し、違えば止める（ADR-0197 と同じ）。1 つの物質を作り直す領域と作り直さない
  領域が共有していれば、また共有する領域の実効断面積か SPH 因子が違えば、作り直せないのでエラーにする
- 自己遮蔽因子の比は、無限希釈の値が 0 の群で実効断面積も 0 ならその群の状態の値、実効断面積が 0 でなければエラー
- lattice は、履歴からの分岐を解き終えると、自己遮蔽を解いた回数をログ（`branches` の `shieldings`）に出す。テーブルには方式を書かない
  （入力に書いてある）

### 帰結

- 自己遮蔽の回数は、燃焼度の点の数 × 燃料の温度の点の数（公称の減速材が軸の格子点でなくても同じ）になり、ホウ素と減速材の点の数に
  よらない。ADR-0097 の M3 の 27 状態なら、燃焼度の点ごとに 27 回から 3 回
- 既定は every-state のまま。背景の既定の候補の条件（±10 pcm と同程度以下）を、ホウ素だけを変えた状態は満たす（0.2〜0.4 pcm）が、
  減速材の密度を 3.6〜4.2% 変えた状態は満たさない（69〜118 pcm。「確認」）。nominal-moderator は既定の候補にせず、選べる項目に残す。
  既定を切り替えるかは、この測定を見てユーザーが決める
- 誤差の大半は減速材の密度による（燃料の共鳴の自己遮蔽が Dancoff 係数を通して密度に依る分が候補で、確かめていない）。参照を
  減速材の点ごとにも持ち、ホウ素の軸の物質だけを作り直す方式なら誤差はホウ素の分に留まり、自己遮蔽は M3 の 27 状態で 9 回になる
  見込み（測っていない。#0177）
- 時間は timed でないジョブで流したので記録しない。自己遮蔽の回数の減り（下）に、記録の 1 回の自己遮蔽の時間（背景）を掛けた分が
  見込みの減り
- ホウ素と減速材の軸に挙げた物質に、自己遮蔽が等価なセルの減速計算で作ったリング（被覆管、減速材）があれば、その UFG の範囲の
  群定数は参照の減速計算の中性子束で縮約したまま（状態の組成で解き直さない）で、近似の一部になる
- 制御棒と支持格子の分岐（別の格子の入力）にも使えるが、参照はその入力の公称の状態で、測っていない
