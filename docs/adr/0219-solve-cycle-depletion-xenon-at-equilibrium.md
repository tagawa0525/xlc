# ADR-0219: 燃焼のサイクルの出力のある解は Xe-135 と I-135 を解の中性子束と出力に釣り合う平衡の値で解き、Xe の扱いをケースに必ず書かせる

## 背景

[ADR-0216](0216-tabulate-micro-depletion-cross-sections-per-state.md) の案 E1 は、Xe-135 と I-135 をほかの追う核種と同じくミクロ燃焼の中で時間で追い（過渡の Problem 8 と燃焼の中の
Problem 9 に同じデータを使う）、平衡 Xe（Problem 7）は同じ σ と収率で core が平衡の式を解くとした。燃焼のステップは
[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の中点の形と ADR-0216 の CE/CM（[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md)）で、点は次のステップの状態で解く（[ADR-0218](0218-give-depletion-steps-power-decay-and-states.md) の案 P2）。

小さな炉心（2A の 4 × 4 の 1/4 と反射体、高さ 365.76 cm、軸方向に 22.86 cm のノード 16、熱水力のフィードバックなし）の燃焼で、ステップを
分けても、バンク D を抜いて出力を 0.7 にした後と 18 日の停止の後の誤差が縮まなかった（#0200）。この ADR の測定（examples/depletion/verification.md の
「ステップの大きさの誤差と中点の臨界ホウ素（小さな炉心）」。目標の k 1.071、7b3a057c の入力、d875964f の core、2026-10-29）:

- Xe を時間で追う燃焼の分割を 16 から 32、64、128 に細かくすると（最初のステップは 0.20、0.10、0.051 日）、分割 32 まで 0.00 か ±0.02 だった
  燃焼の初めの軸方向の出力の偏り（上半分 − 下半分の出力の割合）が、分割 64 と 128 では 4〜5 日のうちに ±0.75 の振動に育つ（分割 128 は 3.6 日の
  −0.02 から 4.1 日の −0.50 まで、0.05 日ごとにほぼ倍）。振動の周期は分割 64 で約 1.9 日、分割 128 で約 0.9 日とステップの幅で変わり、1 MWd/kg の
  点の分割 64 と 128 の差は、ホウ素 −0.97 ppm、ノードの出力の割合の相対差の最大 7.5（分割 16 と 32 は 0.51 ppm、0.046）。細かくしても一つの解に
  近づかない
- 同じ燃焼を、Xe-135 と I-135 を各解の平衡の値にして解くと（下の案 X2）、軸方向の偏りはどの分割でも滑らかで、最後の点のホウ素は分割を倍に
  するごとに一つの値に近づく（値は「確認」）

Xe の振動が物理（熱水力のフィードバックのない背の高い炉心の軸方向の Xe の不安定）か、細かいステップでの時間の進め方の不安定かは確かめていない
（育つ速さ（e 倍に約 0.07〜0.1 日）は Xe-135 の時定数（約 3 時間）より速く、周期がステップの幅で変わる）。どちらでも、Problem 9 の約 15 EFPD の
ステップは Xe と I の時間の変化（数時間〜1 日）を解けない。

判断の軸: 正確さ > 実行速度（CLAUDE.md の「方針」）。ADR-0190 の中点の形の 2 次の性質を、ステップの中で状態が一定のときに保つ。黙った既定を
作らない。

## 検討した案

- 案 X1: Xe を時間で追う（ADR-0216 のまま）で、ステップの幅の指針を記録に書く: 上の測定で、分割 16 まで（最初のステップ 0.41 日以上）は
  振動が出ずに 5 MWd/kg まで 2 次で縮むが、振動を解けない幅で抑えているだけで、細かくすると解が一つに近づかない。Problem 9 の幅では
  使えない
- 案 X2: 出力のある解（中点と、出力のステップの終わりの点）で、Xe-135、I-135 とそれらへ崩壊で流れ込む補助の核種を、その解の反応率で生成と
  消滅が釣り合う値にし、置き換える値が変わらなくなるまで解き直す（採用）: 多くの炉心の計算コードが燃焼のステップで使う形。Xe は解の
  中性子束の代数的な関数になり、ステップの中の ODE から外れるので、ほかの核種の CE/CM の 2 次の形は保つ。Xe の過渡（停止の後の立ち上がり、
  Problem 8）は解かない
- 案 X3: Xe と I だけを陰的に進める（ステップの終わりの中性子束と Xe を一致させる。CE/CM の中で Xe と I だけ陰的 Euler）: 長いステップでは
  X2 に近づき、短いステップでは過渡を追う。ステップの終わりで中性子束と Xe の固定点を解くので費用は X2 と同じで、Xe は 1 次になる。上の測定で、
  短いステップで時間で追う解は一つに近づかないので、短いステップで過渡を追える利点が今の炉心では確かめられない
- 案 X4: ステップの中の出力の形を固定しない（ステップを細かいステップに分け、それぞれで解く）: 細かいステップは X1 を細かくしたものと
  同じで、上の測定のとおり一つの解に近づかない

固定点の解き方（X2）:

- 案 F1: 平衡の値をそのまま次の組成にする（単純な反復）: 中性子束が Xe に強く応じる炉心では、反復の写像の傾きの大きさが 1 に近いか超え、
  互い違いに振れて収束しないことがある（時間で追う燃焼の長いステップの振れと同じ形）
- 案 F2: Anderson の加速（type II、前の 3 回の反復）（採用）: 前の反復の残差の差の最小二乗で次の組成を選ぶ。小さな炉心の分割 1 では、解き直しは
  1 回の解あたり 5〜6 回（初めの残差 0.02〜0.3 から 1e-6 以下へ。単純な反復の 1 回目の縮みは約 0.2 倍）
- 案 F3: NEM の外側の反復ごとに Xe を置き換える（固有値計算の中に入れる）: 固有値計算 1 回分の費用で済むが、部分挿入のノードの定数を
  外側の反復ごとに作り直す仕組み（ADR-0127 の `Refresh`）の中で、区間ごとの線形の補正を作り直すことになり、変える範囲が大きい。#0201 の
  固有値計算の初期値（平らな初期値から 2301 回の反復）と合わせて、速さの issue に残す

Xe の扱いの選び方:

- 案 S1: 入力の `micro` に `xenon` を必ず書く（`"tracked"` か `"equilibrium"`）（採用）: Xe と I の時間の変化を解くステップ（Problem 8 の過渡）では
  時間で追うのが、それより長いサイクルのステップでは平衡が正しく、どちらも黙った既定にできない
- 案 S2: 省けば時間で追う（ADR-0216 のまま）: Problem 9 の入力で書き忘れると、上の測定の解けない Xe の振動に黙って入る
- 案 S3: ステップの幅で自動で選ぶ: 閾値を決める測定がなく、推測の既定になる

## 決定と理由

これは ADR-0216 の「Xe と Sm（案 E1）」のうち「Xe-135、Sm-149 とその先行核をミクロ燃焼で追う」を、`xenon = "equilibrium"` の燃焼の Xe-135 と
I-135 について置き換える（Sm-149 と Pm-148m は追うまま）。平衡を同じ σ と収率で core が解くことと、平衡 Xe のケース（Problem 7）の入力が #0193 に
残ることは変わらない。

### 入力（案 S1）

```toml
[depletion]
micro = { chain = "chain.msgpack", xenon = "equilibrium" }   # tracked か equilibrium。必ず書く
```

### 平衡 Xe の解（案 X2、F2）

`xenon = "equilibrium"` の燃焼では、次の解を「出力のある解」とする:

- ステップの中点（そのステップの出力の割合）
- 出力のステップの終わりの点。点は次のステップの状態で解く（ADR-0218 の案 P2）ので、次も出力のステップならその出力の割合、次が崩壊だけの
  ステップか最後の点なら終わったステップの出力の割合。ステップの初めの点、中点、修正子が同じ出力の平衡になる

燃焼点 0 と、崩壊だけのステップの後の点は、組成を時間で進めた値のまま解く（新しい燃料と停止の後の Xe は平衡でなく、崩壊の結果）。

出力のある解は、ノードごとに Xe-135、I-135 と、それらへ崩壊で流れ込む補助の核種（追う核種のほかは平衡にしない）の数密度を、解の反応率
（ADR-0218 の出力の割合で規格化した、ミクロ燃焼と同じ燃焼行列 A）で Σⱼ∈S Aᵢⱼ Nⱼ = −Σⱼ∉S Aᵢⱼ Nⱼ（i ∈ S）を解いた値に置き換えて解き直す。
置き換える値の、解き直す前後の相対の変化（初めの平衡の値に対する比）の最大が 1e-6 以下になったら止め、その組成で解いた解と組成を点と
中点の値にする。50 回で止まらなければエラー。次の組成は Anderson の加速で選ぶ（案 F2）。探索の状態は、解き直すたびに臨界ホウ素を探す
（ADR-0191）。点の固有値計算の回数は、解き直したすべての解の和。修正子は、中点の平衡の組成で規格化した反応率で、初めの組成から CRAM で
進める（ADR-0216 のまま。ステップの終わりの Xe は、終わりの点の平衡で置き換わる）。

### 出力

燃焼の履歴（`xlc-core-history`）に、ミクロ燃焼のとき `xenon`（`"tracked"` か `"equilibrium"`）を書く。

## 帰結

- Problem 9 のサイクルは `xenon = "equilibrium"` で解く。停止の後の Xe の立ち上がり（数日）は、崩壊だけのステップの後の点だけが崩壊の結果の
  Xe で、そこからのステップの中点は平衡になる。ステップの幅の誤差は、停止の後の最初のステップで点と中点の Xe が違う分を含む
- 平衡の解は、固有値計算を約 5.6 倍にする（小さな炉心の分割 16。値は「確認」）。固有値計算の初期値を前の解にする、NEM の外側の反復の中で Xe を
  置き換える（案 F3）は、速さの issue（#0201）に残す
- 時間で追う燃焼の、細かいステップで育つ軸方向の振動が物理か時間の進め方かは確かめていない（#0200 の残り）
- 燃焼のケースの `micro` は `xenon` を持たないとエラーになる。今までのケースの入力は `xenon = "tracked"` を書き足した（結果は変わらない）
- 平衡 Xe のケース（Problem 7。燃焼のないケースの状態）の入力は #0193 に残る。この ADR のノードの平衡の式（`MicroChain::equilibrium`）を使える
