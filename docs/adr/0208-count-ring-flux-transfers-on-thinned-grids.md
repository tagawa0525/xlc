# ADR-0208: UFG の範囲の群の移行を、間引いた格子でも、行を核種の格子で縮約した弾性散乱に合わせて数える

## 背景

[ADR-0207](0207-collapse-ufg-transfers-by-ring-flux.md) は、等価なセルのリングの物質の UFG の範囲の群の散乱行列の移行の形を、UFG の減速計算と
同じ格子点の中性子束と散乱核で数える（`ufg-transfer = "ring-flux"`）。自分の群への移行は、リングの中性子束で縮約した弾性散乱断面積から
ほかの群への移行を引いたもので、行の和が自己遮蔽した弾性散乱断面積になる（中性子は保存する）。

[ADR-0185](0185-thin-ufg-grid-by-macroscopic-tolerance.md) の間引いた格子（`ufg-tolerance`）では、核種の群定数を核種自身の格子（間引いた格子点と核種の
ポイントワイズの点の和）で縮約する。間引きはリングの物質の巨視的な全断面積と弾性散乱断面積を許容差で再現する点だけを残すので、物質の中の
割合の小さい核種の共鳴の点は落ちうる。ほかの群への移行を間引いた格子で数え、自分の群への移行を核種の格子で縮約した弾性散乱との差で決めると、
2 つの格子の弾性散乱の差（核種ごとの間引きの誤差）がそのまま自分の群への移行に入る。ADR-0207 はこのため間引いた格子と組めないとした。

間引きは集合体の燃焼の入力のすべてが使い（`p2_inputs.py`）、2A の燃焼の自己遮蔽を約 3.0 倍速くし、k の差は −1.0〜+0.8 pcm（ADR-0185 の確認）。
ADR-0207 の移行を既定にするには、間引いた格子と組める必要がある。

判断の軸（依頼、2026-10-28）: 正確さ > 速度 > 保守。説明できない定数や補正を入れない。中性子の保存（行の和）を確かめる。

## 検討した案

- 案 G1: 自分の群への移行も間引いた格子の弾性散乱との差で決める（行の和は間引いた格子で縮約した弾性散乱）。行の和が群定数の弾性散乱
  （核種の格子）と核種ごとの間引きの誤差だけ食い違い、全断面積と吸収と散乱の和が合わなくなる（中性子が保存しない）
- 案 G2: 群から出る移行を間引いた格子で数え、同じ格子の弾性散乱の率 ∫_h σs F du（減速計算の移行と同じく σs F を格子点の間で線形とした
  台形則）で割った割合を、核種の格子で縮約した弾性散乱断面積に掛ける（採用）。行は「核種の格子の弾性散乱 × 間引いた格子での出る割合」で、
  行の和は核種の格子の弾性散乱になる。掛ける比は同じ量（群の弾性散乱）の 2 つの格子での縮約の比で、間引かない格子では 1 になる
- 案 G3: 移行を核種の格子（間引いた格子点と核種の点の和。間の中性子束は内挿）で数える。核種の格子で数え直す手間は、分離共鳴を持つ核種で
  間引かない格子に近く、自由ガスの核の差 D と S(α,β) の移行も核種ごとの格子で数え直す。案 G2 の誤差が目標を超えるときの候補
- 間引いた格子とは組めないまま（ADR-0207）: `ring-flux` を集合体の入力の既定にできない

## 決定と理由

案 G2 にする。これは ADR-0207 の「間引いた格子（`ufg-tolerance`）とは組めない（…）。組めば入力を読むところで止める」の部分を置き換える。
ほかの部分は変わらない。

- 間引いた格子では、核種の格子で縮約するときに（`collapse`）、同じ核種の弾性散乱断面積を間引いた格子点だけの台形則でも縮約し、群 h の
  比 s_h = σ_el(核種の格子) / σ_el(間引いた格子) を、リングの核種ごとに求める。ほかの群への移行は s_h を掛け、自分の群への移行は
  σ_el(核種の格子) から掛けた後のほかの群への移行を引く。行の和は ADR-0207 と同じく自己遮蔽した弾性散乱断面積になる
- 間引いた格子の σ_el が 0 の群で核種の格子の σ_el が 0 でなければ（比が有限でない）、移行の要素の検査（ADR-0207）で止める。どちらも 0 なら、
  ほかの群への移行は 0 で、比は使わない
- 間引かない格子は比を掛けない（比は台形則が同じなので丸めの範囲で 1。ADR-0207 の記録の結果をビットで保つ）

測定は実装の後に書く。

## 帰結

- `ring-flux` を `ufg-tolerance` と組める（入力の検査と減速計算のエラーを外す）
- 間引いた格子の移行の誤差は、間引いた格子で数えた出る割合の誤差だけになる（群の弾性散乱の大きさは核種の格子のもの）
