# ADR-0208: UFG の範囲の群の移行を、間引いた格子でも同じ数え方で数える

## 背景

[ADR-0207](0207-collapse-ufg-transfers-by-ring-flux.md) は、等価なセルのリングの物質の UFG の範囲の群の散乱行列の移行の形を、UFG の減速計算と
同じ格子点の中性子束と散乱核で数える（`ufg-transfer = "ring-flux"`）。自分の群への移行は、リングの中性子束で縮約した弾性散乱断面積から
ほかの群への移行を引いたもので、行の和が自己遮蔽した弾性散乱断面積になる（中性子は保存する）。

[ADR-0185](0185-thin-ufg-grid-by-macroscopic-tolerance.md) の間引いた格子（`ufg-tolerance`）では、核種の群定数を核種自身の格子（間引いた格子点と
核種のポイントワイズの点の和）で縮約する。ADR-0207 は、ほかの群への移行を間引いた格子で数え、自分の群への移行を核種の格子で縮約した
弾性散乱との差で決めると、自分の群への移行に格子の差が入るとして、間引いた格子と組めないとした。

間引きは集合体の燃焼の入力のすべてが使い（`p2_inputs.py`）、2A の燃焼の自己遮蔽を約 3.0 倍速くし、k の差は −1.0〜+0.8 pcm（ADR-0185 の確認）。
ADR-0207 の移行を既定にするには、間引いた格子と組める必要がある。

判断の軸（依頼、2026-10-28）: 正確さ > 速度 > 保守。説明できない定数や補正を入れない。中性子の保存（行の和）を確かめる。

## 検討した案

群 h の自己遮蔽した弾性散乱を σ（核種の格子）、ほかの群への移行の和を O、間引かない格子で数えた O を O_full、間引いた格子で数えた O を
O_thin = O_full + δ とする。

- 案 G0: 数え方を変えない（採用）。自分の群への移行は σ − O_thin = (σ − O_full) − δ で、間引かない格子の行（の σ を同じ群定数にしたもの）
  との差は、ほかの群への移行の誤差 δ だけになる。2 つの格子の弾性散乱の差（σ と間引いた格子で縮約した弾性散乱の差）は行に入らない。
  ADR-0207 が挙げた「格子の差」は、この δ の大きさで決まる。δ は、群の境界の近く（核の届く幅）の σs F を間引いた格子で数えた誤差である
- 案 G1: 自分の群への移行も、間引いた格子の弾性散乱との差で決める（行の和は間引いた格子で縮約した弾性散乱）。行の和が群定数の弾性散乱と
  核種ごとの間引きの誤差だけ食い違い、全断面積と吸収と散乱の和が合わなくなる（中性子が保存しない）
- 案 G2: ほかの群への移行に、同じ核種の弾性散乱の 2 つの格子の比 σ / σ_thin（σ_thin は間引いた格子点だけの台形則で縮約した弾性散乱）を
  掛け、「核種の格子の弾性散乱 × 間引いた格子での出る割合」にする。作って試験のセルで測った（このブランチの途中の版）。比は群の全体の
  弾性散乱の比で、ほかの群へ出るのは群の境界の近くで散乱した中性子だけなので、間引いた格子から落ちた共鳴が境界から離れていると、比が出る
  移行を誤って拡大縮小する。燃料に、5.19 eV に弾性散乱の共鳴を持ち、物質の断面積への寄与が許容差より小さい薄い核種（間引いた格子から
  共鳴の点が落ちうる）だけを置いた試験のセル（`transfer_cell` の途中の版。Tc-99 を足す前）で、間引かない格子の行との差の最大（行の和に対する比）は、数密度 2e−9 で
  G2 が 1.4e−6、G0 が 3.4e−7、1e−8 で G2 が 2.5e−7、G0 が 3.9e−7。ほかの核種はどちらも 3.8e−8 以下で同じ。G2 は良くなる場合も
  悪くなる場合もあり、比は群の境界の近くの散乱と関係のない量（群の中の共鳴の分）を出る移行に掛けるので、悪くなる場合（2e−9 で G0 の 4 倍）
  を説明できる。説明できない係数を掛けることになるので採らない
- 案 G3: 移行を核種の格子（間引いた格子点と核種の点の和。間の中性子束は内挿）で数える。分離共鳴を持つ核種で間引かない格子に近い手間に
  なる。G0 の δ が目標を超えるときの候補

## 決定と理由

案 G0 にする。これは ADR-0207 の「間引いた格子（`ufg-tolerance`）とは組めない（群定数は核種自身の格子で縮約し、移行は間引いた格子で
数えるので、差で決める自分の群への移行に格子の差が入る）。組めば入力を読むところで止める」の部分を置き換える。ほかの部分は変わらない。
入力の検査と減速計算のエラーを外し、間引いた格子でも減速計算の格子点で移行を数える。

測定（examples/depletion/verification.md「UFG の範囲の群の移行の縮約（ADR-0207）」の「間引いた格子（ADR-0208）」。xlc は 0d8b29551、
2026-10-28、Slurm 562）。1C の 0 MWd/kg と 2A-40 のピンセルで、S(α,β) の速い方法に許容差 1e-4 の間引きを足した:

- 間引きは k を、どちらの形も 1C の 0 MWd/kg と 2A-40 で +1.0〜+1.2 pcm 動かす（6 桁の k の差と、ログの k − OpenMC の差の両方）。
  間引いた格子で数えた移行の分（リングの中性子束の形と無限希釈の形の間引きの差の差）は、6 桁の k で 2 つの状態とも +0.1 pcm、4 つの k の
  丸め（各 ±0.05 pcm）を含めて −0.1〜+0.3 pcm。残りは群定数の間引きの誤差（ADR-0185 の 2A の燃焼で −1.0〜+0.8 pcm）と同じ大きさ。目標は、
  間引きの誤差（±1 pcm）を移行が広げないこととし、この範囲で満たす
- 群から出る移行の、間引かない格子との相対差の最大は、減速材 8.3e−7、燃料 −8.1e−6（2A-40 の 17 群）。同じ群の無限希釈の形（行の形は
  変わらず、群定数の弾性散乱の間引きの誤差だけ）は −3.6e−6 で、差の −4.5e−6 が間引いた格子で数えた移行の分（行のログは 0.05 /cm ほどの行で
  相対 1.9e−7 の桁まで）

## 帰結

- `ring-flux` を `ufg-tolerance` と組める。集合体の燃焼の入力（間引いた格子）でも ADR-0207 の移行を選べ、既定の切り替えの前提が揃う
- 間引かない格子の移行は変わらない（コードの変更は検査を外すことだけ。間引かない形の k は ADR-0207 の測定のログと表示の桁まで同じ）
- 間引いた格子の移行の時間は `--timed` で測っていない。数える格子点が減るので、移行を数える時間（ADR-0207 で 2A-40 の間引かない格子の
  0.71 秒）も減る見込みで、確かめていない
- G0 の誤差 δ は群の境界の近くの σs F の間引きの誤差である。間引きの許容差が抑えるのは物質の巨視的な断面積で、核種ごとの δ は抑えない
  （物質の中の割合の小さい核種の共鳴の点は落ちうる）。落ちた共鳴が群の境界から核の届く幅の中にある薄い核種（試験のセルの Tc-99。4.06 eV、
  境界 4 eV）では、その核種の行の間引かない格子との差が行の和の 2.0e−4 になる（群の中ほどの Ag-109 は 3.7e−7）。物質の移行の中では数密度の
  重みで小さくなる
- 自分の群への移行が負になれば（弾性散乱断面積の 1e−9 倍より負。ADR-0207 の検査）、間引いた格子でも止める。δ がそれを超えるには、δ が
  自分の群への移行（重い核種では核の届く幅が狭く、行の和のほとんど）を超える必要がある。試験の Tc-99 で行の和の 2.0e−4、1C の 0 MWd/kg と
  2A-40 のピンセル（2A-40 の燃料の核種 49）では止まらなかった。ほとんどの散乱が群から出る軽い核種（H-1 など）は物質の主な核種で、その σs F は許容差で
  抑えられる。集合体の間引いた入力では流していない

## 確認

- 試験: `crates/lattice/src/ufg/tests.rs` の `transfers_balance_the_slowing_down_of_an_infinite_medium`（無限媒質の群の中性子収支が、4 つの
  散乱核で間引いた格子でも 1e−6 以内で閉じる。最も大きい群で 6.3e−7）、`thinned_transfers_follow_the_full_grid`（静止した標的、自由ガス、
  分離共鳴を持つ核種の自由ガス、S(α,β) の 4 つの散乱核で、間引かない格子の行との差が行の和の 1e−6 以内。測った最大は 3.7e−7。共鳴が群の
  境界の近くにある薄い核種 Tc-99 は 1e−3 以内で、測った最大は 2.0e−4）、`dilute_resonances_drop_out_of_the_thinned_grid`（その試験のセルで、
  物質の断面積への寄与が許容差より小さい 2 つの薄い核種の共鳴の頂点の近くの点が、間引いた格子からほとんど落ちる）。入力は `ufg_transfer_defaults_to_the_infinite_dilution_rows`（`ufg-tolerance` と組める）
