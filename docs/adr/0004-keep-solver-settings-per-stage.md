# ADR-0004: 段階ごとのソルバの設定は、同じ値でも共有せず段階ごとに持つ

## 背景

xs のライブラリの重みの減速計算（`crates/xs/src/multigroup/slowing.rs`）と、lattice のピンごとの減速計算
（`crates/lattice/src/ufg.rs`）は、同じ減速の式を同じ格子の作り方で解く。格子の細かさ（1つの散乱の窓に入れる
格子点の最少の数 `WINDOW_POINTS`）は、どちらも 16 である。共通の計算を `xlc-numeric` に移したとき、この定数も
一度そこに移した（7e05b3d、2026-10-08）。

## 検討した案

- 定数を `xlc-numeric` で共有する: 一度そうしたが、xs で確かめた収束が lattice でも確かめてあるように見えてしまう
- 段階ごとに定義し、値の根拠をコメントで示す（採用。b002625、2026-10-08）

## 決定と理由

段階ごとのソルバの設定（減速計算の格子の細かさなど）は、同じ値でも共有せず、段階ごとに根拠とともに持つ。
格子の細かさは、それぞれの減速計算の設定であり、段階の間で共有するデータではないため。

`WINDOW_POINTS` は xs と lattice でそれぞれ定義し、コメントで次を示す。xs の値は、格子を細かくしても中性子束が
変わらないことを確かめた値である。lattice は xs で確かめた値をそのまま使っており、lattice のセル（多リングの
衝突確率法、全核種）での収束はまだ確かめていない。

## 確認

xs の値は `finer_grids_do_not_change_the_flux`（xs）で確かめている。lattice の値は確かめていない（#0002）。

## 帰結

- lattice の格子の収束の確認は #0002
