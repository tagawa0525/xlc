# ADR-0215: 履歴の補正は、燃焼度で重みを付けた平均の履歴の変数ごとに 1 本の履歴の分岐を流し、ミクロ燃焼で追わない核種の分を変数に比例して、線形化の誤差を組成の指標に比例して足す

## 背景

[ADR-0035](0035-track-history-by-micro-depletion.md) は、core が主要な核種をノードごとにミクロ燃焼で追い、追わない核種の残りを
履歴の変数と履歴の分岐（条件を変えた燃焼計算）で補正すると決めたが、履歴の変数を挙げていない。
[ADR-0026](0026-output-two-group-tables-from-lattice.md) は lattice が「燃焼履歴の補正のデータ」を出すとし、
[ADR-0187](0187-tabulate-burnup-branches-from-history.md) は燃焼度の軸を持つ分岐のテーブルを公称の燃焼の履歴の組成を固定した瞬時の分岐で作り、
条件を変えた燃焼の履歴（examples/depletion/p2 の 2A-density と 2A-rods）からも同じ形のテーブルを作れるとして、core がそれを
どう組み合わせるかを計画（docs/plans/m4-depletion.md の「進め方」6、7）に残した。テーブルの状態の取り方は
[ADR-0200](0200-tabulate-burnup-branches-by-cut-hdmr.md)（公称の状態、1 軸ずつの分岐、2 軸の組の部分格子。制御棒の値ごとに別の組）。

計画の「格子計算の燃焼」の「履歴」の項が ADR で決めるとしたのは、履歴の変数、履歴の分岐の数と条件、Pyrex を抜いた集合体
（VERA Problem 10 のサイクル 2 で、サイクル 1 から残る集合体）の扱いで、この ADR はそれに、テーブルに持つ補正の形、core がミクロ燃焼の
補正と履歴の補正を重ねる形、ADR-0026 の「履歴の補正のデータ」の出力の形を加えて決める。熱水力の ADR（HFP の燃料の温度と減速材の
密度の範囲）の前なので、軸の格子点と、履歴の分岐の条件の値は決めない。

### 判断の軸

- 正確さ: 落とす項は、ADR-0200 と同じく 1 項あたり |Δρ| ≤ 5 pcm を目安にする（炉心の k の 10 pcm と集合体の出力 0.5% から。ADR-0200 の
  「判断の軸と目安」）。格子計算の目標は ±100 pcm（[ADR-0032](0032-target-lattice-accuracy.md)）
- 二重に数えない: ミクロ燃焼が追う核種の数密度の違いは、ミクロ燃焼の補正だけが担う
- 格子計算の回数: 集合体 1 種の燃焼は、2A が 37 分 28 秒（ADR-0209 の既定、32 スレッド、Slurm 582）、前の既定と 16 スレッドで 2A が
  18 分 58 秒（Slurm 520）、2A-density が 18 分 55 秒（Slurm 522）、2A-rods が 39 分 27 秒（Slurm 523）。どれも timed のジョブの elapsed で、
  lattice と OpenMC との比較のステージの和（examples/depletion/verification.md の「集合体の燃焼」の「時間」）。分岐のテーブルは ADR-0200 の
  見積もり（前の既定の 1 状態の目安）で約 2.6〜5.4 時間
- テーブルの格子点で格子計算の値を返す性質（ADR-0097、ADR-0200）を保つこと

### 測った大きさ

examples/depletion/verification.md の「履歴の効き（2A）」（xlc の分岐は 02f35491 の lattice と、入力 09869909、0424eb34、2026-10-29、
Slurm 587、588。比較は 8b65319c）。2A（減速材 0.743 g/cc、565 K、1300 ppm）、2A-density（0.661 g/cc）、2A-rods（案内管 24 本に AIC）の
3 本の燃焼の履歴は同じ lattice と既定とライブラリのもので、燃焼度の同じ点で、履歴の分岐の k∞ を 2A の組成からその条件への瞬時の分岐と
比べた（履歴の効き）。さらに、2A の組成のうち ADR-0035 の候補の元素（U、Np、Pu、Am、Xe、Sm、Gd）だけを履歴の分岐の値にした組成を
同じ条件で解き、履歴の分岐との差を「追わない核種の分」とした。置き換えたのは元素の核種のすべてで、分岐が輸送する 89 核種のうち 26 核種
（Xe-135、Sm-147、149〜152、Gd の 7 核種、U の 4 核種、Np-237、239、Pu-238〜242、Am-241、243）。燃料で置き換えない輸送する核種は Mo-95、Tc-99、
Ru-101、Rh-103、I-135、Cs-133、Nd-143、Nd-145、Pm-148m、Eu-153、Cm-242、Cm-244 と O-16。逆向きは、履歴の分岐の組成を 2A の条件に戻した
分岐と 2A の差。値は Δρ (pcm)。

- 追う核種の分は履歴の効きの 97.1〜103.5% で、追わない核種の分は（2 MWd/kg の密度のほかは）逆の符号の、効きの大きさの 1.1〜3.5%。
  それでも目安の 5 pcm を、密度の履歴は
  10〜20 MWd/kg から、制御棒の履歴は 2 MWd/kg から超える（履歴の分岐は一生を通して条件を変えた極端なもので、炉心のノードの履歴の
  変数の差はこれより小さい。変数の差に比例すると見ると、密度の差 0.02 g/cc で 60 MWd/kg の −42 pcm。比例は確かめていない）
- 追わない核種の分は、密度では瞬時の条件（0.661 か 0.743 g/cc）にほとんど依らない（違いは最大 2.1 pcm（60 MWd/kg）、相対で 10〜60 MWd/kg の 1.0〜4.3%）。制御棒では瞬時の制御棒の有無で
  大きく違う（10 MWd/kg で −56.4 と −16.8 pcm。Δρ の 1/(k k′) を除いた k の差で、制御棒を入れた側が 2〜10 MWd/kg で約 1.9 倍、30 MWd/kg で
  ほぼ同じ、60 MWd/kg で 0.66 倍）
- 追わない核種を核種ごとに分けていない。燃焼度 0 では、分岐が履歴の点を 0.051 pcm 以内で再現する
- 測ったのは輸送で解いた差で、下の決定の残り R（ミクロ燃焼の線形の補正 Σᵢ σᵢ ΔNᵢ を引いたもの）ではない。R は追わない核種の分に、
  追う核種の線形化の誤差を足したもので、その大きさは #0153 の σᵢ ができるまで測れない。ミクロ燃焼が追う核種を上の 26 より少なく
  選べば、追わない核種の分は変わる（大きさと符号は確かめていない。上の測定では追う核種の分と追わない核種の分の符号が逆）

### 既にある見方

- [#0153](../issues/0153-burnup-table-micro-and-kinetics.md): ミクロ燃焼の核種の均質化した数密度（燃焼度の点ごと）と微視的断面積（状態ごと）の置き場は ADR-0187 で決めたが、
  lattice はまだ書かない。この ADR の残りの定数は、その微視的断面積と数密度を引いて作るので、#0153 が先に要る
- ADR-0187 の案 B3（履歴の効果を別の軸に持ち、瞬時の分岐を持たない）は、瞬時の状態の効果を表せないので採らず、履歴の変数は瞬時の
  分岐に加える補正とした。ADR-0187 の判断の軸は、履歴の違いを ADR-0035 のミクロ燃焼と履歴の補正に任せる
- ADR-0200 で、離散の軸（制御棒）を公称の状態の差だけで持つと 2,780 pcm の誤差になった。制御棒の有無で残りが変わる上の測定と同じく、
  制御棒の効きが状態で大きく変わることが候補
- [#0135](../issues/0135-depletion-pin-powers-per-point.md): 燃焼点ごとのピン出力は ADR-0181 で履歴に入れた。ピン出力の形状関数の履歴の補正は、ここで扱わない
- [#0168](../issues/0168-reuse-dancoff-across-branch-states.md): 履歴からの分岐の Dancoff 係数の持ち越し（時間の話で、ここの決定に影響しない）
- [#0174](../issues/0174-nominal-table-from-history.md)（閉じた）: 公称の状態の少数群定数を燃焼の履歴の点から取る。履歴の分岐の自分の条件の定数も同じく取れる
- [ADR-0178](0178-verify-assembly-depletion.md) は、密度の差が ±1.3% では履歴の効果が ±100 pcm の目標より小さく分けられないので、履歴を変えた燃焼を
  0.661 g/cc と案内管すべての AIC にした。上の大きさはこの極端な 2 本のもの

## 検討した案

先行例（出典つき）:

- SIMULATE5（Studsvik, "SIMULATE5 Overview," NRC Pre-Submittal Meeting (2015-04-08)、https://www.nrc.gov/docs/ML1508/ML15083A470.pdf 。
  スライド 9 と 18）: 巨視的断面積を、ρ_h の関数の基準の値 Σ^base(E, ρ_h) に、瞬時の変数の差分の項（ΔΣ^BOR(E, ρ)、ΔΣ^TFU(E, ρ)、
  ΔΣ^CRD(E, ρ) など）と、別に足す履歴の項（ΔΣ^HBOR(E)、ΔΣ^HTFU(E)、ΔΣ^HCRD(E, CRD)）と ΔΣ^BCRD(E, CRD)（何の項かは資料から読み取れない）を
  足し、さらにミクロ燃焼の補正 Σᵢ σᵢ(E, ρ_h, ρ, …) (Nᵢ^actual − Nᵢ^SA(E, ρ_h, …)) を足す（スライド 9 の式。E は燃焼度）。履歴の変数は
  EXP、HTMO、HBOR、HTFU で、ノードごとに作る（ρ_h は減速材の履歴の HTMO に当たるとみられるが、確かめていない）。ミクロ燃焼の核種は、
  スライド 18 の見出しが「17 actinides/~30 Fission products/BA (node level)」、その下の項目が 16 のアクチニド、30 余りの核分裂生成物、
  可燃性毒物（B-10、Gd）で、数が食い違う。Nᵢ^SA は単一集合体の計算の数密度で、ρ_h の関数なので、ミクロ燃焼の補正は同じ履歴の格子計算の
  数密度からの差になる。ほかの履歴の項とミクロ燃焼の補正の重なりの扱いは、この資料から読み取れない。履歴の変数の定義（重み）と、格子計算の履歴の分岐の条件は、この資料にない（出典を確かめていない）
- SIMULATE-3: 巨視的断面積のモデルで、最近の燃焼の条件に大きな重みを付ける（R. J. Borland, H. Fu, "Evaluation of spectral history effects in
  B&W PWRs using Studsvik CMS," Trans. Am. Nucl. Soc. 73 (1995)、OSTI 411765 の要旨だけ読んだ）。履歴の変数の定義と重みの式は出典を確かめていない。
  ADR-0035 は、履歴の変数による補正だけの形を近似が多いとして採らなかった
- PARCS と PMAXS（B. Meunier, "Multi-Cycle PWR Modeling with DRAGON and PARCS," arXiv:2509.19450 (2025)。3.1〜3.3 節）: 履歴の分岐は
  「参照の履歴から 1 つの変数だけを変えた」燃焼で、履歴ごとに分岐の木を持つ PMAXS を作り、1 つのファイルにまとめる（3.3 節）。3.1 節の式 (3.4)〜(3.6) は
  制御棒の位置（0 と 1）と冷却材の密度の点の間の線形の内挿の例で、表 1 の分岐と対応する。履歴の間を core がどう引くかは、この論文から
  読み取れない（確かめていない）。履歴の変数は
  H(B₀ + ΔB) = (H(B₀) B₀ + ω V₁ ΔB) / (B₀ + ωΔB)（3.1 節の式。V₁ はステップの終わりの値、ω は重み）で、PARCS のマニュアルは ω を 2〜2.5 と
  勧め（論文の引用 [11]。マニュアルは読んでいない）、論文は Pyrex の挿入の履歴に 2.25、減速材の密度の履歴に 1.0 を使い、理論の根拠は
  ないと書く。減速材の密度の履歴は 0.65、0.71、0.77 g/cc の 3 本（3.2 節）。Turkey Point 3 の 3 サイクルで、履歴をひとつずつ足した臨界ホウ素の
  比較（序論の図 1。Polaris の断面積）では、Pyrex の挿入の履歴が最も効き、次が減速材の密度の履歴、ホウ素の履歴はずっと小さく、燃料の
  温度の履歴はほとんど見えない。PARCS がミクロ燃焼と履歴の補正をどう重ねるかは、この論文にない（出典を確かめていない）
- CASMO の履歴の分岐（条件を変えた燃焼を、燃焼点からの分岐と組みで流す入力）: 出典を確かめていない
- ANC の spectral history index（Pu の蓄積に結びつけた指標）: DYN3D の論文の検索の要約で見ただけで、出典を確かめていない

履歴の補正の形:

- 案 C1（履歴の分岐ごとに分岐のテーブルを丸ごと持ち、core が履歴の変数でテーブルの間を内挿する。PMAXS が履歴ごとに分岐の木を持つ形）:
  分岐のテーブルの状態（ADR-0200 の 397〜777 状態）を履歴の分岐の数だけ解く。ミクロ燃焼と重ねるには、ミクロ燃焼の基準の数密度も
  テーブルごとに持ち、履歴の変数で内挿した数密度からの差にする（SIMULATE5 の Nᵢ^SA(E, ρ_h, …)）。履歴の効きは追う核種の分でほぼ尽き
  （97.1〜103.5%）、追わない核種の分の瞬時の密度への依存は最大 2.1 pcm（相対で 10〜60 MWd/kg の 1.0〜4.3%）なので、テーブルを丸ごと持つ費用に見合わない（R の状態への依存は、
  線形化の誤差を含めて測ってから見直す。「確認」。今の既定で測った R の依存は最大 −7.48 pcm、公称の状態で使った誤差は最大 −18.50 pcm で
  目安を超え、見直しは #0190）
- 案 C2（SIMULATE5 の形: 基準の定数を履歴の変数の関数にし、ミクロ燃焼の補正を同じ履歴の格子計算の数密度からの差にする）: 二重に数えない
  形だが、基準の定数の履歴への依存を、ミクロ燃焼が担う分も含めて持つので、C1 と同じく履歴の分岐ごとに状態を解く
- 案 C3（履歴の分岐の自分の条件でだけ、ミクロ燃焼の線形の補正を引いた残りを持ち、core は履歴の変数の差に比例して足す。採用）: 履歴の
  分岐 1 本あたり、燃焼 1 回と、自分の条件の状態を燃焼点の数だけ。残りは追わない核種の分と、ミクロ燃焼の線形化の誤差（その点で）を含む。
  連続の軸の瞬時の状態への依存は持たない（密度で最大 2.1 pcm。追わない核種の分の値で、R の測定は「確認」）が、制御棒の値ごとには持つ（制御棒の有無で追わない核種の分が k の差で
  0.66〜1.9 倍に違い、燃焼度とともに向きも変わる）
- 案 C4（履歴の補正を持たず、ミクロ燃焼だけ）: 追わない核種の分が目安の 5 pcm を超える（密度は 10〜20 MWd/kg から、制御棒は 2 MWd/kg から）
- 案 C5（追う核種を増やして残りを 5 pcm より小さくする）: 追わない核種を核種ごとに分けていないので、何を足せば足りるか分からない。
  追う核種の選び方は #0153 と「進め方」7 で決めるので、この ADR はどの選び方でも残りを担う形にする

ミクロ燃焼の微視的断面積と基準の数密度の履歴（2026-10-30。core の側の測定で、一生を条件 j で燃焼させた core の追う核種の数密度が
第 1 項のテーブルより少なく（Pu-239 −0.925%、Pu-240 −1.911%、Pu-241 −0.828%、U-235 −1.756%）、k が第 1 項の k∞ から 60 MWd/kg で −245.402 pcm 離れた。R の足し方の誤差は 1e-5 pcm 以内
（反応率を補正する前の版。ブランチ feat/0190-history-core の 8e6c0b77、Slurm 625。値は #0190 の経緯）。同じ燃焼を
第 1 項のテーブル（σᵢ、N̄ᵢ、定数がどれも履歴の分岐のもの）ですると、差は −4.284〜+8.549 pcm で、公称の燃焼の core と公称のテーブルの差
−3.808〜+7.714 pcm と同じ水準。この比べ方は σᵢ、N̄ᵢ、定数を一度に替えるので、それだけでは原因を σᵢ に絞れない。反応率の σᵢ だけを
履歴の分岐の値にした燃焼（下の案 S2 の実装で w = 1。定数は R を持つ公称のテーブルから）でも差は −3.788〜+8.551 pcm（60 MWd/kg で −1.465 pcm）に
なり、原因は core のミクロ燃焼の反応率が公称の履歴の組成で解いた σᵢ を使うこと（σᵢ の違いを、履歴の分岐の組成のスペクトルと自己遮蔽などに
分けていない）。記録は examples/depletion/verification.md の「履歴の補正の core（2A の集合体 1 体）」。以下、σᵢ^j、cᵢ^j、N̄ᵢ^j、f^j は
第 1 項のテーブル（履歴の分岐の組成、条件 j）の値、cᵢ(j)、f(j) は公称のテーブルの条件 j の状態の値、ΔN̄ᵢ = N̄ᵢ^j − N̄ᵢ^0）:

- 案 S1（SIMULATE5 の形を案 C3 の費用で）: 反応率と線形の補正の係数を cᵢ(x, u) + w (cᵢ^j(u) − cᵢ(j, u))、線形の補正の基準を
  N̄ᵢ(w) = N̄ᵢ^0 + w ΔN̄ᵢ にし、R を第 3 項のない定数の差 R' = f^j − f(j) にする。w = 1、x = j、Nᵢ = N̄ᵢ^j で線形の補正が 0 になり
  f = f(j) + R' = f^j、w = 0 で今と同じ。追う核種の違いのうち、履歴から見込む分 w ΔN̄ᵢ は R' が、そこからの外れ Nᵢ − N̄ᵢ(w) は線形の補正が
  担い、二重に数えない（ただし判断の軸の「追う核種の違いはミクロ燃焼の補正だけが担う」とは分け方が違う）。費用は、`histories` に cᵢ^j

## 決定と理由

### 履歴の変数（案 V1）

core はノードごとに、次の履歴の変数を燃焼度で重みを付けた平均で持つ: 減速材の密度 H_m（g/cc）、制御棒の挿入の割合 H_r（0〜1。ノードの
高さのうち制御棒が入った割合）、Pyrex の集合体だけ Pyrex の挿入 H_p（0〜1）。

H(B) = (1/B) ∫₀ᴮ x dB'

燃焼のステップ（[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の中点の形）では、ステップの燃焼度の増分 ΔB と、ステップの中点の解の値 x̄ で
H(B₀ + ΔB) = (H(B₀) B₀ + x̄ ΔB) / (B₀ + ΔB) と進める。燃焼度 0 の値は、その燃焼度での瞬時の値（B = 0 では残りが 0 なので、補正に効かない）。
ホウ素と燃料の温度の履歴の変数は持たない。

### 履歴の分岐（数と条件）

集合体の種類ごとに、公称の燃焼（ADR-0187 のテーブルの元の履歴）に加えて、次の燃焼を流す。燃焼度の点は公称の燃焼と同じ（[ADR-0199](0199-add-a-burnup-point-at-14.md) の 27 点）:

- 減速材の密度の履歴の分岐: 減速材の密度だけを公称と違う 1 つの値にして一生を燃焼させる。値は分岐のテーブルの減速材の軸の格子点の 1 つ
  （熱水力の ADR で決める軸の、公称でない点）にし、その条件への瞬時の分岐がテーブルの格子点（ADR-0200 の 1 軸の分岐）になるようにする
- 制御棒の履歴の分岐: 制御棒を入れたまま一生を燃焼させる（2A-rods と同じ。ADR-0200 の制御棒を入れた組の公称の状態の格子）
- Pyrex の集合体は、Pyrex のない格子の公称の燃焼を足す（下の「Pyrex を抜いた集合体」）

履歴の分岐の数は、変数ごとに 1 本（変数の 2 点）。補正は変数の差に比例すると置く（「確認」で測る）。

### テーブルに持つ補正（案 C3）と、core の重ね方

履歴の変数 j の履歴の分岐（変数の値 H_j^b、公称の燃焼の値 H_j^0）について、lattice は燃焼度の点 u と制御棒の値 r ごとに、少数群定数の
各項目 f の残り R_j,r(u) を作る:

R_j,r(u) = f(履歴の分岐 j の組成、条件 j、制御棒 r) − f(公称の組成、条件 j、制御棒 r) − Σᵢ cᵢ(条件 j、r、u) (N̄ᵢ^j(u) − N̄ᵢ^0(u))

を、公称の組成のうち追う核種（ミクロ燃焼の核種。#0153）だけを履歴の分岐 j の値にした組成（ハイブリッド）の定数 f(H_j、条件 j、r) で 2 つに分けて持つ:

U_j,r(u) = f(履歴の分岐 j の組成、条件 j、r) − f(H_j、条件 j、r)（追わない核種の分）
L_j,r(u) = f(H_j、条件 j、r) − f(公称の組成、条件 j、r) − Σᵢ cᵢ(条件 j、r、u) (N̄ᵢ^j(u) − N̄ᵢ^0(u))（追う核種の線形化の誤差）

- 第 1 項は、履歴の分岐の履歴を読んだ ADR-0187 の分岐（`[history]`）を、自分の条件で解いた定数（燃焼度の点ごとに制御棒の値の数だけ輸送）。
  ハイブリッドは、その履歴の追う核種の数密度を公称の燃焼の履歴に入れた組成を、同じ点と条件で解いた分岐（同じ数だけ輸送）。均質化した
  数密度 N̄ᵢ は燃焼の領域の体積の平均なので、ハイブリッドの N̄ᵢ は履歴の分岐と同じ
- 第 2 項は、公称の燃焼から作った分岐のテーブルの、条件 j の状態（格子点）の定数。R を持つ燃焼度の点は、テーブルが第 2 項の状態を
  格子計算で解いた燃焼点から選び、最初と最後を含む（公称の状態は 27 点のすべて、公称でない状態は ADR-0200 の、その組の公称でない状態を
  解く燃焼点。制御棒を入れた組と、Gd と Pyrex の集合体の組は、ADR-0200 のとおり #0176 で測るまで 27 点のすべて）。点は
  （変数、制御棒の値）の組ごとに選ぶ。ほかの燃焼点のテーブルの値は公称の状態との差の
  内挿で、格子計算の値でないため
- 第 3 項は、ミクロ燃焼の線形の補正（[#0153](../issues/0153-burnup-table-micro-and-kinetics.md) の、テーブルの微視的断面積 σᵢ と均質化した数密度 N̄ᵢ）を、core が使うのと同じ
  係数 cᵢ で引いた分。cᵢ は、テーブルに数密度の微分を持つ核種は ∂Σ/∂N̄ᵢ、ほかは σᵢ（[ADR-0221](0221-correct-micro-linearization-by-number-density-derivatives.md)。吸収は全断面積の係数から
  散乱の行の和を引いたもの）。ミクロ燃焼の補正を持たない項目（拡散係数、ADF など）では 0
- 条件 j は、履歴の分岐の条件（密度の履歴なら公称と違う密度、ほかの軸は公称）。制御棒の履歴の分岐の条件 j は制御棒を入れた状態で、
  制御棒を抜いた値 r の残りは、その組成を制御棒を抜いた格子で解く（逆向きの分岐）

core はノードの少数群定数を次で求める（ノードの瞬時の状態 x、燃焼度 u、制御棒の値 r）:

f = f_table(x, u, r) + Σᵢ cᵢ(x, u, r) (Nᵢ − N̄ᵢ^0(u)) + Σ_j [w_j U_j,r(u) + (P / P_j,r(u)) L_j,r(u)]、w_j = (H_j − H_j^0) / (H_j^b − H_j^0)

P = Σᵢ cᵢ_νf,G(x, u, r) (Nᵢ − N̄ᵢ^0(u))、P_j,r(u) = Σᵢ cᵢ_νf,G(x, u, r) ΔN̄ᵢ^j(u)

- P は熱群（最後の群 G）の νΣf の線形の補正（ノードの数密度の差のもの）、P_j は同じ係数の履歴の分岐の数密度の差 ΔN̄ᵢ^j = N̄ᵢ^j − N̄ᵢ^0 の
  もの（「検討した案」の案 R4 の指標 (ii)）。ΔN̄ᵢ^j は R の点で作り、U と L と同じ燃焼度の内挿で引く（R の点が燃焼度の軸の点の一部のとき、
  2 つの数密度を別々の点で内挿した差にしない）。係数 cᵢ_νf は線形の補正と同じ（数密度の微分を持つ核種は ∂νΣf/∂N̄ᵢ）
- 第 2 項がミクロ燃焼の補正で、追う核種の違いはこの項が担う。L はこの項と同じ係数 cᵢ の線形の補正の誤差（履歴の分岐の組成での）で、
  ノードの追う核種の数密度の差を線形の補正に足すのでなく、その線形の補正の誤差の見込みを、ノードの組成の差の大きさ（P）の履歴の分岐の
  組成の差の大きさ（P_j）に対する比で足す。線形の補正が担う分を重ねて足さないので、二重に数えない（前の版も同じ L を R の中で w 倍して
  足していた）。U は追う核種が同じ 2 つの組成の差で、第 2 項と重ならない
- 履歴の分岐の点（w_j = 1、条件 j、ノードの数密度が履歴の分岐のもの）では、P = P_j で L の係数も 1 なので、core は第 1 項の格子計算の定数を
  そのまま返す。ノードの数密度をその点に導くミクロ燃焼の反応率の σᵢ は、下の「ミクロ燃焼の反応率の微視的断面積（案 S2）」で履歴の分岐の
  値に補正する
- w_j が厳密に 0 の変数は U も L も足さない（公称の履歴は補正を持たないテーブルとビットで同じ定数）。ΔN̄ᵢ^j がすべて 0 の燃焼度（燃焼度 0。
  履歴の分岐の組成が公称と同じ）は、ハイブリッドが公称の組成そのもので L は定義から 0 なので、L を足さない（テーブルの値は 2 つの格子計算の
  解の差）。ΔN̄ᵢ^j が 0 でないのに P_j が 0 ならエラー（黙って w などで置き換えない）
- 履歴の変数が複数（制御棒、Pyrex）のとき、P はノードの組成の差の全体なので、変数ごとに P / P_j を掛けると L を重ねて足す。変数の間の分け方は、
  その変数を足すときに決める（#0190。今の core は減速材の密度の変数だけを持つ）
- U と L は連続の軸の瞬時の状態に依らない（条件 j の値を使う）。測った密度の履歴では、瞬時の密度による追わない核種の分の違いは最大 2.1 pcm。
  ただし、この 2.1 pcm は追わない核種の分（ADR-0209 の前の既定、565 K）の値で、線形の補正の誤差を含む R を今の既定で測ると、状態への依存は
  最大 −7.48 pcm、条件 j の R を公称の状態で使った誤差は最大 −18.50 pcm で目安を超えた（下の「確認」）。この決定の見直し（案 C1 の側）は #0190 で決める。
  制御棒の値ごとには持つ（制御棒の履歴では、制御棒の有無で追わない核種の分が k の差で 0.66〜1.9 倍に違う）。制御棒が一部だけ
  入ったノードは、制御棒の値の補正を足した定数を [ADR-0127](0127-weight-partially-rodded-nodes-by-axial-fine-mesh-flux.md) と同じ重みで混ぜる
- 燃焼度について U、L、ΔN̄ᵢ^j を ADR-0192 の内挿で引き、範囲の外はエラー（外挿しない）。履歴の変数ごとの補正は足し合わせ、変数の間の交差は
  持たない（測っていない）

### ミクロ燃焼の反応率の微視的断面積（案 S2）

core は、ミクロ燃焼のノードの追う核種の反応率（ADR-0216 の反応率と、中性子束の大きさの規格化）に使う微視的断面積を、テーブルを状態と
燃焼度で内挿した σᵢ(x, u, r) に、履歴の変数ごとの差を足したものにする:

σᵢ^rate(x, u, r) = σᵢ(x, u, r) + Σ_j [w_j Δσᵢ_U,j,r(u) + (P / P_j,r(u)) Δσᵢ_L,j,r(u)]

Δσᵢ_U,j,r(u) = σᵢ(履歴の分岐 j の組成、条件 j、r、u) − σᵢ(H_j、条件 j、r、u)（追わない核種の分）
Δσᵢ_L,j,r(u) = σᵢ(H_j、条件 j、r、u) − σᵢ(公称の組成、条件 j、r、u)（追う核種の組成の分）

- H_j は U と L のハイブリッド、w_j と P / P_j は定数の U と L と同じ（「検討した案」の案 R7）。和 Δσᵢ_U + Δσᵢ_L は履歴の分岐と公称の組成の
  差 σᵢ(履歴の分岐 j の組成、条件 j) − σᵢ(公称の組成、条件 j)

- 差の第 1 項は R の第 1 項と同じ分岐（`[history]`）の微視的断面積、最後の項は公称のテーブルの条件 j の状態（格子点）の値。燃焼度の点、制御棒の
  値、w_j、燃焼度の内挿（ADR-0192。範囲の外はエラー）、部分挿入のノードの混ぜ方（区間ごとに足してから ADR-0217 の重みで混ぜる）は R と同じ
- 補正する項目は反応率に使うものだけ: チェーンの反応の経路ごとの断面積、核分裂の断面積、収率の境界より下の核分裂の断面積（割合 × 群の和の
  σf。ADR-0216 の内挿と同じく断面積で足し、補正した σf の群の和との比を割合にする）。線形の補正の係数 cᵢ（全断面積、νσf、σf、散乱行列、
  数密度の微分）、基準 N̄ᵢ^0、R の定義は変えない。履歴の分岐の点（w_j = 1、条件 j、ノードの数密度が N̄ᵢ^j で P = P_j）で、反応率は第 1 項の
  σᵢ^j、定数は f(j) + Σᵢ cᵢ(j) ΔN̄ᵢ + R = f^j になる。係数まで補正すると、その点に Σᵢ (cᵢ^j − cᵢ(j)) ΔN̄ᵢ が残る
- 数密度の微分を持つ核種（ADR-0221）も、反応率の σᵢ はほかの核種と同じく補正し、係数の微分は公称のテーブルの値のまま（履歴の分岐の点の
  微分との違いの分は R に入る）。第 1 項の分岐は微分を持たなくてよい
- Δσ は R と同じく連続の軸の瞬時の状態に依らない（条件 j の値）。状態への依存は測っていない（R と一緒に #0190 で見直す）
- w_j が厳密に 0 の変数は足さない（公称の履歴の反応率は、補正のないテーブルとビットで同じ）。ΔN̄ᵢ^j がすべて 0 の燃焼度は、L と同じく
  ハイブリッドが公称の組成そのもので Δσ_L は定義から 0 なので、Δσ_L を足さない。補正した断面積が負か、割合が 0〜1 の外なら
  エラー（黙って切らない）

### Pyrex を抜いた集合体（案 Q1）

Pyrex を入れている間は、Pyrex の集合体のテーブル（Pyrex を入れた公称の燃焼から作る）を使い、H_p の補正は使わない。抜いた後は、同じ集合体の
Pyrex を抜いた格子（案内管の中が減速材）を公称の燃焼として作ったテーブルを使い、Pyrex の履歴の変数 H_p（Pyrex を入れて燃焼させた燃焼度の
割合。抜いた後は B_抜く / B）で、Pyrex の燃焼を履歴の分岐（H_p^b = 1、H_p^0 = 0）とした残り R_p を足す。R_p の第 1 項は、Pyrex の燃焼の履歴を
Pyrex を抜いた格子で解いた分岐（案内管の中身を変えた格子の分岐。ADR-0187）。Pyrex を抜いた格子の公称の燃焼は、同じ濃縮度の毒物のない
集合体の燃焼と同じなので、装荷にその集合体があれば共有する。

### 出力の形（ADR-0026 の「履歴の補正のデータ」）

`xlc-table` に、履歴の変数ごとの項目 `histories` を足す。変数の名前（`moderator-density`、`rods`、`pyrex`）、公称の燃焼の値 H^0、履歴の分岐の
値 H^b、制御棒の値ごとの、R を持つ燃焼度の点（上の規則で選んだ点）と、その点ごとの U と L（状態の少数群定数の項目のうち、全断面積、吸収、
νΣf、核分裂、χ、拡散係数、散乱行列、ADF。k∞、真空の辺の比、ピン出力の形状関数は持たない）と、履歴の分岐の均質化した数密度 N̄ᵢ^j（core が
P_j を作る）。ミクロ燃焼の補正を持たない項目（χ、拡散係数、ADF）の L は線形の補正の項が 0 で、2 つの定数の差（履歴の分岐の点で core が第 1 項の
定数を返すため）。R の点ごとに、追う核種ごとの反応率の微視的断面積の差 Δσ_U と Δσ_L（上の案 S2 と案 R7）も持つ。ミクロ燃焼の σᵢ と N̄ᵢ は ADR-0187 の置き場（#0153）。
lattice は、履歴の分岐の自分の条件の分岐（`[history]`）のテーブル、同じ条件のハイブリッドのテーブルと、公称のテーブルから U、L、Δσ_U、Δσ_L を作り、
公称のテーブルに書く。R を 1 つで持つ前の形は読まない（後方互換を作らない）。

実装（#0190）: ファイルの形は `histories` の列で、項目ごとに `variable`、`nominal`（H^0）、`branch`（H^b）、`rods`（`rod`、`burnup`（MWd/kg）、
`untracked` と `linearization`（どちらも `total`、`absorption`、`nu_fission`、`fission`、`chi`、`diffusion`、`scatter`、`adf`）、`densities`（R の
点ごとの、追う核種の順の N̄ᵢ^j）、`micro`（`untracked`（Δσ_U）と `linearization`（Δσ_L）の map で、どちらも R の点ごとの、追う核種の
順の `fission`、`reactions`（`mt` と経路ごとの `channels`）、`thermal_fission`（収率の境界より下の核分裂の断面積の差。核分裂しない
核種は nil で、キーは省けない）。分けない 1 つの列の前の形は読まない））。持たないテーブルはキーを書かない（crates/format/src/table.rs）。テーブルの検査は、ミクロ燃焼のデータを持つこと、変数が重ならず、H^0 と H^b が減速材の軸の公称と公称でない
1 つの格子点の密度で、制御棒の値が軸の値（軸がなければ `out`）、燃焼度の点がその条件の状態（変数の軸だけが H^b の格子点で、ほかの軸は
公称）をテーブルが解いた燃焼度の点で増え、最初と最後を含むこと、U と L が点ごとに状態と同じ群と辺の数の有限の値であること、N̄ᵢ^j が点ごとに
追う核種の数の有限の負でない値であること、Δσ_U と Δσ_L のそれぞれが点ごとに追う核種の数だけあり、反応の並びと核分裂の有無がミクロ
燃焼のデータと同じで、群の数の有限の値であること、ΔN̄ᵢ^j がすべて 0 の点（core が L と Δσ_L を足さない点）の L と Δσ_L が条件 j の状態の
値（項目ごとの絶対値の最大）の 1e-6 以内（同じ組成と状態の 2 つの格子計算の解の差。MOC の中性子束の収束の判定の大きさ）であること。変数は今は `moderator-density` だけを受け、`rods` と `pyrex` は、その
履歴の分岐を作る作業で検査と一緒に足す。結合は lattice の副コマンド `lattice histories <入力>`（crates/lattice/src/residual.rs）で、
入力（TOML）は公称のテーブル `nominal`、出力 `output`、`[[history]]` ごとの `variable` と制御棒の値ごとの履歴の分岐の自分の条件の
テーブルとハイブリッドのテーブル `branches`（`{ out = { branch = "…", hybrid = "…" } }`）。ハイブリッドのテーブルは、分岐のテーブルと同じ軸と
点、追う核種、初めの重金属、群境界と、同じ均質化した数密度を持ち、ミクロ燃焼の σᵢ の反応の並びと核分裂の有無が分岐と公称のテーブルと
同じこと（違えばエラー）。条件 j は履歴の分岐のテーブル（燃焼度の軸のほかは点が 1 つ）の値を公称のテーブルの格子点に引いて決め、変数の
値 H^0 と H^b もその格子点の密度から取る（入力に書かせると格子点と食い違いうる）。履歴の分岐のテーブルの燃焼度の点は、公称のテーブルが
条件 j を解いた燃焼度の点と同じこと、追う核種と初めの重金属が同じことを求め、R を持つ公称のテーブルに重ねて足すとエラー。
制御棒のテーブルをまとめる examples/core/rod_table.py（#0093 までのつなぎの Python）には倣わず、本番の経路を lattice に置いた。
core は `histories` を持つテーブルの R を、ミクロ燃焼のノードに足す（下の「帰結」）。
2A の測定の減速材の密度の履歴の分岐は、減速材の軸の格子点が温度と密度の組なので、減速材と被覆管の温度も変えた履歴（565 K から 600 K）で、
R はその温度の履歴の分も含む。core は変数を密度だけで持つので、ノードの密度の履歴と温度の履歴が格子点の組と同じ関係で動く（一定の圧力の
飽和に近い関係）と置いている（確かめていない。#0190）。

### 理由

- 2A の履歴の効きは追う核種の分でほぼ尽き（97.1〜103.5%）、追わない核種の分は 60 MWd/kg で密度の履歴 −171 pcm、制御棒の履歴 −546 pcm と、
  目安の 5 pcm を超える。補正を持たない案 C4 は採れず、テーブルを丸ごと持つ案 C1、C2 は、瞬時の密度に最大 2.1 pcm しか依らない残りのために
  分岐のテーブルを履歴の分岐の数だけ解く（2.1 pcm は追わない核種の分の値。線形の補正の誤差を含む R は「確認」の測定で目安を超え、
  見直しは #0190）
- 残りを自分の条件の格子点で、core と同じ係数 cᵢ の線形の補正を引いて作るので、履歴の分岐の点で格子計算の定数を返し、ミクロ燃焼と
  二重に数えない
- 残りを U と L に分け、L を熱群の νΣf の線形の補正の比で足すのは、途中で条件を変えた燃焼で R を 1 つの w で足した差（+3.751〜+52.248 pcm）の
  大半が L の比例からの外れで、L が w でなく追う核種の組成の差に 1 次で近いため（「検討した案」の案 R4。格子計算の組成で測った L の外れは
  w の +17.903〜+48.388 pcm から −1.096〜+3.892 pcm）。重み ω、2 次の内挿、指数の忘却の重み（案 R2、R3、R5）はどれも目安に入らない。
  指標の比は反応度の比（i）だと燃焼度の前半で発散するので、符号を変えない熱群の νΣf の補正の比（ii）にした。U と L を分ける費用は、
  履歴の分岐の自分の条件の分岐 1 本ごとに、同じ点と条件のハイブリッドの分岐 1 本（下の費用）
- ミクロ燃焼の反応率の σᵢ を履歴の分岐の差 Δσ で補正する（案 S2）のは、一生を条件 j で燃焼させた core の数密度の違い（k の差 60 MWd/kg で
  −245.402 pcm）が反応率の σᵢ の履歴への依存で、定数の残りでは直らないため。線形の補正と R を変えない S2 は、判断の軸の「追う核種の違いは
  ミクロ燃焼の補正だけが担う」をそのまま保ち、テーブルに足すのは反応率の項目の差だけで、2A の第 1 項の分岐（Pu-240 の微分を持たない）を
  解き直さずに作れる。基準と係数も履歴で補正する案 S1 との差は、x = j では係数の違いとノードの数密度の S1 の基準からの外れの積で、
  ノードが見込みの数密度にあれば 0。公称の状態で使った誤差は S1 が最大 10.67 pcm（10 MWd/kg）、S2 が最大 −18.50 pcm（60 MWd/kg）で、どちらが良いとは決まらない（「検討した案」）
- Δσ を U と L と同じハイブリッドで分けて同じ重みで足す（案 R7）のは、Δσ が追わない核種の分（w に比例すると置く U と同じ）と追う核種の
  組成の分（組成の指標の比で足す L と同じ）を含み、1 つの重みでは片方を違う重みで足すため。追加の格子計算は無い（ハイブリッドの分岐が σᵢ を
  持つ）。途中で条件を変えた燃焼では案 R6 とほとんど変わらず目安に入らないが、Δσ_U の外れは小さく、残りの外れが Δσ_L の側にあると分けて示せる
- 費用は、毒物のない集合体 1 種あたり燃焼 2 回と、R の状態（履歴の分岐 2 本 × 制御棒の値 2 の 4 組、組ごとに燃焼点の数）。前の既定と
  16 スレッドの時間で、燃焼は 2A-density が 18 分 55 秒（Slurm 522）、2A-rods が 39 分 27 秒（Slurm 523。どちらも比較のステージを含むので
  少し多い）。R の状態は ADR-0200 の 1 状態の目安（制御棒なし 15 秒、あり 32 秒。割り込まれうるジョブの目安）で、制御棒を入れた 2 組と
  制御棒の履歴の抜いた組（公称の状態）を 27 点、密度の履歴の抜いた組を 10〜27 点とすると約 38〜42 分。U と L に分けるハイブリッドの分岐が
  R の状態と同じ数だけ要り（同じ点、条件、制御棒の値）、さらに約 38〜42 分で、和は約 2.2〜2.4 時間。同じ前の
  既定の分岐のテーブルの約 2.6〜5.4 時間（ADR-0200）より小さい。Pyrex の集合体は、Pyrex を抜いた格子の燃焼 1 回と R_p の状態（制御棒の
  値 2 の 2 組）を足し、組はどれも 27 点。ADR-0209 の既定と 32 スレッドの燃焼は 2A で 37 分 28 秒（前の既定と 16 スレッドの約 2 倍）で、
  2A-density、2A-rods と分岐の状態は測っていない。燃焼の時間は 41 点（輸送 81 回）のもので、27 点の燃焼ならそれより短い（測っていない）。
  Pyrex の集合体で、同じ濃縮度の毒物のない集合体が装荷に無ければ、Pyrex を抜いた格子のテーブルの密度と制御棒の履歴の分岐（燃焼 2 回と
  4 組）も要る。Gd の集合体は、燃焼が 2A より長く（2O、2P は 71 点）、組はどれも 27 点で、見積もっていない

## 帰結

- lattice: 集合体の種類ごとに履歴の分岐の燃焼 2 本（Pyrex の集合体は Pyrex を抜いた格子の公称の燃焼も）と、その自分の条件の分岐と、
  ハイブリッドの分岐を流し、U と L をテーブルに書く。U と L の作成と書き込みは、減速材の密度の変数と制御棒の値 `out` について
  `lattice histories`（上の「出力の形」）で済んだ（ブランチ feat/0190-history-residual-lattice、U と L はブランチ feat/0190-split-residual-core）。
  ハイブリッドの組成（公称の燃焼の履歴の追う核種を履歴の分岐の値にしたもの）は、今は examples/depletion/history/make_hybrid.py（`--micro`）が
  燃焼の履歴を書き換えて作る。本番の経路（lattice の入力で選ぶ）は #0190 に残る。同じ点の反応率の微視的断面積の差 Δσ（案 S2）も `lattice histories` が書く
  （ブランチ feat/0190-history-micro-sigma。crates/lattice/src/residual.rs の `rate_difference`）。制御棒の履歴（制御棒の軸のテーブルの結合 examples/core/rod_table.py と絡む）と
  Pyrex の変数、制御棒を入れた値の R は #0190 に残る
- lattice: 途中で条件を変えた燃焼（「確認」）は、`[depletion]` の `continue = { file, burnup }` で、既存の燃焼の履歴の燃焼点から
  この入力の条件で燃焼を続ける（crates/lattice/src/depletion.rs の `continued_start`、入力の説明は crates/lattice/src/input.rs。ブランチ
  feat/0190-history-switch-lattice）。続ける点より前の点を履歴から引き継ぎ、続ける点の組成と時間（燃焼度と出力の基準の初めの重金属の質量は
  燃焼度 0 の組成のもの）からチェックポイントの再開（ADR-0196）と同じく CE/CM を進め、燃焼度 0 からの 1 本の履歴（`[history]` で分岐を
  解ける）を書く。続ける点は、core の燃焼点がそこから始まるステップの状態で解く（ADR-0218）のと同じく、この入力の条件で解き直す。
  履歴は続けた燃焼点を `continued` に持つ（続けない燃焼の履歴はキーを書かず、今の出力のバイトは変わらない）。燃焼の領域、チェーンの
  核種、輸送する核種、燃焼度 0 の組成、少数群定数の有無と群境界と `pins` が履歴と違うか、履歴が続けた履歴ならエラー
- core: ミクロ燃焼のノードごとに H_m を燃焼のステップで進め（燃焼度 0 の値は燃焼点 0 を解く状態の瞬時の値、出力のステップはステップの状態の
  値、中点の解は中点の燃焼度までの値。crates/core/src/depletion.rs の `advance_history`）、燃焼の履歴（`xlc-core-history`）の点ごとに
  `history_variables` と `histories`（集合体、軸方向のノード、変数の順の列）に持ち、restart で最後の点の値を集合体の ID で引き継ぐ（装荷替えで
  集合体を回しても集合体の状態。[ADR-0036](0036-keep-core-state-per-assembly.md)、ADR-0220）。H_m の x は、core の状態が減速材の密度を
  持たないので、ノードのテーブルの減速材の軸の格子点の（温度、密度）の組を、状態の減速材の温度で、温度の内挿と同じ重みで内挿した密度
  （crates/core/src/state.rs の `moderator_density`。ノードの密度と温度の履歴が格子点の組と同じ関係で動くと置く。確かめていない）。
  H_r と Pyrex の H_p は、その履歴の分岐を作るときに足す（ノードの値は変数の列で、`HISTORY_VARIABLES` に足せる形）。重みの効きを測るため、
  `[depletion]` の `micro` の `history-weight`（ω）で、ステップを PARCS の形 H(B₀ + ΔB) = (H(B₀) B₀ + ω x̄ ΔB) / (B₀ + ω ΔB) で進められる
  （省略すると 1 で、この決定の形とビットで同じ。有限の正の値でなければエラー。crates/core/src/input.rs の `MicroInput`、
  `advance_history`）。ω はケースの入力で、燃焼の履歴に書かず、restart は引き継がない
- core: ノードの定数は、テーブルの内挿 + 線形の補正 + Σ_j [w_j U_j,r + (P / P_j,r) L_j,r]（crates/core/src/case.rs の `node_constants` と
  `add_histories`。P は crates/core/src/micro.rs の `production_index`、ΔN̄ᵢ^j の内挿は crates/core/src/state.rs の `interpolate_branch_difference`）。
  w_j が厳密に 0 の変数は足さない（公称の履歴は補正を持たないテーブルとビットで同じ定数）。ΔN̄ᵢ^j がすべて 0 の燃焼度は L を足さない。
  部分挿入のノードは、区間のテーブルの使い方ごとにその制御棒の値の補正を足した定数を ADR-0127 の重みで混ぜる。黙って補正なしにせず、
  次をエラーにする: w_j が 0 でないのにノードの制御棒の値の補正がテーブルに無い、R の燃焼度の点の範囲の外、R の点が燃焼度の軸の点でない、
  ΔN̄ᵢ^j が 0 でないのに P_j が 0、core の持たない変数の補正、ミクロ燃焼でない位置（燃焼させない状態の解を含む）に補正を持つテーブル、
  ミクロ燃焼のテーブルのうち補正を持つものと持たないものの混在（持たないテーブルのノードの履歴を補正しない）
- core: ミクロ燃焼の反応率の σᵢ は、テーブルの内挿 + Σ_j [w_j Δσ_U,j,r + (P / P_j,r) Δσ_L,j,r]（案 S2、案 R7。crates/core/src/case.rs の
  `node_micro`。w_j と制御棒の値の選び方は定数の R と同じ関数 `weighted_histories`、P / P_j は L と同じ関数 `production_ratio`（P_j が 0 なら
  エラー）。燃焼の反応率は、その解の定数を作ったノードの履歴の変数で引く）。履歴の分岐の追う核種の数密度の差がすべて 0 の燃焼度は、L と
  同じく Δσ_L を足さない（ハイブリッドが公称の組成そのもので定義から 0）。P は反応率を規格化する組成、つまりその解の定数を作った組成で作る
  （予測子は点の組成、修正子は中点の組成。平衡 Xe の反復ではその反復の組成。crates/core/src/depletion.rs の `node_rates`）。解の定数の L と同じ
  P になり、反応率の組成と定数の組成を分けない。係数は Δσ を足す前の内挿の値（P が使う熱群の νσf と数密度の微分は Δσ で変わらないが、微分を持たない核種の σf の係数は変わる）。ADR-0216 の「追う核種の反応率は、テーブルの微視的断面積 ×
  ノードの中性子束」の σᵢ はこの補正を足したもので、ADR-0216 の帰結の「σᵢ を燃焼度で引くので…自己遮蔽の変化も燃焼度の関数として入る」は
  公称の燃焼の変化で、履歴の分岐の組成のスペクトルと自己遮蔽の違いは、この補正が足す（ADR-0216 の本文は変えない）
- 線形の補正の係数の選び方（`linear_coefficients`。`add_linear_correction` と core の P が呼ぶ）と、履歴の分岐の条件の格子点
  （`Table::history_condition`）は xlc-format の 1 つの関数で、core のノードの補正と P、lattice の L の線形の補正の項、テーブルの検査が同じものを呼ぶ
- 途中で条件を変えた燃焼の core の差は −37.497〜+12.157 pcm で目安に入らない（「確認」）。差の大半は core の数密度の効き（Pu-240 と Pu-241）で、
  反応率の Δσ を w で足しても（−32.314〜−17.018 pcm）、P / P_j で足しても（案 R6。−37.614〜+11.347 pcm）、Δσ_U と Δσ_L に分けても（案 R7）入らない。
  残りの最大の候補は Pu-240 の高速群の捕獲の Δσ_L の重み（「確認」）で、Δσ_L を核種自身の数密度の比で足す案 R8 は、56 MWd/kg への
  ステップで止まり（比の分母が 0 を通る核種の比の大きさが候補）、採らない。この決定の status は、数密度の効きの見直し（#0190）の後に決める
- 本番の格子点（熱水力の ADR）の後に、密度の履歴の分岐の値を決める。ホウ素と燃料の温度の履歴は、HFP の範囲で大きさを測ってから
  足すか決める
- 2A の測定は ADR-0209 の前の既定の組で、履歴の効きの大きさの目安。本番の既定で再測定するかは、比例と重みの確認（#0190）のときに決める
- 計画 docs/plans/m4-depletion.md の「履歴」の項と「進め方」6 の残りを、この ADR を参照する形にした
