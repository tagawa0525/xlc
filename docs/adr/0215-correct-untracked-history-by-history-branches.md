# ADR-0215: 履歴の補正は、燃焼度で重みを付けた平均の履歴の変数ごとに 1 本の履歴の分岐を流し、ミクロ燃焼で追わない核種の残りの定数を変数に比例して足す

## 背景

[ADR-0035](0035-track-history-by-micro-depletion.md) は、core が主要な核種をノードごとにミクロ燃焼で追い、追わない核種の残りを
履歴の変数と履歴の分岐（条件を変えた燃焼計算）で補正すると決めたが、履歴の変数を挙げていない。
[ADR-0026](0026-output-two-group-tables-from-lattice.md) は lattice が「燃焼履歴の補正のデータ」を出すとし、
[ADR-0187](0187-tabulate-burnup-branches-from-history.md) は燃焼度の軸を持つ分岐のテーブルを公称の燃焼の履歴の組成を固定した瞬時の分岐で作り、
条件を変えた燃焼の履歴（examples/depletion/p2 の 2A-density と 2A-rods）からも同じ形のテーブルを作れるとして、core がそれを
どう組み合わせるかを計画（docs/plans/m4-depletion.md の「進め方」6、7）に残した。テーブルの状態の取り方は
[ADR-0200](0200-tabulate-burnup-branches-by-cut-hdmr.md)（公称の状態、1 軸ずつの分岐、2 軸の組の部分格子。制御棒の値ごとに別の組）。

計画の「格子計算の燃焼」の「履歴」の項が ADR で決めるとしたのは、履歴の変数、履歴の分岐の数と条件、Pyrex を抜いた集合体
（VERA Problem 10 のサイクル 2 で、サイクル 1 から残る集合体）の扱いで、この ADR はそれに、テーブルに持つ補正の形、core がミクロ燃焼の
補正と履歴の補正を重ねる形、ADR-0026 の「履歴の補正のデータ」の出力の形を加えて決める。熱水力の ADR（HFP の燃料の温度と減速材の
密度の範囲）の前なので、軸の格子点と、履歴の分岐の条件の値は決めない。

### 判断の軸

- 正確さ: 落とす項は、ADR-0200 と同じく 1 項あたり |Δρ| ≤ 5 pcm を目安にする（炉心の k の 10 pcm と集合体の出力 0.5% から。ADR-0200 の
  「判断の軸と目安」）。格子計算の目標は ±100 pcm（[ADR-0032](0032-target-lattice-accuracy.md)）
- 二重に数えない: ミクロ燃焼が追う核種の数密度の違いは、ミクロ燃焼の補正だけが担う
- 格子計算の回数: 集合体 1 種の燃焼は、2A が 37 分 28 秒（ADR-0209 の既定、32 スレッド、Slurm 582）、前の既定と 16 スレッドで 2A が
  18 分 58 秒（Slurm 520）、2A-density が 18 分 55 秒（Slurm 522）、2A-rods が 39 分 27 秒（Slurm 523）。どれも timed のジョブの elapsed で、
  lattice と OpenMC との比較のステージの和（examples/depletion/verification.md の「集合体の燃焼」の「時間」）。分岐のテーブルは ADR-0200 の
  見積もり（前の既定の 1 状態の目安）で約 2.6〜5.4 時間
- テーブルの格子点で格子計算の値を返す性質（ADR-0097、ADR-0200）を保つこと

### 測った大きさ

examples/depletion/verification.md の「履歴の効き（2A）」（xlc の分岐は 02f35491 の lattice と、入力 b1ddab7d、0e653ef7、2026-10-29、
Slurm 587、588。比較は fa18abad）。2A（減速材 0.743 g/cc、565 K、1300 ppm）、2A-density（0.661 g/cc）、2A-rods（案内管 24 本に AIC）の
3 本の燃焼の履歴は同じ lattice と既定とライブラリのもので、燃焼度の同じ点で、履歴の分岐の k∞ を 2A の組成からその条件への瞬時の分岐と
比べた（履歴の効き）。さらに、2A の組成のうち ADR-0035 の候補の元素（U、Np、Pu、Am、Xe、Sm、Gd）だけを履歴の分岐の値にした組成を
同じ条件で解き、履歴の分岐との差を「追わない核種の分」とした。置き換えたのは元素の核種のすべてで、分岐が輸送する 89 核種のうち 26 核種
（Xe-135、Sm-147、149〜152、Gd の 7 核種、U の 4 核種、Np-237、239、Pu-238〜242、Am-241、243）。燃料で置き換えない輸送する核種は Mo-95、Tc-99、
Ru-101、Rh-103、I-135、Cs-133、Nd-143、Nd-145、Pm-148m、Eu-153、Cm-242、Cm-244 と O-16。逆向きは、履歴の分岐の組成を 2A の条件に戻した
分岐と 2A の差。値は Δρ (pcm)。

- 追う核種の分は履歴の効きの 97.1〜103.5% で、追わない核種の分は（2 MWd/kg の密度のほかは）逆の符号の、効きの大きさの 1.1〜3.5%。
  それでも目安の 5 pcm を、密度の履歴は
  10〜20 MWd/kg から、制御棒の履歴は 2 MWd/kg から超える（履歴の分岐は一生を通して条件を変えた極端なもので、炉心のノードの履歴の
  変数の差はこれより小さい。変数の差に比例すると見ると、密度の差 0.02 g/cc で 60 MWd/kg の −42 pcm。比例は確かめていない）
- 追わない核種の分は、密度では瞬時の条件（0.661 か 0.743 g/cc）にほとんど依らない（違いは最大 2.1 pcm（60 MWd/kg）、相対で 10〜60 MWd/kg の 1.0〜4.3%）。制御棒では瞬時の制御棒の有無で
  大きく違う（10 MWd/kg で −56.4 と −16.8 pcm。Δρ の 1/(k k′) を除いた k の差で、制御棒を入れた側が 2〜10 MWd/kg で約 1.9 倍、30 MWd/kg で
  ほぼ同じ、60 MWd/kg で 0.66 倍）
- 追わない核種を核種ごとに分けていない。燃焼度 0 では、分岐が履歴の点を 0.051 pcm 以内で再現する
- 測ったのは輸送で解いた差で、下の決定の残り R（ミクロ燃焼の線形の補正 Σᵢ σᵢ ΔNᵢ を引いたもの）ではない。R は追わない核種の分に、
  追う核種の線形化の誤差を足したもので、その大きさは #0153 の σᵢ ができるまで測れない。ミクロ燃焼が追う核種を上の 26 より少なく
  選べば、追わない核種の分は変わる（大きさと符号は確かめていない。上の測定では追う核種の分と追わない核種の分の符号が逆）

### 既にある見方

- [#0153](../issues/0153-burnup-table-micro-and-kinetics.md): ミクロ燃焼の核種の均質化した数密度（燃焼度の点ごと）と微視的断面積（状態ごと）の置き場は ADR-0187 で決めたが、
  lattice はまだ書かない。この ADR の残りの定数は、その微視的断面積と数密度を引いて作るので、#0153 が先に要る
- ADR-0187 の案 B3（履歴の効果を別の軸に持ち、瞬時の分岐を持たない）は、瞬時の状態の効果を表せないので採らず、履歴の変数は瞬時の
  分岐に加える補正とした。ADR-0187 の判断の軸は、履歴の違いを ADR-0035 のミクロ燃焼と履歴の補正に任せる
- ADR-0200 で、離散の軸（制御棒）を公称の状態の差だけで持つと 2,780 pcm の誤差になった。制御棒の有無で残りが変わる上の測定と同じく、
  制御棒の効きが状態で大きく変わることが候補
- [#0135](../issues/0135-depletion-pin-powers-per-point.md): 燃焼点ごとのピン出力は ADR-0181 で履歴に入れた。ピン出力の形状関数の履歴の補正は、ここで扱わない
- [#0168](../issues/0168-reuse-dancoff-across-branch-states.md): 履歴からの分岐の Dancoff 係数の持ち越し（時間の話で、ここの決定に影響しない）
- [#0174](../issues/0174-nominal-table-from-history.md)（閉じた）: 公称の状態の少数群定数を燃焼の履歴の点から取る。履歴の分岐の自分の条件の定数も同じく取れる
- [ADR-0178](0178-verify-assembly-depletion.md) は、密度の差が ±1.3% では履歴の効果が ±100 pcm の目標より小さく分けられないので、履歴を変えた燃焼を
  0.661 g/cc と案内管すべての AIC にした。上の大きさはこの極端な 2 本のもの

## 検討した案

先行例（出典つき）:

- SIMULATE5（Studsvik, "SIMULATE5 Overview," NRC Pre-Submittal Meeting (2015-04-08)、https://www.nrc.gov/docs/ML1508/ML15083A470.pdf 。
  スライド 9 と 18）: 巨視的断面積を、ρ_h の関数の基準の値 Σ^base(E, ρ_h) に、瞬時の変数の差分の項（ΔΣ^BOR(E, ρ)、ΔΣ^TFU(E, ρ)、
  ΔΣ^CRD(E, ρ) など）と、別に足す履歴の項（ΔΣ^HBOR(E)、ΔΣ^HTFU(E)、ΔΣ^HCRD(E, CRD)）と ΔΣ^BCRD(E, CRD)（何の項かは資料から読み取れない）を
  足し、さらにミクロ燃焼の補正 Σᵢ σᵢ(E, ρ_h, ρ, …) (Nᵢ^actual − Nᵢ^SA(E, ρ_h, …)) を足す（スライド 9 の式。E は燃焼度）。履歴の変数は
  EXP、HTMO、HBOR、HTFU で、ノードごとに作る（ρ_h は減速材の履歴の HTMO に当たるとみられるが、確かめていない）。ミクロ燃焼の核種は、
  スライド 18 の見出しが「17 actinides/~30 Fission products/BA (node level)」、その下の項目が 16 のアクチニド、30 余りの核分裂生成物、
  可燃性毒物（B-10、Gd）で、数が食い違う。Nᵢ^SA は単一集合体の計算の数密度で、ρ_h の関数なので、ミクロ燃焼の補正は同じ履歴の格子計算の
  数密度からの差になる。ほかの履歴の項とミクロ燃焼の補正の重なりの扱いは、この資料から読み取れない。履歴の変数の定義（重み）と、格子計算の履歴の分岐の条件は、この資料にない（出典を確かめていない）
- SIMULATE-3: 巨視的断面積のモデルで、最近の燃焼の条件に大きな重みを付ける（R. J. Borland, H. Fu, "Evaluation of spectral history effects in
  B&W PWRs using Studsvik CMS," Trans. Am. Nucl. Soc. 73 (1995)、OSTI 411765 の要旨だけ読んだ）。履歴の変数の定義と重みの式は出典を確かめていない。
  ADR-0035 は、履歴の変数による補正だけの形を近似が多いとして採らなかった
- PARCS と PMAXS（B. Meunier, "Multi-Cycle PWR Modeling with DRAGON and PARCS," arXiv:2509.19450 (2025)。3.1〜3.3 節）: 履歴の分岐は
  「参照の履歴から 1 つの変数だけを変えた」燃焼で、履歴ごとに分岐の木を持つ PMAXS を作り、1 つのファイルにまとめる（3.3 節）。3.1 節の式 (3.4)〜(3.6) は
  制御棒の位置（0 と 1）と冷却材の密度の点の間の線形の内挿の例で、表 1 の分岐と対応する。履歴の間を core がどう引くかは、この論文から
  読み取れない（確かめていない）。履歴の変数は
  H(B₀ + ΔB) = (H(B₀) B₀ + ω V₁ ΔB) / (B₀ + ωΔB)（3.1 節の式。V₁ はステップの終わりの値、ω は重み）で、PARCS のマニュアルは ω を 2〜2.5 と
  勧め（論文の引用 [11]。マニュアルは読んでいない）、論文は Pyrex の挿入の履歴に 2.25、減速材の密度の履歴に 1.0 を使い、理論の根拠は
  ないと書く。減速材の密度の履歴は 0.65、0.71、0.77 g/cc の 3 本（3.2 節）。Turkey Point 3 の 3 サイクルで、履歴をひとつずつ足した臨界ホウ素の
  比較（序論の図 1。Polaris の断面積）では、Pyrex の挿入の履歴が最も効き、次が減速材の密度の履歴、ホウ素の履歴はずっと小さく、燃料の
  温度の履歴はほとんど見えない。PARCS がミクロ燃焼と履歴の補正をどう重ねるかは、この論文にない（出典を確かめていない）
- CASMO の履歴の分岐（条件を変えた燃焼を、燃焼点からの分岐と組みで流す入力）: 出典を確かめていない
- ANC の spectral history index（Pu の蓄積に結びつけた指標）: DYN3D の論文の検索の要約で見ただけで、出典を確かめていない

履歴の補正の形:

- 案 C1（履歴の分岐ごとに分岐のテーブルを丸ごと持ち、core が履歴の変数でテーブルの間を内挿する。PMAXS が履歴ごとに分岐の木を持つ形）:
  分岐のテーブルの状態（ADR-0200 の 397〜777 状態）を履歴の分岐の数だけ解く。ミクロ燃焼と重ねるには、ミクロ燃焼の基準の数密度も
  テーブルごとに持ち、履歴の変数で内挿した数密度からの差にする（SIMULATE5 の Nᵢ^SA(E, ρ_h, …)）。履歴の効きは追う核種の分でほぼ尽き
  （97.1〜103.5%）、追わない核種の分の瞬時の密度への依存は最大 2.1 pcm（相対で 10〜60 MWd/kg の 1.0〜4.3%）なので、テーブルを丸ごと持つ費用に見合わない（R の状態への依存は、
  線形化の誤差を含めて測ってから見直す。「確認」）
- 案 C2（SIMULATE5 の形: 基準の定数を履歴の変数の関数にし、ミクロ燃焼の補正を同じ履歴の格子計算の数密度からの差にする）: 二重に数えない
  形だが、基準の定数の履歴への依存を、ミクロ燃焼が担う分も含めて持つので、C1 と同じく履歴の分岐ごとに状態を解く
- 案 C3（履歴の分岐の自分の条件でだけ、ミクロ燃焼の線形の補正を引いた残りを持ち、core は履歴の変数の差に比例して足す。採用）: 履歴の
  分岐 1 本あたり、燃焼 1 回と、自分の条件の状態を燃焼点の数だけ。残りは追わない核種の分と、ミクロ燃焼の線形化の誤差（その点で）を含む。
  連続の軸の瞬時の状態への依存は持たない（密度で最大 2.1 pcm）が、制御棒の値ごとには持つ（制御棒の有無で追わない核種の分が k の差で
  0.66〜1.9 倍に違い、燃焼度とともに向きも変わる）
- 案 C4（履歴の補正を持たず、ミクロ燃焼だけ）: 追わない核種の分が目安の 5 pcm を超える（密度は 10〜20 MWd/kg から、制御棒は 2 MWd/kg から）
- 案 C5（追う核種を増やして残りを 5 pcm より小さくする）: 追わない核種を核種ごとに分けていないので、何を足せば足りるか分からない。
  追う核種の選び方は #0153 と「進め方」7 で決めるので、この ADR はどの選び方でも残りを担う形にする

履歴の変数の定義:

- 案 V1（燃焼度で重みを付けた平均。H(B) = (1/B) ∫₀ᴮ x dB'。PARCS の式の ω = 1。採用）: 残りは追わない核種の分で、その大きさは数密度の
  差の積み上がりに比例すると見込む（追わない核種は Xe と Sm を除いた核分裂生成物などで、寿命の長いものの蓄積は燃焼度について
  積分の形になる。核種ごとに分けていないので候補）
- 案 V2（最近の燃焼に大きな重み。PARCS の ω = 2〜2.5、SIMULATE-3）: 巨視的断面積だけの補正では、Pu-241 や Xe、Sm のように最近の条件に
  効く核種も履歴の変数が担うので重みが要る。ミクロ燃焼でそれらを追うときに要るかは測っていない（Meunier も ω の根拠はないと書く）
- 案 V3（スペクトルの指標の履歴）: 指標の作り方（どの核種や反応率の比か）が決められず、Pu はミクロ燃焼が追う

V1 と V2 は、一生を通して条件を変えた履歴の分岐では区別できない（どちらも H は一定）。途中で条件を変えた燃焼で比べる（「確認」）。

履歴の変数の数:

- 減速材の密度と制御棒（採用）: 2A で測った大きさが目安を超える。Meunier の比較でも、Pyrex を除けば減速材の密度の履歴が最も効く
- ホウ素の履歴と燃料の温度の履歴（後回し）: 測っていない。Meunier の比較ではホウ素は密度よりずっと小さく、燃料の温度はほとんど見えない
  （PARCS がどの核種を微視的に扱ったかは確かめていない）。燃料の温度の履歴の大きさは、HFP の燃料の温度の範囲（熱水力の ADR）が決まってから測る
- Pyrex の挿入（Pyrex の集合体だけ。採用。下の案 Q1）

Pyrex を抜いた集合体:

- 案 Q1（Pyrex の挿入を履歴の変数にする。採用）: 抜いた後は、Pyrex を抜いた格子（案内管の中が減速材）のテーブルを使い、Pyrex の燃焼の
  履歴（2F の形）をその格子へ瞬時に分岐させた定数との差を、Pyrex の履歴の分岐の残りとする。Pyrex の履歴の変数は、Pyrex を入れて
  燃焼させた燃焼度の割合（V1）。ADR-0187 の決定のとおり、案内管の中身を変えた格子でも燃料のセルが同じなら同じ履歴を読める
- 案 Q2（抜く燃焼度ごとに、抜いた後を燃焼し直した履歴を持つ）: 抜く燃焼度でだけ正しい。抜くときのノードの燃焼度は軸方向と集合体で
  違うので、抜く燃焼度の数だけ燃焼が要る。Q1 の比例の誤差を測る参照に使う（「確認」）
- 案 Q3（抜いた後は Pyrex のない格子のテーブルとミクロ燃焼だけ）: Pyrex の履歴の追わない核種の分を落とす。大きさは測っていないが、
  Meunier の比較では Pyrex の挿入の履歴が最も効く

## 決定と理由

### 履歴の変数（案 V1）

core はノードごとに、次の履歴の変数を燃焼度で重みを付けた平均で持つ: 減速材の密度 H_m（g/cc）、制御棒の挿入の割合 H_r（0〜1。ノードの
高さのうち制御棒が入った割合）、Pyrex の集合体だけ Pyrex の挿入 H_p（0〜1）。

H(B) = (1/B) ∫₀ᴮ x dB'

燃焼のステップ（[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の中点の形）では、ステップの燃焼度の増分 ΔB と、ステップの中点の解の値 x̄ で
H(B₀ + ΔB) = (H(B₀) B₀ + x̄ ΔB) / (B₀ + ΔB) と進める。燃焼度 0 の値は、その燃焼度での瞬時の値（B = 0 では残りが 0 なので、補正に効かない）。
ホウ素と燃料の温度の履歴の変数は持たない。

### 履歴の分岐（数と条件）

集合体の種類ごとに、公称の燃焼（ADR-0187 のテーブルの元の履歴）に加えて、次の燃焼を流す。燃焼度の点は公称の燃焼と同じ（[ADR-0199](0199-add-a-burnup-point-at-14.md) の 27 点）:

- 減速材の密度の履歴の分岐: 減速材の密度だけを公称と違う 1 つの値にして一生を燃焼させる。値は分岐のテーブルの減速材の軸の格子点の 1 つ
  （熱水力の ADR で決める軸の、公称でない点）にし、その条件への瞬時の分岐がテーブルの格子点（ADR-0200 の 1 軸の分岐）になるようにする
- 制御棒の履歴の分岐: 制御棒を入れたまま一生を燃焼させる（2A-rods と同じ。ADR-0200 の制御棒を入れた組の公称の状態の格子）
- Pyrex の集合体は、Pyrex のない格子の公称の燃焼を足す（下の「Pyrex を抜いた集合体」）

履歴の分岐の数は、変数ごとに 1 本（変数の 2 点）。補正は変数の差に比例すると置く（「確認」で測る）。

### テーブルに持つ補正（案 C3）と、core の重ね方

履歴の変数 j の履歴の分岐（変数の値 H_j^b、公称の燃焼の値 H_j^0）について、lattice は燃焼度の点 u と制御棒の値 r ごとに、少数群定数の
各項目 f の残り R_j,r(u) を作る:

R_j,r(u) = f(履歴の分岐 j の組成、条件 j、制御棒 r) − f(公称の組成、条件 j、制御棒 r) − Σᵢ σᵢ(条件 j、r、u) (N̄ᵢ^j(u) − N̄ᵢ^0(u))

- 第 1 項は、履歴の分岐の履歴を読んだ ADR-0187 の分岐（`[history]`）を、自分の条件で解いた定数（燃焼度の点ごとに制御棒の値の数だけ輸送）
- 第 2 項は、公称の燃焼から作った分岐のテーブルの、条件 j の状態（格子点）の定数。R を持つ燃焼度の点は、テーブルが第 2 項の状態を
  格子計算で解いた燃焼点から選び、最初と最後を含む（公称の状態は 27 点のすべて、公称でない状態は ADR-0200 の、その組の公称でない状態を
  解く燃焼点。制御棒を入れた組と、Gd と Pyrex の集合体の組は、ADR-0200 のとおり #0176 で測るまで 27 点のすべて）。点は
  （変数、制御棒の値）の組ごとに選ぶ。ほかの燃焼点のテーブルの値は公称の状態との差の
  内挿で、格子計算の値でないため
- 第 3 項は、ミクロ燃焼の線形の補正（[#0153](../issues/0153-burnup-table-micro-and-kinetics.md) の、テーブルの微視的断面積 σᵢ と均質化した数密度 N̄ᵢ）を、core が使うのと同じ
  σᵢ で引いた分。ミクロ燃焼の補正を持たない項目（拡散係数、ADF など）では 0
- 条件 j は、履歴の分岐の条件（密度の履歴なら公称と違う密度、ほかの軸は公称）。制御棒の履歴の分岐の条件 j は制御棒を入れた状態で、
  制御棒を抜いた値 r の残りは、その組成を制御棒を抜いた格子で解く（逆向きの分岐）

core はノードの少数群定数を次で求める（ノードの瞬時の状態 x、燃焼度 u、制御棒の値 r）:

f = f_table(x, u, r) + Σᵢ σᵢ(x, u, r) (Nᵢ − N̄ᵢ^0(u)) + Σ_j w_j R_j,r(u)、w_j = (H_j − H_j^0) / (H_j^b − H_j^0)

- 第 2 項がミクロ燃焼の補正で、追う核種の違いはこの項だけが担う。R はこの項と同じ σᵢ の線形の補正を引いてあるので、二重に数えない。
  履歴の分岐の点（w_j = 1、条件 j、ノードの数密度が履歴の分岐のもの）では、core は第 1 項の格子計算の定数をそのまま返す
- R は連続の軸の瞬時の状態に依らない（条件 j の値を使う）。測った密度の履歴では、瞬時の密度による追わない核種の分の違いは最大 2.1 pcm。
  制御棒の値ごとには持つ（制御棒の履歴では、制御棒の有無で追わない核種の分が k の差で 0.66〜1.9 倍に違う）。制御棒が一部だけ
  入ったノードは、制御棒の値の R を [ADR-0127](0127-weight-partially-rodded-nodes-by-axial-fine-mesh-flux.md) と同じ重みで混ぜる
- 燃焼度について R を ADR-0192 の内挿で引き、範囲の外はエラー（外挿しない）。履歴の変数ごとの R は足し合わせ、変数の間の交差は持たない
  （測っていない）

### Pyrex を抜いた集合体（案 Q1）

Pyrex を入れている間は、Pyrex の集合体のテーブル（Pyrex を入れた公称の燃焼から作る）を使い、H_p の補正は使わない。抜いた後は、同じ集合体の
Pyrex を抜いた格子（案内管の中が減速材）を公称の燃焼として作ったテーブルを使い、Pyrex の履歴の変数 H_p（Pyrex を入れて燃焼させた燃焼度の
割合。抜いた後は B_抜く / B）で、Pyrex の燃焼を履歴の分岐（H_p^b = 1、H_p^0 = 0）とした残り R_p を足す。R_p の第 1 項は、Pyrex の燃焼の履歴を
Pyrex を抜いた格子で解いた分岐（案内管の中身を変えた格子の分岐。ADR-0187）。Pyrex を抜いた格子の公称の燃焼は、同じ濃縮度の毒物のない
集合体の燃焼と同じなので、装荷にその集合体があれば共有する。

### 出力の形（ADR-0026 の「履歴の補正のデータ」）

`xlc-table` に、履歴の変数ごとの項目 `histories` を足す。変数の名前（`moderator-density`、`rods`、`pyrex`）、公称の燃焼の値 H^0、履歴の分岐の
値 H^b、制御棒の値ごとの、R を持つ燃焼度の点（上の規則で選んだ点）と、その点ごとの R（状態の少数群定数と同じ
項目。ピン出力の形状関数は持たない）。ミクロ燃焼の σᵢ と N̄ᵢ は ADR-0187 の置き場（#0153）。lattice は、履歴の分岐の自分の条件の分岐
（`[history]`）のテーブルと、公称のテーブルから R を作り、公称のテーブルに書く（制御棒のテーブルをまとめる examples/core/rod_table.py と
同じく、テーブルの結合の手順。どこに置くかは実装で決める。#0190）。

### 理由

- 2A の履歴の効きは追う核種の分でほぼ尽き（97.1〜103.5%）、追わない核種の分は 60 MWd/kg で密度の履歴 −171 pcm、制御棒の履歴 −546 pcm と、
  目安の 5 pcm を超える。補正を持たない案 C4 は採れず、テーブルを丸ごと持つ案 C1、C2 は、瞬時の密度に最大 2.1 pcm しか依らない残りのために
  分岐のテーブルを履歴の分岐の数だけ解く
- 残りを自分の条件の格子点で、core と同じ σᵢ の線形の補正を引いて作るので、履歴の分岐の点で格子計算の定数を返し、ミクロ燃焼と
  二重に数えない
- 費用は、毒物のない集合体 1 種あたり燃焼 2 回と、R の状態（履歴の分岐 2 本 × 制御棒の値 2 の 4 組、組ごとに燃焼点の数）。前の既定と
  16 スレッドの時間で、燃焼は 2A-density が 18 分 55 秒（Slurm 522）、2A-rods が 39 分 27 秒（Slurm 523。どちらも比較のステージを含むので
  少し多い）。R の状態は ADR-0200 の 1 状態の目安（制御棒なし 15 秒、あり 32 秒。割り込まれうるジョブの目安）で、制御棒を入れた 2 組と
  制御棒の履歴の抜いた組（公称の状態）を 27 点、密度の履歴の抜いた組を 10〜27 点とすると約 38〜42 分で、和は約 1.6〜1.7 時間。同じ前の
  既定の分岐のテーブルの約 2.6〜5.4 時間（ADR-0200）より小さい。Pyrex の集合体は、Pyrex を抜いた格子の燃焼 1 回と R_p の状態（制御棒の
  値 2 の 2 組）を足し、組はどれも 27 点。ADR-0209 の既定と 32 スレッドの燃焼は 2A で 37 分 28 秒（前の既定と 16 スレッドの約 2 倍）で、
  2A-density、2A-rods と分岐の状態は測っていない。燃焼の時間は 41 点（輸送 81 回）のもので、27 点の燃焼ならそれより短い（測っていない）。
  Pyrex の集合体で、同じ濃縮度の毒物のない集合体が装荷に無ければ、Pyrex を抜いた格子のテーブルの密度と制御棒の履歴の分岐（燃焼 2 回と
  4 組）も要る。Gd の集合体は、燃焼が 2A より長く（2O、2P は 71 点）、組はどれも 27 点で、見積もっていない

## 帰結

- lattice: 集合体の種類ごとに履歴の分岐の燃焼 2 本（Pyrex の集合体は Pyrex を抜いた格子の公称の燃焼も）と、その自分の条件の分岐を
  流し、R をテーブルに書く。#0153（ミクロ燃焼の断面積と数密度）が先に要る（#0190）
- core: ノードごとに H_m、H_r（Pyrex の集合体は H_p）を燃焼のステップで進め、restart のファイル（計画の「炉心の燃焼」）に持つ。装荷替えで
  集合体を回しても、ノードの履歴の変数は集合体の状態として引き継ぐ（[ADR-0036](0036-keep-core-state-per-assembly.md)）
- 本番の格子点（熱水力の ADR）の後に、密度の履歴の分岐の値を決める。ホウ素と燃料の温度の履歴は、HFP の範囲で大きさを測ってから
  足すか決める
- 2A の測定は ADR-0209 の前の既定の組で、履歴の効きの大きさの目安。本番の既定で再測定するかは、比例と重みの確認（#0190）のときに決める
- 計画 docs/plans/m4-depletion.md の「履歴」の項と「進め方」6 の残りを、この ADR を参照する形にした

## 確認

- 測った値: examples/depletion/verification.md の「履歴の効き（2A）」（上の「測った大きさ」。比較のツールは examples/depletion/history/compare_history_effect.py、
  置き換えた組成は make_hybrid.py。テストは同じディレクトリの test_compare_history_effect.py、test_make_hybrid.py）
- 実装のときのテストの観点（#0190）:
  - core: 履歴の分岐の点（w = 1、条件 j、ノードの数密度が履歴の分岐の均質化した数密度）で、履歴の分岐の自分の条件の分岐の定数を
    再現する。w = 0（公称の履歴）では今の定数とビットで同じ。履歴の変数の進め方が、一定の x で H = x、途中で x を変えると燃焼度の
    重みの平均になる。R の燃焼度の範囲の外と、テーブルに無い履歴の変数を求めるノードはエラー
  - lattice: R の第 1 項の分岐が、履歴の分岐の燃焼の点の k∞ を ADR-0187 の確認と同じ程度（0.06 pcm）で再現する。R の第 3 項が σᵢ と N̄ᵢ の
    積の差で、ミクロ燃焼の補正を持たない項目では 0
  - 形式: `histories` の読み書きと、燃焼度の点がテーブルの点であること
- 実装のときの測定（#0190）: 途中で条件を変えた燃焼（例: 2A を 20 MWd/kg まで公称で燃焼させ、その後を 0.661 g/cc で燃焼させる）で、V1（ω = 1）と
  変数の差に比例する補正の誤差を測り、目安を超えれば重みと、履歴の分岐の数（変数の 3 点）を見直す。Pyrex を抜いた後を燃焼し直した格子計算
  （案 Q2）で、H_p の比例の誤差を測る。lattice は履歴の途中の組成から条件を変えて燃焼を続けられないので、その入力を足す
- 実装のときの測定（#0190）: #0153 で選んだ追う核種と σᵢ で R を作り、その大きさと、連続の軸の瞬時の状態（密度の履歴の分岐を 2A の
  条件で解いた逆向き）への依存を測る。依存が目安の 5 pcm を超えれば、R を連続の軸の点ごとにも持つ（案 C1 の側へ）
