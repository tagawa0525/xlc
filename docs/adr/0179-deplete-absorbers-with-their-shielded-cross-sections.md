# ADR-0179: 格子計算の燃焼で燃料でない吸収体を燃焼させ、領域の微視的断面積はその物質を遮蔽した値にする

## 背景

[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md) は、燃焼の領域を「自己遮蔽の対称操作のセルの組 × 入力に挙げた燃料の物質」とし、
領域の反応率を燃料のリングの自己遮蔽した微視的断面積から求めた。集合体の燃焼の検証（[ADR-0178](0178-verify-assembly-depletion.md)）の
2F（Pyrex）、2M（IFBA の被覆）、2N（IFBA と WABA）は燃料でない吸収体も燃焼させ、OpenMC の参照解（openmc_depletion_assembly.py の
`regions`）もそれらを燃焼させる。lattice は燃料のリングの外の領域の微視的断面積を持たないので止まった（#0139）。

前提:

- 自己遮蔽は、燃料のピンの等価なセル（燃料、IFBA の被覆のような燃料と減速材の間のリング、被覆管、減速材）を UFG の範囲で
  リングごとに解き、範囲の外は燃料を等価原理（Carlvik の 2 項）で解く。燃料のピンの外の構造材や吸収体の塊（Pyrex、WABA など）は
  塊として遮蔽する。それ以外の物質は MOC でも無限希釈の値を使う
- 輸送する核種は ADR-0173 の案 N1（ライブラリがすべての燃焼の領域の温度で持つ核種。数密度 0 の核種も輸送する）。N1 は温度が
  1 つのピンセルで決めたもので、燃焼させる物質の温度が複数のときの集合は調べていない

判断の軸:

- 反応率が輸送と食い違わない: 燃焼の反応率の微視的断面積は、MOC がその領域の物質に使った値と同じであること
- OpenMC の参照解と同じ範囲を燃焼させ、比べる量（B-10 の数密度など）を揃える
- 範囲を最小にする: 新しい自己遮蔽を作らず、あるものを読む

## 検討した案

領域の微視的断面積:

- 案 A1: 領域の物質を遮蔽した値（その領域の MOC の物質を作った微視的断面積）をそのまま使う（採用）。燃料のピンの等価なセルの
  リングは、UFG の範囲の群がそのリングの減速計算の値で、範囲の外は燃料のリングが等価原理の値、ほかのリング（IFBA の被覆など）が
  無限希釈。遮蔽した塊は塊の値（中心のリングを埋める棒は、棒の等価なセルの UFG のリングの値）。遮蔽しない物質は無限希釈
- 案 A2: 吸収体を無限希釈の値だけで燃焼させる: 実装は最も小さいが、IFBA の被覆の B-10 の自己遮蔽を落とす。MOC は被覆の吸収を
  遮蔽した値で解くので、燃焼の反応率が輸送の吸収と食い違う（差の大きさは確かめていない）
- 案 A3: 吸収体のための自己遮蔽（吸収体のリングの等価原理など）を新しく作る: いまの等価なセルの減速計算が吸収体のリングを
  すでに解いており、範囲の外の吸収体の自己遮蔽は B-10 のように分離共鳴のない核種では小さい。要るかは OpenMC との比較で決める

燃焼させる物質の温度が複数のときの輸送する核種（この ADR では決めない）:

- すべての温度で持つ核種の共通部分（N1 の文言どおり）にすると、吸収体の温度のデータがない燃料の核種が、燃料でも輸送されなくなり得る
- 燃料と吸収体で別の集合（領域の温度ごとに、その温度のデータがある核種）にすると、物質ごとに輸送する核種と数密度の並びが変わる。
  OpenMC の参照解が物質ごとの温度で何を輸送しているかは確かめていない
- どちらにするかは、ライブラリの核種と温度、OpenMC の扱いを調べてから決める（#0139）。今の入力（examples/depletion）は燃焼させる物質が
  どれも 1 つの温度なので、決めるまでは温度が複数なら止める

## 決定と理由

- 入力の `[depletion] materials` に燃料でない物質を挙げてよい。燃焼の領域の分け方は ADR-0173 のまま（対称操作のセルの組 × 物質）
- 領域の微視的断面積は案 A1。自己遮蔽（`FuelShielding::region_cross_sections`）が、MOC の物質を作った値を領域ごとに渡し、燃焼は
  それを物理的な中性子束と掛ける。輸送と燃焼が同じ断面積を使い、新しい近似を足さない
- 燃焼させる物質の温度が複数のときの輸送する核種は決めない。それまでは、温度が複数なら止める
- 断面積を持たない領域（真空）と、輸送する核種の数と断面積の数が合わない領域は、エラーで止める

### 帰結

- 燃焼させる吸収体は輸送する核種すべてを数密度 0 から持つので、IFBA の被覆のリングの UFG の縮約と Pyrex の塊の反復が核種の数だけ
  重くなる（#0137）
- 中心のリングを埋める吸収体の棒を燃焼させると、UFG の範囲（`material_range`）が数密度 0 の核種の分離共鳴で広がる。p2 の入力にはなく、
  確かめていない
- 塊の候補と組（`shield_lumps`）は、燃料でない物質の分離共鳴を持つ核種のうち数密度が正のものから決まる。燃焼させる吸収体では、
  数密度 0 から始まる捕獲の生成物が正になると、燃焼の途中で塊の組と Dancoff 係数が不連続に変わり得る（確かめていない）
- IFBA の 10 μm の被覆の中の中性子束の取り方（薄い領域の MOC の平均）が十分かは、OpenMC との比較で決める（#0139）
