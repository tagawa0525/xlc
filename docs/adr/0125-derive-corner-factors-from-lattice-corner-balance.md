# ADR-0125: 均質な解が平らでない格子の角の不連続因子は、格子の中で core と同じ角の点の釣り合いを解いた均質な角の値から作り、反射体の角は燃料の値で割って持つ

## 背景

core のピン出力の再構成（[ADR-0096](0096-reconstruct-pin-power-analytically.md)）は、ノードごとに2群の解析的な関数の展開を、ノード平均、面の平均の
正味の流れ（3 つの組み合わせ）と 4 つの角の均質な中性子束で決める。角の不均質な中性子束 Φ は角を囲むノードで共通とし、
各ノードの均質な角の値を Φ / CDF とし、Φ を角の点の釣り合い（corner point balance、CPB）の連立方程式で求める。

CDF は、外周がすべて鏡面反射の単一の格子でだけ作っている（[ADR-0103](0103-define-adf-by-one-node-kernels.md)、ADR-0096）。均質な解が平らなので、角の均質な値を
ノード平均とし、CDF = 角の不均質な中性子束 / ノード平均の中性子束とする。集合体を分けた部分ノード（[ADR-0108](0108-split-assemblies-with-shared-constants.md)）も同じ
前提である。反射体の格子（[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）とカラーセットのノードごとの均質化では均質な解が平らでなく（I 型の反射体のノードの
高速群の中性子束は、燃料側の面から真空の面まで約 50 分の 1 に下がる。[ADR-0102](0102-solve-non-fissile-nodes-with-anm.md)）、ノード平均は角の均質な値にならない。
core は反射体のノードを含む層の再構成をエラーにしており（`crates/core/src/pins.rs` の `node_constants`）、REF1-2D と 5-2D の
外周のピン出力を判定できない（#0043、[ADR-0118](0118-judge-pin-powers-by-error-source.md)）。

ADR-0096 の展開では、角の値は展開の結果でなく条件である。ノード平均と面の平均の正味の流れは、モードごとに 8 つの条件の
うち 4 つしか決めないので、ノードの中の参照の量（平均、面の流れ、ADF を作る1ノードの問題の面の中性子束）だけからは角の
均質な値が一つに決まらない。core はその残りを、ノードどうしをつなぐ CPB で決めている。

- 定数を作った体系では、core の再構成が参照（格子計算の MOC）の角の不均質な中性子束とピン出力を再現すること（ADF の
  GET の等価性と同じ考え方。ADR-0103）
- 原理で決まり、手で合わせる係数を持たないこと
- 外周がすべて鏡面反射の単一の格子では、今の CDF（ADR-0096）に一致すること
- 段階のクレートの独立（[ADR-0002](0002-keep-stage-crates-independent.md)）と、共通の計算の切り出し（[ADR-0003](0003-extract-shared-computation-on-second-use.md)）

## 検討した案

### 角の均質な中性子束

- ノード平均で割る（今の定義）: PARCS は単一集合体の計算で CDF = 角の中性子束 / 平均の中性子束とし、平らでない格子の
  扱いは書いていない（PARCS v3.0 Theory Manual、5.1.2.3 節、式 (5.22)、(5.33)、https://www.nrc.gov/docs/ML1016/ML101610117.pdf ）。
  反射体のノードでは角とノード平均が桁で違い、定数を作った体系でも再現しない
- 角に接する細かい領域の中性子束の平均だけを出す（MPACT。角の中性子束は厳密には求められないとし、角に接する領域の
  中性子束を体積で平均する。MPACT Theory Manual 4.3、ORNL/SPR-2021/2330、13.1.3 節。ADR-0094 が引いた 4.4 の同じ節）:
  不均質な角の値の定義で、均質な角の値を与えない。不均質な角の値の定義としては、ADR-0108 と同じくこの考え方を使う
- ADF を角の不連続因子に使う（RENUS。不均質な角の中性子束を、均質な展開の角の値 × ADF と置く。J. I. Yoon, H. G. Joo,
  "Improvement of Two-Dimensional Source Expansion Based Multigroup Pin Power Reconstruction Method," Trans. KNS Spring
  Meeting (2008)、式 (5)。反射体の ADF は燃料と反射体の 2 集合体の計算から作る）。Scarabee は CDF を持たない物質（反射体）の
  角に、角で接する2つの辺の ADF の平均を使う（`DiffusionData::cdf_I` など、https://github.com/HunterBelanger/scarabee 、
  d41339e、2026-02-23）: 角の中性子束は面の中性子束と違うので、定数を作った体系でも角を再現しない。どの辺の ADF を使うかの
  選び方も原理で決まらない
- 1ノードの問題の x と y の 1D の形から角の値を作る（Scarabee の NEM の再構成は、交差の項を除いた 1D の形の和で角の値を
  見積もり、CDF = 不均質な角の中性子束 / その値とする。`compute_adf_cdf_from_cmfd` と `flux_xy_no_cross`、同上）: core の
  再構成の展開と CPB と別の量なので、定数を作った体系で角を再現しない。和の形は、外周の真空の角のように両方の面の値が
  ノード平均より小さいところで負になりうる
- ノードの中の 2D の均質な拡散方程式を、参照の辺に沿った正味の流れの分布を境界条件として細かいメッシュで解く（Smith の
  GET の元の定義。K. S. Smith, Prog. Nucl. Energy 17(3), 303–335 (1986)。原典は読んでいない）: core の再構成の展開と
  違う解なので、定数を作った体系で再現しない。拡散のソルバを lattice に持つことになる（ADR-0103 で ADF について採らなかった
  案と同じ理由）
- core と同じ解析的な展開で、角の値の代わりに1ノードの問題の均質な面の中性子束（ADF の分母）を条件にする（Boer と
  Finnemann は面の平均の中性子束と角の中性子束を条件とした。PARCS の同 5.1.1 節の記述。原典は読んでいない）: 8 つの関数を
  x と y の偶奇で分けると、偶偶（3 関数）には平均、x と y の面の和、流れの組み合わせの 4 つの条件が重なり、奇奇
  （sinh x sinh y の形の1関数）には条件がない。角の値が持つ奇奇の成分を面の量から決められない
- 格子の中で core と同じ CPB を解き、角の点を囲むノードの均質な角の値を等しくする: core の CPB と同じ式を満たすので、
  定数を作った体系で再現する。ただし、面では均質な中性子束が ADF の比で不連続なのに、角でだけ連続とすることになる。
  反射体の CDF を燃料の CDF で割ると、燃料と接する角の比が常に 1 になり、反射体の格子の情報が角に残らない
- 格子の中で core と同じ CPB を解き、角の点を囲むノードの間の均質な角の値の比を、各ノードの1ノードの問題の均質な面の
  中性子束から見込み、角の点ごとの大きさを CPB で決める（採用）。定数を作った体系で再現し、ノードの間の不連続は面の ADF と
  同じ1ノードの問題から来る

### 反射体の CDF の持ち方

- 反射体の格子の CDF をそのまま使う: core で隣にある燃料は、反射体の格子の代表の燃料と種類も状態も違うので、燃料側の
  大きさが合わない（ADR-0095 で ADF の f* を選んだのと同じ理由）
- 燃料の CDF で割って持ち、core で隣の燃料の CDF を掛ける（採用）: 面の f*（ADR-0095。Smith の方法として Scarabee と
  nTRACER-RENUS が使う。J. H. Jeong, Y. S. Ban, H. G. Joo, Trans. KNS Spring Meeting (2017)、式 (4)、(5)）を角に広げる。
  角の点は複数の燃料のノードに接しうる（I 型の境の角は、面で接する燃料と、斜めに接する燃料に接する）ので、どの燃料の
  CDF で割るかを決める必要がある。文献で角の f* を扱うものは見つからなかった

### 形状関数

- 平らでない格子の形状関数を作らない（今の決定。ADR-0096 は外周がすべて鏡面反射の格子でだけ作る）: 燃料のノードが
  平らでない格子の定数を使う体系（定数を作った体系、カラーセットのノードごとの定数）で再構成できない
- セルの核分裂率 / ノード平均の核分裂率（今の定義を広げる）: 均質な解が平らでないので、形状関数 × 均質な展開が参照を
  再現しない
- セルの核分裂率 / （均質化した核分裂断面積 × 格子の中で再構成した均質な中性子束のセルの平均）（採用）: 平らな格子では
  今の定義に一致する

## 決定と理由

CDF は、どの格子でも「角の不均質な中性子束 / core の再構成が定数を作った体系で与える角の均質な中性子束」とする。角の
均質な中性子束は、格子の中で core と同じ展開と CPB を解いて求める。ADF を、core と同じノードの核で1ノードずつ解いた均質な
面の中性子束で作る（ADR-0103）のと同じく、core が使う式で格子の中の均質な解を作れば、定数を作った体系で core が参照を
再現するためである。

格子のノードごとの均質化（`nodes`。ADR-0095）では、次の順に作る。外周がすべて鏡面反射の単一の格子は、ノードが1つの
場合として同じ手順になる。

- 角の点 p の不均質な中性子束 Φ_p は、角の点に接する格子の中の領域（角の点を頂点とする 4 つの象限のうち格子の中にある
  もの）の中性子束の平均とする（ADR-0108 の定義。集合体の外周の角では ADR-0103 の余白の角のセルの値と同じ）
- ノード n の角 c の均質な値の見込みを h̃_{n,c} = φ_x,c φ_y,c / φ̄_n とする。φ_x,c と φ_y,c は角 c を含む x と y の辺の、
  ADR-0103 の1ノードの問題の均質な面の中性子束（ADF の分母）、φ̄_n はノード平均の中性子束
- 格子の中で、ノード n の角 c の均質な値を s_p h̃_{n,c}（p は角 c の点）とし、角の点と群ごとの大きさ s_p を、core と同じ
  CPB の連立一次方程式で求める。ノードの展開は ADR-0096 のもので、格子のノードの定数、格子の k、MOC のノード平均の中性子束、
  MOC の辺ごとの正味の流れ（ADR-0103 の1ノードの問題と同じ量）、軸方向の漏れ 0 を与える。外周の鏡面反射の辺は流れ 0、
  真空の辺は J = r Φ_p（ADR-0101 の比 r と、既知の Φ_p）とする。連立方程式が特異なとき、s_p が正でないときはエラーにする
- CDF_{n,c} = Φ_p / (s_p h̃_{n,c})

この CDF で、定数を作った体系は参照を再現する。core の NEM（燃料）と ANM（反射体）は、GET の ADF で参照のノード平均と面の
正味の流れを再現する（ADR-0103。I 型の格子で k が MOC と +0.0006 pcm。examples/reflector/verification.md、aa95e62a、2026-10-10）。
すると core の再構成の入力は格子のものと同じになり、Φ = Φ_ref のとき各ノードの均質な角の値 Φ_p / CDF_{n,c} は格子の中の
s_p h̃_{n,c} に戻るので、core の CPB は Φ_ref で満たされる。CPB の解は一つなので、core は Φ_ref を求め、ノードの展開は格子の
中のものと一致する。形状関数をその展開で作れば（下）、ピン出力も参照に一致する。

見込みの比 h̃ は、角の点を囲むノードの間の均質な値の比だけを決め、大きさは CPB が決めるので、定数を作った体系での再現には
効かない。効くのは別の体系（燃料が代表と違う炉心）だけである。積の形にしたのは、次の理由による。

- 均質な解が一方向にしか変わらない格子（I 型の境の角）では、h̃ は角を含む辺の均質な面の中性子束になり、角のノードの間の
  比が面の ADF の比（f*）と同じになる
- 均質な解が平らなら h̃ = φ̄ で、s_p = 1 が CPB を満たすので、CDF は今の定義（角の不均質な中性子束 / ノード平均）になる
- 均質な面の中性子束は正（ADR-0103 がそれを確かめてエラーにする）なので、h̃ も正になる。1D の形の和（Scarabee）は負に
  なりうる

反射体の CDF は、燃料の CDF で割って持つ。

- 反射体のノード（`reflector`）の角のうち、角の点が反射体でないノードにも接するものは、C*_{n,c} = CDF_{n,c} / H_p を持ち、
  少数群定数の形状のデータ（`pins`）にその角の印を付ける。H_p は、格子の中で角の点 p に接する反射体でないノードの、その点の
  CDF の調和平均とする。Φ_p が共通なので、調和平均で割ることは、反射体の均質な角の値を、燃料のノードの均質な角の値の
  算術平均に対する比で持つことに当たる
- core では、印の付いた角の CDF を C*× （炉心でその角の点に接する反射体でないノードの CDF の調和平均）とする。印の付いた
  角の点に反射体でないノードがなければエラーにする（f* の面の検査と同じ）
- 反射体のノードの、反射体でないノードに接しない角（反射体どうしの角、外周の真空の辺の角）は、CDF をそのまま持つ
- 割る相手を特定の燃料（面で接するもの）に限らないのは、L 型の角の点のように面で接する燃料が2つあるときと、角型の
  反射体のように斜めにしか燃料に接しないときにも、同じ規則で決まるためである。定数を作った体系では、割った値と掛ける値が
  同じなので、どの規則でも再現は変わらない

形状関数と core の扱いは次のとおりとする。

- 格子のノードごとの均質化でも、`pins` を作る。形状関数は f_g（セル）= セルの少数群 g の核分裂率の平均 /
  （ノードの Σf,g × 上で再構成した均質な中性子束のセルの平均）とする。均質な解が平らなら今の定義と同じ
- 反射体のノード（核分裂がない）も、形状関数を 0 にした `pins` を持ち、CPB に入る。core は反射体のノードを含む層の再構成を
  エラーにせず、反射体のノードの展開を、その定数（ADR-0104 の Koebke の等価な D を含む）から作る
- 再構成の展開（`core::pins` の `basis` と `node`）と CPB の式は、lattice と core の両方で使うので、共通の計算のクレート
  （`xlc-numeric`）に移す（ADR-0003。lattice は core に依存しない。ADR-0002）。格子の中の CPB と core の CPB は、同じ関数で
  式を組む
- 集合体を分けた部分ノード（ADR-0108）は変えない（外周が鏡面反射の集合体の定数を分けるもので、均質な解を平らとする）

ADR-0096 と ADR-0103 は、反射体の角と平らでない格子の CDF、平らでない格子の形状関数を #0020 で決めるまでエラーにすると
していた。この ADR はそのエラーの代わりの扱いを決めるもので、両者の他の決定は変えない。

## 確認

テスト（What）:

- 外周がすべて鏡面反射の単一の格子では、CDF と形状関数が今の値（ADR-0096 の `pin_shapes`）に一致する
- 均質な面の中性子束が一方向にしか変わらない格子（燃料と反射体の帯）で、境の角の h̃ が均質な面の中性子束に、ノードの間の
  CDF の比が ADF の比に一致する
- 定数を作った体系の再現: 格子のノードごとの定数で core を解き、再構成した角の不均質な中性子束が格子の Φ_ref に、ピン出力が
  MOC のピン出力に、丸めの程度で一致する（燃料と反射体の帯、2D の 2 × 2 のノード）
- 反射体の角の C*: 定数を作った体系で、割ってから掛け戻した CDF が元の値に一致する。印の付いた角の点に反射体でないノードが
  ないとエラー
- 格子の CPB が特異なとき、s_p が正でないときはエラー

比較（数値はまだない）:

- I 型の反射体の格子（examples/reflector）で、core の再構成が格子の MOC の燃料のピン出力を再現する
- REF1-2D の外周の集合体のピン出力を、core（燃料は単一集合体の定数、反射体は I 型の定数）と、同じ多群定数の xlc の MOC
  （3 × 3 の形状をそのまま解く）で比較する。判定は ADR-0118 の 2 段階の手法の閾値（RMS 1%、出力 0.8 以上のピンの最大 3%）。
  反射体に接する集合体は出力の低いピンが多く、出力 0.8 以上に限ると判定から外れるピンが増えるので、反射体に接する列の
  RMS と最大を別に記録する
- 5-2D で同じ比較をする。L 型と角型の反射体の定数（#0029）が先に要る
- 差が閾値を超えたら、ADR-0118 の結果の切り分け（集合体の平均と集合体の中の形）に、角の扱いの効き（反射体の CDF を燃料で
  割らない場合との差）を加えて切り分ける

## 結果

- 少数群定数の `pins` に、角ごとの「燃料の CDF で割った値」の印を加える。反射体のノードも `pins` を持つ。`few-group` の
  `pins = true` を `nodes` と使えるようにする。格子計算の出力が変わるので、テーブルを作り直す
- 反射体のノードを含む層を core で再構成できるようになり、#0043 の REF1-2D と 5-2D の判定に進める
- 残る近似: 均質な角の値のノードの間の比 h̃（別の体系でだけ効く）、core の燃料の単一集合体の CDF と形状関数（周りの
  集合体の影響を表さない。ADR-0118 の結果）、複数の種類の燃料に接する角の点での調和平均、点の不均質な中性子束を
  接する領域の平均で表す近似（ADR-0103、ADR-0108）
- 格子の中の CPB は、ノードの数が数個の格子では小さい密な連立方程式である。core と同じ組み方なので、#0042（帯行列）を
  入れるときは両方が変わる
- CDF は、ノードの核（ADR-0103）に加えて、再構成の展開（ADR-0096）と h̃ の定義に結びつく。これらのどれかを変えたら、
  テーブルを作り直す
- 一次情報で確かめていないこと: SIMULATE-3 の再構成（K. R. Rempe, K. S. Smith, A. F. Henry, Nucl. Sci. Eng. 103(4),
  334–342 (1989)）の角の扱いと反射体の CDF、Smith（1986）の GET の角の扱い、Koebke と Hetzelt（Nucl. Sci. Eng. 91(2),
