# ADR-0270: UFG で解く核種を、全核種を輸送した燃焼の組成での自己遮蔽の目安が、どれかの燃料で 0.1 pcm を超える核種に選ぶ

## 背景

課題 #0292 は、輸送する核種をデータのある全核種（VIII.0 で 549）に広げ、UFG の減速計算でポイントワイズの断面積で解く核種を効く核種に絞る形
（[ADR-0268](0268-solve-unlisted-fuel-nuclides-by-group-constants.md) の `ufg-nuclides`。挙げない燃料の核種は等価原理の段の断面積の静止した
標的）に進めている。挙げない核種には、ライブラリにポイントワイズの断面積を持たせない（[ADR-0269](0269-let-xs-leave-out-pointwise-of-nuclides-the-ufg-does-not-solve.md)
の `pointwise = false`）。どの核種を挙げるかを、選ぶ量、閾値、その量を出す組成で決める。

全核種を輸送するライブラリ（565 K の 1 点）で U、MOX、Gd のセルを燃焼させた試行の値（examples/depletion/verification.md の
「データのある全核種を輸送した燃焼と、UFG で解く核種を絞った差と時間（試行）」。2026-11-20、ブランチ feat/0292-all-nuclides-trial の df36c7c9 と 18dbec8a）:

- 全核種を輸送すると、154 核種の燃焼から 60 MWd/kg で U −188.0、MOX −81.6、Gd −414.3 pcm、今の本番の 89 核種からは U −4803.6、MOX −3207.4、
  Gd −5113.8 pcm 変わる。154 核種からの差は、154 核種の燃焼が崩壊だけで追う核種（[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md)）が
  捕獲するようになった分（その核種自身の吸収と、捕獲の先の Sm-149、Gd-157、Dy-161 などの増え。Pm-148 → Sm-149、Eu-156 → Gd-157、Gd のセルの
  Tb-160、Dy-160〜164）の 1 次の和で、直接の差の 0.79〜1.18 倍になる
- すべてを UFG で解く自己遮蔽の時間は、549 核種で 154 核種のライブラリの 2.2 倍（U）。足した 459 核種をどれも UFG で解かない組の時間の比は 0.70〜0.75 で、
  核種を絞る利得は 3 割弱が上限
- 足した核種をどれも UFG で解かない組は 30 と 60 MWd/kg で U −73.6、−77.9、Gd −73.1、−89.8 pcm ずれ、使えない

## 決定の要因

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。挙げる組は速度のための近似で、既定（`ufg-nuclides` を省くと全核種を UFG で解く）は
  ADR-0268 のまま厳密な経路として残す
- 既定や近似を決める測定は、燃料の種類と燃焼度を変えて行う（CLAUDE.md の「方針」）
- 項目ごとの誤差の目安 5 pcm（ADR-0200、ADR-0215。ADR-0268 が組の差を比べた目安）
- 組は、規則と閾値と組成から作り直せること（手で一覧を選ばない）

## 検討した案

選ぶ量は、どの案も足した核種の自己遮蔽の目安（examples/depletion/issue-0292/dilution_shielding.py。核種ごとの Bondarenko の表を燃料の組成の希釈で
内挿した吸収の比 r と、その核種の吸収の割合 f から 1e5 f (1 − r) / k∞。燃焼度 10、30、60 MWd/kg の最大の絶対値）で、組はどれかの燃料で閾値を超える核種。
組の差は、すべてを UFG で解いた k∞ との差（上の記録の表。3 つの燃料、燃焼度 0、10、30、60 MWd/kg の基準条件の 1 状態）:

- 案 A（採る）: 目安を、全核種を輸送した燃焼の組成から出し、閾値 0.1 pcm。組 `a0.1` は足した核種 47。差は 12 状態で 1.8 pcm 以下（Gd の 60 MWd/kg の
  +1.8）。組の外に残る目安の和は 3 つの燃料で 1.0 pcm 以下
- 案 B: 目安を、今の本番（p2、89 核種）の燃焼の組成から出す（65 核種と 549 核種の試行で使った組成）。89 核種の燃焼では足した核種が捕獲しないので、
  その捕獲の先（Pm-148、Dy-160〜163、Tb-160）がほとんど無く、順位に上がらない。閾値 0.1 pcm の組 `t0.1`（41 核種）は U と MOX で 1.3 pcm 以下だが、
  Gd の 60 MWd/kg で −10.5 pcm。全核種の組成の目安で `t0.1` の外に残る和はそこで 9.2 pcm（Dy-162 4.8、Dy-160 1.75）
- 案 C: 閾値 1 pcm か 0.3 pcm（案 A の組成で 23、32 核種、案 B の組成で 20、28 核種）。差が組の目安の外の和に合わず、足す核種で符号が変わる:
  60 MWd/kg で U は `t1` +10.1、`a1` −9.8 pcm、MOX は `t0.3`、`a0.3` とも −5.6 pcm、Gd は `a1` −7.4、`t0.3` −9.7 pcm。どれも目安 5 pcm を超える。
  時間は `t1` と `t0.1` の比の差が 0.03〜0.09（`a` の組は測っていない）で、0.1 pcm にする費用は小さい
- 案 D: 目安を使わず、核種を 1 つずつ足して測った差で選ぶ。差の小さい核種の数百の格子計算が要り、上の符号の変わる揺らぎ（数 pcm）で順位が決まらない
- 案 E: [ADR-0165](0165-reduce-chain-by-contribution-and-folding.md) を書き直して、この選び方を入れる（#0292 の「残る判断」の案）。ADR-0165 が
  選ぶのは格子計算の燃焼と core が使う燃焼チェーンの核種（#0116）で、UFG で解く核種とは対象も誤差の測り方も違う。1 件 1 決定のため、ADR-0165 は
  proposed のまま残す

## 決定と理由

案 A にする。本番の入力の `ufg-nuclides` は、輸送する核種から、次の規則で選んだ核種のほかの足した核種を除いたものにする:

- 組成: データのある全核種を輸送するライブラリで燃焼させた U、MOX、Gd のセルの履歴（examples/depletion/issue-0292/all/<燃料>/nominal.msgpack）
- 目安: 燃焼度 10、30、60 MWd/kg の基準条件の状態での自己遮蔽の目安（全核種の組成の吸収の割合は examples/depletion/issue-0292/added_effect.py、
  目安は dilution_shielding.py。輸送する核種の σ0 の背景からは自分の項を除く）。燃焼度を通じた最大の絶対値
- 閾値: どれかの燃料で 0.1 pcm を超える核種（examples/depletion/issue-0292/ufg_subset.py の `a0.1`）
- 足していない核種（p2 の 89 核種）と、被覆管と減速材の核種は、どれも UFG で解く（ADR-0268 の規則で挙げる）

理由:

- 案 B の組成は、選ぶ核種の多くの捕獲の先を持たない。捕獲の先は全核種を輸送して初めて生まれるので、目安は全核種を輸送した燃焼の組成から出す
- 閾値 1 と 0.3 pcm は、組の目安の外の和が数 pcm でも、測った差が符号を変えて 5〜10 pcm 動く。0.1 pcm にすると、12 状態の差が 1.8 pcm 以下に収まる
- 挙げない核種のポイントワイズの断面積は、ADR-0269 の `pointwise = false` で持たせない（その核種の組はこの規則の組の補集合）

## 帰結

- 既定は変わらない（`ufg-nuclides` を省くと全核種を UFG で解く。ADR-0268）。この組は本番の入力に書く近似で、厳密な経路は入力を省けば通る
- proposed のまま。決めるのに足りない測定:
  - `a` の組の自己遮蔽の時間（区分 timed の排他のジョブ）。`t0.1` の比（0.75〜0.82）から、`a0.1` の利得は 2 割程度と見込むが、測っていない
  - 選んだ組成と別の履歴での差（組は同じ 3 つのセルの履歴で選び、同じ履歴で差を測った）。集合体（2A、2O など）か、別の濃縮度と Gd の量のセルで
    `a0.1` の差を測る
  - 温度: 565 K の 1 点だけ。本番の 13 温度の全核種のライブラリ（#0292 の完了の条件）で、燃料の温度のブランチを含めて差を測る
- 閾値の粗い組の符号の変わる差（上の案 C）と、燃焼度 0 の +0.1〜0.2 pcm の原因は確かめていない（候補は上の記録）。`none` が 10 と 30 MWd/kg の間で
  約 −75 pcm に離れる分は Xe-131、Pm-147、Pd-108、Rh-105 の中にあり、どの核種かは分けていない
- 全核種の燃焼で順位を付けるので、本番の全核種のライブラリを作るたびに、燃焼させてから組を作り直す。He-4、H-3、Be-7 は捕獲も核分裂も無く、
  目安の順位の外（UFG で解かない）

### 確認

測定は上の記録の節（Slurm 1004 は区分 timed、1005 は区分 decision、2026-11-20）。`a0.1` の差: U +0.1、+1.2、+1.4、+1.5、MOX +0.1、+0.6、+0.6、+0.7、
Gd +0.1、+1.1、+1.3、+1.8 pcm（燃焼度 0、10、30、60 MWd/kg）。組を作るツールのテスト: examples/depletion/issue-0292/test_ufg_subset.py
（`test_the_sets_of_another_ranking_take_its_prefix`）、test_added_effect.py、test_dilution_shielding.py（`Background`）。
