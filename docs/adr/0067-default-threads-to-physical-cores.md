# ADR-0067: スレッド数の既定は物理コアの数とする

## 背景

1つのコアを2つのスレッドで分ける（SMT）と、使えるスレッドが倍になる。既定のスレッド数を決める必要があった。

- 速さ
- メモリ

## 検討した案

- 論理コアの数（SMT を使う）: P0 では 3〜6% 速いが、既定の P3 では 12% 遅く、メモリも増える
- 物理コアの数（採用）

## 決定と理由

スレッド数の既定は物理コアの数とする。SMT を使うと、P0 では 3〜6% 速いが、既定の P3 では方向ごとの作業用の配列が
スレッドごとに増えて 12% 遅くなり、メモリも増える（2B の P3、無限希釈の多群定数で、16 → 32 スレッドで 8.9 → 11.9 GB。
docs/plans/m2-assembly.md、447e421 と ae658a1、2026-10-08）。

## 確認

数値は計画に記録した測定で（docs/plans/m2-assembly.md、447e421 と ae658a1、2026-10-08）、examples/ の検証の記録（verification.md）には
ない。確かめるテストはない。

## 結果

なし。
