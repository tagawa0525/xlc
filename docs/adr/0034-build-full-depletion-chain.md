# ADR-0034: 全核種の燃焼チェーンを作り、輸送計算に使う縮約したチェーンはそこから作る

## 背景

燃焼チェーンは、輸送計算と、後に加える冷却計算（崩壊熱と放射能）の両方が使う。

## 検討した案

- 輸送計算に要る範囲だけのチェーンを作る: 崩壊熱と放射能には足りない
- 全核種のチェーンを作り、そこから縮約する（採用）

## 決定と理由

xs が ENDF の崩壊・収率データから全核種のチェーン（崩壊エネルギーを含む）を作り、輸送計算に使う縮約したチェーンは
そこから作る。崩壊熱と放射能には、縮約したチェーンでは足りない（数千の核種と、構造材の放射化生成物が要る）ため。
CRAM は数千核種を解けるよう疎行列で実装する。

## 確認

まだ実装していない（M4）。

## 結果

ENDF を読むのは xs だけとする（[ADR-0002](0002-keep-stage-crates-independent.md)）。
