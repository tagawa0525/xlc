# ADR-0012: ファイルの形式に後方互換と版を持たない

## 背景

M1 では、多群ライブラリの形式に版を持たせていた。ファイルの形式は、まだ誰も使っていない。

- 保守のコスト（古い形式を読むコードを残さない）

## 検討した案

- 形式の版を持ち、古い形式も読む（M1 の形）
- 後方互換も版も持たない（採用）

## 決定と理由

後方互換は持たない（まだ誰も使っていないため）。形式を変えたら古いファイルは作り直し、古い形式を読むコードは
残さない。形式の版も持たない。M1 の形式の版は M2 で廃止した。

## 確認

約束事で、確かめるテストはない。

## 結果

形式を変えるたびに、ライブラリと参照の出力を作り直す。
