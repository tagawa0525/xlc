# ADR-0207: UFG の範囲の群の散乱行列の移行の形を、等価なセルのリングの UFG の中性子束で縮約する

## 背景

[ADR-0068](0068-solve-pinwise-slowing-down.md) は、UFG の範囲（分離共鳴の範囲。1C のピンセルで 14〜27 群、4 eV〜15.03 keV）の燃料、
被覆管、減速材の群定数を、等価なセルのリングの UFG の中性子束で縮約する。散乱行列は縮約せず、[ADR-0076](0076-store-legendre-scattering-moments.md)
のとおり、ライブラリの無限希釈の行（群の中の重みは [ADR-0039](0039-weight-with-njoy-iwt4.md) の iwt=4。UFG の範囲では 1/E）の形のまま、
行の和を自己遮蔽した弾性散乱の変化の分だけ変える（ADR-0076 は「散乱行列の自己遮蔽は効果が小さいので後回し」とした。散乱行列の群の中の
重みと共鳴のくぼみのあるスペクトルの違いは、#0005 と [ADR-0133](0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md) の「帰結」に、確かめていない候補として
残っていた）。

1C のピンセルで、新しい燃料から 2A の 40 MWd/kg の組成（2A-40）への k の差（xlc − OpenMC）の増えは、UFG の散乱核を自由ガスと
S(α,β) にしても +62.5 pcm 残る（[ADR-0205](0205-scatter-h-in-h2o-by-sab-in-ufg.md)、#0152）。そのうち減速材の 27 群（4〜9.877 eV）の移行の
行を OpenMC の行に置き換えた寄与が、1C の 0 MWd/kg で −3.8、2A-40 で +44.5 pcm と状態で +48 pcm 違い、散乱核によらなかった。

OpenMC の群の行を、群の中の細かい入射の区間（27 群で 196）ごとの行（核）と、区間の中性子束（重み）に分けて測った（examples/depletion/verification.md
「群の移行の行の群の中の重み（#0152）」。xlc は 20b94bdf、OpenMC は 31ea7e26、2026-10-27）:

- 減速材の 27 群から出る移行は、OpenMC で 1C の 0 MWd/kg の 0.59358 /cm から 2A-40 で −0.81%、MOX-1 の新しい燃料で −0.49% 減る。
  xlc の行は状態によらず同じで、2A-40 で OpenMC より +0.75% 大きい。燃料の 27 群から出る移行は、xlc が OpenMC より 2A-40 で 16.4%、
  MOX-1 で 13.5% 小さい
- OpenMC の核を xlc 自身の等価なセルのリングの UFG の中性子束でまとめると、減速材の 27 群の行はどの状態でも OpenMC の行と 0.06% 以内、
  燃料の 27 群は 0.4% 以内で合う。14〜26 群では、減速材は 15〜26 群で 0.10% 以内、範囲の最も上の 14 群で −0.18〜−0.22%、燃料は
  15〜26 群で 0.56% 以内、14 群で −1.26、−1.50%（xlc の行は燃料の 22〜25 群で −2〜−15%）。減速材の核は燃料の組成によらない
  （2 つの実行の核を同じ重みでまとめた行は、27 群で 0.01%、14〜26 群で 0.11% 以内）
- 置き換えの寄与の状態の差（2A-40 − 1C の 0 MWd/kg）は、減速材の 27 群で +48.3 pcm のうち群の中の重みが +51.4、14〜26 群で −22.6 pcm の
  うち −21.4。残り（OpenMC の行と、核を xlc の中性子束でまとめた行の置き換えの差）は、どの行の寄与でも 4.9 pcm 以内で、別の実行の
  統計誤差（4 pcm ほど）と区別できない

xlc の UFG の中性子束の群の中の形は合っており、状態で変わる行の差は、その中性子束で行を縮約していないことから来る。

判断の軸（依頼とユーザーの指示、2026-10-27）: 正確さ > 速度 > 保守。説明できない定数や補正を入れない。

## 検討した案

### 重み

- 案 W1: 無限希釈の 1/E の形のまま（今。ADR-0076）。上の測定のとおり、状態で変わる群の中のスペクトルを行が追えない
- 案 W2: 測った比（OpenMC / xlc）を補正の因子として掛ける。状態と燃料の組成ごとに比が変わり（減速材の 27 群から出る移行で −0.06、+0.75、
  +0.44%）、説明できない定数になる
- 案 W3: 等価なセルのリングの UFG の中性子束で、リングの物質の UFG の範囲の群の散乱行列（P0 の群の間の移行の形）を縮約する（採用）。
  断面積の縮約と同じ重みで、上の測定では 27 群の OpenMC の行を 0.06%（減速材）、0.4%（燃料）以内で再現する（14 群を除く 14〜26 群で
  0.10%、0.56% 以内）

### 縮約のしかた（案 W3）

- 案 M1: ライブラリに、UFG の範囲の群を細かい入射の区間に分けた散乱行列（区間ごとの行）を持たせ、lattice がリングの UFG の中性子束と
  点の弾性散乱断面積で区間の行をまとめる。上の測定と同じ形（区間は 1 桁に 500）で、評価済みデータの核をそのまま使えるが、ライブラリが
  区間の数 × 出射の群 × 次数 × 温度だけ大きくなる。区間の中の共鳴の形（重い核種の弾性散乱）は区間の重みに入らない
- 案 M2: UFG の減速計算の散乱源から、群の中の格子点から出射の群への移行の率を直接数え、リングの群の中性子束で割る。出射が範囲の中なら
  UFG の解と同じ移行になり（[ADR-0071](0071-correct-with-sph-factors.md) が「多群の散乱行列は UFG と同じ群間の移行を与えない」とした差が
  消える）、ライブラリを変えない。範囲の下限より下への出射（27 群から 4 eV より下）は、UFG の格子が無いので、核（H in H2O は ADR-0205 の
  S(α,β) の移行の表、ほかは静止した標的か自由ガスの核）で数える必要がある。P1 以上の行の扱いは別に決める（要素ごとに P0 と同じ比を掛ける
  案は、`swap_transfer` の例の置き換えと同じ）

案は M2 を第一とする（評価済みデータからの追加のデータを持たず、UFG の解と群の移行が揃う）。範囲の下限より下への出射の扱い、P1 以上の
次数、手間（格子点ごとの移行の数え上げ）は、実装の依頼で測って決める（確かめていない）。

## 決定と理由

UFG の範囲の群について、等価なセルのリング（燃料、被覆管、減速材）の物質の散乱行列の群の間の移行の形を、そのリングの UFG の中性子束で
縮約する（案 W3）。これは ADR-0076 の「散乱行列は σ0 ごとに持たず、角度分布と群の間の移行の形は無限希釈のままとする」の部分を、UFG の範囲の群の
等価なセルのリングの物質について置き換える。ほかの部分は変わらない。断面積と同じ
重みで縮約し、状態ごとの群の中のスペクトルの違いを行に入れるためで、上の測定で OpenMC の行を 0.06%（減速材の 27 群）以内で再現することを
根拠とする。

## 帰結

- 置き換えの寄与の足し合わせで見積もると（確かめていない）、新しい燃料から 2A-40 への増えのうち減速材の群の中の重みの分 +30.0 pcm
  （27 群 +51.4、14〜26 群 −21.4）がなくなる。1C の 0 MWd/kg でも、減速材の 14〜26 群の群の中の重みの寄与が +50.3 pcm あり、k の差の
  大きさも変わる。燃料の行も動く（記録の表の群の中の重みの列で 2A-40 の 27 群 −13.0、14〜26 群 +39.0 pcm。燃料の列は弾性散乱の自己遮蔽の差も含む。1C の 0 MWd/kg は測っていない）
- 1/E でまとめた OpenMC の減速材の核は、xlc の行より 27 群から出る移行が 0.22% 大きく（xlc の行の和は 0.19% 小さい）、k への寄与は
  1C の 0 MWd/kg で −15.7 pcm。この縮約では消えない（候補は ADR-0133 の 4〜10 eV の H in H2O の散乱断面積の約 0.2% の差。確かめていない）
- 等価なセルに入らない物質（案内管の水など）と UFG の範囲の外の群（熱群、高速群。#0151、#0148）は、この決定の外で、無限希釈の形のまま
- 既定を変えると、静止した標的で出した記録（燃焼、分岐、集合体、炉心）がすべて古くなる。入力で選べる形にするか、既定にするかは実装の
  依頼で決める

## 確認

- 測定: examples/depletion/verification.md「群の移行の行の群の中の重み（#0152）」（OpenMC の核を xlc の UFG の中性子束でまとめた行の
  置き換え）。実装では、縮約した行が、この測定の「核 × xlc の中性子束」の行（OpenMC の核を xlc の中性子束でまとめたもの）に近づく
  こと（27 群で OpenMC の行と 0.06%（減速材）、0.4%（燃料）以内）と、置き換えの寄与の状態の差が群の中の重みの分だけ減ることを確かめる。
  14 群の −0.2%（減速材）、−1.3〜−1.5%（燃料）は、この測定でも残る差で（候補は UFG の範囲の上端の扱い。確かめていない）、閾値は実装の依頼で
  決める
