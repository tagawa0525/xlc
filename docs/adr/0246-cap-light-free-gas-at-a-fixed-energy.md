# ADR-0246: UFG の減速計算で、分離共鳴を持たない核種の自由ガスの上限を、温度によらない 1 keV にする

## 背景

[ADR-0203](0203-scatter-light-nuclides-by-free-gas-in-ufg.md) は、UFG の減速計算で分離共鳴を持たない核種（以下、軽い核種。PWR の
ピンセルでは H-1、O-16、B-10、B-11）の散乱核を温度 T の自由ガスの核にし、入力の `ufg-free-gas.upper`（核種の kT の倍数）より上の入射を
静止した標的にした。[ADR-0209](0209-default-ufg-to-physical-kernels.md) はその既定を `upper = 400` にした。理由の 1 つは、上限なし（参照）
からの k の差が #0133 のピンセルで −4.3、−3.0 pcm（[ADR-0205](0205-scatter-h-in-h2o-by-sab-in-ufg.md)）と小さいことで、この値は移行を
無限希釈の形（ADR-0076）で解いたものである。既定の移行は、同じ散乱核で数えるリングの中性子束の移行
（[ADR-0207](0207-collapse-ufg-transfers-by-ring-flux.md)）になった（ADR-0209）。

[ADR-0243](0243-cap-resonant-free-gas-at-a-fixed-energy.md) は分離共鳴を持つ核種の上限を温度によらない 31 eV にし、軽い核種の `upper` は
分離共鳴を持たないので上限が共鳴を横切らないとして変えなかった。#0274 の燃料の温度を 17 点に細かく取ったピンセルで、`upper` の
400 kT が残差を燃料の温度の点ごとに振らせていると分かった（k∞ の √T、T、T^1.5 の当てはめの残差の最大が新しい燃料、燃えた燃料で
5.41、7.66 pcm、隣の点からの跳びの最大が 5.33、7.63 pcm。`upper = inf` で 0.41、0.54 pcm と 0.24、0.42 pcm）。上限をなくすと反応度
1/k(400 kT) − 1/k(上限なし) が新しい燃料で −14.61〜−25.58、燃えた燃料で −30.95〜−47.41 pcm 動く。

参照解の OpenMC 0.15.2 は `FREE_GAS_THRESHOLD`（400。`include/openmc/physics.h` の 18 行）を使い、`E >= FREE_GAS_THRESHOLD * kT && awr > 1`
のときだけ標的を静止させる（`src/physics.cpp` の 842 行。`references/openmc/src` の v0.15.2）。H-1（質量比 0.99917）はどのエネルギーでも
自由ガスで、O-16 は 400 kT より上で静止した標的になる。

判断の軸: 正確さ > 実行速度 > 保守（CLAUDE.md の「方針」）。既定は物理的に正しい方法か、それが数時間で既定にできなければ参照からの差を
測った速い設定にし（ADR-0209）、厳密な経路を入力で残す。

### 上限が効く仕組み

数値は特記のない限り、`examples/depletion/issue-0274/light-cap/` の `l-*.toml`（#0274 の 2A の新しい燃料のピンセルで、燃料 900 K、
減速材 580 K、重い核種の上限 31 eV、移行はリングの中性子束）を `light_caps.py` で上限なし（`l-inf`）と比べた反応度の差
1/k(上限) − 1/k(上限なし)（#0274 の「軽い核種の自由ガスの上限」）。

1. O-16 の上限 E_c が、U-238 の共鳴 E_r の E_r/α を越えるときに共鳴の吸収が振れる（燃料の温度の振れ）: 自由ガスの核は、入射 E' の
   静止した標的の窓 [αE', E'] の両端をぼかす。出射 E から見ると、上端の側では E より下の入射からの上方散乱が中性子を運び（得）、
   下端の側では E/α の近くの入射の一部が E より下に落ちる（損）。1/E の減速では得と損が打ち消し合う。上限より上の入射を静止した
   標的にすると、出射 E が αE_c と E_c の間では、上端の側（E_c より下の入射）は自由ガスで得があるのに、下端の側（E_c より上の入射）は
   静止した標的で損が無く、O-16 の散乱源が多い。出射 αE_c の近くでは、E_c のすぐ上の入射が自由ガスなら落としていた中性子が来ず、
   散乱源が窪む。`edge_source.py`（O-16、900 K、E_c = 27.14 eV）で、上限のない核に対する散乱源の比 − 1 は、αE_c = 21.08 eV で −5.0%、
   その 0.5 eV 下で −2.1%、2 eV 上で +1.4%。E_c が E_r/α（O-16 の α = 0.7768）を越えると窪みが共鳴の上を通る。燃料 900 K で上限を
   kT の倍数で動かすと、燃料の O-16 の上限が 20.872/α = 26.87 eV を越える 350 kT（27.14 eV）で −29.78 pcm と、310 kT の −16.69、400 kT の
   −19.76 pcm から落ちる。同じ形の落ち込みが、燃料の O-16 の 36.683/α = 47.22 eV（610 kT、47.31 eV で −18.52 pcm。570 kT で −12.76）、
   66.03/α = 85.00 eV（1100 kT、85.31 eV で −10.36 pcm。1040 kT で −7.91）と、減速材の O-16 の 26.87 eV（540 kT で −14.43 pcm。500 kT で
   −11.59）、47.22 eV（960 kT で −9.58 pcm。900 kT で −8.35）にある。UFG の範囲を 9 群に分けた吸収（`l-groups-*`）では、落ち込みはその
   共鳴の群に入る（上限なしからの相対差が、350 kT で 15.97〜27.7 eV の群の −262e-5、610 kT で 27.7〜48.05 eV の群の −174e-5、1100 kT で
   48.05〜75.5 eV の群の −137e-5）。上限が共鳴そのものを越えるところ（燃料の O-16 で E_c = E_r の 269、473 kT）と、H-1 の上限が共鳴を
   越えるところ（減速材で 418、734 kT）には段が無い。燃料の温度の軸では、400 kT の燃料の O-16 が 26.87 eV を 779.6 K で、47.22 eV を
   1370 K で越え、#0274 の 17 点の跳び（750〜800 K と 1300〜1350 K）と合う
2. H-1 の上限が熱群への移行を変える（燃料の温度によらない反応度の段）: H-1 の静止した標的の核は入射 E の中性子を 0 と E の間に一様に
   散らす。自由ガスの核では標的の運動の分だけ出射が上にずれ、0.625 eV より下に落ちる割合が 0.625/E から (0.625 − kT/2)/E になる
   （`edge_source.py`。580 K で −4.0%、入射 20〜200 eV で同じ）。リングの中性子束の移行は減速計算と同じ散乱核で数えるので、400 kT
   （減速材で 20.0 eV）より上の入射が熱群へ落ちる分だけ、9 群の散乱行列の熱群より上の群から熱群への移行の和が上限なしより +3.21%
   多い（`l-groups-400`。300 kT で +4.48%、1100 kT で +0.82%）。移行を無限希釈の形にすると
   （`l-dilute-*`）、400 kT の上限なしからの差は −19.76 から +1.45 pcm に、350 kT は −29.78 から −5.56 pcm に、300 kT は −16.95 から
   +10.54 pcm になる。#0133 のピンセル（燃料 900 K、減速材 600 K。`pin-<状態>-[ring-]light-<上限>.toml`）で、上限をなくした k の変化は、
   無限希釈の形で 1C の新しい燃料 +4.1、2A-40 で +2.9 pcm（ADR-0205 の −4.3、−3.0 pcm と同じ大きさ）、
   リングの中性子束で −27.8、−29.6 pcm
3. 数値の離散化は効きを変えない: 300、350、400 kT の上限なしからの差は、スイープ 12 回、区間の細かさ 4、格子を間引かない計算の
   どれでも 0.01 pcm 以内で同じ

OpenMC との関係:

- 1 の振れは、断面積一定の自由ガスの核を入射エネルギーの閾値で静止した標的に切り替える近似から出るので、同じ近似の OpenMC にもある
  見込み。Lentchner ほか（Incorrect Resonance Escape Probability in Monte Carlo Codes due to the Threshold Approximation of
  Temperature-Dependent Scattering、arXiv:2403.14486、2024。HTML 版を要約で読んだ）は、MCNP 6.2、OpenMC、決定論の計算で、閾値
  θ kT が E_r/α を越える温度 T = (E_r/α)/(θ k) に共鳴を逃れる確率の振れ（共鳴あたり最大 1% ほど）を示し、O-16 と U-238 の 20.8、
  36.7 eV で 776 K、1370 K と見積もった。xlc の 779.6 K、1370 K と合う。OpenMC の側の大きさを、このピンセルで測ってはいない
- 2 の段は OpenMC に無い、xlc だけの近似である（OpenMC は H-1 を静止させない）。#0133 のピンセルの OpenMC との k の差（Slurm 534 の
  1.17200 ± 0.00017、0.82486 ± 0.00017 に対して）は、400 kT で 1C の新しい燃料 +40.4 pcm、2A-40 +78.0 pcm、上限なしで +12.6、
  +48.4 pcm（ライブラリが p2 のもので、記録の比較（examples/depletion/verification.md の「UFG の範囲の群の移行の縮約（ADR-0207）」）と
  違うので、差の値は目安）

## 検討した案

燃料の温度についての滑らかさは、#0274 の 17 点のピンセル（`fine_pin.py`。燃料 560〜1350 K、新しい燃料と燃えた燃料）の、k∞ の √T、T、
T^1.5 の当てはめの残差と跳びの最大で、上限なしとの差は 17 点の 1/k(案) − 1/k(上限なし) の範囲で測った。#0133 のピンセルは既定の
リングの中性子束の移行で解いた。時間は自己遮蔽の 1 回で、#0133 のピンセルは Slurm 750（`--timed`、8 スレッド、xlc 80e62cc72、
2026-11-12）、17 点と無限希釈の形のピンセルは手元の 8 スレッドの目安（xlc e94fd3f10、2026-11-11。`--timed` でない）。

- 案 1: 400 kT のまま（今の既定）: 残差 5.41、7.66 pcm、跳び 5.33、7.63 pcm。上限なしとの差 −14.61〜−25.58、−30.95〜−47.41 pcm。
  #0133 のピンセルで上限なしより k が 27.8、29.6 pcm 高い。振れ（1）は、燃料の温度の格子点をどこに置いても O-16 の上限が E_r/α を
  越える区間に残り、段（2）は参照に無い H-1 の近似
- 案 2: 上限なし（`upper = inf`）: 物理のモデルの上で厳密（O-16、H-1、B の散乱断面積は UFG の範囲で滑らかで、断面積一定の自由ガスの
  核が標的の熱運動の扱いになる。H-1 の扱いは OpenMC と同じ）。残差 0.41、0.54 pcm、跳び 0.24、0.42 pcm。時間は 17 点で新しい燃料が
  1.0〜1.2 → 3.0〜4.1 秒、燃えた燃料が 1.3〜1.6 → 3.4〜4.6 秒、#0133 のピンセルで 1C が 3.13 → 13.1 秒、2A-40 が 27.8 → 77.4 秒（2.8〜4.2 倍）。
  採らない理由: 下の「帰結」のとおり 2A の直積のテーブルが 10 時間ほどになり、案 3 との差（1 pcm 以下）に釣り合わない。参照の経路として
  入力で残す
- 案 3: 温度によらない入射エネルギーの上限（ADR-0243 の `heavy` と同じ形の `upper = { energy = <eV> }`）。上限のエネルギーが燃料の温度で
  動かないので、1 の窪みの位置が温度によらず、効きは温度について滑らか
  - 1000 eV（採用）: 残差と跳びは上限なしと同じ（0.41、0.54 pcm と 0.24、0.42 pcm）。上限なしとの差は新しい燃料で −0.47〜−0.50、燃えた
    燃料で −0.87〜−0.96 pcm、#0133 のピンセルで k が 1C、2A-40 とも +0.8 pcm。時間は 17 点で 1.4〜1.9 秒（新しい燃料）、1.6〜2.2 秒
    （燃えた燃料）、#0133 のピンセルで 6.61、51.7 秒（400 kT の 1.9〜2.1 倍、上限なしの 0.50〜0.67 倍）
  - 3000 eV: 上限なしとの差は −0.14〜−0.15、−0.26〜−0.29 pcm。時間は 17 点で 1.7〜2.5、2.0〜2.8 秒、#0133 のピンセルの無限希釈の形で
    8.59、64.5 秒（1000 eV の同じ形の 6.12、51.2 秒の 1.3〜1.4 倍）
  - 値: 上限なしとの差は、900 K の走査で 10000 kT（燃料 776 eV）−0.98、30000 kT（2,327 eV）−0.34、100000 kT（7,756 eV）−0.08 pcm と、上限に
    従って小さくなる。時間が上限なしの半分ほどで差が 1 pcm 以下の値として 1000 eV にした。1 の窪みの大きさは標的と中性子の速さの比
    √(kT/(A E)) で、2 の段は上限より上の入射から熱群に落ちる割合 0.625/E で小さくなる
- 案 4: OpenMC と同じ扱い（質量比 1 より大きい核種だけ 400 kT、H-1 は上限なし）: 参照と同じモデルでコードどうしを比べられるが、1 の振れ
  （OpenMC にもある近似の誤差）を残す。入力で選べず、測っていない。参照の側の近似の誤差を既定にしないので採らない。同じモデルで比べる
  要が出たら、入力の項目として足す
- 案 5: 400 kT のまま、燃料の温度の格子点を、上限が E_r/α を越える温度から離す: 振れは格子点の間に残り（17 点の足した点の誤差）、
  共鳴と組成で位置が変わる

## 決定と理由

案 3 の 1000 eV にする（上限なしとの差と時間を示した 1000 eV と上限なしの 2 案から、ユーザーが 1000 eV を選んだ。ユーザー 2026-11-12）:
`ufg-free-gas.upper` の既定を `{ energy = 1000 }` にする（今まで 400 kT）。kT の倍数（`upper = 400` で前の既定）と
`inf`（上限なし。参照）は今のまま選べる。`{ energy = <eV> }` の書き方は `heavy` と同じ（正の有限のエネルギー。上限なしは `inf` で書く）。

理由:

- 燃料の温度について滑らか（残差と跳びが上限なしと同じ）で、17 点の格子点から引いた足した点の誤差は、上限の振れで決まる 5.30〜12.46 pcm
  （方式による）から、√T の 3 次 Hermite で 0.27、0.40 pcm、√T の線形で 0.59、0.78 pcm（上限なしと同じ値。#0274）になる
- 物理のモデルの上で厳密な上限なしとの差が 1 pcm 以下で、H-1 の熱群への移行は参照（OpenMC）と同じ扱いに近づく
- 時間は #0133 のピンセルで上限なしの 0.50〜0.67 倍（400 kT の 1.9〜2.1 倍）

前の理由の扱い: ADR-0209 の `upper = 400` の理由（参照からの差 −4.3、−3.0 pcm）は無限希釈の形の移行の値で、既定のリングの中性子束の
移行では上限なしへの k の変化が −27.8、−29.6 pcm だった。ADR-0243 の、軽い核種の上限は分離共鳴を持たないので共鳴を横切らないという
理由は、上限の効きが散乱する核種の共鳴でなく、散乱された中性子が入る先の吸収体の共鳴で決まるので成り立たない（「上限が効く仕組み」の 1）。

### 帰結

- 実装: `FreeGas::default()` の `upper` は `FreeGasCap::Energy(1000.0)`（`crates/lattice/src/ufg.rs`）で、入力の注釈
  （`crates/lattice/src/input.rs`）も同じ値を示す。ADR-0209 の「決定と理由」の `upper` の既定と、ADR-0243 の「決定と理由」の軽い核種の
  `upper` を変えない文は、それぞれの「## 変更」に 1 項を足して直した（どちらも決定の一部の変更で、比べた案はこの ADR に置く。ADR-0243 が
  ADR-0209 の `heavy` を変えたときと同じ形）。ADR-0205 の測った値は、その時点の記録として変えない
- `upper` を書かない入力の結果が変わる。`upper` を明示した入力（examples の下の 201 個。issue-0133、issue-0152、issue-0181、issue-0274 の
  試行）は変わらない。前の既定の結果は `upper = 400` を書けば同じになる（kT の倍数の経路は変えていない）。前の既定で作った記録の節と
  作り直しになる DVC のステージは #0274 の「既定を 1000 eV にした後に古くなる記録」
- 作り直し: 既定を変えると、`upper` を書かない lattice のステージの出力が変わる（bin/lattice のバイトが変わるので、DVC では lattice を
  呼ぶステージがどれも changed になる。この ADR の入力の項目を足しただけでも同じで、kT の倍数の経路の出力は変わらない）。次に作り直す
  2A の直積のテーブル（examples/depletion/p9-product の `lattice-2A`、`branch-2A`）は Slurm 747 で 4 時間 44 分（割り込まれうるジョブで
  目安）。そのうち自己遮蔽が 68%（main の作業ツリーの `lattice-2A.log`、`branch-2A.log` の `shielding` の和 11,329 秒と `total_seconds` の
  和 16,537 秒。747 のログとみるが確かめていない）。自己遮蔽が #0133 の 2A-40 のピンセルと同じ倍率（1.86、2.78 倍。Slurm 750）で延びるとみて、1000 eV で
  7.3 時間、上限なしで 10.2 時間の見込み（測っていない）。ほかのステージの時間の合計は見積もっていない
- OpenMC の参照解は作り直さない。OpenMC の燃料の温度の分岐（400 kT）との比べは、1 の振れ（OpenMC の側の近似の誤差）を含む。OpenMC の
  側の大きさを測るには、`FREE_GAS_THRESHOLD`（`constexpr`）を入力で変えるパッチ（docs/patches/）と references の devShell の作り直し
  （ADR-0212。参照のステージの deps が変わる）が要り、Slurm 534 の 3 本のピンセル（12 分 18 秒で σ 14〜17 pcm）から、振れ（k∞ で
  ±5 pcm）を分ける σ 1.5 pcm には 1 本あたり約 130 倍（8 時間ほど）の粒子が要る見込み。作っていない
- 重い核種の 31 eV（ADR-0243）より上の、分離共鳴の上方散乱（共鳴の形を入れた核。ADR-0204 の案 R2）は残る（#0152、#0083）

### 確認

- 入力: `crates/lattice/src/input/tests.rs` の `ufg_scattering_defaults_to_the_fast_free_gas_with_sab`（省略したときの `FreeGasCap::Energy(1000.0)`、
  前の既定の `upper = 400` と `upper = { energy = .. }` の書き方、止める値と、真偽値の `upper` のエラーの文）。単体試験: `crates/lattice/src/ufg/tests.rs` の
  `a_light_energy_cap_stops_the_free_gas_at_the_same_energy_at_every_temperature`、`crates/lattice/src/ufg/free_gas/tests.rs` の
  `an_infinite_multiple_of_kt_leaves_the_free_gas_uncapped_at_any_temperature`（`upper = inf` は kT が 0 でも上限なし）
