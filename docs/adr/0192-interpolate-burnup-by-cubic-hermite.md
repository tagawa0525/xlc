# ADR-0192: core は燃焼度の軸を、3 点の放物線の傾きの 3 次 Hermite で内挿し、燃焼度 0 からの区間だけ線形にする

## 背景

[ADR-0187](0187-tabulate-burnup-branches-from-history.md) は、core が燃焼度の軸を隣の 2 点で線形に内挿する（案 I1）とし、3 点のラグランジュの 2 次やスプライン（案 I2）を、
Gd や IFBA の燃え尽きの折れ曲がりの近くで振動しうること、多重線形のほかの軸と次数が揃わないこと、点を増やせば線形の誤差は減ることで
退けた。[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の確認（2A の集合体 1 体、履歴の 40 点から選んだ 17 点のテーブル）で、点の間の k∞ の誤差は −32.8〜+179.7 pcm に
なった（48 と 56 の間の 52 MWd/kg が最大。34〜38 MWd/kg でも +117〜+167 pcm）。ホウ素に直すと 15〜20 ppm で、Problem 9 のサイクルの
追跡に使えない。

線形の誤差は点の間隔の 2 乗で減るので、10 pcm にするには間隔をおよそ 1/4（点を約 4 倍）にする。燃焼度の点を 1 つ足すと、分岐の
輸送が状態の数だけ増える（2A で 1 状態 79 秒、`ufg-tolerance` なし。本番の 108 状態なら 1 点あたり約 2.4 時間、集合体の種類ごと）。点を増やす方向は本番で
成り立たないので、燃焼度の軸の内挿の次数を上げる。テーブルの作り方、形式、ほかの軸の多重線形（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)）、範囲の外をエラーにする
決定は変えない。

判断の軸:

- 点の間の k∞ の誤差（最大と rms）。目標は、本番のテーブルの点の数で ±10 pcm
- 折れ曲がり（Xe と Sm の蓄積、Gd の燃え尽き）の近くのオーバーシュート（データの範囲を越えるか）
- 格子点で誤差がないこと（ADR-0097 の性質）。点が 2 つか 3 つの軸の振る舞いが決まっていること（黙った既定を作らない）
- 少数群定数と形状関数のすべての項目に同じ方式を当て、k は内挿した定数から解く（今の形）。ほかの軸との直積の和の形を保つこと

## 検討した案

比べ方: 履歴のすべての燃焼点で公称の 1 状態を解いたテーブル（Gd の 2O の 71 点、2A の 41 点）から点を間引き、選ばなかった点の k∞ を
方式ごとに内挿した定数で解き、全点のテーブルの値と比べた（examples/depletion/verification.md の「燃焼度の内挿の方式と点の選び方」、
daaff322e、2026-10-23）。値は |Δρ| の最大 / rms（pcm）で、「17 点」は ADR-0190 の確認の点、「指針」は下の 26 点。

| 方式                                                | 2O 17 点     | 2O 指針      | 2A 17 点     | 2A 指針      |
| --------------------------------------------------- | ------------ | ------------ | ------------ | ------------ |
| 線形（ADR-0187 の案 I1）                            | 198.8 / 82.9 | 182.3 / 59.8 | 179.7 / 77.8 | 179.7 / 69.7 |
| 3 点のラグランジュの 2 次                           | 214.8 / 49.7 | 24.5 / 8.2   | 29.6 / 9.2   | 12.1 / 5.6   |
| 自然 3 次スプライン                                 | 52.0 / 20.2  | 15.1 / 4.5   | 39.7 / 9.6   | 6.9 / 3.0    |
| 3 次 Hermite、PCHIP（Fritsch–Butland の単調な傾き） | 120.5 / 46.8 | 23.2 / 12.1  | 64.4 / 26.5  | 36.0 / 13.2  |
| 3 次 Hermite、Akima の傾き                          | 98.8 / 45.6  | 19.4 / 7.2   | 64.6 / 22.5  | 20.1 / 8.2   |
| 3 次 Hermite、3 点の放物線の傾き（採用）            | 126.5 / 37.3 | 9.4 / 4.0    | 29.6 / 7.6   | 7.4 / 2.5    |

線形以外の方式は、どれも燃焼度 0 の点を曲線に使わず、0 から次の点までを線形にした値（下の「燃焼度 0 の点」）。

- 案 L（線形）: 格子点で誤差がなく、オーバーシュートしない。指針の 26 点でも 180 pcm 前後（間隔 8 の 40〜60 MWd/kg）
- 案 Q（3 点のラグランジュの 2 次。区間の 2 点と、q に近い側の隣の点）: 区間の中点で使う 3 点が切り替わり、値が不連続になる。
  指針の 26 点で 2O が 24.5 pcm
- 案 S（自然 3 次スプライン）: 滑らかで、2A の指針では最良（6.9 pcm）。2O の指針では 15.1 pcm（58 MWd/kg。端の曲率を 0 にする条件が
  効く候補で、確かめていない）。1 つの点の値が軸のすべての区間に効く（大域的）ので、点を足すと遠い区間の値も変わる
- 案 H-PCHIP: オーバーシュートしない（項目の値の極値の点の傾きを 0 にする）。滑らかな区間の誤差が大きく、2A の指針で 36.0 pcm
- 案 H-Akima: 折れ曲がりに強く、0 の点を曲線に使っても 2O の指針で 23.6 pcm にとどまる。滑らかな区間の誤差が大きい（指針で 19.4〜20.1 pcm）
- 案 H-放物線（採用）: 各点の傾きを、その点と両隣の 3 点を通る放物線の微分にする（端では端の 3 点）。値は区間の 2 点とその外側の
  2 点の、計 4 点の線形結合で、重みは燃焼度の点の位置だけで決まる。2 次の関数を厳密に再現する

燃焼度 0 の点:

- 案 Z1: 0 の点もほかの点と同じく曲線に使う。0 は Xe と Sm のない新しい燃料で、0.1 MWd/kg（2.6 日）までの Xe の平衡で反応度が 2O で
  2741 pcm、2A で 2766 pcm 下がる（履歴の k∞）。この折れ曲がりが 0.1 の点の傾きを通して先の区間に効き、17 点の 0.1 と 0.5 の間で
  2O が −1151.9 pcm、2A が −1185.1 pcm になる
- 案 Z2: 0 の点を傾きに使わず、0 から次の点までを線形にする（採用）。0 から次の点の変化は燃焼度でなく時間（Xe の半減期 9 時間）で
  決まり、燃焼度の多項式では表せない。線形の区間は 0 から次の点（0.1 MWd/kg）までに限る

2 点や 3 点の軸:

- 案 N1: 傾きに使う点（0 を除く点）が 2 つの軸はエラーにする: ADR-0187 の確認のような小さなテーブル（[0, 10, 20]）や、0 と 1 点だけの
  テーブルが使えなくなる
- 案 N2: 傾きを、使える点の放物線（2 点なら直線）の微分にする（採用）。2 点では 3 次 Hermite が線形と一致し、3 点では放物線と一致する。
  曲がりの情報がない 2 点で、データから決まる唯一の多項式に落ちるだけで、推測を足さない

## 決定と理由

これは ADR-0187 の「燃焼度の内挿（案 I1）」の部分を置き換える。ほかの部分（分岐の作り方、構造と形式、範囲の外と燃焼度のない状態の
エラー、核分裂のないテーブルの扱い、入力と段階）は変わらない。

core は燃焼度の軸を、3 点の放物線の傾きの 3 次 Hermite（案 H-放物線）で内挿する。燃焼度の点 B₀ < B₁ < … の区間 [Bᵢ, Bᵢ₊₁] で、
h = Bᵢ₊₁ − Bᵢ、t = (B − Bᵢ)/h として、値は H₀₀(t) yᵢ + H₀₁(t) yᵢ₊₁ + h (H₁₀(t) dᵢ + H₁₁(t) dᵢ₊₁)（Hermite の基底）。点 k の傾き dₖ は、k と両隣
（端では端の 3 点）を通る放物線の B = Bₖ での微分。

- 燃焼度の軸の最初の点が 0 なら、0 の点は傾きに使わず（傾きは 0 を除いた点で求める）、0 から次の点までは線形にする（案 Z2）
- 傾きに使う点が 2 つなら、傾きは 2 点の直線の傾きで、内挿は線形になる。1 点の軸は今のとおり、その値でだけ使える（案 N2）
- 値は 4 点（区間の 2 点と外側の 2 点）の線形結合なので、少数群定数と形状関数のすべての項目に同じ重みを掛け、ほかの軸の多重線形
  （ADR-0097）との直積の和にする。項目ごとに方式を変えない。k は内挿した定数から解く
- 格子点では重みがその点で厳密に 1、ほかで 0 になり（基底を t と 1 − t の積の形で書く）、格子点の状態をそのまま返す
- 重みに負があり凸結合でないので、内挿した定数はソルバに渡す前に今の値の検査（`FewGroup::validate`）を通し、負の重みで内挿したときは
  断面積（全、吸収、νΣf、Σf、χ、散乱）と拡散係数が負でないことも確かめる。負ならエラーにし、点を足すよう示す（0 で切り詰めない）

理由: 採った方式は、比べた方式のうち唯一、2O（Gd）と 2A の指針の点で ±10 pcm に入った（2O で −9.4〜+8.0 pcm、2A で −7.4〜+3.4 pcm）。
重みが点の位置だけで決まる局所的な線形結合で、ほかの軸との直積の形と、すべての項目に同じ方式を当てる今の実装にそのまま入る。
ADR-0187 が案 I2 を退けた理由のうち、振動（オーバーシュート）は測った大きさで扱い（「確認」）、次数がほかの軸と揃わないことは、
燃焼度の軸の点の間隔と曲がりがほかの軸と桁で違うことで説明する（下）。

ほかの軸と次数を変える理由: 格子点の間の線形の誤差は、燃焼度の軸がほかの軸より桁で大きい。燃焼度の軸は、2A の 17 点の間隔
8 MWd/kg の 40 と 48 の間で、44 MWd/kg の線形の誤差が +177.5 pcm（ADR-0190 の確認）、2O の 17 点の Gd の領域（間隔 2）で 9 MWd/kg が
−198.8 pcm（「確認」の記録）。ほかの軸の多重線形の誤差は、新しい燃料の 2B のテーブル（examples/branches/verification.md、6867728、
2026-10-09）で、ホウ素の格子点の間隔 400 ppm の中点で約 5 pcm、減速材と燃料の温度で 0.5 pcm 以下。2A の燃焼した組成のほかの軸の
誤差は測っていない（2A のテーブルのほかの軸は 2 点ずつで、間の値がない）。本番の格子点（熱水力の ADR の後）で再測定する。

### 燃焼度の点の選び方（指針）

本番のテーブルの燃焼度の点は、履歴の燃焼点から次のように選ぶ（26 点）: 0、0.1、0.1 と 0.5 の間に 1 点、0.5、0.5 と 1 の間に 1 点、1、
2、4、5〜12 は 1 おき、16〜40 は 4 おき、40〜60 は 8 おき（MWd/kg）。

- 0.1 は Xe の平衡（2.6 日）、0.1〜1 の 2 点は Sm の蓄積の曲がり、5〜12 の 1 おきは Gd の燃え尽き（2O の k∞ の極大は 8.5 MWd/kg）
- 点の選び方は、曲がりの強い燃料（Gd の 2O）で決め、すべての集合体の種類に同じ指針（区間ごとの点の数と間隔）を当てる（集合体の
  曲がりに合わせて点を増減しない）。0.1 と 0.5、0.5 と 1 の間の点は、それぞれの履歴にある燃焼点から選ぶ（記録では 2O が 0.2 と 0.8、
  2A が 0.25 と 0.75）。本番の燃焼の履歴は、指針の点を燃焼点に含むように燃焼度の点を選ぶ（含まなければ thin_burnup_table.py と
  lattice の `[history]` がエラーにする）。Gd と
  Pyrex で食い違うときは Gd を主にし（日本の PWR の可燃性毒物はガドリニア入り燃料が標準。ユーザー、2026-10-23）、Pyrex（2F）は確認として、
  ±10 pcm に入らなければその分だけ点を足す（#0170。2F は実行していない）
- 2O の 26 点の最大は Gd の極大の 8.5 MWd/kg の −9.4 pcm で、余裕は小さい。Gd の本数や濃度の違う集合体（2P）は確かめていない

  （傾きが 0 から s に変わる折れ線を間隔 h で並べると、折れ曲がりの手前の 1 区間だけでデータの範囲を 2/27 h s 越え、それより 2 区間より
  離れたところは折れ線そのもの）。`negative_interpolated_cross_sections_are_errors`、`negative_interpolated_form_functions_name_the_burnup_points`、`burnup_weights_match_the_python_comparison`（比べた Python と同じ点と値で、
  同じ重みの値。examples/depletion/test_compare_burnup_interpolation.py の `test_hermite_weights_match_the_core` と対）。ADR-0187 と
  ADR-0190 のテストはそのまま通る
- 比べるツール（examples/depletion/test_compare_burnup_interpolation.py、test_thin_burnup_table.py）と記録の表
  （examples/test_verification_tables.py の `DrawBurnupInterpolation`）
- 方式の比較と指針（examples/depletion/verification.md の「燃焼度の内挿の方式と点の選び方」、daaff322e、2026-10-23）: 上の表。オーバー
  シュート（真値がデータの範囲にある項目で、内挿がその範囲を越えた量の相対値の最大。chi を除く）は、採った方式で 17 点の 2O の 4.3e-4、
  指針の 26 点では丸めの 1.1e-16
- core（Rust）の内挿: 2O の指針の 26 点のテーブルで 2O の履歴の 70 点を燃焼させ、点の間の差は −9.5〜+7.9 pcm（同じ記録）。ADR-0190 の
  2A の 17 点のテーブルでは −14.4〜+29.6 pcm（「core の燃焼（2A の集合体 1 体）」。線形のときは −32.8〜+179.7 pcm）

## 帰結

- 本番のテーブルの燃焼度の点は指針の 26 点。ADR-0187 の帰結の「本番の燃焼度の点は、この誤差を測って細かくする」は、この指針で
  決まった。計画の見積もり（30 点 × 108 状態）は 26 点 × 108 状態になる
- 点の選び方は曲がりの強い燃料で決め、全種に同じ指針を当てる。Pyrex の 2F での確認は #0170。Gd の本数の多い 2P、IFBA の 2M は
  確かめていない
- 内挿は 4 点の重みになり、燃焼度の軸のあるテーブルの内挿の手間は、ほかの軸が同じなら線形の 2 倍。全炉心の時間は #0156 で測る
- 燃焼度 0 と次の点の間（0〜0.1 MWd/kg、2.6 日）は線形のまま。Xe を燃焼度でなく時間で扱う（ADR-0035 のミクロ燃焼）ときに見直す
- 指針は、出力密度 38.41 W/g の公称の燃焼の履歴で決めた。Xe の平衡までの燃焼度は出力密度で変わる
