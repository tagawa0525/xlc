# ADR-0229: core の熱水力のフィードバックを、集合体ごとの閉じた 1 次元の流路と燃料棒の径方向の熱伝導で解き、固有値計算と繰り返す

## 背景

VERA の Problem 6〜9 は HFP で、仕様書（CASL-U-2012-0131-004）は熱水力のフィードバックを求める。Problem 6（78〜79 ページ）は Problem 3 の
3D の単一集合体を、表 P6-1 の燃料の密度 10.257 g/cc、入口の温度 565 K、圧力 2250 psia、ホウ素 1300 ppm、定格の出力 17.67 MW（3411 MW / 193 体）、
定格の流量 0.6823 Mlbs/hr（全流量 144.7 Mlbs/hr からバイパスの 9% を除き 193 体で割ったもの）で解く。熱水力の物性（燃料の熱伝導度、
ギャップのコンダクタンス、水の物性）は与えない（MATERIAL PROPERTIES）。表 18（19 ページ）は燃料で発生する熱の割合を 97.4% とする。
Problem 9 の流量は 131.7 Mlbs/hr、圧力は 2250 psia（表 P9-1、86 ページ）、入口の温度は状態ごとに 554.9〜558.8 °F（表 P9-2、90 ページ）。

[ADR-0029](0029-defer-thermal-hydraulic-feedback.md) は、熱水力のフィードバックを初期のマイルストーンで扱わず、燃焼後の結果を実機データと比べる段階で
導入するとした。docs/plans/m4-depletion.md の「熱水力のフィードバック」は、Problem 9 の臨界ホウ素濃度の実測との比較をその段階とみて
M4 で入れるかを ADR で決めるとした。親のセッションが熱水力（#0228）を先に進める案を出し、ユーザーはその案を採った
（2026-11-06 00:04）。この ADR は M4 で入れることを前提に、残りを決める。

今の core は、ケースの状態ごとに減速材の温度と燃料の温度を 1 つずつ持ち、炉心のすべてのノードで同じ値でテーブルを内挿する
（crates/core/src/input.rs の `CaseState`、crates/core/src/state.rs の `State`）。減速材の密度は、テーブルの減速材の軸の格子点の
温度と密度の組で決まる（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)）。core のノードの状態は集合体ごとに持つ（[ADR-0036](0036-keep-core-state-per-assembly.md)）。

判断の軸:

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）
- 既定値は ADR で決めたものだけにし、怪しい状態は推測せずエラーで止める。速度のための近似は入力で選べる項目にし、既定は物理的に
  正しい方にする（CLAUDE.md の「方針」）
- 依存は保守コストで、事実上の標準でない crate は、手書きと比べて保守コストが小さいときだけ足す（グローバルの CLAUDE.md の「設計指針」）

## 検討した案

### 流路の粒度

- 案 G1: 集合体ごとの閉じた 1 次元の流路（採用）。集合体の位置ごとに 1 本の流路を置き、流量は燃料の集合体に等しく分け、横流れを
  持たない。軸方向のノードの減速材の状態は流路のエンタルピーから求め、集合体の位置を `radial-nodes` で分けたノードは同じ流路の
  状態を使う。燃料の温度はノードごとに求める。core のノードは集合体 × 層で、テーブルは集合体で均質化した定数なので、ノードの
  状態に落ちる粒度で足りる
- 案 G2: ピンごと（サブチャンネル）: 仕様書の CAPABILITIES は pin-by-pin の熱水力を挙げるが、core はピンごとの断面積を持たず
  （ピン出力は形状関数の再構成）、ピンごとの状態を断面積に返せない。返すにはピンごとの断面積のモデル（ピンごとの分岐）が要る
- 案 G3: 集合体の間の流量の再配分（圧力損失を等しくする開いた流路）: 損失係数と流路の寸法の仕様がなく、Problem 6 は 1 体なので
  効かない。Problem 7、9 の全炉心で効くかは確かめていない

### 水の物性

圧力 2250 psia（15.513 MPa）、温度 554〜620 K の圧縮水の密度、エンタルピー、比熱、粘性、熱伝導率が要る。

- 案 W1: IAPWS-IF97 の領域 1（IAPWS R7-97(2012)、式 (7)、表 2〜4）と、領域 4 の飽和温度（式 (31)、表 34）を手書きする。粘性は IAPWS
  R12-08 の工業用の推奨（3 節: 式 (10) で μ₂ = 1、密度は IF97）、熱伝導率は IAPWS R15-11 の工業用の推奨（3.1 節: 臨界の項 λ₂ の比熱、
  比熱の比、圧縮率を IF97 から求め、ζ(T_R, ρ) は式 (25) と表 6）を手書きする（採用）。係数は各文書の表から写し、検証用の表（IF97 の
  表 5、35、36、R12-08 の表 4、R15-11 の表 7）でテストできる。領域 1 は 623.15 K まで、PWR の単相の範囲を覆う。表 P6-1 の圧力で、
  IF97 の密度は仕様書の付録 G の表 G-2（550〜580 K、5 K ごと）の 7 点と 5 桁まで一致した（手元の試算、2026-11-06）
- 案 W2: crate を足す: crates.io の IF97 の crate は seuif97 2.3.8（MIT、累計 18,710 ダウンロード）、rust-steam 0.1.9（12,072、
  2023-02 から更新なし）、vle-steam 0.18.0（417）で（crates.io の API、2026-11-06）、serde のような事実上の標準ではない。領域 1、
  飽和温度、工業用の輸送物性だけなら手書きは数百行で、検証用の表で確かめられるので、依存の保守コストの方が大きい
- 案 W3: 物性の表を入力で与える: 物性の出どころが入力ごとに変わり、テーブルの格子点の密度と食い違いうる

### 燃料の温度

燃料棒の径方向の 1 次元の定常の熱伝導（ペレット、ギャップ、被覆管、表面の熱伝達）で、ノードの線出力から燃料の実効温度を求める。

- ペレットの熱伝導度:
  - 案 K1: NRC の MatLib-1.2.2（PNNL-39258、2026-05、2.1.1 節）の UO2 の式（NFI のモデルを Lanning らが直したもの。式 (2-1)、(2-2)。
    燃焼度と温度に依存）と、密度の補正（Lucuta、式 (2-4)）。理論密度は 10.96 g/cc（2.1.6 節）（採用）。FRAPCON-3 以来の NRC の燃料の
    コードの式で、燃焼度の依存を持つ
  - 案 K2: NEA の PWR MOX/UO2 炉心過渡のベンチマーク（NEA/NSC/DOC(2006)20、付録の仕様の 7) の式 (3)）の k = 1.05 + 2150 / (T − 73.15):
    燃焼度の依存がなく、ベンチマークのための簡略の物性
- ペレットの中の温度の解き方:
  - 案 S1: 一様な発熱で、Kirchhoff の積分 ∫_{T_s}^{T(r)} k dT = q′ (1 − r²/R²) / (4π) を熱伝導度の積分の逆で解く（採用）。メッシュがなく、
    一様な発熱の 1 次元の定常の解として厳密。体積平均は u = 1 − r²/R² の Gauss–Legendre の求積
  - 案 S2: 径方向の有限体積: メッシュの誤差が入り、S1 と同じ仮定（一様な発熱）なら得るものがない。径方向の出力の分布（燃焼した燃料の
    リムの効果）を入れるときに要る
- ギャップのコンダクタンス:
  - 案 H1: 入力の定数（W/(m² K)、ペレットの外面の熱流束に掛ける）を必須の項目にし、既定を持たない（採用）
  - 案 H2: FRAPCON や FAST のガスの熱伝導、輻射、接触の和のモデル（熱膨張、再配置、温度のジャンプの距離を含む）: NRC の FAST-1.2.2 の
    コードの説明（PNNL-39254、2026-05）は再配置の式 (2-127)、(2-128) を載せるが、燃焼度 0.0937 GWd/MTU を超える側の係数 2447 ln(Bu) と、
    「P > 20 kW/ft」が 2 か所ある場合分けが、同じページの図 2-24 の曲線と合わない。ギャップのコンダクタンスの式そのものは同じ文書に
    見つからず、FRAPCON-3.4 の説明（NUREG/CR-7022 Vol. 1）は NRC のサイトから取得できなかった（Access Denied、2026-11-06）。出典の式を
    確かめられないので作らない
  - 案 H3: 定数を既定にする（NEA の MOX/UO2 のベンチマークの hgap = 10⁴ W/(m² K)、同じ文書の式 (8)）: 物理から導いた値ではなく、
    既定にすると黙った近似になる
- 被覆管: MatLib-1.2.2 の 3.1.1 節の Zircaloy の式 (3-1)、(3-2) を、Kirchhoff の積分 ∫ k dT = q′ ln(r_co/r_ci) / (2π) で解く（採用。
  発熱なし）
- 表面の熱伝達:
  - 案 F1: FAST-1.2.2 の 4.2.3 節の、単相の強制対流の Dittus–Boelter（式 (4-11)、層流の Nu = 7.86 との大きい方、式 (4-13)）と、核沸騰の
    Jens–Lottes（式 (4-15)）。壁の温度は 2 つの小さい方（採用）。FAST の表 2-19 は Dittus–Boelter の壁の温度が飽和温度を超えたら
    核沸騰の式に切り替えるが、切り替えの直後に壁の温度が数 K 跳び、出力との繰り返しの中で 2 つの式の間を行き来しうる。小さい方を
    とる形は連続で、伝熱の大きい機構を選ぶ
  - 案 F2: Dittus–Boelter だけ: 集合体の平均の流路でも、燃料の上部で壁の温度が飽和温度を超えうる（Problem 6 の平均の熱流束は
    約 0.6 MW/m²。壁の過熱の大きさは確かめていない）
- 燃料の実効温度（テーブルの燃料の温度の軸に渡す 1 つの温度）:
  - 案 E1: 体積平均: VERA の Problem 6 の MC21/CTF と MPACT/CTF の比較（Kelly ら、Nuclear Engineering and Technology 49 (2017) 1326、
    3 節）は CTF の体積平均の温度をピンの一様な温度として MC21 に渡す
  - 案 E2: Rowlands の実効温度 T_eff = (4/9) T_c + (5/9) T_s（中心と表面）: 共鳴の吸収がペレットの表面に偏ることを近似する。
    NEA の MOX/UO2 のベンチマークは T_f = 0.3 T_c + 0.7 T_s（仕様の式 (2)）
  - 案 E3: 格子計算で温度の径方向の分布を解く: 格子計算の燃料を温度の違うリングに分ける必要があり、分岐のテーブルの燃料の温度の
    軸の意味が変わる
  - E1 と E2 のどちらが E3 に近いかを測った値は手元になく、どちらも入力で選べるようにし、既定を持たない（採用）。E3 との差は、
    格子計算でリングごとの温度を変えた参照で測る（#0228 に残す）
- 燃料の発熱の割合: ノードの出力のうち燃料で発生する割合を入力の必須の項目にする（表 18 の 97.4%）。残りは冷却材に直接入る

### 出力との繰り返し

- 案 I1: Picard の繰り返し（採用）: ノードの状態 → テーブルの内挿 → 固有値計算 → ノードの出力 → 熱水力 → ノードの状態。初めの
  ノードの状態は、核分裂のあるノードに一様な出力密度を置いた熱水力の解。収束は、核分裂のあるノードの出力の変化の最大を、核分裂の
  あるノードの出力の平均で割った値が許容 `tolerance` より小さいこと。既定は 1e-5（ノードの出力の 1e-5 の変化は、燃料の温度で
  約 1e-5 × 300 K = 0.003 K、ドップラー係数を −3 pcm/K として 0.01 pcm 未満の見込み。確かめていない）。上限 `max-iterations` の既定は
  50 で、超えたらエラー
- 案 I2: 緩和（出力を前の値と混ぜる）を既定にする: 単一集合体の HFP は、減速材と燃料の負のフィードバックで振動しない見込み
  （確かめていない）。繰り返しが振動したら、緩和を入力の項目として足す
- 臨界ホウ素の探索（[ADR-0145](0145-search-critical-boron-by-illinois-in-input-bracket.md)）との入れ子:
  - 案 B1: 探索の各ホウ素濃度で熱水力の繰り返しを収束させる（採用）: 探索が解く k(ppm) が熱水力を含む 1 つの関数になり、Illinois 法の
    前提（同じ ppm で同じ k）が成り立つ。繰り返しは前の濃度の収束した出力から始める
  - 案 B2: 熱水力の繰り返しの各回でホウ素を探す: 探索の関数が繰り返しの途中の状態で変わる。解く回数は少なくなりうるが、収束の
    判定が 2 つの量にまたがる

### テーブルの内挿

- 案 T1: 熱水力のノードの状態（減速材の温度と燃料の実効温度）で、ADR-0097 のとおり減速材の軸を温度で内挿する（採用）。テーブルの
  減速材の軸の格子点の密度が、熱水力の圧力の IF97 の密度と 5e-6 g/cc（テーブルの入力の小数 5 桁の丸め）より食い違えばエラーにする
  （熱水力の密度とテーブルの密度が別の水を表さないため）。格子点の間は密度を温度で線形に内挿するのと同じで、IF97 の密度との差は
  格子点の間隔で決まる（570 と 600 K の間の 585 K で −0.0034 g/cc、手元の試算）。差の最大を解ごとに出す
- 案 T2: 減速材の軸を密度で内挿する: 格子点の間の密度が熱水力の密度と一致するが、軸の意味（ADR-0097）とテーブルの検査が変わる。
  T1 の差が結果に効くと分かったら見直す

### 入力の形

- 案 N1: ケースに `[thermal-hydraulics]` を足し、状態には減速材と燃料の温度の代わりに入口の温度 `inlet` を書く（採用）
- 案 N2: 状態の `moderator` を入口の温度と読み替える: 同じ項目の意味がケースで変わり、黙った読み替えになる

HFP のケースで `[thermal-hydraulics]` がないときにエラーにするかは、core が入力から HFP を判別できず、一様な温度で解くことは比較の
ための正しい入力（熱水力を切った解）なので、エラーにしない。

## 決定と理由

ADR-0029 を置き換え、熱水力のフィードバックを M4 で入れる。ケースに `[thermal-hydraulics]` がなければ、今のとおり状態の減速材と燃料の
温度を炉心のすべてのノードに使う（HZP のケースと、熱水力を切った比較の解）。ADR-0029 の「M3 でも扱わず、燃料・被覆管・減速材の温度は
入力で与える」は、この形で残る。

### 入力（案 N1）

```toml
[thermal-hydraulics]
power = 17.67                 # 炉心の熱出力 (MW)。ノードの出力は、これに規格化した核分裂率（Σ_g Σf,g φ_g V）の割合
flow = 85.968                 # 燃料の集合体を流れる流量の和 (kg/s)。バイパスを除く。燃料の集合体に等しく分ける
pressure = 15.5132            # (MPa)
fuel-heat-fraction = 0.974    # ノードの出力のうち燃料で発生する割合。残りは冷却材に直接入る
effective-temperature = "volume-average"   # または "rowlands"。既定なし
tolerance = 1.0e-5            # 省けば 1e-5
max-iterations = 50           # 省けば 50
# 半径 (cm)、ペレットの密度 (g/cc)、ギャップのコンダクタンス (W/(m² K))、集合体あたりの燃料棒の本数
rod = { pellet-radius = 0.4096, clad-inner-radius = 0.418, clad-outer-radius = 0.475, pellet-density = 10.257, gap-conductance = 1.0e4, rods = 264 }
# 集合体あたりの流路の面積 (cm²) と濡れ縁 (cm)
channel = { flow-area = 246.65, wetted-perimeter = 882.49 }

[state.hfp]
boron = 1300
b10 = 0.199
inlet = 565                   # 入口の温度 (K)。熱水力のあるケースは moderator と fuel を書かない
```

- 熱水力のあるケースの状態は `inlet` を持ち、`moderator` と `fuel` を書けばエラー。ないケースは逆に `inlet` を書けばエラー
- 燃焼のケースでは、ステップの状態の `inlet` をそのステップの入口の温度にする（下の「燃焼のステップ」）

### 流路と減速材（案 G1、W1）

集合体の位置ごとの流路の流量 ṁ は、`flow` を燃料の集合体の数で割った値。入口のエンタルピーは IF97 の h(p, T_inlet)。軸方向のノード k の
減速材の状態は、ノードの中点のエンタルピー h_k = h_in + (Σ_{j<k} P_j + P_k / 2) / ṁ（P は集合体の位置の層のノードの出力の和）から、
h(p, T) = h_k を温度について解いた温度と、その温度の IF97 の密度。燃料の上と下の核分裂のないノードも同じ式で、燃料の上は出口の
エンタルピーになる。温度が飽和温度（IF97 の式 (31)）以上になればエラー（沸騰を扱わない）。流路は核分裂のある層を持つ集合体の位置だけで、
径方向の反射体の位置（バイパスの水）と核分裂のある層のない集合体の位置は入口の温度。燃料の温度の軸には、核分裂のないノードでは減速材の温度を渡す（発熱がない）。被覆管と構造材の温度は、テーブルの
約束どおり減速材の軸に従う。

### 燃料棒（案 K1、S1、H1、F1、E1 と E2）

ノードの燃料棒 1 本の線出力は q′ = P × `fuel-heat-fraction` / (棒の本数 × ノードの高さ)。棒の本数は `rods` を `radial-nodes` の 2 乗で
割った値。外から順に:

1. 被覆管の外面: T_co = min(T_b + q″ / h_DB, T_sat + (q″ / C_JL)^{1/4} e^{−p / 6.2 MPa})。q″ = q′ / (2π r_co)、h_DB は FAST-1.2.2 の
   式 (4-11)、(4-13)（物性は減速材の温度 T_b の IF97 と R12-08、R15-11、水力直径 4A / P_w）、C_JL = 2.553509 W/(m² K⁴)（式 (4-15)）
2. 被覆管の内面: ∫_{T_co}^{T_ci} k_clad dT = q′ ln(r_co / r_ci) / (2π)
3. ペレットの外面: T_s = T_ci + q′ / (2π r_p h_gap)
4. ペレット: ∫_{T_s}^{T(u)} k_fuel dT = q′ u / (4π)、u = 1 − r²/r_p²。k_fuel は MatLib の式 (2-1)、(2-2)、(2-4)（燃焼度はノードの
   状態の燃焼度、なければ 0。ガドリニアなし）。体積平均は u の Gauss–Legendre の求積、中心は u = 1

熱膨張と再配置は扱わず、寸法は入力の値。実効温度は `effective-temperature` で、`volume-average` はペレットの体積平均、`rowlands` は
(4/9) T(u = 1) + (5/9) T_s。

### 繰り返し（案 I1、B1）

固有値計算は、ノードごとの状態（ノードの減速材の温度、燃料の実効温度と、ケースの状態のホウ素濃度、B-10 の割合、燃焼度）でテーブルを
内挿して解く。初めは一様な出力密度の熱水力の解で、`tolerance` と `max-iterations`（既定 1e-5 と 50）で止める。探索の状態は、探索の
各ホウ素濃度で繰り返しを収束させる（前の濃度の収束した出力から始める）。

### テーブルの内挿（案 T1）

減速材の軸は ADR-0097 のとおり温度で内挿する。軸の格子点の密度が IF97 の ρ(p, T_i) と 5e-6 g/cc より食い違えばエラー。ノードの
温度での線形の内挿の密度と IF97 の密度の差の最大を出す。

### 燃焼のステップ

燃焼のケースでは、ステップの状態（[ADR-0218](0218-give-depletion-steps-power-decay-and-states.md) の名前つきの状態）の `inlet` をそのステップの入口の温度にし、出力は
`power` にステップの出力の割合を掛けた値、流量は一定（表 P9-1 の注）にする。ADR-0218 の「入口の温度は熱水力の ADR の後で、…状態の
減速材の温度…を状態ごとに書く形にとどめ」をこの形に変える。

- 繰り返しの置き場所: 点と中点のすべての解で、繰り返しを固有値計算のすぐ外に置く。探索は各ホウ素濃度で（案 B1）、平衡 Xe の解き直し
  （ADR-0219。同時の反復を含む）は各組成で繰り返しを収束させる。固有値計算の初期値は ADR-0231 のとおり、同じ点か中点の直前の固有値計算
  （繰り返しの前の回を含む）から。繰り返しの初めの出力は、直前に収束した繰り返しの位置の出力の割合に、その解の熱出力を掛けたもの
  （案 B1 の「前の濃度の収束した出力」を、Xe の解き直しと、点と中点の間にも当てる。最初の解だけ一様な出力密度）。案 B1 と同じく、
  探索と Xe の反復が解く関数が熱水力を含む 1 つの関数になる（同時の反復の中でもホウ素が動く）
- 解の熱出力: `power` に、その解が運転している出力の割合を掛ける。中点はステップの割合、点はそこから始まる出力のステップの割合（そこから
  崩壊だけのステップが始まる点と最後の点は、その前の最も近い出力のステップの割合。燃焼点 0 から崩壊だけのステップが始まれば、最初の出力の
  ステップの割合）。平衡 Xe の点の反応率の出力の水準と同じ割合（ADR-0218）で、停止の前後の点も、熱出力は運転している割合（入口の温度は
  ADR-0218 の案 P2 のとおり、点を解く状態のもの）
- 減速材の密度の履歴の変数（[ADR-0215](0215-correct-untracked-history-by-history-branches.md)）: ノードの減速材の温度の、熱水力の圧力の IF97 の
  密度。燃焼度 0 のノードの値は、燃焼度 0 のまま解いた点（燃焼点 0 など）の解の値、ステップの値 x̄ は中点の解の値（熱水力の状態は状態の
  減速材の温度を持たない）

### 出力

状態ごとに、繰り返しの回数と最後の変化、集合体の位置ごとの出口の温度とエンタルピーの上昇、核分裂のあるノードの燃料の実効温度の
体積平均と最大、減速材の密度の内挿の差の最大を標準出力に出す。

### 帰結

- Problem 6 を解くには、テーブルの減速材の軸が出口の温度まで要る。表 P6-1 の条件で、IF97 の入口のエンタルピーは 1293.89 kJ/kg、上昇は
  17.67 MW / 85.968 kg/s = 205.54 kJ/kg、出口の温度は約 600.5 K で（手元の試算、2026-11-06）、examples/vera/xs.toml のライブラリの
  減速材の物質の核種（H-1 を除く被覆管、ホウ素、構造材）の温度の上限 600 K を超える。ライブラリに 600 K より高い温度を足すまで、
  Problem 6 の分岐のテーブルは作れない（#0228）
- ギャップのコンダクタンスと実効温度の式は入力で選ぶ。機構のモデル（案 H2）と、実効温度の格子計算との比較（案 E3）は #0228 に残す
- 燃焼のケースの熱水力は、ブランチ feat/0228-depletion-thermal-hydraulics で「燃焼のステップ」のとおりに入れた（crates/core/src/depletion.rs の
  `deplete`）。繰り返しの置き場所の解の回数と時間は examples/depletion/verification.md の「熱水力のある燃焼（小さな炉心と全炉心）」（定格の
  3 % の熱出力の試行）。実装の形:
  - 点の固有値計算の回数（燃焼の履歴の `solves`）は、繰り返しのすべての回を数える。燃焼の履歴の状態は `moderator` と `fuel` の代わりに
    `inlet` を持ち、点はノードの減速材と燃料の温度 `temperatures` を持つ。点と中点ごとに、繰り返しの回数、出口の温度の最大、燃料の温度の
    平均と最大、密度の内挿の差の最大をログに出す
- ADR-0218 の `micro` のないケースの出力の割合（案 M1）は、燃焼の熱水力を入れても開いていない（`micro` のない熱水力の燃焼は、どのステップも
  定格の熱出力で解く）。開くかは #0228 に残す
- 流路は集合体ごとに閉じ、流量は等分する。全炉心（Problem 7、9）の流量の再配分の効きは確かめていない
- 減速材の温度の内挿の誤差は格子点の間隔で決まる。600 K までの今のライブラリの温度の点（560、565、570、600 K）では、570〜600 K の間で
  約 0.003 g/cc（案 T1）。ライブラリに点を足すとき、間隔をこの誤差で選ぶか、案 T2 を見直す
