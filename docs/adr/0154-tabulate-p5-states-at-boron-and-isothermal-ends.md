# ADR-0154: Problem 5 の分岐のテーブルは、ホウ素 1100 と 1400 ppm、温度 560 と 570 K の 8 状態にし、565 K は内挿する

## 背景

Problem 5（3D の全炉心の零出力試験）は、32 の場合の状態をすべて分岐のテーブルの内挿で解く（ADR-0097、ADR-0146）。
core は状態を与えるとき、すべてのテーブル（燃料の層、径方向の反射体、軸方向の平板）が boron、moderator、fuel の 3 つの
軸を持つことを求め、点が 1 つの軸は状態がその値に等しいときしか使えない。表 P5-2 の状態は次のとおり。

- ホウ素: 1170、1230、1285、1291 ppm。臨界ホウ素濃度の探索（ADR-0145）の範囲は格子点の中に置く
- 温度: 565 K（等温）。等温温度係数の場合 20、21 は 560 K と 570 K（燃料、減速材、構造材のすべて）

ホウ素の格子点の一般の範囲と間隔は #0038 で決まっていない。Problem 5 の入力は約 90 の 2D の格子と 12 の平板からなり、
どれも状態の数だけ格子計算を繰り返す（1 状態は、集合体の格子で約 2 分、平板で約 13 分）。

- 内挿の誤差が、比べる量（臨界ホウ素濃度、ホウ素価値、等温温度係数）に比べて十分小さいこと
- 格子計算の回数

## 検討した案

- (a) ホウ素 [1100, 1400] × 減速材 [560, 570] K × 燃料 [560, 570] K の 8 状態。565 K は内挿する（採用）
- (b) (a) の減速材に 565 K（0.743 g/cc）を足した 12 状態。565 K の減速材の定数が格子点そのものになる
- (c) ホウ素、減速材、燃料のそれぞれ 3 点の 27 状態
- (d) (a) のうち、反射体の格子だけ燃料の温度の軸を落とした 4 状態（#0121）

## 決定と理由

(a) を採る。

- ホウ素の内挿の誤差は、VERA 2B のテーブル（間隔 400 ppm）の中点で +5.0 と +4.8 pcm（examples/branches/verification.md）。
  間隔の 2 乗に比例するとすると、間隔 300 ppm の中点で約 2.8 pcm（臨界ホウ素濃度で約 0.3 ppm、ホウ素価値で約 0.05%）
- 温度の内挿の誤差は、間隔 15 K の中点で 0.5 pcm 以下（同）で、間隔 10 K では約 0.2 pcm
- 等温温度係数は、格子点そのもの（560 K と 570 K）の 2 つの状態の差で求めるので、温度の内挿の誤差を含まない
- 減速材の密度は付録 G の表 G-2（560 K 0.75207、570 K 0.73294 g/cc）。565 K の内挿した定数は密度約 0.7425 g/cc に
  当たり、表 P5-1 の 0.743 g/cc と 0.07% 違う。VERA 2B と 2A の密度の差（1.3%）による −258 pcm から見積もると約 13 pcm で、
  その効きは測って「確認」に書く。大きければ (b) に替える

反射体の格子も (a) の 8 状態で解き、(d) は採らない。

- 反射体のノードの定数は燃料の温度の 10 K で 0.012% 以下しか動かず、外周の燃料のノードの燃料の温度の比は単一集合体の
  格子の比と 0.002% 以内で一致する（#0121）。(d) の誤差は小さい見込みだが、k への効きは測っていない
- core はどのテーブルにも 3 つの軸を求めるので、(d) には core の変更（無い軸を定数として使う、または外周の燃料のノードの
  分岐を単一集合体の比で掛ける）と、その誤差の確認が要る。Problem 5 の格子の時間は、反射体の格子（3.10% の 22 の層の
  種類）の半分を減らせるだけで、core の変更を待たずに 8 状態で解く

炉心のメッシュと設計の層からは、Pyrex の毒物の下端（15.761 cm）の境界を除き、15.761〜15.817 cm（KENO の層の境界）の
0.056 cm を下の端栓の層に含める（p5_inputs.py の `CORE_MERGED_BOUNDS`）。格子と平板は除かない。

- この薄いノードが径方向の真空の面に接する反射体の列にあると、core の NEM の反復が止まる（#0123。ADR-0099 の真空の面の
  横方向の漏れ）。根本の修正は #0123 で、入ったら炉心の段階だけを元の層で再実行する
- 含めたことの効きは Problem 3B（径方向が鏡面反射なので両方を解ける）で測り、k で +0.03 pcm、軸方向の出力で下端の層の
  +0.17%（「確認」）。3B の xlc と KENO-VI の下端の層の差（−4.2%）の 1/25 で、炉心の比べる量に比べて小さい

ライブラリは、H-1 を除く全核種に 560 K と 570 K を足す（lattice は S(α,β) を持たない核種の温度を内挿しない。ADR-0080）。
減速材の温度の軸は、冷却材、Zircaloy-4、SS304、Inconel-718、Pyrex、AIC、B4C を動かし、燃料の温度の軸は燃料を動かす
（表 P5-2 の等温の状態。KENO-VI の付録 G の DTC も、H-1 を除く全物質の温度を燃料とともに動かしている）。

## 確認

- ライブラリ: 560 K と 570 K を足したライブラリ（5b2f4a0e で作った。分岐点 704b59e5、md5 d2215543）と足す前のライブラリ
  （md5 55be71c9）で、2A（565 K）と 2B（600 K）の k はどちらも同じ（1.182781、1.183877）で、ピン出力はバイト単位で同じ
  （93f0b407、2026-10-14。trials/p5-hzp/assembly-2[AB]-{before,after}.toml）。足した温度は、ほかの温度の値を変えない
- 565 K の内挿（`interp-31`）: 3.10% の支持格子のない層のテーブルを 565 K、1300 ppm で内挿した k∞ は 1.182833 で、5-2D の
  単一集合体の格子（565 K、0.743 g/cc、1300 ppm を直接解いたもの）の 1.182781 と +4.4 pcm 違う（93f0b407、分岐点
  704b59e5、2026-10-14。`compare-interp-31.out`）。密度の差（0.07%）の見積もり約 13 pcm より小さく、(b) には替えない
- 15.761 cm の境界を除いたこと: Problem 3B の炉心を、境界あり（examples/vera/p3/core-3B.out とバイト単位で同じ）と、
  15.761〜15.817 cm を下の端栓の層に含めたもので解いた（ad0a3e5d の trials/p5-hzp/p3b-merged、分岐点 a66351f2、
  2026-10-14）。k は 1.00208418 から 1.00208452（+0.03 pcm）、付録 D の 49 層の軸方向の出力の相対差は層 1（燃料の下端から
  0〜3.866 cm）で +0.172%、層 2 で +0.117%、層 3 で +0.060%、それより上は小さく、軸方向のオフセットは −0.0409% から
  −0.0478%

## 帰結

- 範囲の外（1100 ppm 未満、1400 ppm 超、560 K 未満、570 K 超）の状態はエラーになる（ADR-0097）。ほかの問題には、
  その範囲で格子点を決め直す（#0038）
