# ADR-0164: 全核種の燃焼鎖を ENDF/B-VIII.0 の decay、nfy と中性子のデータから決めた規則で作る

## 背景

[ADR-0034](0034-build-full-depletion-chain.md) は、ENDF の崩壊と収率のデータから全核種の燃焼鎖を作り、輸送に使う鎖はそこから縮約すると決めた。
作り方（核種の集合、崩壊の分岐、反応の遷移と準安定状態、核分裂の収率のエネルギー点、データの欠けの扱い）は決めていない
（docs/plans/m4-depletion.md の「核データ」と「進め方」2）。元のデータは、flake で固定した ENDF/B-VIII.0 の decay、nfy、
neutrons のサブライブラリ（[ADR-0124](0124-pin-reference-assets-with-nix.md)）。

データの形（OpenMC 0.15.2 の `openmc.data` で読んで数え、2026-10-14、`chain` の警告と examples/depletion/verification.md の比較で
数え直した）:

- decay: 3,821 の評価（中性子そのものを除いて 3,820。安定 245）。崩壊の分岐比の和の 1 からのずれは最大 9e-7（Ba-114）。
  不安定（NST = 0）なのに半減期が 0 のものが 14（Xe-136、Te-130 など。二重 β 崩壊の型）。娘が decay にない崩壊が 9
  （He-5 の α、Ni-48、Cf-239 などの、炉に現れない核種）。自発核分裂（SF）の分岐を持つ崩壊が 128
- neutrons: 557 の評価。準安定状態への分岐（MF8 の LMF = 9 か 10 と、MF9 か MF10）は、(n,γ) で 17 核種（Am-241、Am-243、
  In-115、W、Pt など。Pm-147、Ag-109 にはない）、(n,2n) と (n,3n) などで数十核種にある。生成物が decay にない反応は
  Pu-245 の (n,p)（Np-245）だけ。核分裂の断面積を持つが nfy に収率のない核種が 57（U-239、Np-239、Pu-243、Am-242、Cf-252
  など）
- nfy: 31 の核分裂する核種の独立収率（MT454）。エネルギーの点は核種で違い、U-235 と Pu-240 は 0.0253 eV、0.5 MeV、14 MeV、
  U-238 は 0.5 MeV と 14 MeV（熱の点がない）、Pu-239 は 2 MeV を加えた 4 点、Th-227 は 0.0253 eV の 1 点。生成物のうち
  decay にない状態への収率は、U-235 の熱で準安定状態が 0.0080、基底状態が 1.6e-8（収率の和は 2）

判断の軸:

- 評価済みデータだけで決まること。データにないものは、推測で埋めずに規則と警告で示す
- 参照の OpenMC（`openmc.deplete.Chain.from_endf`）と同じデータから作るので、違いを理由つきで数えられること
- 冷却計算（崩壊熱と放射能。ADR-0034）にも使えること

## 検討した案

核種の集合:

- 案 N1: decay のすべての評価（採用）。冷却計算に全核種が要る（ADR-0034）
- 案 N2: 中性子のデータを持つ 557 核種とその崩壊の娘: 核分裂生成物の短寿命の先行核が抜け、収率を足し込む先がなくなる

崩壊:

- 分岐比の和が 1 からずれるとき: OpenMC は最大の分岐に差を足す。比で割り直す（採用）と、分岐の比を保つ。ずれは 9e-7 以下なので、
  どちらでも差は 1e-6 の水準
- 自発核分裂: OpenMC は SF の娘を親そのものにし（`openmc.data.Decay` の `daughter` が SF の (ΔZ, ΔA) を持たないため）、
  燃焼行列では SF の分岐が親を減らさない。SF は核を壊すので、親を減らし、生成物を追わない（核分裂片の収率は固定した
  サブライブラリにない）（採用）
- 半減期が 0 の不安定な核種: 安定とみなす（OpenMC と同じ）か、エラーにするか。14 核種はどれも二重 β 崩壊などの、半減期が
  1e18 年を超える核種で、評価が半減期を与えていない。安定とみなし、警告を出す（採用）
- 娘が decay にないとき: OpenMC は質量数の近い長寿命の同位体から β− か β+ の向きを決め、ある核種に着くまで進める。崩壊の型を
  推測することになる。9 件はどれも炉に現れない核種なので、その分岐は娘を生まず（親は減り、α の He-4 は生む）、警告を出す（採用）。
  He-5 の α の娘は中性子で、β−n の中性子と同じく追わない

反応:

- 反応の種類: OpenMC の `from_endf` の既定と同じ (n,γ)、(n,2n)、(n,3n)、(n,4n)、(n,p)、(n,α) と核分裂（採用）。(n,d)、(n,t)、
  (n,np) などを足すと放射化（冷却計算のトリチウムや構造材）に効くが、燃焼の輸送には効かない。冷却計算を作るときに足す
- 準安定状態への分岐の出所:
  - 案 R1: 生成物を基底状態だけにする（OpenMC の `from_endf`）。Am-241 の (n,γ) の Am-242m（熱で約 1 割。MF9 の値）が抜け、
    Am-242m の核分裂と Cm-242 の生成が変わる
  - 案 R2: ほかの評価や、ほかのコードがスペクトルで平均した固定の分岐比（OpenMC が配る PWR 向けの鎖の分岐比の出所は確かめて
    いない）: 評価済みデータの外の数を持ち込み、スペクトルに依存しない
  - 案 R3: 中性子のデータの MF8 が状態を挙げる反応だけ、状態ごとの経路（チャネル）に分ける。割合は MF9（多重度）か MF10
    （状態ごとの生成断面積）のエネルギーの関数なので、鎖には数を持たず、状態ごとの群の反応断面積を xs が作る（採用）
- MF8 の状態と decay の状態の対応:
  - 励起エネルギーの一致（相対 1e-3）で引く: 鎖を作って試すと、Am-243 (n,γ) の Am-244m（MF8 は 72.9 keV、decay は 86.1 keV）、
    Np-237 (n,2n) の Np-236m（185 keV と 56 keV）など 12 件が一致せず、評価が生成を与えた準安定状態を基底状態に落とした
    （このブランチの a74cc2f3〜a998a089、2026-10-14）
  - LFS を準安定状態の番号とみなす: LFS は準位の番号で、Am-241 (n,γ) の Am-242m は LFS = 2
  - 励起状態を decay の準安定状態に、励起エネルギーの相対の差の小さい組から 1 対 1 で対応させ、余った状態は基底状態にする
    （採用）。MF8 の励起状態は、評価が生成を与えた準安定状態を指すので、エネルギーの食い違いより対応の有無を重く見る。余るのは、
    decay に準安定状態がない準位（Cr-51 (n,α) の Ti-48 の 3.63 MeV）か、準安定状態より多く挙げた準位（Ir-191 (n,2n) の Ir-190 の
    36.15 keV）で、即発の γ で落ちる
- 生成物が decay にないとき（Pu-245 の (n,p)）: 崩壊と同じく生成物を追わず、警告を出す

核分裂の収率:

- 収率の種類: 独立収率（MT454）（採用）。累積収率（MT459）は崩壊を通った和なので、鎖の崩壊と二重に数える
- エネルギーの点:
  - 案 Y1: 熱の点だけを使う（OpenMC の `ConstantFissionYieldHelper` の既定 0.0253 eV）: U-238 のように熱の点がない核種で
    決まらない
  - 案 Y2: エネルギーで線形に内挿する: 0.0253 eV と 0.5 MeV の間を線形にする物理の根拠がない
  - 案 Y3: 鎖はすべての点を持ち、使う側が、点ごとの区間（隣の点との幾何平均で区切る。U-235 では 112 eV と 2.65 MeV）の
    核分裂率の割合で重み付けする（採用）。U-235 の熱と 0.5 MeV の境の 112 eV は、OpenMC の `FissionYieldHelper` の
    cutoff の既定値（112 eV）と同じ
- 収率のない核分裂する核種（57）:
  - OpenMC: 同じ質量数の準安定状態、同じ中性子数（isotone）、U-235 の順に探す。U-239 は Pu-241、Np-239 は Pu-240 の収率になる
  - 同じ原子番号で質量数の最も近い核種（採用）。収率の分布は複合核の質量と電荷で決まるので、原子番号を揃えて質量数の差を
    最小にする。U-239 は U-238、Np-239 は Np-238、Am-242 は Am-242m。同じ原子番号がなければ（Ra、Ac、Bk）原子番号の
    最も近い元素で同じ規則
- decay にない生成物: 準安定状態は同じ (Z, A) の基底状態へ（OpenMC と同じ）。基底状態もなければ、核分裂片は中性子過剰
  なので β− の向き（Z + 1）にある核種まで進める（OpenMC は長寿命の同位体との質量数の比較で向きを決めるが、核分裂片では
  β− になる）

切り捨て:

- 全核種の鎖は、分岐比と収率が 0 の項だけを落とし、ほかは切り捨てない（採用）。閾値による切り捨ては、輸送に使う鎖の縮約（ADR-0034）で行う

## 決定と理由

全核種の鎖を次の規則で作る。データにないものを補うときは、補った核種と量を警告に出す。

- 核種: decay の評価のすべて（中性子を除く）。状態は MF1/MT451 の (ZA, LISO) で決め、名前は [ADR-0015](0015-name-nuclides-like-u-235.md) の形。並びは
  (Z, A, LISO) の順
- 崩壊（decay の MF8/MT457）: 半減期、平均の崩壊エネルギー（軽い粒子、電磁、重い粒子の 3 つ）、崩壊の型（RTYP の各桁を
  順に当てる）と娘の状態（RFS）、分岐比。α は He-4、陽子の放出は H-1 を、桁の数だけ生む（娘も同じ核種なら 1 つにまとめて個数を足す。Li-8 の β−α）。β−n などの中性子は追わない。
  分岐比の和が 1 から 1e-5 を超えてずれればエラー、その内なら比で割り直す。SF の分岐は親を減らし、生成物を持たない。
  不安定で半減期が 0 なら安定とみなす。娘の準安定状態が decay になければ基底状態へ送り、基底状態もなければ、その分岐は娘を生まない（α の He-4 などは生む）
- 反応（neutrons、MF1/MT451 の (ZA, LISO) で decay の核種に対応させる）: MF3 に (n,γ) 102、(n,2n) 16 と 875〜891、(n,3n) 17、
  (n,4n) 37、(n,p) 103 と 600〜649、(n,α) 107 と 800〜849 のどれかがあれば、その反応を持つ。生成物は (Z, A) の変化の先の
  基底状態と、(n,p) の H-1、(n,α) の He-4。同じ MT の MF8 が LMF = 9 か 10 で状態を挙げていれば、挙げた状態ごとの
  チャネルに分ける。ELFS = 0 の状態は基底状態、励起状態は decay の準安定状態に励起エネルギーの相対の差の小さい組から 1 対 1 で
  対応させ、余った状態は基底状態にする。MF8 が基底状態を挙げなければ（In-115 (n,γ)）、挙げた状態を除いた残りを基底状態への
  チャネルにする（鎖では LFS を nil と書く）。チャネルの割合は鎖に持たず、xs が状態ごとの群の断面積として作る（「進め方」3）。
  核分裂は MF3 に 18、19〜21、38 のどれかがあれば持つ。中性子そのものの評価（n + n）は鎖に入れない
- 核分裂の収率（nfy の MT454 の独立収率）: すべてのエネルギーの点を持つ。使う側は、点ごとの区間（隣の点との幾何平均で
  区切り、両端は 0 と無限大）の核分裂率の割合で、点の収率を重み付けして足す。nfy の評価は核分裂する核種のものに限り（中性子のデータに核分裂がなければエラー）、同じ核種の評価の重なりもエラーにする。収率のない核分裂する核種は、同じ原子番号で
  質量数の最も近い核種（同じなら軽い方、同じ質量数なら基底状態）の収率を使い、どの核種の収率かを鎖に書く。decay にない
  準安定状態は基底状態へ、基底状態もなければ β− の向きに進める
- 切り捨てない。分岐比と収率が 0 の項だけを落とす

中性子のデータのない核種（約 3,260）は反応を持たない。その断面積の出所は [ADR-0033](0033-store-kinetics-and-cooling-data-in-m4-tables.md) が M4 の計画で決めるとした
ままで、冷却計算を作るときに決める。

## 確認

- 規則: crates/chain/src/build/tests.rs（`applies_each_decay_step_and_emits_light_nuclides`、
  `removes_the_parent_without_products_by_spontaneous_fission`、`rescales_decay_ratios_that_sum_close_to_one`、
  `matches_excited_states_to_isomers_by_the_nearest_energy`、`keeps_the_remainder_when_mf8_lists_only_isomers`、
  `borrows_yields_from_the_nearest_mass_of_the_same_element` ほか）と、ENDF の読み口の crates/chain/src/endf/tests.rs
- OpenMC との比較（examples/depletion/verification.md の「燃焼鎖」、38cae2f9、2026-10-14）: 核種の集合（3,820）、半減期、
  自分の収率（31 核種）が一致し、崩壊の分岐、反応、借りる収率の違いは、すべてこの ADR の規則で説明がつく。同じ 1 群の反応率で
  全核種の鎖の 1 ステップを解くと、U-238 → Pu-239、I-135 → Xe-135、Pm-149 → Sm-149 の経路の核種が 1e-14 の水準で一致する

## 帰結

- OpenMC の鎖と、SF（127 の分岐）、準安定状態への分岐（104 の反応）、収率のない核種の収率の出所（57 核種のうち 53）、
  分岐比の和の直し方（差は 2.1e-7 以下）、decay にない娘（8）で違う（examples/depletion/verification.md）
- MF8 と decay の準安定状態の励起エネルギーが食い違う 12 件は、`chain` の警告に出る。評価の食い違いなので、評価の
  更新（ENDF/B-VIII.1 など）で見直す
- 準安定状態のチャネルの割合は、xs が状態ごとの群の断面積を作る（「進め方」3）までは燃焼に使えない
- 核分裂の Q 値と捕獲のエネルギー（出力の規格化）は鎖に持たない。格子計算の燃焼の出力の規格化（「進め方」5）で決める
- 自発核分裂の収率（sfy）、崩壊のスペクトル、(n,d)、(n,t) などの放射化の反応は、冷却計算を作るときに足す
