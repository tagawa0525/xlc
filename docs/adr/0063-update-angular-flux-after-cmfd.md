# ADR-0063: CMFD の後はトラックの端の角度中性子束も更新し、境界の角度中性子束は等方な値から始める

## 背景

CMFD（[ADR-0083](0083-generalize-to-rectilinear-lattice.md)。M2 では [ADR-0061](0061-accelerate-moc-with-cmfd.md)）で粗メッシュの中性子束を更新したあと、MOC の細かい領域の量をどこまで更新するかと、境界の角度
中性子束の初期値を決める必要があった。

## 検討した案

- 境界の角度中性子束を 0 から始める: 鏡面反射の辺でも漏れがあるように見える
- 等方な値から始める（採用）

## 決定と理由

CMFD の後は、領域の中性子束に加えて、トラックの端の角度中性子束もセルごとの比で更新する。境界の角度中性子束は 0 でなく
等方な値から始める（0 だと鏡面反射の辺でも漏れがあるように見える）。

## 確認

この更新と初期値だけを確かめるテストはない。CMFD の加速のテスト（`cmfd_accelerates_a_pin_cell` など）が、この更新を
含めて同じ解に収束することを確かめる。

## 帰結

なし。
