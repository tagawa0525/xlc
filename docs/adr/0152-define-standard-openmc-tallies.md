# ADR-0152: OpenMC の参照解に、細かな比較に要るタリーの組（標準のタリーの組）を版つきで固定して仕込む

## 背景

OpenMC の statepoint には、実行する前に定義したタリーしか入らない。参照解の k と出力だけなら仕様書の KENO-VI の値を
見ればよく、参照解を自分で作る意味は、xlc と細かく比べられる量（群ごと、物質ごと、核種ごとの反応率、散乱の移行、
集合体の面の量）を持てることにある（ユーザーの指摘、2026-10-12）。これまでのモデルのタリーは、ピンの核分裂率
（2A〜2Q、3A、3B のピンと層、5-2D のピンと集合体）だけで、細かな比較は比較ごとに別の実行で作ってきた:

- 燃料の核種ごとの実効断面積: 入力の `effective-xs-groups` に xlc のライブラリを書いて再実行する。xlc のライブラリは
  xs のコードを変えるたびに作り直されるので、それを deps にすると OpenMC のステージが再実行する（ADR-0130 の帰結）
- 物質ごと・群ごとの中性子収支と移行行列: `openmc_balance.py` の別の実行（1B で 59 分、2K で 97 分、16 スレッド。
  examples/vera/verification.md の「k の差の内訳」）

Problem 3 と 5-2D の参照解は 1 本が 5〜6 時間で、外部の計算機で流す（ADR-0151）。流したあとに足りない量に気づくと、
同じ時間をもう一度かける。statepoint は公開の一次の成果物にする（ADR-0150）ので、何が入っているかが版で分かる必要もある。

判断の軸:

- 実行したあとに足せないので、xlc と比べる量を広めに入れる
- 世代あたりの時間の増え（費用）と statepoint の大きさ（Zenodo の 1 レコード 50 GB、100 ファイル。ADR-0150）
- xlc の量と 1 対 1 に対応すること（群構造、物質、散乱の次数）。xlc のライブラリを OpenMC の deps にしないこと
- 名前と中身が版で固定され、比べるツールが版を見て読めること

## 検討した案

組の決め方:

- 案 A（採用）: 問題の種類（ピンセル、2D の集合体、3D の集合体、2D の 1/4 炉心）ごとに決まった組を 1 つのモジュール
  （examples/vera/openmc_tallies.py）に書き、名前を `standard-<版>/<名前>` にする。モデルのスクリプトは組を足す呼び出しだけを持つ。
  組を変えたら版を上げ、`openmc_tallies_check.py` の表を直す
- 案 B: タリーを入力の TOML に書く。問題ごとに組がばらつき、比べるツールが読む名前が揃わない。どの参照解に何があるかを
  入力ごとに見ることになる
- 案 C: 今のまま、比較ごとに別の実行を足す。Problem 3 と 5-2D では 1 本 5〜6 時間を比較の数だけかける

群構造:

- 案 D（採用）: xlc のライブラリの群構造（WIMS 69 群）の下と上に、範囲の外のビン（0〜1e-5 eV、10 MeV〜1e10 eV）を足した
  71 のビン。境界はモジュールに定数で持ち、xlc の crates/format/src/group.rs と同じことを確認のスクリプトが照らす。範囲の
  外のビンは、バランス（すべてのエネルギーの生成で規格化する）に要る（`openmc_balance.py` の `outside` と同じ）
- 案 E: xlc のライブラリ（vera.msgpack）から群構造を読む（`openmc_common.group_filter`）。xs のコードを変えるたびに
  OpenMC のステージが再実行する（ADR-0130 の帰結）

群構造に縛られない量:

- 案 F（採用）: 物質ごとの ECCO 1968 群（OpenMC の `openmc.mgxs.GROUP_STRUCTURES` のうち、20 MeV までで最も細かい
  もの）の中性子束、吸収、生成。xlc の群構造を変えても、群定数の重みのスペクトルを比べられる
- 案 G: 等対数の数百群。ECCO 1968 は既知の構造で、共鳴の範囲が細かい
- 案 H: ピンごとの細かい群。2D の集合体で 289 × 1968 のビンになり、比べる量（ピンごとの重みのスペクトル）は物質ごとで
  足りる

散乱の次数:

- 案 I（採用）: 物質ごとの移行行列は Legendre の P0〜P3（xlc の散乱は P3。ADR-0075）。層と集合体（均質化の比較）は P0
- 案 J: すべて P0。P1〜P3 の散乱行列を比べられない

核種ごとの反応率:

- 案 K（採用）: 決めた核種（燃料の U-234〜U-238、O-16、減速材の H-1、B-10、吸収体の Ag-107、Ag-109、In-113、In-115、
  Cd-113、Gd-155、Gd-157）のうちモデルにあるもの × 物質 × 71 のビン。ピンごとは、2D と 3D の集合体の燃料の核種だけ
  （燃焼の参照に備えた 1 群の核分裂、(n,γ)、(n,2n) も、群の和で得られる）
- 案 L: モデルのすべての核種（Zr、Sn、Fe、Cr、Ni などを含めて 50 を超える）。核種ごとの断面積を飛跡ごとに引く費用が
  核種の数に比例し、構造材の核種ごとの比較の見込みがない（物質ごとの組で足りる）
- 案 M: 1/4 炉心（5-2D）のピンごとの核種。ピンのメッシュのセルが 18,225（集合体の間の余白を含む）、燃料の物質が 3 つで、
  ビンが 18,225 × 3 × 71 × 5 核種 × 7 スコアの約 1.4 億、statepoint で約 2.2 GB（1 ビン 16 バイト）になる
- 案 N: 3D の集合体の層ごとのピンの核種。全長で積分したピンの 49 倍（約 560 MB）

集合体の面の中性子束（ADF、真空の面の J/φ）:

- 案 O（採用）: 面の両側の水のギャップ（格子の外の 0.04 cm）を帯にしたメッシュの中性子束。鏡面反射の面では法線の向きの
  勾配が 0 なので、帯の平均は面の値と帯の幅の 2 乗の差しか違わない。集合体の間の面では、面を挟む対称な帯（0.08 cm）の
  平均が同じく 2 次で面の値になる。角の帯の交わり（角の中性子束。ADR-0131）も入る。正味の中性子流は MeshSurfaceFilter の
  current
- 案 P: 面のタリーの flux。OpenMC 0.15.2 は面のフィルタに current のほかのスコアを許さない（src/tallies/tally.cpp の
  「Cannot tally score other than 'current' when using a surface filter」）

## 決定と理由

案 A、D、F、I、K、O にする。組の版は 1（`standard-1`）。どの参照解にも入れ、入力に `standard-tallies = false` と書いた
ときだけ入れない（時間の比較のため）。テキストの tallies.out は書かない（標準の組で数十 MB になり、statepoint と同じ値）。

| 名前                                                       | フィルタ                                                                       | スコア                                                                               | 問題              | 比べる xlc の量                                                                    | 統計誤差の見込み                         |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ----------------- | ---------------------------------------------------------------------------------- | ---------------------------------------- |
| `material groups`                                          | 物質 × 71 ビン                                                                 | flux、total、scatter、absorption、fission、nu-fission、2 個以上の中性子を出す 9 反応 | すべて            | 物質ごとの中性子束と反応率、正味の吸収と生成（k の差の内訳の平均。#0096）、群定数  | ≤ 0.05%                                  |
| `material transfer`                                        | 物質 × 71 × 出射 71 × P0〜P3                                                   | nu-scatter                                                                           | すべて            | 散乱行列（P0〜P3）、群から出る移行（`swap_transfer`）                              | ≤ 0.14%                                  |
| `material fine`                                            | 物質 × ECCO 1968 群                                                            | flux、absorption、nu-fission                                                         | すべて            | 群定数の重みのスペクトル、自己遮蔽の群の中の形                                     | ≤ 0.49%                                  |
| `nuclides`                                                 | 物質 × 71 ビン × 決めた核種                                                    | total、elastic、absorption、fission、nu-fission、(n,γ)、(n,2n)                       | すべて            | 核種ごとの実効断面積（燃料の `fuel-xs.msgpack`、吸収体の Ag、In、Cd、B-10）        | ≤ 0.07%                                  |
| `pin groups`                                               | ピンのセル × 71 ビン                                                           | flux、total、scatter、absorption、fission、nu-fission                                | 2D と 3D の集合体 | ピンのセルの均質化した反応率、ピン出力の群ごとの内訳                               | ≤ 0.41%                                  |
| `pin nuclides`、`… flux`                                   | ピンのセル × 燃料の物質 × 71 ビン × 燃料の核種                                 | `nuclides` と同じ、flux                                                              | 2D と 3D の集合体 | ピンごとの実効断面積（`pin-xs.msgpack`、`compare_pin_xs.py`）、燃焼の 1 群の反応率 | ≤ 1.7%（`pin nuclides flux` は ≤ 0.53%） |
| `boundary`                                                 | 外周の帯と角（3D は層ごと）× 71 ビン                                           | flux                                                                                 | 集合体、1/4 炉心  | ADF、角の中性子束（ADR-0131）、1/4 炉心の集合体の面の中性子束と J/φ                | ≤ 0.34%                                  |
| `layer groups`、`layer transfer`、`layer current`          | 軸方向の層（燃料の下と上の構造の境と 49 層）× 71 ビン（× 出射 71、層の境の面） | `pin groups` と同じ、nu-scatter（P0）、current                                       | 3D の集合体       | 軸方向の反射体と層の均質化した群定数、軸方向の正味の中性子流                       | ≤ 0.54%                                  |
| `assembly groups`、`assembly transfer`、`assembly current` | 集合体のメッシュ × 71 ビン（× 出射 71、集合体の面）                            | `pin groups` と同じ、nu-scatter（P0）、current                                       | 1/4 炉心          | 炉心の中の集合体の均質化した群定数、集合体の面の正味の中性子流（NEM との比較）     | ≤ 0.55%                                  |

統計誤差の見込みは、短い実行（下の「帰結」の時間の測定、10 世代を数える）の相対標準偏差を、アクティブバッチの数の平方根に
反比例するとして本番の世代数（2B は 300、3A と 5A-2D は 2000）に延ばしたもの。値の大きいビンから和の 90% を占めるビンの
中の最大を書く（相関と源の収束は考えていない）。目標の誤差を決めて世代数を足すことはしない: 世代数はピン出力の誤差で
決めてある（examples/vera/verification.md の「参照解」「Problem 3 の参照解」「Problem 5-2D の参照解」）ので、ここの誤差は
その世代数で得られるものとし、比べる差がこれより小さいときは比べられない、と読む。

組は、同じフィルタを 1 つのフィルタとして共有する（物質、群、メッシュ）。OpenMC は飛跡ごとのビンの探索をフィルタごとに
1 回で済ませる。

既存のツールとの関係:

- `openmc_model.py` の extract は、`fuel-xs.msgpack`（ピンセル）と `pin-xs.msgpack`（集合体。2K の 2 種の燃料も）を標準の組の
  `nuclides` と `pin nuclides` から書く。入力の `effective-xs-groups` はなくした（xlc のライブラリを OpenMC のステージの deps に
  しない）
- `openmc_balance.py` の別の実行は残す。平均は標準の組から作れるが、σ に要る世代ごとの値が statepoint に残らない（#0096）

## 帰結

費用の目安（Slurm の排他のジョブ、16 スレッド、1 世代 100 万粒子・15 世代で最初の 5 世代を捨てて 10 世代を数える。ライブラリは
`references/openmc/p3-p5-timing`、入力は trials/std/timing-*.toml。2026-10-13、組の版 1。`openmc_tallies.py` を足した
コミットを rebase した上のもの。記録（verification.md）には書かない目安）。タリーはアクティブバッチにだけ効き、非アクティブバッチの
時間は変わらない:

| 問題  | アクティブバッチの時間 s/世代（なし → あり） | 比  | 非アクティブバッチ s/世代（なし → あり） | 15 世代の合計 s（なし → あり） | statepoint MB（なし → あり） |
| ----- | -------------------------------------------- | --- | ---------------------------------------- | ------------------------------ | ---------------------------- |
| 2B    | 7.07 → 22.19（再測定 23.67）                 | 3.1 | 4.85 → 4.11                              | 96 → 243（再測定 258）         | 104.0 → 119.4                |
| 3A    | 10.73 → 25.63（再測定 26.22）                | 2.4 | 5.43 → 5.00                              | 136 → 283                      | 104.3 → 128.2                |
| 5A-2D | 7.95 → 20.91（再測定 20.37）                 | 2.6 | 5.32 → 5.33                              | 108 → 237                      | 104.3 → 115.3                |

statepoint の大半は源の粒子のバンク（104 MB）で、標準の組は 11〜24 MB（3A が最大）。本番の世代数（2B は 400、3A と
5A-2D は 2000。捨てる 100 世代を含む）では、アクティブバッチの比がそのまま全体の時間の比に近く、2B で約 2.7 倍、3A と 5A-2D で約 2.4〜2.6 倍に
なる（Problem 3 と 5-2D の 5〜6 時間が 12〜15 時間）。外部の計算機（ADR-0151）の費用はそれに比例する。

世代の時間が 2 倍を超えたので、（ブランチに残さない試行の入力で）3A でタリーを 1 組ずつ落とした実行（trials/std/ablate.py。アクティブバッチの s/世代、組全体は
25.6）と 5A-2D の実行で内訳を調べた。落とした組と時間: 3A は `nuclides` と `pin nuclides` の両方 18.3、`pin` 3 組 20.8、
層 3 組 22.1、`boundary` 22.3、(n,2n) などの 9 スコア 24.3、`material fine` 24.5、移行行列 2 組 27.8。5A-2D は
`material fine` と (n,2n) などの 9 スコア 15.8、`boundary` 19.0、`nuclides` 19.2、`assembly current` 20.6、`material transfer` 21.4、
`assembly transfer` 24.1。ピンごとの核種のスコアを 7 つから 4 つか 3 つにしても 3A は 23.5〜25.6 で変わらず、3D の集合体から
`pin nuclides` だけを落としても 26.2 で変わらなかった。同じ組を再測定した 3 問題の差は 0.5〜1.6 s で、組を 1 つ落とした差
（多くは 1〜5 s）と同じ大きさなので、1 つのタリーが費用の大半を占めるとは言えず、1 回の実行の差から落とす組を決められない
（確認していない原因の候補: タリーの数と飛跡ごとのフィルタの探索の和）。組は絞らず、費用を上の表のとおり受け入れる。
絞るなら、ここで最も減った `material fine` と (n,2n) などの 9 スコア、`nuclides`（物質の核種ごと）が候補になる。その場合は版を上げる。

- 今の参照解（1B〜2Q。標準の組の前に実行したもの）の statepoint には、標準の組がない。標準の組を使う比較が要るときに
  再実行する
- `openmc_balance.py` の別の実行は残る（#0096）
- 組を変えたら版を上げる。比べるツールは名前（`standard-<版>/…`）で読むので、版の違う statepoint を黙って読まない
- 1/4 炉心のピンごとの核種と、3D の層ごとのピンの核種は入れない（案 M、N）。要るようになったら、版を上げて足す

## 確認

- `examples/vera/openmc_tallies_check.py`（references の devShell で実行する）が、問題の種類ごとのタリーの名前、フィルタの
  並び、スコア、核種と、群の境界が xlc の WIMS 69 群と同じことを確かめる
- 短い実行（上の測定。10 世代を数える）で、すべての物質とビンの合計の P/A と k（P/A は、生成の合計を正味の吸収の合計で割ったもの）、物質ごとの nu-scatter の P0 の
  行の和と scatter + 増える分の比が合うこと（trials/std/consistency.py）。P/A と k（± は k の標準偏差）は、2B が 1.18329 と
  1.18364 ± 0.00030、3A が 1.17134 と 1.1712 ± 0.0006、5A-2D が 1.00470 と 1.00488 ± 0.00035。比は 2B が 0.9998〜1.0000、3A が
  0.9958〜1.0000、5A-2D が 0.9955〜1.0002（0.5% ほど外れるのは数えた粒子の少ない物質）。差は k の標準偏差の 1 倍程度以内
