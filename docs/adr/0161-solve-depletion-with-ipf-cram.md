# ADR-0161: 1 ステップの燃焼を CRAM の不完全部分分数形（次数 16 と 48）と疎な LU で解く

## 背景

ADR-0025 は燃焼を CRAM で解き、予測子・修正子法で時間を進めると決め、ADR-0034 は CRAM を数千核種の疎行列で解くとした。
CRAM の形、次数、係数の出所と検算、線形の解法、1 回の呼び出しで何をするかは決めていない（docs/plans/m4-depletion.md の
「進め方」4）。

解く式は、燃焼行列 A（崩壊定数と反応率から作る。`A[i][j]` は核種 j の 1 個が単位時間に核種 i を生む割合）、初期の数密度
n(0)、時間 t に対する n(t) = exp(A t) n(0) である。行列の大きさは、輸送に使う縮約した鎖で数百〜1,500 核種、冷却計算の全核種の
鎖で約 3,800 核種（ADR-0034、計画の「核データ」）。

- 精度: 崩壊定数は 1e-15 1/s 未満から 1e+3 1/s 以上に広がり、t（1e5〜1e7 s）を掛けた ‖A t‖ は 1e9 を超える。短寿命の核種を
  含む硬い系を、安定に解く
- 費用: 格子計算は燃焼のステップごとに、燃焼の領域（ピンかリング。1/8 の対称性で百〜数百）ごとに、予測子と修正子で 2 回解く
- 照合: 参照解の OpenMC（openmc.deplete）は CRAM48 を既定に使うので、同じ方法なら燃焼の比較から行列指数の差を外せる

## 検討した案

方法（論文は手元になく、各案の出典の要旨は読み直していない）:

- 案 A: CRAM（Chebyshev 有理近似。負の実軸の上で exp を一様に最良近似する有理関数）を行列に当てる。次数 k の誤差は
  およそ 9.289^−k（Trefethen, Weideman, Schmelzer, BIT 46, 653–670, 2006）で、‖A t‖ によらない。極の数だけ複素の疎な連立方程式を
  解く。固有値が負の実軸から離れると精度が落ちる（Pusa, Nucl. Sci. Eng. 169, 155–167, 2011）
- 案 B: Bateman の解析解（直列の鎖に分けた TTA）。分岐と環（α 崩壊で戻る、(n,2n)）を鎖に展開する打ち切りがいり、崩壊定数が
  近いと打ち消しで桁を失う。Serpent で CRAM と比べた Isotalo, Aarnio（Ann. Nucl. Energy 38, 261–268, 2011）は、CRAM の方が
  速く精度もよいとした。解析解は、小さな鎖の検証の参照にだけ使う
- 案 C: Runge–Kutta などの常微分方程式の積分。陽解法は ‖A t‖ が 1e9 の硬い系で刻みが極端に小さくなる。陰解法
  （BDF、Rosenbrock）は安定だが、誤差の制御と多くの刻みが要り、1 ステップあたり CRAM の極の数より多くの連立方程式を解く
- 案 D: Krylov 部分空間（Arnoldi）で exp(A t) n(0) を近似する。‖A t‖ が大きいと部分空間の次元が増え、硬い系に向かない
  （Pusa, Leppänen, Nucl. Sci. Eng. 164, 140–150, 2010 が燃焼行列で比べた方法の 1 つ）
- 案 E: Padé 近似とスケーリング・二乗（Moler, Van Loan, SIAM Rev. 45, 3–49, 2003 の方法の 1 つ。Rust の `expm`、`expm_rust`）。
  密行列で、二乗の回数は log2 ‖A t‖（約 30）。1,500 核種の密行列の積を数十回行い、疎の形を失う
- 案 F: Chebyshev 多項式（有理でない）の展開。次数が ‖A t‖ の平方根に比例して増え、硬い系では数万次になる。複素平面の周回積分の
  台形則（Talbot の型）の有理近似は、同じ極の数で CRAM より誤差が大きい（Trefethen ほか、2006）

CRAM の形（案 A の中）:

- 部分分数分解（PFD）: r(z) = α0 + 2 Re Σ α_l/(z − θ_l)。次数 16 までは使えるが、高い次数では留数が大きく、和の打ち消しで
  丸めが増える
- 不完全部分分数（IPF、Pusa, Nucl. Sci. Eng. 182, 297–318, 2016, doi:10.13182/NSE15-26）: r(z) = α0 ∏ (1 + 2 Re[α̃_l/(z − θ_l)])。
  因子ごとに解いて次の右辺にするので、次数 48 でも丸めが増えない。OpenMC の `IPFCramSolver` と同じ形（採用）

次数:

- 次数 16（8 極）だけ: 安いが、複素の固有値を持つ系（環）で誤差が増える（「確認」の環で 6.1e-12）
- 次数 48（24 極）だけ: 環でも倍精度の丸めの水準（1e-15）に届くが、16 の 3 倍の連立方程式を解く
- 両方を持ち、呼ぶ側が選ぶ（採用）

線形の解法:

- 密行列の LU: 1,500 核種の複素 LU は (8/3) n³ ≈ 9e9 の実数の演算で、1 極あたり 1 コアで 0.1〜0.5 秒（faer の密 LU を数十 GFLOP/s
  として見積もった。測っていない）、CRAM48 の 1 回で数秒〜10 秒。格子計算の燃焼の 1 本（百〜数百の領域 × 2 回 × 40 ステップ、
  約 1 万回）で十数〜数十物理コア時間になり、輸送（約 49 物理コア時間。計画の「CPU と記憶の見積もり」）と同じ桁になる
- 疎行列の LU: 燃焼行列の非零は、崩壊と反応で 1 核種に数個、核分裂する核種（数十）の列に収率の千個ほどで、合わせて数万
  （見積もり）。核分裂生成物の行は核分裂する核種の列とだけつながり、埋め込み（fill-in）は小さい見込みで、密の数千分の 1 以下の
  演算になる（見積もり。本物の鎖で測る。#0111）（採用）

疎な LU の実装:

- faer の疎な LU（ADR-0007。純粋な Rust、複素の疎な LU、記号的な分解を数値の分解から分けて使い回せる。crates.io の
  ダウンロード 504 万、直近 90 日 150 万、0.24.4 は 2026-06-24。crates.io の API、2026-10-14）（採用）
- 自前の Gauss 消去（核種の並びを鎖の向きに合わせた消去）: 順序付けと埋め込みの扱いを抱える。faer で足りるので作らない
- rsparse（CSparse の移植、純粋な Rust、ダウンロード 6.8 万）: 複素数を扱わない
- UMFPACK、SuperLU（scipy が使う）に結ぶクレート: システムの依存が要る（ADR-0007）

CRAM そのものを持つクレート: crates.io の `nucleide-depletion`（0.16.0、2026-09-10 公開、ダウンロード 254）と `halflife`
（0.1.6、2026-08-16 公開、212）は、公開から 1〜2 か月で使われておらず、事実上の標準でない（crates.io の API、2026-10-14）。
CRAM は定番のない数値計算として自前で書く（ADR-0006）。

1 回の呼び出しの範囲:

- 1 ステップの行列指数 exp(A t) n(0) だけを持ち、予測子・修正子、反応率の作り方、出力の規格化は呼ぶ側に任せる（採用）
- 予測子・修正子の方式（CE/LI、CE/CM など）まで共通のクレートに置く: 方式は格子計算の燃焼の ADR で決める（計画の
  「格子計算の燃焼」）。lattice と core で方式が同じとは決まっていない（core は計画で未決）ので、いま共通にしない

## 決定と理由

- 方法: CRAM の IPF の形（Pusa 2016）で exp(A t) n(0) を求める。各極 θ_l について y ← y + 2 Re[α̃_l (A t − θ_l I)⁻¹ y] を
  順に当て、最後に α0 を掛ける。極ごとの行列は対角だけが違い、非零の位置は同じなので、記号的な分解は 1 回の呼び出しで 1 回だけ
  行い、数値の分解を極ごとに行う。硬い系でも ‖A t‖ によらず同じ数の連立方程式で済み、OpenMC と同じ形なので照合できる
- 次数: 16 と 48 の両方を持ち、呼ぶ側が選ぶ（`CramOrder`）。既定値は置かない。どちらを使うかは、格子計算の燃焼と core の
  ミクロ燃焼の ADR で決める。次数 16 は連立方程式が 3 分の 1 で、実の固有値の鎖では 48 と同じ丸めの水準（「確認」）、48 は環を
  含む鎖でも丸めの水準で、OpenMC の既定と同じ
- 係数: Pusa（2016）の表の値を、OpenMC 0.15.2 の `openmc/deplete/cram.py` が写したものから写す（論文の表とは照らしていない。
  手元に論文がない）。写しの誤りは、1 核種の崩壊 exp(−x) を x ∈ [1e-6, 1e5] で近似の誤差の水準で再現することと、OpenMC と
  同じ行列で丸めの水準で一致することで検算する（「確認」）。係数の 1 つの桁の誤りは、その桁の大きさの誤差になる
- 線形の解法: faer の疎な複素 LU（ADR-0007）。faer の並列（rayon の機能）は切り、材料ごとの並列は呼ぶ側が持つ（入れ子の
  並列を避ける）
- 入力の検査: 燃焼行列は非対角が非負（生成）、対角が非正（消滅）なので、同じ位置を足したあとにこれを外れる項、範囲外の
  添字、有限でない値はエラーにする（転置や符号の取り違えを止める）。打ち消し合う寄与の和は丸めで符号を外れうるので、
  和の絶対値が寄与の絶対値の和の 16 ε 以下なら 0 とみなす（m 個の和の丸めは (m − 1) ε × 絶対値の和で抑えられ、16 ε は
  17 個までの寄与を覆う。1 つの位置の寄与は崩壊と反応の数種）。時間は有限の非負、初期の数密度は有限であること。
  初期値の負は許す（前のステップの CRAM が返す、近似の誤差の水準の小さな負の値を、そのまま次に渡すため）
- 単位: 時間は s、行列は 1/s。数密度は線形なので単位を問わない（ADR-0014 の 1/(barn cm) をそのまま渡せる。IPF の途中の値が
  n0 / α0 まで育つので、1e262 程度より大きな値はあふれる）
- 置き場: 共通のクレート xlc-depletion（ADR-0162）

## 確認

解析解との比較（crates/depletion/src/cram/tests.rs）。誤差は、誤差の絶対値の最大を初期の数密度の最大で割ったもの
（CRAM の誤差は、近似の一様誤差 × 初期の大きさで抑えられるため）。閾値は、テストより前の試作で測った値（2026-10-14）に
数十倍の余裕を持たせたもの:

| テスト                                                     | 閾値                 |
| ---------------------------------------------------------- | -------------------- |
| `one_nuclide_decays_exponentially`（x ∈ [1e-6, 1e5]）      | 1e-13                |
| `a_chain_matches_bateman`（‖A t‖ = 1e9 の硬い鎖を含む）    | 1e-13                |
| `a_branching_decay_splits_by_the_ratios`                   | 1e-13                |
| `a_cycle_with_complex_eigenvalues_matches_the_closed_form` | 16: 1e-10、48: 1e-13 |
| `a_small_daughter_keeps_its_relative_accuracy`（相対誤差） | 1e-12                |

最後の行は、親の 1e-9 倍で釣り合う短寿命の娘（Xe-135 の型）の相対誤差で、小さな核種も相対的に精度を保つことを見る。ほかに
`zero_time_keeps_the_densities_exactly`、`the_densities_scale_with_the_initial_densities`（2 の冪で拡大するとちょうど同じ倍）、
入力の検査のテスト（crates/depletion/src/matrix/tests.rs と cram/tests.rs の `rejects_*`）。

OpenMC との比較（examples/depletion/compare_openmc.py、入力は examples/depletion/cases.toml）: `openmc.deplete.cram` の
`CRAM16`、`CRAM48` と xlc に同じ行列を与え、差の絶対値の最大を初期の数密度の最大で割ったものが 1e-13 以下であること
（同じ有理近似を同じ係数で当てるので、差は線形の解法の丸めだけ）。

測った値は examples/depletion/verification.md。2026-10-14 の測定で、解析解の誤差は次数 48 ですべて 2.2e-15 以下、次数 16 は
実の固有値の鎖で 1.9e-15 以下、環で 6.1e-12、OpenMC との差は 6e-16 以下で、すべて閾値の内にある。

## 帰結

- 予測子・修正子、燃焼の領域、出力の規格化は、格子計算の燃焼の ADR で決める（計画の「格子計算の燃焼」）。core の
  ミクロ燃焼も同じクレートの `deplete` を呼ぶ
- 次数 16 は、複素の固有値を持つ系で誤差が 1e-12〜1e-10 の水準になる。燃焼鎖の環（α 崩壊、(n,2n)、準安定状態の
  行き来）がどれほど固有値を実軸から離すかは、本物の鎖で測る
- 1 回の呼び出しで記号的な分解をやり直す。同じ鎖の材料は非零の位置が同じなので、材料の間で使い回せる。CRAM の時間を本物の
  鎖で測り、使い回すかを決める（#0111）
- 係数を Pusa（2016）の表と直接照らしていない。論文を手に入れたら照らす
- crates/depletion（faer）を足すと、build の段階の 3 つの実行ファイルが変わる（#0114）
