# ADR-0111: OpenMC と比べる VERA の集合体の入力を方位角 30・間隔 0.03 cm にする

## 背景

[ADR-0077](0077-keep-vera-discretization.md) で、VERA の入力の離散化（ピンセルは方位角 64・間隔 0.02 cm、集合体は
方位角 32・間隔 0.05 cm、燃料 5 リング）を変えないと決めた。そのあと、2 の冪でない方位角の数を間隔の平均で比べ、
正方形の格子で (0, π/2) の角の数が奇数（補正後も 45° の向きを含む）のとき、近い偶数より k の誤差が小さくなることが多いと分かった
（examples/vera/verification.md「方位角の数の奇偶と間隔の平均」、9da6de8、2026-10-10）。CMFD の高速化
（[ADR-0110](0110-solve-cmfd-as-finely-as-the-moc-change.md)）で MOC が速くなり、細かいトラックの費用も下がった。

- k とピンの核分裂率の離散化の誤差
- 1 状態の時間（自己遮蔽 約 110 秒、MOC 約 40 秒）
- 効く理由の分かっていない規則（#0047）が外れたときの誤差

## 検討した案

数値は、その案の設定で 2B を解き、方位角 128・間隔 0.01 cm と比べた k とピンの核分裂率（rms）の差と、MOC の時間
（examples/vera/verification.md「集合体の入力を方位角 30・間隔 0.03 cm に」の節の、9da6de8 の
測定の表）。

- 案 A: 入力のまま（方位角 32・間隔 0.05 cm）。k −26 pcm、ピンの rms 0.08%、MOC 40.8 秒
- 案 B: 方位角 32 のまま間隔だけ 0.03 cm。k −24 pcm、ピンの rms 0.03%、MOC 44.8 秒。奇偶の規則に頼らない
- 案 C: 方位角 30・間隔 0.03 cm（採用）。k −3 pcm（間隔 0.05、0.04、0.03 cm の平均で −6 pcm）、ピンの rms 0.03%、MOC 43.4 秒
- 案 D: 方位角 18・間隔 0.03 cm。k −5.5 pcm、ピンの rms 0.04%、MOC 37.0 秒
- 案 E: 方位角 64・間隔 0.03 cm。k −5 pcm、ピンの rms 0.02%、MOC 72.4 秒

## 決定と理由

案 C にする。

- ピンの核分裂率の誤差は方位角より間隔で決まり、0.03 cm にすると rms が案 A の約 1/3（案 B、C）から 1/2（案 D）になる
- 案 B との k の差（約 20 pcm）は奇数の効果による。2B では、30 と 32 のどちらも間隔による幅が約 5 pcm 以内（5.1、2.3 pcm）なので、
  この差はばらつきではない
- 奇数の効果は仕組みが分かっていない（#0047）ので、外れたときの誤差を小さく保つ。外れたときの誤差の目安は隣の偶数で、
  案 C は 32（間隔 0.03 cm で −24 pcm。28 は間隔 0.04 cm の 1 点で −38 pcm）、案 D は 16、20（間隔 0.03 cm で −90、−66.5 pcm）。ピンセル 1B（間隔 4 通りの平均）では、方位角 18 は
  −94 pcm で、16（−179 pcm）より小さいが 20（−90 pcm）と変わらない。30 は −37 pcm で 28、32（−83、−63 pcm）より小さいが、1B は間隔による
  幅（30 で 93 pcm）が大きいので、1B は案 C を支持も否定もしない
- 22 と 26 も奇数で、2B で隣より小さいが、2B では間隔 0.04 cm の 1 点しか測っていない
- 案 C は案 B より速く、案 A より MOC が約 3 秒延びるだけで、自己遮蔽を含む 1 状態の時間はほぼ変わらない

適用の範囲は次のとおり。

- 変える: OpenMC と比べる集合体（examples/vera/p2/assembly-2B.toml〜assembly-2D.toml）
- この ADR では変えない: ピンセル（examples/vera/p1/pincell-1B.toml〜1D、方位角 64・間隔 0.02 cm）。1B の間隔 4 通りの平均では
  方位角 70 が 64 より参照に近い（−13、−46 pcm）が、間隔による幅（64 で 94 pcm）が大きく、1 つの間隔で解く入力の誤差は
  間隔の選び方でも決まる。間隔と合わせて選び直すかは #0049 で決める
- 変えない: 同じ離散化の解どうしを比べる入力（方位角 32・間隔 0.05 cm）。ADF と NEM の比較
  （examples/vera/p2/assembly-2B-vacuum.toml、lattice-9x9-vacuum.toml、examples/reflector/）、分岐のテーブルと直接の計算の
  比較（examples/branches/）、テーブルの分割（examples/split/）。離散化の誤差は比べる両方に同じく入るので、
  変えると記録との連続性だけを失う
- 燃料のリングは 5 のまま

## 確認

2B〜2D を案 A と案 C で同じコミットで解いた（examples/vera/verification.md「集合体の入力を方位角 30・間隔 0.03 cm に」、
674fafd、2026-10-10）。k は 3 問題とも +23〜+24 pcm 動き、2B の参照（方位角 128・間隔 0.01 cm）との差は −26 pcm から
−3 pcm になる。OpenMC とのピンの核分裂率の差は rms 0.11% から 0.09% になる。

## 結果

- 奇数の効果の仕組みは分かっていない（#0047）。仕組みが分かったら、方位角の数を見直す
- 正方形でない格子では 45° の向きが入らないので、この選び方はそのまま使えない
- 光学的に非常に厚い領域（無限希釈の共鳴の群）では、k がトラック間隔に対して不規則に動く（ピンセルの P0 で、間隔
  0.012〜0.05 cm で −149〜+91 pcm。燃料を横切るトラックの本数の数え誤差。examples/vera/verification.md、4729666、
  2026-10-08）。ADR-0077 から引き継ぐ。制御棒や Gd のような吸収体を扱うときに見直す（M3 では AIC と B4C を入れたところで
  測る）
