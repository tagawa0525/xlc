# ADR-0228: 履歴の変数が複数のとき、線形化の誤差 L、Δσ_L と自分の数密度の項を、ノードの組成の指標 P を変数ごとの見込み w_j P_j の割合で分けて足す

## 背景

[ADR-0215](0215-correct-untracked-history-by-history-branches.md) は、履歴の変数 j ごとに、追わない核種の分 U_j を w_j = (H_j − H_j⁰) / (H_j^b − H_j⁰) で、
線形化の誤差 L_j と反応率の Δσ_L,j を組成の指標の比 P / P_j で足し、反応率の微分を持つ核種には自分の数密度の項
(∂σᵢ/∂N̄ᵢ)(Nᵢ − N̄ᵢ⁰ − (P / P_j) ΔN̄ᵢ^j) を足すと決めた。P はノードの追う核種の数密度の差 Nᵢ − N̄ᵢ⁰ の全体の熱群の νΣf の線形の補正、P_j は
履歴の分岐 j の数密度の差 ΔN̄ᵢ^j の同じ量。ADR-0215 は、変数が複数のとき P / P_j を変数ごとに掛けると L を重ねて足すので、変数の間の分け方は
その変数を足すときに決めるとした（ADR-0215 の「テーブルに持つ補正（案 C3）と、core の重ね方」と「ミクロ燃焼の反応率の微視的断面積（案 S2）」）。
制御棒の挿入の割合 H_r（ADR-0215 の履歴の変数）を足すので、ここで決める。

判断の軸:

- 1 つの変数だけが公称でないノードでは、ADR-0215 の P / P_j の形をビットで保つ（減速材の密度の確認の測定と同じ値）
- 線形の補正が担う分を重ねて足さない（ADR-0215 の判断の軸の「二重に数えない」）
- 格子計算の回数を増やさない（変数ごとに 1 本の履歴の分岐。ADR-0215）

## 検討した案

- 案 A（変数ごとに独立に P / P_j を掛けて重ねる）: Σ_j (P / P_j) L_j。ADR-0215 は L を組成の差の大きさに 1 次で近いとみた（ADR-0215 の案 R4）。
  そのとおりなら、ノードの組成の差が Σ_k w_k ΔN̄ᵢ^k のとき L の見込みは Σ_j w_j L_j で、案 A は変数 j の L に (Σ_k w_k P_k) / P_j を掛けるので、
  ほかの変数の分 Σ_{k≠j} w_k P_k / P_j を余分に足す。自分の数密度の項も (Nᵢ − N̄ᵢ⁰) を変数の数だけ足す（#0190 の「残ったレビューの指摘」）。
  2A の値での大きさは「確認」
- 案 B（交差の項を持つ: 2 つの変数を同時に変えた履歴の分岐を流し、交差の残り R_{m,r} − R_m − R_r を持つ）: 交差の大きさを測れるが、集合体の
  種類ごとに燃焼 1 本（2A-rods の燃焼の実績で 59 分、Slurm 672）と、その自分の条件とハイブリッドの分岐（制御棒の値ごと）が増え、変数が増えると
  組の数で増える。ADR-0215 は変数の間の交差を持たない（測っていない）とした。交差の大きさは測っていない。交差の項を足しても、2 つの変数の
  L に同じ P を掛ける重なりは残るので、分け方は別に要る
- 案 C（P を見込みの割合で分ける。採用）: 変数 j の L_j、Δσ_L,j に a_j = (P / P_j) × (w_j P_j / Σ_k w_k P_k) を掛ける。Σ_j a_j P_j = P で、
  ノードの組成の差の大きさを 1 回だけ配る。ノードの組成が見込み Σ_k w_k ΔN̄ᵢ^k のとき a_j = w_j（L の見込み Σ_j w_j L_j）、1 つの変数だけが
  公称でなければ a_j = P / P_j（w_j P_j / (w_j P_j) は浮動小数点で厳密に 1）。自分の数密度の項は (Nᵢ − N̄ᵢ⁰ − Σ_j a_j ΔN̄ᵢ^j) ∂σᵢ/∂N̄ᵢ を 1 度だけ
  足す（1 つの変数なら ADR-0215 と同じ式）。Σ_k w_k P_k が 0（見込みの指標が打ち消し合う）なら分けられないのでエラー
- 案 D（|w_j P_j| の割合で分ける）: Σ_k |w_k P_k| は 0 にならないが、見込みの指標が逆の符号の 2 つの変数では、ノードの組成が見込みどおりでも
  a_j が w_j にならず、L の見込み Σ_j w_j L_j を再現しない

## 決定と理由

案 C。core はノードの定数と反応率の微視的断面積に、

f = f_table + Σᵢ cᵢ (Nᵢ − N̄ᵢ⁰) + Σ_j [w_j U_j + a_j L_j]

σᵢ^rate = σᵢ + Σ_j [w_j Δσᵢ_U,j + a_j Δσᵢ_L,j] + (∂σᵢ/∂N̄ᵢ)(Nᵢ − N̄ᵢ⁰ − Σ_j a_j ΔN̄ᵢ^j)

a_j = (P / P_j) × (w_j P_j / Σ_k w_k P_k)

を足す。j と k は、w が 0 でなく、履歴の分岐の数密度の差 ΔN̄ᵢ^j がすべて 0 でない変数（ADR-0215 のとおり、ほかの変数は L、Δσ_L を足さず、
P_j を持たない）。自分の数密度の項は、そのような変数が 1 つ以上あるときだけ足す（ADR-0215 と同じく、公称の履歴の反応率は補正のない
テーブルとビットで同じ）。P_j が 0（ΔN̄ᵢ^j が 0 でないとき）、Σ_k w_k P_k が 0、a_j が有限でなければエラー。

- ADR-0215 は L を組成の差の大きさの指標の比で足すとした。変数が複数でも、ノードの組成の差の大きさは 1 つ（P）で、それを変数ごとの見込みの
  指標 w_j P_j の割合で配れば、案 A のように同じ組成の差を変数の数だけ数えない
- 1 つの変数だけが公称でないノード（今の減速材の密度の確認、制御棒の確認）は ADR-0215 の値をビットで保つ
- 追加の格子計算はない（案 B と違う）

### 帰結

- core は変数ごとの P / P_j と w_j P_j から a_j を作り（crates/core/src/case.rs の `linearization_weights`）、定数の L と反応率の Δσ_L に掛ける。
  自分の数密度の項は変数のループの外で 1 度足す（crates/core/src/state.rs の `accumulate_own_density_rates`）
- 見込みの指標が打ち消し合う（Σ_k w_k P_k が 0 に近い）ノードでは a_j が大きくなる。上限は置かない（ADR-0215 の P / P_j の上限と同じく #0190 の
  「残ったレビューの指摘」と #0226）
- 交差の項（案 B）は持たない。大きさを測るなら、2 つの変数を同時に変えた履歴の分岐が要る（#0190）

### 確認

- 2A の値での案 A との違い（examples/depletion/verification.md の「制御棒を途中まで入れて抜く燃焼（2A）」の表 `depletion-history-rods-split`。
  テーブルは減速材の密度と制御棒の残りを持つ 2854d05b、比較は 55de1bae の examples/depletion/history/compare_rods_switch.py、2026-11-04）: 2 つの
  変数の R の点ごとに、組成の差が見込み 0.5 ΔN̄ᵢ^m + 0.5 ΔN̄ᵢ^r のノード（案 C の a_j は 0.5）で、案 A は P / P_m = 2.92〜3.09、P / P_r = 0.596〜0.603 を
  掛け、案 C との k の差は −9.784〜−494.144 pcm（60 MWd/kg で −494.144 pcm）。制御棒の履歴の組成の差が減速材の密度の履歴より大きく、案 A は
  減速材の密度の L に見込みの約 6 倍の重みを掛ける
- 制御棒を途中まで入れて抜く燃焼（同じ節。1 つの変数だけが公称でないので、a_j は P / P_j）は ADR-0215 の確認（H_r）で、この決定の分け方を
  使わない
- テスト: crates/core/src/case/tests.rs の `linearizations_of_two_variables_share_the_production_index_by_their_expected_parts`（a_j の L と、1 つの変数
  だけが公称でないときの P / P_j）、`rate_linearizations_of_two_variables_share_the_index_and_add_the_own_density_once`（Δσ_L と自分の数密度の項）、
  `expected_indices_that_cancel_over_the_variables_are_errors`
