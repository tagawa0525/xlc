# ADR-0185: UFG の格子を、リングの物質の巨視的な断面積を許容差で再現できる点に間引き、核種の群定数は核種自身の格子で縮約する

## 背景

燃焼した燃料では、UFG の減速計算（[ADR-0068](0068-solve-pinwise-slowing-down.md)）の格子が、輸送する 89 核種と被覆管・減速材の
核種のポイントワイズの断面積の格子の和になり、代表ピン 1 本で 1,266,012 点（新しい燃料の 3.67 倍）になる。集合体 2A の燃焼では
1 回の輸送が約 72 秒で、そのうち自己遮蔽が 61〜76 秒、その 94% が代表ピン 39 本の UFG の減速計算だった（#0045 と #0137 の
「測定（2026-10-22）」）。40 点の燃焼（輸送 81 回）が 1 時間 41 分かかり、燃焼の本番（2A、2F、2N、2O、2P、2M）の前に速くする
（ユーザーの要求、2026-10-22。目標は 2A の 1 本を 10 分程度）。

判断の軸:

- 精度: ADR-0032 の ±100 pcm のうち、この近似に使う分は小さく（目安で ±10〜20 pcm、群定数の相対差 1e-4 程度、主要な核種の
  数密度 0.1% 以内）。核種ごとの共鳴の範囲の捕獲の相対差は 0.1% 以下（#0133 で、燃えた組成の薄い共鳴吸収核種に OpenMC と
  1〜2% の捕獲の差が見つかっており、それを広げない）
- 速さ: 自己遮蔽の 1 回を数秒にする
- 間引かない格子（今の経路）を、検証用に入力で選べること

## 検討した案

時間と差は、examples/depletion/issue-0045 の試行で、全核種をポイントワイズで解く今の経路と比べた: VERA 2A の燃焼の 1 ステップ
（2A-step。0.1 MWd/kg、輸送 3 回）、2A の 60 MWd/kg の組成の 1 状態（2A-60。組成は examples/depletion/p2/lattice-2A.msgpack）、
1C のピンセルの燃焼（1C-rings1、1C-rings4。5 MWd/kg まで）。時間は排他の Slurm のジョブ（16 スレッド）の値。ブランチ feat/0045-ufg-background-nuclides のコミットの分岐点は main の
682dead38（案 L は rebase の前の 2d58b2d1f（分岐点 6d391910e）で計算し、lattice のコードの同じ rebase の後のコミットで書く）。

### 案 L: ポイントワイズで解く核種を絞る

入力で挙げた核種だけをポイントワイズで解き、ほかの核種はリングごとに 1 つの項（群の中で一定の巨視的な断面積の和。散乱の α は
減速能 Σ ξ N σs を保つ値）にまとめて減速計算に入れる。その核種の群定数は、等価原理（中心のリング）と無限希釈（ほかのリング）の値の
ままにする（`given`）。[ADR-0169](0169-build-chain-library-in-nuclide-stages.md) の案 P3（UFG を多群の扱いに置き換えたときの k の差で
核種を決める）の実装にあたる。

2A の 1 ステップの自己遮蔽は、1 回あたり 64.4 秒が、U-238、O-16、H-1 だけで 7.0 秒、Zr の 5 同位体を足して 8.8 秒、さらに
U-235、U-236、Pu-239〜242 を足して 13.0 秒になったが、k の差は −304、−148、+21 pcm だった。1C（5 MWd/kg まで）では −405、
−192、+26 pcm、2A-60 では −115、+45、+20 pcm（ブランチ feat/0045-ufg-background-nuclides のコミット 6139c794e、Slurm 435、
2026-10-22）。

核種ごとの寄与は、その核種だけをポイントワイズから外す計算（1C の 4 リングの 5 MWd/kg の組成のピンと、2A の 60 MWd/kg の組成の
ピン 1 本。1 スレッド、Slurm 439 の排他でない実行）で測った。外した核種の群定数の与え方を 2 つ比べた:

- `given`（上の方式。コミット 6139c794e）
- `collapse`: 核種のポイントワイズの断面積を、その核種をバックグラウンドにして解いたリングの中性子束で縮約する（ほかの核種の共鳴の影は入り、
  自身の自己遮蔽は入らない。コミット 55af65e95）

| 外した核種ごとの k の差の絶対値の和（pcm） | given | collapse |
| ------------------------------------------ | ----- | -------- |
| 1C の 4 リング、5 MWd/kg（64 核種）        | 527   | 347      |
| 2A のピン、60 MWd/kg（76 核種）            | 1,044 | 973      |

1 核種で大きいもの（60 MWd/kg）: Zr-91 はどちらも −139〜−143 pcm（被覆管の Zr は自己遮蔽が大きい）。U-236 は given −35、
collapse −267、Sm-152 は +138、−53、Tc-99 は −111、−92、Cs-133 は −6、−116、Sm-150 は −101、−23。5 MWd/kg の U-235 は −200、+89。
どちらの与え方でも 1 pcm を超える核種が 14〜76 あり、残す核種を増やすと点と時間が戻る（1 pcm を超える核種の点だけで約 72 万点）。
`collapse` の値に等価原理と無限希釈の値の比を掛けた与え方も試したが（コミットしていない）、60 MWd/kg で差の和が 447 pcm と、
同じ結論だった。

外した核種の捕獲の向き（#0133 との関係）: `collapse`（核種自身の自己遮蔽を除き、無限希釈の断面積をセルの中性子束で重みづけした
もの）では、自己遮蔽のある核種はどれも捕獲が増えて k が下がる（60 MWd/kg で U-236 −267、Cs-133 −116、Tc-99 −92、Sm-152 −53、
Pu-240 −49、Mo-95 −48 pcm）。等価原理の σ0 の表（`given`）では向きが核種で違い、Sm-152 +138、Nd-145 +38、Ag-109 +30、Pu-242 +6
pcm（捕獲が減る）、Tc-99 −111、Sm-150 −101、U-236 −35、Am-243 −9 pcm（捕獲が増える）。

採らない（差の和を 10 pcm 以内にできる核種の集合が、速さを保つほど小さくならない）。

### 案 T: 格子を巨視的な断面積の許容差で間引き、核種は自身の格子で縮約する（採用）

核種の格子の和（群の境界と不連続点を含む）から、リングの物質ごとの巨視的な全断面積と弾性散乱断面積が、残した点の間のレサジーに
ついての線形な補間でどの点でも相対差 ε 以内に再現できる点だけを残す（傾きの許される範囲を点ごとに狭める swinging door。群の
境界と不連続点は残す）。その後に、今と同じく散乱の窓に 16 点が入るよう点を足し、減速計算（衝突確率、散乱の窓）はこの格子で解く。
薄い核種の共鳴は、物質の断面積に効かなければ格子から落ちるので、核種の群定数は、核種自身のポイントワイズの断面積の点と減速計算の
格子点の和の上で、中性子束を格子点の間で線形に内挿して、今と同じ台形則で縮約する（間引かない格子では、減速計算の中の積分と同じ
値）。#0046 の「断面積の表現から決める」案に、核種ごとの縮約を足したもの。

全核種の経路との差（全核種の経路はコミット 047d9379c、Slurm 441。間引いた格子はコミット 91e05bfa6、Slurm 451。2026-10-22）:

| 例                      | ε    | k の差 (pcm) | 2 群の吸収の相対差 | 主要核種の数密度の相対差 |
| ----------------------- | ---- | ------------ | ------------------ | ------------------------ |
| 2A-step                 | 1e-3 | −4.7         | （少数群定数なし） | 1.9e-4（Pu-239）         |
| 2A-step                 | 1e-4 | +0.8         | （少数群定数なし） | 3.2e-5（Pu-239）         |
| 1C-rings1（〜5 MWd/kg） | 1e-3 | −6.1〜−5.5   | 1.1e-4〜1.2e-4     | 2.2e-4（Pu-239）         |
| 1C-rings1（〜5 MWd/kg） | 1e-4 | +1.0〜+1.1   | 2.2e-5             | 3.9e-5（Pu-239）         |
| 1C-rings4（〜5 MWd/kg） | 1e-3 | −6.1〜−5.5   | 1.1e-4〜1.2e-4     | 2.4e-4（Pu-239）         |
| 1C-rings4（〜5 MWd/kg） | 1e-4 | +1.0〜+1.1   | 2.2e-5             | 7.1e-5（Pu-239）         |
| 2A-60                   | 1e-3 | −4.6         | 8.5e-5             | （1 状態）               |
| 2A-60                   | 1e-4 | +0.9         | 1.6e-5             | （1 状態）               |

核種ごとの共鳴の範囲（4 eV〜20 keV）の捕獲（群の 1/E の重みの和）の相対差のピンの中の最大は、2A-60 で ε = 1e-4 のとき Zr-96 の
1.2e-4、燃料の核種では U-236 の 6.2e-5 以下（Pu-242 5.3e-5、U-238 4.6e-5）、ε = 1e-3 のとき U-238 の 2.6e-4 以下で、どちらも 0.1% を
下回る（examples/depletion/issue-0045/compare.py の `pin_xs` の出力の比較。コミット 047d9379c、Slurm 442。間引きの起点を
低い側の極限にした 91e05bfa6 の前の値で、k の差はどの例も同じだった）。

点（2A-60 の代表ピン 1 本）は 1,256,122 点が、ε = 1e-3 で 41,452 点、1e-4 で 94,337 点。自己遮蔽の 1 回は、2A-step で 68.7 秒が
1e-3 で 14.5 秒、1e-4 で 17.2 秒、2A-60 で 62.4 秒が 15.5 秒、17.9 秒（Slurm 451）。

ε = 1e-4 の 2A-60 の自己遮蔽 18.2 秒（`RUST_LOG` で区間の時間を出した実行。Slurm 451）の内訳: ピンの UFG（39 本のスレッド時間の和
173.5 秒、16 スレッドで約 11 秒）のうち、核種の格子の和を作って全核種を和の点で評価する前処理が 83.5 秒、飛程の表 29.0 秒、減速計算
29.0 秒、衝突確率 8.6 秒、断面積の評価 7.1 秒、縮約 約 16 秒。ピンの外は Dancoff 係数 2.7 秒、塊 2.7 秒、複製 0.5 秒。前処理は 1 スレッドでは
ピン 1 本 0.56 秒が 16 スレッドでは 2.1 秒で、メモリの帯域で決まっているのが候補（確かめていない）。

### 案 P: ピンの並列の粒度

39 本を 16 スレッドに配る粒度（ピン 1 本の中の減速計算は逐次）。案 T のあとは、ピンの計算より、組成によらない前処理（1 回の輸送
あたり Dancoff 係数 2.0〜2.7 秒、塊 2.0〜2.9 秒、移り合うピンへの複製 0.3〜0.7 秒）のほうが大きい。この ADR では決めない（#0137）。

### 案 F: 自己遮蔽を解き直す頻度（#0134）

CE/CM の中点で自己遮蔽を解き直さなければ、回数はほぼ半分になる。差は中点までの組成の変化で決まり、測っていない。ADR-0173 の決定を
変えるので、この ADR では決めない。

## 決定と理由

案 T を採る。格子の間引きの許容差は入力 `ufg-tolerance` で選び、省略すると間引かない（今の経路。検証用の高精度版）。燃焼の
入力に書く値は ε = 1e-4 とする。

- 許容差 1 つで、核種の数にも核種の選び方にもよらずに差を抑えられる。1e-4 で k の差は 1 pcm 前後、2 群の吸収の差は 2.2e-5 以下、
  核種ごとの共鳴の範囲の捕獲の差は 1.2e-4 以下で、判断の軸の精度に収まる。案 L は、どの与え方でも核種ごとに 1〜270 pcm の差があり、
  差の和を抑えるには残す核種が多くなりすぎた
- 薄い核種の共鳴は、その核種の群定数には核種自身の格子の縮約で残るので、#0133 の捕獲の差を広げない（落ちるのは、物質の断面積に
  ε より効かない共鳴が中性子束をへこませる分だけ）
- 1e-3 は自己遮蔽の 1 回が 1e-4 より 13〜16% 速いだけで（2A-step と 2A-60）、2A の燃焼の 1 本では差がなかった（「確認」）。一方で k の差は −5 pcm、
  捕獲の差は 2.6e-4 と、1e-4 の数倍になる
- 入力の省略を間引かない経路にするのは、既存の例（examples/vera）のステージと記録を再実行しないため（ADR-0169 の判断の軸と同じ）。
  燃焼の入力（examples/depletion）に 1e-4 を書くのは、燃焼の本番の前にそれぞれの入力で行う

## 帰結

- 燃焼した燃料の代表ピンの格子の点は 1/13（1e-4）になり、ピンの計算は、核種の格子の和を作って全核種を和の点で評価する前処理と、
  ピンの外の前処理（Dancoff 係数、塊）が主になる。残りの時間の内訳は「確認」の 2A の燃焼に書く
- 間引きの基準の量は、リングの物質の巨視的な全断面積と弾性散乱断面積だけで、核分裂と捕獲は入れない（全断面積と散乱が中性子束を
  決め、核種ごとの反応率は核種の格子で縮約する）
- 格子そのものの収束（#0002）は確かめていない。差は今の格子（全核種の和に窓の点を足したもの）に対するもの
- 案 L のために足した入力（`pointwise`）とバックグラウンドの項は、案 T で要らなくなったので消した（コミット be555a776）。測った値は上のコミットで
  再現できる
- ADR-0169 の「ポイントワイズを持たせる核種を k の差で決め、xs にポイントワイズを持たせない核種の指定を足す」は、この ADR で格子を
  間引く方式に置き換える（ライブラリの核種は、今までどおりすべてポイントワイズを持つ）。ADR-0169 のほかの部分は変わらない
- #0137（組成によらない前処理の再利用）は、ピンの時間が減ったので、1 回の輸送の約 3 割（5 秒前後）になる。#0134 は回数を半分にする
