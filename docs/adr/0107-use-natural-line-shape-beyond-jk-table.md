# ADR-0107: 非分離共鳴の J, K は、θ = Γ/Δ が 10⁶ を超えると Lorentz の線形状の解析式で求める

## 背景

非分離共鳴の自己遮蔽（NJOY UNRESR 相当）の J, K 積分は、(log10 β, log10 θ) の表から補間している。表の θ の範囲
（10⁻³〜10⁴）は燃料の核種で決めたが、構造材の Fe-58 は 550 K で θ ≈ 1.0e4 になり、表の外でエラーになった（#0035）。
NJOY UNRESR は J, K をどの θ でも直接に積分する。

## 検討した案

- θ が表より大きいときも直接に積分する（NJOY と同じ）: 幅のゆらぎの積分の節点ごとに積分するので遅い
- θ > 10⁴ で Lorentz の線形状 ψ = 1/(1 + x²) の解析式を使う: Voigt の線形状との差は 1/θ² の程度で、表の端で約 1e-8
  跳ぶ。幅のゆらぎの適応積分（許容誤差 1e-10）が端の近くで収束しにくい
- 表を θ = 10⁶ まで延ばし、その上で解析式を使う（採用）: 表の端の跳びは 1e-12 程度で、許容誤差より小さい。表は
  最初に一度だけ作り、行が 28% 増える

## 決定と理由

J, K の表の θ の上限を 10⁶ にし、それより大きい θ では Lorentz の線形状の J, K を使う。a² = (1 + β)/β として
J = π/(2aβ)、K = 2J − ∫ψ²/(ψ + β)² dx = 2J − π/(4a³β²)。解析式は β > 0 ならどこでも成り立つので、β が表より小さくても
使う。

## 確認

表の端（θ = 10⁶）の内と外、θ = 1.0025e4 と 1e8、β = 1e-6〜1e10 で、表の補間または解析式と直接の積分の相対差が 1e-10
より小さい（crates/xs/src/resonance/line_shape.rs の `table_uses_natural_line_shape_above_its_theta_range`）。
Fe-58 の 550 K でライブラリを作れる。

## 帰結

- 低温（550 K）の構造材を含むライブラリを作れる
- J, K の表を作る時間が増える（行が 28% 増える）
