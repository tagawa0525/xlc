# ADR-0245: 本番のテーブルの燃料は、MOC の 5 リングをそのまま 5 つの燃焼の領域にし、方位には分けない

## 背景

[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md) は、燃焼の領域を、入力の `[depletion]` に挙げた燃料の物質と、自己遮蔽の対称操作で移り合うセルの組の対ごとに
1 つにした（案 R1）。径方向はリングごとに別の名前の物質を書けば分けられ、領域の数は入力で決まる。[ADR-0244](0244-deplete-fuel-by-sector.md) は、
`[depletion]` の `sectors`（4 か 8）で方位の扇形の組ごとにも分ける入力を足した（書かなければ分けない）。どちらも分ける口を
決めただけで、本番のテーブルでどう分けるかは決めていない。

本番に向けた 2A のテーブルの履歴（examples/depletion/p9-product/lattice-2A.toml）は、燃料を MOC の 5 リング（等体積）に切るが
物質は 1 つで、ペレットは 1 つの組成で燃える。外側から先に燃える分布（周辺の Pu の蓄積）と、案内管や水ギャップの側から先に
燃える方位の偏りを、組成として持たない。分けるとテーブルの作り直しになるので、作り直す前に分け方を決める（#0275、#0276）。

前提:

- MOC の燃料のリングは、ゾーンの中を等体積に分ける（crates/lattice/src/input.rs の `rings` の半径）。5 リングを 1 本ずつの 5 つの
  ゾーン（半径 R√(k/5)）に書き直すと、MOC の領域は同じになる
- 方位に分けたときの自己遮蔽は、扇形の組成の違いをリングの扇形の平均の組成で解く近似（ADR-0244 の案 B1）で、その誤差を測る
  正しい経路（2 次元の UFG の減速計算）は無い
- 燃焼点からの分岐（`[history]`。ADR-0187）は、扇形に分けた履歴をエラーで止める（ADR-0244）。リングごとの物質の履歴は読める

判断の軸:

- 正確さ > 実行速度 > 保守の容易さ（CLAUDE.md の「方針」）。分けない誤差を、分岐のテーブルで落とす項ごとの目安 |Δρ| ≤ 5 pcm
  （[ADR-0200](0200-tabulate-burnup-branches-by-cut-hdmr.md)）と、格子計算の精度の目標の k ±100 pcm、ピン出力 rms 0.2%（[ADR-0032](0032-target-lattice-accuracy.md)）に照らす
- MOC の離散化（2A の入力の燃料 5 リング、飛程の表）を変えずに選べる分け方の中で決める。離散化を変えると、燃焼の分け方の差に
  離散化の差が混ざる

## 検討した案

値は 60 MWd/kg までの 40 点（輸送 81 回）の、分けた k∞ − 分けない k∞（Δk）と Δρ = 1/k_分けない − 1/k_分けた（pcm）の、
すべての燃焼点からの最大か最小。0 の点は分け方によらず同じ。出典は examples/depletion/verification.md の「ペレットを径方向に
分けた燃焼（#0275）」（2A の燃料のピンのピンセル。xlc は 1f9883c0、分岐点は main の b0f445a2、2026-11-11、Slurm 731〜735）と
「燃料のピンを方位の扇形の組にも分けた燃焼（#0276）」（2A の燃料のピンを並べた 3 × 3 の格子で、中央が案内管の `guide` と、周りに
0.04 cm の水の余白を付けた `gap`。xlc は 28283d5a、分岐点は main の 3948bff8、2026-11-11、Slurm 737〜744）。時間は、最初の 2 点
（輸送 5 回）の輸送ごとの時間の和とその比で、ピンセルは Slurm 730（#0275 の記録の「計算」）、3 × 3 の格子は Slurm 736
（docs/issues/0276 の「測る入力と時間」）。どちらもパーティション timed の排他のジョブ、2026-11-11。

- 案 Z1: 今のまま、ピンの組ごとに 1 つの領域。分けた 5 領域との差は、ピンセルで Δk の最大 +35.92 pcm、Δρ の最大 +43.73 pcm
  （40 MWd/kg）、`guide` で Δk の最大 +36.24 pcm、Δρ の最大 +44.84 pcm、`gap` で Δk の最大 +15.67 pcm、60 MWd/kg で −21.90 pcm
  （Δρ −32.05 pcm）。ADR-0200 の目安の 6〜9 倍で、ADR-0032 の k の目標の約 4 割にあたる。時間は最も短い
- 案 Z5: MOC の 5 リングを 1 本ずつ別の物質にし、5 つの燃焼の領域にする（採用）。離散化は Z1 と同じで、時間はピンセルで 1 領域の
  1.116 倍（15.35 秒と 17.14 秒）、3 × 3 の格子で 1.17 倍（`guide`、19.40 秒と 22.73 秒）と 1.22 倍（`gap`、22.48 秒と 27.44 秒）、
  2A の集合体（p9-product/lattice-2A.toml の燃焼度を最初の 0.1 MWd/kg の 1 点、輸送 3 回にしたもの）で 1.29 倍（106.40 秒と
  137.33 秒。自己遮蔽が 89.34 秒から 119.45 秒の 1.34 倍。Slurm 746 と 745、パーティション timed の排他のジョブ、32 スレッド、
  2026-11-11、bin/lattice は main の 3a52e2c9 のもの。入力とログは examples/depletion/p9-product/short-check/ の
  `lattice-2A-short-1` と `lattice-2A-short`。時間はログの最後の行の `shielding`、`moc`、`rates`、`matrix`、`cram` の和）。0 の点の k∞ は
  同じ値（1.25192422551263）で、0.1 MWd/kg の差は −0.07 pcm
- 案 Z8: 領域の数をさらに増やす（例えば 8）。ピンセルで 8 領域（8 リング、飛程は格子点ごと）− 1 領域は Δk の最大 +43.42 pcm
  （40 MWd/kg）、Δρ の最大 +53.51 pcm（44 MWd/kg）で、8 領域 − 4 領域（同じ 8 リング）は Δk の最大 +16.34 pcm（52 MWd/kg）、
  Δρ の最大 +22.92 pcm（60 MWd/kg）と、領域の数について収束していない。ただし 8 領域には MOC を 8 リングにし、飛程の求め方も
  変える離散化の変更が伴い、ピンセルの 8 リングと格子点ごとの飛程 − 本番の離散化（どちらも 1 領域）は 0 の点で +19.26 pcm、
  60 MWd/kg で −20.46 pcm と、離散化そのものの差が分け方の差と同じ大きさにある。本番の離散化の 5 領域と同じ条件で比べた値は無く、
  5 領域にどれだけ残るかは測っていない。時間は 8 リングでピンセルの 1 領域 22.67 秒、8 領域 22.77 秒（本番の離散化の 1 領域の
  1.48 倍）
- 案 S: 5 領域をさらに方位の扇形の組に分ける（ADR-0244 の `sectors = 4` か `8`）。`rings5` との差は、`guide` で Δk の最小 −0.58 pcm
  （4 つ）と −0.76 pcm（8 つ）、Δρ の絶対値の最大 0.67 pcm と 0.89 pcm、`gap` で Δk の最小 −0.08 pcm と −0.11 pcm、ピン出力の差の
  最大 0.002% 以下。ADR-0200 の目安の約 1/6 で、径方向の効きの 1/50〜1/200。時間は `rings5` の 1.05〜1.07 倍。分けると、
  分岐（`[history]`）に扇形ごとの物質を作り直す経路が要る（ADR-0244）。値は ADR-0244 の案 B1 の下のもので、扇形の組成の差
  （最も外のリングの U-235 の (最大 − 最小) / 平均が最大 10.942%、`guide` の 8 つ）が自己遮蔽を変える分は入っていない

## 決定と理由

- 本番のテーブル（examples/depletion/p9-product/ と、これから作る種類ごとの格子の入力）の燃料は、案 Z5 で燃焼させる: MOC の
  燃料の 5 リングを 1 本ずつのゾーン（等体積の半径 R√(k/5)、`rings = 1`）にし、ゾーンごとに別の名前の物質（`fuel-0`〜`fuel-4`。
  内から外の順）を書いて、`[depletion]` の `materials` にすべて挙げる。燃焼の領域はピンの組 × 5 になる。分岐（`branch-*.toml`）は
  同じ形状と物質を書き、燃料の温度の軸の `materials` に 5 つすべてを挙げる
- 方位には分けない（案 S を採らない。`[depletion]` の `sectors` を書かない）
- 親が #0275 と #0276 の測定からこの 2 つを推し、ユーザーがそのとおりに決めた（ユーザー 2026-11-11）
- 理由: 分けない誤差（Z1）は ADR-0200 の目安の 6〜9 倍で、時間の増え（ピンセルで 1.116 倍、3 × 3 の格子で 1.17〜1.22 倍、2A の集合体の最初の 1 点で 1.29 倍）で
  取り除ける。Z5 は MOC の離散化を変えないので、テーブルの差は燃焼の分け方だけによる。Z8 は領域の数の効きが残ることを示すが、
  離散化の変更と分けて測っていないので、今は採る根拠が無い（領域の数を増やすかは #0277）。方位（S）は、測った差が
  ADR-0200 の目安より小さく、ピン出力の差も ADR-0032 の目標の 1% に満たないので、分ける得が測れる大きさに無く、分岐の経路を
  足す費用に見合わない
- ADR-0173 と ADR-0244 との関係: どちらも置き換えない。ADR-0173 の案 R1（物質の名前で径方向に分ける口）と ADR-0244 の
  `sectors`（方位に分ける口）のうち、本番の入力でどれを使うかを決める、両者を補う決定。ADR-0244 が分岐の状態で扇形ごとの
  物質を作り直す経路を本番のテーブルで分けると決めてから足すとしたのは、分けないと決めたので足さない

### 帰結

- 本番のテーブルの作り直しが要る（2A は examples/depletion/p9-product/ の履歴、分岐のテーブル、比べた要約）。0 の点の値は
  分け方によらず同じ
- p2 の 2A の OpenMC の参照解（燃料をピンごとに 1 つの帯で燃焼させる）とは模型が変わる。p9-product の比較（compare-2A、grid-2A）は
  同じテーブルの中の比較で、OpenMC と比べない
- 輸送ごとの自己遮蔽は ADR-0173 の案 S1 のまま（UFG の範囲の減速計算はリングごとの組成、範囲の外の等価原理はリングの体積平均の組成）
- 確かめていないこと（#0277）: 本番の離散化の 5 領域に残る領域の数の効き（Z8 の値は離散化の違う比較）、集合体の 60 MWd/kg までの径方向の効き
  （3 × 3 の格子は案内管の割合が 1/9 で、集合体の 25/289 より高い）、方位に分けない誤差のうち ADR-0244 の案 B1 で
  落とした分。Gd 入りの燃料（p2 の 2O、2P の Gd 燃料はリングごとに 8 つの物質）と Pyrex のある種類の格子に同じ分け方を当てるかは
  測っておらず、決めない（種類ごとの格子の入力を作るときに #0277 で決める）

### 確認

- 入力: examples/depletion/p9-product/lattice-2A.toml と branch-2A.toml が燃料を `fuel-0`〜`fuel-4` の 5 つの物質で書き、
  lattice-2A.toml の燃焼の領域が 39 のピンの組 × 5 = 195 になる（上の Z5 の時間の短い実行の Slurm 745 のログ `short-check/lattice-2A-short.log` の `regions=195`。
  MOC の領域は 1 物質のときと同じ 28928）
- テーブルの値: 作り直した 2A のテーブル（Slurm 747、xlc 8d6c3ffc、2026-11-11）を examples/depletion/verification.md の「Problem 9 の格子点の直積（2A）」に書いた
