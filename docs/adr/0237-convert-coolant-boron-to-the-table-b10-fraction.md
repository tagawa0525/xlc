# ADR-0237: 冷却材の B-10 の割合がテーブルと違う状態は、B-10 の個数密度が同じになるテーブルの割合の ppm に換算して内挿する

## 背景

分岐のテーブルは B-10 の割合（ホウ素の中の B-10 の原子分率）をテーブルごとに 1 つ持ち、core はケースの状態の `b10` がテーブルと違えば
エラーにする（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md) の「決定と理由」）。冷却材の B-10 は (n,α) で減り、補給するホウ酸で一部は
戻るので、サイクルの途中の B-10 の割合は天然の値と違う（#0036）。Problem 9 は BOC の B-10 の割合を仕様書の値で置く（docs/plans/m4-depletion.md の
「冷却材の B-10 の割合の燃焼（#0036）」の項）。濃縮ホウ酸（B-10 を天然より多くしたもの）を使う炉もあるので、天然より大きい割合も扱う（#0036 の起こした時点の
「懸念」の節。経緯は git）。

ここでは、状態の `b10` がテーブルの値と違うときに core が少数群定数をどう求めるかを決める。B-10 の割合を誰が与えるか（入力で与えるか、
core が燃焼で追うか）は別に決める（#0036 の「問題」の未解決の点）。この ADR の入力は、今の状態の `b10`（[ADR-0146](0146-solve-named-states-of-a-case-in-parallel.md)）をそのまま使う。

判断の軸:

- テーブルの B-10 の割合と違う状態で、直接の格子計算の k を再現すること
- 格子計算の回数（テーブルの状態の数）

## 検討した案

- 案 1（ppm の換算。採用）: ケースの (ppm, b10) を、テーブルの b10 で B-10 の個数密度が同じになる ppm' = ppm · (b10 / M(b10)) · (M(b10ₜ) / b10ₜ)
  に直し、今のホウ素の軸で内挿する（M はホウ素の平均の原子質量。[ADR-0106](0106-compose-borated-water-from-density-and-ppm.md)。式は #0036 の起こした時点の「方針の案」の 1。経緯は git）。
  格子計算を増やさず、ホウ素の軸の内挿が B-10 の個数密度によるスペクトルの変化も含める。B-11 の個数密度のずれと、換算した ppm による水（H-1 と O-16）の個数密度の
  ずれは入らない。B-10 の割合が
  上がると ppm' が上がるので、テーブルのホウ素の軸の範囲を換算後の値で決める（19.9 at% のテーブルで 30 at% の 1300 ppm を引くには、約 1978 ppm
  まで要る）
- 案 2（B-10 の割合を分岐の軸にする）: テーブルに B-10 の割合の軸を足し、ほかの軸と同じく多重線形で内挿する。格子点では直接の格子計算を
  そのまま再現するが、分岐の状態が B-10 の割合の点の数だけ増える（3 点なら 3 倍）。ホウ素の効果は B-10 の個数密度でほぼ決まるので、
  状態の数に見合わない（#0036 の「検討して捨てた形」）
- 案 3（B-10 の微視的断面積の補正）: テーブルに状態ごとの冷却材の B-10 の均質化した個数密度と少数群の微視的断面積を持たせ、core が個数密度の
  差に掛けて少数群定数に足す（[ADR-0236](0236-correct-coolant-boron-10-by-micro-cross-sections.md)。core が B-10 の個数密度を追う形にそのまま使える）。
  実装して、2A の燃焼度 0、20、40 MWd/kg、600 と 1300 ppm で直接の格子計算と比べると、差は 18 at% で −17.641〜+34.929 pcm（B-10 の割合を
  変えた効きの最大 2.51%）、30 at% で −266.950〜+86.568 pcm（最大 3.64%）で、同じ点の案 1 の 18 at% の +4.389〜+13.705 pcm（最大 0.99%）、
  30 at% の −7.532〜+17.490 pcm（最大 0.55%）より大きかった（ADR-0236 の「帰結」。格子計算は 7a62424c（Slurm 713）、core と比較は 80d83c07、分岐点はどちらも main の dd5941ee、
  2026-11-07）。B-10 の個数密度によるほかの核種のスペクトルの変化を持たないことが候補で、確かめていない

ユーザーは案 3 を一度採った（ADR-0236）が、測った差と、案 1 は案 2 と結果がほぼ同じで費用が小さいという親の説明を受けて、案 1 に替えた（2026-11-07 06:02）。

先行事例:

- MPACT（VERA-CS）: 炉心を直接 MOC で解き、冷却材の B-10 の割合を燃焼のステップごとに、炉心の B-10 の吸収率と一次系の体積との比から
  求め直す。割合は入力の状態（`[STATE]`）でも与えられる（B. Kochunas et al., "Operational Reactor Depletion Analysis Capability,"
  CASL-U-2014-0189-000 (2014)、2.4.4 節の式 (2.9)、(2.10)、https://www.osti.gov/servlets/purl/3013447 ）。分岐のテーブルを使わない
  （ADR-0097 の「検討した案」）ので、どの案にも当たらない。同じ報告は、Watts Bar 1 号機のサイクル 1 で、B-10 の燃焼を入れないと
  臨界ホウ素濃度を最大で約 60 ppm 低く見積もると書く（3.6 節）
- RAST-K v2.2: 機能に冷却材と制御棒の B-10 の燃焼を挙げ、B-10 が減った条件の臨界ホウ素濃度を求め直す（"the adjusted critical
  boron concentration can be calculated for considering B-10 depleted condition"。J. Park et al., "Development Status of Nodal Diffusion
  Code RAST-K v2.2," Trans. KNS Spring Meeting (2019)、2.1 節、https://www.kns.org/files/pre_paper/41/19S-731-박진수.pdf ）。求め直しの式は
  書いていない。案 1 の形と読めるが、確かめていない
- CASMO-4/SIMULATE-3: Taiwan Power Company の検証の論文が B-10 の燃焼の計算のモデルを入れたと書く（H.-C. Lin et al., Nucl. Eng. Des. 253,
  71 (2012)、要旨の highlights）。モデルの中身は、本文を読めず確かめていない
- PARCS（GenPMAXS の断面積）: ホウ素濃度は分岐の変数（ADR-0097 の「検討した案」の偏微分の木）。B-10 の割合の扱いは、理論マニュアル
  （ADR-0097 の出典）を開けず、確かめていない

## 決定と理由

案 1 にする。測った差が案 3 より小さく、格子計算もテーブルの形式も変えない。

状態の `b10` がテーブルのホウ素の軸の `b10` と違えば、core はホウ素の軸の内挿に、状態のホウ素濃度の代わりに

ppm' = ppm · ρ、ρ = (b10_c / M(b10_c)) / (b10_t / M(b10_t))、M(b) = b M_B10 + (1 − b) M_B11

を使う（b10_c は状態、b10_t はテーブルの値、M_B10 と M_B11 は ADR-0106 の AME2020 の原子質量）。ppm と密度が同じホウ酸水の B-10 の個数密度は
b10 / M(b10) に比例するので、ρ は B-10 の個数密度の比で、ppm' はテーブルの b10 で同じ B-10 の個数密度になる ppm である。

- 換算はホウ素の軸の内挿の重みだけを変えるので、少数群定数、追う核種の微視的断面積（ADR-0216）、履歴の補正（ADR-0215）、部分ノードと
  反射体のテーブルのどれにも同じ ppm' が当たる。臨界ホウ素の探索（ADR-0145）は、状態の b10 の ppm を探し、内挿のたびに換算する
- ppm' がテーブルのホウ素の点の範囲の外なら、今の範囲の外と同じくエラーにする（外挿しない）。エラーには換算した値と元の値を書く
- `b10` がテーブルと同じなら換算せず、内挿はビットで同じ。割合が 0..1 の外か、テーブルの `b10` が 0（ρ が決まらない）で状態と違えばエラーにする
- B-11 の個数密度の差は入らない。B-11 の吸収は B-10 より 6 桁ほど小さい見込み（#0036 の起こした時点の「方針の案」の 1 の文。経緯は git。確かめていない）
- 水（H-1 と O-16）の個数密度の差も入らない。ホウ酸水の水の個数密度は 1 − w（w = ppm × 10⁻⁶ はホウ素の質量分率）に比例する
  （crates/lattice/src/water.rs の `borated_water`）ので、ppm を ppm' に換算したテーブルの状態の水は、ケースの状態の (1 − w') / (1 − w) 倍に
  なる。その効きの大きさは確かめていない
- 直接の格子計算と比べた差（「確認」）は、B-11 と水の個数密度の差の効きも含む

### 帰結

- ADR-0097 の「core の状態と B-10 の割合が違えばエラーにする」を、この換算に置き換える（ADR-0097 の「## 変更」）
- テーブルのホウ素の軸の範囲は、使う B-10 の割合での換算後の ppm を覆うように選ぶ
- B-10 の割合を core が燃焼で追う形は #0036 に残る。追った B-10 の割合（またはノードの B-10 の個数密度）から、同じ換算で ppm' を作って引くのが
  候補

### 確認

- 形式（crates/format/src/table/tests.rs）: `b10_density_ratio_follows_the_atoms_per_boron_mass`
- core（crates/core/src/state/tests.rs）: `differing_b10_interpolates_at_the_ppm_of_the_same_b10_density`（換算した ppm の状態をテーブルの割合で
  引いたものとビットで同じで、多重線形な量を再現する）、`converted_ppm_outside_the_boron_points_is_an_error`、`table_b10_is_not_converted`、
  `invalid_states_are_errors`（割合が範囲の外）
- 測定（examples/depletion/verification.md の「冷却材の B-10 の割合がテーブルと違う状態（2A の集合体 1 体）」。直接の格子計算は c24cb657（分岐点は
  main の 8af94417）、19.9 at% のテーブルは ecdc4d9c、core は ef616079（どちらも分岐点は main の dd5941ee）、比較は d0c5320a（分岐点は 8af94417）、
  2026-11-07）: 2A の燃焼度 0、20、40 MWd/kg、600 と 1300 ppm で、換算した core の k と
  直接の格子計算の k∞ の差は、18 at% で +4.389〜+13.705 pcm（B-10 の割合を変えた効きの最大 0.99%）、30 at% で −7.532〜+17.490 pcm（最大 0.55%）。
  換算した ppm はホウ素の格子点の間にあるので、差はホウ素の軸の内挿の誤差を含む
