# ADR-0033: M4 の分岐テーブルに、動特性と冷却計算が使うデータを入れる

## 背景

M4 の後に、動特性と、取り出した燃料の冷却計算（ORIGEN と同じく、放射能と崩壊熱を求める）を加える。分岐テーブルは
全燃焼点・全分岐の格子計算から作る大きなデータで、後から項目を足すとすべて作り直しになる。

## 検討した案

- 必要になるまで作らない（ふだんの原則）: 後でテーブルをすべて作り直すことになる
- 動特性と冷却計算が使うデータを M4 で入れる（採用）

## 決定と理由

動特性と冷却計算が使うデータは、必要になるまで作らないという原則の例外として M4 で入れる。解法そのものは、それぞれを
作るときに入れる。

- 遅発中性子のデータ（即発と遅発の ν、族ごとの遅発中性子の割合と崩壊定数、遅発中性子のスペクトル）と群速度の逆数。
  遅発中性子の割合は燃焼で変わる（Pu が増える）ので燃焼点ごとに持つ
- 分岐の軸は固定せず、燃料温度や減速材密度などの状態の軸を足せる形にする。動特性は熱水力のフィードバックと
  組み合わせて初めて意味を持つため
- 冷却計算の燃焼をやり直すための、全核種の1群の微視的断面積

## 確認

まだ実装していない（M4）。

## 結果

核データの出所（ENDF/B-VIII.0 の中性子データがない核種や、放射化断面積）と、状態と履歴への依存の扱いは、テーブルの
項目に効くので M4 の計画で決める。
