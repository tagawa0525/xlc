# ADR-0177: 非分離共鳴の自己遮蔽を、ETOX（J 積分と重なりの補正）から、ラダーをサンプリングした断面積の Bondarenko 平均に変える

## 背景

非分離共鳴の σ0 ごとの実効断面積は、NJOY UNRESR と同じ ETOX 法で求めていた（[ADR-0048](0048-shield-unresolved-like-unresr.md)）。系列（l, J）ごとに、
孤立した 1 つの共鳴の線形状をローレンツの裾ごと無限の範囲で積分した J, K（[ADR-0107](0107-use-natural-line-shape-beyond-jk-table.md)、[ADR-0170](0170-take-gaussian-limit-jk-below-table.md)）を幅の
ゆらぎで平均し、系列どうしの重なりを 1 次の補正 σ = σm yy/(1 − yj) で入れる（NJOY unresr.f90 の 1181 行と同じ式）。

燃焼チェーンの核種のライブラリ（ADR-0169）で、5 核種の非分離共鳴の自己遮蔽が小さい σ0 で NaN になった（#0127）。Pm-149 の 565 K で測ると
（xlc 316e30b6 に一時的な出力を足したもの、2026-10-15）、2.6 eV で系列ごとの J Γ/D（自己遮蔽した共鳴が占めるエネルギーの割合にあたる量）の
和が σ0 = 10 b で 1.36、1 b で 2.73 になる（s 波の 2 系列で 1.20 と 1.53）。ほかの系列の和が 1 を超えるので重なりの補正 1 − (ほかの系列の和)
が負になり、σ0 = 1 b の遮蔽した捕獲が −1.33 b になる。これを非分離共鳴のパラメータの補間則（log-log）で補間するので、ln が NaN になる。
同じ量の最大（非分離共鳴の格子の最初の 40 点）:

| 核種            | σ0 = 10 b | σ0 = 1 b |
| --------------- | --------- | -------- |
| Pm-148          | 2.5       | 5.0      |
| Am-242m         | 2.1       | 3.0      |
| Eu-151（900 K） | 1.4       | 2.2      |
| Pm-147          | 0.64      | 1.55     |
| U-238           | 0.14      | 0.24     |
| Pu-240          | 0.19      | 0.33     |

J は孤立した共鳴の裾を無限の範囲で数えるので、σ0 が共鳴のピークより十分小さいと J ≈ π/(2√β) で大きくなり、J Γ/D が 1 を超える。実際には
準位間隔 D の区間で σ が σ0 を下回らない（「黒い」）状態で、割合は 1 で頭打ちになるはずである。孤立した共鳴と 1 次の重なりの補正という
式の前提の外で、NJOY UNRESR も同じ式をそのまま使う。U-238 と Pu-240 でも、補正は 0.1〜0.3 で小さくない。

判断の軸:

- 重なりと「黒い」極限を、式の近似でなく分布そのもので扱えること
- 参照解の OpenMC が使う確率テーブル（NJOY PURR の MT153）と同じ考え方にして、参照解との差から非分離共鳴の扱いの差を除けること
- 評価済みデータ（ENDF-6 の LRF = 2 の平均の幅、準位間隔、自由度）だけで決まり、乱数で決まる部分を再現できること

## 検討した案

- 案 A: 確率テーブルの考え方: ENDF-6 の平均のパラメータから共鳴のラダー（エネルギーの並びと幅）を乱数で作り、その上の断面積を多くのエネルギーで
  求め、σ0 ごとの実効断面積を Bondarenko の平均 ⟨σx/(σt + σ0)⟩/⟨1/(σt + σ0)⟩ で直接求める（NJOY PURR の「bondarenko cross sections by direct
  sampling」と同じ量）。重なりは複数の系列のラダーを重ねたものの断面積に入り、黒い極限も分布として入る（採用）
- 案 A′: 確率テーブルを、ETOX の前提が崩れる点（例えば J Γ/D の和 > 0.5）だけに使う: 既存の核種の値は変わらないが、同じ量を 2 つの方式で求める継ぎ目が
  σ0 の表にでき、判定の閾値に根拠がない
- 案 B: 前提が崩れる点をエラーにする: Pm-149（Sm-149 の先行核）を含む 5 核種のライブラリを作れず、燃焼の検証（M4 の「進め方」5）が進まない
- 案 C: ETOX の 1 − yj を 0 で止める、遮蔽した値を 0 で止める: 式の外の量を推測で埋める

## 決定と理由

案 A にする。ETOX の自己遮蔽（J, K の積分、表、重なりの補正）は残さない。無限希釈の平均断面積は、これまでどおり幅のゆらぎの積分で
求める（[ADR-0049](0049-integrate-width-fluctuations-adaptively.md)。LRF = 1 は [ADR-0058](0058-read-lrf1-as-lrf2-with-l3.md)）。LSSF = 0 の核種の無限希釈の断面積も、これまでどおり共鳴パラメータから
求める（ADR-0048 の決定のうち残る部分）。

- ラダー: 非分離共鳴の格子の各エネルギー E で、系列ごとに、E を中心とする窓の中に共鳴を並べる。間隔は Wigner 分布（平均 D(E)）、最初の共鳴の
  位置は一様。中性子幅、核分裂幅、競合幅は、自由度 ν の χ² 分布（平均を ENDF の平均の幅にする）から引く。NJOY PURR は χ² を 20 点の分位点の
  表から引くが、ここでは ν 個の標準正規の 2 乗の和で厳密に引く。捕獲幅は一定（ENDF-6 の LRF = 2 と同じ）。パラメータは E での値を使う
  （窓の中ではエネルギーによらない。PURR と同じ）
- 断面積: 捕獲と核分裂は、系列ごとの単準位 Breit-Wigner を、ドップラー拡がりの ψ（Faddeeva 関数 w の実部）で求めて足す（NJOY PURR の unrest と
  同じ式）。弾性散乱は、同じ系列（同じ J）の共鳴どうしの干渉を多準位 Breit-Wigner の |1 − U|² で入れ、ポテンシャル散乱との干渉を含めて、極の
  展開でドップラー拡がりの w から求める。単準位の和（PURR）は干渉の谷で弾性散乱が負になりうるが（PURR は 1 μb に置き換える）、|1 − U|² は負に
  ならない。中性子幅のエネルギー依存は透過因子で入れる（無限希釈の平均と同じ）。各共鳴の寄与は裾を切らずに窓の外の共鳴まで足す。PURR は
  共鳴から 31.83 Γ + max(31.83 Γ, 20 Δ) より遠い点の寄与を落とす（purr.f90 の unrest の delr）
- 実効断面積: 窓（系列の最大の準位間隔の 50 倍）の中の等間隔の点を、ラダーごとに 1 つの一様な乱数でずらしたエネルギー（系統抽出。PURR は
  独立な一様の乱数）で全断面積 σt（MF3 の背景を含む）と部分の反応を求め、σ0 ごとに
  σx,eff = Σ σx/(σt + σ0) / Σ 1/(σt + σ0)、流れの重みの全断面積は Σ σt/(σt + σ0)² / Σ 1/(σt + σ0)²。同じサンプルの平均（σ0 → ∞）を、
  これまでの「無限希釈」の欄に入れ、ライブラリの補正（LSSF = 0 は差、LSSF = 1 は比。NJOY GROUPR の getunr と同じ）がサンプルの揺らぎの 1 次を
  打ち消すようにする
- 温度: 同じラダーとエネルギーで、温度ごとのドップラー幅だけを変える（温度の間の相関を保つ。PURR と同じ）。乱数のシードは核種の格子のエネルギーの
  番号で決め、温度と σ0 によらない
- 乱数: 標準ライブラリの外の依存を足さず、決まった種から決定的に作る（スレッドの数によらない）
- サンプルの数: ラダー 512 組、ラダーごとのエネルギー 250 点に固定する（`Sampling::LIBRARY`）。U-238 の σ0 = 1 b の捕獲の、格子点 1 つの
  統計誤差が 0.1% を下回る数（「確認」）。Pu-240 と Pm-149 は 0.1% に届かない（σ0 = 1 b で最大 0.20% と 0.94%）。誤差はサンプルの数の
  平方根に反比例するので、0.1% にするには Pu-240 で約 4 倍、Pm-149 で約 90 倍の数が要り、遮蔽の時間もその倍数で増える。どちらも燃料の
  中の数密度が U-238 より小さく、σ0 は数密度に反比例して大きいので、U-238 で決める。格子点ごとの種は独立なので、群の平均では誤差が
  さらに下がる
- 全断面積が 0 以下になる点（MF3 の背景が負のときなど）はエラーにする

## 確認

- 単体テスト（crates/xs/src/resonance/ladder/tests.rs、unresolved/tests.rs）: 一様乱数、χ² の幅の平均と分散、Wigner の間隔の平均、
  種ごとの再現。サンプルの平均が幅のゆらぎの積分（ADR-0049）に、16 の種の統計の中で合うこと、σ0 → ∞ で平均になること、孤立した共鳴の
  極限で Bondarenko 平均が 1 つの間隔の直接の積分に合うこと、黒い極限（Pm-149 の 2.6 eV、565 K、σ0 = 1 b）で正の有限な値になること、
  同じ種なら温度を変えても同じラダーを使うこと（1 K ずつの差が滑らか）
- 統計誤差と NJOY PURR との比較（xlc ff11ba5d、2026-10-15。NJOY2016 PURR、256 ラダー、565 K、ENDF/B-VIII.0。入力と比べるツールは
  examples/urr-purr/）: `crates/xs/examples/urr_convergence.rs` で、種 1〜16 の遮蔽の比（実効断面積 / 同じサンプルの平均）の平均と、
  種 1 つあたりの相対標準偏差を求め、PURR の「bondarenko cross sections by direct sampling」の同じ比と比べた。

| 核種   | エネルギー (eV)       | σ0 = 1 b の捕獲の統計誤差（種 1 つ） | 捕獲の比の PURR との差（σ0 = 1〜1000 b） | 全断面積の比の差（σ0 = 1 b） |
| ------ | --------------------- | ------------------------------------ | ---------------------------------------- | ---------------------------- |
| U-238  | 2e4、5e4、1e5、1.49e5 | 0.026〜0.089%                        | −0.03〜+0.04%                            | 0.00〜−0.32%                 |
| Pu-240 | 5.7e3、1e4、4e4       | 0.059〜0.20%                         | −0.05〜+0.06%                            | 0.00〜−0.19%                 |
| Pm-149 | 1e3、1e4、1e5         | 0.032〜0.37%                         | −0.27〜+0.31%                            | −0.04〜−3.05%                |
| Pm-149 | 2.6、10、100          | 0.69〜0.94%                          | +0.30〜+56.6%                            | +3.3〜+49%                   |

  U-238 と Pu-240 の捕獲の比は、PURR と 0.06% の中で合う（PURR の統計誤差は求めていない）。全断面積は σ0 が小さいほど xlc が低く（U-238 の 1.49e5 eV で −0.32%）、候補は弾性
  散乱の扱いの差（xlc は系列の中の多準位、PURR は単準位の和で負を 1 μb に置き換える。確かめていない）。Pm-149 の 100 eV 以下では、σ0 が
  小さいほど xlc の遮蔽が弱い（2.6 eV の σ0 = 1 b で捕獲の比が 0.0281 と 0.0180）。候補は、PURR が共鳴の寄与を 31.83 Γ + max(31.83 Γ, 20 Δ)
  の外で落とすことで（確かめていない）、2.6 eV では Γ ≈ 0.07 eV、Δ ≈ 0.06 eV から約 4.5 eV になり、s 波の準位間隔（5.2〜6.7 eV）の中ほどの
  谷で隣の共鳴の裾が消え、PURR の確率テーブルの最も低い区間の捕獲が 1.3 mb になる（xlc の窓では裾を落とさない）。1 keV 以上では Δ が大きく、
  切る幅が準位間隔の数倍になり（1 keV で約 25 eV）、捕獲の比の差は 0.31% 以下になる

- サンプルの数の選び方（Pu-240 の 5.7 keV、Pm-149 の 2.6 eV、σ0 = 1 b の捕獲、種 1 つあたり）: U-238 と Pu-240 の統計誤差は、ラダーの数で
  決まり、ラダーごとのエネルギーの数によらない（Pu-240 は 64 × 1000 点で 0.68%、64 × 4000 点で 0.68%、640 × 100 点で 0.26%、
  256 × 250 点で 0.32%）。Pm-149 の 2.6 eV は総点数に依る（64 × 1000 点で 1.8%、640 × 100 点で 1.9%、64 × 4000 点で 0.92%）。512 × 250 点
  の時間は、上の表の 13 点（種 16、1 コア）で 966 秒、64 × 1000 点で 486 秒。差の多くは Pm-149 の 1 keV 以上で、窓の外の共鳴（準位間隔の
  1000 倍まで）の係数の計算がラダーの数に比例して増える（U-238 の 2e4 eV の 1 点は 38 秒と 39 秒で同じ）
- 試して捨てた方式: 窓の幅を最小の準位間隔で決める（512 × 250 点で、Pm-149 の 100 eV の誤差は 0.69% から 0.26% に下がるが、
  Pm-149 の 2.6 eV は 0.83% から 1.07%、Pu-240 は大きい間隔の系列の共鳴が窓に減って 0.20% から 0.24% に上がり、U-238 は 0.089% で変わらない）。独立な一様の乱数の
  エネルギー（系統抽出の代わり）: 512 × 250 点で Pm-149 の 2.6 eV の誤差が 1.33%（系統抽出は 0.83%）。U-238 の 2e4 eV と Pu-240 の 5.7 keV は 0.113% と 0.089%、0.178% と
  0.196% で、種 16 の標準偏差の推定の揺らぎ（約 18%）の中で同じ
- VERA 1B と 2A の k の変化、5 核種を戻した燃焼のライブラリ: （計算中）

## 帰結

- 非分離共鳴を持つすべての核種の σ0 の表が変わる。xs の段階はすべて走り直し、VERA の記録の k が動く
- 実効断面積に乱数による統計誤差が入る（サンプルの数で決まる。「確認」の表）
- 燃焼のライブラリ（ADR-0169）に、#0127 で外した Pm-147、Pm-148、Pm-149、Am-242m、Eu-151 を戻す
- ADR-0048（自己遮蔽の部分）、ADR-0107、ADR-0170 を置き換える
