# ADR-0177: 非分離共鳴の自己遮蔽を、ETOX（J 積分と重なりの補正）から、ラダーをサンプリングした断面積の Bondarenko 平均に変える

## 背景

非分離共鳴の σ0 ごとの実効断面積は、NJOY UNRESR と同じ ETOX 法で求めていた（[ADR-0048](0048-shield-unresolved-like-unresr.md)）。系列（l, J）ごとに、
孤立した 1 つの共鳴の線形状をローレンツの裾ごと無限の範囲で積分した J, K（[ADR-0107](0107-use-natural-line-shape-beyond-jk-table.md)、[ADR-0170](0170-take-gaussian-limit-jk-below-table.md)）を幅の
ゆらぎで平均し、系列どうしの重なりを 1 次の補正 σ = σm yy/(1 − yj) で入れる（NJOY unresr.f90 の 1181 行と同じ式）。

燃焼チェーンの核種のライブラリ（ADR-0169）で、5 核種の非分離共鳴の自己遮蔽が小さい σ0 で NaN になった（#0127）。Pm-149 の 565 K で測ると
（xlc 316e30b6 に一時的な出力を足したもの、2026-10-15）、2.6 eV で系列ごとの J Γ/D（自己遮蔽した共鳴が占めるエネルギーの割合にあたる量）の
和が σ0 = 10 b で 1.36、1 b で 2.73 になる（s 波の 2 系列で 1.20 と 1.53）。ほかの系列の和が 1 を超えるので重なりの補正 1 − (ほかの系列の和)
が負になり、σ0 = 1 b の遮蔽した捕獲が −1.33 b になる。これを非分離共鳴のパラメータの補間則（log-log）で補間するので、ln が NaN になる。
同じ量の最大（非分離共鳴の格子の最初の 40 点）:

| 核種            | σ0 = 10 b | σ0 = 1 b |
| --------------- | --------- | -------- |
| Pm-148          | 2.5       | 5.0      |
| Am-242m         | 2.1       | 3.0      |
| Eu-151（900 K） | 1.4       | 2.2      |
| Pm-147          | 0.64      | 1.55     |
| U-238           | 0.14      | 0.24     |
| Pu-240          | 0.19      | 0.33     |

J は孤立した共鳴の裾を無限の範囲で数えるので、σ0 が共鳴のピークより十分小さいと J ≈ π/(2√β) で大きくなり、J Γ/D が 1 を超える。実際には
準位間隔 D の区間で σ が σ0 を下回らない（「黒い」）状態で、割合は 1 で頭打ちになるはずである。孤立した共鳴と 1 次の重なりの補正という
式の前提の外で、NJOY UNRESR も同じ式をそのまま使う。U-238 と Pu-240 でも、補正は 0.1〜0.3 で小さくない。

判断の軸:

- 重なりと「黒い」極限を、式の近似でなく分布そのもので扱えること
- 参照解の OpenMC が使う確率テーブル（NJOY PURR の MT153）と同じ考え方にして、参照解との差から非分離共鳴の扱いの差を除けること
- 評価済みデータ（ENDF-6 の LRF = 2 の平均の幅、準位間隔、自由度）だけで決まり、乱数で決まる部分を再現できること

## 検討した案

- 案 A: 確率テーブルの考え方: ENDF-6 の平均のパラメータから共鳴のラダー（エネルギーの並びと幅）を乱数で作り、その上の断面積を多くのエネルギーで
  求め、σ0 ごとの実効断面積を Bondarenko の平均 ⟨σx/(σt + σ0)⟩/⟨1/(σt + σ0)⟩ で直接求める（NJOY PURR の「bondarenko cross sections by direct
  sampling」と同じ量）。重なりは複数の系列のラダーを重ねたものの断面積に入り、黒い極限も分布として入る（採用）
- 案 A′: 確率テーブルを、ETOX の前提が崩れる点（例えば J Γ/D の和 > 0.5）だけに使う: 既存の核種の値は変わらないが、同じ量を 2 つの方式で求める継ぎ目が
  σ0 の表にでき、判定の閾値に根拠がない
- 案 B: 前提が崩れる点をエラーにする: Pm-149（Sm-149 の先行核）を含む 5 核種のライブラリを作れず、燃焼の検証（M4 の「進め方」5）が進まない
- 案 C: ETOX の 1 − yj を 0 で止める、遮蔽した値を 0 で止める: 式の外の量を推測で埋める

## 決定と理由

案 A にする。ETOX の自己遮蔽（J, K の積分、表、重なりの補正）は残さない。無限希釈の平均断面積は、これまでどおり幅のゆらぎの積分で
求める（[ADR-0049](0049-integrate-width-fluctuations-adaptively.md)。LRF = 1 は [ADR-0058](0058-read-lrf1-as-lrf2-with-l3.md)）。LSSF = 0 の核種の無限希釈の断面積も、これまでどおり共鳴パラメータから
求める（ADR-0048 の決定のうち残る部分）。

- ラダー: 非分離共鳴の格子の各エネルギー E で、系列ごとに、E を中心とする窓の中に共鳴を並べる。間隔は Wigner 分布（平均 D(E)）、最初の共鳴の
  位置は一様。中性子幅、核分裂幅、競合幅は、自由度 ν の χ² 分布（平均を ENDF の平均の幅にする）から引く。NJOY PURR は χ² を 20 点の分位点の
  表から引くが、ここでは ν 個の標準正規の 2 乗の和で厳密に引く。捕獲幅は一定（ENDF-6 の LRF = 2 と同じ）。パラメータは E での値を使う
  （窓の中ではエネルギーによらない。PURR と同じ）
- 断面積: 系列ごとの単準位 Breit-Wigner を、ドップラー拡がりの ψ, χ（Faddeeva 関数 w の実部と虚部）で求めて足し、ポテンシャル散乱と、それとの
  干渉（cos 2φ、sin 2φ の項）を足す（NJOY PURR の unrest と同じ式）。中性子幅のエネルギー依存は透過因子で入れる（無限希釈の平均と同じ）
- 実効断面積: 窓の中央部の一様な乱数のエネルギーで全断面積 σt（MF3 の背景を含む）と部分の反応を求め、σ0 ごとに
  σx,eff = Σ σx/(σt + σ0) / Σ 1/(σt + σ0)、流れの重みの全断面積は Σ σt/(σt + σ0)² / Σ 1/(σt + σ0)²。同じサンプルの平均（σ0 → ∞）を、
  これまでの「無限希釈」の欄に入れ、ライブラリの補正（LSSF = 0 は差、LSSF = 1 は比。NJOY GROUPR の getunr と同じ）がサンプルの揺らぎの 1 次を
  打ち消すようにする
- 温度: 同じラダーとエネルギーで、温度ごとのドップラー幅だけを変える（温度の間の相関を保つ。PURR と同じ）。乱数のシードは核種の格子のエネルギーの
  番号で決め、温度と σ0 によらない
- 乱数: 標準ライブラリの外の依存を足さず、決まった種から決定的に作る（スレッドの数によらない）
- サンプルの数: ラダーの数と、ラダーごとのエネルギーの数を固定する。値は、実効断面積の、ラダーの組ごとの標準偏差から求めた統計誤差が
  σ0 = 1 b の捕獲で 0.1% を下回るように、U-238、Pu-240、Pm-149 で測って決め、この ADR に書く（実装で測る）
- 全断面積が 0 以下になる点（単準位 Breit-Wigner の干渉で弾性散乱が負になりうる）はエラーにする（NJOY PURR は弾性散乱を 1 μb に置き換える）

## 確認

（実装で書く）

- ラダーの統計（間隔の平均 D、幅の平均と分散が χ² のもの）、孤立した共鳴の極限で Bondarenko 平均が直接の積分に合うこと、σ0 → ∞ で平均に
  なること、黒い極限（σ0 → 0）で正の有限な値になることの単体テスト
- U-238、Pu-240、Pm-149 の σ0 ごとの実効断面積を NJOY PURR の Bondarenko の表と比べる
- VERA 1B と 2A の k の変化、5 核種を戻した燃焼のライブラリ

## 帰結

- 非分離共鳴を持つすべての核種の σ0 の表が変わる。xs の段階はすべて走り直し、VERA の記録の k が動く
- 実効断面積に乱数による統計誤差が入る（サンプルの数で決まる）
- ADR-0048（自己遮蔽の部分）、ADR-0107、ADR-0170 を置き換える
