# ADR-0092: 自己遮蔽した核種の散乱行列は、無限希釈の形のまま行の和を自己遮蔽した弾性散乱断面積に合わせる

## 背景

M1（2026-10-06）で、多群ライブラリは無限希釈の散乱行列だけを持つことにした（[ADR-0050](0050-tabulate-sigma0-per-nuclide-and-temperature.md)）。自己遮蔽した核種で、散乱
行列をどう合わせるかを決める必要があった。M1 の計画では [ADR-0050](0050-tabulate-sigma0-per-nuclide-and-temperature.md) と同じ項目に書いていたものを、別の決定として
分けた（番号はこの分割のときに振った）。

## 検討した案

- 散乱行列も σ0 ごとに持つ: 効果が小さいので後回しにする
- 無限希釈の形のまま、行の和を自己遮蔽した弾性散乱断面積に合わせる（採用）

## 決定と理由

散乱行列は無限希釈の形のまま、行の和を自己遮蔽した弾性散乱断面積に合わせる（散乱行列の自己遮蔽は効果が小さいので
後回しにする）。

## 確認

なし。この形では実装していない。

## 結果

格子計算で遮蔽を使い始めたとき（M2、d072037、2026-10-07）は、行の和には弾性散乱のほかに非弾性散乱や多重度も入る
ので、行の和に弾性散乱の変化を足す形で実装した。M2 の計画はその形を [ADR-0076](0076-store-legendre-scattering-moments.md) に書いたので（df9171a、2026-10-07）、
この ADR は [ADR-0076](0076-store-legendre-scattering-moments.md) に置き換えられた。
