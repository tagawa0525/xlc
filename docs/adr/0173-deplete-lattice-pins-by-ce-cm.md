# ADR-0173: 格子計算の燃焼を、ピンの組と燃料の物質ごとの領域で、CE/CM の予測子・修正子と一定の出力で進める

## 背景

[ADR-0025](0025-deplete-with-cram.md) は燃焼を CRAM で解き、予測子・修正子法で時間を進めるとだけ決めた。[ADR-0161](0161-solve-depletion-with-ipf-cram.md) は 1 ステップの行列指数を
`xlc_depletion::deplete` に置き、予測子・修正子の方式、燃焼の領域、出力の規格化、CRAM の次数の選び方を、格子計算の燃焼の
ADR に任せた。docs/plans/m4-depletion.md の「格子計算の燃焼」は、燃焼の領域、時間の進め方、出力の規格化、自己遮蔽を
解き直す頻度を ADR で決めるとし、「核データ」は核分裂の Q 値と捕獲のエネルギー（出力の規格化）を「進め方」5 で決めるとした。

前提:

- チェーンは全核種のチェーン（[ADR-0164](0164-build-full-chain-from-endf.md)、3,820 核種）。輸送に使う縮約したチェーン（[ADR-0165](0165-reduce-chain-by-contribution-and-folding.md)、#0116）はまだない
- 反応ごと（(n,γ)、(n,2n)、(n,3n)、(n,4n)、(n,p)、(n,α) と MF9、MF10 の状態ごとの経路）の群の断面積は、[ADR-0172](0172-store-chain-reactions-in-library.md) で
  ライブラリに入れた（σ0 ごとの捕獲と UFG のポイントワイズの捕獲、しきい値の反応と経路は無限希釈）
- 自己遮蔽は、1 つのセルの燃料のリングがすべて同じ物質であることを求める（`SelfShieldingError::MixedFuel`）。自己遮蔽と MOC は
  格子で成り立つ対称操作（[ADR-0112](0112-use-verified-symmetry-in-moc-and-shielding.md)）で移り合うピンを 1 つにまとめて解く
- 参照解は OpenMC の `openmc.deplete`（0.15.2）。同じ方式を選べば、時間の進め方と規格化の差を比較から外せる

判断の軸:

- 精度: 燃焼を通じて k ±100 pcm（[ADR-0032](0032-target-lattice-accuracy.md)）。時間の進め方の誤差は、参照解と同じ方式にすれば比較に入らない
- 費用: 時間のほとんどが自己遮蔽（2B の 1 状態の 94%。計画の「CPU と記憶の見積もり」）なので、輸送の回数が時間を決める
- 範囲を最小にする: まず燃焼の全体を一通り通し、ネックを測ってから詰める

## 検討した案

燃焼させる状態:

- 案 B1: 公称の 1 つの状態（燃料の温度、減速材の温度と密度、ホウ素濃度を入力に書く）だけで燃焼させる（採用）。分岐の状態（ホウ素、
  温度の表。[ADR-0085](0085-branch-on-core-states.md)、[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)）は作らない。燃焼度の軸を持つテーブルと燃焼点からの分岐は計画の「進め方」6 で決め、
  内挿の誤差はそこで集合体どうしの比較で見る
- 案 B2: 燃焼点ごとに分岐を解く（CASMO の型）: テーブルの構造が決まっていない。いまの目的（OpenMC の燃焼との比較と時間の内訳）に
  要らない

燃焼の領域:

- 案 R1: 入力に挙げた燃料の物質を、自己遮蔽の対称操作で移り合うセルの組ごとに 1 つの領域にする（組 × 物質）。リングごとに
  燃焼させるときは、リングごとに別の名前の物質を書く。領域の数は入力で決まり、MOC のリングの分け方と独立に選べる（採用）
- 案 R2: MOC の燃料のリングごとに自動で燃焼させる: 燃焼の分け方が MOC の分け方に縛られる（1B の 5 リングを 1 つの燃焼の領域に
  できない）
- 案 R3: 入力の帯（zone）ごとに燃焼させる: 形状が帯を領域の名前の外に持つ必要があり、同じことを R1 は物質の名前で書ける
- 案 R4: 対称性を使わずセルごとに燃焼させる: 1/8 の格子で領域が約 8 倍になり、自己遮蔽の解く数も同じだけ増える。移り合うピンは
  形状と組成が同じなので、燃焼の結果も同じになり、増やす意味がない

1 つのセルに組成の違う燃料のリングがあるときの自己遮蔽（R1 でリングごとに燃焼させるときに要る）:

- 案 S1: UFG の範囲の減速計算はリングごとの組成で解き（減速計算はもともとリングごとの物質を持つ）、範囲の外の等価原理
  （Carlvik の 2 項）はピンの燃料のリングの体積平均の組成で解く。リングの物質は核種の並びと温度が同じであること（採用）。
  等価原理はピン全体を 1 つの燃料の塊として扱う近似で、範囲の外（4 eV 以下と分離共鳴の上）は自己遮蔽が小さい
- 案 S2: 等価原理もリングごとに解く: リングごとの Dancoff 係数と弦長が要り、いまの仕組み（ピンに 1 つ）を作り直す

時間の進め方（h はステップの長さ、A(n) は組成 n で解いた反応率の燃焼行列）:

- 案 T1: 予測子だけ（n₁ = exp(h A(n₀)) n₀）。輸送はステップに 1 回だが 1 次で、Xe と Gd の変化の速いところでステップを細かくする
  必要がある
- 案 T2: CE/CM（n½ = exp(h/2 A(n₀)) n₀、n₁ = exp(h A(n½)) n₀。Isotalo, Aarnio, Ann. Nucl. Energy 38, 2011 の区分。OpenMC の
  `CECMIntegrator`）: 2 次で、輸送はステップに 2 回、前のステップの反応率を持たない（採用）
- 案 T3: CE/LI（始まりと予測子の後の反応率の線形の内挿で、修正子を 2 つの行列指数に分ける。OpenMC の `CELIIntegrator`）:
  2 次で輸送は 2 回、修正子の CRAM が 2 回
- 案 T4: LE/QI（前のステップの反応率を使う 3 次の方式。OpenMC の `LEQIIntegrator`）: 最初のステップを別の方式で始め、前の
  ステップの反応率を持つ

CE/CM にするのは、OpenMC の `CECMIntegrator` と同じ式で、比べるときに時間の進め方の差が消えるからである。T3、T4 の精度は、
ステップの数を減らす段階（燃焼度の格子点を決めるとき）に、測ってから選び直す。

自己遮蔽を解き直す頻度:

- 案 F1: 輸送のたび（ステップの始まりと中点）に解き直す（採用）
- 案 F2: ステップの始まりだけで解き、中点では始まりの微視的断面積を使う: 自己遮蔽の回数が半分になる。誤差は中点の組成の
  変化（初めの Xe、Sm の平衡、Gd）で決まり、測っていない。まず F1 で通して時間の内訳を測り、F2 の誤差と時間は集合体で測って
  決める（帰結）

出力の規格化:

- 案 P1: 一定の出力。燃焼の領域のすべての核分裂の出力 Σ V N σf φ Q が、初めの重金属の質量あたりの出力密度（W/g）× 初めの
  重金属の質量に等しくなるよう、中性子束の大きさを決める。Q は核種ごとの核分裂の Q 値で、ENDF の中性子のデータの MF3 MT18 の
  QI（OpenMC の `Chain.from_endf` がチェーンに書く値。`normalization_mode="fission-q"` が使う）。捕獲の γ のエネルギーは入れない（採用）
- 案 P2: 一定の中性子束: 出力が燃焼で下がり、燃焼度の軸と結べない。実機の運転は出力で与える
- 案 P3: 出力に捕獲のエネルギー（(n,γ) の Q と崩壊の熱）も入れる（OpenMC の `energy-deposition` に近い）: チェーンとライブラリに Q を
  さらに足す。比べる 2 つで同じ定義を使えば差に入らない。炉心の発熱の分布（γ の輸送）を扱うときに見直す

反応率:

- 案 X1: 領域ごと・核種ごとに、69 群の自己遮蔽した微視的断面積と MOC の物理的な中性子束（SPH 因子を戻したもの）の積を
  群で足し、領域の体積で平均した 1 群の反応率。微視的断面積は、UFG の範囲ではその MOC の領域のリングの減速計算の値、範囲の外は
  等価原理の値（どちらも SPH 因子を掛けない物理的な値）（採用）
- 案 X2: 領域の巨視的断面積から逆に求める: 核種に分けられない

核分裂の収率のエネルギーの重み（[ADR-0164](0164-build-full-chain-from-endf.md) の区間）は、群の核分裂率を区間に分けた割合とする。区間の境界が群の中に
あるときは、群の核分裂率をレサジーの幅の比で分ける。2 点（0.0253 eV と 500 keV）の核種では、境界の幾何平均 112.5 eV で
熱と速に分けるので、OpenMC の `FissionYieldCutoffHelper`（`cutoff` を 112.5 eV にしたもの）と同じになる。500 keV と 14 MeV の収率を
持つ核種（U-235 の 3 点、U-238 の 2 点など）では、xlc は 2.65 MeV（幾何平均）より上に 14 MeV の収率を使い、OpenMC の `cutoff` は
112.5 eV より上をすべて 500 keV の収率にするので、扱いが違う（差は #0133）。

微量の核種の自己遮蔽: 燃焼でできたばかりの核種は、背景断面積 σ0 がライブラリの無限希釈の値（σ0 の表の最初の値）を超える。
σt ≪ σ0 で群定数は σ0 によらないので、表は無限希釈の値で引く（範囲の外をエラーにすると、燃焼の 2 回目の輸送で止まる）。

輸送する核種:

- 案 N1: チェーンの核種のうち、ライブラリがすべての燃焼の領域の温度そのもので持つもの（温度の内挿で引ける核種も、その温度の表が
  なければ数えない）。数密度が 0 の核種も輸送して 1 原子あたりの反応率を求める（OpenMC の燃焼の tally は数密度を掛けず、0 の
  核種にも反応率を与える。始まりに 0 の Xe-135 も最初の予測子で燃え尽きる）。それ以外は反応率を 0（崩壊と生成だけ）と
  する（採用）。ライブラリにあっても領域の温度のデータがない核種（燃料の温度で作っていない被覆管と減速材の核種。燃料の中に
  チェーンの反応と崩壊でわずかにできる H-1、B、Fe、Cr）は、輸送のたびに名前と数密度の和を warn で示す。ライブラリにない核種は
  数と数密度の和を info で示す。OpenMC も、断面積のない核種を輸送と反応率の tally から外す（`CoupledOperator` の
  `nuclides_with_data`）ので、参照解では `nuclides_with_data` を燃料の温度のデータのある核種に絞り、同じ集合を輸送する
- 案 N2: 領域の温度のない核種に、ライブラリの最も近い温度のデータを使う（OpenMC の既定の `nearest` のモード）: 黙った代用になる。
  核分裂生成物の Zr と Sn は燃料の温度でライブラリに作る（ADR-0172 のライブラリの作り直しで）ので、代用が要るのは微量の核種だけ
- 縮約（#0116）ができたら、輸送する核種は縮約したチェーンとライブラリが決める
- CRAM は近似の誤差で小さな負の値を返す（ADR-0161）。輸送には 0 として渡し、状態には値のまま持つ（OpenMC は −1e-21 /(barn cm)
  より小さい値を状態でも 0 に戻す。差は近似の誤差の水準）。領域の最大の数密度の 1e-12 倍より大きな負の値は、近似の誤差
  （初めの最大の 1e-15 倍の水準）で説明できないので、エラーにする

## 決定と理由

- 燃焼の領域は案 R1。入力の `[depletion]` に燃焼させる燃料の物質を挙げ、自己遮蔽の対称操作のセルの組と物質の対ごとに 1 つの
  領域にする。組の中のピンは同じ組成を持つ
- 自己遮蔽は案 S1。セルの燃料のリングは、核種の並びと温度が同じなら別の物質でよい
- 時間の進め方は CE/CM（案 T2）。CRAM の次数は 48（OpenMC の既定の `CRAM48` と同じ。[ADR-0161](0161-solve-depletion-with-ipf-cram.md) の環の誤差を避ける）
- 自己遮蔽は輸送のたびに解き直す（案 F1）
- 出力は一定の出力密度（案 P1）。単位は初めの重金属（Z ≥ 90 の核種）の W/g、燃焼度は初めの重金属の MWd/kg。重金属の質量は
  ライブラリの AWR × 中性子の質量（1.00866491595 u。CODATA 2018）から求める。2 次元の格子なので、出力と質量は高さ 1 cm あたり。
  核分裂の Q 値はチェーンに持たせ、xlc-chain が MF3 MT18 の QI から書く
- 反応率は案 X1。反応ごとの群の断面積はライブラリ（ADR-0172）から引く: 捕獲は自己遮蔽した捕獲（UFG の範囲はリングの減速計算の
  値）を、経路の無限希釈の断面積の比で群ごとに分け、しきい値の反応は無限希釈の値を使う。引く口は lattice の中のトレイト 1 つ
- 輸送する核種は案 N1
- 入力のステップは、燃焼度の点（MWd/kg、0 より大きく増える列）で書く。各点の時間は、出力密度から決まる
- 出力: 燃焼点（0 と各ステップの終わり）ごとに、時間、燃焼度、k∞、領域ごとの全核種の数密度、格子全体の少数群定数（`[depletion]` の
  `few-group` に群境界を書いたとき）を、1 つの燃焼の履歴のファイルに書く。ファイルの `few-group` とは使えない。燃焼度の軸を持つ分岐のテーブルの構造は、計画の「進め方」6 の
  ADR で決める。それまでは、分岐（`[branches]`）と燃焼を同じ入力に書けない
- 燃焼させる状態は案 B1（公称の 1 状態。分岐と燃焼を同じ入力に書けない）
- チェーンの縮約との関係: いまは全核種のチェーンを領域ごとに解き、輸送する核種はライブラリが決める（案 N1）。縮約は #0116 に任せる

OpenMC との対応（参照解を同じ方式で解く設定）:

| xlc                                 | OpenMC 0.15.2                                              |
| ----------------------------------- | ---------------------------------------------------------- |
| CE/CM、CRAM48                       | `CECMIntegrator`（`solver="cram48"`）                      |
| 一定の出力密度（W/g、初めの重金属） | `power_density`、`timestep_units="MWd/kg"`                 |
| Q = MF3 MT18 の QI、捕獲を入れない  | `normalization_mode="fission-q"`（`Chain.from_endf` の Q） |
| 反応率 = 自己遮蔽した 69 群の σ × φ | `reaction_rate_mode="direct"`（連続エネルギーの tally）    |
| 収率の区間の重み                    | `fission_yield_mode="cutoff"`、`cutoff=112.5`              |
| 燃焼の領域 = 物質                   | リングごとの物質（`depletable=True`）                      |
| 温度のデータのない核種は崩壊だけ    | `nuclides_with_data` を燃料の温度のデータのある核種に絞る  |

チェーンそのものの違い（MF8 の状態のチャネル、借りる収率など）は examples/depletion/verification.md の「燃焼チェーン」にある。

## 確認

- 単体のテスト（crates/lattice/src/depletion/tests.rs）: `ce_cm_with_constant_rates_is_one_matrix_exponential`、
  `ce_cm_converges_at_second_order`（dA/dt = −c A² の解析解で、ステップを半分にした誤差の比から次数 1.8〜2.2）、
  `ce_cm_solves_the_transport_twice_per_step_and_at_the_end`、`fission_products_count_the_energy_released`（核分裂生成物の原子の数から
  求めたエネルギーが出力密度 × 重金属の質量 × 時間と 1e-3 で一致）、`yield_weights_split_groups_at_the_bounds_by_lethargy`、
  `region_rates_average_sigma_phi_over_the_region_volume`、`pins_of_one_symmetry_orbit_deplete_as_one_region`、
  `fuel_rings_deplete_as_their_own_regions`、`nuclides_without_data_at_the_fuel_temperature_only_decay`、
  `capture_channels_split_the_shielded_capture_by_the_dilute_ratios`、`library_channels_must_match_the_chain`。自己遮蔽
  （crates/lattice/src/shielding/tests.rs）: `fuel_rings_of_equal_composition_shield_like_one_material`、
  `fuel_rings_take_their_own_compositions`、`ring_cross_sections_resolve_the_rim_in_the_ufg_range`、
  `a_trace_nuclide_beyond_the_table_is_infinitely_dilute`。チェーンの Q（crates/chain）: `takes_each_nuclides_own_fission_q_even_when_it_borrows_yields`、
  `rejects_fission_without_the_q_value_of_mt18`。チェーンの Q は OpenMC の `Chain.from_endf` と 88 核種で一致
- 参照解との比較（examples/depletion/verification.md の「格子計算の燃焼」）: VERA 1C のピンセル（燃料 900 K）を 5 MWd/kg まで
  OpenMC の燃焼と同じ方式で燃焼させ、輸送する核種（49）が同じことを確かめて比べた。k∞ の差の 0 の点からの変化は、燃料 1 リングで
  +31〜+69 pcm（ADR-0032 の ±100 pcm の内）、4 リングで +3〜+120 pcm（2 MWd/kg の点だけ外れる。OpenMC の組成の揺らぎが候補、#0133）。
  U-235 と U-238 は 0.05% 以内、Pu-239 は +0.1〜+0.2%、Xe-135 は −0.1〜−0.2%、Sm-149 は 1 MWd/kg から +0.7〜+0.9%（#0133）。数密度が
  0 の核種に反応率を与える前は、最初のステップの終わりで Pu-239 が +4.7%、Xe-135 が +2.5% ずれていた

## 帰結

- 捕獲の経路の比を群の中で一定とする近似（ADR-0172 の帰結）は、反応率にもそのまま入る
- リングごとに燃焼させると、飛程の表（ADR-0156）が燃料のリングの物質の数とともに大きくなり、格子点ごとの計算が要る（#0129）
- 自己遮蔽を中点で解き直さない案（F2）の誤差と時間は、集合体の燃焼で測って決める（#0134）。時間の大部分は自己遮蔽で（1C の
  ピンセルで 95%、2A の 1 ステップで 73%）、燃焼行列と CRAM48 は全核種のチェーンのままでも 1 回の輸送あたり 0.04 秒以下（1 領域）
- 輸送ごとに組成によらない自己遮蔽の前処理（Dancoff 係数など）をやり直す。効きは測っていない（#0137）
