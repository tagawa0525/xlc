# ADR-0085: ホウ素濃度、減速材の温度と密度、燃料の温度、制御棒、支持格子を分岐として少数群定数のテーブルにする

## 背景

M3 の炉心計算は、ノードの定数を状態（ホウ素濃度、温度、制御棒）でテーブルから内挿する。分岐の軸と、テーブルの形式を
決める必要があった。

## 検討した案

計画には、ほかの軸の組を比べた記録はない（テーブルの形式は [ADR-0011](0011-write-data-files-in-messagepack.md) で M4 に回している）。

## 決定と理由

ホウ素濃度、減速材の温度（と密度）、燃料の温度、制御棒の有無、支持格子の有無を分岐として計算し、少数群定数のテーブルに
する。燃料の温度を入れるのは、等温温度係数が燃料のドップラーの効果を含むため。テーブルは MessagePack で書く。燃焼度の
軸を持つ大きな分岐テーブルの形式（HDF5 への移行を含む）は、M4 で設計し直す（[ADR-0011](0011-write-data-files-in-messagepack.md)）。M3 のテーブルは計算し直せば
作れるので、作り直しは重くない。

## 確認

まだ実装していない（M3 の作業）。Problem 5 の等温温度係数と臨界ホウ素濃度を、仕様書の実測値と KENO の値と
比べて確かめる。

## 帰結

支持格子の層の定数の作り方は #0011。
