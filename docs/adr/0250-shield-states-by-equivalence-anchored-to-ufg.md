# ADR-0250: 分岐の状態の自己遮蔽は、燃焼点ごとの公称の状態の UFG を基準に、等価原理で状態の変化だけを求める

## 背景

本番の形の 2A の分岐のテーブル（#0278。114 状態 × 27 燃焼点）は約 21〜22.5 時間の見込みで、そのうち自己遮蔽を解く状態（燃焼点 27 ×
減速材と燃料の温度の組 49 = 1,323 回）が約 15〜16.5 時間を占める（#0180 の「自己遮蔽を省いたときの誤差」）。1 回は 2A の 60 MWd/kg で
約 48.2 秒（Slurm 815。ADR-0249 の背景）。ビットで変えない直しは尽き、省く試み（燃焼点の間引き、減速材の軸の再利用）は誤差の
基準を作れなかった（#0180、ADR-0201 の案 M）。

ユーザーは、今の UFG を詰めるより、手法の違う速い方式を新しい機能として入れ、今の UFG を参照解にするほうがよいと提案した
（ユーザー 2026-11-13）。CLAUDE.md の「方針」の「自己遮蔽は UFG のまま、物理的に正しい改善で速くし」（ユーザー 2026-10-12）を見直す
話になる。既にある記録、文献、PSM との照合は #0285。

## 決定の要因

- 正確さ > 実行速度 > 保守（CLAUDE.md の「方針」）。速度のための近似は入力の項目にし、厳密な経路（今の UFG）を参照解として残す
- 特定の燃料の種類（典型は標準のウラン燃料の未燃焼）だけで精度のよい設定にしない。燃料の種類（ウラン、Gd、MOX、可燃性毒物、
  制御棒）、燃焼度、温度の分布、リングごとの自己遮蔽（リム効果）、共鳴の重なりで評価する（ユーザー 2026-11-13）
- 目安の誤差は ADR-0200 の 5 pcm（テーブルの点の k∞）。xlc の目標は ADR-0032 の ±100 pcm の全体で、自己遮蔽の近似に使える分は
  その一部
- ライブラリ（WIMS 69 群、ADR-0022。UFG の範囲 4 eV〜15.03 keV は 14 群）と形式を変えると、全核種のライブラリの作り直しと、
  それを deps にするすべての記録の再実行が要る

## 検討した案

時間は 2A の 60 MWd/kg の 1 状態（32 スレッド）。「見込み」は測っていない値。

- 案 A: 等価原理だけで遮蔽する（ADR-0023、ADR-0074 の計算を UFG の範囲にも当てる）。xlc で測った誤差は VERA 1B で −1887 pcm
  （UFG の重みのライブラリ。ADR-0068、2026-10-07）、AIC の 2G で −212 pcm（ADR-0142）、範囲の下の Pu-242 の群の捕獲 +11%（#0001）。
  文献でも、補正を持たない版は燃焼したピンで約 400 pcm、Gd と Pyrex の集合体の初期で約 −600 pcm（PSM-II）。商用コードは非公開の
  経験的な補正で埋める。時間の見込みは、Dancoff 係数 2.0 秒（#0180。減速材の状態ごとで、#0168 で燃焼点をまたいで持てる）と σ0 の
  反復で数秒以下。単独では精度の要因を満たさない
- 案 B: サブグループ法。文献の PWR の精度はモンテカルロと 50〜200 pcm の桁（APOLLO3 の Gd-UOX の 50 pcm 未満は要旨だけで、MPACT の
  直接の比較の数値は確かめていない）で、MOX の干渉に弱い（Liu & Martin）。xlc ではライブラリに群・温度ごとの準位と重みを足す形式の
  変更が要り、ADR-0068 が採らなかった準位のフィットと IR の λ を持つ。時間の見込みは、固定源の MOC を共鳴の群 14 × 準位 4 程度解き、
  黒体の Dancoff 係数（69 群で 2.0 秒）と同じ桁から数倍（MPACT の 2a で 8.2 秒）
- 案 C: ESSM。xlc の feat/essm（NR 近似、69 群）は 1B で −3080 pcm（ADR-0068）。文献の Polaris は KENO より 100〜200 pcm 低く
  （Gentry 2018）、リムの U-238 の吸収を 15% 少なく見積もる（Liu & Martin）。リング、温度の分布、干渉に補正（ESSM-X）が要る。時間の
  見込みは案 B と同じ桁（Polaris の Fast は 14 状態の平均で 11 CPU 秒）
- 案 D: 今の UFG のピンセルで共鳴積分や実効断面積の表を作り、格子では表を引く。表の軸は、Dancoff 係数（等価なセルの外径）、燃料の
  リングごとの温度、減速材の密度と温度、それに組成（燃焼の領域ごとの 116 核種）が要る。組成は履歴と燃料の種類で決まるので、燃料の
  種類と燃焼度の指標で表を作ると、決定の要因の「特定の燃料の種類に合わせ込まない」に反する。組成ごとに表を作り直すなら、1 表の点の
  数 × ピン 1 本約 40 スレッド秒（#0285 の照合）で、今の解き方より速くならない
- 案 E: UFG のままで計算の構造を変える。(E1) 燃焼点の間引き: 8 点で最大 22.8 pcm、誤差の基準が作れない（#0180）。(E2) 減速材の軸の
  再利用: −118.4〜+89.7 pcm（ADR-0201 の案 M）。(E3) 代表のピンを減らす: 燃焼点ではピンの組ごとに組成が違い（燃焼の領域 195）、
  同じ答えの体系が無い（#0180）。誤差は測っていない。(E4) 同じ系統の中で作りを PSM に寄せる（自由ガスを U-238 の補正に替える、固定の
  格子、孤立したペレットの CP の表、質量で核種をまとめる）: PSM は 1 本 0.233 秒、xlc は約 40 スレッド秒（#0285）。差の大きな部分は、
  xlc が精度のために選んだ自由ガス（静止した標的は −46.7〜−94.9 pcm。ADR-0209）、点の数、CP の 1e-9 で、どれも近似になる。PSM の
  精度（モンテカルロと約 100 pcm）は自己遮蔽の近似に使える分より大きい
- 案 F: UFG を基準の状態（燃焼点ごとの公称の減速材と燃料の温度）でだけ解き、ほかの状態は、基準の UFG の実効断面積に、同じ速い
  方法（等価原理）で求めた状態と基準の比を掛ける（採用）。速い方法の絶対値の誤差（案 A の数百 pcm）は比で打ち消し、残るのは速い
  方法が状態の変化（減速材の密度による Dancoff 係数、燃料の温度による Doppler の拡がり）を取り違える分。組成、リングの分布、共鳴の
  重なりの絶対値は、その燃焼点の実際の組成で解いた UFG が持つので、燃料の種類に合わせ込んだ表を持たない。案 E2 の −118.4〜+89.7 pcm
  は比を掛けない（変化を 0 とする）ときの誤差で、5 pcm に入れるには、速い方法が変化の 95% 以上を再現すればよい（再現するかは
  測っていない）。時間の見込みは、基準の UFG が燃焼点ごとに 1 回（27 × 48.2 秒 ≈ 0.36 時間）、ほかの状態は Dancoff 係数 2.0 秒と
  比の計算（見込みで 1 秒以下）で、1,296 回に約 0.9 時間。燃料の温度の 7 点ごとに基準を持つ形（減速材の軸だけを比で埋める）では、
  基準 189 回に約 2.5 時間。本番の形の 2A のテーブルは、約 21〜22.5 時間から、自己遮蔽を解く状態の約 15〜16.5 時間をこれに替えて、
  約 7〜10 時間の見込み（残りは MOC と、再利用する状態、微分の摂動）
- 案 G: 細かい共鳴の群の多群（文献の多群の方式の前提。MPACT の共鳴の群 17、DRAGON5 の SHEM 295 群）に替えて、案 B か C を単独で
  使う。群の構造と全核種のライブラリ、群の構造を前提にするすべての記録が変わる。精度は文献の 50〜200 pcm の桁で、xlc の UFG の
  精度より粗い

## 決定と理由

案 F を、分岐の状態の自己遮蔽の新しい方式として、入力で選べる形で入れる（proposed。方式はユーザーが決める）。

- 基準の状態: 燃焼点ごとに、減速材と燃料の温度を公称にした状態を今の UFG で解く（ADR-0201 の参照の状態と同じ作り方で、ホウ素の
  軸は ADR-0201 のとおり再利用）。制御棒の値は形状が変わるので、制御棒の値ごとに基準を持つ
- ほかの状態: 燃料のピンのリング・核種・群ごとに、σ(状態) = σ_UFG(基準) × σ_eq(状態) / σ_eq(基準)。σ_eq は、ADR-0074 の等価原理
  （ピンごとの Dancoff 係数、Carlvik の 2 項有理近似、Bondarenko の反復、リングの温度で引く）を UFG の範囲の群にも当てた値で、基準と
  状態で同じ式で求める。UFG の範囲の外は今のまま等価原理。SPH 因子は基準のものを使う（段 1 で、状態ごとの変化を測る）
- 差で埋める軸は、段 1（#0285 の段階の計画）の測定で決める。まず減速材の軸だけを差で埋め、燃料の温度の軸は燃料の温度の点ごとに
  基準を持つ形から始める（燃料の温度は Doppler の拡がりそのもので、ADR-0201 は燃料の温度の再利用を燃料の温度係数そのものの近似と
  して採らなかった）
- 既定は変えない（`every-state` と今の既定の `nominal-boron` を残す）。既定にするかは、段 1〜3 の測定の後にユーザーが決める
- 差の計算が基準を外れる燃料か軸の状態は UFG で解く（入力で選ぶ。黙って切り替えない）

理由:

- 案 A〜C と G は、xlc で測った値でも文献でも、単独の絶対値の誤差が数十〜数百 pcm で、xlc の UFG の精度（同じ核データの OpenMC と
  数十 pcm）を捨てる。補うのは経験的な補正（等価原理、ESSM）か、準位のフィット（サブグループ）か、群の構造の変更で、どれも ADR-0068 の
  判断の軸（評価済みデータだけから決まる）に反するか、ライブラリと記録の全体を変える
- 案 D は組成の軸を持てず、燃料の種類に合わせ込むことになる
- 案 E（同じ系統の中の作りの変更）は、xlc が精度のために選んだ自由ガス、点、CP を近似に戻すことが時間の差の大半を占める
  （#0285 の照合）。個々の近似の誤差は測っておらず、#0180 の続きで扱える
- 案 F は、燃焼点ごとの実際の組成で解いた UFG を基準に持つので、燃料の種類、燃焼度、リムの分布、共鳴の重なりの絶対値は UFG のまま。
  近似は状態の間の変化だけで、その誤差は、状態ごとに解き直した UFG（`every-state`）と同じ入力で比べて測れる。部品（Dancoff 係数の MOC、
  Carlvik の 2 項、Bondarenko の反復、`remix` の作り直しと検査。ADR-0074、ADR-0201）は既にあり、ライブラリの形式を変えない

「手法を変える」のは状態の間の変化の求め方（UFG から等価原理の比へ）で、基準の UFG の作り（自由ガス、点、CP）は変えない。基準の
UFG を速くすることは同じ系統の中の作りの変更で、この ADR では決めない（案 E4。#0180）。

### 帰結

- 実装は段 1 から（#0285）。決めた時点で実装は無い
- ライブラリの形式は変わらない。読めなくなる出力は無い
- 燃料の種類ごとの弱い所（見込み。段 1 で測る）: Gd のピン（強い空間の自己遮蔽で、ピンに 1 つの σ0 の比がリングの変化を取り違え
  うる）、MOX（Bondarenko の反復の干渉の変化）、可燃性毒物と制御棒（塊と棒の遮蔽の変化。AIC の棒は ADR-0142 の UFG で、その比の
  作り方は段 1 で決める）、温度の分布（燃料の温度の軸の比。文献では等価原理は非一様な温度で数百 pcm 外れる）、リム（比はリングに
  同じ σ0 の変化を当てるので、リングの分布の変化を落とす）
- 燃焼の領域（ADR-0244、ADR-0245）: 基準の UFG は燃焼の領域ごとの組成で解くので変わらない。比は燃焼の領域のリングごとに掛ける
- 微分の摂動（ADR-0247、ADR-0249）: ADR-0249 の固定（状態の自己遮蔽のまま作り直す）はそのまま使える。比で摂動の暗黙の効きの一部を
  入れる形は段 5 の後に測る
- CLAUDE.md の「方針」の自己遮蔽の項は、方式が決まった後に書き直す

### 確認

この ADR の時点では測っていない（2026-11-13）。今の入力で等価原理だけの経路も比の経路も選べず（UFG の範囲の群は、ライブラリに
ポイントワイズのデータが無いと止まる。crates/lattice/src/ufg.rs の `UfgError::NoPointwise`）、feat/essm は 2026-10-07 の main から
分かれた古いコードで、今のライブラリでは動かない見込み（確かめていない）。段 1 の測定で、案 F の誤差と時間を `every-state` と比べて
記録する。
