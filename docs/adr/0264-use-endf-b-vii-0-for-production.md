# ADR-0264: 本番の核データを ENDF/B-VII.0 にする

## 背景

本番の核データは ENDF/B-VIII.0 である（ADR-0020）。ADR-0020 は、ほかの評価済みライブラリと比べた記録を持たない。燃焼の検証は同じ
VIII.0 の OpenMC と比べていて、核データそのものの偏りは xlc と参照の両方に同じように入るので、この比較には表れない。偏りが表れるのは、
実機の炉心追跡（Problem 9 の臨界ホウ素濃度）と比べるときである。

VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告がある。次は 2026-11-20 に本文を開いて読んだもので、PDF は `references/papers/`、
URL と sha256 は docs/specs.sha256 にある。

- ORNL（Kim、Wieselquist、J. Nucl. Eng. 2(4), 2021。`kim-wieselquist-2021-endfb80-vs-71-lwr.pdf` の 3.1.3 節）: VERA の燃焼ベンチマーク問題を
  Serpent で解き、VIII.0 は VII.1 より高い燃焼度で k を低く見積もる。共鳴の上方散乱（DBRC）を入れない計算で、60 MWd/kgU での差は k で
  約 400 pcm、反応度で 650 pcm。燃焼度 0 では U-238（+230 pcm）、U-235（−210 pcm）、O-16（−120 pcm）が打ち消し合い、燃焼が進むと Pu-239 の
  寄与が負に伸びる。DBRC を入れると、HFP でさらに 150〜200 pcm 低くなる。同じ著者の CSEWG 2020 の資料
  （`kim-csewg2020-endfb80-depletion.pdf`）は、反応度の差を 647 pcm、効く核種を Pu-239、U-235、O-16、U-238、Pu-242、Pu-240 の順とする
- ENDF/B-VIII.1 の公開論文（`endfb81-2025-arxiv-2511.03564.pdf` の XIV.D）:
  - Serpent の TMI-1 のピンセル（XIV.D.1）: VIII.0 は VII.1 より k が約 500 pcm 低く、差は燃焼度に対して 200 pcm 以内でほぼ一定。VIII.1 は
    燃焼の初めに VII.1 より約 300 pcm 低く、30 MWd/kg で VII.1 に近づく。VII.1 を基準にする理由を、産業界で日常の炉の解析に使われ
    性能がよいためとする
  - 実測に基づくベンチマーク（IRPhE/DUKE）: 燃焼に伴う反応度の低下は、VII.1 が 1σ 付近、VIII.0 と VIII.1 が 2σ 以内
  - CASMO5（XIV.D.3、Studsvik）: 途中の版（β1）は 0〜20 MWd/kg で VII.1 より最大 600 pcm 低く、原因は Pu-239 の評価。最終版は VII.1 の性能を
    実質的に回復したとし、臨界実験と燃焼の間の妥協と書く。VII.1 の CASMO5 のライブラリが、運転中の炉の測定と最もよく合うと書くのはこの節
  - 核分裂あたりのエネルギーの仮定が、燃焼に伴う反応度の傾きに最も強く効く（XIV.D.4）
- VIII.1 の途中の版（β2）の検証の資料（`endfb81-beta2-multi-application-validation.pdf`）: β2 は VIII.0 より高い燃焼度で反応度が高いが、
  PWR の高い燃焼度で k を低く見積もる懸念が残るとする。最終版についての同じ形の検証は読んでいない
- Studsvik（Ferrer、Wemple、Mini-CSEWG 2023。`ferrer-wemple-mini-csewg-e8r1-casmo5.pdf`）: CASMO5 の既定のライブラリは VII.1 で、VII.0 の
  ライブラリも持つ
- ORNL（Procop、CSEWG 2026 年 1 月。`procop-csewg2026-snf-validation.pdf`）: 使用済燃料の核種の量の計算と実測の比で、U-235 は VIII.0 が高い
  燃焼度で 6% の過小評価、Pu-239 は VII.1、VIII.0、VIII.1 でおおむね一致。VIII.1 の U-235 は図だけで、本文の文字からは読めない

2 つの資料は、VIII.0 と VII.1 の差の燃焼度への依り方で食い違う（ORNL の論文は燃焼度 0 でほぼ打ち消し合い、燃焼とともに広がる。VIII.1 の
論文の TMI-1 のピンセルは初めから約 500 pcm でほぼ一定）。体系（濃縮度、ホウ素）と DBRC の扱いが違い、どちらが xlc の本番の条件に近いかは
確かめていない。読んだ資料に、VII.0 を燃焼で比べた記述は無い。

読めていない資料: IAEA の INDC(NDS)-0893（<https://www-nds.iaea.org/publications/indc/indc-nds-0893.pdf>。U-238 の共鳴領域の捕獲を原因に置くと
される。取得が HTML になった）、VERA の問題 1〜5 を VII.0 と VII.1 で解いた UNIST の MCS の論文
（<https://scholarworks.unist.ac.kr/bitstream/201301/30668/2/000526899400002.pdf>。同じ）、VERA の 2B と 2P の燃焼を VII.1 の MCNP で解いた論文
（J. Theor. Appl. Phys.、<https://oiccpress.com/jtap/article/view/7924>。未取得）。

VERA の参照解の版:

- 仕様書（`references/vera/spec.txt`）の問題 1〜5 の参照解は KENO-VI の ENDF/B-VII.0 で、付録に VI.8 の結果がある。VII.1 の参照解は無い
- 仕様書の外では、問題 6、7 の MC21 の解が VII.1（`mc21-ctf-vera-problems-6-7.pdf`）。VERA の燃焼ベンチマークを VII.1 の Serpent で解いた
  結果が上の ORNL の論文にある（数値の表があるかは確かめていない）
- Problem 9 の参照は実測の臨界ホウ素濃度で、版に依らない

xlc の側で確かめたこと（2026-11-20、手元の実行。ステージではない）:

- 燃焼チェーンは 4 つの版（VII.0、VII.1、VIII.0、VIII.1）から作れる（ADR-0262、ADR-0263。数は #0303 の経緯）
- 中性子のファイルの読み込み: examples/vera/xs.toml の `endf-directory` だけを VIII.1、VII.1 のディレクトリに替え、main 5e67e41e の
  `bin/xs nuclide` で 1B の主な 16 核種（U-234、U-235、U-236、U-238、O-16、H-1、B-10、B-11、Zr-90、Zr-91、Zr-92、Zr-94、Zr-96、Fe-56、Cr-52、
  Sn-120。熱散乱は VIII.0 のまま）を処理し、どちらの版も 16 核種とも終了コード 0 で終わった。VII.0 は VERA の格子の 60 核種の検証用
  ライブラリがある（ADR-0175）。Pu と核分裂生成物は、VIII.0 のほかの版では試していない
- 核分裂収率と崩壊データの版ごとの違い（物質ごとに MF8 の行の列 1〜66 が同じかを比べた。文字の一致で、数値の比較ではない）: 収率の
  31 核種は、VII.1 と VIII.0 が 31 とも同じ、VII.0 と VII.1 は Pu-239 だけが違い、VIII.0 と VIII.1 は 31 とも違う。崩壊データは、VII.0 と VII.1 に
  共通の 3,723 核種のうち同じものが 1、VII.1 と VIII.0 の 3,821 核種のうち違うものが 97、VIII.0 と VIII.1 では 10。違いが値か書き方かは
  確かめていない

## 検討した案

- 案 A（VIII.0 のまま）: ライブラリ、チェーン、参照解が揃っていて、作り直しが要らない。燃焼で反応度を低く見積もるという報告があり
  （背景）、VIII.1 の論文は、調整なしには産業界が受け入れられないと書く
- 案 B（VII.0。採用の候補）: 仕様書の問題 1〜5 の参照解（k とピン出力の表）と同じ版で、本番と検証が 1 つの版で済む（今は本番が VIII.0、
  検証用が VII.0 の 2 つ。ADR-0175）。xlc が VERA の格子の 60 核種を読めると分かっている。短所は、燃焼で比べた文献が読んだ範囲に無いこと、
  崩壊データと Pu-239 の収率が VII.1 と違うこと（背景）、4 つの中で最も古いこと
- 案 C（VII.1）: 文献が基準に置く版で、軽水炉の燃焼での実績がある（背景）。短所は、仕様書の参照解と版が合う問題が無くなること
  （問題 6、7 の MC21 と、他のコードの論文の値だけになる）
- 案 D（VIII.1）: VIII.0 の燃焼の問題を直す対象にした版。短所は、燃焼の初めに VII.1 より約 300 pcm 低いと公開論文が書くこと、最終版の
  独立の検証を読めていないこと、途中の版に同じ問題が残っていたこと（背景）

## 決定と理由

案 B（VII.0）を候補にし、下の「確認」の比較の後に確定する。確定するまで、本番は VIII.0 のままにする。

- 手法の検証は同じ核データの参照と比べる（ADR-0175）。数値の表とピン出力の揃った公式の参照解は VII.0 だけなので、本番を VII.0 にすると
  本番の結果をそのまま参照解と比べられる。親のセッションは始め VII.1 を推し、ユーザーは、VII.1 の VERA の参照解が無いなら VII.0 を選ぶと
  述べた（ユーザー 2026-11-20）。その前提を仕様書と文献で確かめた結果が背景の「VERA の参照解の版」で、親のセッションが推奨を VII.0 に改めた
- VII.0 が燃焼の反応度で VII.1 と同じ側にいることは、文献では確かめられない。4 つの版のピンセルの燃焼を xlc で比べ、VII.0 と VII.1 の差が
  VII.1 と VIII.0 の差より十分小さいことを見てから確定する。小さくなければ、案 C と比べ直す
- 燃焼の参照解は仕様書に無いので、どの版でも OpenMC で作る（版に依らない費用）
- 同じ VII.0 でも、OpenMC と KENO-VI の k には約 100〜180 pcm の差がある（#0302）。版を揃えても、KENO-VI との k の差がそのまま手法の差には
  ならない

### 帰結

- 確定したら ADR-0020 を置き換える。xlc のライブラリ、燃焼チェーン、燃焼の履歴、テーブル、OpenMC の参照解（燃焼を含む）を VII.0 で
  作り直す。本番の作り直しの前に確定する（docs/plans/upstream-error-budget.md の #0303 の行）
- 燃焼チェーンの全核種の VII.0 のライブラリはまだ無い。チェーンと xs で、天然の元素の評価を当てる核種を揃える（ADR-0262 の帰結）
- 核分裂の Q 値は版で変わるので、出力の規格化（#0293 の項目 3）の決定と合わせる
- k の手法の差を何と比べて見るか（#0302）は、本番の版で選択肢が変わるので、合わせて決める

### 確認

確定の前に行うこと（まだ行っていない）:

- 燃焼チェーンの全核種を、4 つの版の中性子のファイルから xs で処理できること
- 1 つのピンセルの燃焼で、4 つの版の反応度の差を、Problem 9 の範囲（約 17 MWd/kg）と 60 MWd/kg までの燃焼度ごとに測ること。規格化の定義を
  そろえる
- 核分裂収率と崩壊データの版ごとの違いを、数値で比べること（ユーザーは、機械的に確かめられる形を求めた。ユーザー 2026-11-20）
