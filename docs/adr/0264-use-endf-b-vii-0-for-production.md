# ADR-0264: 本番の核データを ENDF/B-VII.0 にする

## 背景

本番の核データは ENDF/B-VIII.0 である（ADR-0020）。ADR-0020 は、ほかの評価済みライブラリと比べた記録を持たない。燃焼の検証は同じ
VIII.0 の OpenMC と比べていて、核データそのものの偏りは xlc と参照の両方に同じように入るので、この比較には表れない。偏りが表れるのは、
実機の炉心追跡（Problem 9 の臨界ホウ素濃度）と比べるときである。

VIII.0 が軽水炉の燃焼で反応度を低く見積もるという報告がある。次は 2026-11-20 に本文を開いて読んだもので、PDF は `references/papers/`、
URL と sha256 は docs/specs.sha256 にある。

- ORNL（Kim、Wieselquist、J. Nucl. Eng. 2(4), 2021。`kim-wieselquist-2021-endfb80-vs-71-lwr.pdf`）: VERA の燃焼ベンチマーク問題を Serpent で解き、
  VIII.0 は VII.1 より高い燃焼度で k を低く見積もる。3.1.3 節は、共鳴の上方散乱（DBRC）を入れない計算で、60 MWd/kgU での差を k で
  約 400 pcm、反応度で 650 pcm とする。結論の節は、60 GWd/MTU で約 −800 pcm とし、この過小評価は発電所のデータとの比較でも見え、VIII.0 を
  軽水炉の解析に勧められないと書く（650 と 800 の違いの理由は本文から読み取れていない）。燃焼度 0 では U-238（+230 pcm）、U-235（−210 pcm）、
  O-16（−120 pcm）が打ち消し合い、燃焼が進むと Pu-239 の寄与が負に伸びる。DBRC を入れると HFP でさらに 150〜200 pcm 低くなるが、燃焼の
  履歴を通すと反応度は上がり、燃焼の初めの反応度が直れば高い燃焼度の低さは問題にならないかもしれないとも書く
- 同じ著者の CSEWG 2020 の資料（`kim-csewg2020-endfb80-depletion.pdf`）: VERA（MPACT の 51 群）で 3.1 wt% のピンの核種を 1 つずつ VII.1 に替えた
  感度解析で、反応度の差は 647 pcm（核種ごとの和は 654 pcm）。効く核種は Pu-239、U-235、O-16、U-238、Pu-242、Pu-240 の順。崩壊データと
  核分裂収率を VII.1 のものに替えても影響は無いとする。VII.1 も高い燃焼度で k を低く見積もるというのが一般の理解で、DBRC を入れるとさらに
  低くなるとも書く
- ENDF/B-VIII.1 の公開論文（`endfb81-2025-arxiv-2511.03564.pdf` の XIV.D）:
  - Serpent の TMI-1 のピンセル（XIV.D.1）: VIII.0 は VII.1 より k が約 500 pcm 低く、差は燃焼度に対して 200 pcm 以内でほぼ一定。燃焼に伴う
    反応度の低下で比べると、VIII.0 には約 −500 pcm の振れがあり、VIII.1 では VII.1 との差がほぼ一定になったとする。VIII.1 は
    燃焼の初めに VII.1 より約 300 pcm 低く、30 MWd/kg で VII.1 に近づく。VII.1 を基準にする理由を、産業界で日常の炉の解析に使われ
    性能がよいためとする
  - 実測に基づくベンチマーク（IRPhE/DUKE）: 燃焼に伴う反応度の低下は、VII.1 が 1σ 付近、VIII.0 と VIII.1 が 2σ 以内
  - Shift（XIV.D.2）: VERA の燃焼ベンチマークの 1C のピン（3.1 wt%、燃料 900 K）を解き、VIII.1 は VIII.0 から大きく改善し、高い燃焼度の
    臨界性が VIII.0 より VII.1 に近いとする（Figure 206 の k の差。図から読むと、VIII.1 − VII.1 は燃焼度 0 の付近の約 −15〜−75 pcm から
    約 5 MWd/kgU までに約 −150 pcm まで負に広がり、その後はゆっくり負に広がる。隣り合う点は約 50 pcm ばらつき、統計誤差は本文に無い）。
    TMI-1 のピンセルとの傾向の違いは、濃縮度とホウ素濃度の違いによると書く
  - CASMO5（XIV.D.3、Studsvik）: 途中の版（β1）は、PWR の集合体の燃焼で 0〜20 MWd/kg に VII.1 より最大 600 pcm 低く、原因は Pu-239 の評価。最終版は VII.1 の性能を
    実質的に回復したとし、臨界実験と燃焼の間の妥協と書く。VII.1 の CASMO5 のライブラリが、運転中の炉の測定と最もよく合うと書くのはこの節
  - 核分裂あたりのエネルギーの仮定が、燃焼に伴う反応度の傾きに最も強く効く（XIV.D.4）
- VIII.1 の途中の版（β2）の検証の資料（`endfb81-beta2-multi-application-validation.pdf`）: β2 は VIII.0 より高い燃焼度で反応度が高いが、
  PWR の高い燃焼度で k を低く見積もる懸念が残るとする。VII.1 も高い燃焼度で反応度が低いと書く。最終版についての同じ形の検証は読んでいない
- Studsvik（Ferrer、Wemple、Mini-CSEWG 2023。`ferrer-wemple-mini-csewg-e8r1-casmo5.pdf`）: CASMO5 の既定のライブラリは VII.1（E7R1）。今の
  ライブラリの表は VII.1、VIII.0、VIII.1 を挙げ、VII.0 は早くに取り入れた版の一覧にあるだけ。β1 の Pu-239 を JENDL-4 の評価に替えると VII.1 に
  近づく。結論は、データとの比較で VII.1 が最もよい予測を与えるとする
- ORNL（Procop、CSEWG の資料。表紙の日付は 2025 年 1 月 9 日と CSEWG 2026。`procop-csewg2026-snf-validation.pdf`）: 使用済燃料の核種の量の計算と
  実測の比で、U-235 は VIII.0 が高い燃焼度で 6% の過小評価、Pu-239 は比べたライブラリの間でおおむね一致。比べた版は VII.1、VIII.0、VIII.1。
  核種ごとの版の違いは図で示され、本文の文字からは読めない

VIII.0 と VII.1 の差の燃焼度への依り方は、体系で違う（VERA の 1C のピンは燃焼度 0 でほぼ打ち消し合って燃焼とともに広がり、TMI-1 の
ピンセルは k の差が初めから約 500 pcm でほぼ一定）。VIII.1 の論文は、傾向の違いを濃縮度とホウ素濃度の違いによるとする。xlc の検証に使う
体系は VERA の 1C のピンに近い。読んだ資料に、VII.0 を燃焼で比べた記述は無い。基準に置かれる VII.1 にも、高い燃焼度で k を低く見積もる
という記述がある（上の CSEWG 2020 と β2 の資料）。

読めていない資料: IAEA の INDC(NDS)-0893（<https://www-nds.iaea.org/publications/indc/indc-nds-0893.pdf>。U-238 の共鳴領域の捕獲を原因に置くと
される。取得が HTML になった）、VERA の問題 1〜5 を VII.0 と VII.1 で解いた UNIST の MCS の論文
（<https://scholarworks.unist.ac.kr/bitstream/201301/30668/2/000526899400002.pdf>。同じ）、VERA の 2B と 2P の燃焼を VII.1 の MCNP で解いた論文

## 決定と理由

案 B（VII.0）を候補にし、下の「確認」の比較の後に確定する。確定するまで、本番は VIII.0 のままにする。

全核種の MOX のセルで下の 2 つ目の項の条件が成り立たないので、案 C との比べ直しを「検討した案」に書いた。どちらにするかはユーザーの判断を
待つ（2026-11-21）。

- 手法の検証は同じ核データの参照と比べる（ADR-0175）。問題 1〜5 の全部に k とピン出力の表のある公式の参照解は VII.0 だけ（VI.8 の結果は付録に、問題 1、2 の一部、4-2D だけ）なので、本番を VII.0 にすると
  本番の結果をそのまま参照解と比べられる。親のセッションは始め VII.1 を推し、ユーザーは、VII.1 の VERA の参照解が無いなら VII.0 を選ぶと
  述べた（ユーザー 2026-11-20）。その前提を仕様書と文献で確かめた結果が背景の「VERA の参照解の版」で、親のセッションが推奨を VII.0 に改めた
- VII.0 が燃焼の反応度で VII.1 と同じ側にいることは、文献では確かめられない。4 つの版のピンセルの燃焼を xlc で比べ、VII.0 と VII.1 の差が
  VII.1 と VIII.0 の差より十分小さいことを見てから確定する。小さくなければ、案 C と比べ直す
  - 結果（背景の 2 つの表。VII.1 基準の反応度の差の絶対値を、VII.0 / VIII.0 の順に pcm で並べる）: 65 核種の 1C は 36 の燃焼点のすべてで VII.0 の
    差が小さい（0、10、30、60 MWd/kg で 4 / 103、17 / 215、105 / 436、185 / 706）。全核種の U と Gd は 0、10、30、60 MWd/kg で VII.0 の差が小さい
    （U は 6.3 / 93.7、30.8 / 209.5、70.2 / 508.0、104.7 / 833.3、Gd は 38.7 / 141.5、30.5 / 241.7、72.7 / 526.8、101.7 / 841.8）。全核種の MOX は
    0、10 MWd/kg で VII.0 の差が小さく（48.4 / 238.0、57.9 / 157.4）、30、60 MWd/kg で大きい（134.6 / 10.4、257.0 / 195.8）。41 の燃焼点
    （JSON の `reactivity_pcm`）で VII.0 の差が VIII.0 の差以上になるのは、MOX の 20 MWd/kg から先のすべての点と、Gd の 0.5〜1.5 MWd/kg の
    4 点（VIII.0 の差が正から負へ符号を変える前後。VII.0 +103.5〜+107.4、VIII.0 +81.3〜−50.4 pcm）で、U には無い。MOX の 30、60 MWd/kg では
    条件は成り立たない。差の小さい点で「十分」に当たるかの線は決めていない
- 燃焼の参照解は仕様書に無いので、どの版でも OpenMC で作る（版に依らない費用）
- 同じ VII.0 でも、OpenMC と KENO-VI の k には約 100〜180 pcm の差がある（#0302）。版を揃えても、KENO-VI との k の差がそのまま手法の差には
  ならない

### 帰結

- 確定したら ADR-0020 を置き換える。xlc のライブラリ、燃焼チェーン、燃焼の履歴、テーブル、OpenMC の参照解（燃焼を含む）を VII.0 で
  作り直す。本番の作り直しの前に確定する（docs/plans/upstream-error-budget.md の #0303 の行）
- 燃焼チェーンの全核種の VII.0 のライブラリはまだ無い。チェーンと xs で、天然の元素の評価を当てる核種を揃える（ADR-0262 の帰結）
- 核分裂の Q 値は版で変わるので、出力の規格化（#0293 の項目 3）の決定と合わせる
- k の手法の差を何と比べて見るか（#0302）は、本番の版で選択肢が変わるので、合わせて決める

### 確認

確定の前に行うこと（1 つ目は 565 K の 1 点だけを行った）:

- 燃焼チェーンの全核種を、4 つの版の中性子のファイルから xs で処理できること。燃焼のライブラリの 65 核種は 4 つの版のどれでも処理できた。
  全評価は、評価の誤りを宣言すると 565 K の 1 点の `xs nuclide` を通る（背景。宣言の要る評価は「検討した案」の表）。本番の温度で止まるかと、
  修正の前の xs で通った評価を今の main で通し直すことは残る（背景の 2 つの走査の限界）
- 1 つのピンセルの燃焼で、4 つの版の反応度の差を、Problem 9 の範囲（約 17 MWd/kg）と 60 MWd/kg までの燃焼度ごとに測ること。規格化の定義を
  そろえる。入力とステージは examples/depletion/dvc.yaml の lattice-1C-version と compare-depletion-versions
  （examples/depletion/verification.md の「版ごとのピンセルの燃焼」）。2026-11-20 に測った（背景の表）。どの版も、出力をそのチェーンの
  核分裂の Q 値で規格化した（#0293 の項目 3 の定義は決めていない）。2026-11-21 に、全核種を輸送した U、MOX、Gd のセルの燃焼でも測った
  （背景の 2 つ目の表。examples/depletion/verification.md の「核データの 4 つの版の、全核種を輸送した燃焼の差（試行）」、比べたのは 1ad312e0、
  main へのマージは 147b7a34e）
- 核分裂収率と崩壊データの版ごとの違いを、数値で比べること（ユーザーは、機械的に確かめられる形を求めた。ユーザー 2026-11-20）。
  2026-11-20 に `examples/depletion/compare_chain_versions.py` で比べた（背景。examples/depletion/verification.md の「版ごとの燃焼チェーン」）。
  違いが燃焼の反応度にどれだけ効くかは、2 つ目のピンセルの燃焼で見る
