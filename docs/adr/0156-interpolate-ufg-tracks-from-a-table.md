# ADR-0156: UFG の減速計算の飛程を、物質ごとの全断面積の格子の表から内挿する

## 背景

ピンごとの等価なセルの UFG の減速計算（ADR-0068）は、エネルギーの格子点（VERA 2A で 344,958 点、1B で 342,106 点）ごとに、円筒のセルの
衝突確率法で飛程 W を求め直す。VERA 2A の 1 状態（16 スレッド、排他のジョブ）で、自己遮蔽は 95.2 秒（出力を変えない
高速化の後。e9ca8d55、分岐点 bf7d2439、2026-10-13）、MOC は 7.4 秒で、高速化の前（db8530c0）に 1B の 1 ピンを 1 スレッドで測ると UFG の時間の 97% が衝突確率だった（#0039 の
経緯）。Problem 5 の 3D の分岐（8 状態 × 多数の格子）と #0070 の測り直しの前に、1 状態の自己遮蔽を 10〜20 秒台にしたい。

- 精度: k とピン出力が、格子点ごとに求める方法と区別できない程度（目安で 0.1 pcm、ピン出力 1e-6）に収まり、表の細かさに
  ついての収束を示せること
- 速さ: 2A の 1 状態の自己遮蔽を 10〜20 秒台にする
- 保守: 表の細かさは入力で選べるパラメータ 1 つで、既定値はこの ADR で決める

等価なセルのリングは、燃料（同じ組成と温度の 5 リング）、真空のギャップ、被覆管、減速材と、支持格子の枠（減速材の外の
リング。ADR-0088）からなり、同じ物質のリングは同じ全断面積を持つ。W は物質ごとの全断面積 Σ_m（2A と 2Q で燃料、
Zircaloy、水の 3 つ。2Q の枠は被覆管と同じ物質）だけの関数になる。

## 検討した案

### (a) 物質ごとの全断面積の格子の表から内挿する

物質ごとの ln Σ の等間隔の格子（10 倍あたり N 点。範囲はそのピンの UFG の格子点の Σ の最小から最大まで、1 物質に
最低 4 点）の点の組で W を求め、4 点の Lagrange 補間（次元ごとの積）で内挿する（PEACO/SRAC の衝突確率の表と同じ考え方）。
内挿するのは R_ij = W_ij Σ_j（真空のリングは W_ij）で、真空でない列についての R の行の和は体積 V_i、補間の重みの和は 1 なので、
中性子の保存は丸めの範囲で保たれる。試行はブランチ perf/0039-cp-table（分岐点は main の bf7d2439。da796a34、入力は 2e58062f と f7362b66 の `trials/table/`）。
結果（xlc の `lattice`、16 スレッド。2A、2Q、2G の時間は排他のジョブ 288〜290 と 294、2026-10-13。比べる基準は格子点ごとに
求めたもの: 2A は e9ca8d55 のジョブ 288 と db8530c0 のジョブ 286 の 1 本目（どちらも分岐点 bf7d2439）で、出力はバイト単位で同じ。2Q と 2G は da796a34 の既定（格子点ごと）の
ジョブ 290 と 294。1B は手元の走行で、時間は書かない）:

k の差は Δk/k で、「0（6 桁）」はログの 6 桁の k が同じ（|Δk| < 1e-6、k ≈ 1.18 で約 0.08 pcm 未満）。媒質の全断面積と吸収断面積の差は、格子全体を
細かい群のまま均質化した媒質（`medium`）の全断面積と、全断面積から P0 の散乱の行の和を引いた吸収断面積の、群ごとの
相対差の最大（2Q の吸収は求めていない）。N を倍にするごとに差は約 1/16 になり（4 点の
補間の 4 次の収束）、N = 16 で k は区別できず、ピン出力の差は OpenMC の統計誤差（中央値 0.07%）の 2A で 1e-4 倍以下、2Q で約 1e-4 倍、2G で約 2e-4 倍（統計誤差は 2A〜2K と 2Q の中央値で比べた）。
2A の N = 16 の自己遮蔽 12.9 秒は、Dancoff 係数 2.1 秒、塊の遮蔽 2.2 秒、ピン 39 本の約 8.5 秒からなる。1 ピンの中の内訳は、
1B を 1 スレッドで測ると（da796a34、分岐点 bf7d2439、排他のジョブ 299）UFG 1.91 秒のうち、表の作成と Σ の範囲を求める前処理が 0.71 秒、
格子点ごとの逐次の減速の反復が 0.79 秒、内挿が 0.30 秒、ポイントワイズの断面積の補間が 0.11 秒（格子点ごとに求める
9518ec5a では UFG 38.1 秒、同じジョブ）。
N = 8 が N = 16 より速い原因の候補は表の作成の差だが、N = 8 の内訳は測っていない。

### (b) 表をピンの間や分岐の状態の間で共有する

表をピンの間や分岐の状態の間で共有する。表はセルの形（ピンごとの等価なセルの外半径 R を含む）と、物質ごとの Σ の
範囲で決まる。R はピンごとに Dancoff 係数から決まり、2A の代表のピン 39 本はみな違うので、共有するには R を表の次元に
足す（4 次元）。分岐の状態の間では、減速材の密度で R と Σ の範囲が、燃料の温度で燃料の Σ の範囲が変わるので、R と Σ の
範囲を状態の全体で覆う表にすれば共有できる。上の内訳（1B の UFG 1.91 秒）で表の作成と前処理は約 4 割で、R を 8 点とした共有の表（6,600 × 8 点、ピン 8 本分の作成）なら
その大半を省ける。一方で、4 次元の内挿は点の組が 64 から 256 になり、内挿（約 16%）が約 4 倍になるので、差し引きの効果は
小さい見込みで、量は見積もっていない（試していない）。
R の内挿の精度は測っていない

### (c) Dancoff 係数の近いピンをまとめる

Dancoff 係数の近い代表のピンをまとめ、先に解いたピンの結果を使う（試行: perf/0039-cp-table の 94968942、入力の
`dancoff-tolerance`。(a) の N = 16 と組み合わせ、排他のジョブ 291、2026-10-13）。差は格子点ごとに求めた方法から:

| 群ごとの Dancoff 係数の差の上限 | 解くピン | 自己遮蔽 | k の差    | ピン出力の差の最大 |
| ------------------------------- | -------- | -------- | --------- | ------------------ |
| なし（(a) の N = 16）           | 39       | 12.9 秒  | 0（6 桁） | 6.0e-8             |
| 0.001                           | 19       | 8.0 秒   | −0.34 pcm | 7.6e-6             |
| 0.003                           | 13       | 8.3 秒   | +0.59 pcm | 3.0e-5             |
| 0.01                            | 7        | 7.4 秒   | +8.0 pcm  | 2.7e-5             |
| 0.03                            | 2        | 5.6 秒   | +1.3 pcm  | 8.1e-4             |

k の差は上限について単調でなく（0.01 で +8 pcm、0.03 で +1.3 pcm）、差の小さい上限があるのは打ち消し合いが候補だが、確かめていない。速さは
(a) だけの 12.9 秒が 5.6〜8.3 秒になるだけで、(a) より 2〜4 桁大きいピン出力の差を持ち込む

### 弦の求積の点を減らす（#0044）

弦の求積を小区間あたり 16 点から 8 点にする（#0044）。2B の自己遮蔽は 182 秒から 118 秒になったが、黒い燃料で求積の
基準（1e-9）を満たさない。(a) では衝突確率を求める回数がピンあたり約 345,000 から 6,600 になるので、逆に求積の点を増やして精度を
上げる余地ができる

### UFG のエネルギーの格子を間引く（#0046）

UFG のエネルギーの格子を間引く（#0046）。1B で点を 342,106 から 95,222 にして自己遮蔽 4.9 秒が 2.1 秒、k の差 +0.5 pcm
だったが、いまの格子が点の配置について収束しておらず（#0002）、精度の基準がない。(a) の後に残る逐次の減速の反復を
減らすのにも効くので、#0002 の後に見直す

### 出力を変えない高速化だけにする

出力を変えない高速化だけにする。#0039 の 3 つのコミット（Ki3 の行ごとの計算、Hermite 補間の係数の表、減速の反復の
作業用の配列の使い回し）で、2A の自己遮蔽は同じ日の測定で 119 秒から 95.2 秒（ジョブ 286 と 288）で、目標に届かない。
ジョブ 286 は手元の 1 スレッドの走行と重なったので、119 秒は大きめの候補がある（1f4fcaaf の 110 秒は examples/vera/verification.md の 1ee38bd6 より前の版）

## 決定と理由

(a) を採り、既定の細かさを 10 倍あたり 16 点とする（ユーザーの決定、2026-10-14）。燃料のピンと塊の棒の等価なセルの
UFG の減速計算は、どちらも表から内挿する。格子計算の入力の `track-table` で細かさ（正の整数）を選べ、`track-table = false`
で格子点ごとに求める（表の検証の基準）。物質は、組成（核種、温度、個数密度）が同じリングをまとめたもので、範囲はそのセルの
UFG の格子点の全体での全断面積の最小と最大である。2A と 2Q で、自己遮蔽は 95.2 秒と 165 秒から 12.9 秒と
13.6 秒になり、k はログの 6 桁で変わらず、ピン出力の差は 1e-7 以下で、細かさについて 4 次で収束することを示せる。
(c) は (a) に足しても 12.9 秒が 5.6〜8.3 秒になるだけで、ピン出力に 7.6e-6〜8.1e-4 の差を持ち込み、差が上限について単調でないので
採らない。(b) は (a) の次の段として、R の内挿の精度を測ってから決める（試していない）。

## 帰結

- 試行のブランチ perf/0039-cp-table は、実装のマージの後に消す（ユーザーの決定）。上の表の試行のコミット（da796a34、
  94968942、2e58062f、f7362b66）は main から辿れなくなり、根拠はこの ADR の表の数値として残る
- 出力が変わる（2A でピン出力 6e-8、媒質の全断面積 5e-7）ので、記録（examples/vera/verification.md）の xlc の k とピン出力は
  測り直しになる。実装のブランチでは時間だけを測り直し、k とピン出力は、DVC の段階の deps を release の実行ファイルに替えた
  後にまとめて流す（ユーザーの決定、2026-10-14）
- 表の点の衝突確率は、格子点ごとと同じ求積で求める。求める回数が約 1/50 になるので、#0044 の求積の精度を上げる余地ができる
- 内挿の範囲は、ピンごとに UFG の格子点の Σ の最小と最大から決めるので、範囲の外の Σ は現れない（現れればエラー）。Σ が
  有限でない物質は、格子点ごとに求めるときと同じエラーで止める。Σ が 0 になる物質（ln Σ の格子で覆えない）と、格子点の組の
  数が UFG の格子点の数以上になる表（格子点ごとより遅く、メモリも大きい）は、作る前にエラーで止め、`track-table = false` か
  小さな細かさを示す
- 2G（AIC の棒）では、N = 16 の自己遮蔽 40.0 秒のうち塊の遮蔽が 31.4 秒（格子点ごとでは 39.4 秒）で、残りの大半になる。棒の
  等価なセル（リング 10、物質 4 つで表の点 123,420）の減速計算 5 つ（1 つ 3〜4 秒）が塊の遮蔽の中で逐次に回り、そのほかに塊の
  Dancoff 係数の MOC がログで 3 回ある。実装のブランチで、塊の遮蔽をピンと同じく並列にした（出力はバイト単位で同じ）。2G の自己遮蔽は、並列にする前の
  3 回が 37.7〜58.5 秒、後の 4 回が 30.2〜40.5 秒（排他のジョブ 304、306、2026-10-14）で、回ごとのばらつきが大きく、差の大きさは
  決められない。並列にした後も、棒の等価なセル（表の点 123,420）の表の作成と、塊の Dancoff 係数の MOC（ログで 3 回）が残る
- 残る時間は、Dancoff 係数と塊の遮蔽（2A で計 4.3 秒）、ピンの中の表の作成と逐次の減速の反復。表の作成は (b)、反復は
  #0046 で減らせる候補

## 確認

- 試行の数値は上の表（ブランチ perf/0039-cp-table、2e58062f と f7362b66 の `trials/table/` の入力と `diff.py`、`pins.py`、`absorption.py`）
- crates/lattice/src/track_table/tests.rs: 燃料、真空のギャップ、被覆管、水のセルで、表から内挿した飛程が細かさについて
  4 次で収束し（`interpolated_tracks_converge_at_fourth_order`。10 倍あたり 16 点で衝突確率の差が 1e-5 未満、8 点との比が
  10 より大きい）、真空でない列の衝突の和が体積に 1e-12 で等しく（`interpolated_tracks_keep_the_neutrons`）、表の点で
  格子点ごとの値になる（`tracks_at_the_nodes_are_the_cell_tracks`）
- crates/lattice/tests/track_table.rs の `table_tracks_stay_within_the_adr_differences_in_1b`（examples/vera/vera.msgpack を
  読むので既定では走らせない。`cargo test --release -p xlc-lattice --test track_table -- --ignored`）: VERA 1B を既定の表と
  `track-table = false` で解き、k の差を 1e-6、群ごとの吸収断面積の相対差を 2.3e-6 で抑える（上の表の 1B の 16 点）。
  実装のブランチの走行（2026-10-14）で Δk/k = −0.020 pcm、吸収断面積の差の最大 2.24e-6
- crates/lattice/src/input/tests.rs の `track_table_defaults_to_the_adr_density`: 既定が 16 点で、整数と false を受け、true、0、
  負の数を拒む。`track_table_needs_self_shielding`: 自己遮蔽しない入力の `track-table` を拒む
- crates/lattice/src/ufg/tests.rs: 共鳴を持つ試料のセルで、既定の表の群定数（全、弾性散乱、核分裂、νσf）が格子点ごとの値と
  1e-6 で合う（`table_tracks_give_the_group_constants_of_the_exact_tracks`）。NaN の全断面積はどちらでも同じエラーで止まり、
  全断面積が 0 になるリングと、格子点の数以上の点を持つ表は、表を作る前に止まる
