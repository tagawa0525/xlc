# ADR-0002: 段階のクレートは互いに依存せず、形式と共通の計算のクレートにだけ依存する

## 背景

M2 では、データファイルの型のために core が lattice に、lattice が xs に依存しており、前の段階を直すと後の段階まで
作り直しになっていた。M3 と M4 で、段階の間を渡る型（分岐テーブル、ADF、燃焼チェーン）が増える。

## 検討した案

- 後の段階が前の段階のクレートに依存する（M2 までの形）: 前の段階を直すと後の段階まで作り直しになる
- 段階のクレートは互いに依存せず、データファイルの形式のクレートと共通の計算のクレートにだけ依存する（採用）

## 決定と理由

- 段階のクレートは互いに依存しない。依存してよいのは、データファイルの形式のクレート（`xlc-format`）と共通の計算の
  クレート（`xlc-numeric`）だけとする
- 段階の間を渡る型が増える前に、データファイルの型（多群ライブラリ、群構造、少数群定数）と、xs にあった MessagePack の
  厳密な読み書きを `xlc-format` に移す（M3 の初めに行った）
- ENDF を読むのは xs だけとする。燃焼チェーンも xs が ENDF の崩壊・収率データから作り、データファイルに書く

段階の間の依存をファイル形式だけにする（[ADR-0001](0001-split-into-three-stage-crates.md)）ことを、クレートの依存でも守るため。

## 確認

各クレートの `Cargo.toml` の依存で確かめる（段階のクレートが別の段階のクレートを依存に持たない）。自動の検査はない。

- 段階の間で共有する計算の扱いは [ADR-0003](0003-extract-shared-computation-on-second-use.md)
- 燃焼チェーンの作り方は [ADR-0034](0034-build-full-depletion-chain.md)
