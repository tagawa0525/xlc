# ADR-0274: 非分離共鳴（LSSF=0）の範囲の MF3 の捕獲か核分裂のバックグラウンドが負の評価は、既定はエラーにし、入力の宣言でその反応の File 2 のサンプルを (平均 + バックグラウンド)/平均 倍にする

## 背景

非分離共鳴の自己遮蔽は、ラダーのサンプルで σ0 ごとの実効断面積を求める（ADR-0177）。LSSF=0 の評価は、MF3 のバックグラウンドを
各サンプルの点に定数で足し、差 s(σ0) − s(∞) をポイントワイズの断面積に足す。LSSF=1 の評価は、MF3 を入れない File 2 だけのラダーの
比 s(σ0)/s(∞) を掛ける。ADR-0177 は、弾性散乱（バックグラウンドを含む）が負になる点を 1 μb にし（NJOY PURR と同じ）、ほかの反応の
負のバックグラウンドで全断面積が 0 以下になる点はエラーにすると決めた。

4 つの版の全評価を `xs nuclide` に通す走査（#0292）で、ENDF/B-VII.0 の 3 評価が止まった（#0319、#0320。xlc 2dc2899a の main の xs と、
一時の出力を足した同じ版、2026-11-20）:

- Ta-181（範囲 330〜5000 eV）: MF3 の MT102 のバックグラウンドが 330 eV で −1.61 b、MT2 が −6.47 b。サンプルの全断面積が 0 以下になり、
  `the sampled total cross section is not positive` で止まる
- Es-253（101.2〜10000 eV）: バックグラウンドは 101.2 eV の 0 から 10 keV の MT102 −0.698 b、MT2 −6.12 b へ線形。同じ文で止まる
- Cf-253（100.4〜10000 eV）: 10 keV で MT102 のバックグラウンドが −0.965 b、File 2 の平均の捕獲がおよそ 0.98 b で、和（無限希釈の捕獲）は
  0.014 b。遮蔽した捕獲が 10 keV で σ0 = 30 b から負になり（σ0 = 1 b で −0.041 b）、8500 eV の正の値との間を非分離共鳴の補間則
  log-log（INT=5）で補間するので、y1/y0 < 0 の冪が NaN になる（endf/tab1.rs の `Interpolation::LogLog`）。ライブラリの検査が
  `non-finite value NaN` で止める

原因は 3 つとも同じで、共鳴の部分の捕獲と核分裂は負にならない（ψ ≥ 0）のに、負のバックグラウンドを各サンプルに定数で足すので、共鳴の
間の点の捕獲か核分裂が負になる。NJOY2016 は止まらない: PURR は Ta-181 の 330 eV でサンプルの全断面積の最小が −1.54 b、確率テーブルに
負の値が 16 あり、直接のサンプルの Bondarenko の σ0 = 1 b の全断面積は −195 b、確率テーブルからは捕獲 −0.374 b を出す。Cf-253 の 10 keV の
σ0 = 1 b の捕獲は −0.019 b。UNRESR は σ0 と全断面積のバックグラウンドとポテンシャル散乱の和が負のときだけ警告し、これらでは警告しない
（references/njoy-runs/issue-0319/、issue-0320/ の output。NJOY2016.79、565 K、2026-11-20）。

ENDF-102（BNL-224854-2023-INRE）の 2.3.1 節と 2.4.17 節は、LSSF=0 の MF3 を「File 2 から求めた平均（無限希釈か遮蔽した）に足す部分の
バックグラウンド」と定め、点ごとにどう配るかは決めていない。LSSF=1 は、File 2 から求めた遮蔽した平均と無限希釈の平均の比を、MF3 の
無限希釈の断面積に掛ける自己遮蔽因子の方法とする。

止まらない評価にも同じ状態がある。MF2 と MF3 の静的な走査（4 つの版の全中性子の評価）で、LSSF=0 の範囲の MT102 か MT18 の
バックグラウンドに負の値があるのは次の評価（範囲の中の最小）:

| 評価                   | 版    | 最小のバックグラウンド | 565 K で捕獲か核分裂が負のサンプルの割合 |
| ---------------------- | ----- | ---------------------- | ---------------------------------------- |
| Na-22                  | 4 版  | MT102 −0.0396 b        | 83 %                                     |
| Ar-36                  | 4 版  | MT102 −0.0005 b        | 16 %                                     |
| Cd-106                 | 4 版  | MT102 −0.0647 b        | 17 %                                     |
| Cd-111                 | 4 版  | MT102 −0.1457 b        | 0.16 %                                   |
| Eu-154                 | 4 版  | MT102 −0.099 b         | 0                                        |
| Am-241                 | VII.0 | MT102 −0.0422 b        | 0                                        |
| Cf-252                 | VII.0 | MT18 −0.0679 b         | 22 %                                     |
| Cf-253、Es-253、Ta-181 | VII.0 | 上の値                 | 4.8 %、止まる、止まる                    |

割合は、ラダーの和に一時の計数を足した xs（xlc 2dc2899a）の 565 K の 1 点の `xs nuclide`（examples/depletion/process-survey/<版>/ の入力）で、
全断面積が正なので止まらず、負の捕獲か核分裂の点を黙って和に入れていた。負になる割合は温度（ドップラー拡がり）とラダーの密度で
変わり、バックグラウンドの大きさでは決まらない（Ar-36 は −0.0005 b で 16 %）。

判断の軸:

- 物理として無い負の部分断面積を、自己遮蔽の和と群定数に入れないこと
- 評価の欠陥か、方法の前提の外にある評価は、黙って直さずに止め、扱いは入力の宣言で読めるようにすること（リポジトリの CLAUDE.md の
  「方針」。ADR-0267、ADR-0272 と同じ形）
- 宣言で読み替える評価でも、今の方法からの変化を、負のバックグラウンドの成分に限ること
- 宣言の要らない評価の出力を変えないこと

## 検討した案

宣言したときの読み方:

- 案 A: バックグラウンドが負の反応（捕獲、核分裂）だけ、定数で足す代わりに、ラダーの File 2 の共鳴の部分のサンプルを
  (File 2 の平均 + バックグラウンド)/(File 2 の平均) 倍にする。正か 0 のバックグラウンドの反応と弾性散乱は、今のとおり定数で足す。
  全断面積は反応の和（採用。親のセッションの案）
- 案 B: 評価の全体を File 2 だけのラダーの比 s(σ0)/s(∞) で遮蔽し、無限希釈の断面積（File 2 の平均と MF3 の和）に掛ける（LSSF=1 と
  同じ経路。最初に実装した。「確認」の表の因子の方法）: 正のバックグラウンドの成分も File 2 の比で遮蔽し、重みの全断面積から
  バックグラウンドを除くので、負の成分の読み替えより広く値を変える。VII.0 の Cf-252（負は核分裂だけ）の σ0 = 1 b の遮蔽した捕獲は
  −31 %、Ar-36（捕獲の負は −0.0005 b だが、全と弾性散乱の背景が −2.2 b）は −37 %
- 案 C: 負の成分だけを、ラダーの比で無限希釈に掛ける別の経路にする（担当の代わりの案）: 案 A と同じく負の成分に変化を限るが、LSSF=0 と
  LSSF=1 の経路を反応ごとに混ぜることになり、重みの全断面積にはその成分の遮蔽した値が入らない。案 A は同じラダーの和の中で、
  サンプルの値そのものを縮めるので、重みと平均が同じサンプルから決まる
- 案 D: 負のバックグラウンドを、遮蔽した平均にだけ足す（ENDF-102 の文の字義どおり。重みの σt に入れない）: 遮蔽した捕獲はラダーの比の
  分だけ小さくなるのに、負のバックグラウンドは遮蔽されずに全部引かれるので、Cf-253 の 10 keV の σ0 = 1 b の遮蔽した捕獲は、File 2 の平均
  0.98 b に遮蔽因子を掛けた値から 0.965 b を引いて負のまま。ADR-0177 も「バックグラウンドを平均の補正としてだけ足す」を比べて採らなかった
- 案 E: サンプルの捕獲か全断面積を小さな正の値で下から抑える: 抑える値に根拠が無く、平均を変える

既定（宣言の無い評価）:

- 案 F: LSSF=0 の範囲の MF3 の捕獲か核分裂のバックグラウンドに負の値があれば、エラーにする（採用）
- 案 G: 宣言を、止まる 3 評価だけに求める（サンプルの全断面積の検査のまま）: 今は止まらない評価（Na-22 の 83 % など）の負の捕獲の
  サンプルが、黙って和に残る
- 案 H: エラーの条件を、サンプルの捕獲か核分裂が負の点があること（ラダーの和の中の検査）にする: ラダーの種とサンプルの数は
  `Sampling::LIBRARY` と格子点の番号で決まり入力で変えられないので、同じ温度の組なら同じ評価が同じに止まるが、温度の組で条件が変わり、
  ある温度で負のサンプルが出なくても、別の温度の入力で止まる。今は負のサンプルの出ない Eu-154 と VII.0 の Am-241 でも、共鳴の間の点の和は
  負になりうる（共鳴の部分は 0 に近づく）
- 案 H2: エラーの条件を、範囲の中の MF3 の表の点で決める（最初に実装した）: ラダーは格子点の値を足すので、格子点の間だけの負の点で、
  サンプルが負にならない評価を止め、宣言すると warn を出しても何も縮めない（レビューの 1 周目）
- 案 I: エラーの条件を、バックグラウンドの絶対値と File 2 の平均の比のしきい値にする: しきい値は物理で決まらない（Ar-36 は比が小さくても
  16 % の点が負）。4 つの版の捕獲と核分裂のバックグラウンドの負の値に丸めの大きさのものは無く、最小の絶対値は Ar-36 の 5e-4 b なので、
  しきい値は置かない（丸めの大きさの負の値にも宣言を求める ADR-0267 と同じ）
- 案 J: 宣言なしで、負のバックグラウンドの評価に自動で案 A を使い、warn を出す（「参照コードの誤りを真似ず、正しい方法を実装して
  warn」の読み方）: 既定がエラーでなくなり、評価の欠陥と扱いが入力に見えなくなる
- 案 K: NJOY PURR と同じく止めずに負のサンプルを和に入れる: σ0 の小さいところで無意味な値になる（PURR の Ta-181 の σ0 = 1 b の全断面積
  −195 b）。Cf-253 は NaN のまま

## 決定と理由

案 A と案 F にする。

- 共鳴の部分の捕獲と核分裂は負にならないので、MF3 の捕獲か核分裂のバックグラウンドが負なら、各サンプルに定数で足す今の方法（ADR-0177）は
  共鳴の間の点で負の部分断面積を作りうる。既定のエラーの条件は、ラダーに足す値そのもの、つまり非分離共鳴の格子点の MF3 の値（線形化した表の、
  下端は右、上端は左の値）で決め、温度、σ0、サンプルの数と種、スレッドの数によらない。宣言した評価の縮める反応も、同じ格子点の値で決まる
- 負のバックグラウンドは滑らかな物理の成分ではありえず、File 2 の平均の強さを評価の値に合わせる補正としてしか読めない。正のバックグラウンドは
  滑らかな成分として定数で足すのが LSSF=0 の普通の読み方で、そこは変えない。案 A はその読み方で、縮めたサンプルは負にならず、サンプルの平均は
  評価の値（File 2 の平均とバックグラウンドの和）を保ち、重みの全断面積も読み替えた後の反応の和になる。今の方法からの変化は、負の成分の
  反応のサンプルのゆらぎの大きさの違いに限られる（定数で足すと、ゆらぎの大きさを File 2 のまま平均だけを下げるので、相対のゆらぎが
  大きくなり、共鳴の間で負になる）
- 倍率の File 2 の平均は、格子点のエネルギーでの無限希釈の平均（`UnresolvedXs::cross_sections`、0 K の表の非分離共鳴の部分と同じ式）。
  遮蔽の補正は差 s(σ0) − s(∞) で当て、s(∞) は同じサンプルの平均なので、遮蔽のない極限は 0 K の表に戻る。平均が正でないか、
  バックグラウンドが平均より負に大きい（和が負）点は、倍率が負になるので止める（0 K の表の負の値で、読み替えでは直らない。
  0 K の表の負の値は ADR-0267 の検査が先に止める）
- 縮めた分は全断面積のバックグラウンドからも除き、ほかの反応（MF3 の全断面積と部分の和の差）を変えない
- 弾性散乱の負のバックグラウンドの 1 μb の扱い（ADR-0177、Mo-95 など）は変えない。弾性散乱の File 2 の部分は干渉で負になりうるので、
  倍率では読み替えず、宣言した評価でも今のとおり定数で足して 1 μb にする
- 宣言は評価ごとの入力の核種の項目 `unresolved-negative-background = "scale"` で、当てたら warn を出す。値は `"scale"` だけを取る
  文字列にする（真偽の項目は、効かない `false` の宣言を書けてしまう）。輸送しない放射化の核種には遮蔽が無いので、書くと止める
- 宣言の要らない評価（非分離共鳴が無い、LSSF=1、バックグラウンドが負でない、弾性散乱だけが負）への宣言は止める（評価が替わって古くなった
  宣言を黙って当てない。ADR-0267、ADR-0272 と同じ）
- 宣言しない評価の計算は変わらない（倍率 1 を掛けた値のビットは同じ）

### 帰結

- 既定のエラーで止まる評価が、走査で止まった 3 つ（Ta-181、Es-253、Cf-253）のほかに増える: 4 つの版の Na-22、Ar-36、Cd-106、Cd-111、
  Eu-154 と、VII.0 の Am-241、Cf-252。宣言の要る評価は VII.0 で 10、VII.1、VIII.0、VIII.1 で各 5 の計 25。走査の入力の宣言は
  examples/depletion/process-survey/<版>/declarations.toml
- 本番と検証のライブラリの入力のうち、AIC の Cd-106、Cd-111 を輸送する examples/vera/xs.toml、examples/vera/endfb70/xs.toml、
  examples/depletion/p2/xs.toml、examples/core/xs.toml、examples/m3-nuclides/xs.toml と、VII.0 の Am-241 を輸送する examples/depletion/endfb70/xs.toml に
  宣言を足した（p2 の Na-22、Ar-36、Eu-154 は放射化の核種で当たらない）。#0292 の試行の入力（issue-0292 の trial、no-pointwise、all の library と
  control）にも足した。ライブラリは作り直していない（ステージは changed）。AIC の結果に効く大きさは確かめていない（#0327）。入力の全部が宣言を
  持つことは、examples/depletion/test_input_declarations.py が版の走査の宣言と突き合わせて確かめる
- Cf-253 の NaN は、エラーで手前で止まる。符号の違う 2 点を log-log で補間すると NaN を返す `Interpolation::LogLog`（endf/tab1.rs）は
  変えていない（別のセッションが issue にする）
