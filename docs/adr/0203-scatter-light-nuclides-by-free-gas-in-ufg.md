# ADR-0203: UFG の減速計算で、分離共鳴を持たない核種の散乱核を、温度 T の自由ガスの核として入力で選べるようにする

## 背景

[ADR-0202](0202-measure-burnup-bias-candidates-by-cross-section-swaps.md) の測定で、1C のピンセルの新しい燃料から 2A の 40 MWd/kg の組成（以下 2A-40）への
同じ組成の輸送の差の増え +111 pcm のうち +83 pcm が UFG の範囲（4 eV〜15 keV）にあった（吸収 +44、うち 4〜9.88 eV の群が +34.6。移行
+39）。#0152 は、27 群（4〜9.877 eV）の燃料の中性子束が OpenMC より U-238 の 6.67 eV の共鳴の下で約 −1%、上で約 +1% 傾くことを示し、
候補に UFG の散乱核の標的の扱い（[ADR-0070](0070-treat-targets-at-rest.md)。どの核種も静止した標的）を挙げた。

参照解の OpenMC 0.15.2 は次のとおり扱う（[ADR-0133](0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md) の背景、ADR-0070 の検討した案）。

- H in H2O の H は、S(α,β) の上限 B(4) = 10.00008 eV より下で S(α,β)、その上でエネルギーによらず温度 T の自由ガス（質量比が 1 未満の
  核種は静止させない）
- 質量比が 1 より大きい核種は、400 kT より下で断面積を一定とした自由ガス、その上で静止した標的。分離共鳴の上方散乱の扱い
  （DBRC など）は使っていない（入力に `resonance_scattering` がない。`references/openmc/pin-rates-1C/2a40-fine/model.xml`）

判断の軸（依頼、2026-10-24）: 正確さ > 速度 > 保守。厳密な方法（参照）と、誤差を許容して速く解く方法を作り、誤差を測る。近似は入力の
項目で選べるようにし、既定は ADR で決める。説明できない定数や補正は入れない。

## 検討した案

### 厳密な核

- 案 K1: 分離共鳴を持たない核種（ライブラリの `resolved` が nil。この例では H-1、O-16、B-10、B-11）を、断面積を一定とした温度 T の
  自由ガスの核にする（採用）。断面積が一定のときの自由ガスの核は閉じた式で、xs が 4 eV より下の弾性散乱に使う式と同じ
- 案 K2: H in H2O の H を、B(4) より下で有効温度 T_eff の短時間衝突近似（THERMR と ADR-0133 の式）にする（依頼の案 2）。H の質量比は
  ほぼ 1 なので、短時間衝突近似の P0 の核は、出射が 4 eV 以上で物質の温度の自由ガスの核と erfc(6) ≈ 2e−17 の差で同じになる（下方散乱は
  erf(√(E'/kT_eff))/E、上方散乱は物質の温度の詳細つり合いで e^{−(E'−E)/kT}。
  `short_collision_kernel_of_hydrogen_is_the_free_gas_at_the_material_temperature`）。K1 と結果が同じで、ライブラリに T_eff と B(4) を
  足す変更（形式の変更で、すべてのライブラリの作り直し）が要らないので、K1 に含める
- 案 K3: H in H2O の H を、B(4) より下で S(α,β) の表そのものの核にする（OpenMC と同じ）。ライブラリに S(α,β) の表（温度ごとの α、β の
  格子と S）を持たせ、UFG の格子点ごとに表を α について積分する。費用は #0001 の案 A（UFG を熱中性子の範囲まで延ばし、S(α,β) の核と
  上方散乱の反復を入れる。見積もり 1〜2 週間）の一部で、4〜10 eV だけなら上方散乱の反復は K1 と同じ仕組みで足りる。この ADR では
  作らない（誤差は「決定と理由」の 27 群の行の比較）
- 分離共鳴を持つ核種（U-238 など）の熱運動: 共鳴の中では断面積を一定とした自由ガスは正しい核でなく、正しい扱い（DBRC、RST）には
  0 K の弾性散乱のポイントワイズの断面積がライブラリに要る（[ADR-0073](0073-store-pointwise-data-in-library.md) のライブラリは温度に拡げた断面積だけを持つ）。
  OpenMC の参照解は 400 kT より下で断面積一定の自由ガス（DBRC なし）。この ADR では静止した標的のまま残し、別の ADR で決める

### 核の差の積分

- 案 Q1: 格子点ごとに、自由ガスの核と静止した核の差を、散乱核の幅の 1/16 の格子で直接に求積する（ブランチ `feat/free-gas-ufg`、
  ADR-0070 の検討した案）。差は E' = E で不連続なので h² でしか収束せず（幅の 1/16 で 0.45%、1/32 で 0.12%）、試験だけで 25 分かかった
- 案 Q2: 核を R = R_static/N(E') + D と分け、R_static/N は静止した標的の窓の積分で（弾性散乱断面積を σs/N にする）、D は静止した核の
  両端の近くの区間ごとに 3 点の 2 次式で近似し、中性子束の累積の積率（倍精度 2 つの和）で積分する（採用）。区間の端は核の不連続点
  （u' = u、u' = u − Δ）にそろえるので、区間を細かくすると区間の幅の 3 乗ほどで収束する（`cells_integrate_the_correction_against_the_flux`、
  `free_gas_spectrum_converges_with_the_cells`）。上端の側の区間は E' = E ± y kT（y は 0 から 28 まで、端から離れるほど e^{y/4} 倍に
  広げる）、下端の側は E' = E/α のまわりのぼけの幅 2√(E' kT)/ζ の ±6 倍
- 上方散乱は、まだ解いていない低いエネルギーの中性子束を使う。最初のスイープは格子点より後の中性子束をその点の値とみなし（未知数に
  入れる）、次からは前のスイープの値を使って、中性子束の相対変化が 1e−10 以下になるまでスイープし直す。1 回のスイープで変化は
  2 桁ほど縮む（2A-40 で 1.2e−2、2.6e−5、2.2e−7、4.2e−9、8.4e−11）ので、50 回で収束しなければ止める（`UfgError::NotConverged`）
- 範囲の下限（4 eV）より下からの上方散乱は、その中性子束を範囲の最後の格子点の値（1/E）とする。上方散乱の区間は 600 K の H で
  2.55 eV、900 K の O-16 で 1.8 eV まで下に届くが、重みは e^{−(E−E')/kT} で、4 eV の近くの数 kT に集まる。その誤差は測っていない

### 速い方法

- 案 F1: 自由ガスの核を使う入射エネルギーに上限（kT の倍数）を置く（OpenMC の質量比 1 より大きい核種の 400 kT と同じ形）。それより
  上は静止した標的
- 案 F2: 区間の細かさを下げる（核の幅あたりの区間の数）
- 案 F3: 上方散乱のスイープの回数を固定する（1 回なら、格子点より後の中性子束をその点の値とみなすだけ）
- 案 F4: 温度ごとに前計算した核の表（エネルギー比の関数）で、区間の点の核の評価を置き換える。F1〜F3 で足りるかを測ってから決める
  （作っていない）

## 決定と理由

入力の項目 `ufg-scattering = "static" | "free-gas"`（省略すると `"static"`）と、`"free-gas"` の条件 `ufg-free-gas = { upper, cells, sweeps }`
（`upper` は kT の倍数で、省略すると上限なし。`cells` は省略すると 4。`sweeps` は省略すると収束するまで。省略した条件は参照）を足す。
`"free-gas"` は案 K1 と案 Q2 で、分離共鳴を持たない核種だけを自由ガスにする。既定は静止した標的のまま（ADR-0070 の記録を再現できる
ように）。

測定（examples/depletion/verification.md の「UFG の自由ガスの散乱核（ADR-0203）」。xlc は 4a2fd7e8 と 5d25f8fb、2026-10-24）:

- 参照の k は、1C のピンセルの新しい燃料で +67.1、5 MWd/kg で +52.1、2A-40 で +29.5 pcm 動き、新しい燃料から 2A-40 への k の差の増えは
  +110.7 から +73.1 pcm になる。U-238 の 27 群の吸収の置き換えの寄与は −54.3 → +4.0（新しい燃料）、−33.9 → −3.5 pcm（2A-40）で、
  #0152 の 27 群の燃料の中性子束の傾きは半分ほどに縮む
- 速い方法の参照からの k の差: 細かさ 2 は 0.0 pcm、スイープ 1 回は +0.8〜+0.9 pcm、400 kT の上限は −2.9〜−4.1 pcm、3 つの組は
  −2.0〜−3.3 pcm（目安の ±5 pcm の中）。新しい燃料から 2A-40 への増えの差は +0.1〜+1.3 pcm
- 時間は測っていない（測定のジョブは `--timed` でなく、その時間は記録に使えない）。手間は、参照がすべての格子点で区間の核の評価と
  スイープの 6 回ほどの繰り返しを要し、400 kT の上限は自由ガスの核を範囲の下端の近くの格子点に限る
- H in H2O の 27 群の入射の移行は、S(α,β) の表（OpenMC）では群の中に残る割合が自由ガス（K1、K2）より +2.54% 多く、低い群へは
  −0.3〜−32% 少ない（行の和の差は −8.2e−5）。K1 の H の核の、OpenMC に対する誤差はこの大きさで、K3 で消える

既定の案（決めるのはユーザー）: `ufg-scattering` の既定を `"free-gas"` にし、条件の既定を 400 kT の上限、細かさ 2、スイープ 1 回に
する。参照からの差は 4 pcm 以内。自己遮蔽の時間の増えは、決める前に `--timed` のジョブで測る。既定を切り替えると、静止した
標的で出した記録（燃焼、分岐、集合体、炉心）がすべて古くなる。

自由ガスの核の閉じた式と誤差関数は、xs の同じ式を lattice に複製する。共通のクレート（xlc-numeric）に移すと、xs と lattice の実行ファイルの
バイトが変わり、DVC の xs のすべてのステージが古くなる（[ADR-0166](0166-build-chain-in-its-own-crate.md) の測定）。

## 帰結

- 静止した標的の既定では、自己遮蔽の結果はビットで変わらない（1C のピンセルの 2A-40 の `fine_flux` の出力の md5 が main と同じ）
- 参照（上限なし、細かさ 4、収束まで）は重い。区間ごとに核を 2 回評価し、全範囲の格子点でスイープを 6 回ほど繰り返す。並列は格子点
  ごとの区間の塊だけで、格子点ごとに並列の領域を開くので、スレッドを増やしても速くなりにくい（`--timed` で測っていない）
- 自由ガスの核は k の差を全体に正の側へ動かす（新しい燃料で −46.5 → +20.6 pcm）。新しい燃料の差は、ほかの候補（#0148 の 15 keV より
  上 +142 pcm など。ADR-0202）との打ち消しで決まっていたので、1 つの候補を直したときの値は、ほかの候補と合わせて読む
- 残る UFG の範囲の差の候補: H in H2O の 4〜10 eV の束縛（K3）、分離共鳴を持つ核種の熱運動（OpenMC は 400 kT より下で断面積一定の
  自由ガス。正しい扱いは DBRC など）。#0152 に書く

## 確認

- 単体試験: `crates/lattice/src/ufg/free_gas/tests.rs`（閉じた式と散乱則の積分、A = 1 の Wigner-Wilkins の形、N(E) への規格化、
  T → 0 の静止した核、区間の外の D、区間と直接の求積）と `crates/lattice/src/ufg/tests.rs`（T → 0 で静止した標的の結果、区間の細かさ、
  上限、スイープの収束、分離共鳴を持つ核種）。入力は `ufg_scattering_defaults_to_targets_at_rest`。H の短時間衝突近似と自由ガスは
  xs の `short_collision_kernel_of_hydrogen_is_the_free_gas_at_the_material_temperature`
- 測定は examples/depletion/verification.md の「UFG の自由ガスの散乱核（ADR-0203）」
- 集合体: 2A と 2O の燃焼を、ADR-0204 の速い方法（軽い核種と重い核種を 400 kT まで自由ガスにする。細かさ 2、スイープ 3 回）で OpenMC と比べた。0 から 60 MWd/kg への k の差の増えは 2A で +169.0 → +110.3 pcm、2O で +112.1 → +68.7 pcm に縮み、0 の点の差は 2A で +10.6 → +42.2 pcm、2O で +66.1 → +88.0 pcm に上がる。ピン出力の rms は不変（examples/depletion/verification.md の「集合体での自由ガスの散乱核（ADR-0203、ADR-0204）」）
