# ADR-0276: 燃焼の出力は、核分裂を MT458 の ER で、捕獲などを heating-local と同じ量で反応率から数えた発熱で規格化し、OpenMC の燃焼の参照解も energy-deposition にそろえる

## 背景

格子計算の燃焼は、燃焼の領域の核分裂の出力 Σ V N σf φ Q が決めた出力になるよう、中性子束の大きさを決める（[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md) の
案 P1）。Q はチェーンの核分裂の Q 値（MF3 MT18 の QI）で、捕獲の γ、B-10 の (n,α) などのエネルギーを入れない。ミクロ燃焼の中性子束の
大きさ（[ADR-0216](0216-tabulate-micro-depletion-cross-sections-per-state.md) の案 P1）と、炉心のノードの出力の割合と燃焼度の増分（[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の κΣf）も同じ Q を使う。
OpenMC の燃焼の参照解は `normalization = "fission-q"`（OpenMC の `normalization_mode`）で、xlc と同じ定義にそろえてある。

ADR-0173 は、捕獲のエネルギーも入れる案 P3 を「比べる 2 つで同じ定義を使えば差に入らない。炉心の発熱の分布（γ の輸送）を扱う
ときに見直す」として採らなかった。この理由はコードどうしの比較には当たるが、次の 2 点を見ていなかった（#0293 の項目 3）。

- エネルギーの収支: 炉内では捕獲の γ などのエネルギーも熱になる。核分裂の Q だけで出力を数えると、決めた出力に着くまでの
  核分裂を、その分だけ多く数える。同じ「40 MWd/kg」が、実際より多くの核分裂を経た組成になる
- 実測との比較: Problem 9 は実測の臨界ホウ素濃度と EFPD と比べる。燃焼度の軸のずれは、同じ定義の 2 つのコードの比較には
  入らなくても、実測との比較には入る

大きさは、規格化だけを変えた OpenMC の 1C のピンセル（燃料 1 リング）の燃焼 2 本で測った（examples/depletion/verification.md の
「出力の規格化を OpenMC の燃焼で確かめる（項目 3）」。acdbcb546、Slurm 962 と 968、2026-11-19〜20。ライブラリは ENDF/B-VIII.0）:

- `energy-deposition` で決めた出力の、チェーンの Q で数えた核分裂の出力に対する超過 δ は、燃焼度 0、20、40 MWd/kg で 3.09%、
  4.30%、4.77%
- 同じ燃焼度の k∞ の差（`energy-deposition` − `fission-q`）は、20 MWd/kg で +482 ± 52 pcm、40 MWd/kg で +757 ± 59 pcm（± は 2 本の
  標準誤差の二乗和の平方根で、同じシードの正の相関があるので差の標準誤差の上限）。燃焼度の軸は 40 MWd/kg で 1.69 MWd/kg ずれる。
  40 MWd/kg の数密度の差は U-235 +7.21%、Pu-239 −0.55%、Pu-241 −3.12%
- 向きと桁は、xlc の 69 群の反応率からの 1 次の見積もり（同じ記録の「非分離共鳴の自己遮蔽（項目 6）、収率の 2 点の重み（項目 7）、
  出力の規格化（項目 3）」。U で 20 MWd/kg の +460〜+573 pcm、40 MWd/kg の +826〜+999 pcm、MOX で 40 MWd/kg の +455〜+485 pcm）と
  合う。40 MWd/kg では見積もりが下端で 69 pcm 大きい（候補は k∞ の傾きの差で、確かめていない）。MOX の燃料は OpenMC で確かめていない

差は [ADR-0032](0032-target-lattice-accuracy.md) の目標（k ±100 pcm）を大きく超える。親のセッションが、規格化は燃焼度の軸の話（同じ MWd/kg に着くまでの
核分裂を、捕獲の γ の分だけ多く数える）と説明したのに対し、ユーザーは、エネルギーの収支が合っていないなら当然直すべきだと
述べた（ユーザー 2026-11-25）。

OpenMC 0.15.2 の `energy-deposition` は、`heating-local` の tally をフィルターなし（問題の全体）で数え（`openmc/deplete/helpers.py` の
`EnergyScoreHelper`）、それで出力を規格化する。`heating-local` は NJOY の HEATR の、γ をその場に落とした KERMA で、核分裂の反応の
分だけを MF1 MT458 の EFR + EGP + EGD + EB に置き換えたもの（`openmc/data/neutron.py` の 788〜846 行）。捕獲の γ（H-1 の 600 K、
0.0253 eV で 2.2246 MeV）、B-10 の (n,α)、即発中性子の運動エネルギー（ENP。減速材などの散乱の KERMA に入る）を含み、ニュートリノを
含まない。核分裂の反応の分と ENP の和は MT458 の ER に当たる（VIII.0 の U-235 の 0.0253 eV で 189.24 + 4.83 MeV、ER は 194.08 MeV。
同じ記録の節）。

核データの版に依るもの: QI、MT458 の成分、捕獲の断面積は評価ごとに変わる。VIII.0 では U-235 の ER がチェーンの QI より +0.35%、
U-238 が −0.63% 違い、版を替えると `fission-q` のままでも燃焼度の軸が動く（同じ記録の節の「核データの版に依るもの」）。本番の版は
[ADR-0264](0264-use-endf-b-vii-1-for-production.md) が決める（ENDF/B-VII.1。proposed）。

判断の軸（CLAUDE.md の「方針」の順）:

- 正確さ: エネルギーの収支を閉じ、実測と比べる燃焼度の軸を物理的に正しくする。燃料の種類、燃焼度、毒物による変化を落とさない
- 実行速度: 規格化は輸送ごとに 1 回の和で、時間の大部分（自己遮蔽と MOC）に比べて小さい
- 保守の容易さ: 値は使う版の評価から来て、版を替えたときに手で直す定数を持たない

## 検討した案

規格化に使うエネルギー:

- 案 F: 今のまま、核分裂の Q（MF3 MT18 の QI）だけで数える（ADR-0173 の案 P1）。参照解と同じ定義にすれば、コードどうしの比較に
  差が入らない。エネルギーの収支が閉じず、燃焼度の軸が 40 MWd/kg で 1.69 MWd/kg ずれる（背景）。実測と比べる Problem 9 では、
  ずれが k と燃焼度で読む量（臨界ホウ素濃度、EFPD）にそのまま入る
- 案 K: 核種ごとの定数の核分裂あたりのエネルギー。VERA の燃焼のベンチマークの仕様書（CASL-X-2015-1014-000 Rev. 0）の Kappa、
  または WIMSD のように U-235 の値を決めて Q を比で拡げる。ベンチマークと同じ定数で比べられ、実装は核分裂の Q の差し替えで済む。
  捕獲と核分裂の比の燃焼度による変化、スペクトル、Gd のピンの捕獲、減速材の H-1 と B-10 の捕獲を失う。仕様書の Kappa は、
  `fission-q` の履歴の核種ごとの核分裂の出力で重み付けると、Q に対して燃焼度 0、20、40 MWd/kg で 4.77%、6.37%、7.02% を足し、
  `energy-deposition` の δ の約 1.5 倍になる（同じ記録の節）。Kappa は ENDF/B-VII.0 の値の定数で、ライブラリの版を替えても
  変わらない。仕様書は Kappa の定義を書かず、捕獲の分を含むかは確かめていない
- 案 R: 反応率から、核分裂のエネルギーを MT458 の ER で、捕獲などの反応のエネルギーをその反応の Q で数える（ADR-0173 の案 P3 から
  崩壊の熱を除いたもの。崩壊の熱は帰結）。エネルギーの保存として正しく、燃焼度、燃料の種類、毒物による変化を反応率が持つ。OpenMC の `energy-deposition` と
  同じ量を数える。値はすべて使う版の評価から来る。燃料の外（減速材、被覆管）の反応率と、反応ごとの Q が要る。炉心のテーブルに
  発熱の断面積が 1 つ増える（採用）

案 R の数え方:

- 案 R1: 反応ごとの Q。核分裂は ER、ほかの反応は評価の Q を、反応率に掛けて足す。即発中性子の運動エネルギーは ER の ENP として
  数え、散乱の KERMA は数えない。KERMA を作る処理は要らないが、燃焼の領域の外とチェーンの反応の外（VII.1 の B-10 の MT104、
  MT113 など）の反応率が要り、評価ごとの Q の書き方の違いを規則で吸収する必要がある。このブランチのレビューで、VII.1 に次が
  見つかった（references/endf の評価の MF3 の見出しを手元で読んだ。2026-11-25）:
  - 部分反応の QI は脱励起の γ を含まない（B-10 の MT801 は QI 2.3119 MeV、QM 2.7895 MeV。代表の MT107 は QI も QM も 2.7895 MeV）
  - 和の反応として置いた代表の MT の QM が 0 のものがある（Gd-157 の MT103 は QM 0、部分反応 MT600 は −0.581 MeV）
  - 部分反応どうしの QM が一致しないものがある（O-16 の MT107 と MT800 は −2.2143 MeV、MT801 と MT803 は −2.2156 MeV）
  - 和の MT（B-10 の MT3 の QM は 11.456 MeV）と核分裂の MT は数えず、分解する非弾性散乱の準位（B-10 の MT55 の QM は −4.46 MeV）の
    Q は数える必要がある
- 案 R2: KERMA の群定数（NJOY の HEATR と同じ量を群に縮約し、核分裂の分を MT458 に置き換えたもの。OpenMC の `heating-local` と
  同じ量）: 反応ごとのエネルギーの収支を評価の生成物のデータから数えるので、上の Q の書き方の違いに依らない。xs に KERMA を作る
  処理と、ライブラリの新しい項目が要る

漏れの無い無限の格子の定常では、即発中性子が持ち出した運動エネルギーは、散乱で落とす分と、吸収されるときに持つ分に分かれるので、
R1 と R2 の総量は 1 次で同じになる見込みである（差の大きさは確かめていない）。どちらで数えるかは、実装のブランチで、OpenMC の
`heating-local` との総量の差と実装の手間を測って決め、この ADR に書く。

今の方式（案 F）を入力に残すか:

- 案 S1: `fission-q` を入力で選べる経路として残す（採用）。OpenMC も両方を持つので、規格化の差を比較から外して、ほかの差だけを
  見る診断に使える。今の記録の比較（`fission-q` どうし）を出し直せる
- 案 S2: 残さない: 保守する経路が 1 つ減る。規格化の差とほかの差を分ける比較ができなくなる

`fission-q` は速度のための近似でも厳密な経路でもないので、CLAUDE.md の「方針」の、速度のための近似を足すときに厳密な経路を残す
規則は当たらない。残すのは、上の診断の用途があり、今のコードの経路をそのまま使えて保守の費用が小さいからである。古い形式を
読むための後方互換ではない。

案 K を入力の選択肢に足すか: 足さない。VERA の結果と同じ定数で比べる用途はありうるが、今は要る比較が無い。要る比較ができたときに、
入力の選択肢として足すかを決める。

OpenMC の燃焼の参照解の規格化:

- 案 O1: 参照解も `energy-deposition` にする（採用）。既定の xlc と同じ量で比べ、規格化の差が比較に入らない
- 案 O2: 参照解は `fission-q` のまま、xlc も比べるときだけ `fission-q` にする: 本番の既定の経路を参照解と比べられない

## 決定と理由

- 燃焼の出力の規格化は案 R を既定にする。格子計算の燃焼は、問題の全体（燃焼の領域の外の減速材と被覆管を含む）の発熱が決めた
  出力になるよう、中性子束の大きさを決める。発熱は、核分裂を MF1 MT458 の ER で、ほかの反応を `heating-local` と同じ量（脱励起と
  捕獲の γ をその場に落としたエネルギー）で数え、値はライブラリと同じ評価から取る。数え方（案 R1 か R2）は実装のブランチで決める
  （「検討した案」）。評価のデータが数え方の前提に合わなければ、黙って代わりの値を使わず、エラーにする
- 核分裂の反応率を持つ核種の評価が MT458 を持たなければ、エラーにする（黙って MF3 MT18 の QI や KERMA に戻さない。OpenMC は
  MT458 が無いと HEATR の KERMA のまま使う。`openmc/data/neutron.py` の 782〜786 行と、824 行と 836 行の `if f is not None`）。MF3 MT18 を持つ評価のうち MT458 を持たない
  ものは、ENDF/B-VII.0 で 65 のうち 44（U-232、Pa-233、Np-239、Am-242m、Cm-244、Cm-245 などを含む）、VII.1 で 85 のうち 7（Ra-223、Ra-226 と
  Es の 5 つ）、VIII.0 と VIII.1 で 88 のうち 9（main の 3f23edc39 の references/endf の評価の、MF1 MT458 と MF3 MT18 の行の有無を手元で数えた。2026-11-25）。
  本番の VII.1 で欠ける 7 つは、本番の形の入力 examples/depletion/p2/xs.toml でどれも放射化だけの核種（輸送しない）で、規格化に入らない。
  VII.0 で欠ける核種には p2 で輸送する Np-239、Cm-244 などがあり、VII.0 のライブラリで既定の規格化の燃焼を流すとエラーで止まる。
  輸送する核種を足すとき（#0292）に欠けがあれば、代わりの値をそのとき ADR で決める
- 入力は `[depletion]` の `normalization` で、`"energy-deposition"`（既定）と `"fission-q"`（ADR-0173 の案 P1）を選ぶ（案 S1）。名前は
  OpenMC の `normalization_mode` と同じにする
- 燃焼度（MWd/kg）は、規格化に使ったエネルギーで数える
- 炉心のテーブルの状態に、発熱の断面積（群ごと、eV/cm。格子計算と同じ定義）を足す。ADR-0190 のノードの出力の割合と燃焼度の
  増分、ADR-0216 のミクロ燃焼の中性子束の大きさは、格子計算の燃焼と同じ定義の発熱で数える。テーブルは使った `normalization` を
  持ち、炉心は規格化の違うテーブルを混ぜればエラーにする。数え方の細部（ミクロ燃焼の、追う核種で閉じる形をどう直すか、補正した
  定数の発熱の扱い）は実装のブランチで決め、ADR-0190 と ADR-0216 の「## 変更」に書く
- OpenMC の燃焼の参照解は `normalization = "energy-deposition"` にする（案 O1）。photon を輸送しないので、OpenMC は `heating-local` で数える
- 案 K は採らず、入力の選択肢にも足さない

理由:

- エネルギーの収支を閉じることは正確さの軸そのもので、背景のとおり差は ADR-0032 の目標を大きく超える。直すことは、ユーザーが
  エネルギーの収支が合っていないなら直すべきだと述べたことに沿う（ユーザー 2026-11-25）。案 R を既定にすることは親のセッションの
  推奨で、ユーザーはそれに異論を述べていない（ユーザー 2026-11-25）
- 案 R は反応率から数えるので、捕獲と核分裂の比の燃焼度による変化、燃料の種類（U と MOX で捕獲の Q の割合が違う。背景の
  見積もり）、Gd の捕獲を持つ。案 K の定数はこれらを失い、版を替えても VII.0 の値のまま残る
- 核分裂の分を ER にそろえるのは、ER が評価の定める核分裂あたりの回収できるエネルギー（ニュートリノを除く）で、OpenMC の
  `heating-local` の核分裂の反応の分と ENP の和に当たるからである。MF3 MT18 の QI は評価によって ER と食い違う（VIII.0 の U-235、U-238）
- 数え方を R1 と R2 から今選ばないのは、R1 は評価の Q の書き方の違い（「検討した案」）を規則で扱う必要があり、R2 は KERMA の処理が
  要り、どちらの費用と OpenMC との差も測っていないからである。どちらも同じ量を数えるので、規格化の定義はこの ADR で決まる
- 参照解も同じ規格化にすれば、既定の xlc の経路を、規格化の差を入れずに参照解と比べられる

### 帰結

- 実装は、本番の版のライブラリが揃った後（ADR-0264、#0303）の別のブランチで行う。それまで格子計算、ミクロ燃焼、炉心は今の
  `fission-q` の定義のまま。実装のブランチで ADR-0173（出力の規格化の項と OpenMC との対応の表）、ADR-0216（案 P1 の中性子束の
  大きさ）、ADR-0190（ノードの出力の割合と燃焼度の増分）の決定を直し、それぞれの「## 変更」にこの ADR を書く。どの ADR もほかの
  決定は変わらないので、置き換えない
- ER と、数え方に要るもの（R1 は反応ごとの Q とチェーンの外の反応の断面積、R2 は KERMA の群定数）を、ライブラリかチェーンに持たせる。燃焼の領域の外（減速材の H-1、B-10、被覆管の核種）の反応率を、規格化の
  ために MOC の中性子束から数える
- 燃焼度の軸が動くので、燃焼の履歴、燃焼のテーブル、ミクロ燃焼の基準、炉心の燃焼の結果のすべてが作り直しになる。本番の作り直し
  （CLAUDE.md の「計算」の規模）に合わせて行う
- OpenMC の燃焼の参照解（examples/depletion/ の 1C、MOX-1、p2 の集合体の入力。今は `normalization = "fission-q"`）は、
  `energy-deposition` で作り直す。参照解を作り直すとき（本番の版を改めるとき（ADR-0264、#0303）を含む）に合わせ、規格化だけの
  ための流し直しはしない。今の記録の `fission-q` どうしの比較は、`fission-q` の経路の検証として残る
- 熱水力のノードの出力の重み（#0266）を燃焼のノードの出力にそろえるなら、そろえる先はこの ADR の発熱の断面積になる。重みを
  そろえるかは #0266 で決める
- 輸送しない核種（ADR-0173 の案 N1）の吸収のエネルギーをどう扱うかは、実装のブランチで決める。ライブラリに無い核種は反応率を
  持たず数えられない。放射化だけの核種はライブラリに断面積を持つ（ADR-0238）ので数えられるが、OpenMC の参照解は輸送する核種の
  集合だけを数えるので、数えれば参照解との差になる。数えない分だけエネルギーの収支は開く。吸収の割合と反応度は
  examples/depletion/verification.md の「輸送しない核種の吸収（U、Gd、MOX）」と #0292 が扱い、抜けるエネルギーの割合は測っていない。
  記録の節の案 R は、この Q も要るものに挙げている
- 捕獲でできた核種の崩壊のエネルギー（U-239 の β など）は数えない。OpenMC の `heating-local` も反応の即発の分（KERMA）と MT458 の

- 発熱を反応の場所に落とす近似は、規格化の総量には効かない。ピンとノードの出力の分布で γ を輸送しない誤差は、この ADR の範囲の外
- 版を替えると ER、Q、捕獲の断面積が変わり、燃焼度の軸もその評価に合わせて動く。版による燃焼の反応度の傾きを文献と比べる
