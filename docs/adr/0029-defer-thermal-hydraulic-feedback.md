# ADR-0029: 熱水力のフィードバックは初期のマイルストーンでは扱わない

## 背景

炉心計算に熱水力のフィードバックをいつ入れるかを決める必要があった。

## 検討した案

計画には、ほかの案を比べた記録はない。

## 決定と理由

熱水力のフィードバックは初期のマイルストーンでは扱わず、燃料温度・減速材温度は一定とする。燃焼後の結果を実機データと
比べる段階で導入する。M3 でも扱わず、燃料・被覆管・減速材の温度は入力で与える。

## 確認

範囲の判断で、確かめるテストはない。

## 帰結

- 熱水力のフィードバックを含む BEAVRS との比較は、M4 の後に検討する
- 分岐の軸は、燃料温度や減速材密度を足せる形にしておく（[ADR-0033](0033-store-kinetics-and-cooling-data-in-m4-tables.md)）
