# ADR-0118: ピン出力の判定の閾値を、再構成だけの誤差と 2 段階の手法の誤差に分けて決める

## 背景

ピン出力の再構成（[ADR-0096](0096-reconstruct-pin-power-analytically.md)）の検証で、判定の閾値が決まっていなかった
（#0043。案: xlc の MOC に対してピン出力の差の RMS 1%、出力 0.8 以上のピンの相対の差の最大 3%）。2 × 2 のカラーセット
（3.10% と 2.11% の VERA 2B 型の集合体を市松に、外周は鏡面反射）で測ると、2 段階の手法の誤差（MOC に対して RMS 0.95%、
最大 1.83%）の大部分は、集合体 1 体で作った定数と形状関数が周りの集合体の影響を表せない分で、再構成だけの誤差（同じ定数の
細かいメッシュの拡散に対して RMS 0.18%、最大 0.78%）は小さかった（examples/colorset/verification.md、02a2cd43、
2026-10-10）。

- 再構成の実装が劣化したときに、それだけを見つけられること
- 2 段階の手法として、実用の精度に収まっているかを見られること

## 検討した案

- 案 A: 2 段階の手法の誤差だけに閾値を置く（RMS 1%、最大 3%）。再構成の誤差が今の 0.18% から数倍に悪くなっても、
  定数の誤差に埋もれて閾値の内に収まりうる
- 案 B（採用）: 再構成だけの誤差と、2 段階の手法の誤差に、別々の閾値を置く

## 決定と理由

案 B にする（ユーザーの判断）。ピン出力の相対の差（出力はそれぞれ燃料のピンの平均で規格化）で判定する。

| 比べるもの   | 参照                                         | RMS  | 出力 0.8 以上のピンの最大 |
| ------------ | -------------------------------------------- | ---- | ------------------------- |
| 再構成だけ   | 同じノードの定数で解いた細かいメッシュの拡散 | 0.5% | 1.5%                      |
| 2 段階の手法 | 体系の全体を xlc の MOC で解いた解           | 1%   | 3%                        |

再構成だけの閾値は、今の値（RMS 0.18%、最大 0.78%）に、体系による違いの余裕を見て置いた。2 段階の手法の閾値は #0043 の
案のまま。

## 確認

examples/colorset/verification.md のカラーセットの結果が、両方の閾値の内にある（再構成だけ RMS 0.18%・最大 0.78%、
2 段階の手法 RMS 0.95%・最大 1.83%）。

## 結果

- 2 段階の手法の RMS は、カラーセットで閾値に近い（0.95%）。濃縮度の差が大きい体系や、反射体に接する集合体では超えうる。
  超えたら、環境の効果の補正（再均質化など）を検討する
- 反射体を含む VERA 4-2D、REF1-2D、5-2D での判定は、角の CDF（#0020）が決まってから行う（#0043）
