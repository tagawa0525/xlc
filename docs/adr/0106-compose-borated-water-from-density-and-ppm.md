# ADR-0106: 格子計算の減速材の組成は、密度、ホウ素の質量 ppm、B-10 の原子分率から AME2020 の原子質量で作る

## 背景

分岐のテーブル（ADR-0097）は、ホウ素濃度と減速材の温度（と密度）を変えて格子計算を繰り返す。いまの格子計算の入力は
物質を核種の個数密度で書くので、分岐ごとに減速材の4核種の個数密度を手で計算して書く必要がある。VERA の仕様書は
ホウ素濃度を質量分率で与え（1285 ppm なら水の質量分率 0.998715 と天然のホウ素 0.001285。CASL-U-2012-0131-004、
Problem 5 の節）、個数密度の表（Moderator (565K and 0.743 g/cc)）を載せている。

## 検討した案

- 個数密度を入力に書く（今のまま）: 分岐ごとの計算を入力の外でする。書き誤りに気づけない
- 密度、ホウ素の質量 ppm、B-10 の原子分率を書き、核種の質量にライブラリの AWR を使う: ライブラリを読むまで組成が
  決まらず、入力の読み込みとライブラリの読み込みが絡む
- 同じ量を書き、核種の質量に AME2020 の原子質量を定数で持つ（採用）: 入力の読み込みだけで組成が決まる。使う核種は
  H-1、O-16、B-10、B-11 の4つだけ

## 決定と理由

物質に `nuclides` の代わりに `water = { density = 0.743, boron = 1291, b10 = 0.199 }` と書けるようにする。`density` は
ホウ酸水の密度 (g/cm³)、`boron` はホウ素の質量 ppm（混合物の中のホウ素の質量分率 × 10⁶）、`b10` はホウ素の中の B-10 の
原子分率。すべて必須とし、既定値を置かない。個数密度は、水（H-1 2 個と O-16 1 個の分子）の質量分率 1 − w と
ホウ素の質量分率 w = boron × 10⁻⁶ から、N = ρ w N_A / M で求める（N_A = 0.602214076 × 10²⁴ /mol、厳密値）。
ホウ素の平均の原子質量は B-10 と B-11 の原子分率で重みをつける。原子質量（u）は AME2020（M. Wang et al., Chinese
Phys. C 45, 030003 (2021)）の H-1 1.00782503223、O-16 15.99491461957、B-10 10.01293695、B-11 11.00930536。
`boron = 0` なら B-10 と B-11 を組成に入れない。

## 確認

VERA の Problem 5 の減速材（565 K、0.743 g/cm³、B-10 19.9 at%）の 1285、1291、1170、1230 ppm の個数密度の表と、
相対差 10⁻⁵ 以内（表示の 6 桁）で一致する（crates/lattice/src/input.rs の `borated_water_matches_vera_number_densities`）。

## 結果

- 分岐のテーブルの入力は、ホウ素濃度と減速材の密度をこの3つの量の変化として書ける
- 水以外の物質（ノズルや炉心板の混合物など）は、今のまま核種の個数密度で書く
