# ADR-0026: 格子計算は燃焼度ごとの2群定数、ADF、ピン出力形状と分岐テーブルを出す

## 背景

格子計算から炉心計算に渡すデータを決める必要があった。

## 検討した案

- 炉心側で追跡する核種を Xe と Sm に限り、その微視的断面積と数密度を別に出す（全体計画の最初の版）
- 主要な核種の微視的断面積と数密度、燃焼履歴の補正のデータを出す（採用。[ADR-0035](0035-track-history-by-micro-depletion.md)）

## 決定と理由

出力は燃焼度ごとの2群の均質化定数、ADF、ピン出力形状とする。ホウ素濃度と制御棒挿入の有無などの状態は、各燃焼点
からの分岐計算でテーブル化する（軸は後から燃料温度や減速材密度を足せる形にする）。炉心側でミクロ燃焼する主要な
核種の微視的断面積と数密度、燃焼履歴の補正のデータも出力する（[ADR-0035](0035-track-history-by-micro-depletion.md)）。

## 確認

M3 以降の炉心の結果で確かめる。ADF は #0010。

## 結果

- M2 の出力は、集合体を均質化した2群定数と、ピンごとの核分裂率の分布
- M3 の状態の分岐は [ADR-0085](0085-branch-on-core-states.md)、M4 の分岐テーブルの中身は [ADR-0033](0033-store-kinetics-and-cooling-data-in-m4-tables.md)
