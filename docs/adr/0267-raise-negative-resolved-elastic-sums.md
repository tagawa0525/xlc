# ADR-0267: 分離共鳴の弾性散乱が MF3 のバックグラウンドとの和で負になるところは形式によらず 0 にし、ほかの負の 0 K の断面積はエラーにする

## 背景

ENDF/B-VIII.1 の Fe-54 の `xs nuclide` は、ドップラー拡がりの格子づくりで点が際限なく増え、常駐のメモリ 77 GB でカーネルに止められた
（#0309）。R 行列（LRF = 7）の弾性散乱は負にならないが、分離共鳴の範囲の MF3 の弾性散乱のバックグラウンドが負で、その和が 3.5 keV
付近で負になる。ドップラー拡がりの格子の判定（`doppler::split`、NJOY broadn と同じ規則）は値が正であることを前提にしていて、
区間の両端の値がどちらも負だと、両端の比の判定が常に「分ける」になり、中点が両端の間に入らなくなるまで分け続ける。

ADR-0265 は、SLBW の弾性散乱と MF3 のバックグラウンドの和が負になるところを 0 にすると決めた（ENDF-102 の 2.4.9.1 の手当て）。
ほかの形式（MLBW、Reich-Moore、R 行列）は、共鳴の部分が負にならないので、和の負を扱っていなかった。

NJOY2016 の RECONR は、共鳴の部分を負なら 0 にしてから MF3 を足し（`sigma`）、足したあとの弾性散乱が 1e-8 b 以下なら、どの範囲でも
1e-8 b にする（`emerge`）。ほかの反応の負の値は直さない。

判断の軸:

- 物理として無い負の断面積を、ドップラー拡がりと群定数に渡さないこと
- 評価の誤りに見える値は、黙って直さずにエラーで止めること（リポジトリの CLAUDE.md の「方針」）
- 負の値の無い評価の出力を変えないこと

## 検討した案

- 案 A: 分離共鳴の範囲の中の弾性散乱は、形式によらず、和の lin-lin の表を 0 で切る（零点を表に足す）。それ以外（範囲の外の弾性散乱、
  ほかの反応）で、ドップラー拡がりで広げる負の値があればエラーにする（採用）
- 案 B: ADR-0265 と同じく、共鳴の関数の中で弾性散乱を −MF3 で下から抑え、MF3 の表の点を再構成の格子に足す: 共鳴の再構成の格子が
  変わるので、負の値の無い評価（VIII.0 の Fe-54、U-238 など）の出力も変わる
- 案 C: NJOY と同じく、どこでも弾性散乱を 1e-8 b 以上にする: 範囲の外の MF3 は断面積そのもので、そこが負なのは評価の誤り
  （VII.0 の Cl-35 の 1e-5 eV の −2218 b）。黙って直すと誤りが見えなくなる
- 案 D: ドップラー拡がりの格子の判定を、負の値でも止まるように変える: 負の断面積を広げた値に意味が無く、群定数に負の値が残る
- 案 E: 格子の側で、拡げた値に負の値があればエラーにする: 上限の上の窓の値と、0 K の再構成を通らずに `broaden` を呼ぶ例
  （`compare_njoy_broadr`）も捉えられるが、本番のコードは panic を禁じる（Cargo.toml の clippy の `panic = "deny"`）ので、`broaden` と
  `ColdParts::at` をエラーを返す形にする変更が要る。窓の値で格子が止まらなくなる評価は 4 つの版に無い（#0309）ので、要るときに行う

## 決定と理由

案 A にする。

- 分離共鳴の範囲の中の MF3 の弾性散乱は、共鳴の部分に足すバックグラウンドで、ENDF-102 は負の値を認める。和が負になるのは、評価者が
  打ち消しきれなかった分で、ENDF-102 の 2.4.9.1 は「負になったら 0 にする」程度の手当てでよいとする（ADR-0265 と同じ理由）
- 0 で切るのは、和を表した lin-lin の表に対して行う。区間の中で符号が変わるところに線形補間の零点を足すので、0 にした表は元の表を
  0 で切った関数と同じになる。0 で切っても、共鳴の部分の線形化の誤差は大きくならない。負の点の無い表は変えない
- 範囲の端の段差では、下端は右、上端は左の値だけを範囲の中とみなす（ADR-0265 と同じ）
- 0 にした点があれば、その数、最も小さかった値、エネルギーの範囲を warn で出す。NJOY の 1e-8 b の下限は真似ない（ADR-0265）
- SLBW の範囲は ADR-0265 の扱いのままで、和はすでに負でないので、ここでは何も変わらない
- 0 K の再構成の後、ドップラー拡がりで広げる反応（`is_broadened`）の、広げる上限（`broadening_limit`）より下の表の点と、上限を
  またぐ区間の上限での値（左からの極限）に負の値が残れば、MT、エネルギー、値を示してエラーにする。格子の判定が止まらなくなる入力を、
  メモリを使い尽くす前に止める。上限より上の値は広げないので見ない。ただし、拡がりの積分の窓（上限の上の数百 eV。Fe-54 の
  1.036 MeV、1200 K で約 450 eV）に入る負の値は、拡げた値に届きうる。4 つの版でそれに当たるのは VIII.1 の Ni-60 の上限 800 keV の
  右の値（−1.06e-12 b）だけで、1200 K の `xs nuclide` は終わる（#0309）

## 確認

- 単体テスト（crates/xs/src/pointwise/tests.rs）: `negative_resolved_elastic_with_its_background_is_raised_to_zero`、
  `negative_broadened_cross_sections_are_an_error`
- VIII.1 の Fe-54 の `xs nuclide`（2 温度）が終了コード 0 で終わり、最大常駐は VIII.0 の Fe-54 と同じ桁（examples/depletion/verification.md の
  「版ごとのライブラリの負の分離共鳴の弾性散乱」）
- NJOY との比較（xlc 20e70134、2026-11-20）: VIII.1 の Fe-54 の 0 K の再構成を NJOY2016 の RECONR の PENDF と比べ、全断面積と捕獲は
  許容誤差の 2 倍を超える点が無い。弾性散乱の 2 倍を超える点は、NJOY の値が 5.14e-5 b 以下の和が 0 に近い点だけ（同じ節）
- 負の値の無い評価の出力が変わらないこと: VIII.0 の Fe-54、Fe-56、U-238 の `xs nuclide` の出力のバイトが、この変更の前の main
  （c0e6195f）と同じ（同じ節）

## 帰結

- 分離共鳴の範囲の弾性散乱の和が負になる点が 0 になる: VIII.1 の Fe-54 と Ni-60、VII.0 と VII.1 の Ar-40、Gd-152、Dy-160（#0309）
- 0 にした点の弾性散乱は NJOY より 1e-8 b 小さい
- VII.0 の Cl-35（範囲の外の MF3 の弾性散乱が負）と Co-58（MF3 の捕獲のバックグラウンドとの和が負）は、エラーで止まる
- 広げる上限より上の負の値（VII.0 の Y-89 の MT91 など）と、窓の値を格子の側で止めるか（案 E）は #0309 に残す
