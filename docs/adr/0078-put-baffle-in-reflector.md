# ADR-0078: 炉心の外の構造は、バッフルと周りの水までを反射体の定数に入れ、バレルより外は除く

## 背景

VERA Problem 3〜5 の炉心の外には、バッフル、バレル、中性子パッド、圧力容器がある。円筒や扇形の形状を格子計算に
加えるかを決める必要があった。

- 結果への影響
- 形状を加える手間

## 検討した案

- バレル、中性子パッド、圧力容器まで入れる: 円筒や扇形の形状を格子計算に加える必要がある
- バッフルと周りの水までを反射体の定数に入れる（採用）

## 決定と理由

炉心の外の構造は、バッフルと周りの水までを反射体の定数に入れ、バレル、中性子パッド、圧力容器は除く。仕様書の付録 J
（表 J-1）で、5-2D のバッフルより外の構造の違いは k で数 pcm にとどまり（docs/plans/m3-core-hzp.md、efdfc8f、
2026-10-08）、円筒や扇形の形状を格子計算に加える手間に見合わないため。

判断は k だけで行った。同じ表の Case 2（バッフルだけ）と Case 1（実際の反射体）の差は、出力分布では次のとおりで、
仕様書も小さいが観測できる差としている（VERA の仕様書 CASL-U-2012-0131-004 の表 J-1、KENO-VI、5A-2D の 1/4 炉心）。

- k: −4.5 ± 1.1 pcm
- 集合体出力の最大の差（絶対値）: −0.57% ± 0.01%
- ピン出力の差の RMS（絶対値）: 0.19% ± 0.08%
- ピン出力の最大の差: 絶対値で 1.01% ± 0.17%、相対で −0.81% ± 0.09%（出力 0.8 以上）、−5.07% ± 0.19%（出力 0.8 未満）

## 確認

仕様書の付録 J の値による判断で、xlc では確かめていない。REF1-2D と 5-2D を OpenMC（2D）と KENO の値と比べるとき
（M3 の検証）に、反射体の定数全体として確かめる。

## 結果

- 5-2D の出力分布を KENO の値（Case 1 の実際の反射体）と比べると、上の差が偏りとして入る。出力 0.8 未満の
  ピンでは相対で数 % になりうる。比べ方を決めるのは #0016
- 反射体の定数の作り方は [ADR-0084](0084-make-reflector-constants-with-fuel.md)、格子の形は [ADR-0083](0083-generalize-to-rectilinear-lattice.md)
