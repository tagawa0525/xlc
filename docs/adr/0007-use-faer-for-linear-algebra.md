# ADR-0007: 線形代数は faer とする

## 背景

CRAM の燃焼計算は疎行列（複素数）の LU 分解を、CMFD はクリロフ法を使う。これらを自前で書くか、どのクレートを
使うかを決める必要があった。

- 純粋な Rust で、システムの依存を持ち込まないこと
- 疎行列の LU 分解とクリロフ法を持つこと

## 検討した案

- nalgebra: 疎行列の LU 分解とクリロフ法を持たない
- LAPACK や UMFPACK に結びつけるクレート: システムの依存が要る
- faer（採用）

## 決定と理由

線形代数は faer とする。密行列と疎行列（複素数を含む）の LU 分解、クリロフ法、クリロフ型の固有値の解法を、純粋な
Rust の1つのクレートで持つため。疎行列の LU 分解（CRAM）とクリロフ法（CMFD）に使う。

## 確認

選定の判断で、確かめるテストはない。faer はまだ依存に入っていない（CRAM と CMFD のクリロフ法を作るときに入れる）。

## 結果

- faer にない GMRES と前処理は、必要になったときに別のクレートか自前の実装かを比べて決める
- 毎回解く小さな密行列は faer にしない（[ADR-0008](0008-keep-own-small-dense-solvers.md)）
