# ADR-0272: 評価の誤りは、xs の入力の核種の項目に、行と欄と元の値と正しい値を宣言して直してから読む

## 背景

ENDF/B-VII.0 の Rb-87（n-037_Rb_087.endf）の MF5 MT17 の、最初の入射エネルギー（18.8049 MeV）の出射エネルギーの分布の TAB1
（1193〜1195 行）は、NR = 1、NP = 3 で、区切りが NBT = 1、INT = 2。ENDF-102 は NBT(m) を m 番目と m+1 番目の補間の範囲を分ける点の
番号とし（0.5 節）、最後の範囲は最後の点で終わるので、NR = 1 では NBT = NP（= 3）になる。xs は TAB1 の読み込み（`Reader::tab1`）で
これを「last NBT must equal NP」で止め、`xs check` と `xs nuclide` が止まる（#0316）。4 つの版（VII.0、VII.1、VIII.0、VIII.1）の
中性子のファイルの全部の走査（ADR-0266。examples/depletion/verification.md の「中性子のファイルの読み込みの走査」）で、この理由で
止まるのは VII.0 の Rb-87 だけ。

ユーザーは、4 つの版のライブラリの全部の核種が流れるようにすることを求めた（ユーザー 2026-11-20。別のセッションが伝えたもの）。

誤りの中身（2026-11-20 にファイルを読んだもの）:

- 正しい区切りは 1 つに決まる。NR = 1 なので、ただ 1 つの範囲の区切りは NP = 3 のほかにない。点は (0, 0)、(2.157e5, 0)、
  (2.158e5, 2e-2) で、INT = 2（線形）の 2.157e5〜2.158e5 eV の積分は 0.5 × 100 × 0.02 = 1 と、分布の規格化に合う
- ENDF/B-VII.1 の同じ評価は、この欄だけを 3 に直した。MF5 MT17 の節の 1〜75 桁を VII.0 と VII.1 で比べると、違うのは 1194 行の
  最初の欄（`1` → `3`）だけ。VIII.0 と VIII.1 も 3
- NJOY2016 は止まらない。TAB1 の積分（endf.f90 の `intega`）と補間（`terpa`）は、点の番号が区切りを超えると次の範囲に進み、
  範囲の番号が NR を超えても止めずに、範囲の表の後ろの語（最初の点の y = 0）を補間則として読む。補間則 0 の区間の積分（`gral`）は
  どの分岐にも当たらず 0 を返すので、GROUPR の MF5 の表の分布（`getsed`）では、この分布の 2.157e5〜2.158e5 eV の区間が 0 になりうる
  （どの区間が補間則 0 になるかは、呼び出しの間に持ち越す範囲の番号で変わる）。コードを読んだもので、NJOY を実行しては確かめていない

リポジトリの方針（CLAUDE.md の「方針」）: 黙ったフォールバックを足さず、怪しい入力はエラーで止める。選べない選択肢は入力で選べる
機能として足す。参照コードが誤っていそうなときは真似ない。TAB1 の読み込みは全部の MF が使う。

判断の軸:

- 宣言しなければ今のとおり止まり、直すことを入力で明示して選ぶこと
- 直す中身が、評価のどの値をどう変えたかとして、入力とログから読めること
- 評価のファイルが替わったら（宣言が別の値を指したら）黙って当てず止まること
- MF ごとの読み込みのコードに、読み替えの経路を通さないこと

## 検討した案

- 案 A: VII.0 の Rb-87 を輸送しない（ライブラリから外す）: ユーザーの求め（全部の核種が流れる）に合わない
- 案 B: 黙って最後の区切りを NP まで延ばす: 方針の「黙ったフォールバックを足さない」に反する。全部の MF の TAB1 に当たり、ほかの
  評価の別の誤り（点の数の打ち間違いなど）も黙って通す
- 案 C: NJOY の読み方に合わせ、`tracing::warn!` を出す: NJOY の読み方は補間則を点の値から読み、結果が呼び出しの順で変わる
  （背景）。参照コードの誤りを真似ない方針に反する
- 案 D: TAB1 の読み込みに「最後の区切りを NP まで延ばす」を宣言する項目を足し、該当の節に渡す: `Reader::tab1` を呼ぶ MF ごとの
  コード（MF5 の分布の表など）に、宣言を渡す引数を通すことになる。宣言の当たる TAB1 を節の中で順番で指す形も要る
- 案 E: 入力の核種の項目に、ファイルの行、MF と MT、欄、元の値、正しい値を宣言し、読む前にテープの欄を書き換える（採用）

## 決定と理由

案 E にする。xs の入力の核種の項目に `corrections` を足す:

```toml
[nuclide.Rb-87]
endf = "n-037_Rb_087.endf"
temperatures = [600]
corrections = [{ line = 1194, mf = 5, mt = 17, field = 1, from = 1, to = 3 }]
```

- `line` はファイルの 1 始まりの行番号（読み込みのエラーの文の行番号と同じ数え方）、`field` は 1〜6 の 11 桁の欄、`from` と `to` は
  整数
- テープを読んだ直後、MF ごとの読み込みの前に、宣言ごとに、その行の MF と MT が宣言と同じこと、その欄の整数が `from` であることを
  確かめ、欄を `to` に書き換える。どれかが違えば止まる（評価のファイルが替わったとき、宣言を黙って当てない）。書き換えるたびに
  `warn` で、核種、行、MF と MT、欄、元の値と正しい値を出す
- 宣言しなければ、テープは今のとおりで、TAB1 の検査も今のとおり止まる

理由:

- 書き換えは読み込みの前の 1 か所で行うので、MF ごとの読み込みのコードは変えない（案 D の引数が要らない）。直した後のテープは
  正しい評価と同じ形で、どの検査もそのまま当たる
- 宣言は評価のどの値をどう変えたかそのもので、ENDF/B-VII.1 の修正（1194 行の最初の欄を 1 から 3）と 1 対 1 に比べられる
- `from` を確かめるので、別の版のファイルや作り直された評価に古い宣言が当たらない
- 欄は整数だけにする。今の誤りは整数の欄で、実数の欄の誤りが見つかったら、そのときに足す

`xs check`（ADR-0266）は入力を読まず、ファイルのパスだけを受けるので、走査では VII.0 の Rb-87 は止まるまま残す。宣言した入力での
`xs nuclide` の結果は、検証の記録に別に書く。

### 帰結

- ほかの評価の誤りも、同じ形で入力に宣言して直す。正しい値の根拠（後の版の修正など）は入力のコメントに書く
- 宣言は ENDF のファイルの行番号に結ぶので、ファイルを替えたら宣言を見直す（`from` が違えば止まる）
- 実数の欄の宣言は持たない。要るときに足す
- 4 つの版の走査（`xs check`）は宣言を読まないので、宣言で直す評価も走査では止まると数える
- Rb-87 の MT17 のしきい値（18.80 MeV。MF3 MT17 の最初の点）は WIMS 69 群の上端（10 MeV）より上なので、直した分布はライブラリの
  群の値に入らない。NJOY の読み方との差も、この群構造では表れない

### 確認

- 合成のテープのテスト（crates/xs/src/endf/tape/tests.rs）: 宣言しなければ、最後の区切りが点の数より短い TAB1 は
  「last NBT must equal NP」で止まる（`a_tab1_whose_last_break_falls_short_of_the_points_is_an_error`）。宣言すると欄を書き換えて
  読める（`a_declared_correction_rewrites_the_integer_field_before_reading`）。行が無い、MF か MT が違う、欄が 1〜6 の外、欄が整数で
  ない、元の値が違う、11 桁に収まらない宣言は止まり、テープを変えない（`a_correction_that_does_not_match_the_tape_is_an_error`）
- 入力のテスト（crates/xs/src/main/tests.rs）: `corrections` を読み、項目の欠けと余りを止める
  （`reads_declared_corrections_of_the_evaluation`）。宣言が無ければ warn を出さずに TAB1 で止まり、宣言 1 つで warn を 1 つ出して
  読める（`a_short_break_stops_the_reading_unless_a_correction_is_declared`）
- VII.0 の Rb-87 の 600 K の `xs nuclide`（宣言した入力 examples/depletion/read-survey/sample-VII.0.toml）が終了コード 0 で
  終わる。宣言しない核種の出力は変わらない（VIII.0 の Li-7、N-14、Ni-58 の出力のバイトが main のビルドと同じ）。数値の出どころは
  examples/depletion/verification.md の「走査が見逃す種類」
- 4 つの版の全評価を 565 K の 1 点で `xs nuclide` に通す走査（examples/depletion/verification.md の「中性子の評価のすべての `xs nuclide`」）は、
  `examples/depletion/process-survey/VII.0/declarations.toml` で Rb-87 の修正を宣言し、Rb-87 は通る（93387633、分岐点 0f883589 の
  `cargo build --release`、手元、2026-11-21）
