# ADR-0139: Problem 3 と 5-2D の OpenMC の参照解は、仕様書が決めていない形を次のように解釈する

## 背景

Problem 3（3A、3B。3D の集合体）と Problem 5-2D（5A〜5C。炉心の高さの中央の 2D の 1/4 炉心）の OpenMC の参照解は、
`examples/vera/openmc_model_3d.py` と `openmc_core_2d.py` で作る。KENO-VI の入力は公開されておらず、仕様書の数値と図から
形を読むところに解釈の余地がある。この解釈は両スクリプトの docstring と verification.md の記述にあるだけで、決定として
残っていなかった。xlc の入力も同じ形を解くので、解釈をそろえる必要がある。

判断の軸:

- xlc と同じ問題を解くこと。モデルの違いが k や出力の差に混ざらないこと
- 仕様書の数値から読めるものは読み、読めないものは推測で足さず、置かないこと
- 既存の決定（He を真空、反射体の範囲）と食い違わないこと

## 検討した案

- 案 A: 解釈を docstring と verification.md だけに置く。決定の理由と、変えたときに xlc の入力も変える必要があることが
  残らない
- 案 B: 解釈を 1 件の ADR にまとめ、スクリプト、verification.md、xlc の入力が参照する。個々の解釈は小さいが、同じ参照解の
  モデルの形として一緒に変わるので 1 件にする
- 5-2D の鏡映の代わりに 1/8 の回転の対称性: 計装管のシンブルがなく、装荷図と Pyrex の配置（図 5）は鏡映で対称だが、
  回転では対称でないので、1/8 には切れない（採らない）
- 反射体を Case 2（バッフルだけ）にする: xlc の反射体（ADR-0078）とそろうが、仕様書の参照解（KENO-VI）は Case 1 なので、
  比べる相手と形が変わる（採らない。下）

## 決定と理由

案 B を採る。解釈は次のとおり。

3A、3B（`openmc_model_3d.py`）:

- 炉心板とノズルは、仕様書の表 P3-3 の均質な組成で、集合体の外周の水のギャップを含む箱全体を占める
- 3B の Pyrex の棒は、下の端栓（SS304 の中実の棒、2.54 cm）、毒物、プレナム（被覆管の中は真空）で、上部ノズルの下端で
  切る。端の栓の高さ 2.54 cm は下の端栓の高さとする（毒物の上のプレナムの上端が上部ノズルの中にあるため）。プレナムの
  内管は寸法がないので置かない
- 3B のシンブルプラグ（Pyrex の棒のない 8 本の案内管）は SS304 の中実の棒で、表 9 の位置 383.31 cm を下端とする
  （燃料と Pyrex の毒物の位置が、どれも下端だから）
- 燃料棒のばねは仕様書のとおり除く

5A-2D〜5C-2D（`openmc_core_2d.py`）:

- 対称性は、中心の集合体（H8）の中心を通る 2 つの面の鏡映で、1/4 炉心を解く（仕様書の quarter symmetry）。出力は鏡映で
  全炉心に広げる
- 反射体は付録 J の Case 1（バッフル、バレル、中性子パッド、圧力容器の内張りと炭素鋼の圧力容器まで入れ、外を真空）。
  仕様書の参照解（KENO-VI）が Case 1 なので、比べる形をそろえる。xlc の反射体はバッフルと水まで（ADR-0078）なので、
  比べる差には外の構造の効果（Case 2 との差が k で −4.5 pcm、集合体の出力の最大で −0.57%。表 J-1）が入る。この差は
  モデルの違いとして記録に書き、参照解を Case 2 に合わせて消さない
- バッフルの隙間 0.19 cm（表 16 の「Gap between Fuel and Baffle」）は、集合体の外周（ピッチ 21.50 cm の正方形の和）からの
  水の隙間と読む。バッフルは、外周の正方形をミンコフスキー和で d だけ太らせた形の d = 0.19 から 0.19 + 2.85 の間で、
  平らな板が凸の角でも凹の角でも直角に会う（examples/reflector と同じ）
- 計装管のシンブルとシンブルプラグは入れない（仕様書のとおり）

共通:

- ギャップと、案内管の棒（Pyrex の棒、制御棒）の中の He は真空にする（ADR-0054、ADR-0120。KENO-VI は He）
- 粒子数、世代数、非アクティブバッチ数、乱数のシード、スレッド数は決定でなく計算の条件なので、入力の TOML と verification.md に書く
  （ADR-0122）

## 帰結

- xlc の 3A、3B、5A〜5C の入力は、この解釈に従う（炉心板とノズルの均質な組成、Pyrex の端栓、シンブルプラグの位置など）。
  変えるときは、OpenMC のスクリプトと xlc の入力を同じブランチで変える
- 3B の Pyrex の端栓、シンブルプラグの位置、バッフルの隙間の読みは、KENO-VI の入力と確かめていない。KENO との差が
  これらに由来するかは、差の内訳で調べる
- 5-2D の KENO との差には、外の構造の効果が入る（上）

### 確認

- `openmc_model_3d.py` と `openmc_core_2d.py` の docstring がこの解釈と一致する
- 参照解の k とピン出力の記録は examples/vera/verification.md の「Problem 3 の参照解」「Problem 5-2D の参照解」
