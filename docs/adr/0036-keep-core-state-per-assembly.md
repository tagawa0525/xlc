# ADR-0036: core のノードごとの状態は、集合体ごとにまとめて集合体に結びつけて保存する

## 背景

core はノードごとに燃焼度、数密度、出力履歴を持つ（[ADR-0035](0035-track-history-by-micro-depletion.md)）。装荷替えで複数サイクルを扱うときと、冷却計算が
集合体ごとの出力履歴を使うときに、状態の持ち方が効く。

## 検討した案

- ノードに結びつけて保存する: 装荷替えのたびに状態の持ち方を変えることになる
- 集合体ごとにまとめ、集合体に結びつけて保存する（採用）

## 決定と理由

core のノードごとの状態（燃焼度、数密度、出力履歴）は、集合体ごとにまとめ、集合体に結びつけて保存する。装荷替え
（集合体の移動・回転）で複数サイクルを扱うときと、冷却計算が集合体ごとの出力履歴を使うときに、状態の持ち方を
変えずに済むため。

## 確認

まだ実装していない（M4）。

## 結果

装荷替えそのものは、実機のデータ（BEAVRS など）と比べる段階で入れる。
