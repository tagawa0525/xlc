# ADR-0082: MF6 の角度のデータは散乱行列に入れず、MF6 の中性子の P1 以上は 0 とする

## 背景

MF4 の角度分布は散乱行列に入れる（[ADR-0081](0081-use-mf4-angular-distributions.md)）。MF6 の角度のデータ（LAW=1 の Kalbach-Mann と Legendre、LAW=2 の Legendre）
も入れるかを、対象の核種で調べて決めた（2026-10-08）。

- PWR への影響
- 入射エネルギーの間の単位基底の補間に角度を通す手間

## 検討した案

- MF6 の角度のデータも入れる: 入射エネルギーの間の単位基底の補間に角度を通す手間がかかる
- 入れない（採用）

## 決定と理由

MF6 の角度のデータは入れず、MF6 の中性子の P1 以上は 0 のままとする。角度のデータを持つ MF6 の中性子は、重心系の
Kalbach-Mann（O-16、B-11、U-234、U-236 の (n,2n) や連続の非弾性散乱、構造材の MT5）と、実験室系の Legendre（Si-28 の
MT91）だけで、WIMS 69 群の上端 10 MeV より下に入るのは O-16 の (n,nα)（8 MeV 以上）、Si-28 の MT91（9.5 MeV 以上）と、
微量の U-234, U-236 の反応だけである。重心系で等方な放出（U-235、U-238、Zr など）の実験室系の P1 も、重い核では重心の
速さが小さくわずか。PWR への影響は無視できる大きさと見込み、手間に見合わない。

## 確認

上の調査（2026-10-08）。影響の大きさは測っていない。

## 結果

MF6 の連続的な放出の P1 以上は 0 である（`crates/xs/src/multigroup/scatter.rs` のコメント）。
