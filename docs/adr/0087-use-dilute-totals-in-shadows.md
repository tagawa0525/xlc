# ADR-0087: 影の計算で、黒体でない物質の全断面積は無限希釈の群平均とする

## 背景

影の計算（燃料のピンの Dancoff 係数、等価なセルの外半径、構造材の塊の Dancoff 係数）では、黒体でない物質の全断面積が
要る。Dancoff 係数は黒体が吸収するエネルギーでの透過なので、原理的には UFG の範囲の群で、黒体の吸収率で重みづけした
平均 Σ_m,g = ∫ Σt,m g du / ∫ g du（g = Σa,A / (Σt,A + 1/l̄_A)、A は黒体）が正しい。

- 精度
- 計算の量（M4 の燃焼で燃料の物質がピンごとに分かれる）
- コードの量

## 検討した案

- 黒体の吸収率で重みづけした平均（ブランチ `feat/dancoff-potential` に残す）: 実装して VERA と比べると、群ごとの差が
  打ち消し合い、k は 1B と 2B の枠あり、枠なしで −5〜+0.4 pcm しか動かなかった（examples/vera/verification.md、6a0345c、
  2026-10-08）。燃料の物質ごとに Dancoff 係数の MOC を解くことになり、燃料の物質がピンごとに分かれる M4 の燃焼では
  集合体1つで数百回になる。ポイントワイズの断面積の積分のコードも増える
- ポテンシャル散乱（λΣp。MPACT（ORNL/SPR-2021/2330 の式 9.17–9.18）、HELIOS 系、SCALE/Polaris が使う）: 上の平均の、
  共鳴が重ならない極限にあたる。吸収率の重みの平均より Zircaloy を透明にしすぎ（4 eV〜200 keV の群で無限希釈より
  最大 45% 透明にし、k が +44 pcm 動く。examples/vera/verification.md）、共鳴の重なる物質の影も落とす
- 無限希釈の群平均（採用）

## 決定と理由

影の計算で、黒体でない物質の全断面積は無限希釈の群平均とする。吸収率の重みの平均は k を数 pcm しか動かさず
（docs/plans/m3-core-hzp.md、de72f03、2026-10-08）、計算の量とコードの量に見合わないと判断した。

この近似の前提は、黒体でない物質の共鳴の大部分が、黒体の共鳴と同じエネルギーにないこと。

## 帰結

制御棒の AIC（Ag-109 の 5.2 eV の共鳴が U-238 の 6.67 eV の共鳴に近い）は前提が崩れる候補なので、制御棒を入れた
ところで、吸収率の重みの実装で測り直す（#0007）。
