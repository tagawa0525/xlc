# ADR-0102: 核分裂のないノードは2群の解析的ノード法（ANM）で解き、core と1ノードの問題で同じ核を使う

## 背景

炉心計算は 3D NEM の2群の拡散計算とし、1集合体を径方向に1ノードとしていた（[ADR-0027](0027-solve-core-with-nem.md)。展開は4次。
[ADR-0045](0045-expand-nem-to-fourth-order.md)）。反射体の定数（[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）の I 型の格子で、反射体のノード（21.50 cm）の高速群の不均質な
中性子束は、燃料側の面の 0.0717 から真空の面の 0.00147 まで約 50 分の 1 に下がる。[ADR-0094](0094-define-adf-by-one-node-nem.md) の1ノードの問題を
NEM で解くと、ノード平均を保ち両方の面の正味の中性子流を合わせた4次の多項式は、真空の面で −0.0024 になり、ADF を
作れない。反射体を 10.75 cm の2つのノードに分けても、外側のノードで −7.1 × 10⁻⁵ になる（examples/reflector/verification.md、
44f4d0d、2026-10-09。#0027）。core も同じ NEM でこのノードを解くので、ADF を作れても、炉心での形は同じ多項式になる。

- 反射体のノードの中性子束の形（指数関数に近い減衰）を表せること
- GET の等価性（ADR-0094）: core と1ノードの問題が同じ式でノードを解くこと
- 燃料のノードの結果を変えないこと

## 検討した案

- 負の ADF を許す: GET の式は ADF の符号によらず成り立ち、core は格子計算を再現する。ただし均質な解の面の中性子束が
  負で、反射体の中の形が物理的でなく、ADR-0094 の「ADF が作れないときはエラー」を外す必要がある
- 反射体のノードを細かくする: 10.75 cm でも負になった。core のメッシュを燃料と反射体で変える必要があり、ADR-0095 の
  ノードの大きさ（集合体のピッチ）とも合わない
- 半解析的な方法（SANM、QPANDA のように多項式に双曲線関数を足す展開）: 自群の項を解析的に、群の間の源を多項式で
  近似する。反射体では高速群の形（指数関数）を熱群の源として多項式で近似するので、熱群の形の誤差が残る
- 2群の解析的ノード法（ANM。K. Smith, MIT の Nuc. Eng. Thesis (1979)、読んでいない。PARCS v3.0 Theory Manual の 4.1 節）
  （採用）: 横方向に積分した2群の1D の式を、2群の行列の固有値の双曲線関数で厳密に解く。PARCS は ANM を主に使い、
  k∞/k_eff が 1 に近いノードで ANM が不安定になるので、そのノードを NEM で解く（hybrid ANM/NEM。H. G. Joo, G. Jiang,
  T. J. Downar, Proc. ANS M&C (1997)、読んでいない。PARCS の Theory Manual の 4.1.2 節）。核分裂のないノードは
  k∞ = 0 で、この不安定はない

## 決定と理由

核分裂のないノード（νΣf がどの群も 0 の物質）は2群の ANM で、核分裂のあるノードは NEM（ADR-0045 の4次）で解く。
ANM の核は共通の計算のクレート（`xlc-numeric`）に置き、core と、ADF を作る1ノードの問題（ADR-0094）の両方で使う。
NEM の核と同じく、core が使う式で格子計算の1ノードの問題を解くことで、GET の等価性を保つ。

- 方向ごとの横方向に積分した式 −D φ″ + A φ = −L(x)（A は除去と群の間の散乱の 2×2 の行列、L は横方向の漏れ）を、
  ノード平均 φ̄、横方向の漏れの1次と2次の項の多項式の特解、D⁻¹A の2つの固有値 κ² の双曲線関数（cosh、sinh。
  ノード平均が 0 になるように定数を引く）で表す。ノード平均は NEM と同じく引数とし、0 次のモーメント（ノードの
  バランス）は 3D のバランス式で課す。4 つの双曲線関数の係数を、2群の両方の面の入射の条件（i = β o + 外からの入射）
  から解く
- 横方向の漏れは NEM と同じ2次式（隣のノードを含む）とする
- 核の出力は NEM と同じ形（群ごとの、ノード平均について線形な出ていく部分中性子流と、面の中性子束）とし、core の
  群ごとのスイープにそのまま入れる。ほかの群のノード平均と入射は、スイープのそのときの値を使う
- 2群でない核分裂のないノード、D⁻¹A の固有値が正の実数で異ならないノードはエラーにする（ADR-0098 の少数群は2群）
- 核分裂のあるノードは NEM のままとする。ANM を燃料に使うと、k∞/k_eff が 1 に近いノードの不安定の扱い（PARCS の
  hybrid の閾値）を決める必要があり、燃料の NEM の結果（VERA の検証）が変わる

この ADR は [ADR-0027](0027-solve-core-with-nem.md) を置き換える。ADR-0027 のうち次はそのまま有効である: 炉心計算は 3D のノード法の2群の拡散
計算とし、1集合体を径方向に1ノード（必要なら2×2）とする。燃料（核分裂のある）のノードは NEM で解く（商用コードの
標準的な手法で、ADF とピン出力の再構成を含めて確立しているため）。展開の次数は [ADR-0045](0045-expand-nem-to-fourth-order.md)、加速は
[ADR-0028](0028-accelerate-core-with-nonlinear-cmfd.md)。

## 確認

まだ実装していない。次で確かめる。

- 核分裂のない均質な平板で、ANM の核の出ていく部分中性子流が、細かいメッシュの差分の解に一致すること
- 燃料と反射体の 1D の細かいノードの解を、粗いノード（反射体は ANM）の GET の定数で再現すること
- 燃料だけの問題の結果が変わらないこと（既存のテスト）
- I 型の反射体の格子で1ノードの問題の均質な面の中性子束が正になり、core が MOC の k を再現すること

## 結果

- ADR-0094 の1ノードの問題は、核分裂のないノードで ANM を使う
- 燃料が真空に直接面する集合体の負の均質な面の中性子束（#0027）は、燃料のノードが NEM のままなので残る
- ピン出力の再構成（[ADR-0096](0096-reconstruct-pin-power-analytically.md)）は燃料のノードだけなので、反射体のノードの形は使わない
