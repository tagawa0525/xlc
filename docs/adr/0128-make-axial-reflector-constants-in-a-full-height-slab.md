# ADR-0128: 軸方向の反射体の定数は、単一集合体から書き出した均質な燃料の媒質と層の物質を集合体の高さ全体に並べた平板の格子計算で作り、少数群定数に z の面を足して、core の z の面にも径方向と同じ GET の面の条件と真空の比を使う

## 背景

[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md) は、軸方向の反射体（下: 炉心板、ボトムノズル、端栓とギャップ。上: プレナム、端栓、トップノズル、炉心板、
水）の定数を、均質化した燃料と層ごとの均質な物質を並べた 1D の平板の格子計算で作り、燃料と接する面は燃料側の ADF で
割って持つ（f*）と決めた。燃料は、単一集合体の計算からライブラリの群で中性子束の重みで均質化したものとする。これを
実装に落とすには、次が決まっていない（#0030）。

- 均質化した燃料を、平板の格子計算の物質として渡す形。格子計算の物質はいま、多群ライブラリの核種の組成か、
  ライブラリと排他の巨視的断面積の TOML（P0 だけ、群のエネルギーなし、少数群定数を作れない）から作る
- 平板の格子の x を炉心の z として、層ごとの定数と、燃料と接する面の f*、外側の真空の面の比 J/φ、ANM（[ADR-0102](0102-solve-non-fissile-nodes-with-anm.md)）と
  Koebke の等価な D（[ADR-0104](0104-weight-transport-cross-sections-by-currents.md)）を core の z の面に渡す形。少数群定数の辺はいま（左、右、上、下）の4つだけで、
  core は z の面の ADF を 1 とし、z の面の `vacuum` をエラーにしている（[ADR-0101](0101-impose-transport-current-ratio-at-vacuum-faces.md)）
- 層の数、厚さ、組成（VERA の仕様書の寸法から）と、反射体の層どうしの面の ADF
- 分岐のテーブル（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)）での扱い

判断の軸:

- 定数を作った体系（平板）では、core が格子計算の MOC の k とノード平均の中性子束を再現すること（GET。[ADR-0103](0103-define-adf-by-one-node-kernels.md)）
- 原理で決まり、手で合わせる係数を持たないこと。径方向と軸方向で同じ規則を使い、場合分けを増やさないこと
- 段階のクレートの独立（[ADR-0002](0002-keep-stage-crates-independent.md)）、ファイルの厳密な読み込み（[ADR-0013](0013-read-files-strictly.md)）、後方互換を作らない（[ADR-0012](0012-drop-backward-compatibility.md)）
- 入力の誤り（層の厚さと core のメッシュのずれ、上下の取り違え）を、推測せずにエラーにできること

## 検討した案

### 均質化した燃料を格子計算の物質にする形

- 多群ライブラリの形式に巨視的な物質を足す: ライブラリは xs が ENDF から作る核種ごと・温度ごとのデータで、ホウ素濃度と
  水の密度の分岐で変わる燃料の媒質は温度の表に収まらない。lattice の出力を xs の形式に書き込むことになり、段階の
  役割が混ざる
- 均質化した燃料を密度 1 の擬似的な核種にする: 核分裂の項（χ）、温度の軸、分岐の状態を核種の形に押し込む。物質と
  核種の区別を崩す
- いまの巨視的断面積の TOML（`cross-sections`）: ライブラリと排他、P0 だけ、群のエネルギーがなく少数群定数を作れず、
  分岐の状態を持たず、10 進のテキストで値が丸まる。拡張すると、ライブラリと混ぜる、P1 以上を持つ、状態を持つ、の
  すべてが要り、別の形式と同じになる
- 1つの格子計算の入力で、単一集合体を解いてから同じ実行で平板を解く: 分岐の状態が自然にそろうが、2つの形状を1つの
  入力に持ち、平板ごとに単一集合体を解き直す。平板の入力を別の燃料で使い回せない
- 単一集合体の格子計算が、細かい群のまま中性子束で均質化した媒質を新しいデータファイル（`xlc-medium`）に書き、平板の
  格子計算がそれを物質として読む（採用）
- 燃料を均質化せず、ピンを z に沿った帯（燃料、被覆管、水の長方形の層）にして平板の中に置く（KAERI の DeCART2D の
  簡略化した 1D の炉心の模型は、燃料と減速材の繰り返しを Y-Z の断面で表す。C. B. Shim, K. H. Lee, J. Y. Cho,
  "Improvement of Axial Reflector Cross Section Generation Model for PWR Core Analysis," Trans. KNS Autumn Meeting
  (2016)、2 節、https://kns.org/files/pre_paper/36/16A-652심천보.pdf 。全文を読んだ）: 燃料の上下の端のピンの不均質が
  入る。円柱のピンを平らな帯にすると体積と表面積の比が変わり、単一集合体の格子と違うスペクトルと自己遮蔽になる。
  ADR-0095 が均質化した燃料と決めており、燃料側の ADF は f* で割って消える

### 平板の範囲

- 下と上の反射体を別の平板にし、燃料の端を鏡面反射にする: 燃料の長さを手で選ぶ必要があり、f* がその長さに依存する
- 集合体の高さ全体（下の水から上の水まで）を1本の平板にする（採用）。KAERI の 1D の炉心の模型も、下の反射体、燃料、
  上の反射体を1本に並べる（上の Shim et al.、図 2）。KAERI は VERA の炉心の追跡にもこの形を使った（S. M. Kim et al.,
  Trans. KNS Autumn Meeting (2018)、https://www.kns.org/files/pre_paper/40/18A-591김성민.pdf 。仕様書の軸方向の反射体の
  情報が DeCART2D の模型に足りず、Hanbit 3 号機の設計データで代えたとある。全文を読んだ）

### 軸方向の定数を core の z の面に渡す形

- 少数群定数の4つの辺を流用し、`axial` の印で（左、右）を（−z、+z）と読む: 同じ項目が定数によって別の向きを意味し、
  core に場合分けが要る。軸方向の定数の径方向の ADF をどこに持つかも決まらない
- core の入力（設計の `layers`）に、その層が軸方向の定数であることを書く: 向きの情報が、定数を作った場所から離れた
  入力にあり、取り違えを検出できない
- 反射体の層の z の面の ADF を 1 とし、外側を Marshak の条件にする: GET の等価性が崩れる。I 型の格子で反射体を2つの
  ノードに分けると、内側のノードの ADF は燃料側で（0.916, 0.238）、外側の面で（4.16, 8.41）と 1 から大きく離れた
  （examples/reflector/verification.md の「I 型の格子の1ノードの問題」、a1fe39d、2026-10-09。NEM で作った値）
- core の中で、チャネルごとの軸方向の 1D の拡散の計算により反射体とスペーサの層を細かい層から均質化し直す
  （SIMULATE5。1-D channel の拡散の式で subnode の中性子束と体積で重みづけし、軸方向の不連続因子を使う。Studsvik,
  "SIMULATE5 Overview," NRC Pre-Submittal Meeting (2015-04-08)、11〜13 枚目、https://www.nrc.gov/docs/ML1508/ML15083A470.pdf 。
  スライドを読んだ）: core に細かい層の拡散の計算と、層ごとの多群でない定数の組が要る。xlc は ADF を格子計算の
  1ノードの問題で作り、core と同じ核を使う（ADR-0103）ので、軸方向も格子計算で作る
- 少数群定数の辺を6つ（左、右、上、下、−z、+z）にする（採用）

### 反射体の層どうしの面の ADF

- 1 とする（ADR-0095 の径方向の反射体のノードどうしの扱い）: 径方向は同じ物質どうしの面だが、軸方向の層は物質が
  違い（ノズル、炉心板、水）、上の I 型の例のように 1 から大きく離れうる
- 平板の1ノードの問題の GET の ADF をそのまま使う（採用）: 軸方向の層の並びは、平板と炉心で同じ（同じ集合体の設計の
  層）なので、定数を作った体系の隣のノードが炉心でもそのまま隣に来る

### 層の組成

- 層の断面（ピン、案内管、水、支持格子）を 2D の格子計算で解いて中性子束で均質化する: いまの MOC は固有値計算だけで、
  核分裂のない格子を解けない。プレナムの被覆管と He、ノズルの鋼と水は熱中性子の吸収が小さく、断面の中の中性子束の
  ゆがみは小さいと見込む（確かめていない）
- 仕様書の寸法から、層の断面の中で体積で混ぜる（採用）。KENO の参照もノズルと炉心板を体積で混ぜた組成を使う
  （仕様書の Problem 3 の節、表 P3-3。炉心板は SS304 と冷却材を 50% ずつ。仕様書 1.4 節の表 5）

### 外側の真空の z の面

- Marshak の条件（ADR-0101 で z の面に許すただ一つの条件）: 径方向の燃料ピンの格子では P1 の関係による誤差が
  +1510〜+3803 pcm あった（ADR-0101）。50 cm の水の外の面では漏れが小さいが、径方向と別の規則を持つ理由がない
- 平板の真空の辺の比 r = J/φ_het を z の面に課す（採用。ADR-0101 の径方向と同じ）

### 文献の扱い

- SIMULATE-3 は、径方向と軸方向の反射体に不連続の考え方を使い、境界のアルベドを入力しない（NRC の SCE-9001 の安全評価。
  ADR-0095 が引く。今回は取得できず読み直していない）。作り方の詳細は確かめていない
- CASMO-5 は反射体の計算のために黒体の境界を加えた（J. Rhodes, K. Smith, D. Lee, PHYSOR 2006。軸方向の反射体の
  模型の記述はない）
- PARCS v3.0 Theory Manual は、軸方向の反射体の定数の作り方を書いていない（9.7.4 節で、1D の計算の2ノードの ANM に
  軸方向の不連続因子を使うとだけ書く。https://www.nrc.gov/docs/ML1016/ML101610117.pdf ）
- KAERI の SMART の設計では、従来の燃料の集合体と反射体の2ノードの模型（ピンが界面に平行）と 1D の炉心の模型（ピンが
  界面に直交）で、下の反射体の燃料側の高速群の DF が 0.701 と 0.990、反射体の高速群の D が 7.2% 違い、臨界ホウ素濃度の
  誤差が 80 ppm 超から 50 ppm 程度に、Fq の誤差が約 6% から 2.5% に下がった（上の Shim et al.、表 I、図 4、5）。
  反射体のノードは 30 cm を推奨している
- MPACT は炉心を 2D/1D で直接解き、軸方向の反射体の少数群定数を作らない。MPACT の 1D の反射体の模型は一次資料で
  確かめられなかった

## 決定と理由

### 均質な燃料の媒質（`xlc-medium`）

- 単一集合体の格子計算の入力に `medium = "<出力>"` を書くと、格子全体を細かい群（ライブラリの群）のまま中性子束と体積で
  均質化した媒質を、分岐の状態ごとに書く。項目は、全断面積、散乱行列のすべてのモーメント（P0 から、ライブラリにある
  次数まで。どの次数もスカラー中性子束で重みづけする）、核分裂、νΣf、χ（核種ごとの χ を生成率で重みづけした1つ）。
  外周がすべて鏡面反射の格子でだけ書け、ほかはエラーにする。外周が鏡面反射なら、この媒質の無限媒質の解は格子の
  平均の細かい群の中性子束と k に一致する（反応率と生成率を保存するため）。拡散係数の B1 の計算が使う均質化
  （`b1_diffusion` の `Medium`）と同じ重みで、P1 より高い次数と核分裂の量を足したもの
- 形式は `xlc-format` の新しいデータファイル（フィールド名付きの map の MessagePack）: `format`（"xlc-medium"）、
  `bounds`（ライブラリの群境界）、`axes`（テーブルと同じ軸。ADR-0097）、`states`（軸の直積の順）。読み込みは厳密にする
- 平板の格子計算の入力では、物質を `[material.fuel] medium = "<ファイル>"` と書く（`nuclides`、`water`、`temperature`、
  `mix` と排他）。媒質の群境界がライブラリと違う、散乱のモーメントの次数がほかの物質と違う、平板の分岐の軸（名前、点、
  密度、B-10 の割合）が媒質の軸と一致しない、ときはエラーにする。分岐の状態ごとに、媒質の同じ状態を使う
- 媒質は自己遮蔽しない（単一集合体の計算で済んでいる）。核種の組成を持たないので、燃料のピンの自己遮蔽の対象に
  ならない

### 平板の格子

- 集合体の軸方向の全体（下の水の外端から上の水の外端まで）を、格子の x（左が炉心の −z）に並べる。行は1つで、上下の辺は
  鏡面反射、左右の辺は真空とする。層の物理的な境（仕様書の寸法）を列の境にし、列を MOC の平坦線源の近似が収束する
  幅に分ける。ADR-0083 の長方形のセルで表せ、形状の追加は要らない
- 燃料は、媒質を燃料の高さ全体に置く。燃料の中の支持格子の層は入れない（#0011 で支持格子の層の定数を決めたら見直す）
- 自己遮蔽はしない（真空の辺のある格子の Dancoff 係数が #0008 で未決のため。ADR-0095 の I 型と同じ）。層の物質は
  無限希釈になり、ノズルと炉心板の鋼の共鳴の吸収を大きく見積もる（大きさは確かめていない）
- 層の物質は、断面の中で体積で混ぜる。入力に `mix = [{ material = "ss304", volume = 0.27923 }, { material = "water",
  volume = 0.72077 }]` のように、ほかの物質の名前と体積の割合を書く（割合の和が 1 でなければエラー。真空は `void`）。
  混ぜた物質の核種の個数密度は、成分の個数密度 × 割合の和で、成分ごとの温度のライブラリの値を使う。分岐が成分
  （ホウ酸水の密度とホウ素濃度、温度）を変えると、混ぜた物質も変わる。割合は仕様書の寸法から求め、入力のコメントに
  出典と導出を書く。ノズルと炉心板の水の割合は、仕様書の表 P3-3 の H-1 の比（ボトムノズル 0.72077、トップノズル
  0.80853、炉心板 0.50000。3A と 3B で同じ）と一致する
- 少数群定数の `few-group` に `axial = true` を書くと、格子の x を炉心の z として定数を書く。各ノードは格子のすべての行に
  わたり、格子の上下の辺は鏡面反射であることを求める（ほかはエラー）

- 1つのノードは複数の物理的な層を含んでよい。ノードの均質化は MOC の中性子束で重みづけする（[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md) の格子の

  中だけである
- ノードは ADR-0095 が挙げた層ごとに1つとする。燃料は、core の燃料のノードの高さに分けて、等価性の確認に使う
- 挿入物（Pyrex、シンブルプラグ）の端は物理的な層の境に足す（Problem 3B と 5）。挿入物の違う設計は、別の
  平板で反射体の定数を作る。制御棒は設計に固定されないので、層の境に足さず、分岐の離散の軸で扱う（下の「制御棒の
  軸」）。燃料の媒質は、その設計の単一集合体から作る（代表の燃料を選ぶ考え方は ADR-0095 と同じ）

### 少数群定数の z の面

- 少数群定数の辺を6つ（左、右、上、下、−z、+z）にする。`adf`、`vacuum_ratio`、`normalized_adf` を6つの辺で持つ。
  後方互換は作らない（テーブルは作り直す）
- 2次元の格子計算（単一集合体、径方向の反射体）の定数は、z の辺の ADF を 1、真空の比を持たず、f* の印を持たない。
  軸方向に一様な格子では、z の面の不均質な中性子束はノード平均に等しく、均質な解も z に平らなので、GET の ADF が
  厳密に 1 になる（近似でない）
- `axial = true` の定数は、（−z、+z）の辺を格子の（左、右）の辺の値に、径方向の4つの辺を格子の上の辺の値（鏡面反射の
  1ノードの問題の ADF。横に一様な平板ではほぼ 1）にする。真空の比と f* の印も同じ対応で置く
- 少数群定数に `height`（z の厚さ (cm)）を足す。`axial = true` の定数はノードの格子の x の幅を持ち、2次元の格子計算の定数は
  nil（軸方向に一様で、どの高さのノードにも使える）。キーは省けない（`pins` と同じ）
- 回転（`@90`。[ADR-0105](0105-load-core-by-assembly-ids.md)）は径方向の4つの辺だけを回し、z の辺は変えない。上下を反転する入力は作らない（平板を炉心の向きで
  作るので要らない）

### core の z の面

- どの面も、少数群定数のその面の辺の ADF を使う（z の面を 1 とする場合分けをやめる）。2次元の格子計算の定数どうしでは
  z の ADF が 1 なので、燃料の層どうしの面の結果は変わらない
- f*の辺は、向きによらず f* × 隣のノードの向かいの辺の ADF とする（ADR-0095）。隣のノードが核分裂のない物質なら
  エラーにする（f*は燃料の ADF で割った値で、上下を取り違えて燃料でない層に向けた f* を見つける）
- 反射体の層どうしの z の面は、両側の定数の ADF（平板の GET の ADF）をそのまま使う。ADR-0095 の「反射体のノードどうしの
  面の ADF は 1」は、径方向の反射体のノードどうしの面だけに当てはめる（#0029）
- z の面の `vacuum` は、その面のノードの物質の z の辺の真空の比 r を使い、径方向と同じ J = r f φ を課す。物質が その辺の r を
  持たなければエラーにし、`marshak` を示す（燃料の層を直接真空に面させるときは `marshak` を書く）
- `height` を持つ物質を置いたノードの z の幅が `height` と丸めの範囲で等しくなければエラーにする。ADF と Koebke の D は
  ノードの幅で決まる1ノードの問題の量なので、軸方向の反射体の層を core のメッシュで分けたり、厚さの違う層に置いたり
  すると等価性が崩れる。設計の `bounds` と `axial-mesh` は、反射体の層を1つのノードにするように書く

### 分岐のテーブル

- 平板の格子計算は、径方向の反射体と同じく、分岐の状態ごとに解き、ノードごとに軸を持つテーブル（ADR-0097）を書く。
  軸は媒質と同じ3つ（ホウ素濃度、減速材、燃料の温度）。燃料の温度の軸は媒質の状態を選ぶだけで、平板の層の物質は
  変えない。ホウ素濃度と減速材の軸には、平板のホウ酸水と、それを成分に持つ混ぜた物質を挙げる
- f* の印と `height` は状態によらないので、状態の間で違えばエラーにする

### 制御棒の軸

VERA の制御棒は、全引き抜き（230 ステップ）でも吸収体の下端が 17.031 + 230 × 1.5875 = 382.156 cm にあり、燃料の
上端（377.711 cm）より上のプレナムの層の中にある（仕様書 1.6 節の表 8）。吸収体の下の 101.6 cm は AIC なので、全引き
抜きではプレナムの層と上の端栓とギャップの層に AIC が入る。全挿入では吸収体の上端が燃料の上端に来て、その上の
棒のプレナム（被覆管と He）10.7 cm と端栓がプレナムの層に入る。制御棒の部分挿入の ADR（ブランチ
docs/control-rod-cusping で proposed。main にマージしたあとで番号で引く）は、ノードを制御棒の状態が一様な区間に分け、区間ごとに層のテーブルの
制御棒の軸の値を選ぶ。したがって上の軸方向の反射体の層のテーブルにも、制御棒の離散の軸が要る。

- 制御棒が入りうる上の層（プレナム、上の端栓とギャップ）のテーブルは、燃料の層と同じ制御棒の離散の軸（値は棒の
  材料ごと。AIC、B4C、棒のプレナム（被覆管と真空）など、制御棒の型の区間に現れる材料の値の集合。部分挿入の ADR と同じ
  値）を持つ。KENO の参照はトップノズルの中と上の棒を入れない（仕様書の Problem 5 の節）ので、トップノズル、上の
  炉心板、上の水、下の層の 4 つは制御棒の軸を持たない
- 平板の格子計算の分岐では、制御棒の軸の値ごとに、制御棒が入りうる上の層のすべての領域の物質を、案内管の中の水を
  その値の棒（吸収体または真空、被覆管、間隙）に置き換えて体積で混ぜた物質に替える。燃料の媒質は替えない。入力の
  書き方（ADR-0097 の「基準の形状に対する変更」の形）は、制御棒の軸を入れる実装で格子計算の燃料の分岐とそろえて決める
- 媒質は制御棒の軸を持たない。平板の連続の軸だけを媒質の軸と照らし合わせ、制御棒の軸の各値で同じ媒質の状態を使う
- 制御棒の値の定数は、その層全体に棒があり、燃料には棒がない平板から作る。部分挿入の区間は、部分挿入の ADR の方法で
  core が混ぜる。燃料の層に棒があるときの反射体側の f* は、棒のない燃料で割った値のままである（近似。大きさは
  確かめていない）
- [ADR-0097](0097-tabulate-branches-on-a-full-grid.md) の「反射体のテーブルは制御棒と支持格子の軸を持たない」は径方向の反射体について書かれており、上の軸方向の
  反射体の層には当てはめない。ADR-0097 の本文との食い違いは、制御棒の軸をテーブルに入れる ADR で ADR-0097 を
  置き換えるときに、あわせて直す

### ADR-0101 から引き継ぐもの

この ADR は [ADR-0101](0101-impose-transport-current-ratio-at-vacuum-faces.md) を置き換える（accepted にするとき、フロントマターの `supersedes` に ADR-0101 を入れ、ADR-0101 を
`status: superseded` にする。proposed のあいだは ADR-0101 が有効）。変えるのは z の面の扱い（ADF を 1 に固定しない、z の `vacuum` を許す）だけで、
次はそのまま有効である（ADR の運用。docs/adr/README.md）。

- 格子計算は、真空の辺ごと・少数群ごとに r = J/φ_het（MOC の辺の外向きの正味の中性子流と不均質な面の中性子束の、辺に
  わたる平均の比。細かい群の和）を出す。0 < r ≤ 1 の外はエラー。少数群定数は真空の辺にだけ r を持つ
- core の `vacuum` の面は J = r f φ を課し、入射は i = β o、β = (1 − 2 r f)/(1 + 2 r f)。`marshak` は r = 1/2 で、P1 の
  関係を置くことを入力で明示したときだけ使う。外周がすべて鏡面反射の格子の定数で外周を真空にするときは `marshak` を書く
- 面の条件は GET（K. S. Smith, Prog. Nucl. Energy 17, 303 (1986)）のとおり f φ と正味の中性子流を連続にし、入射は
  i = ((f' − f) o + 2 f' o')/(f + f')。反射（β = 1）と中性子束 0（β = −1）は f によらない。ADF は少数群定数の必須の値で、
  欠けたり正でなかったりすればエラー。辺の対応は −x が左、+x が右、−y が下、+y が上、−z と +z は z の辺
- 横方向の漏れの2次式では、真空（`vacuum` と `marshak`）の面の漏れを、ノードの漏れ × 面の中性子束 / ノード平均とする。
  真空の面のノード平均が正でなければエラー
- r を少数群定数に持ち、core が格子計算の途中の量から作らない（状態の分岐のテーブルに入れる量になるため）。アルベドの
  境界は core にない

## 確認

数値はまだない。実装の PR で、次のテストと比較で確かめる。

- 媒質: 外周が鏡面反射の格子の媒質を、同じライブラリの均質な格子（全体が媒質）で解くと、k が元の格子の k に、細かい
  群の中性子束が元の格子の平均に、固有値の収束の許容差で一致する。形式の往復と、群境界・次数・軸の不一致のエラー
- 混ぜた物質: 仕様書の表 P3-3 のトップノズル、ボトムノズル、炉心板の個数密度を、SS304 とホウ酸水（3A の 1300 ppm と
  3B の 1066 ppm）の `mix` が表の有効数字で再現する。割合の和が 1 でないときのエラー
- 少数群定数の6つの辺: 2次元の格子計算の z の辺の ADF が 1、`axial = true` の辺の対応、`height` の往復と検査、
  回転が z の辺を変えないこと。core: z の面の ADF の跳びが x、y と同じ解析解に合う（`side_mapping_matches_two_region_analytic`
  を z に広げる）、z の `vacuum` の解析解（`vacuum_ratio_matches_analytic` を z に）、z の幅と `height` の不一致、
  f* の向かいが核分裂のない物質のときのエラー
- 平板の等価性（examples に Problem 3A の平板を置く）: core の 1 × 1 × N のノード（径方向は鏡面反射）に平板の全ノードの
  定数（燃料のノードも平板から）を置くと、MOC の k とノード平均の中性子束を再現する。判定の閾値（案）は I 型の結果
  （k +1.5 pcm、中性子束 10⁻⁴。ADR-0095）に合わせ、k ±5 pcm、ノード平均の中性子束の相対 10⁻³
- f*の方法の誤差: 燃料のノードを単一集合体の定数（z の ADF 1）に替えた k とノード平均の中性子束の差を記録する
  （I 型は −129 pcm、1.4%）。燃料のノードの高さ（core の燃料の端のノードの高さ）を変えたときの f* の変化も記録する
- Problem 3A と 3B（3B は Pyrex とシンブルプラグの平板）を、core（燃料は単一集合体のテーブル、軸方向は平板のテーブル）
  で解き、同じ核データの OpenMC（3D）と KENO の値（仕様書の表 P3-4。3A は k 1.175722 ± 0.000005、軸方向の
  オフセット 0.163%、3B は 1.000154 ± 0.000006、−0.062%。軸方向の出力は付録 D）と比較する。OpenMC との比較はコード
  同士の検証で、KENO は ENDF/B-VII.0 なので核データの差を含む。判定の閾値（案）: OpenMC に対して k ±100 pcm、
  集合体の軸方向の出力（KENO の 49 の層）の差の RMS 1%、最大 3%（ユーザーの決定が要る）。支持格子の層（#0011）が
  ないあいだは、その差を分けて記録する
- 制御棒の軸: 上の層のテーブルが制御棒の値ごとの状態を持ち、下の層と、トップノズルより上の層が持たないこと。
  Problem 5 の全引き抜きの状態で、上の層の制御棒の値を棒なしに替えたときの k の差を記録し、反射体の層の棒の効きの
  大きさを示す（部分挿入の ADR の Problem 5 のバンクの価値の比較とあわせる）

## 結果

- 上の軸方向の反射体の層は制御棒の離散の軸を持つ。吸収体（とくに AIC）は層の断面の中で体積で混ぜるので、棒の中の
  中性子束のくぼみ（空間の自己遮蔽）を表さず、吸収を大きく見積もる候補がある（大きさは確かめていない）。全引き抜きの
  棒の効き（上の「確認」）が KENO との差に比べて無視できないときに、棒のセルを中性子束で均質化した媒質を混ぜる形を
  #0030 で検討する
- 少数群定数の形式が6つの辺と `height` に変わり、テーブルと既存の例の定数を作り直す。core の z の面の場合分け
  （ADF を 1、z の `vacuum` をエラー）がなくなる
- 格子計算に、媒質の出力と読み込み、混ぜた物質（`mix`）、`axial = true` が加わる。格子計算のノードごとの均質化の
  「反射体のノードは燃料と少なくとも1辺で接する」の検査は、燃料と接しない軸方向の層（ノズル、炉心板、水）を許す
  ように変える。燃料と接しない反射体のノードは、f* でない GET の ADF を持つ（径方向の燃料に接しない反射体は #0034）
- 平板は燃料を均質化するので、燃料の上下の端のピンの不均質と、燃料の端の支持格子を表さない。Problem 3 の上下の端の
  出力の差が大きいときに、ピンの帯の模型（上の検討した案）か支持格子の層の媒質（#0011）を見直す
- 層の物質は無限希釈で、層の断面は体積で混ぜる。#0008 で真空の辺のある格子の Dancoff 係数を決めたら、層の物質を
  構造材の塊として遮蔽する（[ADR-0086](0086-shield-structural-lumps.md)）ことを比較する
- 媒質の P1 以上の散乱のモーメントはスカラー中性子束で重みづけする。鏡面反射の格子では正味の中性子流が 0 で、
  中性子流のモーメントの重みが定まらないための近似である（B1 の拡散係数の均質化と同じ）
- 燃料の層の定数は単一集合体の格子のままなので、反射体に近い燃料のスペクトルの変化は f* の方法の誤差として残る
  （径方向の I 型の −129 pcm と同じ種類）
- Problem 5 の径方向の反射体の位置の、軸方向の反射体の高さの定数（反射体と反射体の角）は決めていない（#0034 とあわせて
  決める）
- ADR-0095 の軸方向の決定を実装に落とした。ADR-0101 は z の面の扱いを除いて引き継いだ
