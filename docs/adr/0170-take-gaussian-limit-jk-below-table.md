# ADR-0170: 非分離共鳴の J, K は、θ が 10⁻³ より小さい行を芯の幅で伸ばして積分し、10⁻¹⁰ より下はガウス形の線形状の級数で求める

## 背景

非分離共鳴の自己遮蔽の J, K 積分は、(log10 β, log10 θ) の表（θ = 10⁻³〜10⁶）から補間し、θ が表より大きければ Lorentz の
線形状の解析式を使う（[ADR-0107](0107-use-natural-line-shape-beyond-jk-table.md)）。燃焼チェーンの核種の棚卸しで、VERA の燃料の温度（565〜1200 K）で θ が 10⁻³ より小さく
なり、止まる評価が 10 あった（Nd-148、Nd-150、Sm-154、Gd-160、Au-197 など。#0119）。Au-197 の非分離共鳴は Γγ = 1e-9 eV の
系列を 2 つ持ち（ほかの系列は 0.04〜0.13 eV）、θ は 600〜1200 K で 1e-10 を下回る。

J と K の積分は x = tan φ と置いて [0, π/2] を適応 Gauss-Kronrod で求める。θ が小さいと線形状の芯は x ≈ 2/θ まで広がり、
φ = π/2 の近くの幅 θ ほどに潰れる。θ の下限を 10⁻¹⁰ にして表を作ると、この置換のままでは積分が 10,000 区間で収束しなかった
（fix/0119-jk-small-theta、2026-10-14）。

## 検討した案

- 案 A: 表の θ の下限を、評価の θ を含むまで下げる（10⁻¹⁴ など）: 表の下限が評価のデータ（Γγ の小さい系列）で決まり、それより
  小さい θ の評価でまた止まる。10⁻¹⁰ にしたあと Au-197 が 9.9e-11 で止まり、10⁻¹⁴ に下げた試み（同じブランチ）は、この理由で
  捨てた。行も 361 から 801 に増える
- 案 B: θ が小さい点で、希釈の極限 J = π/(2β) に切り替える: 希釈の極限の相対の誤差は ψ の最大値/β ≈ (√π/2) θ/β で、止まった
  点の β ≈ 1e5、θ ≈ 1e-3 では約 7e-9 になり、ADR-0107 の許容誤差 1e-10 を超える
- 案 C′: すべての θ で積分の変数を芯の幅 max(1, 2/θ) で伸ばす: 置換が 1 つになるが、燃料の主な核種が使う θ ≥ 10⁻³ の行の
  積分も変わる。θ ≥ 10⁻³ は x = tan φ のままで収束するので、変える理由がない
- 案 C: θ が小さい行は積分の変数を芯の幅で伸ばし（x = (2/θ) tan φ）、表を 10⁻¹⁰ まで延ばす。その下は、ドップラー幅に比べて
  自然幅が無視できる線形状 ψ = (√π θ/2) e^{−u²}（u = θx/2）で、b = 2β/(√π θ) とした J = (2/θ) ∫ g/(g + b) du、
  K = (2/θ) ∫ g(g + 2b)/(g + b)² du（g = e^{−u²}）を 1/b の冪に展開して項ごとに積分した級数で求める（採用）。Voigt の
  線形状との差はローレンツの裾による相対 θ の程度（伸ばした積分と比べて 0.24〜0.46 θ。θ = 10⁻⁶〜10⁻¹¹、b ≥ 2.8）で、10⁻¹⁰ より
  下では 1e-10 より小さい。θ の下限がなくなる

## 決定と理由

案 C にする。

- 積分: θ < 10⁻³ では x = (2/θ) tan φ と置き、θ ≥ 10⁻³ は x = tan φ のままにする。θ ≤ 0 はエラー
- 表: θ = 10⁻¹⁰〜10⁶（間隔は log10 で 0.025 のまま。行は 361 から 641）
- θ < 10⁻¹⁰ で b = 2β/(√π θ) ≥ 10⁴: J = (√π/θ) Σₙ₌₁ (−1)ⁿ⁺¹ b⁻ⁿ/√n、K = (√π/θ) Σₙ₌₁ (−1)ⁿ⁺¹ (n + 1) b⁻ⁿ/√n（∫ gⁿ du = √π/(2√n)）。
  b ≥ 10⁴ では 5 項で倍精度に収束する（表の下限 θ = 10⁻¹⁰ と表の β の下限 10⁻⁶ で b ≈ 1.1e4）。b が倍精度を超えないよう、
  先頭の項 π/(2β) でくくって計算する

## 確認

- crates/xs/src/resonance/line_shape/tests.rs: `quadrature_approaches_the_gaussian_limit_for_narrow_lines`（θ = 10⁻⁶〜10⁻¹¹ で、
  伸ばした置換の積分が、テストの中で独立に書いた級数と、b ≈ 2.8 の芯の形まで 0.6 θ + 1e-12 の内で合う）、
  `table_takes_the_gaussian_limit_below_its_theta_range`、`table_meets_the_gaussian_limit_at_its_lower_theta_edge`（表の下限の内と
  外で、直接の積分と 1e-10 の内で合う）、`gaussian_limit_stays_finite_for_the_narrowest_lines`、
  `table_rejects_nonpositive_theta`、`integrals_need_positive_theta`、`stretched_substitution_matches_simpson_below_a_thousandth`
  （θ = 3e-4 で、伸ばした置換の J と K が置換によらない Simpson 則と 1e-6 の内で合う）、`table_covers_resonances_narrower_than_a_thousandth_of_the_doppler_width`、
  `table_matches_direct_integration`（θ = 10⁻³〜10⁶ と 10⁻¹⁰〜10⁻³ で別に選んだ点で、補間と直接の積分が 1e-6 の内）
- 棚卸しのツール（crates/chain/examples/survey_neutrons.rs）で、#0119 の 10 評価が VERA の燃料の温度と σ0 の 9 点で読める
  （xlc 1d16ba74、分岐点 bf5f08ef、2026-10-14。そのあとのコードのコミットは、θ ≤ 0 と b < 10⁴ の扱いと、θ < 10⁻¹⁰ の級数の
  計算の順で、10 評価の点の値は丸めの程度でしか変えない）

## 帰結

- θ の小さい非分離共鳴（核分裂生成物の偶偶核など）を持つ評価を、VERA の燃料の温度で処理できる
- 表の原点が動き、格子の θ と補間の重みが丸めの程度で変わる。examples/vera の Ag-109 の段階の出力（565、600 K、σ0 9 点）で、
  群定数の相対差は最大 4.3e-16（xlc 4149736f、分岐点 bf5f08ef、2026-10-14）
- 表の行は 361 から 641 に増える。構築は、ほかの計算と重なった実行で 1 秒未満で（時間は記録しない）、xs の核種ごとの処理
  （数秒〜数分）に比べて小さい
