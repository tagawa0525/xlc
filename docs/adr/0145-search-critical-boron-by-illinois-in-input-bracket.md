# ADR-0145: 臨界ホウ素濃度は、入力で与えた範囲を囲い込んだまま Illinois 法で探す

## 背景

VERA Problem 5（全炉心の零出力試験）は、臨界ホウ素濃度の実測値を与える（仕様書の表 P5-1、P5-2。初臨界は D バンク
167 ステップで 1285 ppm、全引き抜き（ARO）で 1291 ppm。どちらも B-10 を 19.9 at% に換算した値）。xlc の core は、
ケースで状態を与えて k を解くだけで（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md)、[ADR-0105](0105-load-core-by-assembly-ids.md)）、k が目標になるホウ素濃度を探す仕組みが
ない。

k はホウ素濃度に対して単調に減り、ほぼ線形である（KENO-VI の ARO の 2 点は、1291 ppm で 1.000321、1170 ppm で
1.012841。表 P5-6 の場合 2、11。反応度で −10.21 pcm/ppm）。ホウ素濃度は分岐のテーブルの軸で、格子点の範囲の外は
内挿でエラーになる（ADR-0097）。

- 正確さ: 求めたホウ素濃度で解いた k が、目標から入力で決めた許容の中にあること。探索の途中の点で外挿しないこと
- 実行の速さ: 1 回の評価が全炉心の固有値計算なので、評価の回数を少なくする
- 保守の容易さ: 実装と入力が小さいこと
- 黙った既定を作らない（CLAUDE.md、[ADR-0137](0137-compute-options-as-input.md)）: 範囲、目標、許容、回数の上限を入力で受ける

## 検討した案

探索の方法:

- 二分法: 必ず収束するが、評価の回数が多い。決定の例の範囲 300 ppm から、k の許容 1e-6（ホウ素濃度で約 0.01 ppm）まで狭めるには、
  両端と log2(300 / 0.01) ≈ 14.9 回の切り上げで約 17 回
- 割線法: k がほぼ線形なので数回で収束するが、囲い込みを保たないので、途中の点がテーブルの範囲の外に出うる（そのときは
  内挿のエラーで止まる）。k が曲がっていると収束が保証されない
- Newton 法（微分ホウ素価値を摂動で求める）: 摂動の計算（随伴）が core にない
- Brent 法: 囲い込みを保ち、逆 2 次補間で速いが、ほぼ線形な関数では割線の系と回数がほとんど変わらず、実装が大きい
- Illinois 法（採用。囲い込みを保つ割線法 = regula falsi の変形。M. Dowell, P. Jarratt, "A modified regula falsi
  method for computing the root of an equation," BIT 11, 168–174 (1971)。新しい点が直前の点と同じ側なら、
  残った端の関数値を半分にする）: 囲い込みを保つので途中の点が範囲の外に出ず、超 1 次（次数約 1.44）で収束する。線形な関数
  なら両端のあと 1 回で解に着く

範囲の与え方:

- 1 点の初期値から探す: 範囲を広げる規則（刻みと上限）が要り、それが黙った既定になる
- テーブルのホウ素の格子点の両端を範囲にする: 入力は要らないが、端の点は解から遠く評価が増え、テーブルごとに範囲が
  違うので共通の範囲を求める処理が要る
- 入力で範囲を与える（採用）: 両端で k が目標を挟むことを確かめ、挟まなければエラーにする。範囲がテーブルの外なら
  内挿のエラーで止まる

## 決定と理由

ケースの状態（[ADR-0146](0146-solve-named-states-of-a-case-in-parallel.md)）に `search` を書くと、core はその状態の `boron` の代わりに、k が目標になる
ホウ素濃度を Illinois 法で探す。

```toml
[state.aro]
b10 = 0.199
moderator = 565
fuel = 565
search = { boron = [1100.0, 1400.0], k = 1.0, tolerance = 1.0e-6, max-solves = 20 }
```

- `boron`: 探す範囲（ppm。下端 < 上端）。両端で解いた k − 目標の符号が同じならエラー（範囲が解を挟まない）。端で
  すでに許容の中なら、その端を解とする
- `k`: 目標の k（正）
- `tolerance`: 収束の判定。|k − 目標| ≤ `tolerance` になった点を解とする。ホウ素濃度の幅でなく k で判定するのは、
  比べる量（臨界）が k で定義されるため。NEM の固有値の反復の k の判定（`nem::Options` の `k_tolerance`）以下の値は
  区別できないので、解く前にエラーにする。判定は、反復ごとの k の変化が等比で減ると仮定して見積もった残りの誤差
  （crates/core/src/nem.rs の `Remaining`）で、仮定が外れれば k の誤差は判定より大きくなりうる。そのときは判定を
  超える許容でも、探索は収束せずに回数の上限で止まりうる（誤差の大きさは確かめていない）
- `max-solves`: 固有値計算の回数（両端を含む）の上限。両端のほかに 1 点を解けるように 3 以上。超えたらエラーにして、
  最後の範囲と両端で解いた k を示す。k が有限でなければエラーにする
- `boron` と `search` はどちらか一方だけを書く（両方、どちらもなしはエラー）
- 出力: 求めたホウ素濃度、固有値計算の回数、その点の k。その点の解（核分裂率、ピン出力）は、探索の最後に解いたもの
  を出す（解き直さない）

Illinois 法は、囲い込みを保つので探索の点が入力の範囲（したがって、範囲を確かめたテーブルの格子点の中）を外れず、
k がほぼ線形なホウ素濃度では割線法と同じく数回で収束する。二分法より評価が少なく（正確さは同じ許容で決まる）、
Brent 法より実装が小さい。

### 帰結

- 探索の評価のたびに、固有値計算を一様な初期値から解き直す。前の評価の中性子束から始めれば反復が減る候補だが、
  `nem::solve` は初期値を受けない。必要になったら（全炉心の時間を測ってから）入れる
- 探索の状態は 1 つのタスクの中で固有値計算を順に数回解くので、ホウ素濃度を与えた状態と並列に解くと、全体の時間は
  探索の状態が決める（ほかのコアは先に空く）
- 探索の対象はホウ素濃度だけ。ほかの量（バンクの位置、温度）を探す場面が出たら、`search` に同じ形で足す

### 確認

- 探索の関数（crates/core/src/search/tests.rs）: 線形な関数は両端のあと 1 回で解に着くこと、曲がった関数でも許容の
  中に収束すること、範囲が解を挟まないとき・回数の上限を超えたときにエラーになること。曲がった関数
  k = 1/(0.8 + 2e-4 ppm) を 0〜3000 ppm、許容 1e-10 で探すと 9 回（同じ条件で、片方の端が残る regula falsi は 16 回、
  二分法は 33 回）
- 炉心（crates/core/src/case/tests.rs）: ホウ素の軸（1000、1500 ppm）を持つ 2 群のテーブルの 2 × 2 の集合体の炉心
  （+x の面だけ中性子束 0）で、k が範囲の中で 1.127 から 0.884 まで曲がって下がる。許容 1e-7 で 8 回の固有値計算で
  1225.985 ppm に収束し、その点で解き直した k が探索の k と一致した。範囲がテーブルの外、範囲が解を挟まない、許容が
  固有値の判定（1e-8）以下のときはエラーになる（いずれも 21820f36、2026-10-12）
