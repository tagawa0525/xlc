# ADR-0003: 段階の間で共有する計算は、2つ目の段階が使う時点で共通のクレートに切り出す

## 背景

段階のクレートは互いに依存できない（[ADR-0002](0002-keep-stage-crates-independent.md)）。同じ計算を2つの段階で使うには、共通のクレートに切り出すか、
複製するしかない。

## 検討した案

- 段階ごとに複製する: 高速化や修正を二重に行うことになる
- 2つ目の段階が使う時点で共通のクレートに切り出す（採用）

## 決定と理由

段階の間で共有する計算は、2つ目の段階が使う時点で共通のクレート（`xlc-numeric` など）に切り出す。複製すると
高速化や修正を二重に行うことになるため。予定しているものと、移したもの:

- CMFD の粗メッシュのソルバ: M3 で core が使うときに切り出す。形状に依存しない演算子と反復だけを共通にし、結合係数の
  作り方と細かい領域への戻し方は段階に残す（MOC と NEM でそれぞれ持つ）
- 燃焼のソルバ: M4 で、lattice の燃焼と core のミクロ燃焼が使う。lattice の中に置かないのは、冷却計算を輸送計算なしで
  単独で動かすためでもある。M4 で分岐計算の流し方（lattice の1回の実行の中で燃焼と分岐を行うか、燃焼点の状態を
  ファイルで渡すか）を決めても、燃焼のソルバを共通のクレートに置くことは変えず、そのクレートが受け渡す型をそれに
  合わせて決める
- Gauss-Legendre の分点と Legendre 多項式: xs と lattice の両方にあったので、M3 の初めに `xlc-numeric` に移した

## 確認

構成の約束事で、確かめるテストはない。

## 帰結

- 段階ごとのソルバの設定は、同じ値でも共有しない（[ADR-0004](0004-keep-solver-settings-per-stage.md)）
- 線形代数は faer で解く（[ADR-0007](0007-use-faer-for-linear-algebra.md)）
