# ADR-0142: 燃料でない棒の塊は、UFG の範囲を Dancoff 係数を合わせた等価なセルの減速計算で遮蔽する

## 背景

燃料でない物質の塊は、黒体の Dancoff 係数と平均弦長から等価原理の σ0 を求め、Bondarenko の表を Carlvik の2項有理近似で
引いて遮蔽している（[ADR-0086](0086-shield-structural-lumps.md)）。VERA 2G（AIC の制御棒 24 本）で、xlc の k は OpenMC より 222 pcm 低い
（吸収体のない 2E-empty は +45 pcm）。正味の吸収の差に分けると、AIC の 4 eV〜15.03 keV の吸収が k で −259 pcm
（9.877 eV〜15.03 keV −83、4〜9.877 eV −177）を占める（examples/vera/verification.md の「k の差の内訳」の 2G の節。OpenMC と xlc は
ea8aa99b、2026-10-12）。

核種ごとの実効断面積（反応率 / 中性子束）では、Ag-109 の 5.19 eV の共鳴の群（27 群、4〜9.877 eV）が +15.0% で、中性子束を
OpenMC に固定した 1 次の近似で k に −212 pcm 効く。同じ群の In-115 は −23%（+51 pcm）、Ag の 21〜25 群は −4〜+9% で、AIC の
核種の 4 eV〜15.03 keV の計は −201 pcm。燃料の U-238 でも、等価原理は UFG の重みのライブラリと組み合わせると共鳴吸収を
多く見積もった（[ADR-0068](0068-solve-pinwise-slowing-down.md)）。

- 精度（評価済みデータだけから決まり、経験的な補正を持たないこと）
- 燃料のピンと同じ仕組みで扱えること

## 検討した案

- 等価原理のまま（[ADR-0086](0086-shield-structural-lumps.md)）: 上のとおり、AIC の 4 eV〜15.03 keV の吸収を多く見積もる（k で −201 pcm）
- λ（IR）のような係数で σ0 を補正する: 経験的な補正を持つので採らない（ADR-0068 のサブグループ法と同じ理由）
- 棒のセルを UFG の減速計算で解く（採用）。`cell_ufg` の例（cb314009）で、2G の AIC のセルを、帯をそのまま、最後の水を
  半径 2 cm と 4 cm の円まで延ばした白色境界の円筒（ほぼ孤立した棒。2G の AIC の塊の Dancoff 係数は 27 群で約 0.01）で
  解くと、Ag-109 の 27 群は +3.8%、+4.6%、In-115 の 27 群は −4.8%、−5.0%、AIC の核種の 4 eV〜15.03 keV の計は −9、−23 pcm
  になる（OpenMC は ea8aa99b、2026-10-12）。外半径をピッチの正方形と面積の等しい 0.711 cm にすると（同じ棒の格子の影が
  入る）、Ag-109 の 27 群は −19% になり、棒の外の水の量に強くよる。そこで、燃料のピンと同じく、塊の Dancoff 係数を
  合わせた等価なセルで解く
- 棒の平均の実効断面積を棒のすべてのリングに置く（等価原理と同じ形）: 2b83441b で試した。実効断面積は合う（AIC の核種の
  4 eV〜15.03 keV の 1 次の近似の計 +9.6 pcm）が、MOC の棒の中の中性子束が 4〜9.877 eV で OpenMC より 5.7% 高く（等価原理の
  ときは +0.6%）、AIC のその範囲の吸収の差は k で −131 pcm 残り、2G の k の差は −113 pcm（k の推定値）にとどまった
  （OpenMC は ea8aa99b、2026-10-12）。平坦な群定数で解く MOC の空間の自己遮蔽が、減速計算の中性子束の形と合わないため。
  等価原理の +15% の断面積は、この中性子束の誤差を打ち消していた
- 棒のリングごとの UFG の群定数に SPH 因子を掛ける（燃料のピンと同じ。採用）。c33c5135 で、2G の k の差は +63 pcm、AIC の
  4〜9.877 eV の正味の吸収の差は k で −24 pcm、中性子束の差は −0.8%、AIC の核種の 4〜15.03 keV の計は +24 pcm になった（OpenMC は
  c582b3ba の `openmc_balance.py`、2026-10-12）。3 つの版の 2G の k の差は、等価原理 −212 pcm、棒の平均を全リングに −102 pcm、
  リングごと +63 pcm（xlc は順に 1f4fcaaf、2b83441b、c33c5135。参照解 0.848986 との差）

## 決定と理由

塊のうち、ピンセルの内側のリングを（扇形すべてで）ちょうど埋める、燃料でない物質の塊を棒とする。棒の物質が分離共鳴を
持つ核種を含めば、次の範囲の群を UFG の減速計算で遮蔽する。

- 範囲: ライブラリのポイントワイズの断面積の下限から、棒の物質の核種の分離共鳴の上端のうち最も高いもの（UFG の上限の
  頭打ち、[ADR-0069](0069-cap-cell-slowing-down-at-20-kev.md)）以下で最も高い群の境界まで（燃料のピンの範囲と同じ決め方を、燃料でなく棒の物質の核種で行う）
- 等価なセル: 棒のリング、その外の帯（減速材の前まで）、減速材のリング（外半径は、UFG の範囲の群ごとに塊の Dancoff 係数を
  合わせた外半径の平均）、セルに枠があれば枠のリング。燃料のピンの等価なセル（[ADR-0068](0068-solve-pinwise-slowing-down.md)、[ADR-0088](0088-add-frame-ring-to-equivalent-cell.md)）と同じ作り方
- 棒のリングの群定数: 範囲の群は、等価なセルの棒のリングごとの UFG の群定数に、燃料のピンと同じ SPH 因子
  （[ADR-0071](0071-correct-with-sph-factors.md)。等価なセルのすべてのリングを合わせる）を掛けたもの。範囲の外の群は等価原理のまま（ADR-0086）。
  棒の外の帯（被覆管、案内管、水）は、等価なセルの値を使わず、これまでどおり塊か無限希釈とする
- 塊の実効断面積（報告用）: 範囲の群は、棒のリングの UFG の群定数を中性子束と体積で平均したもの

棒の中の散乱源の形と、核種の間の共鳴の重なりを、評価済みデータから直接解ける。燃料のピンと同じ減速計算を使うので、新しい
近似を持たない。

### 帰結

- 2G の k の差は −212 pcm から +63 pcm になり、吸収体のない 2E-empty（+45 pcm）からの変化は −257 pcm から +18 pcm になった。
  2H（B4C）は分離共鳴の核種を持たず、0.789520 のまま。ピン出力の差は 2G で rms 0.12%、最大 −0.38%（(9, 8)）
- 吸収体のリングの数は k に効く（5 リングは収束した値より 2G で約 −9 pcm。2G は等面積の 5、10、20 リングで 0.849616、0.849682、
  0.849699）。リングの数は #0059 で扱う
- 範囲の下（4 eV より下）の In-115 の 1.46 eV の共鳴の翼（28 群 +14%、31 群 +11%。k で −94 pcm）は残る（#0001）
- 等価なセルの外の燃料の共鳴が、棒に入る中性子束に作るくぼみは入らない（燃料のピンの等価なセルと同じ近似）

### 確認

`absorber_rods_are_shielded_by_slowing_down`、`absorber_rod_rings_take_their_own_cross_sections`、`physical_flux_restores_the_rod_sph_factors`。

2G の k は 0.849616、OpenMC（参照解）は 0.848986 ± 0.000050 で、差は +63 pcm（xlc は c33c5135、2026-10-13。#0082 の作業で
rebase の前後とも同じ値）。2G の内訳は examples/vera/verification.md の「k の差の内訳」の 2G の節。
