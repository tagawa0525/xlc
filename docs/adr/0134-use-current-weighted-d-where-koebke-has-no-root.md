# ADR-0134: 核分裂のないノードの等価な D は、Koebke の D が面の均質な中性子束を正にする範囲にないとき、中性子流で重みづけた D にする

## 背景

[ADR-0104](0104-weight-transport-cross-sections-by-currents.md) は、核分裂のないノード（反射体）の拡散係数を Koebke の等価理論の D（ノードの正味の中性子流の向きの
2つの面で、均質な1ノードの解の面の中性子束の比を、参照の不均質な面の中性子束の比 t に合わせ、2つの面の不連続因子を
等しくする D）とし、解がなければエラーにすると決めた。

軸方向の反射体の平板（[ADR-0128](0128-make-axial-reflector-constants-in-a-full-height-slab.md)。VERA 3A）の「下のギャップと端栓」のノード（5.898 cm。ボトムノズルと燃料の間の、
水と Zircaloy の層）で、熱群の Koebke の D の根は 0.00113 cm にしかなく、そこでは均質な −z の面の中性子束が負
（−0.0712）で、ADF を作れなかった。熱群の正味の流れは両面とも外向き（−z 4.66 × 10⁻⁴、+z 4.97 × 10⁻⁴）で、ノード平均
（0.00660）は両面の不均質な中性子束（0.00549、0.00512）より大きい。根を探して評価した D のうち、面の均質な中性子束が正の
点の均質な比 φ+/φ− は 0.99999999〜11.84 で（D を大きくすると 1 に近づく）、不均質な比 t = 0.933 に届かない
（examples/reflector/verification.md、ebb35b2e、分岐点 9f34e390、2026-10-12）。高速群の
中性子束が燃料に向かって 2.5 倍に上がり（0.0073 → 0.0182）、熱群の源（減速）が燃料側で大きいので、均質な熱群の解は
燃料側で高くなるが、不均質な面の熱群の中性子束は燃料側で低い（燃料が熱中性子を吸う界面の効果が候補。確かめていない）。
群の源の形と不均質な面の比が逆向きのとき、Koebke の D の前提（t を再現する D が正の面の範囲にある）が崩れる

判断の軸:

- 原理で決まり、手で層やノードを選ばない
- 定数を作った体系での等価性（GET。[ADR-0103](0103-define-adf-by-one-node-kernels.md)）を保つ: GET の1ノードの問題は、面の均質な中性子束が正なら、
  どの D でも ADF が差を受け持ち、参照の k とノード平均を再現する
- 黙ったフォールバックにしない: どちらの D を使ったかと、その根拠を出す

## 検討した案

- 層を束ねる（例: 下のギャップと端栓をボトムノズルと1つのノードにする。そうすると熱群の Koebke の D は 0.251 cm で
  両面が正、ADF は 1.024）: 束ねる層を手で選ぶことになり、原理で決まらない。「Koebke の D が存在するまで隣と束ねる」と
  書けば機械的になるが、層の境が解の性質で決まり、炉心のメッシュがそれに縛られる。ADR-0128 の層（ADR-0095 の層ごとの
  ノード）を保てない
- 核分裂のないノードの D を、中性子流で重みづけた D だけに統一する: 下の水（50 cm、外側が真空）で、高速群の均質な真空の
  面の中性子束が負（−2.2 × 10⁻⁶）になる。Koebke の D（2.80 cm）では両面が正（ADR-0104 の I 型の結果と同じ種類）
- Koebke の D の範囲の端（正の面の範囲で比が t に最も近い D。このノードでは D → ∞）を使う: 不連続因子が極端になり、
  D が範囲の取り方で決まる
- Koebke の D が正の面の範囲にあればそれを、なければ中性子流で重みづけた D を使う（採用）

## 決定と理由

- 核分裂のないノードの等価な D は、Koebke の D（ADR-0104 の定義）が、面の均質な中性子束を正にするときはそれを使う。
  根が見つからないか、見つかった根で面の均質な中性子束が正でないとき（群の源の形と不均質な面の比が逆向きのとき）は、
  ノードのすべての群で中性子流で重みづけた D（ADR-0104 の outflow の D）を使う。どちらでも GET の1ノードの問題の
  ADF が差を受け持つので、定数を作った体系の等価性は保たれる
- どちらを使ったかと、Koebke の D がない根拠（その群、不均質な比 t、根を探して評価した点のうち面の均質な中性子束が
  正の点の、均質な比の範囲）を `tracing::info` で出す
- `xlc_numeric::equivalence::equivalent_diffusion` は、正の面の範囲に根がないことを、エラーでなく戻り値（`Equivalence::Missing`）
  で返し、呼ぶ側（格子計算）がこの規則で選ぶ。面が負になる根を解として返さない。正味の中性子流がない、核分裂のある
  ノード、群の間の反復が収束しないときは、これまでどおりエラーにする
- 中性子流で重みづけた D でも面の均質な中性子束が正にならなければ、GET の1ノードの問題がエラーにする（黙って別の D に
  しない）

この ADR は ADR-0104 の「解がない…ときはエラーにし、別の D に替えない」の部分だけを置き換える。ADR-0104 のほかの部分は
変わらない。ADR 全体の置き換えではないので、ADR-0104 の前付けは変えない（ADR-0129 と ADR-0013 と同じ扱い）。

## 確認

- `slab_gap_node_has_no_koebke_d_and_takes_the_current_weighted_d`（crates/numeric/src/equivalence.rs）: 平板の下のギャップと
  端栓のノードの1ノードの問題の入力で、Koebke の D がない（熱群、t = 0.933、正の面の比はすべて t より大きい）と判定し、
  中性子流で重みづけた D（1.682、0.764 cm）で両面の均質な中性子束が正になる
- `slab_water_node_at_vacuum_takes_the_koebke_d`: 下の水（−z が真空）では、中性子流で重みづけた D で真空の面が負になり、
  Koebke の D（両面の ADF が等しい）を選ぶ
- `impossible_equivalences_are_missing_or_errors`: 源のない群で解がないときは `Missing`、正味の中性子流がない、核分裂の
  あるノードはエラー
- VERA 3A の平板（examples/reflector/verification.md、ebb35b2e、分岐点 9f34e390、2026-10-12）: 中性子流で重みづけた D になったのは下の
  ギャップと端栓のノードだけで、上側の層（プレナム、上の端栓とギャップほか）は Koebke の D。core は平板の MOC の k を
  −0.0000 pcm、ノード平均の中性子束を相対 5.8 × 10⁻⁷ の内で再現する

## 帰結

- 2つの面の ADF は、Koebke の D のないノードでは等しくない。core の面の条件は両側の ADF をそのまま使うので、等価性には
  効かない
- 定数を作った体系と違う体系（炉心）で、2つの D の選び方の違いがどう効くかは確かめていない
- 不均質な面の熱群の中性子束が燃料側で低くなる原因は確かめていない
