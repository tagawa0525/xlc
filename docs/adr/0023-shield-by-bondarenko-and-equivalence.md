# ADR-0023: 共鳴の自己遮蔽は Bondarenko の f-table を等価原理の σ0 で引いて扱う

## 背景

全体計画の最初の版（2026-10-06）で、共鳴の自己遮蔽の方式を決める必要があった。まず全体を端から端まで通すことを
優先した。

## 検討した案

- サブグループ法: 実装が複雑
- Bondarenko の f-table と等価原理（採用）
- Dancoff 係数をピンセルの衝突確率法で求める（全体計画の最初の版）: 無限に並んだ同じピンを仮定するので、案内管の隣や
  集合体の端でのピンごとの違いが出ない
- Dancoff 係数を集合体全体の黒体の燃料の MOC で求める（M2 で採用）

## 決定と理由

自己遮蔽は Bondarenko の f-table（背景断面積 σ0 と温度に依存する遮蔽因子）で扱い、格子計算の側で等価原理と Dancoff
係数を使って σ0 を決める。サブグループ法より実装が単純で、まず全体を通すことを優先した。

M2 で次のとおり詳細を決め、実装した（2026-10-07）。

- 燃料の各核種の背景断面積 σ0 を、他の核種の断面積と、Dancoff 係数を入れた燃料の脱出断面積（Carlvik の2項有理近似）
  から求め、ライブラリの σ0 ごとの断面積を補間する。σ0 は他の核種の遮蔽された断面積に依存するので、反復で求める
- Dancoff 係数は、燃料を黒体にした固定源の MOC を集合体全体で解き、ピンごとに求める。集合体の MOC はすでにあるので、
  それを使う。群ごとに求め、被覆管と減速材にはその群の全断面積と、無限に広がれば中性子束が 1 になる一様な等方線源
  （散乱なし）を置く。孤立したピンへの入射の流れ（周長 × 1/4）に対する、燃料の吸収率の不足分を C とする
- ライブラリの σ0 の格子点の間は、断面積を ln σ0 に線形に補間する。格子の外はエラーにする
- 脱出断面積は Dancoff 係数 C を入れた Carlvik の2項有理近似とする。A = (1 − C)/C から
  α₁,₂ = [(5A + 6) ∓ √(A² + 36A + 36)] / (2(A + 1))、β₁ = ((4A + 6)/(A + 1) − α₁)/(α₂ − α₁)、β₂ = 1 − β₁
  （C = 0 で Carlvik の α = 2, 3、β = 2, −1）。核種 k の背景断面積は σ0,i = (Σ_{j≠k} N_j σt,j + α_i / l̄) / N_k
  （l̄ はペレットの平均弦長 2r）で、実効断面積は2つの σ0 での値を NR 近似の中性子束
  φ_i = σ0,i / (σt(σ0,i) + σ0,i) と β_i で重みづけして合わせる
- 自己遮蔽は燃料の核種にだけ適用し、被覆管と減速材は無限希釈とする。1本のピンの中では σ0 を一様とし、
  ペレット内の半径方向の分布（リム効果）は燃焼を扱う M4 で検討する。共鳴の干渉効果は扱わない

## 確認

`isolated_rod_gives_carlvik_coefficients`、`coefficients_are_ordered_and_betas_sum_to_one`、
`interpolates_shielded_cross_sections_in_ln_sigma0`。VERA のピンセルを OpenMC と比べた（examples/vera/README.md）。

## 結果

分離共鳴の範囲で、ピンごとの UFG の減速計算に置き換えた（[ADR-0068](0068-solve-pinwise-slowing-down.md)）。UFG の重みのライブラリと組み合わせると、
U-238 の共鳴吸収を +4〜6% 多く見積もった（VERA 1B で −1887 pcm。NR の重みのライブラリのときは誤差が打ち消し合って
+232 pcm だった。docs/plans/m2-assembly.md、ebb8e81 と 4538492、2026-10-07）。燃料の中の散乱源を平坦とすることと、有理近似に
よる誤差で、方法そのものの限界である（Gibson の MIT 博士論文 2016 の Table 9.72 と 6.7〜6.8 にも同じ向きと大きさの
誤差がある）。

UFG の範囲の外で有効な部分（Dancoff 係数の求め方、Carlvik の2項有理近似、ln σ0 の補間、燃料だけを遮蔽すること）は
[ADR-0074](0074-shield-outside-range-by-equivalence.md) にまとめ直した。そこでは、共鳴の干渉を Bondarenko の方法の反復で近似する。2項を合わせる重みは [ADR-0089](0089-weight-two-terms-with-potential-scattering.md) で
直した。
