# ADR-0131: 均質な解が平らでない格子の角の不連続因子は、格子の中で core と同じ角の点の釣り合いを解いた均質な角の値から作り、真空の辺の流れは均質な角の値に比 r と面の ADF を掛けて課す

## 背景

[ADR-0125](0125-derive-corner-factors-from-lattice-corner-balance.md) は、均質な解が平らでない格子（反射体の格子、ノードごとの均質化）の角の不連続因子（CDF）を、格子の
中で core と同じ再構成の展開（[ADR-0096](0096-reconstruct-pin-power-analytically.md)）と角の点の釣り合い（CPB）を解いて作ると決めた。角の点 p の均質な
値を s_p h̃ とし、大きさ s_p を CPB で求める。外周の真空の辺は、箱の辺を通って出ていく流れを r Φ_p（[ADR-0101](0101-impose-transport-current-ratio-at-vacuum-faces.md) の
辺の比 r = J/φ_het と、角の点の不均質な中性子束 Φ_p）とし、格子では Φ_p が既知なので流れは既知の項になる。core では
Φ が未知数なので、流れは r Φ になる。

真空の辺のある格子で、s_p が負になり CDF を作れなかった（#0065）。燃料のピン 2 × 2 の右と上に幅 6 cm の水を置き、
右と上を真空にした格子（examples/reflector/vacuum-corner の `w6-n*.toml`。69 群のライブラリ、自己遮蔽なし）で、ADR-0125 の
式の角の点の s_p は次のとおりだった（4b34d96e、2026-10-11。入力は 22919c3d でコミットしたもの）。

| 水のマスの 1 辺 | 2 辺が真空の角の点の s_p（高速、熱） | その点の Φ_p の熱群 | 1 辺が真空の角の点の s_p の熱群 |
| --------------- | ------------------------------------ | ------------------- | ------------------------------- |
| 1 cm            | 0.725、−2.284                        | 0.0920              | 0.356                           |
| 0.5 cm          | 0.899、−1.439                        | 0.0535              | 0.455                           |
| 0.25 cm         | 1.007、−0.519                        | 0.0368              | 0.635                           |
| 0.125 cm        | 1.091、+0.215                        | 0.0284              | 0.789                           |

ノード（燃料 2.52 cm、水 6 cm）は同じで、s_p は水のマスの大きさ、つまり Φ_p の見積もりで大きく動く。Φ_p は角の点に
接する MOC の領域の中性子束の平均（[ADR-0108](0108-split-assemblies-with-shared-constants.md) の定義）で、真空の辺の近くで中性子束が急に下がるところでは、領域が
大きいほど点の値より大きい。上の辺を鏡面反射にした同じ格子（1 cm のマス、`w6-n6-top.toml`）でも、真空の辺と鏡面反射の辺の角の点の熱群で
0.039 だった（同じコミット）。5-2D の外周の角に当たる角型の反射体の格子（examples/reflector/reflector-corner.toml。燃料 1 体と
反射体 3 つ、右と上が真空）では、2 辺が真空の角の点の s_p が（−0.217, −8.18）、真空の辺と鏡面反射の辺の角の点で
（0.463, 0.740）だった（同じコミット）。

2 辺が真空の角の点にはノードが 1 つしかなく、CPB は J_x + J_y = (r_x + r_y) Φ_p（J はノードの展開の、角の点での外向きの
流れ）になる。均質な角の値を上げると、面の平均の流れを保ったまま角の点の外向きの勾配が緩むので、展開の角の点の流れは
下がる。右辺が、角の値 0 の展開が出す流れより大きいと、均質な角の値は負になる。右辺は、不均質な点の値（を見積もった
領域の平均）と、辺にわたって平均した比 r の積で、どちらも均質な展開の量でない。

一方、同じ展開と CPB は、拡散の世界では 2 辺が真空の角でも正の値を与える。核分裂のない 2 群のノード（−x、−y は反射、
+x、+y は J = φ/2）で、細かいメッシュの拡散の解のノード平均と面の流れから CPB で解いた角の値は、拡散の解の角の値に、
真空の 2 辺の角で幅 3 cm、6 cm、12 cm のノードについて 2%、6%、20% 未満（熱群の拡散距離 4.3 cm。ノードが大きいほど
過大）、ほかの角で 1% 未満で一致する（numeric の `vacuum_corners_follow_the_fine_mesh_diffusion`）。拡散の世界では Φ_p が
点の値で、比が辺にそって一定なので、ADR-0125 の式もここで決める式も同じになる。したがって負の s_p は、展開がその形を
表せないことでなく、真空の辺の流れを不均質な点の値で与える CPB の立て方から来る。#0027（4 次の多項式の NEM で面の
中性子束が負になる）とは仕組みが違う。ここの展開は解析的な関数で、ノードの幅を半分の 3 cm にしても ADR-0125 の式の s_p は
負のままだった（`w3-n6.toml`、0.5 cm のマスで熱群 −0.467。同じコミット）。

- 定数を作った体系では、core の再構成が参照の角の不均質な中性子束とピン出力を再現すること（ADR-0125 と同じ）
- 原理で決まり、手で合わせる係数を持たないこと。MOC の領域の分け方で CDF を作れるかどうかが変わらないこと
- 黙ったフォールバックを足さず、作れない場合はエラーにすること

## 検討した案

ADR-0125 の案の比較（角の均質な中性子束の定義、反射体の CDF の持ち方、形状関数）はそのまま有効で、ここでは繰り返さない。
真空の辺の角の点については次を比べた。

- 今のまま（ADR-0125。流れは r Φ_p）: 背景のとおり、s_p が MOC の領域の大きさで負になる。角の点に接する領域を細かく
  すれば正に近づくが、0.125 cm でも熱群 0.215 で、1 辺が真空の点も 0.79 にとどまり、収束していない。CDF を作れるかと
  その値が、真空の角の近くの領域の分け方に強く依る
- 真空に接するノードを分ける（真空の辺から拡散距離の数倍の幅に区切る）: 背景のとおり、ノードの幅は主な原因でない（3 cm
  でも負）。角型の反射体の格子のノードの形（#0029）を変え、core のノードの数も増やすのに、Φ_p の見積もりの問題は残る
- 核分裂のないノードの展開を ANM の形（[ADR-0102](0102-solve-non-fissile-nodes-with-anm.md)。x と y の 1D の形）にする: 拡散の世界では今の展開が真空の
  角を正で表せるので（背景）、原因に当たらない。core の再構成も同じ展開を使うので、両方が変わる大きな変更になる
- 真空の角の近くの領域を細かく分けることを入力に求める: 領域の大きさが CDF を作れるかを決めることになり、原理で
  決まらない。どこまで細かくすれば十分かの基準もない
- 真空の辺の角の点の CDF を作らず、core で別に扱う（見込み h̃ をそのまま均質な角の値にするなど）: 定数を作った体系で
  CPB の解が参照の Φ を再現しなくなる。別扱いの規則を決める原理もない
- 角の点の比 r_p = J_p / Φ_p を MOC から別に出す: MOC の辺の流れは辺の区間でしか定まらず、点の流れの定義が要る。Φ_p の
  見積もりの問題も残り、少数群定数に新しい量が増える
- 真空の辺の流れを、均質な角の値 φ_c に比 r と面の ADF f を掛けた r f φ_c とする（採用）: core の真空の面の条件
  （ADR-0101。面の平均で J = r f φ̄、f φ̄ が不均質な面の中性子束）を、均質な解の境界の条件として面にそって点ごとに置き、
  その端の角の点にも同じ条件を置くことに当たる。ADR-0096 の CPB の式（「真空は J = r f φ」）の字面とも同じになる。均質な
  角の値は均質な量（ノードの定数、ノード平均、面の流れ、r f）だけで決まり、不均質な Φ_p は CDF = Φ_p / 均質な角の値に
  だけ入る。ADF の分母の均質な面の中性子束を均質な量だけから作る（[ADR-0103](0103-define-adf-by-one-node-kernels.md)）のと同じ形になる

PARCS の理論マニュアル（v3.0、5.1.3 節、式 (5.23)、(5.24)、(5.34)、https://www.nrc.gov/docs/ML1016/ML101610117.pdf ）は内部の
角の点の CPB だけを書き、外周の境界の角の点の扱いを書いていない。SIMULATE-3 の扱いは一次情報で確かめていない（ADR-0125 の
帰結の一覧）。

## 決定と理由

CDF は、どの格子でも「角の不均質な中性子束 / core の再構成が定数を作った体系で与える角の均質な中性子束」とする。角の
均質な中性子束は、格子の中で core と同じ展開と CPB を解いて求める。ADF を、core と同じノードの核で1ノードずつ解いた均質な
面の中性子束で作る（ADR-0103）のと同じく、core が使う式で格子の中の均質な解を作れば、定数を作った体系で core が参照を
再現するためである（ADR-0125 と同じ）。

CPB の外周の真空の辺（core の `vacuum` と `marshak`）を通る流れは、ノードの均質な角の値 φ_c に、その辺の比 r（ADR-0101。
`marshak` は 1/2）と、ノードのその辺の ADF f を掛けた r f φ_c とする。格子でも core でも同じ式で、どちらでも未知数に比例する
項になる。均質な角の値は均質な量だけで決まり、MOC の領域の分け方に依らない。ADR-0125 の r Φ_p は、角の点の不均質な
中性子束を均質な展開の境界の条件に持ち込み、その点の値を角に接する領域の平均で見積もるので、真空の近くで負の均質な
角の値を求めることがあった（背景）。

格子のノードごとの均質化（`nodes`。[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）では、次の順に作る。格子全体の出力（`output`。外周がすべて鏡面反射の
単一の格子）は ADR-0096 の作り方のままとし、ノードが 1 つの `nodes` で作った値との違いは、形状関数の分母の正規化だけで
ある。

- 角の点 p の不均質な中性子束 Φ_p は、角の点に接する格子の中の領域（角の点を頂点とする 4 つの象限のうち格子の中にある
  もの）の中性子束の平均とする（ADR-0108 の定義。集合体の外周の角では ADR-0103 の余白の角のセルの値と同じ）
- ノード n の角 c の均質な値の見込みを h̃_{n,c} = φ_x,c φ_y,c / φ̄_n とする。φ_x,c と φ_y,c は角 c を含む x と y の辺の、
  ADR-0103 の1ノードの問題の均質な面の中性子束（ADF の分母）、φ̄_n はノード平均の中性子束
- 格子の中で、ノード n の角 c の均質な値を s_p h̃_{n,c}（p は角 c の点）とし、角の点と群ごとの大きさ s_p を、core と同じ
  CPB の連立一次方程式で求める。ノードの展開は ADR-0096 のもので、格子のノードの定数、格子の k、MOC のノード平均の中性子束、
  MOC の辺ごとの正味の流れ（ADR-0103 の1ノードの問題と同じ量）、軸方向の漏れ 0 を与える。外周の鏡面反射の辺は流れ 0、
  真空の辺は r f s_p h̃_{n,c}（f は ADR-0103 の、f* で割る前のそのノードの ADF）とする。連立方程式が特異なとき、s_p が
  正でないときはエラーにする
- CDF_{n,c} = Φ_p / (s_p h̃_{n,c})

この CDF で、定数を作った体系は参照を再現する。core の NEM（燃料）と ANM（反射体）は、GET の ADF で参照のノード平均と面の
正味の流れを再現する（ADR-0103）。すると core の再構成の入力は格子のものと同じになり、Φ = Φ_ref のとき各ノードの均質な
角の値 Φ_p / CDF_{n,c} は格子の中の s_p h̃_{n,c} に戻る。真空の辺の流れも r f × 均質な角の値で格子と同じになるので、core の
CPB は Φ_ref で満たされる。CPB の解は一つなので、core は Φ_ref を求め、ノードの展開は格子の中のものと一致する。形状関数を
その展開で作れば（下）、ピン出力も参照に一致する。

見込みの比 h̃ は、角の点を囲むノードの間の均質な値の比だけを決め、大きさは CPB が決めるので、定数を作った体系での再現には
効かない。効くのは別の体系（燃料が代表と違う炉心）だけである。積の形にしたのは、次の理由による（ADR-0125 と同じ）。

- 均質な解が一方向にしか変わらない格子（I 型の境の角）では、h̃ は角を含む辺の均質な面の中性子束になり、角のノードの間の
  比が面の ADF の比（f*）と同じになる
- 均質な解が平らなら h̃ = φ̄ で、s_p = 1 が CPB を満たすので、CDF は単一の格子の定義（角の不均質な中性子束 / ノード平均）に
  なる
- 均質な面の中性子束は正（ADR-0103 がそれを確かめてエラーにする）なので、h̃ も正になる

反射体の CDF は、燃料の CDF で割って持つ（ADR-0125 と同じ）。

- 反射体のノード（`reflector`）の角のうち、角の点が燃料（核分裂のある）のノードにも接するものは、C*_{n,c} = CDF_{n,c} / H_p
  を持ち、少数群定数の形状のデータ（`pins`）にその角の印を付ける。H_p は、格子の中で角の点 p に接する燃料のノードの、
  その点の CDF の調和平均とする。Φ_p が共通なので、調和平均で割ることは、反射体の均質な角の値を、燃料のノードの均質な
  角の値の算術平均に対する比で持つことに当たる
- core では、印の付いた角の CDF を C*× （炉心でその角の点に接する燃料のノードの CDF の調和平均）とする。印の付いた
  角の点に燃料のノードがなければエラーにする（f* の面の検査と同じ）。core はどのノードが格子で反射体だったかを知らない
  ので、格子と core のどちらも、燃料を核分裂の有無で見分ける
- 反射体のノードの、燃料のノードに接しない角（反射体どうしの角、外周の真空の辺の角）は、CDF をそのまま持つ
- 割る相手を特定の燃料（面で接するもの）に限らないのは、L 型の角の点のように面で接する燃料が2つあるときと、角型の
  反射体のように斜めにしか燃料に接しないときにも、同じ規則で決まるためである。定数を作った体系では、割った値と掛ける値が
  同じなので、どの規則でも再現は変わらない

形状関数と core の扱いは次のとおりとする（ADR-0125 と同じ）。

- 格子のノードごとの均質化でも、`pins` を作る。形状関数は f_g（セル）= セルの少数群 g の核分裂率の平均 /
  （ノードの Σf,g × 上で再構成した均質な中性子束のセルの平均）とする。均質な解が平らなら、単一の格子の定義（解析的な
  体積で平均したノードの核分裂率で割る）と、分母の正規化（トラックの体積で平均した Σf と φ̄）の比だけ違う
- 反射体のノード（核分裂がない）も、形状関数を 0 にした `pins` を持ち、CPB に入る。core は反射体のノードを含む層の再構成を
  エラーにせず、反射体のノードの展開を、その定数（[ADR-0104](0104-weight-transport-cross-sections-by-currents.md) の Koebke の等価な D を含む）から作る
- 再構成の展開と CPB の式は、lattice と core の両方で使うので、共通の計算のクレート（`xlc-numeric`）に置く（[ADR-0003](0003-extract-shared-computation-on-second-use.md)。
  lattice は core に依存しない。[ADR-0002](0002-keep-stage-crates-independent.md)）。格子の中の CPB と core の CPB は、同じ関数で式を組む。真空の辺の流れも
  均質な角の値に比例する項なので、両者の違いは均質な角の値と未知数の比（格子は h̃、core は 1/CDF）だけになる
- 集合体を分けた部分ノード（ADR-0108）は変えない（外周が鏡面反射の集合体の定数を分けるもので、均質な解を平らとする）

この ADR は ADR-0125 を置き換える。変えたのは CPB の真空の辺の流れ（r Φ_p から r f × 均質な角の値）だけで、ADR-0125 の
ほかの決定は上に書き直して含む。

## 帰結

- 少数群定数の形式は変わらない。真空の辺のある格子の CDF の値が変わるので、真空の辺のある反射体の格子の定数は作り直す
- 均質な角の値は、MOC の領域の分け方に依らない。CDF には Φ_p（角に接する領域の平均）が入るので、CDF の値は領域の
  分け方に依る。定数を作った体系の再現には効かない
- 2 辺が真空の角では、展開が拡散の解の角の値を過大に表す（拡散の世界で、熱群の拡散距離 4.3 cm に対し幅 12 cm の
  ノードで 20% 未満。背景）。定数を作った体系では CDF がこれを吸収する。別の体系では、外周の反射体の角の値の近似として
  残る。外周の反射体の角の近くにピンはない
- 残る近似は ADR-0125 と同じ: 均質な角の値のノードの間の比 h̃（別の体系でだけ効く）、core の燃料の単一集合体の CDF と
  形状関数（周りの集合体の影響を表さない。ADR-0118 の結果）、複数の種類の燃料に接する角の点での調和平均、点の不均質な
  中性子束を接する領域の平均で表す近似（ADR-0103、ADR-0108）、形状関数の分母のトラックの体積と解析的な体積の違い（#0041）
- 格子の中の CPB は、ノードの数が数個の格子では小さい密な連立方程式である。core と同じ組み方なので、#0042（帯行列）を
  入れるときは両方が変わる
- CDF は、ノードの核（ADR-0103）に加えて、再構成の展開（ADR-0096）と h̃ の定義に結びつく。これらのどれかを変えたら、
  テーブルを作り直す
- 一次情報で確かめていないこと: ADR-0125 の帰結の一覧（SIMULATE-3 の再構成の角の扱い、Smith（1986）の GET の角の扱い
  など）。外周の境界の角の点の扱いを書いたものがあれば、ここの案と比較する

## 確認

テスト（What）:

- 2 辺が真空の格子でも、格子のノードごとの定数と形状で core の形の CPB（未知数が不均質な角の中性子束、均質な角の値は
  Φ / CDF、真空の辺の流れは r × ADF × 均質な角の値）を、参照のノード平均と辺の正味の流れで解くと、角の点の不均質な
  中性子束と再構成したセルの核分裂率が格子の値に相対 10⁻⁹ で一致する（lattice の
  `two_vacuum_sides_pins_reproduce_the_lattice`。真空の辺が 1 つの `l_shaped_pins_reproduce_the_lattice`、
  `strip_pins_reproduce_the_lattice` も同じ式で）
- core の真空の辺の角の点の流れは r f × 均質な角の値（CDF と ADF が違うとき。core の
  `vacuum_corners_lose_r_times_the_homogeneous_corner_flux`）
- 未知数の大きさを角の点ごとに変えても、均質な角の値は変わらない（numeric の
  `corner_scales_do_not_change_the_homogeneous_corner_values`）
- 拡散の世界で、2 辺が真空の角の CPB の値が細かいメッシュの拡散の解に近い（numeric の
  `vacuum_corners_follow_the_fine_mesh_diffusion`。背景）
- s_p が正でなければエラー（lattice の `non_positive_corner_scales_are_errors`）
- ADR-0125 から変わらない決定のテスト（`one_reflective_node_keeps_the_assembly_pins`、
  `strip_corner_factors_follow_the_face_discontinuity`、`pins_need_reflector_nodes_without_fission`、
  `normalized_reflector_corners_take_the_fuel_corner_factor`、`normalized_corners_need_fuel_at_the_corner_point`、
  format の `pins_are_checked`、`pins_round_trip_and_share_cells`、core の `rotation_turns_pins_counterclockwise`）

- 「真空の辺の角の点の大きさ」: 背景の格子の系列で、s_p はどれも 0.92〜1.12。2 辺が真空の角の点の熱群は、水のマスを
  1 cm から 0.125 cm にしても 0.947 から 0.922（Φ_p は 3.2 分の 1）で、領域の分け方にほとんど依らない
- 「角型の反射体の格子の角の不連続因子」: 5-2D の外周の角に当たる角型の格子（燃料 1 体と反射体 3 つ、右と上が真空）で、
  s_p はどれも正で、CDF を作れた。2 辺が真空の角の点の熱群の s_p は 0.046 で、見込み h̃ がその点で大きく外れる（再現には
  効かない）

  f* の方法は RMS 1.867% から 1.897% になった
