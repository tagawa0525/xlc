# ADR-0236: 冷却材の B-10 の割合がテーブルと違う状態は、テーブルの B-10 の微視的断面積で個数密度の差を補正する

## 背景

分岐のテーブルは B-10 の割合（ホウ素の中の B-10 の原子分率）をテーブルごとに 1 つ持ち、core はケースの状態の `b10` がテーブルと違えば
エラーにする（[ADR-0097](0097-tabulate-branches-on-a-full-grid.md) の「決定と理由」）。冷却材の B-10 は (n,α) で減り、補給するホウ酸で一部は
戻るので、サイクルの途中の B-10 の割合は天然の値と違う（#0036）。Problem 9 は BOC の B-10 を 19.78 at% と置く（docs/plans/m4-depletion.md の
「冷却材の B-10 の割合の燃焼（#0036）」の項）。濃縮ホウ酸（B-10 を天然より多くしたもの）を使う炉もあるので、天然より大きい割合も扱う（#0036 の起こした時点の
「懸念」の節。経緯は git）。

ここでは、状態の `b10` がテーブルの値と違うときに core が少数群定数をどう求めるかを決める。B-10 の割合を誰が与えるか（入力で与えるか、
core が燃焼で追うか）は別に決める（#0036 の「問題」の未解決の点）。この ADR の入力は、今の状態の `b10`（[ADR-0146](0146-solve-named-states-of-a-case-in-parallel.md)）をそのまま使う。

判断の軸:

- テーブルの B-10 の割合と違う状態で、直接の格子計算の k を再現すること
- 格子計算の回数（テーブルの状態の数）
- core が B-10 の燃焼を追う形（ノードごと、またはサイクルの中で変わる個数密度）に、テーブルを作り直さずに進めること

## 検討した案

- 案 1（ppm の換算）: ケースの (ppm, b10) を、テーブルの b10 で B-10 の個数密度が同じになる ppm' = ppm · (b10 / M(b10)) · (M(b10ₜ) / b10ₜ)
  に直し、今のホウ素の軸で内挿する（M はホウ素の平均の原子質量。[ADR-0106](0106-compose-borated-water-from-density-and-ppm.md)）。格子計算を増やさず、
  ホウ素の軸の内挿が B-10 の個数密度によるスペクトルの変化も含める。B-11 の個数密度のずれは入らない。B-10 の割合が上がると ppm' が上がるので、
  テーブルのホウ素の軸の範囲を換算後の値で決める（19.9 at% のテーブルで 30 at% の 1300 ppm を引くには、約 1978 ppm まで要る）。
  B-10 を core が追うときも ppm' に直せばよいが、B-10 の反応率（個数密度を減らす量）を求める微視的断面積は別に要り、B-10 を追う形に進めない
- 案 2（B-10 の割合を分岐の軸にする）: テーブルに B-10 の割合の軸を足し、ほかの軸と同じく多重線形で内挿する。格子点では直接の格子計算を
  そのまま再現するが、分岐の状態が B-10 の割合の点の数だけ増える（3 点なら 3 倍）。ホウ素の効果は B-10 の個数密度でほぼ決まるので、
  状態の数に見合わない（#0036 の「検討して捨てた形」）
- 案 3（B-10 の微視的断面積の補正。採用）: テーブルに、状態ごとに冷却材の B-10 の均質化した個数密度と少数群の微視的断面積を持たせ、
  core はケースの個数密度とテーブルの個数密度の差に微視的断面積を掛けて少数群定数に足す（ミクロ燃焼の線形の補正（[ADR-0216](0216-tabulate-micro-depletion-cross-sections-per-state.md)）と
  同じ形）。格子計算を増やさない。B-10 の個数密度の変化によるスペクトルの変化（ほかの核種の均質化した断面積の変化）は入らない。
  core が B-10 の個数密度を追うときは、その個数密度をそのまま補正に使え、反応率にも同じ微視的断面積を使える

ユーザーは 3 つの案を比べ、「1と2はほとんど同じかなという気持ちですね。3は入れても悪くないかなとは思います。」（ユーザー 2026-11-07）と答え、
案 3 を採ることにした。

先行事例:

- MPACT（VERA-CS）: 炉心を直接 MOC で解き、冷却材の B-10 の割合を燃焼のステップごとに、炉心の B-10 の吸収率と一次系の体積との比から
  求め直す。割合は入力の状態（`[STATE]`）でも与えられる（B. Kochunas et al., "Operational Reactor Depletion Analysis Capability,"
  CASL-U-2014-0189-000 (2014)、2.4.4 節の式 (2.9)、(2.10)、https://www.osti.gov/servlets/purl/3013447 ）。分岐のテーブルを使わない
  （ADR-0097 の「検討した案」）ので、どの案にも当たらない。同じ報告は、Watts Bar 1 号機のサイクル 1 で、B-10 の燃焼を入れないと
  臨界ホウ素濃度を最大で約 60 ppm 低く見積もると書く（3.6 節）
- RAST-K v2.2: 機能に冷却材と制御棒の B-10 の燃焼を挙げ、B-10 が減った条件の臨界ホウ素濃度を求め直す（"the adjusted critical
  boron concentration can be calculated for considering B-10 depleted condition"。J. Park et al., "Development Status of Nodal Diffusion
  Code RAST-K v2.2," Trans. KNS Spring Meeting (2019)、2.1 節、https://www.kns.org/files/pre_paper/41/19S-731-박진수.pdf ）。求め直しの式は
  書いていない。案 1 の形と読めるが、確かめていない
- CASMO-4/SIMULATE-3: Taiwan Power Company の検証の論文が B-10 の燃焼の計算のモデルを入れたと書く（H.-C. Lin et al., Nucl. Eng. Des. 253,
  71 (2012)、要旨の highlights）。モデルの中身（微視的断面積の補正か、ppm の換算か）は、本文を読めず確かめていない
- PARCS（GenPMAXS の断面積）: ホウ素濃度は分岐の変数（ADR-0097 の「検討した案」の偏微分の木）。B-10 の割合の扱いは、理論マニュアル
  （ADR-0097 の出典）を今回は開けず、確かめていない

## 決定と理由

案 3 にする。格子計算を増やさず、core が B-10 の燃焼を追う形（#0036 の「問題」の未解決の点）に、テーブルを作り直さずに進める。案 1 との精度の
差は、直接の格子計算と比べて測る（「確認」）。

### テーブルに持つ量

`xlc-table` の `boron10` に、`points` の点ごとに次を持つ:

- `density`: ホウ素の軸の物質（ホウ酸水。ADR-0106）の B-10 の、格子（ノードごとの出力ではそのノード）で均質化した個数密度
  N̄ = Σ_r V_r N_r / V（1/(barn cm)。r はホウ酸水の領域、V は格子かノードの体積）
- `total` と `scatter`: B-10 の少数群の微視的断面積（barn）。全断面積と P0 の散乱行列（行が入射の群）。定義は ADR-0216 の「微視的断面積の項目と
  定義」の σᵢ,G の式で、燃焼の領域の代わりにホウ酸水の領域で足す（MOC の中性子束 × SPH 因子 × 体積 × 個数密度で重みを付けた B-10 の群定数を、
  N̄ と少数群の中性子束で割る）。B-10 の群定数は、その領域の物質を作ったものと同じ（自己遮蔽した物質は領域の実効断面積と UFG の範囲の移行、
  自己遮蔽の組成にない B-10 は無限希釈）。N̄ が 0 の点（ホウ素 0 ppm）は、ADR-0216 の案 Z1 と同じく領域で 1 として重みを付け、ホウ酸水の
  体積の割合で割る。ホウ酸水の領域のないノード（燃料や構造材だけ）は、個数密度も断面積も 0（補正は 0）

吸収は少数群定数と同じく全断面積から散乱の行の和を引いたもの。B-10 は核分裂しないので、νΣf と Σf の項目を持たない。

lattice は、テーブルがホウ素の軸を持ち、部分ノードに分けず（`split` が 1）、混ぜた物質（ADR-0128）の成分にホウ酸水がなく、媒質（ADR-0128）が
ないときに書く（どの出力のテーブルにも、ノードごとの出力ではノードごとに）。部分ノードに分けたテーブルと、ホウ酸水を混ぜた物質と媒質の B-10 は、
部分ノードごとの領域と、混ぜた物質と媒質の中のホウ酸水の分（媒質の状態はホウ素の軸に従う）を分けて作る形が要り、使う例がまだないので書かない（#0260）。

### core の補正

状態の `b10` がテーブルのホウ素の軸の `b10` と違えば、core は内挿した少数群定数 f に

Δf = σ_B10(x) (N̄_c(x) − N̄_t(x))、N̄_c(x) = ρ N̄_t(x)、ρ = (b10_c / M(b10_c)) / (b10_t / M(b10_t))

を足す（x は状態、σ_B10(x) と N̄_t(x) はテーブルの `boron10` を少数群定数と同じ重みで内挿した値、M(b) = b M_B10 + (1 − b) M_B11 は
ADR-0106 の AME2020 の原子質量）。ppm と密度が同じなら、ホウ酸水の B-10 の個数密度は b10 / M(b10) に比例するので、均質化した個数密度の比も
ρ になる。足すのは `total`、`absorption`、`scatter`（ADR-0216 の「線形の補正（ADR-0215 との整合）」の項目のうち B-10 に値のあるもの）で、
χ、拡散係数、ADF、形状関数と k∞ は補正しない。`b10` がテーブルと同じなら補正せず、少数群定数はビットで同じ。テーブルが `boron10` を
持たなければエラーにする（推測で進めない）。

- B-11 の個数密度の差は補正しない。B-11 の吸収は B-10 より 6 桁ほど小さい見込み（#0036 の起こした時点の「方針の案」の 1 の文。経緯は git）で、ホウ素の散乱は水の散乱に比べて
  小さい。直接の格子計算は B-11 の差も含むので、比べた差（「確認」）がその効きの上限になる
- 追う核種の微視的断面積（ADR-0216）と履歴の補正（ADR-0215）は、テーブルの `b10` の値のまま使う（B-10 の個数密度の違いによる、ほかの核種の
  スペクトルの変化は、少数群定数と同じく入らない）

### 帰結

採らない（2026-11-07）。実装して、2A の燃焼度 0、20、40 MWd/kg、600 と 1300 ppm で直接の格子計算の k∞ と比べると、この補正の差は 18 at% で
−17.641〜+34.929 pcm（B-10 の割合を変えた効きの最大 2.51%）、30 at% で −266.950〜+86.568 pcm（最大 3.64%。30 at%、1300 ppm、40 MWd/kg）で、
同じ点の案 1 の ppm の換算の 18 at% の +4.389〜+13.705 pcm（最大 0.99%）、30 at% の −7.532〜+17.490 pcm（最大 0.55%）より大きかった（格子計算は
1085a259（Slurm 713）、core と比較は 5753bfd6、分岐点はどちらも main の 7d7b0346、2026-11-07。比較の要約は d5831841 の examples/depletion/branches/compare-core-2A-b10.json）。
補正の差は 18 at% と 30 at% で符号が逆で、B-10 の個数密度の差の 1 次の項がある。B-10 の個数密度によるほかの核種のスペクトルの変化を
持たないことが候補で、確かめていない。ユーザーは測った差を見て「まぁ1でいいよ。」（ユーザー 2026-11-07）と案 1 に替えた（[ADR-0237](0237-convert-coolant-boron-to-the-table-b10-fraction.md)）。
実装（テーブルの `boron10`、lattice の集計、core の補正とそのテスト）はブランチ feat/0036-b10-micro-correction で外した（84e192beb）。
