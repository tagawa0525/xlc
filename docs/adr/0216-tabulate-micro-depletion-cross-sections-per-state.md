# ADR-0216: ミクロ燃焼は ADR-0035 の元素の輸送する核種とその輸送する先行核を追い、テーブルに状態ごとの少数群の微視的断面積と燃焼度の点ごとの均質化した数密度を持つ

## 背景

[ADR-0035](0035-track-history-by-micro-depletion.md) は、core が主要な核種（U、Np、Pu、Am、Xe、Sm、Gd など）をノードごとにミクロ燃焼で追い、追わない核種の残りを
履歴の補正で扱うと決めた。[ADR-0187](0187-tabulate-burnup-branches-from-history.md) は、燃焼度の軸を持つ分岐のテーブル（`xlc-table`）に、核種の名前の列、燃焼度の点ごとの格子で均質化した
数密度、状態ごとの核種ごと反応ごとの少数群の微視的断面積（均質化した反応率 / (均質化した数密度 × 均質化した中性子束)）を置くと決め、
持たせる核種と反応の並びは core のミクロ燃焼を作るときに決めるとした。[ADR-0215](0215-correct-untracked-history-by-history-branches.md)（proposed）は、core が少数群定数を

f = f_table(x, u, r) + Σᵢ σᵢ(x, u, r) (Nᵢ − N̄ᵢ⁰(u)) + Σ_j w_j R_j,r(u)

で求め、履歴の補正の残り R をこの σᵢ と N̄ᵢ で線形の補正を引いて作ると決めた（#0190 がこの ADR を待つ）。ここでは、追う核種、チェーンとの
関係、微視的断面積の定義と項目、Xe と Sm の扱い、線形の補正の形を決める。core の燃焼の解き方（ノードの燃焼、ステップ）は
[ADR-0190](0190-advance-node-burnups-by-midpoint-steps.md) の続きとして core のブランチで決める。

判断の軸:

- 公称の条件で燃焼させたノードのミクロ燃焼が、テーブルの N̄ᵢ⁰(u) を再現すること（再現しなければ、公称の条件でも補正が 0 にならない）
- 線形の補正が、輸送で解いた追う核種の分を再現すること（再現しない分は R に入る。ADR-0215 の判断の軸の 1 項 5 pcm）
- 後からテーブルに項目を足すと、本番のテーブルをすべて作り直す（ADR-0033、#0153）

前提:

- 2A の ADR-0209 の既定の燃焼の履歴（examples/depletion/p2/dvc.lock の `lattice@2A`、md5 7efea664）の輸送する核種は 89 で、ADR-0035 の元素の
  核種はそのうち 26（Xe-135、Sm-147、149〜152、Gd-152、154〜158、160、U-234〜236、238、Np-237、239、Pu-238〜242、Am-241、243）
- 「履歴の効き（2A）」（examples/depletion/verification.md。ADR-0215 の「測った大きさ」）は、この 26 核種を履歴の分岐の値に置き換えた組成と履歴の分岐の差
  （追わない核種の分）を、60 MWd/kg で密度の履歴 −170.8 pcm、制御棒の履歴 −546.0 pcm と測った
- 多群ライブラリは、チェーンの反応（ADR-0164）の経路ごとの群の断面積を、チェーンと同じ経路の並びで持つ（[ADR-0172](0172-store-chain-reactions-in-library.md)）
- 多群ライブラリは遅発中性子の族ごとの割合と崩壊定数を持たない（crates/format/src/library.rs のライブラリの形式に、その項目がない。ADR-0186 は
  遅発中性子を χ に入れただけで、即発と遅発を別に持つ形は ADR-0033 の項目を作るときに足すとした）

## 検討した案

先行例:

- SIMULATE5（ADR-0215 の「検討した案」が読んだ Studsvik の資料のスライド 18。この ADR のために開き直していない）: ミクロ燃焼の核種は、見出しが
  「17 actinides/~30 Fission products/BA (node level)」で、項目は 16 のアクチニド、30 余りの核分裂生成物、可燃性毒物（B-10、Gd）。ミクロ燃焼の
  補正は Σᵢ σᵢ (Nᵢ^actual − Nᵢ^SA)（スライド 9 の式）で、ADR-0215 の式の第 2 項と同じ形
- CASMO5 が SIMULATE5 に渡す微視的断面積の核種と項目: 出典を確かめていない
- PARCS と PMAXS: B. Meunier の論文（arXiv:2509.19450。ADR-0097、ADR-0215 が読んだ）は履歴の分岐と巨視的断面積の木を扱い、PARCS が
  どの核種を微視的に追うかは書いていない（出典を確かめていない）
- MPACT（VERA-CS）: 炉心を直接 MOC で解き、領域ごとに燃焼させるので、ミクロ燃焼の少数群のテーブルを使わない（ADR-0097 が読んだ MPACT 4.4
  Theory Manual の 13 章）

追う核種:

- 案 N1: ADR-0035 の元素の、履歴の `transportable` の核種（2A で 26）だけ: 26 核種の値を置き換えた測定（前提）と同じ集合。ただし、追う核種へ
  崩壊か反応で流れ込む輸送する核種（下の先行核）が追わない核種になり、core のミクロ燃焼はその数密度を公称の履歴の値で引くしかない。
  I-135 を追わないと Xe-135 の過渡（Problem 8）を解けない
- 案 N2: N1 に、追う核種へチェーンの崩壊か反応で流れ込む、輸送する核種（先行核）を足す（採用）。2A のライブラリと
  examples/depletion/chain.msgpack では、26 核種の先行核のうち輸送する核種は Cm-242、Cm-244、Eu-153、I-135、Pm-148m の 5 つで、計 31 核種
  （チェーンの崩壊と、輸送する核種の反応の生成物を逆にたどったクロージャ。収率は数えない。輸送しない先行核は 524 で、下の崩壊だけの補助の核種）
- 案 N3: 輸送する核種のすべて（2A で 89）: 追わない核種の分（R）は輸送しない核種の分だけになる。微視的断面積が状態ごとに約 3 倍に
  なり、core のミクロ燃焼に Mo、Tc、Ru、Rh、Cs、Nd などの核分裂生成物の反応が加わる。R を小さくする必要が測られてから
  （ADR-0215 の案 C5）。核種を足すのは入力の列を足すだけで、形式は変わらない
- 案 N4: N1 より少なく（Xe、Sm と主要なアクチニドだけ）: 前提の測定は 26 核種を置き換えたもので、外した核種の分は R に移る。どれだけ移るかは
  測っていないので、ADR-0215 の 5 pcm の目安に対して判断できない

チェーンとの関係:

- 案 C1: core は格子計算の燃焼と同じチェーンのうち、追う核種と、それへ流れ込む輸送しない核種（補助の核種）を解き、補助の核種は崩壊だけに
  する（採用）。格子計算の燃焼も輸送しない核種を崩壊だけで追う（ADR-0173）ので、公称の条件で同じ式になる
- 案 C2: core が追う核種だけの小さなチェーンを持ち、先行核を畳み込む（ADR-0165 の畳み込みと同じ）: I-135 と Xe-135 の過渡は畳み込めない。
  縮約の方式は ADR-0165 で一度決めるもので、core 専用の別の縮約を作らない

微視的断面積の項目:

- 案 X1: 巨視的な補正に使う項目（全断面積、νΣf、Σf、散乱行列）と、燃焼に使う項目（チェーンの反応の経路ごとの断面積、核分裂の収率の重み）を
  核種ごとに持つ（採用）
- 案 X2: 吸収、νΣf、Σf だけ（散乱の変化を落とす）: U-238 などの散乱の変化が全断面積と移行に入らない。項目を後から足すとテーブルを作り直す
- 案 X3: 燃焼の反応を MT ごとに持ち、準安定状態への経路に分けない: core はチェーンの経路（Am-241 の捕獲の Am-242m と Am-242 への
  分岐など）で燃焼させるので、経路への分け方を core で作り直すことになる。ライブラリは経路ごとの断面積を持っている（ADR-0172）

均質化した数密度が 0 の核種（燃焼度 0 の Pu、Xe）の微視的断面積:

- 案 Z1: 燃焼の領域の体積で一様に重みを付けた値（採用）: ADR-0187 の定義（反応率 / 数密度）は数密度で重みを付けた値で、数密度が 0 なら
  決まらない。どの領域で生まれるかは分からないので、燃焼の領域の中で一様とする。燃焼度 0 の点だけに効き、0 の点の補正は ΔN も 0 から始まる
- 案 Z2: NaN か 0 を書く: core が 0 の点と次の点の間を内挿できない

Xe と Sm:

- 案 E1: ミクロ燃焼の中で追い、平衡 Xe（Problem 7）は同じ σ と収率で core が平衡の式を解く（採用）: 過渡の Xe（Problem 8）と燃焼の中の Xe
  （Problem 9）と同じデータで、別のモデルを足さない
- 案 E2: 平衡 Xe をノードの出力から直接求める（Xe を追わない）: 計画（docs/plans/m4-depletion.md の「炉心の燃焼」）の問いのもう一方。
  Problem 8 の過渡を解けない

ADR-0033 のデータ（動特性と冷却計算）:

- 案 K1: この ADR に入れる: ライブラリが遅発中性子の族の量を持たない（前提）ので、族ごとの割合を書けない。冷却計算の全核種の 1 群の
  微視的断面積は、チェーンの全核種（3,820）を扱い、輸送しない核種（ライブラリにない核種）の断面積の出所を決めなければならない
- 案 K2: 別の ADR に残し、#0153 に残す（採用）

## 決定と理由

### 追う核種（案 N2）

テーブルが微視的断面積を持つ核種（追う核種）は、ADR-0035 の元素（U、Np、Pu、Am、Xe、Sm、Gd）の、燃焼の履歴の `transportable` の核種と、
それへチェーンの崩壊か輸送する核種の反応で流れ込む、輸送する核種（先行核）の和にする。2A のライブラリとチェーンでは 31 核種。lattice の
`[history]` の `micro` に核種の名前を挙げ、lattice はどれも履歴の `transportable` にあることを確かめる（ないとエラー。ライブラリにないか、燃焼の
温度のデータがない核種は輸送しないので、微視的断面積を作れない）。選び方の規則（先行核のクロージャ）は、チェーンを読む core が確かめる（core のブランチ）。

- 26 核種は「履歴の効き（2A）」で置き換えた集合で、追う核種の分は履歴の効きの 97.1〜103.5%。先行核を足すのは、ミクロ燃焼が追う核種の
  生成を公称の条件で再現するため（下の「チェーン」）
- 核種を絞らない。絞った分は R に移り、その大きさを測っていない

### チェーン（案 C1）

core のミクロ燃焼は、格子計算の燃焼と同じチェーン（ADR-0165 の「チェーンは 1 つにし、格子計算の燃焼と core で同じものを使う」。縮約の前は
examples/depletion/chain.msgpack の全核種のチェーン）を読み、追う核種と補助の核種（追う核種へ流れ込む輸送しない核種）を解く。

- 追う核種の反応率は、テーブルの微視的断面積 × ノードの中性子束。補助の核種は反応を持たない（崩壊だけ）。格子計算の燃焼も輸送しない
  核種を崩壊だけで追う（ADR-0173）
- 核分裂の生成物は、追う核種のうち核分裂する核種の収率で作る（チェーンの収率。重みは下の `thermal_fission`）。追わない核分裂性の核種の
  収率は数えず、その分は R に入る
- 均質化した反応率は領域ごとの反応率の体積の和なので、σᵢ N̄ᵢ φ̄ は、その瞬間の格子計算の燃焼の領域の反応率の和を格子の体積で割ったものと
  同じになり、公称の条件のミクロ燃焼の dN̄ᵢ/dt は格子計算の燃焼のその瞬間の値と同じ式になる。σᵢ を燃焼度で引くので、Gd の外側から燃える
  自己遮蔽の変化も燃焼度の関数として入る。公称の条件で N̄ᵢ⁰(u) から外れる分は、ステップの離散化と、追わない輸送する核種の反応の分
  （core のブランチで測る）
- 補助の核種は 2A のチェーンで 524（収率で作る短寿命の核分裂生成物の先行核を含む）。ノードごとに解く大きさは core のブランチで測り、
  ADR-0165 の縮約（短寿命の核種の畳み込み）の後に見直す

### 微視的断面積の項目と定義（案 X1、Z1）

`xlc-table` の `micro` に、核種の名前の列 `nuclides`、燃焼度の点ごとの均質化した数密度 `densities`（燃焼度の点ごと、核種ごとの 1/(barn cm)）、
`points` の点ごとの核種ごとの微視的断面積 `states` を持つ。状態ごとに持ち、少数群定数と同じく状態の格子で内挿する（ADR-0187 の置き場のまま）。
核種ごとの項目（少数群、barn）:

- `total`、`nu_fission`、`fission`、`scatter`（P0 の散乱行列。行が入射の群）: 少数群定数の同じ項目の、その核種の分。吸収は少数群定数と
  同じく `total` から散乱行列の行の和を引いたもの
- `reactions`: ライブラリのチェーンの反応（ADR-0172。MT と経路の並び）ごとの、経路ごとの断面積。捕獲は燃焼の輸送と同じく、自己遮蔽した捕獲を
  経路の無限希釈の断面積の比で分ける（crates/lattice/src/depletion.rs の `LibraryReactions`）。core はチェーンの反応と MT と経路の並びで対応させる
- `thermal_fission`: 核分裂率のうち、収率の境界（112.47 eV。[ADR-0183](0183-weight-fission-yields-by-thermal-fast-cutoff.md)）より下の割合。核分裂しない核種は nil。core はチェーンの
  収率の点とこの割合から、ADR-0183 の規則で重みを作る（少数群の境界は 0.625 eV で、境界の上下を少数群の率から作れないので書く）

定義は格子全体の均質化（部分ノードに分けないテーブル）。燃焼の領域 d（体積 V_d、数密度 N_d,i。負の値は輸送と同じく 0）と、格子の体積 V について

N̄ᵢ = Σ_d V_d N_d,i / V

σᵢ,G = Σ_d Σ_{r∈d} Σ_{g∈G} V_r μ_r,g φ_r,g N_d,i s_i,r,g / (N̄ᵢ Φ_G)、Φ_G = Σ_r Σ_{g∈G} V_r φ_r,g

（φ は MOC の中性子束、μ は SPH 因子、s は自己遮蔽した核種の群定数か経路の断面積。少数群定数と同じ MOC の中性子束で重みを付け、物質の
群定数と同じく μ を掛ける）。少数群定数の項目は、燃焼させない物質の分と、輸送するすべての核種の σᵢ N̄ᵢ の和になる。N̄ᵢ = 0 の核種は、N_d,i の
代わりに燃焼の領域で 1 として重みを付ける（案 Z1）。

### Xe と Sm（案 E1）

Xe-135、Sm-149 とその先行核（I-135、Pm-148m。輸送しない Pm-149 などは補助の核種）をミクロ燃焼で追う。平衡 Xe を求めるケースは、同じ
σ と収率で、I-135 と Xe-135 の生成と消滅が釣り合う数密度を core が解く。

### 線形の補正（ADR-0215 との整合）

core は、ノードの少数群定数の `total`、`absorption`、`nu_fission`、`fission`、`scatter` に Σᵢ σᵢ(x, u, r) (Nᵢ − N̄ᵢ⁰(u)) を足す（σᵢ は状態と燃焼度で
内挿した値、N̄ᵢ⁰ は燃焼度で内挿した値。吸収の σ は `total` から散乱の行の和を引いたもの）。χ、拡散係数、ADF、形状関数と k∞ は補正しない
（ADR-0215 の「ミクロ燃焼の補正を持たない項目」で、R の第 3 項も 0）。ADR-0215 の R の第 3 項は、同じ項目に同じ σᵢ を使う。

### 動特性と冷却計算のデータ（案 K2）

ADR-0033 の遅発中性子のデータと群速度の逆数、冷却計算の全核種の 1 群の微視的断面積は、この ADR に含めない。ライブラリに族の量を足す決定と、
輸送しない核種の断面積の出所の決定を別の ADR にし、#0153 に残す。ADR-0033 のとおり本番のテーブルの前に入れる。

  ホウ素の軸だけを作り直す参照の自己遮蔽の両方で同じ）、`micro_reactions_follow_the_library_chain_reactions_and_split_fissions_at_the_yield_cutoff`、

  燃焼度の点 u₁、u₂ の 40 組で、点 u₁ の少数群定数に Σᵢ σᵢ(u₁)(N̄ᵢ(u₂) − N̄ᵢ(u₁)) を足した 2 群の k∞ と、追う 31 核種だけを u₂ の値にした組成の
  格子計算の k∞ を比べた。線形の補正は輸送の効きの 88.41〜113.43% を再現し、誤差 ρ(線形) − ρ(輸送) は −171.91〜+95.20 pcm。5 MWd/kg より後の
  誤差は効きの約 13% までの負の値（反応度の減りを大きく見積もる）で、数密度の差の 1 乗に比例する（原因の候補は #0191）

## 帰結

- lattice は `[history]` の `micro` で、燃焼度の点ごとの N̄ᵢ と状態ごとの σᵢ をテーブルに書く。core はまだ読まない（ミクロ燃焼は core のブランチ。#0153）
- 部分ノードに分けたテーブル（split > 1）の微視的断面積は持たない（lattice はエラーにする）。履歴からの分岐のテーブルを部分ノードで使うときに、
  部分ノードごとの N̄ᵢ と σᵢ を足す
- ノードの中性子束の大きさは、core がノードの出力から求める。格子計算の燃焼は核分裂の Q 値で重みを付けた出力で規格化するので、core も同じ
  重みが要る（#0154）
- ADR-0033 のデータは #0153 に残る
- status は proposed のまま残す。core の側（読みと内挿、ノードのミクロ燃焼と線形の補正）がまだ無く、線形の補正の 1 次の誤差（#0191）で
  補正の形が変わりうるため。core のブランチで帰結と確認を実装に合わせて accepted にする
- 線形の補正は、2A の燃焼のステップの組成の差で輸送の効きの 88〜113% を再現した（「確認」）。誤差は数密度の差に比例する 1 次の差で、
  ADR-0215 の R に入る。原因（共鳴の自己遮蔽の数密度への依存か、数密度の差の空間の分布）を分け、補正の形を見直すのは #0191
