# ADR-0202: 燃焼で増える k の差の候補を、断面積を OpenMC の値に置き換えて測る k への寄与で順位づけて詰める

## 背景

格子の燃焼で OpenMC との k∞ の差が燃焼とともに増え、60 MWd/kg で +176〜+210 pcm になる（2A、2F、2M、2N、2O、2P、2A-density。
2A-rods は +66。examples/depletion/verification.md「集合体の燃焼」）。全炉心の燃焼の前に、この増えの原因を詰める（ユーザーの決定、
2026-10-24）。

- 1C のピンセルの燃焼（同記録「格子計算の燃焼」）の 0 の点からの変化は、5 MWd/kg で 1 リング +118 pcm、4 リング +45 pcm。1 リングの
  分のうち、OpenMC の参照解（シード 1）の 5 MWd/kg が、シード 2、3 の平均より 66 ± 24 pcm 小さい（#0133）ので、1C の燃焼の k の
  変化は候補の寄与を測るには小さく、OpenMC の統計の揺らぎと区別しにくい
- 同じ組成の輸送の差（xlc の組成の差を除いた分）は、1C のピンセルに 2A の 40 MWd/kg の組成を置いた状態（以下 2A-40）で新しい燃料から
  約 +110 pcm 増え（#0133 の 2026-10-23）、2A の燃焼の 40 MWd/kg の輸送の差の増え（+74 pcm。#0133 の 2026-10-22）と同じ向きで大きい。
  候補の寄与は、新しい燃料（1C の 0 MWd/kg）、1C の 5 MWd/kg、2A-40 の 3 つの組成で測る
- 候補は open の issue にある: #0148（高速の群定数の重み。U-238 の核分裂が生成 1 あたり +2.08%）、#0151（熱群の重み。U-238 の
  捕獲が 0.005〜0.1 eV で +0.1〜+0.6%）、#0152（UFG の 4〜10 eV の燃料の中性子束の傾き。U-238 の 6.67 eV の共鳴の下で −1%、上で +1%）、
  #0133 の核分裂生成物（収率の重みを ADR-0183 にする前の数密度の差 Rh-103 −1.6%、Cs-133 −0.5%、I-135 −0.9%。今は Rh-103 +0.2%、
  ほかは ±0.1%）
- 判断の軸: 正確さ（候補を直す前に、その候補の寄与を測定で裏づける）、説明できない補正を入れない、測る費用

## 検討した案

### 寄与の見積もり方

- 案 E: 既に測った反応率の相対差に、OpenMC の tally の生成と吸収の割合を掛ける（δk ≈ k (r ΔP/P − r ΔA/A)。
  `examples/depletion/issue-0133/estimate_candidates.py`、3d56f87e7、2026-10-24）。相対差は各 issue の測定（多くは新しい燃料か 2A-40）
  で、組成によらず同じとみる仮定が入る。数秒で済むが、中性子束の水準の差と、相対差の組成による変化を追わない
- 案 S: 燃料の核種の吸収と核分裂（`swap_absorption`）と、物質の散乱の移行の行（`swap_transfer`）を、核種と群の範囲ごとに OpenMC の
  実効断面積に置き換えて解き、k の変化の符号を変えたものを寄与とする（#0133 の 2026-10-23 と同じ方法を、移行に広げた）。OpenMC の
  ピンセルの tally（1 状態 6〜16 分）と xlc の置き換え（全部で 7 分）で、近似や仮定の少ない測定になる。置き換えは別々に解くので、和は
  足し合わせの近似（残りに相互作用が入る）
- 案 I: 候補の近似を入力の項目で切り替えて、k の変化を測る。今の入力には、候補の近似（UFG の散乱核、熱群と高速群の重み関数）を
  切り替える項目が無い（`LatticeInput` の UFG の項目は飛程の求め方 `collision` だけ）。項目を足すことは、その近似に代わる手法を
  実装することで、#0001 の方式の決定（A か B の試作）が要る。重み関数の温度などを変えて合わせる項目は、合わせる定数になるので足さない
  （#0151）

見積もり（案 E。pcm。範囲は相対差の範囲の両端。新しい燃料、1C の 5 MWd/kg、2A-40 の順。OpenMC は Slurm 448 と 459）:

| --------------------------------------------------------------------- | ---------- | ---------- | ---------- | ------------------ |
| #0148 U-238 の高速の核分裂（+2.02〜+2.08%）                           | +107〜+110 | +115〜+118 | +134〜+137 | +27                |
| #0151 熱群の重み（U-238、Pu-239 の群の比）                            | −21〜−4    | −1〜0      | +3〜+27    | +6〜+48            |
| #0152 4〜10 eV の傾き（U-236、Nd-145、Ag-109、Tc-99、U-238 の 27 群） | −49        | −40        | −19        | +30                |

## 決定と理由

寄与の順位は案 S で測って決め、案 E は測る前の順番づけにだけ使う。案 E は相対差を組成によらず一定とみるので、#0148 の増え（+27）を
過大に見積もった（案 S では +3。U-238 の 15 keV より上の吸収の寄与は新しい燃料 +52.6、2A-40 +49.8 pcm で、相対差が燃えた組成で
小さくなる）。案 I は手法の実装になり、どの候補を先に実装するかを決めるには、先に寄与を測る必要がある。

案 S の測定（examples/depletion/verification.md の「k の差の候補の寄与（#0133）」。xlc は c1ba5cb75、OpenMC の移行は bf927be49、
2026-10-24）で、新しい燃料から 2A-40 への同じ組成の輸送の差の増え +111 pcm は、次の順に分かれる:

1. UFG の範囲（4 eV〜15 keV）+83: 吸収 +44（U-238 の 4〜9.88 eV +24.7、ほかの核種の 4〜9.88 eV +9.9、U-238 の 9.88 eV〜15 keV +9.4）、
   移行 +39（減速材 +25.8、燃料 +13.5）。#0152 の傾きのある 27 群と、その候補（減速材の H の散乱核、ADR-0070）に当たる減速材の移行が
   主で、増えの 4 分の 3 を占める
2. 0.625 eV より下（#0151）+8（U-235 −30.9 と Pu-239、Pu-241 +34.4 が打ち消す）と、0.625〜4 eV +8.7
3. 15 keV より上（#0148）: 吸収 −3.5、移行 +6.6。寄与は新しい燃料で計 +142、2A-40 で +146 と大きいが、燃焼でほとんど変わらない
4. 核分裂生成物 +8.8（2A-40。ほかの行と重なる。うち Xe-135 と Sm-149 +6.2）
5. 残り +16.6（置き換えていない量と、置き換えどうしの相互作用。移行のある実行（Slurm 534）だけで求める）

次に詰めるのは UFG の範囲（#0152）で、原因の切り分け（減速材の H の散乱核と重い核種の静止した標的の扱い）には、案 I の手法の実装が
要る（#0001 の A か B の試作）。#0148 は輸送の差の増えを説明しないが、U-235 の消費の差（−0.17〜−0.19%）を通して組成の差に効く
（2A の 60 MWd/kg の U-235 +1.27%）ので、組成の差の分の測定は別に要る。

## 帰結

- 測る順番は UFG の範囲（#0152）、熱（#0151）、高速（#0148）の組成への効果、核分裂生成物の順。手法の修正はこの ADR の範囲の外で、
  どの候補から実装するかは別に決める
- #0148 の 15 keV より上の寄与（+142 pcm）だけを直すと、新しい燃料の k の差（−46 pcm）が約 −190 pcm になる。新しい燃料の差は、これと
  UFG の範囲の U-238 の吸収（−90）、燃料の UFG の移行（−52）、残り（−127）の打ち消しなので、1 つの候補を直したときの k の差の変化は、
  ほかの候補の寄与と合わせて読む
- 残りが −106〜−127 pcm と大きい（置き換えていない被覆管と減速材の吸収、χ、非弾性散乱と (n,2n)、輸送の補正、相互作用）。状態による
  変化は +20.5（1C の 5 MWd/kg）、+16.6 pcm（2A-40）で、2A-40 の増えの 15% にあたる
- 寄与は Δk（pcm）で、同じ Δ(1/k) でも k の 2 乗に比例して小さくなる。2A-40 の k は新しい燃料の約 0.70 倍なので、反応度では
  2A-40 の寄与は約 2 倍に当たる
- 1C のピンセルの燃焼の 0 の点からの変化（1 リング +118 pcm）は、OpenMC の参照解の揺らぎを含むので、候補の効果を確かめる指標には
  2A-40 の同じ組成の輸送の差を使う
