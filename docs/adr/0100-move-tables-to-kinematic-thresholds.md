# ADR-0100: 運動学的なしきい値より下の断面積は、最初の点をしきい値に移して捨てる

## 背景

ENDF/B-VIII.0 のしきい反応の MF3 には、最初の点（断面積 0）が運動学のしきい値 −Q (A + 1)/A より下にあるものがある。
評価者が |Q| や丸めた値をしきい値として書いたためで、Cd-112 の MT51 は 623.0002 keV から始まるが、Q と AWR からは
623.5708 keV。M3 の新しい核種では 28 核種の 465 反応が当たり、Ti-46、Ti-47、Ti-50 ではしきい値より下に2点ある反応も
ある（examples/m3-nuclides/verification.md）。しきい値より下では反応は起こらず、xs の2体の散乱行列もそこでは中性子を
出さない。

- 物理（しきい値より下に断面積はなく、断面積はしきい値から連続に立ち上がる）
- NJOY と比べて検証できること
- 怪しい入力を推測で補わないこと（[ADR-0013](0013-read-files-strictly.md)）

## 検討した案

- 表をファイルのとおりに使う（M3 の前の xs）: しきい値より下に、出射する中性子のない断面積が残る。NJOY とはしきい値を
  含む群で最大 1.5e-2（Cd-108 の MT104）、大きい反応で 3.0e-3（Cd-112 の MT51 の 6 群）違う
- しきい値で切る: しきい値より下を 0 にし、しきい値から上は表のまま。しきい値に段差ができ、断面積がしきい値から連続に
  立ち上がらない。NJOY との差も残る（Cd-112 の MT51 で約 3e-3）
- 最初の点をしきい値に移し、しきい値以下のほかの点を捨てる（採用）
- エラーにする: 評価済みデータに広くあり（28 核種）、ライブラリを作れない

## 決定と理由

しきい値より下から始まる表は、最初の点をその値のまましきい値に移し、しきい値以下のほかの点は捨てる
（`crates/xs/src/pointwise.rs` の `start_at_threshold`）。最初の点は通常 0 なので、断面積はしきい値から連続に立ち上がり、
しきい値より下は 0 になる。NJOY RECONR も最初の点をしきい値（有効数字 7 桁で切り上げ）に移す。NJOY はしきい値以下の
ほかの点を有効数字 7 桁でしきい値のすぐ上に詰めて並べるが、その幅は 1e-6 程度で群定数には効かないので、捨てる。

核種ごとに1回 `tracing::warn!` を出し、合わせた反応の数、最も大きい移動（eV、しきい値に対する比）とその MT、捨てた点の
数を示す。反応ごとの詳細は debug に出す。移す先は Q 値と AWR から決まり、推測で補う値ではない。

## 確認

`reactions_start_at_the_kinematic_threshold`、`points_below_the_threshold_are_dropped`、
`threshold_shift_is_reported_per_reaction`、`threshold_shifts_are_summarized_per_nuclide`。NJOY GROUPR と比べて、Cd-112 の
MT51 の 6 群の差は 3.0e-3 から 1.1e-4 になり、0 K の無限希釈で 1e-3 を超えて違う反応は 142 から 129 になった。残る差は
GROUPR の積分による（examples/m3-nuclides/verification.md、b564e08、2026-10-09）。VERA 1B〜1D、2B の k は 6 桁まで
変わらない（examples/vera/verification.md、efd37ee、2026-10-09）。

## 結果

- M3 の新しい核種のライブラリでは 28 核種が警告を出す。最も大きい移動は Cd-112 の MT105 の 3.2 keV（しきい値の 3e-4）
- しきい値より下に点が2つ以上ある表の形は、しきい値の上の点だけで決まる
