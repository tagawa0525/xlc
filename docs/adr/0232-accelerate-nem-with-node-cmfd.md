# ADR-0232: 炉心の NEM を、ノードを粗メッシュとし面の部分中性子流で補正する CMFD で加速する

## 背景

炉心の固有値は非線形 CMFD で加速すると決めた（[ADR-0028](0028-accelerate-core-with-nonlinear-cmfd.md)）が、粗メッシュの単位、補正の求め方、
不連続因子（ADF）と外周の扱い、粗メッシュの固有値問題の解き方と許容、既定値、lattice との共有は決めていない。

全炉心の燃焼（Problem 9 の形）の時間は 99.7 % が固有値計算（NEM）で、1 回の固有値計算は外側の反復を 888〜5,674 回回す
（examples/depletion/verification.md の「出力のステップで探す燃焼（Xe とホウ素の同時の反復）」。Slurm 703、7f113d98、2026-11-06）。平らな初期値から
解く点と中点の最初の固有値計算は 4,213〜6,078 回で（#0156）、遅いモードの収束で決まる（[ADR-0231](0231-start-depletion-eigenvalue-solves-from-previous-solution.md)
の帰結）。全炉心の燃焼の速度の対策は、Xe とホウ素の探索の同時の収束、CMFD（#0076）、複数のスレッドの順に進める（ユーザー 2026-11-06 の判断の要約）。

判断の軸: 正確さ > 実行速度 > 保守（CLAUDE.md の「方針」）。

- CMFD は収束した解を変えない加速で、収束の判定（`nem::Options` の許容）は緩めない。加速の有無の解は、どちらも同じ判定を満たす解として許容の 2 倍の
  中で一致すること
- 黙ったフォールバックを作らない。CMFD の作れない状態はエラーにする
- 加速しない経路を入力で選べる形で残す（[ADR-0231](0231-start-depletion-eigenvalue-solves-from-previous-solution.md) の `initial-guess = "flat"`、
  [ADR-0219](0219-solve-cycle-depletion-xenon-at-equilibrium.md) の `xenon-boron = "nested"` と同じ扱い）

## 検討した案

下書き（ブランチ feat/core-cmfd の ADR の下書きの 0119 番、proposed、main に無い。`git show 177d63bc5:docs/adr/0119-accelerate-nem-with-node-cmfd.md`）は、粗メッシュを
NEM のノードとし（案 M1）、面の正味の中性子流で 1 つの補正を決め（案 C1）、ADF を有限差分の結合に入れ（案 F1）、lattice の固有値問題のソルバを
`xlc_numeric::cmfd` に切り出して共有し（案 S1。旧 worktree /home/tagawa/github/xlc-feat-core-cmfd の未コミットの `crates/numeric/src/cmfd.rs` が切り出しの
試し）、粗メッシュの許容を k 1e-10、中性子束 1e-9 からスイープの変化に比例して緩める形だった。

下の測定は、ブランチ perf/0076-core-cmfd の作業中の版（コミットしていない試行。手元、`RAYON_NUM_THREADS=1`、2026-11-06）。同じ機械の別のセッションの
負荷が変わったので、時間は目安。回数は、crates/core の試しのテスト（均質な直方体と平板）と、全炉心の BOC の固有値計算 1 回（Problem 9 の形の台帳と
サイクル、ホウ素 1100 ppm、燃焼度 0、Xe なし、平らな初期値。入力は c68d6320 の `trials/p9-timing/boc-1100.toml`。加速なしは 118 秒、外側の反復
4,165〜4,183 回。examples/depletion/verification.md の「全炉心の燃焼の時間の内訳（Problem 9 の形）」の目安）で数えた。

粗メッシュの単位:

- 案 M1（採用）: NEM のノードをそのまま粗メッシュのセルにする。ノードは集合体か、それを分けた大きさで、すでに粗い
- 案 M2: 複数のノードをまとめた粗メッシュ。均質化の手順が加わり、ノードの面の流れを粗い面にまとめる必要がある。比べていない

補正の求め方:

- 案 C1: 面の正味の中性子流 J で、J = D̃ (f_n φ_n − f_m φ_m) + D̂ (φ_n + φ_m) の 1 つの D̂ を決める（下書き）。D̂ が D̃ f_m を超えると隣との
  結合が正になり、粗メッシュの解が負になった（`neutron_balance_holds` の問題で外側の反復 2 回目に粗メッシュの中性子束 −3.9e-7）
- 案 C2: NEM の均質な部分中性子流（出ていく o と入ってくる i）で、出ていく向きと入ってくる向きに別の補正 D̂⁺、D̂⁻ を決める（partial current CMFD）。
  ADF の比の大きい面では均質な入ってくる部分中性子流が負になりえ（i = ((f' − f) o + 2 f' o') / (f + f')）、結合が正になった
  （`adfs_make_homogeneous_flux_jump_at_faces` の問題で外側の反復 3 回目に粗メッシュの中性子束 −2.3e-6）
- 案 C3（採用）: 不均質な中性子束 ψ = f φ_s と正味の中性子流 J（どちらも面で連続）から作る部分中性子流 ĵ± = ψ/4 ± J/2 で、D̂⁺、D̂⁻ を決める
  （partial current CMFD）。面の両側で同じ値になる

ADF と外周:

- 案 F1（採用）: 有限差分の結合 D̃ に ADF を入れる（D̃ = a b / (a f_m + b f_n)、a = 2 D_n / h_n、b = 2 D_m / h_m）。NEM の面の条件は両側の ADF の比
  だけで決まる（`Core::face_inputs` の β と外からの入射）ので、両側の ADF を両側の平均で割った値を使う。割らない形は、両側の ADF に同じ数を
  掛けると反復の道筋が変わり、`normalized_adfs_take_the_neighbor_adf`（隣の ADF を 1.1 倍にした解の k が 1e-12 の中で同じ）が k の差 2.1e-9 で落ちた
- 案 F2: D̃ を ADF なしの拡散係数で作り、ADF の効果をすべて D̂ に入れる。ADF の大きい面（反射体との面）で D̂ が大きくなる。比べていない
- 外周の面は、外向きの正味の中性子流をすべて D̂ φ_n で表す（lattice の CMFD と同じ。ほかの形は比べていない）

D̃ の大きさ（D̂ が合わせるので、収束した解は変えない）:

- 有限差分の D̃ を 0、0.1、0.25、0.5、1 倍にした: 均質な 18 × 18 × 18 の直方体（22 cm のノード、中性子束 0 の外周、許容を k 1e-13、中性子束 1e-12 に
  詰めた）で外側の反復は 97〜113 回、1 次元の平板（18 ノード）で 89〜106 回で、効きは小さい。有限差分の値（1 倍）にする
- 部分中性子流 ĵ が負の面（強い吸収体のノードなど）は、結合の符号を保つため、D̃ を −4 min(ĵ⁺, ĵ⁻) / S（S = f_n φ_n + f_m φ_m）まで大きくする
  （ĵ + D̃ S / 2 ≥ −ĵ > 0）

CMFD の後の NEM の状態の更新（r はノードと群ごとの比）:

- 案 U1（採用）: 出ていく部分中性子流を、補正の式に CMFD の解を入れて求め直す（ĵ⁺' = r_n ĵ⁺ + D̃/2 f_m φ_m (r_n − r_m) などから均質な o'）。
  展開係数の a3、a4 は r_n を掛け、a1、a2 は更新した面の中性子束とノードの平均から求め直す。a1、a2 にも r_n を掛ける形は、BOC で外側の反復 57 回
  （求め直す形は 53 回）、crates/core の 4 つの問題（`cmfd_converges_to_the_unaccelerated_answer_in_fewer_iterations`）で 33〜114 回（32〜102 回）
- 案 U2: 出ていく部分中性子流に r_n を掛ける（lattice の角度中性子束と同じ）: 1 次元の 1 群 4 ノードの平板（許容を詰めた）で 64 回（案 U1 も 64 回）、
  BOC で 56 回。案 U1 は面の量が両側の比から決まり、NEM の面の条件で求める入ってくる部分中性子流が CMFD の面の量と一致する
- 案 U3: 部分中性子流を更新しない: 同じ平板で 107 回

収束の判定:

- 案 J1: スイープによる変化（CMFD の前）で判定し、スイープの後の状態を返す: CMFD が遅いモードを除くと、スイープによる変化は残りの誤差より小さく
  なり、`starting_from_a_nearby_solution_converges_to_the_flat_start_answer_in_fewer_iterations` で加速しない解との中性子束の差が 2.4e-7（許容の 2 倍の
  2e-7 を超える）になった
- 案 J2（採用）: CMFD の更新を含めた外側の反復の 1 回による変化で判定する（lattice の CMFD と同じ。加速した反復の変化の縮小率で残りを見積もる）

1 回の CMFD の前のスイープの数と順:

- スイープを 2 回、3 回にした: BOC の外側の反復は 59 回から 53 回、50 回で、全体は短くならなかった（10.3 秒、10.5 秒、12.4 秒）
- スイープの向きを外側の反復ごとに逆にした: 1 次元の平板で 64 回から 68 回

粗メッシュの固有値問題のソルバの置き場（[ADR-0003](0003-extract-shared-computation-on-second-use.md)）。lattice の CMFD を同じソルバに移すと、lattice の

## 決定と理由

炉心の NEM の固有値計算（`nem::solve`、`solve_from`、`solve_with`）は、外側の反復ごとに、全群のスイープの後に、ノードを粗メッシュとする partial
current CMFD を解いて更新する（案 M1、C3、F1、U1、J2）。

- **粗メッシュと補正**: 粗メッシュのセルは NEM のノード。方向 d の面でノード n と隣 m が接するとき、不均質な部分中性子流 ĵ± = ψ/4 ± J/2（ψ = f φ_s、
  f は両側の平均で割ったその側の ADF）を ĵ⁺ = D̃/2 (f_n φ_n − f_m φ_m) + D̂⁺ φ_n、ĵ⁻ = −D̃/2 (f_n φ_n − f_m φ_m) + D̂⁻ φ_m と書き、D̂⁺、D̂⁻ をスイープの
  後の値に合わせる。D̃ は有限差分の値（a b / (a f_m + b f_n)）と −4 min(ĵ⁺, ĵ⁻) / S の大きい方。外周の面は外向きの正味の中性子流を D̂ φ_n で表す
- **更新**: CMFD の k と、ノードと群ごとの比 r で、ノードの平均中性子束と展開係数の a3、a4 に r を掛け、出ていく部分中性子流を補正の式から求め直し、
  a1、a2 を面の中性子束とノードの平均から求め直す。そのあと生成率 1 に規格化する
- **収束の判定**: `nem::Options` の許容のまま、CMFD の更新を含めた外側の反復の 1 回による k と中性子束の変化から見積もった残りで判定する
- **粗メッシュの固有値問題**: ブロック Gauss-Seidel のべき乗法（`xlc_cmfd::Coarse`）を、k と組み立てた中性子束から解き始める。許容は k が
  0.3 × max(NEM の k の許容, スイープによる k の変化)、中性子束が 1 × max(NEM の中性子束の許容, スイープによる中性子束の変化)、反復の上限は 100,000
  （[ADR-0110](0110-solve-cmfd-as-finely-as-the-moc-change.md) の考え方で、比は 1 以下）。変化の見積もりは、丸め（相対 1e-14）以下の変化を収束とみなす
- **エラー**: 補正を作るときにノードの中性子束が正でないとき、粗メッシュの解が正でないとき、粗メッシュの反復が上限に届いたときは、外側の反復の番号を
  付けたエラー（`NemError::Cmfd`）で止める。加速しない反復に替えない
- **入力**: ケースの `acceleration`（既定 `cmfd`）。`none` は加速しない（比べるため）。燃焼の履歴には書かない（どちらも同じ収束の判定を満たす解）
- **共有**: 案 S3。`xlc-cmfd` に置き、lattice は #0241 で移す

理由: 案 C3 は面の両側で同じ値の部分中性子流を使い、部分中性子流とノードの中性子束が正なら行列の対角が正、隣との結合が負になる（案 C1、C2 で解が
負になった問題も解ける）。ADF を平均で割るのは、NEM の面の条件が ADF の比だけで決まるのと同じく、CMFD の反復も比だけで決めるため。案 J2 は、加速した
反復の残りを、加速しない反復と同じ見積もり方（変化の縮小率）で求めるため（案 J1 は見積もりが外れた）。粗メッシュの許容の比は、BOC で時間の最も短い
組（0.3、1）にした。案 S3 にするのは、lattice を今移すか `xlc-numeric` を変えると、xs か lattice のステージが changed になり、出力を変えない変更の
ために再実行か `dvc commit` の判断（[ADR-0212](0212-separate-reference-stage-python.md) の条件に当たらない）が要るためで、CLAUDE.md の「保守性が
上がる変更は、実行ファイルがどのみち変わるときなどに費用を数えて行う」に従う。ADR-0003 は共通のクレートを `xlc-numeric` に限らない。

### 帰結

- core のステージの結果は、加速の有無で許容の中の丸めの桁が変わる。examples の core のステージは `bin/core` が変わるので、次に読む作業で再実行する
- 外側の反復の縮小率は加速しても 0.6〜0.85 ほど残る（crates/core の均質な直方体と平板で、許容を詰めた外側の反復 64〜114 回）。CMFD が何もしない 1 つの
  ノードの問題でも 1 群で 21 回かかり、スイープの数と向き、D̃ の大きさ、更新の形を変えても大きく変わらなかった。原因は確かめていない（候補は #0242）
- 全炉心の外側の反復 1 回は平均 77 ms で、加速しない反復の 31 ms の約 2.5 倍（「確認」の全炉心）。差の内訳は測っていない（粗メッシュの問題を
  作って解く時間が候補。ブロック Gauss-Seidel のべき乗法）。Wielandt のシフトや Krylov 法などの解き方は #0242
- 全炉心の燃焼で、同じ解の直前の固有値計算から解く固有値計算（ADR-0231）の外側の反復が 201〜384 回になるものがあり（10 回）、平らな初期値から解く
  点と中点の解の最初の固有値計算（燃焼点 0 のほかは 49〜52 回）より多い。CMFD の下での ADR-0231 の初期値の利得は確かめていない（#0242）
- 強い吸収体（Σt h ≈ 1000）のノードでは、CMFD の更新の後の反復でノードの熱群の中性子束が負になり、エラーで止まる（`cmfd_needs_positive_node_fluxes`）。
  入力の `acceleration = "none"` で解ける
- 燃焼の固有値計算の初期値（ADR-0231）と、Xe とホウ素の同時の反復（ADR-0219）はそのまま使う。前の解から始める固有値計算も加速する
