# ADR-0141: 領域がすべて1つの核分裂のある媒質の、非反射の格子のノードの拡散係数は、その媒質の B1 の D にする

## 背景

ADR-0104 は、非反射の格子とノードのうち核分裂のあるノードの拡散係数を、ノードの領域の中性子流で重みづけした outflow の
輸送断面積から求め、重みが打ち消して ⟨Σtr⟩ が正でなければ、別の定義に替えずにエラーにすると決めた。

VERA Problem 3A の軸方向の反射体の平板（ADR-0128）で、燃料のノードを炉心のノード（仕様書の表 P3-5 の 49 層）と同じ高さに
分けた（f* は燃料の端のノードの高さに依存するため。ADR-0128 の確認）ところ、上端の燃料のノード（7.92 cm、プレナムの隣）で、
熱群の中性子流がノードの中で向きを変え、重みの打ち消しの程度 Σw/Σ|w| が 0.12 になり、⟨Σtr⟩ = −0.16 /cm で格子計算が
止まった（examples/vera/p3 の axial-3A、94abdf2f、2026-10-12）。examples/reflector の平板の燃料の端のノード（22.86 cm と
11.43 cm）では止まらなかった。

平板の燃料は、単一集合体の格子計算が書いた均質な媒質（ADR-0128）で、炉心ではその燃料の層に、同じ単一集合体の格子の
定数（拡散係数は B1。ADR-0104）を置く。

判断の軸:

- f*の方法で、平板の燃料のノードの均質な1ノードの問題が、炉心の燃料のノードと整合すること（f* は反射体の面の ADF を
  平板の燃料の端のノードの ADF で割った値で、炉心はそれに燃料の層の ADF を掛ける）
- 定数を作った体系の等価性（平板の MOC の k とノード平均の中性子束の再現）を保つこと
- 原理で決まり、手で合わせる係数を持たないこと。黙って別の定義に替えないこと

## 検討した案

- 領域がすべて1つの媒質のノードは、その媒質の B1 の D にする: 媒質は単一集合体の格子全体を細かい群のまま均質化した
  ものなので、その B1 の D は、炉心の燃料の層に置く単一集合体の格子の D と同じになる。平板の燃料のノードの均質な問題が
  炉心の燃料のノードと同じ D を持ち、f* が炉心の燃料と整合する。中性子流の重みを使わないので、打ち消しは起きない。
  等価性は、ADF（GET）が D の違いを吸収するので保たれる
- 核分裂のあるノードにも Koebke の等価な D（ADR-0104 の核分裂のないノードの方法を、MOC の k で核分裂の源を固定して
  広げる）: 1ノードの問題の根を群の結合とともに探す実装が重い。D は等価性のために決まり、炉心の燃料の D とは一致しない
  ので、f* と炉心の燃料の整合は得られない
- いまの D のまま、炉心と平板の燃料の端のノードを粗くする（例: 上の 4 層をまとめて 31.7 cm）: コードは変わらないが、
  炉心の軸方向のメッシュに、打ち消しの起きない高さという制約が残る。打ち消しの程度は層の物質と高さで変わり、別の問題で
  再発しうる

## 決定と理由

1 つ目の案にする。

- 格子計算のノードの均質化で、ノードの領域がすべて同じ1つの核分裂のある媒質（入力の `medium` の物質）なら、拡散係数を
  ノードの領域で均質化した細かい群の媒質の B1 で求める（外周が鏡面反射の単一集合体と同じ `b1_diffusion`）。均質な1つの
  物質のノードでは、中性子束で均質化した細かい群の断面積は物質そのものなので、媒質の B1 の D になる
- 領域に媒質とほかの物質が混ざるノード、ほかの媒質と混ざるノード、媒質のないノード、核分裂のない媒質だけのノードは、
  ADR-0104 のまま（核分裂のあるノードは中性子流で重みづけた outflow の D、負ならエラー。核分裂のないノードは Koebke の D と
  ADR-0134）
- これは、ADR-0104 の「非反射の格子とノードのうち、核分裂のあるノード」の規則から、領域がすべて1つの媒質のノードを
  除き、この ADR の規則に置き換えるものである

## 確認

- `nodes_of_one_medium_take_its_b1_diffusion`（crates/lattice/src/fewgroup.rs）: 均質な燃料のセル 2 つと水のセル（右が
  真空）の格子で、燃料のセルを媒質とすると燃料のノードの D が物質の B1 の D に 10⁻¹² の内で一致し、媒質としなければ
  中性子流の重みの D（B1 と 10⁻³ 以上違う）になる。媒質とほかの物質が混ざるノードと、核分裂のない媒質（水）だけの
  ノードの D は、媒質の印のない場合と同じ
- 平板の等価性（examples/vera/verification.md の「Problem 3 の炉心の計算」、d7944df4、2026-10-13）: 燃料のノードを 49 層
  （3B は 52）に分けた 3A と 3B の平板で格子計算が止まらず、core は平板の MOC の k を +0.0000 pcm、ノード平均の中性子束を
  相対 2.8 × 10⁻⁷ の内で再現する
- examples/reflector の平板（examples/reflector/verification.md の「軸方向の反射体の平板の定数を作った体系の再現」、
  d7944df4、2026-10-13）を、ADR-0141 の前のコミット 808c8ce7（燃料のノードは中性子流で重みづけた D）で同じ段階を流した
  試行（分岐点 5bf22a6e、2026-10-13）と比べた。MOC の k、等価性（Δk/k −0.0000、ノード平均の差 3.5 × 10⁻⁷）は同じ。f* の
  方法の Δk/k と燃料のノードの差の最大（高速、熱。どれも上の端の燃料のノード）:

| 平板   | この ADR の D           | 中性子流の重みの D      |
| ------ | ----------------------- | ----------------------- |
| `16`   | −6.1 pcm、−4.2%、−4.2%  | −9.3 pcm、−7.8%、−8.5%  |
| `32`   | −5.3 pcm、−4.6%、−5.5%  | −3.9 pcm、−3.0%、−2.2%  |
| `fine` | −12.6 pcm、−2.1%、−2.1% | −15.7 pcm、−5.5%、−6.1% |

  下のギャップと端栓の +z の f*は、燃料のノード 22.86 cm で（0.991, 0.765）から（1.037, 0.828）、11.43 cm で
  （1.053, 0.853）から（1.077, 0.767）に、プレナムの −z の f* は（0.947, 0.733）から（0.985, 0.841）、（1.006, 0.849）
  から（1.028, 0.777）に変わった。`32` で差が大きくなる理由は確かめていない

## 帰結

- 平板の燃料のノードの D は、平板の中での位置（反射体の隣か）に依らず、単一集合体の B1 の D になる。反射体に近い燃料の
  中性子流のスペクトルの変化は、D には入らず、ADF（f*）に入る
- 媒質を使うのは軸方向の反射体の平板だけなので、ほかの格子の定数は変わらない。examples/reflector の平板の燃料のノードの
  定数は変わる（燃料のノードの D が中性子流の重みから B1 になる）
