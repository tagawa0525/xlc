# ADR-0132: 炉心の外形（装荷図の `-`）に面する面には、そのノードの定数の真空の辺の比 r を課して階段の外形のまま解き、反射体どうしの面も各側の ADF を使う

## 背景

炉心の形の `map` の `-`（ノードを置かない位置）は、NEM が直方体の外周にしか境界を置けないのでエラーにしている
（[ADR-0105](0105-load-core-by-assembly-ids.md)、#0034）。5-2D と Problem 5 の炉心の外周は階段の形で、径方向の反射体の
ノードは燃料との接し方で 3 種類ある（[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）: 燃料と 1 面で接する I 型、
2 面で接する L 型、角の点だけで接する角型。反射体の定数は、それぞれの形の格子で反射体の外側の辺を真空（入射 0）に
して作り、真空の辺には比 r = J/φ_het を持つ（[ADR-0101](0101-impose-transport-current-ratio-at-vacuum-faces.md)）。

VERA の仕様書（CASL-U-2012-0131-004）の 5-2D の反射体は、2 つの形で書かれている。

- 参照の解（付録 J の Case 1、図 M3-2）: バッフル、バレル、中性子パッド、圧力容器を入れ、円筒の容器の外を真空にする。
  集合体のピッチ 21.50 cm で 15 体の幅の炉心の半幅は 161.25 cm、バレルの内半径は 187.96 cm（1.13 節の表 16）なので、
  軸の上で燃料の端からバレルまでは 26.71 cm ある
- バッフルだけの形（Case 2、図 J-1）: 燃料の外に 1 ピッチの厚さの階段の水の層（バッフル 2.85 cm を含む）を置き、その
  外を void、正方形の外周を真空にする。図 J-1 では、燃料と角の点だけで接する位置も水で、水の層の外形は燃料の階段を
  1 ピッチずらした形に見える（図から読んだ）。仕様書はこれを当時の VERA の中性子のコードの能力に合わせた形とし、
  Case 1 との差を表 J-1 に載せる（k で −4.5 ± 1.1 pcm、集合体出力の最大の差 −0.57%、出力 0.8 未満のピンの相対の差
  −5.07%）。Case 2 の出力分布は求めれば渡すとあり、仕様書には載っていない

[ADR-0078](0078-put-baffle-in-reflector.md) は、反射体の定数にバッフルと周りの水までを入れ、バレルより外を除くと決めた。これは Case 2 の形に
当たる。5-2D と Problem 5 の 15 × 15 の炉心は、反射体の輪を含めて 17 × 17 の直方体に入り、その角の側の位置（燃料から
角の点より離れた位置）に Case 2 は水を置かない。

L 型の格子は、今の格子（列の幅と行の高さが格子全体で共通）では仕様の寸法で作れない。燃料のピンの列の境（21.54、
22.80、24.06 cm …）と、その上の反射体の縦のバッフル（21.69〜24.54 cm）の境が合わない（形状の拡張は #0068）。
角型の格子は作れて、角の不連続因子も作れる（examples/reflector/reflector-corner.toml）。

ADR-0095 は、core の反射体のノードどうしの面の ADF を両側とも 1 とした。理由は「同じ物質どうしの面で、比べる参照の
差が小さいと見込む（5-2D で確かめる）」という見込みだけである。角型の格子を定数を作った体系のまま core で解くと、
反射体どうしの 2 面を 1 にした解は MOC の k より −65.4 pcm 小さく、右上の反射体のノード平均の高速群が +9.61% 違い、
同じ定数を格子の GET の ADF のまま使うと k とノード平均を 10⁻⁶ 未満で再現した（examples/reflector/verification.md の
「角型の格子の定数を作った体系の再現」、59bd6d4f と 80836156、2026-10-11）。

Problem 5 の 3D の炉心では、反射体の列の燃料より上と下の層（ノズル、炉心板、上下の水の高さ）の定数も要る
（[ADR-0128](0128-make-axial-reflector-constants-in-a-full-height-slab.md) の帰結が #0034 とあわせて決めるとしたもの）。仕様書の本文は、バッフルの軸方向の範囲を書いていない
（1.13 節の表 16 は径方向の寸法だけ。中性子パッドだけ「燃料と同じ高さ」とある）。KENO の模型の図 P5-2（仕様書 66 ページ）の
軸方向の断面から、次を読んだ（図から読んだ。寸法は書かれていない）:

- バッフルは、ボトムノズルの帯の上からトップノズルの帯の下までの高さにあり、上下のノズルの帯につながる
- 上下のノズルの帯と炉心板の帯は、燃料の端から外へ、図の目盛り（燃料の端からバレルの内面までを 26.71 cm とする）で
  約 21.6 cm、つまり約 1 ピッチ伸び、その外からバレルまでは水である。帯の物質が均質なノズルか SS304 かは、色から
  区別できない
- 炉心板の外（上下の 50 cm の水）は、反射体の輪の位置も水である

ほかに #0034 は、炉外の検出器の応答の求め方を挙げた。

判断の軸:

- 定数を作った体系（I 型、L 型、角型の格子、軸方向のスラブ）で、core が参照（格子計算の MOC）を再現すること（GET。ADR-0101、
  [ADR-0103](0103-define-adf-by-one-node-kernels.md)、[ADR-0131](0131-derive-corner-factors-with-vacuum-condition-on-homogeneous-corners.md)）
- 原理で決まり、手で合わせる係数を持たないこと。新しい形の格子計算を増やさないこと
- 参照の形状（5-2D の Case 2、ADR-0078）と、core の外形が一致すること
- 入力が簡潔で、怪しい入力をエラーにできること

## 検討した案

### `-` に面する面の境界条件

- (a) 直方体を反射体のノードで埋め、外形の外の位置に燃料に接しない反射体の定数を置き、直方体の外周を真空にする:
  NEM は今のまま直方体を解ける。しかし参照の形状と合わない。Case 2 はその位置を void にし、Case 1 は円筒のバレルの
  内側までの水で、直方体の角（炉心の中心から約 258 cm）は圧力容器の外半径（241.70 cm）より外に出る。ADR-0078 の
  「バッフルと周りの水まで」を、位置によって 2 ピッチ以上の水に広げることになる。定数の面でも、燃料から 2 ピッチ以上
  離れたノードを含む格子計算が要る。ADR-0095 の 2 × 2 の格子では作れず、燃料の種類と装荷に左右されない大きさにする
  原理もない
- (b) `-` に面する面に真空の条件（J = r f φ。ADR-0101）を直接課し、NEM を階段の外形のまま解く（採用）: 5-2D の
  外形では、`-` に面する面はどれも I 型の反射体のノードの燃料と反対の辺か、角型の反射体のノードの外側の 2 辺で、
  定数を作った格子でも真空の辺である（「決定と理由」）。r は、そのノード自身の定数の、その辺の値をそのまま使える。
  Case 2 との違いは、外形の外を void でなく再入射のない真空にすることだけである（「帰結」）
- (c) バッフルの外側で切り、ギャップとバッフル（3.04 cm）だけを反射体のノードとし、その外側の面に条件を課す: 外側の
  水は面の条件だけで表すことになる。その面の J/φ は、外の水が中性子を返す量（アルベド）で、真空の辺の比ではない。
  熱群ではバッフルの外の水から燃料へ向かう正味の中性子流になりうるので、ADR-0101 の 0 < r ≤ 1 に入らない候補がある
  （確かめていない）。アルベドの境界は core になく（ADR-0101）、ピッチと違う幅のノードは装荷図（ADR-0105。`pitch` は
  1 つ）で書けない。I 型の格子（ADR-0095。反射体のノードはピッチの幅）も作り直すことになる

### `-` に面する面の r をどこから取るか

- 隣の I 型の格子の真空の辺の値で統一する: 角型のノードの外側の 2 辺は、定数を作った角型の格子で自分の真空の辺の
  r を持つ。別の格子の r に替えると、その格子で再現しなくなる
- そのノード自身の定数の、`-` に面する辺の r（採用）: 装荷図の回転（ADR-0105）で辺を合わせれば、5-2D の外形では
  どの面も定数を作った格子の真空の辺に当たる。今の直方体の外周の `vacuum` と同じ規則で、場合分けが増えない

### `-` に面する面の条件の書き方

- 常に `vacuum` とし、入力に書かない: 単一集合体の定数（r を持たない）で裸の階段の炉心を解く試験では `marshak` が要る。
  入力に現れない既定の条件になる
- ケースの `boundary` に `outline` を足し、`-` に面する面の条件を 6 面と同じ値で書く（採用）

### 反射体のノードどうしの面の ADF

- ADR-0095 のとおり両側とも 1 にする: 根拠は「差が小さいと見込む」だけである。この ADR の前の core の規則（main
  bbe3ccee の core。2026-10-12）で、examples/reflector の段階の定数（302751a6 の `dvc repro`）を角型の格子の MOC と
  比べた（各側の ADF の値は examples/reflector/verification.md の「外形の面と、反射体どうしの面の ADF」）:

| 炉心                        | 規則       | Δk/k (pcm) | 集合体（高速、熱） | 右と上の反射体 | 右上の反射体   | ピン RMS | 右上のピン |
| --------------------------- | ---------- | ---------- | ------------------ | -------------- | -------------- | -------- | ---------- |
| 角型の格子のノード          | 1          | −65.2      | +0.002%、−0.001%   | −1.01%、−0.17% | +9.56%、+3.19% | 0.105%   | +0.231%    |
| 角型の格子のノード          | 各側の ADF | +0.0013    | 10⁻⁸ の程度        | 10⁻⁸ 未満      | 4 × 10⁻⁸ 未満  | 0.072%   | +0.230%    |
| 右と上に I 型の格子の反射体 | 1          | +107.8     | −0.045%、+0.022%   | −3.96%、+0.24% | +7.41%、+2.42% | 1.897%   | +15.946%   |
| 右と上に I 型の格子の反射体 | 各側の ADF | +161.2     | −0.018%、+0.009%   | −3.35%、−1.07% | +0.24%、+9.00% | 1.868%   | +15.569%   |

定数を作った体系（角型の格子のノード）では、各側の ADF で k を 0.002 pcm、ノード平均を 4 × 10⁻⁸ 以内で再現し、1 に
すると −65.2 pcm 違う。別の格子の定数を組んだ炉心では、k だけは 1 のほうが MOC に近いが、燃料のノード平均と
ピン出力は各側の ADF のほうが近く、どちらでも右上のピンが約 +16% 違う。この差は I 型の定数を定数を作った体系と
違う環境（角型の隣）に置いたことから来て、k の差の大きさの違いは、その誤差と ADF の扱いの打ち消し合いである。

- 同じ格子から来た反射体どうしの面だけ GET の ADF を保ち、別の格子の反射体どうしの面は 1 にする: 角型の格子の
  再現の結果から最初に考えた案。core が 2 つの定数の格子が同じかを知る必要がある。識別子の持たせ方として、
  (A) lattice が入力の本文の安定なハッシュ（FNV-1a）を少数群定数のテーブルに書く、(B) 炉心の形の入力に層の
  ファイルごとに格子の名前を書く、(C) lattice が同じ実行で書いたファイル名の組をテーブルに書く、を比べた。(B) は
  名前の誤りを core が見つけられず、(C) はファイルの名前を変えると壊れる。(A) は形式を変える。どれも、別の格子どうしの
  面を 1 にする理由が「別の格子の GET の ADF は互いの比にならない」ことにあり、燃料どうしの面（別の集合体の格子の
  ADF をそのまま並べる）と同じ理由で、反射体どうしでもそれを 1 にする根拠にならない
- 燃料どうしの面と同じく、格子が同じか別かによらず各側の自分の ADF を使う（採用）: GET の ADF は、そのノードの
  均質な面の中性子束を不均質な面の中性子束に戻す因子で、隣のノードと組で決まる量ではない。燃料の集合体どうしも、
  別の格子（単一集合体）の ADF を並べている。格子の識別子が要らない

### 5-2D の L 型の位置の定数（L 型の格子ができるまで）

- L 型の格子ができる（#0068）まで 5-2D を解かない: 外形の境界と角型の確認が、形状の拡張を待つことになる
- バッフルをピンの列の境に寄せた L 型の格子で作る: 仕様の寸法から外れる（#0068 で採らないとした。2026-10-11 の
  ユーザーの判断）
- L 型の位置に I 型の定数を置く（採用。#0068 まで）: I 型の格子は作れる。L 型の位置のノードは燃料と 2 面で接するが、
  I 型の定数の f*は 1 面だけにあり、もう 1 面は I 型の格子の鏡面反射の横の辺の GET の ADF を、隣の燃料の単一集合体の
  ADF と並べることになる。どちらの燃料の面に f* を向けるかで結果が変わりうる。近似の大きさは 5-2D で測る（#0029）

### 燃料に接しない反射体のノード

- 燃料から角の点より離れた位置（燃料のノードと面でも角の点でも接しない位置）にも反射体のノードを置ける定数を作る:
  (a) と同じく、参照の形状と合わず、定数を作る格子の原理もない。M3 の 5-2D と Problem 5 では要らない
- 角型の格子の、燃料と角の点だけで接するノードは、燃料に面で接しないので f* を持たず、GET の ADF をそのまま持つ
  （採用。#0029 で格子のノードごとの均質化をこの形にした。角の不連続因子は、燃料のノードに接する角の点だけ燃料の
  CDF で割る。ADR-0131）。燃料から角の点より離れた位置は `-` にする（採用）

### 反射体の列の、燃料より上と下の層の定数（Problem 5）

- (A1) バッフルのある高さ（ボトムノズルの上からトップノズルの下まで）には径方向の反射体の定数（I 型、角型）を
  伸ばし、ノズル、炉心板、上下の水の高さには軸方向の反射体の定数（ADR-0128 のスラブの、その高さの層）を置く。
  スラブの定数は径方向の辺に真空の比 r を持たない（スラブの上下の辺は鏡面反射）ので、その層の真空の面（直方体の
  外周と外形）は Marshak の条件（r = 1/2）にすることを、炉心の形の層に明示する（採用）: 組成は図 P5-2 の読み
  （バッフルはノズルの帯の間、ノズルと炉心板の帯は約 1 ピッチ外まで、その外は水）に合う。近似は、r のない層の
  外側の面の P1 の関係だけで、入力に現れる
- (A2) (A1) の配置で、r のない層は、同じ反射体の列のバッフルの高さの層（I 型、角型）の r を借りる: 入力は増えないが、
  別の定数（別の高さ、別の組成）の r を混ぜることになり、その r がスラブの層の外側の面の比である根拠がない
- (B) 反射体の列の全高さに径方向の 2D の定数（I 型、角型）を伸ばす: r と GET の ADF がそろい、入力も今のままで済む。
  しかしノズル、炉心板、水の高さにもバッフルと水の組成を置き、図 P5-2 と合わない（上下の 50 cm の水の層にも鋼が入る）
- (C) r-z の 2D の格子（格子の x を炉心の z、y を径方向にとり、集合体の媒質と反射体の輪を並べ、径方向の外側を真空に
  する）で、反射体の列のノードごとに定数を作る: z と径方向の ADF、外側の r、燃料に向く f* が、すべて一つの格子から
  そろい、原理ではいちばん正確である。ADR-0128 の「各ノードは格子のすべての行にわたる」を外す格子計算の拡張が要り、
  この ADR の範囲を超える。(A1) との差を測る issue にする（#0072）

### 炉外の検出器の応答

- 拡散の解（core の NEM）を炉心の外の水と鋼に延ばし、検出器の位置の中性子束を出す: 炉外の円筒の形状（バレル、
  中性子パッド、圧力容器、検出器の井戸）は ADR-0078 で除いた範囲で、ノードの拡散で厚い水と鋼を通る輸送を表す根拠も
  ない。下の文献はどれもこの方法を使っていない
- 随伴の輸送計算で作った空間の重み関数を、炉心計算の出力分布に掛ける（文献の方法。下）
- M3 では作らない（採用。理由は「決定と理由」）

## 決定と理由

### 外形の境界

炉心の形の `map` の `-` を、ノードを置かない位置として受け付ける。core の NEM は `-` の位置にノードを持たず、`-` に
面する面を外周の面として扱う。

- `-` に面する面の条件は、ケースの `boundary` の `outline`（6 面と同じ値: `reflective`、`zero-flux`、`vacuum`、
  `marshak`）で書く。`map` に `-` があるのに `outline` がなければ、また `-` がないのに `outline` があればエラーにする。
  サイクルの装荷図では `-` の位置を `.` にし、ID を置けばエラーにする
- `vacuum` は、その面のノードの定数の、その面に当たる辺（装荷図の回転を済ませたもの）の r を使い、J = r f φ を課す
  （ADR-0101 と同じ。f はそのノードのその辺の ADF）。その辺の r がなければエラーにする（ADR-0101 の検査と同じ）。
  `-` は `map` のどの高さでも同じ（`map` は径方向の図）なので、z の面には現れない
- 横方向の漏れの 2 次式とピン出力の再構成の角の点のバランス（CPB）は、`-` に面する面を、直方体の外周の同じ条件の面と
  同じに扱う（真空の面の横方向の漏れは ADR-0101 の「ノードの漏れ × 面の中性子束 / ノード平均」、CPB の真空の辺の流れは
  ADR-0131 の r f φ_c、中性子束ゼロの面に接する角の点は 0）。外形の凹んだ角では、角の点を囲む 4 つの位置のうち 3 つに
  ノードがあり、その点から出る 4 本の半分の辺のうち 2 本が `-` に面する。CPB はその 2 本を外周の辺として、ノードの
  ある 3 つの位置でバランスを立てる。どのノードにも接しない角の点は 0 とする（使われない）
- `-` は、`map` の端まで `-` だけを上下左右の隣でたどって出られなければエラーにする。ノードに囲まれた `-` は、炉心の
  中に真空の穴を開けることになり、意図した入力と考えにくい
- ノードのない位置は、解の中性子束と面の中性子流を空にし、炉心全体のピン出力の表では 0 にする（ノードのない列と
  行はセルを持たない）

5-2D の外形（1/4 炉心の行 8〜15 の燃料の数は 8、8、8、8、7、7、6、4。仕様書の図 M3-1）で、反射体の位置を燃料との
接し方で分けると、`-` に面する面は次のどちらかになる（図から数えた）。

- I 型のノードの、燃料と反対の辺（たとえば A-13 の右）。I 型の格子では真空の辺
- 角型のノードの、燃料と反対の 2 辺（A-14、B-15 など。A-12 の右の位置と D-15 の下の位置は 1 辺が直方体の外周）。
  角型の格子では真空の 2 辺

L 型の位置（A-12、B-14、D-15）は、燃料に接しない 2 辺で I 型か角型の反射体のノードに接し、`-` に面しない。どの
`-` に面する面でも、r は定数を作った格子の真空の辺の値になる。

採らなかった (a) と (c) は、参照の形状か、ADR-0101 の真空の比の範囲と合わない（検討した案）。(b) は、参照の形状
（Case 2、ADR-0078）の外形をそのまま表し、新しい格子計算も手で合わせる係数も要らない。

### 反射体のノードどうしの面の ADF

反射体のノードどうしの面も、燃料どうしの面と同じく、各側の少数群定数の ADF（f*の辺なら f* × 隣の燃料の ADF）を
使う。定数が同じ格子から来たか別の格子から来たかは問わない。これは ADR-0095 の「反射体のノードどうしの面の ADF は
1 とする」の部分を置き換える。ADR-0095 のほかの部分（定数を作る格子の形、f*、外側の面の ADF など）は変わらない。
ADR 全体の置き換えではないので、ADR-0095 のフロントマターは変えず、補足に記す（ADR-0129 と ADR-0013 の扱いと同じ）。

core は、炉心の形の反射体の位置に置いた物質（`nem::Problem` の `reflectors`）を、面の ADF には使わず、f* の辺が
ほかの反射体の位置に向く（回転を取り違えた）定数を見つける検査にだけ使う。

ADR-0095 の 1 の根拠は見込みだけで、定数を作った体系で 65 pcm の差の原因と確かめた（背景と検討した案の表）。各側の
ADF では、定数を作った体系を k で 0.002 pcm、ノード平均で 4 × 10⁻⁸ 以内で再現する。GET の ADF はノードごとの量で、
燃料どうしの面では格子が違っても各側の ADF を並べている。反射体どうしだけ 1 にする理由はない。格子の識別子
（検討した案の (A)〜(C)）も要らない。

### 燃料に接しない反射体のノードの定数

燃料と面で接する反射体のノード（I 型、L 型）は ADR-0095 の f*を持つ。燃料と角の点だけで接する角型のノードは、f* の
辺を持たず、角型の格子の GET の ADF をそのまま持つ（#0029 の実装と合わせる）。角の不連続因子は、燃料のノードに接する
角の点だけ燃料の CDF で割り（C*）、ほかの角はそのまま持つ（ADR-0131）。

燃料から角の点より離れた位置には反射体のノードを置かず、`-` にする。5-2D と Problem 5 の反射体は、どの位置も燃料と
面か角の点で接する（Case 2 の水の層と同じ範囲）ので、これで足りる。

### 5-2D の L 型の位置

L 型の格子ができる（#0068）まで、5-2D の L 型の位置（A-12、B-14、D-15 と、ほかの象限の同じ位置）には、I 型の定数を、
f* の辺を燃料の 1 面に向けて置く。1/4 の対称性を保つように、4 つの象限で同じ向き（炉心の中心のまわりに回したもの）に
する。この近似の大きさは 5-2D で測る（#0029）。L 型の格子ができたら、L 型の定数に替えて 5-2D を解き直す。

### 反射体の列の、燃料より上と下の層（Problem 5）

(A1) を採る。径方向の反射体の位置の列（炉心の形の `[reflector.X]`）は、軸方向に次の層を持つ（高さは ADR-0128 の表の
層の境。下の炉心板の上面から）。

| 高さ                                           | 層の定数                                                                 |
| ---------------------------------------------- | ------------------------------------------------------------------------ |
| 下の水、下の炉心板、ボトムノズル（−55〜6.053） | ADR-0128 のスラブの、その高さの層の定数。真空の面は Marshak              |
| 6.053〜397.51（バッフルのある高さ）            | 径方向の反射体の定数（I 型、角型。L 型の位置は I 型）を 1 つの層で伸ばす |
| トップノズル、上の炉心板、上の水（397.51〜）   | ADR-0128 のスラブの、その高さの層の定数。真空の面は Marshak              |

- スラブの定数は、反射体の位置に近い集合体の設計（反射体の定数の代表の燃料と同じ考え方。ADR-0095）のスラブから取る。
  ノズル、炉心板、水の層は燃料に接しないので f* を持たず（ADR-0128）、反射体の位置にそのまま置ける
- 入力: 炉心の形の層を、ファイルのパスか `{ file = "<ファイル>", vacuum = "marshak" }` で書く。`vacuum = "marshak"` の
  層は、その定数の径方向の 4 辺に r = 1/2 を置く（Marshak の条件は r = 1/2 の真空の条件と同じ式。ADR-0101）。
  定数が径方向の辺に格子計算の r を持てば、どちらを使うか決められないのでエラーにする。印のない r のない層が
  `vacuum` の面に接すれば、今のとおりエラーにする（既定の条件を作らない）。書ける値は `marshak` だけにする
- バッフルのある高さの径方向の反射体の定数は、隣の集合体の列の、燃料でない層（下のギャップと端栓、プレナム、上の
  端栓とギャップ）とも x と y の面で接する。そこでは I 型の定数の f*（燃料の ADF で割った値）の辺が核分裂のない
  層に向く。この面は、両側の ADF を 1 にする（近似。I 型の定数は燃料と組で作ったもので、核分裂のない層と組で作った
  定数はない）。f* の辺が反射体の位置に向く場合（回転の取り違え）と、z の面で f* が核分裂のない層に向く場合（スラブの
  上下の取り違え。ADR-0128）は、今のとおりエラーにする

(A1) は、図 P5-2 の組成（バッフルはノズルの帯の間、ノズルと炉心板の帯は約 1 ピッチ外まで、その外は水）に合わせ、
近似を r のない層の外側の面の P1 の関係に限って入力に明示する。(A2) は根拠のない r を混ぜ、(B) は組成が仕様と違う。
(C) は原理では最も正確だが、格子計算の拡張が要る（#0072 で (A1) との差を測り、作るかを決める）。

### 炉外の検出器の応答

炉外の検出器の応答は、炉外の形状（バレル、圧力容器、検出器の位置）での随伴の輸送計算で作った空間の重み関数を、
炉心計算の出力分布に掛けて求めるのが文献の方法である。KEPRI の OPR-1000 の例（M. G. Park, H. C. Shin,
"A Constructive Calibration of Axial Spatial Weighting Functions of Ex-Core Detectors," Trans. KNS Spring Meeting
(2009)。全文を読んだ）は、2D の随伴の輸送計算（DORT、47 群、P3、S8）で集合体の重み ω_2D(x, y) と軸方向の重み
ω_1D(z) を作り、外周の軸方向の出力 P_peri(z) = ∫ P(x, y, z) ω_2D dx dy、応答 R = ∫ P_peri(z) ω_1D(z) dz と
している。重み関数を随伴の輸送計算と点核の模型で作り、応答の 91% が検出器に近い 5 体の集合体から来るとした論文
（M. W. Crump, J. C. Lee, Nucl. Technol. 41(1), 87–96 (1978)）と、圧力容器の外の散乱を入れた 2D の輸送計算で、
検出器から遠いが圧力容器に近い外周の集合体の重みが大きいとした論文（H. Tochihara, E. Ochiai, T. Hasegawa,
Nucl. Technol. 58(2), 310–317 (1982)）は、要旨だけ読んだ。

xlc の core が出すのは出力分布（集合体とピン）で、重み関数を作るには炉心の外の円筒の形状の輸送計算が要る。

M3 では作らない。Problem 5 の実測の値（表 P5-7）は臨界ホウ素濃度、制御棒バンクの効き、ホウ素の効き、等温温度係数で、
仕様書は計算の値を k の差（ρ = (1/k₁ − 1/k₂) × 10⁵ pcm）で出す。ロッドスワップで測ったバンクの効きは、KENO で計算した
影の係数（shadow factor）で換算した値として与えられている（仕様書の Table P5-2 の注と、その後の手順の 4）。炉外の
検出器の応答を xlc で計算しなくても比較できる。実機のデータと比べるときに #0071 で決める。

## 帰結

- core の NEM、CPB、出力の表は、直方体の中にノードのない位置を持つ。NEM はノードのある位置だけを詰めて数える
- 外形の外を再入射のない真空とするのは近似である。Case 2 では、外形の凹んだ角で外に出た中性子が void を通って隣の
  反射体の面に入りうる。外側の水の端の中性子束は燃料側よりずっと小さい（I 型の格子の高速群で燃料側の面から約
  50 分の 1。ADR-0102）ので小さいと見込むが、大きさは確かめていない（「確認」の 5-2D で見積もる）
- 凹んだ角を中性子束ゼロの面で囲むと、粗いノードの NEM は k を大きく外す（確認の 2.5%）。5-2D と Problem 5 の外形の
  `-` に面するのは反射体のノードの真空の辺で、燃料の凹んだ角ではないが、反射体の外形の凹んだ角の誤差は 5-2D の
  比較に含まれる
- I 型と角型の格子では、真空の辺の横は鏡面反射か角型の格子の別の反射体で、炉心の外形の隣（L 型や角型の反射体）とは
  違う。この違いは r と ADF に入り、定数を作った体系でない炉心の誤差として残る（「確認」の I 型と角型を組んだ炉心で測る）
- 反射体どうしの面に各側の ADF を使うので、角型の右上のノードの ADF は、`-` と外周の面だけでなく、隣の反射体との
  面にも効く
- 角型の位置に隣る I 型の位置（5-2D の R-11 など）は、燃料と 1 面で接し、燃料と反対の辺が外周か外形、もう 1 辺が
  角型の位置、残りの辺が I 型の列に続く。これは角型の格子の右と上のノードの環境と同じなので、そこに角型の格子の
  右と上の定数を置けば、反射体どうしの面に各側の ADF を使う規則で角型の格子を再現できる。I 型の定数を置くと
  角型の隣という違う環境の誤差が入る（「確認」の I 型と角型を組んだ炉心）。どちらを置くかは 5-2D の入力で比べる
  （#0029）。格子計算はノードごとに別の少数群定数のファイルを書き（`few-group` の `nodes`。ADR-0095）、炉心の形の
  反射体の種類の層でファイルを選ぶので、角型の格子の右と上のノードの定数は、今の入力のまま選べる
- 5-2D の L 型の位置に I 型の定数を置くのは #0068 までの近似で、その大きさを記録してから 5-2D の結果を読む
- 5-2D の参照（KENO の Case 1）と比べると、バレルより外を除いた偏り（表 J-1）が入る（#0016）。Problem 5 の 3D でも、
  径方向の形は同じで、KENO（図 P5-2）はバレル、中性子パッド、圧力容器を入れているので、同じ種類の偏りが入る
- 燃料から角の点より離れた位置の反射体（バッフルとバレルの間の厚い水など）の定数は作らない。必要になったら、参照の
  形状と、その定数を作る格子の原理を決めて新しい ADR にする
- 反射体の列の上下の層の (A1) の近似（外側の面の P1、`vacuum = "marshak"`）は、ノズル、炉心板、上下の水の高さの、
  中性子束の低い領域の層に限る。バッフルのある高さの層は格子計算の r を使う。(C) との差は #0072 で測り、
  差が小さければ (A1) のまま、大きければ (C) を作る
- バッフルのある高さの径方向の反射体のノードと、集合体の列の核分裂のない層（端栓、プレナム）の x と y の面の ADF を
  両側とも 1 にする近似は、Problem 5 の 3D の比較（#0072 と同じ比較）に含まれる。大きさを分けては測っていない
- 炉外の検出器の応答は M3 では作らず、#0071 に分ける
- 一次情報で確かめていないこと: Case 2 の水の層が燃料と角の点だけで接する位置を含むこと（図 J-1 から読んだ）、
  図 P5-2 のバッフルとノズル、炉心板の帯の範囲（図から読んだ）、Crump と Lee（1978）と Tochihara ら（1982）の本文、
  (c) の熱群の正味の中性子流の向き
