# ADR-0153: 反射体に面する燃料の位置には、その燃料と反射体を並べた格子の燃料のノードの定数を置く

## 背景

径方向の反射体の定数は、燃料の集合体と反射体を並べた I 型と角型の格子で作り、反射体の ADF は燃料の ADF で割った
f\* で持つ（[ADR-0084](0084-make-reflector-constants-with-fuel.md)、[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)、[ADR-0132](0132-impose-vacuum-ratio-along-core-outline.md)）。ADR-0095 は、炉心の燃料のノードには、反射体の隣でも単一集合体（外周が
鏡面反射の無限格子）の定数を置くとした（f\* の方法）。

この方法で VERA 5-2D を解くと、k は KENO-VI より +235〜294 pcm 大きく、集合体出力は中心で低く外周で高い（5A で RMS
4.07%、最大 +10.4%。#0086）。反射体の格子そのものを core で解くと、格子の燃料のノードの定数では MOC の k を 6 桁で
再現するが、単一集合体の定数では I 型で +580 pcm、角型で +1639 pcm 違う（examples/vera/verification.md の「Problem 5-2D の
炉心の計算」）。反射体の隣の燃料は、反射体から戻る熱中性子でスペクトルが軟らかくなり、均質化した断面積と拡散係数が
無限格子と違う（3.10% の燃料の I 型の格子の燃料のノードと単一集合体で、高速群の吸収 −1.5%、拡散係数は高速群 +4.2%、
熱群 −5.2%。584c741b の examples/vera/p5 の `lattice/reflector-I-fuel.msgpack` と `lattice/31.msgpack`、2026-10-12）。f\* は反射体に
面する辺の ADF の比だけを補い、燃料のノードの断面積と拡散係数の違いを補わない。

- 外周の集合体の出力と k（5-2D、Problem 5）
- 格子計算の回数と、炉心の入力の手間
- 装荷に左右されない定数であること（ADR-0095 が、多くの集合体を解いて切り出す案を採らなかった理由）

## 検討した案

試行は examples/vera/verification.md の「外周の燃料の定数の切り分け」（d39cf873 の trials/p5-0086、2026-10-12）。I 型の
格子は格子の MOC の k と、3 × 3 の集合体と反射体の輪は同じ多群定数の MOC と、5A は OpenMC（同じ ENDF/B-VIII.0。「Problem
5-2D の参照解」）と比べた。置き換えは外周の 3.10%（Pyrex なし）の位置だけで、Pyrex のある外周の 12 体は単一集合体の定数のまま。

| 外周の燃料のノードの定数                 | I 型の格子の k | 3 × 3 の k、集合体 RMS | 5A の k、集合体 RMS、最大 |
| ---------------------------------------- | -------------- | ---------------------- | ------------------------- |
| 単一集合体 + f\*（ADR-0095）             | +580.2 pcm     | +688.8 pcm、0.99%      | +97.9 pcm、4.68%、+11.5%  |
| ADF だけ格子のもの                       | +580.2 pcm     | +671.2 pcm、0.52%      | +91.8 pcm、4.52%、+11.2%  |
| 拡散係数だけ格子のもの                   | +376.9 pcm     | +404.4 pcm、0.58%      | +67.5 pcm、3.83%、+9.7%   |
| 断面積だけ格子のもの                     | +207.7 pcm     | +321.2 pcm、2.63%      | +48.8 pcm、2.48%、+6.5%   |
| 断面積と拡散係数を格子のもの             | 0.0 pcm        | +29.8 pcm、2.22%       | +19.5 pcm、1.87%、+4.8%   |
| 格子の燃料のノードの定数（すべて。採用） | 0.0 pcm        | +11.6 pcm、1.74%       | +13.8 pcm、1.72%、+4.5%   |

Pyrex のある外周の位置にもその種類の I 型の格子の定数を置いた実装（ee8195a2）では、5A の OpenMC との差は k −5.7 pcm、
集合体 RMS 1.66%、最大 +4.6% になった（examples/vera/verification.md の「Problem 5-2D の炉心の計算」）。

- 単一集合体の定数と f\*（ADR-0095 の方法。今までの方式）: 格子計算は集合体の種類ごとの単一集合体と、代表の燃料の
  反射体の格子だけで済む。I 型の格子では、燃料のノードの ADF を替えても k は変わらない（反射体側の ADF が f\* × 燃料の
  ADF なので、面の ADF の比は燃料の ADF によらない）。誤差は断面積と拡散係数の環境依存から来て、5-2D では集合体出力を
  10% 傾ける
- 項を分けて一部だけを替える: どの項も同じ格子の同じノードの均質化から出るもので、一部だけを替える理由がない。表の
  とおり、どれか 1 つでは誤差の半分も消えない
- 外周の燃料に、その燃料と反射体を並べた格子（I 型、角型）の燃料のノードの定数（断面積、拡散係数、ADF、形状関数）を
  置く（採用）。カラーセットの考え方で、反射体の定数を燃料と組で作る（ADR-0084）ことを燃料の側にも広げる。I 型と角型の
  格子では、燃料のノードと反射体のノードの定数の組が格子の MOC を再現する（等価性）
- 炉心の解のスペクトルで断面積を補正する（再均質化、スペクトルの補正）: 外周の 2 列目より内側にも効き、装荷によらない。
  core に、ノードの中の群の中性子束の形から断面積を作り直す計算が要り、補正のモデル（スペクトルの指標と断面積の関係）を
  決める必要がある。誤差の大半は 1 列目の燃料の定数で消える（上の表）ので、採らない。残りの誤差（下の帰結）が大きければ
  見直す
- 3 × 3 や全炉心の MOC から燃料と反射体の定数を切り出す: 定数が装荷に依存する（ADR-0095 が採らなかった理由）。5 × 5 の
  集合体の MOC は、自己遮蔽ありでメモリが 82 GB を超えた（#0086）

拡散係数の差には、定義の違い（単一集合体は B1 の中性子流、反射体の格子の燃料のノードは中性子流で重みづけした outflow の
輸送断面積。[ADR-0104](0104-weight-transport-cross-sections-by-currents.md)）と、環境の違いの両方が入る。2 つを分けることは確かめていない。

## 決定と理由

炉心の燃料のノードの定数は、位置の反射体との接し方で選ぶ。

- 反射体に 1 面で面する位置: その位置の集合体の種類の燃料と反射体を並べた I 型の格子（ADR-0095）の、燃料のノードの
  定数を、格子の反射体の向きがその位置の反射体の向きに来るように回して置く
- 隣り合う 2 面で反射体に面する位置: その種類の燃料の角型の格子（ADR-0132）の燃料のノードの定数を回して置く
- 反射体に面しない位置（反射体の位置に角の点だけで接する位置を含む）: 単一集合体の定数
- 向かい合う 2 面や 3 面以上で反射体に面する位置は、格子がないのでエラーにする

格子の燃料は、その位置にある集合体の種類（濃縮度、Pyrex、制御棒）と同じにし、種類と形の組ごとに格子を作る。断面積と
拡散係数の環境依存は燃料の種類で違い、代表の燃料の定数を Pyrex のある燃料に置くことはできないためである。5-2D の外周は
3.10% で、I 型の位置に Pyrex なし、8 本、12 本、角型の位置に Pyrex なしがあり、I 型 3 つと角型 1 つの格子になる。

反射体のノードの定数は、今のとおり代表の燃料（3.10%、Pyrex なし。ADR-0084）の I 型と角型の格子のものを、炉心のすべての
反射体の位置に置く。炉心の形（[ADR-0105](0105-load-core-by-assembly-ids.md) の炉心の形のファイル）が装荷に依存しないようにするためである。Pyrex の
ある燃料に面する 12 の反射体の位置に、その燃料の I 型の格子の反射体のノードの定数を置いた試行（trials/p5-0086/pairing.py）
では、5A の OpenMC との差は k −9.2 pcm、集合体 RMS 1.73%（代表の定数では −5.7 pcm、1.66%）で、f\* で割った反射体の定数の
燃料の種類への依存は小さい（ADR-0095 の見込みのとおり）。

燃料のノードの定数は台帳の設計（`<種類>-I`、`<種類>-corner`）で表し、向きは装荷の回転で表す（ADR-0105 の入力のまま。
core のコードは変えない）。

## 帰結

- 外周の集合体は、炉心の内側の同じ種類の集合体と別の設計になる。燃焼（M4）では、外周の位置の燃焼の履歴と分岐の
  テーブルを、その格子で作る必要がある。集合体を外周と内側の間で動かす装荷替えでは、位置ごとに定数を選び直すことになる
- 外周の 2 列目より内側の燃料も、反射体の影響でスペクトルが変わる。3 × 3 では、k は MOC に +11.6 pcm まで近づいたが、
  中心の集合体の出力は +3.4% 高い（中心の集合体も反射体から 1 体の距離にある）。原因は候補で、確かめていない（#0086）
- L 型の位置（燃料に 2 面で接する反射体）の隣の燃料は、I 型の格子の定数を置く。L 型の格子（#0068）ができたら、その
  格子の燃料のノードの定数に替える
- 5-2D の残りの集合体出力の差（OpenMC に RMS 1.66%）は、L 型の位置の隣（B12 の +4.6%。L 型の I 型の近似の向きで鏡映の
  位置に移る）と、Pyrex のある外周の位置（A08 の −3.4%、H15 の −2.9%。単一集合体の定数では +1% 前後だった）に残る。
  後者の原因は確かめていない（#0086）
- KENO-VI（ENDF/B-VII.0）との k の差（+131 pcm）は、OpenMC と KENO-VI の差（+137 pcm）とほぼ同じで、核データの版の違い
  が占める

## 確認

- 反射体の格子の等価性: I 型と角型の格子を core で解くと、格子の燃料のノードの定数で k が 6 桁で一致する（examples/vera/p5
  の `compare-lattice-*-equivalence`）
- 3 × 3 の集合体と反射体の輪（`compare-small-*`）と、5A を OpenMC と、5A、5B、5C を KENO-VI と比べる
  （examples/vera/verification.md の「Problem 5-2D の炉心の計算」）
- 反射体のノードの定数を、隣の燃料の種類の格子のものに替えた試行（trials/p5-0086/pairing.py）で、代表の燃料の定数を
  置く近似の大きさを測った（上）
