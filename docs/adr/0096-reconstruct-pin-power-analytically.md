# ADR-0096: ピン出力は、ノードの中の均質な中性子束を2群拡散方程式の解析的な関数で再構成し、格子計算の群ごとの形状関数を掛けて求める

## 背景

格子計算はピン出力の形状を出し（[ADR-0026](0026-output-two-group-tables-from-lattice.md)。いまはセルごとの核分裂率だけ）、core はピン出力を再構成する計画である
（[ADR-0027](0027-solve-core-with-nem.md)。いまの core は再構成を持たない）。M3 の計画は、再構成の
方法を実装の前に文献で比べて決めるとしている（docs/plans/m3-core-hzp.md）。NEM は方向ごとに横方向に積分した 1D の形
（4次の多項式）しか持たないので、ノードの中の 2D の形を別に求める必要がある。VERA の参照解のピン出力は核分裂率である
（仕様書の REF1-2D など）。

- 外周の集合体（反射体の隣）のピン出力（熱中性子束の急な勾配）
- 炉心計算が満たしたノードの中性子収支を、再構成した形も満たすこと
- 原理で決まり、手で合わせる係数を持たないこと
- 計算の量と実装の量

## 検討した案

ノードの中の均質な中性子束の形:

- ノード平均だけを使う（形状関数 × ノード平均）: 外周の集合体のように、集合体の中の勾配が大きいところで誤差が大きい
- NEM の x と y の 1D の形の積: 中性子束は空間で分離できないので、積は正確な 2D の形にならない（PARCS v3.0 Theory
  Manual、5.1.1 節、https://www.nrc.gov/docs/ML1016/ML101610117.pdf ）
- 2D の多項式の展開: Koebke の 21 項を Rempe が 13 項に減らした。ノード平均、面の平均の中性子束と流れでは 9 個の条件にしか
  ならず、残りを4つの角の中性子束で決める。角の中性子束は角の周りを低い次数の多項式で近似して求める（同 5.1.1 節。
  K. Koebke, L. Hetzelt, Nucl. Sci. Eng. 91(2), 123–131 (1985)、https://doi.org/10.13182/NSE85-A27435 。K. R. Rempe,
  K. S. Smith, A. F. Henry, "SIMULATE-3 Pin Power Reconstruction: Methodology and Benchmarking," Nucl. Sci. Eng. 103(4),
  334–342 (1989)、https://doi.org/10.13182/NSE89-A23686 。どちらも要旨と PARCS のマニュアルの記述だけ読んだ）。SIMULATE-3
  の方法で、細かいメッシュの方法と同じ程度の精度とされる（Rempe らの要旨）。多項式だけでは反射体の隣の熱中性子束の
  指数関数の形を表しにくいので、熱群にだけ指数関数を足す（PARCS のマニュアルの記述）。角の中性子束の近似が低い次数で、
  UO2 と MOX の市松の角のように勾配の急なところで誤差が出る（同 5.1.1 節）
- 2群拡散方程式を満たす解析的な関数（三角関数と双曲線関数）の展開（採用）: Boer と Finnemann の方法
  （R. Boer, H. Finnemann, Ann. Nucl. Energy 19(10–12), 617–628 (1992)。読んでいない）。PARCS はこの形を、4面の平均の
  正味の中性子流と4つの角の中性子束を条件として使い（面の平均の中性子束の代わりに流れを使うと、ノードの中性子収支を
  必ず満たす）、角の中性子束は、角の点での中性子収支（corner point balance）の連立方程式で求める（同 5.1.1〜5.1.4 節）。
  2群が結合し、1群あたり8個の関数を使う
- ノードの中を細かいメッシュの拡散で解く: 均質な拡散方程式の解を離散化の誤差だけで表せるが、面に沿った流れの分布が
  ノードの解からは分からないので、角の中性子束などの情報が結局要る。計算の量も大きい
- ピンごとの炉心計算（ピンで均質化した SP3 など）: [ADR-0027](0027-solve-core-with-nem.md) の範囲の外

形状関数:

- 1群（出力）の形状関数: 速い群の核分裂が大きい燃料（MOX）で誤差が出る（同 5.1.1 節）
- 群ごとの形状関数（採用）: PARCS は2群の形状関数 f_g(x,y) = κΣf,g φ_g(x,y) / (κΣf,g φ_g の均質化した値) を使い、
  ピン出力を Σ_g κΣf,g φ_g^均質(x,y) f_g(x,y) とする（同 5.1.5 節、式 (5.35)、(5.36)）
- 単一集合体（外周が鏡面反射）の形状関数か、カラーセットの形状関数か: SIMULATE-3 は単一集合体の形状関数を使い、
  集合体の間のスペクトルの相互作用を別に扱う（Rempe らの要旨。扱いの中身は確かめていない）。PARCS も単一集合体の
  形状関数とし、実際の炉心で大きく違わないことを前提にする（同 5.1.5 節）

## 決定と理由

ノードの中の均質な中性子束の径方向の形は、PARCS と同じく、2群拡散方程式を満たす解析的な関数の展開で求める。条件は
core の解の4面の平均の正味の中性子流と4つの角の中性子束とし、角の中性子束は角の点での中性子収支の連立方程式で求める。
展開の関数がノードの中で均質な拡散方程式を厳密に満たし、反射体の隣の熱中性子束の指数関数の形を表せるため、また流れを
条件にするとノードの中性子収支を必ず満たすためである。角の中性子束を求めるバランスの条件も、角の周りを低い次数で
近似する方法より物理の条件に基づく。

- 角では、不均質な角の中性子束（角の均質な中性子束 × CDF）が連続とする（PARCS、5.1.2.3 節）。燃料の CDF は単一集合体の
  格子計算が出す（[ADR-0094](0094-define-adf-by-one-node-nem.md)）。燃料と反射体の角と、反射体のノードの CDF（均質な解が平らでない格子の CDF）は決めて
  いない（#0020）。決まるまで、反射体に接する角を含む再構成はエラーにする
- 形状関数は群ごとに、単一集合体（外周が鏡面反射）の格子計算から作る: f_g(ピン) = （ピンセルの群 g の核分裂率の
  体積平均）/（集合体の群 g の核分裂率の体積平均）。M3 は零出力で、参照解が核分裂率なので、κ は掛けない（κ は燃焼と
  出力を扱う M4 で入れる）。燃料のないセルは 0 とする
- 形状関数と CDF は、少数群定数の `pins` に持つ: 列の幅 `dx` と行の高さ `dy`（-x、-y の辺から順に。余白の
  薄い行と列も1つのセル。境界の座標で持つと、集合体を回すたびに引き算の丸めが入るので、幅で持ち、回すときは並べ替える
  だけにする）、形状関数 `form`（`[群][行][列]` の順で、行は -y から、列は -x から。余白など核分裂のないセルは 0）、CDF
  `corners`（`[角][群]` の順で、角は -x -y、+x -y、+x +y、-x +y）。テーブルの状態はどれも `pins` を持つか持たないかで（持たない
  ときも nil を書く）、セルの大きさも同じとする
- 格子計算は、`few-group` の `pins = true` を書いたときだけ作る（格子全体の出力だけ。`nodes` とは使えない）。外周が
  すべて鏡面反射でない格子、角のセルが余白でない格子はエラーにする。条件を満たさない格子で黙って省かないため、
  作るかを入力で指定する
- 形状関数のセルとノードの平均は、トラックから推定した体積でなく解析的な体積で取る。core はセルの幾何の面積で
  再構成するので、面積で重みを付けた形状関数のノードの平均がちょうど 1 になる（トラックの体積で取ると、テストの 2×2 の
  格子で平均が 1 から 7e-6 ずれた）。CDF は、面の ADF と同じ均質な中性子束を基準にするよう、トラックの体積で平均した
  ノード平均で割る
- 集合体を回して置くとき（ADR-0105）は、形状関数のセルと CDF の角も回す
- ピン出力は Σ_g Σf,g φ_g^均質(ピンセルの平均) f_g(ピン) とする
- 軸方向は径方向と分離できるとし、NEM の z 方向の展開（4次の多項式）をピンの軸方向の区間で平均した値を掛ける。軸方向の
  漏れは、径方向の再構成ではノードの中で一様な線源として扱う（一様な線源の特解は定数）
- 形状関数と CDF は、ほかの定数と同じく状態の分岐のテーブルから内挿する
- スペクトルの相互作用の補正（SIMULATE-3）は M3 では入れない。外周の集合体の差を測ってから決める

## 確認

まだ実装していない（M3 の進め方の 7）。次で確かめる。

- 再構成した形が、ノード平均の中性子束と4面の正味の中性子流を再現すること。均質な正方形の炉心（解析解が cos × cos）で、
  再構成した形が解析解に一致すること
- 均質化した定数の同じ問題を細かいメッシュの拡散で解き、均質な形を比べる（再構成だけの誤差を測る）
- 4-2D、REF1-2D、5-2D のピン出力を、同じ多群定数の xlc の MOC で同じ問題を解いた結果と比べ（2段階の手法の誤差）、
  OpenMC（2D）と KENO の値とも比べる。判定の閾値（案）: xlc の MOC に対してピン出力の差の RMS 1%、出力 0.8 以上の
  ピンの相対の差の最大 3%（ユーザーの決定が要る。KENO の値との比べ方の偏りは #0016）

## 結果

- core に、ノードごとに2群の行列の固有値を使う関数の展開と、角の中性子束の疎な連立方程式（Gauss-Seidel で解ける。
  PARCS 5.1.3.2 節）を加える
- 格子計算に、ピンセルごとの群ごとの核分裂率の比を、状態の分岐ごとに出す機能を加える
- 外周の集合体の再構成は、反射体に接する角の CDF（#0020）が決まるまでできない
- 制御棒の部分挿入（カスピング）は別に決める（M3 の計画）
- 細部は、xlc の格子計算（MOC）の結果との比較を通じて段階的に詰め、新しい ADR か issue に記録する（2026-10-08 の
  ユーザーの方針）
