# ADR-0205: UFG の減速計算で、H in H2O の H の散乱核を、入力で選べば B(4) より下で S(α,β) の表から作った移行の表にする

## 背景

[ADR-0203](0203-scatter-light-nuclides-by-free-gas-in-ufg.md) と [ADR-0204](0204-scatter-resonant-nuclides-by-free-gas-in-ufg.md) は、UFG の減速計算の散乱核を、入力で選べば温度 T の自由ガスにした。H in H2O の H も
自由ガス（ADR-0203 の案 K1）で、H の短時間衝突近似（有効温度）は、A ≈ 1 の下方散乱では物質の温度の自由ガスと同じになる（ADR-0203 の案 K2）。
参照解の OpenMC 0.15.2 は、H in H2O の H を S(α,β) の上限 B(4) = 10.00008 eV より下で S(α,β)、その上で温度 T の自由ガスで扱う
（[ADR-0133](0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md) の背景）。

H in H2O の 27 群（4〜9.877 eV）の入射の移行は、S(α,β) の表では群の中に残る割合が自由ガスより +2.54% 多く、低い群へは −0.3〜−32% 少ない
（examples/depletion/verification.md の「UFG の自由ガスの散乱核（ADR-0203）」、df0bc35c）。ADR-0203 と ADR-0204 の後も、1C のピンセルの
新しい燃料から 2A の 40 MWd/kg の組成（2A-40）への k の差の増えは +67.5 pcm 残り、この束縛の扱い（ADR-0203 の案 K3）がその第一の候補
だった（#0152）。

判断の軸（依頼とユーザーの指示、2026-10-27）: 正確さ > 速度 > 保守。説明できない定数や補正を入れない。S(α,β) の表そのものを使う厳密な
方法（参照）と、誤差を測った速い方法の両方を入力で選べる形で残す（将来ほかの手法を検討するときの参照解にするため）。ライブラリの互換性は
捨ててよい。既定は静止した標的のまま。

## 検討した案

### 移行の表の持ち方

- 案 P1: S(α,β) の表（温度ごとの α、β の格子と S）をライブラリに持たせ、lattice が格子点ごとに α について積分する（ADR-0203 の案 K3 の記述）。
  核の 1 回の評価が α の区間（H in H2O で 222）の積分で、格子点と区間ごとに評価すると重い。xs の `ThermalSab::kernel` と同じ積分を lattice
  に複製することにもなる
- 案 P2: xs が S(α,β) の P0 の核の点の値 p(E→E') を、入射と移行 t = E' − E の格子の上に持たせ、lattice が点の間を線形に補間する。作って
  測った（このブランチの途中の版。H in H2O、600 K）: 核は E' = E に対数の特異点（準弾性散乱の山）を持ち、入射 6 eV で、行の割合で
  |t| = 0.1 eV の 0.19 /eV から 2.5 meV で 0.35、1 µeV で 0.71、t = 0 で 0.83 /eV に上がる。間隔 5 meV の点の値の線形補間は、行の
  中性子の割合の 3.1e−3 を置き違え、WIMS 69 群の出射の群の割合で 15% 違った（間隔 2.5 meV で 1.4e−3、5.7%）。誤差は間隔に 1 次でしか
  減らない
- 案 P3: xs が、入射 E で散乱した中性子のうち出射が E + t 以下の割合（累積）C(E, t) を、入射と移行の格子の上に持たせる（採用）。xs は
  核を格子点の出射を境にした群で積分する（その求積は核の折れ目で区切り、E' = E に向けて細かく分けるので、対数の山も積分になる）ので、
  格子点の上の累積は正しい。格子点の間は区間の中の核を一定とする（累積を線形に補間する）

### 表の格子（案 P3）

格子は評価済みデータだけで決め、温度によらない（温度の間の内挿で点ごとに混ぜられる。[ADR-0080](0080-interpolate-sab-in-temperature.md)）。入射は S(α,β) の上限から
レサジーの等間隔で、UFG の下限から上方散乱の届く幅（表の最も高い温度の 28 kT。lattice の自由ガスの区間の幅 `TAIL` と同じ）の下まで、移行は
等間隔で出射 0 eV から上方散乱の届く幅まで（0 を含む）。行は S(α,β) の散乱断面積で割る。

- 移行の間隔 5 meV（採用）: 入射の格子点の間の累積の誤差は、準弾性散乱の山を含む区間の中で 600 K で 1.9e−4（2.5 meV で 7.4e−5、10 meV で
  4.1e−4）。格子点の上の累積は間隔によらず正しく、この誤差は山の割合の区間の中の位置だけ
- 入射の間隔 0.005（採用）: lattice の試験のセル（6.67 eV の共鳴を持つ燃料と水、600 K）で、自由ガスの核から作った表と自由ガスの核の
  群の中性子束の差が、0.02 で 3.3e−6、0.01 で 9.0e−7、0.005 で 3.2e−7、0.0025 で 1.7e−7 と間隔の 2 乗ほどで減り、自由ガスの区間の
  細かさ 4 と 16 の差 1.2e−7 に近づく（移行の間隔 5 meV。間隔を変えて測った試験は残していない）。0.01 では表の誤差が区間の細かさの誤差を
  超える。0.005 の表で、H in H2O の WIMS 69 群の出射の群の割合の相対差は 600 K で 1.1e−4、550 K で 1.3e−4（xs の例 `sab_transfer_error`）

### UFG の散乱源

- 案 S1: ADR-0203 の核の差 D（核 − 静止した標的の核/N）を S(α,β) の核で作り、自由ガスと同じ区間の 2 次式で積分する。点の値の評価なので、
  案 P2 と同じく対数の山を求積できない
- 案 S2: S(α,β) の上限より下の入射では、静止した標的の窓の σs/N を 0 にし（上限に両側の極限の 2 つの格子点を置く）、別の散乱源で扱う
  （採用）。出射 E の散乱源 ∫ σs F R du'（R = E p）を、入射を表の移行の格子点と減速計算の格子点で区切った小区間の和にし、小区間では表の
  累積の差 C(E'_c, t_b) − C(E'_c, t_a)（E'_c は中点の入射）に E/E'_c を掛けたものを ∫ R du' とし、σs と F は中点の値（F は格子点の値の
  線形補間）とする。上方散乱は自由ガスと同じスイープで扱う。上限より上の入射は自由ガスの核のまま（D の区間を上限より上の入射に限る）

### 行の規格化

- S(α,β) の散乱断面積で割り、行の和を 1 にする（採用）。衝突の率は UFG のポイントワイズの弾性散乱断面積（自由原子を温度に拡げたもの）の
  まま。S(α,β) の散乱断面積との差は 4〜10 eV で 0.3% 以内で、UFG の H の断面積を S(α,β) にしても k は 1 pcm 以内しか動かない
  （ADR-0133 の (b)）
- 行を割らず、S(α,β) の散乱断面積のまま使う: 衝突の率と散乱で出る割合が合わず、中性子が保存しない

### 速い方法

S(α,β) の移行は、ADR-0203 と ADR-0204 の速い方法（400 kT の上限、区間の細かさ 2、スイープ 3 回）とそのまま組める。小区間の数を減らす
近似（表の移行の格子を粗くする、小区間を表の格子点だけで切る）は、下の測定で S(α,β) の移行が速い方法に誤差を足さず、時間の内訳も
測っていないので作らない。

## 決定と理由

入力の項目 `ufg-free-gas` に `sab`（S(α,β) の核種を、S(α,β) の上限より下の入射でライブラリの S(α,β) の移行で散乱させる。省略すると
false）を足す（`ufg-scattering = "free-gas"` のときだけ書ける）。B(4) より上の H と、ほかの核種は ADR-0203、ADR-0204 の扱いのまま。
ライブラリの各温度に、S(α,β) の核種だけ（ポイントワイズの範囲があるとき）案 P3 の表 `sab_transfer`（入射、移行、累積）を持たせる（形式の
変更。nil でも項目は省けず、古い形式のライブラリは読まない）。S(α,β) の上限が UFG の下限から上方散乱の届く幅より下の核種（UFG に
届く S(α,β) の散乱がない）と、届く幅が UFG の下限を超える核種（正の入射から表を始められない）は表を持たない。`sab = true` で、S(α,β) の
核種に表がないか、自由ガスの核を持たないか（`heavy` のない分離共鳴を持つ核種）、S(α,β) の上限が範囲の上端以上（範囲の上の入射を静止した
標的と S(α,β) の移行の両方で数える）か、表が範囲の下限への上方散乱と上限から下限への下方散乱を覆わなければ止める。

測定（examples/depletion/verification.md の「H in H2O の S(α,β) の UFG の散乱核（ADR-0205）」。ライブラリは 843e2223、xlc は b7541488、
2026-10-27）。k の差は xlc − OpenMC（pcm）、増えは 1C の新しい燃料から 2A-40 まで。

| 組み合わせ                                                                                         | 種類 | 1C 0 MWd/kg | 2A-40  | 増え  | 参照からの差 |
| -------------------------------------------------------------------------------------------------- | ---- | ----------- | ------ | ----- | ------------ |
| `{ heavy = 400, sab = true }`（H は B(4) より下で S(α,β)、軽い核種は上限なし、細かさ 4、収束まで） | 参照 | +48.4       | +110.9 | +62.5 | –            |
| `{ upper = 400, heavy = 400, sab = true }`                                                         | 近似 | +44.2       | +108.0 | +63.8 | −4.2、−2.9   |
| `{ upper = 400, cells = 2, sweeps = 3, heavy = 400, sab = true }`                                  | 速い | +44.1       | +107.9 | +63.8 | −4.3、−3.0   |
| ADR-0204 の参照（`sab` なし）                                                                      | 比較 | +35.9       | +103.4 | +67.5 | −12.5、−7.5  |
| ADR-0204 の速い方法（`sab` なし）                                                                  | 比較 | +31.6       | +100.4 | +68.8 | −16.8、−10.5 |

- S(α,β) の移行は、k を自由ガスから 1C の 0 MWd/kg で +12.5、5 MWd/kg で +10.0、2A-40 で +7.5 pcm 動かし、増えを 5 pcm 縮める
  （+67.5 → +62.5）。#0152 の 27 群の燃料の中性子束の傾きは、1C の 0 MWd/kg で −0.45、−0.54、+0.28、+0.72% から +0.07、−0.43、+0.06、
  +0.27% に縮む。H の束縛は増えの残りの 5 pcm ほどしか説明せず、k の差（xlc − OpenMC）は正の側へ開く
- 速い方法と参照の差（−4.3、−3.0 pcm）は、自由ガスの 400 kT の上限の差（ADR-0204 で −4.1、−2.9 pcm）と同じで、S(α,β) の移行を
  足しても速い方法の誤差は増えない（同じ上限どうしの細かさ 2、スイープ 3 回と細かさ 4、収束までの差は −0.1 pcm）
- 時間は測っていない（測定のジョブは `--timed` でなく、その時間は記録に使えない）。手間は、S(α,β) の上限より下と上方散乱の届く幅の
  出射の格子点ごとに、表の移行の格子点（5 meV ごと）と減速計算の格子点で入射を区切る小区間の数に比例する

既定の案（決めるのはユーザー。ADR-0203、ADR-0204 の既定の案と組む）: 速い方法 `{ upper = 400, cells = 2, sweeps = 3, heavy = 400, sab = true }`。
OpenMC と同じ扱い（H の S(α,β)、重い核種の 400 kT の自由ガス）にし、参照からの差は 400 kT の上限の分（4 pcm 以内）。時間は、決める前に
`--timed` のジョブで測る。既定を切り替えると、静止した標的で出した記録（燃焼、分岐、集合体、炉心）がすべて古くなる。

## 帰結

- ライブラリの形式が変わり、xs で作り直していないライブラリ（examples/vera、examples/depletion/p2 などの核種の出力）は lattice が読めない。
  examples/depletion の 65 核種は作り直した（Slurm 550、14 分）。作り直していない例の dvc.lock の出力は古いまま
- ライブラリは H in H2O の 3 つの温度で 20 MB ほど大きくなる（examples/depletion で 299 MB から 319 MB）。表の大きさ、セルごとの表の
  コピー、散乱源の小区間の手間は詰めていない（#0180）
- 既定（静止した標的）と `sab` を書かない `"free-gas"` の結果は変わらない（1C の 0 と 5 MWd/kg の static、heavy-cap、heavy-fast3 の
  `swap_absorption` の出力は、ADR-0204 の記録のログと文字まで同じ）
- 残る UFG の範囲の差の候補: 27 群の 5.0〜6.3 eV の燃料の中性子束の −0.4%（U-238 の 6.67 eV の共鳴の下）、分離共鳴の上方散乱（ADR-0204 の
  案 R2）、等価なセル。#0152 に書く
- 参照（軽い核種の上限なし、収束まで）は ADR-0204 と同じく重い。重い核種の上限なし（`heavy = inf`）が収束しないこと（#0179）は変わらない
