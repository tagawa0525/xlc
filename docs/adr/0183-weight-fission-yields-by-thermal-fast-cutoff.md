# ADR-0183: 核分裂の収率の重みを、112.47 eV の境界で熱と高速の 2 点に分ける

## 背景

[ADR-0164](0164-build-full-chain-from-endf.md) は、チェーンが nfy のすべてのエネルギーの点の独立収率を持ち、使う側が点ごとの区間（隣の点との幾何平均で
区切る）の核分裂率の割合で重み付けすると決めた（案 Y3）。[ADR-0173](0173-deplete-lattice-pins-by-ce-cm.md) は、格子計算の燃焼でその区間の重みを群の核分裂率から求め、
境界を含む群をレサジーの幅の比で分けるとした。参照解の OpenMC 0.15.2 は `fission_yield_mode="cutoff"`（`FissionYieldCutoffHelper`。
境界は `examples/depletion/openmc_depletion.py` の `YIELD_CUTOFF` = √(0.0253 × 5e5) eV）で解く。2 点（0.0253 eV と 500 keV）の
核種では両者は同じだが、500 keV と 14 MeV の点を持つ核種では、区間の重みは 2.65 MeV（500 keV と 14 MeV の幾何平均）より上の
核分裂に 14 MeV の収率を使い、cutoff は 112.47 eV より上をすべて 500 keV の点にする。

nfy（ENDF/B-VIII.0。README によれば ENDF/B-VII.1 から変わっていない。MF1 MT451 の評価は England と Rider の ENDF-349、1992）の
独立収率（MF8 MT454）の入射エネルギーの点（2026-10-22、references/endf/ENDF-B-VIII.0_nfy の各 LIST の C1 を読んだ）:

- 0.0253 eV、500 keV、14 MeV の 3 点: U-233、U-235、Np-237、Pu-240、Pu-242、Am-241
- 0.0253 eV、500 keV、2 MeV、14 MeV の 4 点: Pu-239
- 500 keV と 14 MeV の 2 点（熱の点がない）: Th-232、U-234、U-236、U-238
- 0.0253 eV と 500 keV の 2 点: Pu-241、Cm-243
- 1 点: ほかの 18 核種（Cf-251 は 0.0252 eV）

U-235 の各点の LIST の L1（ENDF-6 の書式では、前の点とその点の間の内挿の則）は 2（線形と線形）。ENDF-6 の書式の手引き（ENDF-102）は
手元になく、L1 の意味は確かめていない。

各点の収率が単色の中性子の値か、スペクトルで平均した値かは、評価のコメント（MF1 MT451）に書かれていない（U-235 のコメントは
評価者、文献 ENDF-349、書式だけ）。OpenMC 0.15.2 の `openmc.data.FissionProductYields` の注記は、収率はふつう単色の中性子源で
測られないので、0.0253 eV の収率は単色の 0.0253 eV でなく熱炉の典型的なスペクトルから導いたものと読むよう書く。500 keV の点が
核分裂スペクトルの中性子による収率（England と Rider の「fast」）を表すことは、ENDF-349 が手元になく、確かめていない。

1C の測定（#0133 の経緯の 2026-10-22。試行の入力は examples/depletion/issue-0133/ の `rings1-cutoff-exact.toml`、xlc は 567003b57 の
`bin/lattice`、組成と tally は参照解の `openmc-1C-rings1`）:

- 区間の重みでは、2.65 MeV より上の核分裂（5 MWd/kg の組成で全核分裂の 4.2%、U-238 の核分裂の 51%）が 14 MeV の収率を取る
- 14 MeV の収率が熱や 500 keV の点と大きく違う核種がある（nfy の値）。Pm-148m の独立収率は、U-235 で 14 MeV が 9.42e-8、熱が
  8.10e-11（約 1,160 倍）、U-238 で 14 MeV が 5.73e-9、500 keV が 1.66e-11（約 350 倍）。I-135 は U-238 で 14 MeV が 2.57%、500 keV が 1.35%
- OpenMC との数密度の相対差は、区間の重みで 5 MWd/kg の I-135 −0.95%、Cs-133 −0.48%、Rh-103 −1.57%、Nd-149 −0.52%、Pm-149 −0.61%、
  Pm-147 −0.79%、Pm-148m +27.1% で、cutoff の重みで +0.02%、0.00%、+0.20%、+0.10%、+0.01%、+0.13%、+0.93% になる。どれもすべての
  燃焼点で消える
- 一方、Xe-135 と Sm-149 の差は cutoff の重みで大きくなる（5 MWd/kg で Xe-135 −0.11 → +0.60%、Sm-149 +0.81 → +1.47%）。#0133 は、
  同じ組成で xlc の燃料の 1 群の捕獲が Xe-135 で −0.79%、Sm-149 で −1.41% 小さいと測り、cutoff の重みの値をこの捕獲の差で説明した。
  区間の重みでは、収率の差がこの捕獲の差を打ち消していた

判断の軸:

- 評価済みデータの点が表すものに合う重みであること。データにない量（点の間の形）を推測で足さない
- 参照解（OpenMC）と同じ方式で、比較から重みの差を外せること
- 経路を 1 つにし、使わない選択肢を持たないこと

## 検討した案

- 案 W1: ADR-0164 の区間の重み（隣の点の幾何平均で区切り、区間の核分裂率の割合で点を重む）。点を単色の中性子の収率とみなして、
  入射エネルギーの近い点を選ぶ。PWR の 2.65 MeV より上の核分裂は核分裂スペクトルの中性子によるもので、14 MeV の点（単色に近い高い
  エネルギーの中性子の収率と読める）は、その中性子の収率を表さない。1C で Pm-148m を +27%、I-135 を −0.95% ずらした。OpenMC と方式が違う
- 案 W2: OpenMC の `FissionYieldCutoffHelper` と同じ cutoff。境界の下の核分裂に熱（0.0253 eV）の点、上に高速（500 keV）の点を使い、
  14 MeV と 2 MeV の点は使わない。点がちょうどなければ OpenMC と同じ選び方（境界が最初の点以下なら最初の点、最後の点以上なら最後の
  点だけ、それ以外は境界の下で熱に、上で高速に最も近い点）。500 keV の点を、熱より上のすべての核分裂（熱外と高速）の収率とみなす。
  熱外（112 eV〜100 keV）の核分裂にも 500 keV の点を使うが、点の間の形は評価にない
- 案 W3: 入射エネルギーで点の間を線形に内挿する（ADR-0164 の案 Y2。L1 = 2 を内挿の則と読む）。点を単色の値とみなす点で W1 と同じ
  で、0.0253 eV と 500 keV の間では熱外の核分裂がほぼ熱の収率になり、2 MeV より上では 14 MeV の収率が混ざる。OpenMC と方式が違う
- 案 W4: 核分裂を起こす中性子のスペクトルで重む（たとえば高速の核分裂の平均のエネルギーで点の間を内挿する、または核分裂スペクトルからの
  ずれだけを 14 MeV の点に回す）。点が表すスペクトル（ENDF-349 の定義）を確かめないと、ずれの基準が決まらない。評価にない量を作る

## 決定と理由

案 W2 にする。収率の重みは、群の核分裂率を境界 √(0.0253 × 5e5) = 112.47 eV で分けた割合で、下を熱（0.0253 eV）の点、上を
高速（500 keV）の点に置く。境界を含む群の核分裂率はレサジーの幅の比で分ける（ADR-0173 と同じ。OpenMC は連続エネルギーで数える）。
点がちょうどないときの選び方は OpenMC 0.15.2 の `FissionYieldCutoffHelper.__init__` と同じにする。核分裂率が 0 の領域は最初の点に 1 を
置く（`Chain::zero_rates` と同じ。燃焼行列に効かない）。

- 1C で、収率で決まる核種の差がすべての燃焼点で消える（背景）。区間の重みは、PWR の核分裂スペクトルの中性子による核分裂に、単色に
  近い高いエネルギーの収率を当てていた。500 keV の点が核分裂スペクトルの収率であることは確かめていない（背景）が、cutoff は 14 MeV の
  点を使わず、W1 と W3 の、点を単色の値とみなす前提を置かない
- 参照解と同じ方式で、比較から重みの差が消える
- 境界は 112.47 eV（熱と高速の点の幾何平均。ADR-0164 の 2 点の核種の区間の境界と同じ）にする。OpenMC 0.15.2 の `cutoff` の既定は
  112.0 eV（`openmc/deplete/helpers.py`）だが、参照解は 112.47 eV を与えている。差は 75.5〜148.7 eV の 1 つの群の中にあり、その群の
  レサジーの幅の 0.62%
- 区間の重み（W1）は消し、経路を 1 つにする。使う予定がない（比べる参照解は cutoff で、W1 の前提は上のとおり成り立たない）。
  入力の `[depletion]` の `yield-cutoff`（境界と 2 点を入力で選ぶ項目。#0133 の試行のために足した）も消し、上の値に固定する。
  境界と点を変える要求が出たら、そのとき ADR で決めて入力に足す

これは ADR-0164 の「核分裂の収率」の「使う側は、点ごとの区間 ... の核分裂率の割合で、点の収率を重み付けして足す」の部分と、
ADR-0173 の「核分裂の収率のエネルギーの重み」の段落と、OpenMC との対応の表の「収率の区間の重み」の行を置き換える。チェーンが nfy の
すべての点を持つこと（ADR-0164）は変えない。どちらの ADR もほかの部分は変わらず、ADR 全体の置き換えではないので、フロントマターは
変えない（ADR-0129 が ADR-0013 の一部を、ADR-0132 が ADR-0095 の一部を置き換えたときと同じ扱い）。

## 確認

- 単体のテスト（crates/lattice/src/depletion/tests.rs）: `yield_cutoff_is_the_geometric_mean_of_the_thermal_and_fast_points`、
  `yield_weights_split_the_group_at_the_cutoff_by_lethargy`、`yield_weights_take_the_thermal_and_fast_points_like_openmc`（3 点と 4 点の
  核種で 14 MeV と 2 MeV に重みを置かない、熱の点のない U-238 の型、1 点、熱か高速の点がちょうどない場合）、
  `fissionless_regions_put_the_yield_weight_on_the_first_point`。入力（crates/lattice/src/input/tests.rs）:
  `depletion_rejects_a_yield_cutoff_entry`
- 1C の比較（examples/depletion/verification.md の「格子計算の燃焼」。xlc は 0587676e、分岐点は main の a6c577d4、2026-10-22）:
  収率で決まる核種の OpenMC との差は、1 リングのすべての燃焼点で I-135 +0.02%、Cs-133 0.00%、Rh-103 +0.19〜+0.20%、Nd-149 +0.10%、
  Pm-149 +0.01〜+0.12%、Pm-147 +0.03〜+0.13%、Pm-148m −0.12〜+0.93%（4 リングも 1% 以内）。k∞ の差の 0 の点からの変化は 1 リングで
  −17〜+116 pcm、4 リングで −15〜+43 pcm。1 リングの 5 MWd/kg の超過は収率の重みでなく、OpenMC の燃焼の最後の点の k の外れ（#0133）が
  最も大きい。Xe-135 は +0.53〜+0.60%、Sm-149 は +0.25〜+1.53% で、区間の重みのときより大きい（背景。捕獲の差は #0133 に残す）

## 帰結

- xlc の燃焼の結果が変わる。1C は再実行する。2A と p2 の集合体の燃焼は、次に流すとき（#0129 の高速化のあと）に新しい重みになる
- 区間の重みで打ち消されていた Xe-135 と Sm-149 の捕獲の差（#0133）が、記録の数密度の差に出る
- 熱外の核分裂にも 500 keV の点を使う近似が残る（OpenMC と同じなので、比較には出ない）
- 500 keV の点が核分裂スペクトルの収率であること（ENDF-349 の定義）は確かめていない。確かめて違えば、この決定を見直す
- `xlc_depletion::chain::Fission` の区間の境界（`yield_bounds`）は使う側がなくなるので消す
