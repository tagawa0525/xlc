# ADR-0104: 非反射の格子の拡散係数は、中性子流で重みづけした outflow の輸送断面積から求める

## 背景

[ADR-0098](0098-derive-diffusion-coefficients-from-b1-and-currents.md) は、外周が鏡面反射の単一集合体の拡散係数を B1 の基本モードの中性子流から、非反射の格子（反射体、
カラーセット）の拡散係数を、outflow の輸送断面積 Σtr を中性子束と体積で重みづけした D = 1/(3⟨Σtr⟩) から求めると決めた。
反射体の I 型の格子（[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）で、反射体のノードの高速群の D は 0.895 cm になり、その D の均質な拡散の式では、
MOC の反射体の透過（出ていく正味の中性子流 / 入る正味の中性子流 = 0.082）を正の中性子束で表せない（ノードの核によらない。
[ADR-0102](0102-solve-non-fissile-nodes-with-anm.md)、[ADR-0103](0103-define-adf-by-one-node-kernels.md)。#0021）。

- 原理で決まり、手で合わせる係数を持たないこと
- 反射体の中性子流のスペクトルと向きの変化を扱えること

## 検討した案

- D = 1/(3Σt) のまま（[ADR-0044](0044-collapse-to-two-groups.md)）: 散乱の非等方性を入れない。水の多い領域と反射体で D を小さく見積もる
- outflow（out-scatter）の輸送補正 Σtr,g = Σt,g − Σ_g' Σs1(g→g')、D = 1/(3Σtr): 広く使われる（MPACT 4.4 Theory
  Manual、式 (5.24)〜(5.26)。手元の写し）。軽い核種で誤差が出る。MPACT は軽い核種に inflow の補正、水素に neutron leakage
  conservation を使う（同 5.3.3 節。B. C. Yee, E. W. Larsen, B. Kochunas, PHYSOR 2016 を引く。読んでいない）
- inflow（in-scatter）の輸送補正 Σtr,g = Σt,g − Σ_g' Σs1(g'→g) φ1_g' / φ1_g（中性子流の1次のモーメント φ1 で重みづけ）:
  より厳密だが、中性子流のスペクトル φ1 が要る。STREAM は減速材と近似のバックリングの 1D の P_N の計算で φ1 を求める
  （D. Lee, S. Choi, K. S. Smith, "On the Diffusion Coefficient of Two-step Method for LWR analysis," Trans. KNS Autumn
  Meeting (2015)、式 (10)）
- 臨界スペクトル（B1 または P1）の計算: 均質化した多群の定数で、臨界のバックリングを探し、B1 の方程式の中性子流 J_g から
  D_g = J_g / (B φ_g) とし、中性子束で少数群に縮約する（同上、式 (1)〜(5)）。B1 の方程式は P1 の散乱行列を含み、in-scatter
  の効果も入る。Polaris は臨界スペクトルの計算を既定で行い（Mode = SEARCH）、P1 と B1 を選べる（SCALE 6.3 の Polaris の
  マニュアル、3.2.7.5 節 option<CRITSPEC>）。CASMO-5 と HELIOS の扱いは一次資料で確かめていない
- MOC の正味の中性子流と中性子束の勾配から D = −J / ∇φ とする: 外周が鏡面反射の集合体では J = 0 で定まらない。勾配が
  小さいところで不安定になる。GET の ADF とは別の自由度を、局所の比で決めることになる

比較の例: STREAM と PARCS の2段階の計算を MCNP6 と比べ、outflow + B1 は k −39 pcm、集合体出力の差の RMS 0.76%、最大
1.79%、inflow + P1 は −58 pcm、0.62%、1.29%、inflow + 基本モード（D = 1/(3Σtr)）は −66 pcm、0.57%、1.28%、outflow +
基本モードは −122 pcm、2.36%、4.70% だった（同上の表 I）。反射体は燃料と並べた 2×1 のカラーセットから、臨界スペクトルの
計算なしに作った（同上 2.2 節）。詳しい比較は S. Choi, K. S. Smith, H. Kim, T. Tak, D. Lee, J. Nucl. Sci. Technol. 54(6),
705–715 (2017)、https://doi.org/10.1080/00223131.2017.1299648 （要旨だけ読んだ）。

この ADR で加えて比べた案（反射体の D。2026-10-09。調べた資料は lee_kns13 など、下の出典）:

- outflow の Σtr を中性子束で重みづけする（ADR-0098）: 反射体の高速群の D を小さく見積もり、I 型の格子で1ノードの均質な
  解が負になった。文献の PWR の径方向の反射体の高速群の D は 1.0〜1.4 cm 程度（例: STREAM の inflow で 1.25 cm）
- 中性子流で重みづけした outflow の Σtr（採用）: 同じ outflow の局所の輸送断面積を、中性子流のスペクトルと空間分布で
  少数群とノードにまとめる。MOC の解だけで決まる
- Koebke の等価理論のように、D を ADF とともに等価性の自由度にする（両方の面の不連続因子を等しくする D を求める。源のない
  1群なら閉じた形）: 均質な解を正にできるが、D が等価性の条件から決まり、輸送の物理量としての意味を持たない。中性子流の
  重みで正にならないときに検討する
- 均質な面の中性子束が正になるまで D を少しずつ大きくする（Scarabee 0.1.1 のリリースノート）: 手で決めた手順で、原理で
  決まらない

## 決定と理由

少数群は、[ADR-0044](0044-collapse-to-two-groups.md) のとおり境界 0.625 eV の2群とし、断面積は領域・群ごとの反応率を保存するように均質化・縮約する
（ADR-0044 から引き継ぐ。比べた案の記録はない）。

拡散係数は、格子の境界によって次のように求める。どれも、ライブラリの P1 の散乱行列と MOC の解から、手で合わせる係数
なしに決まる。

- 外周が鏡面反射の単一集合体（燃料の定数）: 集合体を細かい群のまま中性子束で均質化し（全断面積、P0 と P1 の散乱行列、
  νΣf、χ）、B1 の方程式で臨界のバックリングを探し、D_g = J_g / (B φ_g) を B1 の中性子束で少数群に縮約する。正味の
  中性子流が 0 の格子では、漏れのある体系での中性子流のスペクトルを、均質な無限媒質の基本モードとして求めるほかないため。
  B1 は P1 の散乱行列（in-scatter を含む）と、P1 より高い次数の効果（関数 γ(B²/Σt²)。B → 0 で 1）を含み、P1 より原理に近い。B² < 0（k∞ < 1）では γ の解析接続を使う
- 外周が鏡面反射でも核分裂のない格子（水だけ、核分裂性でない集合体）では、臨界のバックリングが定まらない。このときは
  B² → 0 の極限の B1 の中性子流の式（P1 の式、γ = 1）3 Σt,g d_g − 3 Σ_g' Σs1(g'→g) d_g' = φ_g を、均質化した MOC の
  中性子束 φ で解き、D_g = d_g / φ_g を MOC の中性子束で縮約する。臨界の場合と同じ式の極限で、in-scatter を含み、
  中性子流のスペクトルを決めるのに使えるのは格子自身の中性子束だけだからである（outflow の補正にすると、同じ鏡面反射の
  格子で、核分裂の有無で in-scatter の扱いが変わる）。いまの MOC は核分裂のない格子を解かない（固有値計算だけ）ので、
  この場合は定数を作る経路ができたときに使われる
- B1 には P1 の散乱行列が要る。ライブラリに P1 のモーメントがない（P0 だけで処理した）ときはエラーにする
- 非反射の格子とノード（反射体、カラーセット）: 中性子流で重みづけした outflow の輸送断面積から
  D_G = Σ_g J_g / (3 Σ_g Σtr,g J_g) とする（Σtr,g = Σt,g − Σ_g' Σs1(g→g')、領域ごと）。g は少数群 G の中の細かい群、J は
  MOC の領域ごとの中性子流（角度中性子束の1次のモーメント）を、ノードの正味の中性子流の向き e_G への射影にして体積で
  重みづけしたもの: J_r,g = V_r (J⃗_r,g · e_G)、e_G は Σ_{g∈G} Σ_r V_r J⃗_r,g の向き。Fick の法則 J_g = −D_g ∇φ_g を
  少数群で J_G = −D_G ∇φ_G と保つには、D の逆数（3Σtr）を中性子流で重みづけするのが自然である（Fick の法則を
  J について足す）。中性子束で重みづけすると、反射体では中性子流のスペクトルが中性子束より硬いので、高速群の
  ⟨Σtr⟩ を大きく、D を小さく見積もる（反射体の I 型の格子で、outflow の中性子束の重みの D = 0.895 cm では、1ノードの
  均質な解の真空の面の高速群の中性子束が負になり、正にするには 1.17 cm 以上が要る。examples/reflector/verification.md）
- 中性子流の重みは、ノードの中で符号が変わりうる（反射体の隣の熱群は、反射体から燃料へ戻る向きと外へ出る向きがある）。
  ノードの正味の中性子流の向きへの射影は符号つきの重みで、打ち消しても Σ_g Σ_r J_r,g（ノードの正味の中性子流の大きさ）が
  正なら定まる。ノードの正味の中性子流が 0（対称な位置）か、重みづけした ⟨Σtr⟩ が正でなければ、黙って別の定義に替えず
  エラーにする。打ち消しの程度（Σ|w| に対する Σw の比）はログに出す
- 領域の中性子流は、散乱の次数が 1 以上なら MOC の1次のモーメント、0 ならスイープで中性子流を数えて求める（どちらでも
  使える）。真空の領域は、通り抜ける角度中性子束から数える（Σtr = 0 で、中性子流は重みに入る）
- 外周がすべて鏡面反射の格子（単一集合体）は、ADR-0098 のとおり B1（核分裂がなければ B² = 0 の P1）で求める。ノードの
  正味の中性子流が 0 なので、中性子流の重みが定まらないためである

少数群の断面積の縮約の重みは、いまのとおり MOC の中性子束とし、B1 のスペクトルで重みづけし直さない（臨界スペクトルで
断面積を重みづけし直すかは、k∞ の保存と GET の ADF との整合に効くので、カラーセットでの比較のあとに別に決める）。

ADR-0098 は [ADR-0044](0044-collapse-to-two-groups.md) の D = 1/(3Σt) をやめ、2群の境界と縮約を引き継いだ。

この ADR は ADR-0098 を置き換える。ADR-0098 の決定のうち、2群の境界と反応率を保存する縮約、外周が鏡面反射の格子の B1
と、核分裂のない鏡面反射の格子の B² = 0 の P1、P1 の散乱行列がなければエラー、縮約の重みを MOC の中性子束とすることは、
上に書き直して含む。

## 確認

- MOC の領域の中性子流（`crates/lattice/src/moc.rs`）: 無限媒質で 0（`region_currents_vanish_in_an_infinite_medium`）、
  両側が真空の対称な帯で x が反対称、y はセルで打ち消す（`region_currents_are_antisymmetric_in_a_mirror_lattice`）、
  右が真空の帯で x の1次のモーメントのバランスの式を、等方散乱（スイープで数えた値）と P1 の散乱（1次のモーメント）の両方で
  満たし、差は領域の幅の2乗で減る（0.125 cm で 1% 未満。真空の領域を含む。`region_currents_satisfy_the_first_moment_balance`）
- 拡散係数（`crates/lattice/src/fewgroup.rs`）: 手で計算した符号つきの重み（逆向きの領域を含む）と一致
  （`open_lattice_weights_the_outflow_transport_cross_section_by_currents`、`open_lattice_without_p1_scattering_uses_one_third_total`、
  `current_weighting_counts_a_void_gap_with_its_current`）、MOC の格子の領域の中性子流から手で重みづけした値と一致
  （`open_lattice_d_uses_the_moc_region_currents`）、正味の中性子流が 0 と、重みづけした ⟨Σtr⟩ が正でないときはエラー
  （`current_weighting_needs_a_net_current_and_a_positive_mean`）。ADR-0098 の B1 と P1 の確認はそのまま引き継ぐ
- 反射体の I 型の格子（ADR-0095 の格子のノードごとの均質化を合わせた作業用の版で測った。記録は反射体の定数の
  ブランチで examples/reflector/verification.md に書く。2026-10-09）: 反射体のノードの D は（高速、熱）で、中性子束の
  重みの（0.895, 0.276）cm から（1.448, 0.348）cm になった。高速群は文献の 1.0〜1.4 cm の程度で、1ノードの問題の
  真空の面の高速群の均質な中性子束は正になった。熱群は真空の面で −0.00115 と負のままである。打ち消しの程度
  （Σw/Σ|w|）は、反射体のノードで高速 0.997、熱 0.21（熱群の中性子流は、燃料の近くで燃料へ戻り、外側で真空へ出る）。
  燃料のノードの D は（1.099, 0.375）から（1.538, 0.425）cm になった

## 結果

- 反射体のノードの熱群は、中性子流の向きがノードの中で変わり、重みが大きく打ち消す（0.21）。この D でも1ノードの
  均質な解の真空の面の熱群が負になるので、反射体の ADF はまだ作れない。熱群の扱い（Koebke の等価理論の D など）は
  ユーザーの決定のあとで別に決める
- 対称な位置のノード（正味の中性子流がほぼ 0）では、向きが丸め誤差で決まり、重みが意味を持たない。いまは厳密に 0 の
  ときだけエラーにしている。カラーセットの内側のノードで問題になったら、打ち消しの程度の判定を決める
- 非反射の格子の定数（真空の辺のある格子、ノードごとの均質化）の D は変わるので、作り直す。GET の等価性は D に依らない
- 単一集合体（鏡面反射）の D は B1 のままで変わらない
