# ADR-0249: 数密度の微分の摂動の組成は、既定で状態の自己遮蔽のまま燃焼の領域の物質だけを作り直し、自己遮蔽を解き直す経路は入力で選ぶ

## 背景

ADR-0221 の決定の「摂動の輸送の自己遮蔽」は、数密度の微分（2A では Pu-240）の摂動の組成で自己遮蔽（燃料の実効断面積、UFG の範囲の
移行、SPH 因子）を解き直すとした。解き直さなければ、ADR-0221 の背景の自己遮蔽の分（線形の補正の誤差のうち −12.49〜+4.45 pcm）が
D2 の残りに入る、という理由だった。

本番の形の 2A のテーブル（#0278。ADR-0239 の格子点、114 状態 × 27 燃焼点）の見積もりは約 34〜37 時間で、そのうち自己遮蔽を解く
状態とその微分の摂動が 29.7〜33.0 時間、ほぼ半分ずつ（#0180 の「許容する誤差ごとの時間」）。摂動の自己遮蔽は 1,274 回（自己遮蔽を
解く 49 状態 × Pu-240 が 0 でない 26 燃焼点）で、2A の 60 MWd/kg の 1 状態では摂動の 51.9 秒のうち自己遮蔽が 48.2 秒、MOC が 3.26 秒
（examples/depletion/issue-0180/branch/2A-60-zeroing-after-815.log。Slurm 815、xlc 0d839a956、2026-11-13。摂動の自己遮蔽は #0180 の
3 回目の節の Slurm 776 で 40.9〜41.3 秒）。

issue #0180 の「自己遮蔽を省いたときの誤差」の「微分の摂動の軸」は、自己遮蔽を状態の組成に固定した微分を、解き直した微分と比べた
（examples/depletion/issue-0180/reuse の 2A-derivative.toml と 2A-derivative-fixed.toml、Slurm 804、xlc 5b2b7d42e、分岐点 main の
0d91e4b2b、2026-11-13）。Pu-240 を 1 割変えたときの 2 群の k∞ の反応度の差（固定 − 解き直し）は、2A の 4、20、60 MWd/kg で −0.10、
−3.72、−7.22 pcm（微分の 0.11%、0.90%、0.84%）。テーブルの補正が使う数密度のずれ（2A に対する履歴の違いの Pu-240。60 MWd/kg で
2A-density の +4.70%、2A-rods の +18.68%）に当てた 1 次の誤差は 3.4 pcm と 13.5 pcm（格子の k∞）。

## 決定の要因

- テーブルの補正の誤差を格子の k∞ で見る（格子で乗った誤差は炉心で消えない、というユーザーの見方。ユーザー 2026-11-13）。目安は
  ADR-0200 の 5 pcm
- 本番の形のテーブルの時間（1 集合体の 1 種で 1 日を超える。CLAUDE.md の「方針」の、問題の大きさに釣り合わない時間の項）
- CLAUDE.md の「方針」の、速度のための近似は入力の項目として足し、既定は物理的に正しい方法にする（参照が数時間で既定にできなければ、
  参照からの差を測った速い設定。ADR-0209）。厳密な経路は入力で選べる形で残す
- 既定が特定の燃料の種類（未燃焼の標準のウラン燃料など）に合わせ込んだ設定にならないこと（ユーザー 2026-11-13）

## 検討した案

- 案 S（摂動の組成で解き直す。ADR-0221 の既定）: 厳密。本番の形の 2A のテーブルは約 34〜37 時間（#0180 の表の「1 pcm」の行）
- 案 F（状態の自己遮蔽のまま、燃焼の領域の物質だけを摂動の組成で作り直す）: 摂動は作り直しと MOC だけで、1 回約 4 秒（上の 815 の
  摂動の 51.9 秒から自己遮蔽の 48.2 秒を除いた 3.7 秒と、作り直しの分。作り直しは自己遮蔽の中の `mix` の 0.36 秒と同じ処理）。
  Slurm 822（下の「確認」の燃料の種類の測定。排他でない 32 CPU）の 2F、2M、2O、2P の摂動は 3.6〜5.2 秒（解き直すと 36.4〜91.7 秒）。
  誤差は背景の 3.4〜13.5 pcm（2A）。作り直しは ADR-0201 のホウ素の軸の物質と同じ形（`remix_varied`）で、#0180 の測定の経路
  （`shielding-burnup` にすべての燃焼点を挙げる）とビットで同じ物質になる（その経路は、同じ組成の参照の自己遮蔽を摂動ごとに
  もう 1 度解くので時間は減らない）
- 案 G（一般化摂動の線形化。ADR-0247 の UFG の接線 I2-T）: 暗黙の分を接線で厳密に求める。2A の 60 MWd/kg のピンの UFG の接線は
  31 核種の向きで減速計算に 1 スレッドで 84 秒を足し（Slurm 794）、2A の 1 状態で約 2.0 分の見込み（測っていない。ADR-0247 の
  帰結）。下流の接線（段 I2-3）は作っておらず、案 S の 1 回 41〜48 秒の自己遮蔽より長い。今は採らない（ADR-0247 の段階の計画が
  進んでから比べる）

## 決定と理由

案 F を既定にし、案 S を入力 `[history] derivative-shielding = "solved"` で残す（既定は `"fixed"`）。

- CLAUDE.md の「方針」の速度の近似の項のうち、「参照が数時間で既定にできなければ、参照からの差を測った速い設定」に当たる。厳密な案 S は
  本番の 2A の 1 種で 1 日を超え、既定にできない。案 F の差は 2A と、Pyrex、IFBA、Gd の集合体で測った（背景と「確認」。微分の相対の差は
  2A の 0.11〜0.90% に対して 0.21〜0.99%）。案 S は入力で選べ、案 F の誤差を測る参照になる
- 本番の形の 2A のテーブルは約 20〜22 時間の見込み（帰結）。案 S の約 34〜37 時間の 6 割
- 2A の誤差は、履歴のずれの小さい 2A-density で 3.4 pcm と ADR-0200 の 5 pcm の中、2A-rods で 13.5 pcm と 5 pcm を超える。13.5 pcm は
  ADR-0221 が解き直す理由にした自己遮蔽の分（−12.49〜+4.45 pcm）と同じ大きさで、案 F はこの分を補正に残す。制御棒を入れて燃焼させた
  履歴の補正の誤差を 5 pcm に収める必要が出たら、案 S をその入力で選ぶか、案 G を作る
- `[history] generalized`（ADR-0247）は、摂動の組成を解く核種のどれも解き直す（案 I1）ので、この項目を書けばエラーにする。自己遮蔽の
  組成を固定する `shielding-file`、`shielding-burnup` と `"solved"` もエラーにする（摂動の組成でも自己遮蔽はその組成のままで、
  解き直す経路が黙って案 F と同じになる）

### 帰結

- lattice の `[history]` に `derivative-shielding`（`"fixed"` か `"solved"`。省略すると `"fixed"`。`derivative` のない入力と
  `generalized` の入力に書けばエラー）を足した（crates/lattice/src/input.rs、crates/lattice/src/history.rs の `DerivativeShielding`）。
  案 F の作り直しは crates/lattice/src/branches.rs の `StateShielding::remixed_at`
- 本番の形の 2A のテーブル（#0278）の見込みは約 20〜22 時間（#0180 の「許容する誤差ごとの時間」の後の段落。状態の自己遮蔽とその状態の
  14.85〜16.5 時間、摂動 1,274 回 × 約 4 秒 = 約 1.4 時間、再利用する状態の 4.1 時間）
- ADR-0221 の決定の「摂動の輸送の自己遮蔽」を、この ADR を指す形に直した（ADR-0221 の「## 変更」）
- 案 F では摂動の組成の自己遮蔽を解かず、ログの `derivative_shieldings` は 0
- DVC のステージ: `bin/lattice` が変わったので、deps に持つ 206 のステージ（examples の 18 の dvc.yaml。ほかの deps も changed のものを
  含み、`bin/lattice` だけが changed なのは 26）が changed になる（`dvc status --json`、c9131ba72、2026-11-13。下流は数えていない）。
  既定で結果が変わるのは、`derivative` を持つ入力を解く examples/depletion/p9-2A の `branch-2A`（未実行。見込み約 20〜22 時間）だけで、
  ほかのステージの入力は数密度の微分を持たない。どれも再実行していない（読む作業が来るまで後回し。CLAUDE.md の「計算」）
- 既定に依る examples の入力のうち、案 S で測った記録の入力には `derivative-shielding = "solved"` を書いた（作り直したときに記録と同じ
  経路で解くため）
