# ADR-0227: ノードのテーブルは、制御棒の値が置き換えるセルを含むときだけ制御棒の軸を持つ

## 背景

[ADR-0224](0224-write-rod-branches-as-cell-replacements.md) は、制御棒の分岐を値ごとに基準の形状のセルを置き換えるセルで書くと決め、ノードごとの出力（`few-group` の
`nodes`。[ADR-0095](0095-make-reflector-constants-in-2d-with-normalized-adf.md)）と制御棒の分岐を組む入力をエラーにした。「格子計算はノードごとに軸を付け分ける仕組みをまだ持たず、
すべてのノードのテーブルに軸を入れる」ためで、仕組みは、径方向の反射体の格子（examples/vera/p5 の I 型の反射体の格子）は #0213、
平板は #0030 で作るとした。

ノードのテーブルが制御棒の軸を持つかは、次の ADR が決めている。

- [ADR-0127](0127-weight-partially-rodded-nodes-by-axial-fine-mesh-flux.md) の「反射体のテーブルの制御棒の軸」: 径方向の反射体のテーブルは制御棒の軸を持たない（制御棒は燃料集合体の
  案内管にだけ入る）。軸方向の反射体の層のテーブルは、制御棒が入りうる層だけが持つ
- [ADR-0128](0128-make-axial-reflector-constants-in-a-full-height-slab.md) の「制御棒の軸」: 平板のプレナム、上の端栓とギャップの層は持ち、トップノズル、上の炉心板、上の水と下の 4 つの層は
  持たない

core は、ノードの区間ごとに、その区間の棒の材料をテーブルの制御棒の軸の値として選ぶ（ADR-0127。棒のない区間は `out`）。棒の
入らないノードのテーブルの軸は、`out` のほかの値が選ばれることがない。

examples/vera/p5 の I 型の反射体の格子は、燃料のノード（棒が入る）と反射体のノード（`reflector = true`）を持つ。今は値ごとの別の
入力で解き、燃料のノードのテーブルだけを examples/core/rod_table.py でまとめ、反射体のノードは棒のない値の格子のテーブルを
使う（examples/vera/p5/p5_inputs.py の `REFLECTORS_3D`）。

決めることは、ノードごとの出力のどのノードのテーブルに制御棒の軸を入れるかの入力での書き方と、軸を持たないノードの定数を
どの値の状態から作るかである。カラーセットのノードと平板の燃料の媒質のノードは、ADR-0127 と ADR-0128 が決めていない（#0214）。

- 判断の軸: 既定値は ADR で決めたものだけにし、黙ったフォールバックを足さない。入力で選べること。平板（#0030）とカラーセットを
  後で同じ書き方で表せること

## 検討した案

- 案 A: ノードごとに軸の有無を書く（`nodes` の項目に `rod = true` か `false`）: どのノードにも書け、平板とカラーセットも表せる。
  ただし、置き換えるセルを含むノードに `false` を書くと値の状態を黙って捨て、含まないノードに `true` を書くと core が `out` の
  ほかの値を選ぶことのない軸になる。どちらも誤りとして止めるなら、書いた値は形状から決まる値と同じでなければならず、同じ情報を
  2 か所に書くだけになる。止めないなら、形状と食い違うテーブルを黙って書く
- 案 B: `reflector = true` のノードは軸を持たず、ほかのノードは持つ: 径方向の反射体の格子では ADR-0127 と同じになり、入力の項目を
  足さない。平板では、プレナム、上の端栓とギャップの層は反射体のノード（examples/vera/p5 の平板で `reflector = true`）で、
  ADR-0128 はこれらの層に軸を持たせるので、平板を表せない。`reflector` の意味（燃料と接する辺の ADF と角の点の CDF を燃料の値で
  割る）に、制御棒の軸という別の意味を重ねる
- 案 C: 制御棒の値が置き換えるセルを含むノードのテーブルだけが軸を持つ（採用）: 入力の項目を足さず、置き換えるセルの位置
  （`[branches.rod]` と `rows`）が決める。径方向の反射体の格子では、案内管は燃料のノードにだけあるので ADR-0127 と同じになる。
  平板では、置き換えるのは棒が入りうる上の層のセルだけ（ADR-0224 の「軸方向の平板の上の層も同じ書き方で書く」）なので、
  ADR-0128 の層の分け方と同じになる。core が軸の値を選ぶ意味（そのノードの区間の棒の材料）と、テーブルの軸の有無が一致する

## 決定と理由

案 C にする。ノードごとの出力の各ノードのテーブルは、制御棒のどれかの値が置き換えるセル（`[branches.rod]` の置き換えられる
セル）を、ノードの範囲（`columns`、`rows`。余白（`gap`）の薄い行と列を数える）の `rows` のセルに 1 つ以上含むときだけ、制御棒の軸を
持つ。軸を持つテーブルの軸と点の並びは ADR-0224 のもの（制御棒の軸を最後に、点は辞書式の順）。入力の項目は足さない。

- 制御棒の軸を持たないノードのテーブルは、棒のない値 `out`（基準の形状）の状態の定数だけを、連続の軸の点で持つ。棒のない値の
  状態は基準の形状の別の入力の格子計算と同じ問題を解く（ADR-0224）ので、このテーブルは基準の形状の別の入力のノードの
  テーブルと同じになる（今の examples/vera/p5 の反射体のノードの定数と同じ作り方）。ほかの値の状態のそのノードの定数
  （隣の燃料に棒が入ったときの反射体の定数）は書かない。core はそのノードで `out` だけを選ぶので使わない
- 軸を持たないノードの点は、軸を持つノードの点のうち値が `out` のものから制御棒の軸の番号を除いたもので、同じ順に並ぶ
- この ADR で通すのは、径方向の反射体の格子の形（平板でない（`axial = false`）ノードの出力で、反射体でないノード
  （`reflector = false`）が 1 つ）で、置き換えるセルがすべてその燃料のノードにあるものだけ。次はエラーにする（どれも、形状から
  決まる軸の有無が、ADR の決めていないテーブルになるか、ADR-0127 と食い違う）
  - 平板（`axial = true`）: 上の層の値の定数とともに #0030 で通す。この ADR の規則では、置き換える上の層のノードが軸を持つ
  - 反射体でないノードが 2 つ以上（カラーセット）: 棒の入らない集合体のノードの定数をどの値の状態から作るか（隣の集合体の棒の
    影響を、制御棒の軸を持たないテーブルにどう入れるか）を決めていない。どのノードにも置き換えるセルがあるカラーセット（#0214）も、
    決めるまでエラーにする
  - 反射体のノード（`reflector = true`）が置き換えるセルを含む: 径方向の反射体のテーブルは軸を持たない（ADR-0127）
  - 燃料のノードが置き換えるセルを含まない: 制御棒の分岐の値が、どのテーブルにも入らない
- 軸を持つかを入力で選ぶ形（案 A）にしないのは、選べる値が形状から決まる値と同じでなければ、core が使わないか誤るテーブルに
  なるため。ノードの軸の有無は、置き換えるセル（入力）で選ぶ

### 帰結

- 格子計算は、径方向の反射体の格子の制御棒の分岐を 1 つの入力で解き、燃料のノードのテーブルに制御棒の軸を、反射体のノードの
  テーブルに棒のない値の定数を書く。examples/vera/p5 の HZP の 8 本のテーブル（燃料と支持格子の層の 6 本と、I 型の反射体の
  格子の 2 本）を 1 つの入力の格子に置き換え、examples/core/rod_table.py を消した（#0213）。p5 のステージは再実行していない
- ADR-0224 の決定のノードごとの出力の項は、この ADR に合わせて一部を変えた（ADR-0224 の「## 変更」）
- 平板（#0030）とカラーセット（#0214）は、上のエラーのまま残る

  （crates/lattice/src/branches/tests.rs）
- 結合: `nodes_without_replaced_cells_hold_the_rodless_states`（crates/lattice/tests/rod_branch.rs）。2 群の合成のライブラリの

  別の入力の燃料のノードの状態とビットで一致し、反射体のノードのテーブルは制御棒の軸を持たず、基準の形状の別の入力の
  反射体のノードのテーブルとビットで一致する
