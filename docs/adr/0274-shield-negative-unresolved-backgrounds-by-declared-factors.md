# ADR-0274: 非分離共鳴（LSSF=0）の範囲の MF3 の捕獲か核分裂のバックグラウンドが負の評価は、既定はエラーにし、入力の宣言で File 2 だけの自己遮蔽因子を無限希釈の断面積に掛ける

## 背景

非分離共鳴の自己遮蔽は、ラダーのサンプルで σ0 ごとの実効断面積を求める（ADR-0177）。LSSF=0 の評価は、MF3 のバックグラウンドを
各サンプルの点に定数で足し、差 s(σ0) − s(∞) をポイントワイズの断面積に足す。LSSF=1 の評価は、MF3 を入れない File 2 だけのラダーの
比 s(σ0)/s(∞) を掛ける。ADR-0177 は、弾性散乱（バックグラウンドを含む）が負になる点を 1 μb にし（NJOY PURR と同じ）、ほかの反応の
負のバックグラウンドで全断面積が 0 以下になる点はエラーにすると決めた。

4 つの版の全評価を `xs nuclide` に通す走査（#0292）で、ENDF/B-VII.0 の 3 評価が止まった（#0319、#0320。xlc 2dc2899a の main の xs と、
一時の出力を足した同じ版、2026-11-20）:

- Ta-181（範囲 330〜5000 eV）: MF3 の MT102 のバックグラウンドが 330 eV で −1.61 b、MT2 が −6.47 b。サンプルの全断面積が 0 以下になり、
  `the sampled total cross section is not positive` で止まる
- Es-253（101.2〜10000 eV）: バックグラウンドは 101.2 eV の 0 から 10 keV の MT102 −0.698 b、MT2 −6.12 b へ線形。同じ文で止まる
- Cf-253（100.4〜10000 eV）: 10 keV で MT102 のバックグラウンドが −0.965 b、File 2 の平均の捕獲がおよそ 0.98 b で、和（無限希釈の捕獲）は
  0.014 b。遮蔽した捕獲が 10 keV で σ0 = 30 b から負になり（σ0 = 1 b で −0.041 b）、8500 eV の正の値との間を非分離共鳴の補間則
  log-log（INT=5）で補間するので、y1/y0 < 0 の冪が NaN になる。ライブラリの検査が `non-finite value NaN` で止める

原因は 3 つとも同じで、共鳴の部分の捕獲と核分裂は負にならない（ψ ≥ 0）のに、負のバックグラウンドを各サンプルに定数で足すので、共鳴の
間の点の捕獲か核分裂が負になる。NJOY2016 は止まらない: PURR は Ta-181 の 330 eV でサンプルの全断面積の最小が −1.54 b、確率テーブルに負の値が
16 あり、直接のサンプルの Bondarenko の σ0 = 1 b の全断面積は −195 b、確率テーブルからは捕獲 −0.374 b を出す。Cf-253 の 10 keV の σ0 = 1 b の
捕獲は −0.019 b。UNRESR は σ0 と全断面積のバックグラウンドとポテンシャル散乱の和が負のときだけ警告し、これらでは警告しない
（references/njoy-runs/issue-0319/、issue-0320/ の output。NJOY2016.79、565 K、2026-11-20）。

ENDF-102（BNL-224854-2023-INRE）の 2.3.1 節と 2.4.17 節は、LSSF=0 の MF3 を「File 2 から求めた平均（無限希釈か遮蔽した）に足す部分の
バックグラウンド」と定め、点ごとにどう配るかは決めていない。LSSF=1 は、File 2 から求めた遮蔽した平均と無限希釈の平均の比を、MF3 の
無限希釈の断面積に掛ける自己遮蔽因子の方法とする。

止まらない評価にも同じ状態がある。MF2 と MF3 の静的な走査（4 つの版の全中性子の評価）で、LSSF=0 の範囲の MT102 か MT18 の
バックグラウンドに負の値があるのは次の評価（範囲の中の最小）:

| 評価                   | 版    | 最小のバックグラウンド | 565 K で捕獲か核分裂が負のサンプルの割合 |
| ---------------------- | ----- | ---------------------- | ---------------------------------------- |
| Na-22                  | 4 版  | MT102 −0.0396 b        | 83 %                                     |
| Ar-36                  | 4 版  | MT102 −0.0005 b        | 16 %                                     |
| Cd-106                 | 4 版  | MT102 −0.0647 b        | 17 %                                     |
| Cd-111                 | 4 版  | MT102 −0.1457 b        | 0.16 %                                   |
| Eu-154                 | 4 版  | MT102 −0.099 b         | 0                                        |
| Am-241                 | VII.0 | MT102 −0.0422 b        | 0                                        |
| Cf-252                 | VII.0 | MT18 −0.0679 b         | 22 %                                     |
| Cf-253、Es-253、Ta-181 | VII.0 | 上の値                 | 4.8 %、止まる、止まる                    |

割合は、ラダーの和に一時の計数を足した xs（xlc 2dc2899a）の 565 K の 1 点の `xs nuclide`（examples/depletion/process-survey/<版>/ の入力）で、
全断面積が正なので止まらず、負の捕獲か核分裂の点を黙って和に入れていた。負になる割合は温度（ドップラー拡がり）とラダーの密度で
変わり、バックグラウンドの大きさでは決まらない（Ar-36 は −0.0005 b で 16 %）。

判断の軸:

- 物理として無い負の部分断面積を、自己遮蔽の和と群定数に入れないこと
- 評価の欠陥か、方法の前提の外にある評価は、黙って直さずに止め、扱いは入力の宣言で読めるようにすること（リポジトリの CLAUDE.md の
  「方針」。ADR-0267、ADR-0272 と同じ形）
- 宣言の要らない評価の出力を変えないこと

## 検討した案

- 案 A: LSSF=0 の範囲の MF3 の捕獲か核分裂のバックグラウンドに負の値があれば、既定はエラーにする。入力の核種の項目
  `unresolved-shielding = "factors"` を宣言したときだけ、その評価の自己遮蔽を MF3 を入れない File 2 のラダーの比で求め、無限希釈の
  断面積（File 2 の平均と MF3 の和）に掛ける（LSSF=1 と同じ経路）（採用）
- 案 B: 案 A の宣言を、止まる 3 評価だけに求める（サンプルの全断面積の検査のまま）: 今は止まらない評価（Na-22 の 83 % など）の負の捕獲の
  サンプルが、黙って和に残る
- 案 C: 案 A のエラーの条件を、サンプルの捕獲か核分裂が負の点があること（ラダーの和の中の検査）にする: 同じ温度の組と同じ種なら同じ
  評価が同じに止まるが、温度の組で条件が変わり、ある温度で負のサンプルが出なくても、別の温度の入力で止まる。今は負のサンプルの出ない
  Eu-154 と VII.0 の Am-241 でも、共鳴の間の点の和は負になりうる（共鳴の部分は 0 に近づく）
- 案 D: エラーの条件を、バックグラウンドの絶対値と File 2 の平均の比のしきい値にする: しきい値は物理で決まらない（Ar-36 は比が小さくても
  16 % の点が負）。丸めの大きさの負の値（4 つの版の捕獲と核分裂には無い。最小の絶対値は Ar-36 の 5e-4 b）も宣言を求める（ADR-0267 と同じ）
- 案 E: 宣言なしで、負のバックグラウンドの評価に自動で因子の方法を使い、warn を出す（「参照コードの誤りを真似ず、正しい方法を実装して
  warn」の読み方）: 既定がエラーでなくなり、評価の欠陥と扱いが入力に見えなくなる
- 案 F: NJOY PURR と同じく止めずに負のサンプルを和に入れる: σ0 の小さいところで無意味な値になる（PURR の Ta-181 の σ0 = 1 b の全断面積
  −195 b）。Cf-253 は NaN のまま
- 案 G: 負のバックグラウンドを、遮蔽した平均にだけ足す（ENDF-102 の文の字義どおり。重みの σt に入れない）: 遮蔽した捕獲はラダーの比の
  分だけ小さくなるのに、負のバックグラウンドは遮蔽されずに全部引かれるので、Cf-253 の 10 keV の σ0 = 1 b の遮蔽した捕獲は、File 2 の平均
  0.98 b に遮蔽因子を掛けた値から 0.965 b を引いて負のまま。ADR-0177 も「バックグラウンドを平均の補正としてだけ足す」を比べて採らなかった
- 案 H: サンプルの捕獲か全断面積を小さな正の値で下から抑える: 抑える値に根拠が無く、平均を変える

## 決定と理由

案 A にする。

- 共鳴の部分の捕獲と核分裂は負にならないので、MF3 の捕獲か核分裂のバックグラウンドが負なら、各サンプルに定数で足す今の方法（ADR-0177）は
  共鳴の間の点で負の部分断面積を作りうる。条件は、範囲 [el, eh] の中の MF3 の表（線形化した表の範囲の中の点と、下端は右、上端は左の値）で
  決め、温度、σ0、サンプルの数と種、スレッドの数によらない
- 因子の方法は、ENDF-102 が LSSF=1 に定める自己遮蔽因子の方法で、xs は LSSF=1 の評価に同じ経路を使っている（ADR-0177）。無限希釈の断面積は
  0 K の表（File 2 の平均と MF3 の和）のままで変わらず、遮蔽した値はそれに正の比を掛けるので、無限希釈が正ならどの σ0 でも正
- 負の捕獲か核分裂のバックグラウンドは、物理の平らな断面積ではなく、File 2 の平均を評価の値に合わせる補正と読める。補正は File 2 の共鳴の
  部分と同じく遮蔽されるとみなすのが因子の方法で、定数で足す方法は、補正を遮蔽されない量として扱い、ゆらぎの大きさ（分散）を File 2 のまま
  平均だけを下げるので、遮蔽を大きく見積もる（方法の差の大きさは「確認」）
- 宣言は評価ごとで、入力とログ（warn）から読める。値は `"factors"` だけを取る文字列にする（真偽の項目は、効かない `false` の宣言を書けて
  しまう）。輸送しない放射化の核種には遮蔽が無いので取らない
- 宣言の要らない評価（非分離共鳴が無い、LSSF=1、バックグラウンドが負でない、弾性散乱だけが負）への宣言は止める（評価が替わって古くなった
  宣言を黙って当てない。ADR-0267、ADR-0272 と同じ）
- 弾性散乱の負のバックグラウンドの 1 μb の扱い（ADR-0177、Mo-95 など）は変えない

### 帰結

- 既定のエラーで止まる評価が、走査で止まった 3 つ（Ta-181、Es-253、Cf-253）のほかに増える: 4 つの版の Na-22、Ar-36、Cd-106、Cd-111、
  Eu-154 と、VII.0 の Am-241、Cf-252。宣言の要る評価は VII.0 で 10、VII.1、VIII.0、VIII.1 で各 5 の計 25
- Cf-253 の NaN は、エラーで手前で止まる。符号の違う 2 点を log-log で補間すると NaN を返す `Interpolation::LogLog`（endf/tab1.rs）は
  変えていない
