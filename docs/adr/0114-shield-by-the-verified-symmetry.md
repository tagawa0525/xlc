# ADR-0114: 自己遮蔽のピンと塊の組を、MOC と同じ確かめ方で成り立つと分かった対称操作で作る

## 背景

成り立つ対称操作の判定を、MOC で使う決定（ADR-0112）と、自己遮蔽のピンと塊の組に使う決定（この ADR）に分けて書いていた
（ブランチ feat/0054-symmetry-operations の下書き）。

## 検討した案

- この ADR を独立した決定として残す
- [ADR-0112](0112-use-verified-symmetry-in-moc-and-shielding.md) に統合する（採用）

## 決定と理由

採らない。決定は 1 つ（成り立つ対称操作をトラックの像まで確かめて判定し、その結果を MOC と自己遮蔽の両方で使う）で、MOC 側と
自己遮蔽側に書き分けていただけだった。マージの hook が「1 つの決定を複数の ADR に分けた」と止め、ユーザーの判断で ADR-0112 に
統合した（2026-10-10）。内容（検討した案、確認、結果）は ADR-0112 にある。番号は再利用しないために、この rejected の ADR として
残す。

## 確認

確かめるものがない約束事。

## 結果

- 自己遮蔽のピンと塊の組の決定は ADR-0112 を参照する
