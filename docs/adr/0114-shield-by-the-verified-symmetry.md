# ADR-0114: 自己遮蔽のピンと塊の組を、MOC と同じ確かめ方で成り立つと分かった対称操作で作る

## 背景

自己遮蔽は、格子の対称操作で移り合うピンを組にして代表だけを解き（`symmetry::cell_orbits`）、構造材の塊も組でまとめる
（`shield_lumps`）。MOC の対称性（[ADR-0112](0112-use-every-symmetry-operation-that-holds.md)）は、移り合う領域が同じ物質
（同じ参照）であることを求める。今の自己遮蔽には、入力が対称でも移り合う部分を別々に解く経路が 2 つあり、そのときは別の
物質になって MOC が止まる（#0054）:

- (a) 扇形で分かれた構造材の塊（リングを丸ごと含まないまとまり。リングの内径が半ピッチより大きい四隅など）は、セルごとの
  黒体として遮蔽し、組でまとめない
- (b) 操作を認める条件が「どのセルもリングごとに物質が一様」なので、扇形ごとに物質の違うセルが 1 つでもあると、8 つの操作が
  すべて外れ、どのピンも組にしない

また、`cell_orbits` は操作を認めるときにトラックの像を確かめない。トラックが操作で移り合わない（方位角の組が対角線の鏡映で
閉じないなど）と、Dancoff 係数は対称にならないのに、代表の結果を像のピンに使う。判断の軸:

- 自己遮蔽の結果が、格子の対称性を作りの上で保つこと（値の近さで同じとみなさない）
- MOC と同じ確かめ方の対称操作で組を作ること（片方だけが認める操作を作らない）
- 対称な位置の結果の食い違いを、平均で隠さないこと

## 検討した案

- 案 A（採用）: 自己遮蔽の中で、ADR-0112 と同じ確かめ方（境界条件、セル、トラックの像と区間の長さ、領域ごとの入力の物質の
  番号）で成り立つ操作を求め、その操作でピンの組と塊の組を作る
- 案 B: 候補の操作を引数で受け取り、成り立つものを境界条件、セル、領域の物質だけで確かめる（ブランチ
  fix/0054-shielding-orbits、ADR-0114 の前の下書き）。トラックの像を確かめないので、トラックが移り合わない操作でも塊とピンを
  組にしうる。引数は格子のプログラムからは既定値（8 つの操作すべて）しか渡されず、使われない汎用化だった。また、そのときは
  像の塊どうしの値が食い違っていた（#0055。2 × 2 の格子の 180° の像の隅で Dancoff 係数 0.24353 と 0.24630）のに、組を 1 つの
  黒体にまとめたので、食い違いが組の値の中に隠れ、どこにも現れなかった
- 案 C: 自己遮蔽はそのままにし、MOC で、遮蔽のあとの物質の値が近ければ同じとみなす。丸めの違いを黙って捨て、どの大きさ
  まで捨ててよいかの根拠がない（ADR-0113 と同じ理由で採らない）
- 案 D: (a) だけを直し、(b) は扇形で物質の違うセルを動かさない操作をセルごとに認める。セルごとに操作を選ぶと、組が合成で
  閉じず、代表の選び方が決まらない
- 案 E: 格子のプログラムで強制した対称性（`"quarter"` など）で組を作る。自己遮蔽の組の正しさは、強制の指定によらず確かめた
  対称操作で決まるので、強制した対称性に絞る理由がない。ただし `"none"` だけは、検証の基準として判定そのものをしない（下の
  「使う操作」）

## 決定と理由

案 A にする。

- **使う操作**: 領域ごとの入力の物質を値として `symmetry::detect` で求めた、成り立つ対称操作をすべて使う（ADR-0112）。格子の
  プログラムは解く前に一度だけ求めて `shield_fuel_with` に渡し、`shield_fuel` は自分で求める。渡された操作で領域ごとの物質が
  移り合わなければ、また別の格子やトラッキング（セル、領域、トラック、方位角の数の違い）で求めたものならエラーにする。使った
  対称性と外した操作の理由は info のログに出る。`symmetry = "none"` では判定をせず、組を作らない（2B で解く燃料ピンが 39 本
  から 264 本に増える）。`"none"` は対称性を使わない基準の解で、判定の結果に頼らず、判定が止まる入力でも解けるようにする
  （ADR-0112）
- **ピンの組**: その操作で移り合うセルの最も小さい番号を代表にする。燃料のピンはリングごとに物質が一様
  （`shield_cell`）なので、代表の結果をリングごとに像のピンへ割り当ててよい
- **塊の組**: 塊（セルの中で接する、分離共鳴を持つ核種の組が同じ領域のまとまり）を、その操作で移した塊と同じ組にし、組の
  塊をまとめて 1 つの黒体として Dancoff 係数と平均弦長を求める。組の中の物質ごとの領域を 1 つの塊の物質にする。組の黒体の
  `cell` は、組の代表の領域のセル。まとめてよいのは、操作をトラックの像と領域ごとの区間の長さまで確かめているので、組の
  塊は形状もトラックも同じで、塊ごとに求めた値が丸めの程度で一致するからである（#0055 を区間を作る側で直したあと）。案 B
  との違いは、まとめる前提（像の塊の値の一致）を確かめていることで、テストで組の塊を 1 つずつ別に求めて組の値と比べる
  （下の「確認」）。食い違いが再発すれば、組の値に隠れずにそこで見つかる
- **(a)(b) の解消**: 操作を認める条件は領域ごとの物質の像の一致なので、扇形を物質の同じ扇形に移す操作は認める（(b)）。
  塊はリングを丸ごと含むかによらず像で組にする（(a)）

## 確認

- `shielding::tests::lattice::corner_lumps_keep_the_symmetry`: 3 × 3 の辺の中央に四隅に分かれた Zr の塊のある格子で、自己
  遮蔽のあとの物質の参照で判定した対称性が 1/8 で、その対称性の MOC の k と領域の中性子束が全体を解いた解と MOC の判定
  （k 1e-7、中性子束 1e-6）以内で一致する（#0054 の (a)）
- `shielding::tests::lattice::sectored_cells_keep_the_symmetry`: 中央が扇形 8 で物質の違う水のセルの 3 × 3 の格子で、角の
  ピンどうしと上下の辺のピンどうしが同じ物質を共有し、物質の参照で判定した対称性が左右と上下の鏡映の 1/4 で、その解が全体の
  解と一致する（#0054 の (b)）
- `shielding::tests::lattice::pieces_split_by_sectors_are_grouped_by_images`: 2 × 2 の格子の四隅に分かれた塊 8 つが、像の組
  3 つ（領域 4、4、8）になり、組の領域が1つの物質を共有する（前は塊ごとに 8 つの黒体だった）
- `shielding::tests::lattice::pieces_split_by_sectors_are_grouped_by_images` と `corner_lumps_keep_the_symmetry` の
  `assert_lump_members_agree`: `shield_fuel` が組にした塊を、組の中の塊（`shield_lumps` と同じく `Cell::adjacent` でつないだ
  連結なまとまり。同じセルの中で像どうしの隅も別々）に分けて `lump_dancoff` で別々に求め、どれも組の Dancoff 係数と平均
  弦長に 1e-10 以内で一致する。1 つの隅の隣の水の全断面積を 5% 変えると落ちる（0.2431 と 0.2463）
- `shielding::tests::lattice::symmetry_of_another_tracking_is_an_error`: 方位角の数の違うトラッキングや、セルの数の違う格子で
  求めた対称操作を渡すとエラー
- `shielding::tests::lattice::half_turned_lumps_have_equal_dancoff`: 同じ格子で、隅を別々の塊にして `lump_dancoff` で求めた
  Dancoff 係数と平均弦長が、180° の回転の像どうしで 1e-10 以内で一致する（#0055。自己遮蔽は像の隅を 1 つにまとめるので、
  隅ごとの値は `lump_dancoff` を直接呼んで比べるように書き換えた）
- `symmetry::tests::swapping_axes_turns_blocks`、`swapped_blocks_are_images` ほか: 自己遮蔽のピンの組（`Detected` の
  セルの代表）は、ブロックの像の向き（#0053）、境界条件、物質の違いを `cell_orbits` と同じく扱う
- VERA 2B を、変更の前の main（37a6484a）とこのブランチの `symmetry = "none"` で解くと、ピンの核分裂率のファイルはバイト
  単位で同じだった（k 1.186030、解いた燃料ピン 264 本中 39 本。そのときの none は自己遮蔽を組で解いていた。
  examples/vera/verification.md「成り立つ対称操作をすべて使う」、d6ac2070、2026-10-10）。none が判定をしなくなったあと
  （e57eed6c）は、自己遮蔽が 264 本をすべて別々に解き、ピンの核分裂率は組で解く main と最大 1.2e-12 しか違わない（同じ節の
  注記）

## 結果

- 自己遮蔽は、強制の指定によらず確かめた対称操作で組を作る。`symmetry::cell_orbits` はなくし、ピンの組は `detect` の
  結果（`Detected::cell_representatives`）から作る
- 塊の像が 1 つの塊にならないとき（対称操作がセルの中の接し方を保たないとき）は、内部エラー `LumpImage` で止める。接し方は
  整数の対応で決まり正方形の対称操作で保たれるので届かないはずだが、パニックにしない方針なのでエラーとして残す
- 格子のプログラムは対称操作を一度だけ求め、分岐の状態の間で再利用する（ADR-0112）
