# ビルドの整列の設定の測定

ADR-0157（ループの先頭を 64 バイトに揃えてビルドする）を決めた測定。整列の設定ごとに、xs、lattice、core の出力が
バイト単位で同じかと、時間を比べる。

## 計算

- スクリプトと入力: このディレクトリの `build.sh`、`measure-xs.sh`、`measure-lattice-core.sh`、`measure-2A.sh`、
  `pincell-1B.toml`、`assembly-2A.toml`（examples/vera/p1/pincell-1B.toml と examples/vera/p2/assembly-2A.toml に、少数群定数の
  全桁の出力 `few-group` を足したもの）
- 走らせたコミット 619cdc24、分岐点 5c21dfed（main）、2026-10-14。実行ファイルは 619cdc24 の default の devShell
  （`nix develop`）の中で `build.sh` で作った。r995 の Slurm の排他のジョブ 313（xs）、317（lattice と core）、319（2A の繰り返し）
- 測った実行ファイル: 3 つのコミットのソースを `build.sh` で release でビルドしたもの。6b39ad13（main）、ab7c70b3 と b501c22e
  （ブランチ perf/0088-line-shape-table のコミット。タグ `record/adr-0157-fast-placement` と `record/adr-0157-slow-placement`）。
  b501c22e は ab7c70b3 に、xs の依存の `num_cpus`（Cargo.toml と Cargo.lock）と `num_cpus::get_physical()` の呼び出しを足したもの
  （ほかの差はテストとコメント）
- 設定（各ソースの `.cargo/config.toml` の `target-cpu=znver5` に `-C llvm-args=…` で足す）: v0 なし、v1
  `-align-all-functions=6`、v2 v1 と `-align-all-nofallthru-blocks=6`、v3 `-align-loops=64`
- `xs` の md5 の先頭 8 桁（v0 から順に）: 6b39ad13 は eac55aa7、37d2735e、ccbd1fdd、dd8bc3f5、ab7c70b3 は b6ec398e、9a0a4769、
  14369825、1927c9a1、b501c22e は f4b8ba35、b5e3e7b9、817c10a3、a7fbd526

## 出力の一致

- xs（M0、examples/m0/xs.toml）: 3 つのコミット × 4 つの設定 × 2 回の 24 本のライブラリは、すべてバイト単位で一致した
  （md5 `1943d0c43e0a5023686b829cc4029967`）
- lattice と core（6b39ad13、4 つの設定 × 2 回）: M0 のピンセルの少数群定数と標準出力、M0 の炉心の標準出力、VERA 1B の
  少数群定数と標準出力、2A の少数群定数、ピン出力、標準出力は、すべてバイト単位で一致した。319 の 2A の 12 回も一致した

| v3   | 54.20〜54.39 | 54.16〜54.22 | 54.03〜54.16 | `0x143980`、`0x150b80`、`0x151600`           | 3,611,664 バイト          |

- この devShell で作った実行ファイルでは、遅い置き場所に当たったのは b501c22e の v1（関数を 64 バイトに揃えたもの）で、
  v0 の b501c22e は遅くなかった。#0105 で遅かった b501c22e の v0（`0x141d00`）は、`NIX_NO_SELF_RPATH` のない前の devShell で
  作ったもので、置き場所が変わった（前の devShell では RUNPATH に作業ディレクトリのパスが入る。それが置き場所を変えた
  候補だが、確かめていない）。関数の開始アドレスは、速い b501c22e の v0 も 64 で割り切れ、開始アドレスの
  64 での余りだけでは速さは決まらない
- v2 と v3 は、3 つのコミットのどれも 53.9〜54.4 秒にそろった。v3 の 3 つの `cross_sections` の開始アドレスは 64 で割り切れる
- 同じ実行ファイルの 2 回の差は、v0 で最大 4.7 秒（ab7c70b3）あり、v1、v2、v3 は 0.31 秒以下だった。ばらつきは #0112
