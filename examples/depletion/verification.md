# 燃焼のソルバ（CRAM）、燃焼チェーン、格子計算の燃焼

`xlc_depletion::deplete`（[ADR-0161](../../docs/adr/0161-solve-depletion-with-ipf-cram.md)）を、解析解のある小さなチェーンと、OpenMC の
`openmc.deplete.cram` と比べる（[M4 の計画](../../docs/plans/m4-depletion.md) の進め方の 4）。全核種の燃焼チェーン
（[ADR-0164](../../docs/adr/0164-build-full-chain-from-endf.md)）を、OpenMC の `Chain.from_endf` で同じ ENDF から作ったチェーンと比べる（進め方の 2。「燃焼チェーン」）。
格子計算の燃焼（[ADR-0173](../../docs/adr/0173-deplete-lattice-pins-by-ce-cm.md)）を、VERA 1C のピンセルで OpenMC の燃焼（`openmc.deplete`）と比べ、時間の内訳を測る
（進め方の 5。「格子計算の燃焼」）。

| ファイル                                           | 内容                                                                                                    |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `cases.toml`                                       | OpenMC と比べる燃焼行列（例示の PWR の燃料のチェーン、複素の固有値の環、硬いチェーン、300 核種の乱数）  |
| `compare_openmc.py`                                | 同じ行列を OpenMC の `CRAM16`、`CRAM48` と xlc に与えて差を出す（references の devShell）               |
| `../../crates/depletion/examples/deplete_text.rs`  | 行列を文字で受け取って `deplete` を呼ぶ（`compare_openmc.py` が呼ぶ）                                   |
| `chain.toml`、`dvc.yaml`                           | 全核種のチェーン `chain.msgpack`（`bin/chain`）と OpenMC のチェーン `openmc-chain.xml` を作る段階       |
| `compare_chain.py`                                 | 2 つのチェーンの核種、半減期、崩壊の分岐、反応、収率を比べる                                            |
| `chain-cases.toml`、`compare_chain_depletion.py`   | 2 つのチェーンに同じ 1 群の反応率を与え、1 ステップを CRAM48 で解いて比べる                             |
| `../../crates/depletion/examples/deplete_chain.rs` | チェーンと反応率から燃焼行列を組み立てて `deplete` を呼ぶ（`compare_chain_depletion.py` が呼ぶ）        |
| `lattice-1C-rings1.toml`、`lattice-1C-rings4.toml` | xlc の格子計算の燃焼（VERA 1C、燃料 1 リングと 4 リング）。`lattice-2A.toml` は 2A の 1 ステップの時間  |
| `openmc-library.toml`、`openmc_depletion.py`       | OpenMC のライブラリ（輸送する核種を xlc と揃える）と、OpenMC の燃焼（`openmc-1C-rings*.toml`）          |
| `compare_depletion.py`                             | 2 つの燃焼の履歴を比べた要約（`compare-1C-rings*.json`）。記録の表は `../verification_tables.py` が描く |

誤差と差は、絶対値の最大を初期の数密度の最大で割ったもの（ADR-0161 の「確認」）。


### 計算

a19a9112（分岐点は main の 98c36637）、2026-10-14。チェーンの段階は `bin/chain`（md5 71f0fbbc）と OpenMC 0.15.2 の
`Chain.from_endf`（ENDF/B-VIII.0 の decay 3,821、nfy 31、neutrons 557）。

### チェーンの比較

| 項目                       | 結果                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| 核種                       | どちらも 3,820（同じ集合）。不安定 3,561、反応を持つ 555、核分裂する 88                                   |
| 半減期                     | 不安定の 3,561 核種で一致（相対差 0）。半減期が 0 の不安定な 14 核種（Xe-136 など）はどちらも安定とみなす |
| 崩壊の分岐（型と娘が同じ） | 5,056。分岐比の差の最大 2.1e-7（Bi-196m2）、1e-12 を超えるもの 377                                        |
| 崩壊の分岐（娘が違う）     | SF 127、娘が decay にない 8                                                                               |
| 反応（生成物が同じ）       | 2,430                                                                                                     |
| 反応（生成物が違う）       | xlc が MF8 の状態に分けるもの 104、生成物が decay にない 1（Pu-245 (n,p)）                                |
| 核分裂の収率（自分の収率） | 31 核種の 52 のエネルギーの点で、0 でない生成物の数と値が一致（差 0）                                     |
| 核分裂の収率（借りる）     | 57 核種。借りる先が同じなのは 4（Am-242 の Am-242m など）                                                 |

違いはすべて ADR-0164 の規則による:

- 分岐比の差: 和の 1 からのずれ（最大 9e-7）を、xlc は比で割り直し、OpenMC は最大の分岐に足す
- SF: xlc は親を減らし生成物を持たない。OpenMC は娘を親そのものにするので、燃焼行列で SF の分岐が親を減らさない
- 娘が decay にない 8 件（Cf-239、Cf-256、Es-240、Es-243、Es-258、Rf-253、Ds-279m、Ni-48）: xlc は娘を生まず、OpenMC は
  `replace_missing` で β の向きを推して別の核種にする。He-5 の α の娘（中性子）は、どちらも追わない
- MF8 の状態: xlc は MF8 が LMF = 9、10 で挙げる状態ごとのチャネルに分け（Am-241 (n,γ) の Am-242m、Np-237 (n,2n) の Np-236m、
  Am-243 (n,γ) の Am-244m など）、OpenMC の `from_endf` は基底状態だけにする。xlc は 12 件で、MF8 の励起エネルギーと decay の
  準安定状態の励起エネルギーが 1e-3 を超えて違う（Am-244m が 72.9 keV と 86.1 keV、Np-236m が 185 keV と 56 keV など）ので、
  近い順の対応で決め、2 件（Cr-51 (n,α) の Ti-48 の 3.63 MeV、Ir-191 (n,2n) の Ir-190 の 36.15 keV）は decay に対応する
  準安定状態がなく基底状態に落とす（`chain` の警告に全件が出る）
- Pu-245 (n,p) の Np-245: xlc は残りの核を生まず（H-1 だけ）、OpenMC は β− の向きに進めて Pu-245 にする
- 借りる収率: xlc は同じ原子番号の質量数の最も近い核種（U-239 は U-238、Np-239 は Np-238、Pu-243 は Pu-242）、OpenMC は
  isotone か U-235（U-239 は Pu-241、Np-239 は Pu-240、Pu-243 は Cm-245）
- decay にない収率の生成物（U-235 で 112 の状態）は、どちらも準安定状態を基底状態へ、基底状態を β− の向きに移し、値が一致する

核分裂の Q（MF3 MT18 の QI。出力の規格化に使う。ADR-0173）は、核分裂する 88 核種で一致する（相対差 0）。`compare_chain.py` の
`核分裂の Q` の行で、xlc a0eead78（分岐点 316e30b6。チェーンの段階の `bin/chain` は md5 8a32a619）、2026-10-15。

### 同じ反応率での 1 ステップ

反応率と収率のエネルギー（0.0253 eV）は chain-cases.toml。全核種のチェーン（3,820 核種）の燃焼行列を、xlc は `Chain::matrix` と
`deplete`（次数 48）で、OpenMC は `Chain.form_matrix` と `CRAM48` で解く。差は、絶対値の最大を初期の数密度の最大で割ったものと、
初期の最大の 1e-12 倍より大きな核種の相対差。

| 場合                    | 差 / 初期の最大 | 経路の核種の相対差の最大                                         | 相対差の最大（全核種） |
| ----------------------- | --------------- | ---------------------------------------------------------------- | ---------------------- |
| U-238 の捕獲、30 日     | 2.5e-15         | 2.7e-15（U-239、Np-239、Pu-239）                                 | 1.4e-11（U-235m）      |
| U-235 の核分裂、10 時間 | 6.5e-15         | 9.6e-15（I-135、Xe-135、Pm-149、Sm-149、Cs-135、Xe-136、Sm-150） | 1.0e-7（Ge-81m）       |
| U-235 の核分裂、30 日   | 1.4e-13         | 9.3e-15（同上）                                                  | 1.0e-7（Ge-81m）       |
| Pu-239 の核分裂、30 日  | 4.5e-13         | 1.1e-15（Pu-239 と同上）                                         | 1.0e-7（Ge-81m）       |

経路の核種は丸めの水準で一致し、核種の並び、崩壊と反応と収率の向きが OpenMC と同じ行列になる。Ge-81m の 1.0e-7 は、先行核
Ga-81 の分岐比の和が 1 − 1e-7 で、xlc は比で割り直し（Ge-81m への分岐が 1e-7 増える）、OpenMC は差を最大の分岐（Ge-81 への
分岐）に足すため。U-235m の 1.4e-11（値は初期の最大の 1.3e-12 倍）の原因は確かめていない。この 4 つの場合では、SF と MF8 の
状態の違いは効かない（U-238 の SF は崩壊の 5.5e-7 で、崩壊そのものが 30 日で 1e-11 の水準）。

## 燃焼の多群ライブラリ

燃焼の検証（docs/plans/m4-depletion.md の「進め方」5）の最初の多群ライブラリ `depletion.msgpack`（ADR-0169、形式は ADR-0172）を、
核種ごとの段階（ADR-0138）で作る。

```sh
dvc repro examples/depletion/dvc.yaml          # xs-range、xs-nuclide@<核種>、xs（depletion.msgpack）
```

### 計算

xlc a030052d（分岐点 bcc6d4cb、2026-10-15）。Slurm の排他のジョブ 397 で、VERA のライブラリと同じジョブの後の手順として
`dvc repro examples/depletion/dvc.yaml:xs` を実行した。H-1 の段階だけは、同じ xs のコードの前のジョブ 391（xlc 63713831。弾性散乱の
下限（ADR-0177）の前で、H-1 は非分離共鳴を持たない）で作ったものを引き継いだ。

### 結果

- 核種は 65: VERA の Problem 1 の物質の核種 31（Zr と Sn は燃料の温度 565、600、900、1200 K でも作る）と、燃焼チェーンの核種 34
  （examples/depletion/xs.toml）。ポイントワイズの範囲は 4 eV〜1.353 MeV。ファイルは 299 MB（md5 0f75e26c）
- 非分離共鳴はラダーのサンプリングで遮蔽する（ADR-0177）。Mo-95 は MF3 の弾性散乱の背景が負で、サンプルのエネルギーの 1e-5 以下
  （565 K で 3,712,000 点のうち 33 点）で弾性散乱を 1 μb にした（`tracing::warn!`）
- チェーンの反応の経路のうち状態に分かれるのは、Am-241 と Am-243 の (n,γ)、Am-243 と Np-237 と Zr-90 の (n,2n)、Fe-58 の (n,p)。
  Am-241 の (n,γ) の Am-242m への割合は、熱群（69 群）で 0.100（2,096 b と 233 b）。負の経路の断面積はない（この項は ADR-0177 の
  前の 60 核種のライブラリ（xlc 53c750b3）で確かめたもの。戻した 5 核種と、非分離共鳴の範囲の群は確かめていない）
- 時間: 核種ごとの段階の時間（xs の `time.busy`。65 核種のうち、このジョブの 64）の和は 120 分。長いのは Am-242m（1,205 秒）、
  Eu-151（709 秒）、U-235（421 秒）、Am-243（345 秒）、Eu-153（339 秒）、Pu-239（331 秒）、U-238（310 秒）。ADR-0177 の前（42 分）
  からの増えは、非分離共鳴のラダーの係数の計算（窓の外の共鳴まで、ラダーの数に比例）で、Am-242m と Eu-151 は非分離共鳴の格子の
  点が多い（候補。確かめていない。#0138）

## 格子計算の燃焼

VERA Problem 1C のピンセル（燃料 900 K、被覆管と減速材 600 K、ホウ素 1300 ppm。`../vera/p1/pincell-1C.toml` と同じ形状、組成、
離散化）を、分岐なしの 1 つの状態で、初めの重金属あたり 38.41 W/g（Problem 9 のサイクル 1 の平均、16.939 GWd/MT / 441 EFPD）で
0.1、0.5、1、2、3、5 MWd/kg まで燃焼させ（6 ステップ）、xlc（ADR-0173）と OpenMC 0.15.2 の `openmc.deplete` を比べる。燃料は等しい
面積の 1 リングと 4 リングの燃焼の領域（4 リングの xlc は、飛程の表が大きくなるので格子点ごとに飛程を求める。#0129）。
OpenMC は 1 世代 20 万粒子・130 世代（最初の 30 世代を捨てる）、16 スレッド。方式の対応は ADR-0173 の表
（CE/CM と CRAM48、`fission-q` の規格化、収率の境界 112.5 eV、連続エネルギーの反応率）。

```sh
dvc repro examples/depletion/dvc.yaml          # OpenMC と xlc の燃焼、compare-1C-rings*.json
python3 examples/depletion/compare_depletion.py --report examples/depletion/compare-1C-rings1.json
```

### 計算

OpenMC（Slurm の排他のジョブ 409。ライブラリは Pm-147、Pm-148、Pm-149、Am-242m、Eu-151 を含む）、xlc、比較は a5981e7f、
分岐点は main の 15deefcb。OpenMC は 2026-10-16、xlc の格子の段階は e47ebaf2 の時点で 2026-10-15（排他のジョブの番号は記録していない。
時間の表の xlc の行はこの実行の値）。比較の段階は 2026-10-21 に relock した。
比較の入力は `lattice-1C-rings1.msgpack` md5 75c1b700、`openmc-1C-rings1.msgpack` md5 2c7d0331、
`lattice-1C-rings4.msgpack` md5 c7eb0d29、`openmc-1C-rings4.msgpack` md5 011dfabb（JSON の `inputs`）。

### 輸送する核種

燃料で輸送する核種は、両方で同じ 54 核種（ライブラリが燃料の温度 900 K そのもので持つチェーンの核種。`compare_depletion.py` が確かめる）。
数密度が 0 の核種も、最初の輸送から 1 原子あたりの反応率を持つ（OpenMC の燃焼の tally は数密度を掛けない。ADR-0173）。
ライブラリにないチェーンの核種と、900 K のデータのない H-1、B、Fe、Cr は、どちらも崩壊と生成だけを追う。Pm-147、Pm-148、Pm-149、
Am-242m、Eu-151 は、ADR-0177 の確率テーブルのあとで両方のライブラリに入れ、どちらも輸送する。ADR-0173 の本文の 49 核種と
k∞、数密度の数値は、これらが OpenMC のライブラリになかった測定のもので、この節が今の結果である。
