# LWR MOX ピンセル

NEA の LWR MOX ピンセルのベンチマーク（pin_cell.pdf の付録 2「LWR MOX pin-cell benchmark」、
<https://www.oecd-nea.org/science/docs/pubs/pin_cell.pdf>。手元では references/mox/）の MOX-1 と MOX-2。
Pu の同位体の自己遮蔽を確かめるために使う。特に Pu-240 の 1.06 eV と Pu-242 の 2.67 eV の共鳴は UFG の範囲
（4 eV〜15.03 keV）より下にあり、ライブラリの σ0 の表と等価原理（Carlvik の2項有理近似）で遮蔽する。
参照解は、xs と同じ ENDF/B-VIII.0 から手元の NJOY で作ったデータで OpenMC を動かして作る（examples/vera と同じ）。

この記録の格子計算（自己遮蔽のある lattice）の値と、それから作った定数は、自己遮蔽の UFG の減速計算の古い既定（静止した標的、無限希釈の形）のもので、既定を切り替えた [ADR-0209](../../docs/adr/0209-default-ufg-to-physical-kernels.md) の後に作り直していない。

| ファイル                   | 内容                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| `xs.toml`                  | xlc の多群ライブラリ（`mox.msgpack`）の入力。参照解と同じ核種で、すべて 600 K                      |
| `pincell-mox1.toml` など   | xlc の格子計算の入力（燃料 5 リング、被覆管 1 リング、水 3 + 2 + 1 リング、扇形 8）                |
| `openmc_model.py`          | MOX-1, MOX-2 を OpenMC で解き、燃料の核種ごとの実効断面積を xlc の群で書く                         |
| `openmc-mox1.msgpack` など | 下の参照解の燃料の実効断面積（`openmc_model.py` の `fuel-xs.msgpack`。git で追跡しない。ADR-0121） |
| `compare_capture.py`       | 核種ごとの実効捕獲・核分裂断面積を群ごとに比べ、反応率の差を k の差に換算する                      |

OpenMC のデータは examples/vera/openmc_library.py で作る（Pu-238〜242 と Am-241 は 600 K）。

## 仕様からの変更

- 温度はすべての領域で 600 K にする（仕様は 300 K と、燃料だけ 560 K）。手元のデータ（H in H2O の S(α,β) と
  核種）が 600 K にあるため。xlc と OpenMC を同じデータで比べるのが目的で、公開された結果とは比べない
- 円筒のセル（外半径 0.710879 cm）を、同じ面積の正方形（ピッチ 1.26 cm、外周は鏡面反射）にする
- 被覆管の Zr（0.0388 /(barn cm)）は天然の同位体組成（Zr-90 51.45、Zr-91 11.22、Zr-92 17.15、Zr-94 17.38、
  Zr-96 2.80 at%）で分ける。O は O-16 とする。ギャップはない（仕様のとおり）

## 実行

ステージは DVC で実行する（ADR-0123）。OpenMC のライブラリとツールは examples/vera/dvc.yaml のステージの出力なので、先に戻す（ADR-0130）:

```sh
dvc checkout examples/vera/dvc.yaml
~/.claude/scripts/slurm-run.sh -t 70 dvc-mox 'nix develop -c dvc repro examples/mox/dvc.yaml'
```

ステージは `xs`（`mox.msgpack`）、`lattice-mox<N>`（格子計算の k∞）、`fuel-xs-mox<N>`（xlc の燃料の核種ごとの実効断面積、
`xlc-mox<N>.msgpack`）、`openmc-mox<N>-model`（OpenMC のモデル model.xml）、`openmc-mox<N>`（OpenMC。入力は `openmc-mox<N>.toml`）、`openmc-mox<N>-extract`（k と
`openmc-mox<N>-results/fuel-xs.msgpack`）、`compare-k-mox<N>`（k の差）、`compare-capture-mox<N>`（下の表）。
OpenMC は 1 世代 100 万粒子・250 世代（最初の 50 世代を捨てる）、乱数のシード 1、16 スレッドで 1 問題 16 分ほど。

## 結果

xlc と OpenMC は 90b83b28（分岐点 fea4948a）、2026-10-21。Slurm の排他のジョブで、ライブラリ、格子計算、OpenMC を続けて流した（`dvc.lock` は 2e3a4d26）。
OpenMC の k は前の測定（60cf97d0、2026-10-14）と 6 桁で同じ。xlc の k は xs に ADR-0167 と ADR-0170 が入った分だけ動いた（前の値は MOX-1 1.208694、MOX-2 1.255920）。下の燃料の実効断面積の表は、この実行の
`compare-capture-mox<N>.out` と表の桁で同じだった。

| 問題  | xlc      | OpenMC              | 差       |
| ----- | -------- | ------------------- | -------- |
| MOX-1 | 1.208759 | 1.210946 ± 0.000062 | −219 pcm |
| MOX-2 | 1.255987 | 1.257050 ± 0.000062 | −106 pcm |

[ADR-0133](../../docs/adr/0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md) のライブラリで、k の差は +79、+178 pcm から −219、−106 pcm に動いた（ADR-0167 と ADR-0170 の分を含む）（燃料の実効断面積の差は変わらない）。

燃料の核種ごとの実効捕獲断面積の差（xlc / OpenMC − 1）。xlc の出力には捕獲がないので全 − 弾性 − 核分裂を
OpenMC の (n,γ) と比べ、非弾性散乱などのほかの反応がない群だけを比べる（`compare_capture.py`）。ENDF の MF3 の
しきい値で、Pu-239 は 7.9 keV の第1準位より上の 14、15 群を、U-235 は 77 eV の準位より上の 14〜22 群を除く
（ほかの核種は 40 keV 以上）。しきい値のない発熱反応（U-235 と U-238 の MT5 と (n,α)）による違いは、比べた群で
1.2e-4 以下。OpenMC の実効断面積の相対標準偏差の上限 √(反応率² + 中性子束²) は 34〜41 群で 0.17〜0.20%、
ほかの群で 0.14% 以下:

反応率の差（OpenMC の燃料の中性子束で群について足したもの）を、中性子束を固定した 1 次の近似
Δk/k ≈ ΔνF/νF − (ΔC + ΔF)/A で k に換算すると（14〜69 群、pcm。捕獲は上で比べた群だけ、核分裂はすべての群）:

| 核種                                         | MOX-1 14〜27 群（UFG） | MOX-1 28〜56 群 | MOX-1 14〜69 群 | MOX-2 14〜69 群 |
| -------------------------------------------- | ---------------------- | --------------- | --------------- | --------------- |
| Pu-240                                       | −1                     | −43             | −46             | −47             |
| Pu-239                                       | −2                     | +33             | +46             | +53             |
| Pu-241                                       | +1                     | +9              | +13             | +2              |
| Pu-242                                       | 0                      | −170            | −170            | −1              |
| U-238                                        | −26                    | 0               | −26             | −22             |
| Am-241                                       | +1                     | +15             | +15             | +11             |
| 燃料の核種の計（Pu-238、U-235、O-16 を含む） | −27                    | −150            | −162            | −2              |

- Pu-240 の 1.06 eV の共鳴は、共鳴の群（37 群）で +0.03%（統計誤差の上限 0.18%）と合う。裾の群（33〜36 群）で
  +0.4〜+1.7% 大きく、28〜56 群の捕獲率は +0.36%（k で −43 pcm）違う
- 大きいのは Pu-242 の 2.67 eV の共鳴（29 群）で、MOX-1 で +11%、14〜69 群の捕獲率で +8%（k で −170 pcm）。
  Pu-242 が 1/11 の MOX-2 では +0.4% にとどまる。遮蔽が強いほど差が大きい
- 29 群では、共鳴を持たない Pu-240（+7%）や U-238（−1.2%）も違い、向きは群の中で断面積が下に増えるか上に
  増えるかでそろう。Pu-242 の共鳴による群の中の中性子束のくぼみ（共鳴の干渉）を、核種ごとの σ0 の表では
  表せないためと見込む（確かめていない）。同じく UFG の範囲の 25 群の Pu-240 +2.5% は、U-238 の 20.9 eV の
  共鳴と重なる 20.5 eV の共鳴による
- 29 群の干渉は、量の少ない核種で大きい。MOX-1 で Am-241 +83%、Pu-238 −13%、U-235 −10%（MOX-2 で +9%、−3%、
  −2%）。33 群でも Am-241 −16%、U-235 +9% 違う。どれも反応率が小さく、k には Am-241 の +15 pcm しか効かない
- Pu-242 自身の +11% の原因は切り分けていない。2.67 eV では U-238 の散乱で失うエネルギー（約 0.05 eV）が
  共鳴の幅と同じ程度で、NR 近似（ライブラリの重み）が成り立たないことが候補
- 熱群（57〜69 群）では、Pu-239（+0.1%）を除くどの核種の捕獲も +0.3〜+0.35% 大きく、核分裂も同じ向きなので
  打ち消し合って k には効きにくい（燃料の核種の計で +15 pcm）
- 燃料の核種の 14〜69 群の差の k の計（MOX-1 −162 pcm、MOX-2 −2 pcm）は、k の差（−225、−113 pcm）のうち MOX-1 の大半を説明するが、
  MOX-2 は説明しない。残りは MOX-1 で −63 pcm、MOX-2 で −111 pcm で、UO2 のピンセル（examples/vera の 1B で +60 pcm）と同じく
  断面積の側のほかの誤差（15.03 keV より上の群、被覆管と水、1 次の近似の誤差）を含む
- 燃料の核種の計は MOX-1 が MOX-2 より 160 pcm 低く、そのほとんどは Pu-242 の差（169 pcm）による。k の差の
  違いは 112 pcm（MOX-1 が低い）なので、残りが組成によって逆向きに 48 pcm 違い（MOX-2 で低い）、Pu-242 の差が
  k の差の違いを超える分を打ち消している
