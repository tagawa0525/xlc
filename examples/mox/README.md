# LWR MOX ピンセル

NEA の LWR MOX ピンセルのベンチマーク（pin_cell.pdf の付録 2「LWR MOX pin-cell benchmark」、
<https://www.oecd-nea.org/science/docs/pubs/pin_cell.pdf>。手元では references/mox/）の MOX-1 と MOX-2。
Pu の同位体の自己遮蔽を確かめるために使う。特に Pu-240 の 1.06 eV と Pu-242 の 2.67 eV の共鳴は UFG の範囲
（4 eV〜15.03 keV）より下にあり、ライブラリの σ0 の表と等価原理（Carlvik の2項有理近似）で遮蔽する。
参照解は、xs と同じ ENDF/B-VIII.0 から手元の NJOY で作ったデータで OpenMC を動かして作る（examples/vera と同じ）。

| ファイル                   | 内容                                                                                |
| -------------------------- | ----------------------------------------------------------------------------------- |
| `xs.toml`                  | xlc の多群ライブラリ（`mox.msgpack`）の入力。参照解と同じ核種で、すべて 600 K       |
| `pincell-mox1.toml` など   | xlc の格子計算の入力（燃料 5 リング、被覆管 1 リング、水 3 + 2 + 1 リング、扇形 8） |
| `openmc_model.py`          | MOX-1, MOX-2 を OpenMC で解き、燃料の核種ごとの実効断面積を xlc の群で書く          |
| `openmc-mox1.msgpack` など | 下の参照解の燃料の実効断面積（`openmc_model.py` の `fuel-xs.msgpack`）              |
| `compare_capture.py`       | 核種ごとの実効捕獲・核分裂断面積を群ごとに比べ、反応率の差を k の差に換算する       |

OpenMC のデータは examples/vera/openmc_library.py で作る（Pu-238〜242 と Am-241 は 600 K）。

## 仕様からの変更

- 温度はすべての領域で 600 K にする（仕様は 300 K と、燃料だけ 560 K）。手元のデータ（H in H2O の S(α,β) と
  核種）が 600 K にあるため。xlc と OpenMC を同じデータで比べるのが目的で、公開された結果とは比べない
- 円筒のセル（外半径 0.710879 cm）を、同じ面積の正方形（ピッチ 1.26 cm、外周は鏡面反射）にする
- 被覆管の Zr（0.0388 /(barn cm)）は天然の同位体組成（Zr-90 51.45、Zr-91 11.22、Zr-92 17.15、Zr-94 17.38、
  Zr-96 2.80 at%）で分ける。O は O-16 とする。ギャップはない（仕様のとおり）

## 実行

```sh
target/release/xs examples/mox/xs.toml                    # mox.msgpack（16 コアで 1 分 49 秒）
target/release/lattice examples/mox/pincell-mox1.toml     # 7.5 秒
cargo run --release -p xlc-lattice --example fuel_xs -- examples/mox/pincell-mox1.toml examples/mox/xlc-mox1.msgpack
# references/openmc で（nix develop ../..#references の中、PATH に install/bin）
venv/bin/python ../../examples/mox/openmc_model.py endfb80/cross_sections.xml MOX-1 mox-1 \
  ../../examples/mox/mox.msgpack 1000000 250 50 1
python3 examples/mox/compare_capture.py examples/mox/mox.msgpack examples/mox/xlc-mox1.msgpack \
  examples/mox/openmc-mox1.msgpack
```

OpenMC は 1 世代 100 万粒子・250 世代（最初の 50 世代を捨てる）、乱数のシード 1 で、16 スレッドで 1 問題 16 分。

## 結果

| 問題  | xlc      | OpenMC              | 差       |
| ----- | -------- | ------------------- | -------- |
| MOX-1 | 1.211905 | 1.210946 ± 0.000062 | +79 pcm  |
| MOX-2 | 1.259289 | 1.257050 ± 0.000062 | +178 pcm |

どの群も 0.15% 以下:

| MOX-1 25 群（16〜27.7 eV）      | Pu-240 20.5 eV   | +2.5%       | −0.3%       | −0.3%       | +0.3%       | +0.3%       |
| MOX-1 27 群（4〜9.9 eV）        |                  | −0.5%       | +0.8%       | −0.5%       | −0.8%       | +0.7%       |
| MOX-1 29 群（2.6〜3.3 eV）      | Pu-242 2.67 eV   | +7.2%       | +1.9%       | −3.0%       | +11.1%      | −1.2%       |
| MOX-1 30 群（2.1〜2.6 eV）      |                  | −1.3%       | −0.4%       | +0.1%       | +3.4%       | +0.1%       |

| MOX-2 29 群                     | Pu-242 2.67 eV   | +1.3%       | +0.4%       | −0.6%       | +0.4%       | −0.2%       |
| MOX-2 37 群                     | Pu-240 1.06 eV   | +0.02%      | +0.04%      | +0.01%      | −0.01%      | +0.03%      |

反応率の差（OpenMC の燃料の中性子束で群について足したもの）を、中性子束を固定した 1 次の近似
Δk/k ≈ ΔνF/νF − (ΔC + ΔF)/A で k に換算すると（9.1 keV より下の群、pcm）:

| 核種                                   | MOX-1 4 eV より上 | MOX-1 4〜0.1 eV | MOX-1 計 | MOX-2 計 |
| -------------------------------------- | ----------------- | --------------- | -------- | -------- |
| Pu-240                                 | −1                | −43             | −46      | −47      |
| Pu-239                                 | −2                | +33             | +46      | +52      |
| Pu-241                                 | +1                | +9              | +13      | +2       |
| Pu-242                                 | 0                 | −170            | −170     | −1       |
| U-238                                  | −26               | 0               | −27      | −23      |
| Am-241                                 | +1                | +15             | +15      | +11      |
| 燃料の核種の計（Pu-238、U-235 を含む） | −28               | −151            | −163     | −3       |

- Pu-240 の 1.06 eV の共鳴は、共鳴の群（37 群）で 0.03% と合う。裾の群（33〜36 群）で +0.4〜+1.7% 大きく、
  捕獲率は +0.36%（k で −43 pcm）違う
- 大きいのは Pu-242 の 2.67 eV の共鳴（29 群）で、MOX-1 で +11%、9.1 keV より下の捕獲率で +8%（k で −170 pcm）。Pu-242 が
  1/11 の MOX-2 では +0.4% にとどまる。遮蔽が強いほど差が大きい
- 29 群では、共鳴を持たない Pu-240（+7%）や U-238（−1.2%）も違い、向きは群の中で断面積が下に増えるか上に
  増えるかでそろう。Pu-242 の共鳴による群の中の中性子束のくぼみ（共鳴の干渉）を、核種ごとの σ0 の表では
  表せないためと見込む（確かめていない）。同じく UFG の範囲の 25 群の Pu-240 +2.5% は、U-238 の 20.9 eV の
  共鳴と重なる 20.5 eV の共鳴による
- 29 群の干渉は、量の少ない核種で大きい。MOX-1 で Am-241 +83%、Pu-238 −13%、U-235 −10%（MOX-2 で +9%、−3%、
  −2%）。33 群でも Am-241 −16%、U-235 +9% 違う。どれも反応率が小さく、k には Am-241 の +15 pcm しか効かない
- Pu-242 自身の +11% の原因は切り分けていない。2.67 eV では U-238 の散乱で失うエネルギー（約 0.05 eV）が
  共鳴の幅と同じ程度で、NR 近似（ライブラリの重み）が成り立たないことが候補
- 熱群（57〜69 群）では、Pu-239（+0.1%）を除くどの核種の捕獲も +0.3〜+0.35% 大きく、核分裂も同じ向きなので
  打ち消し合って k には効きにくい（燃料の核種の計で +15 pcm）
- 燃料の核種の 9.1 keV より下の差の k の計（MOX-1 −163 pcm、MOX-2 −3 pcm）は、k の差（+79、+178 pcm）を
  説明しない。残る +200〜+240 pcm は、UO2 のピンセル（examples/vera の 1B で +295 pcm）と同じ断面積の側の
  別の誤差と見込む。MOX-1 と MOX-2 の k の差の違い（99 pcm）は、主に Pu-242 の差（170 pcm）による
