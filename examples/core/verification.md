# 制御棒の部分挿入（燃料の列）

制御棒の先端や棒の中の材料の境界がノードの途中にあるノードの扱い（[ADR-0127](../../docs/adr/0127-weight-partially-rodded-nodes-by-axial-fine-mesh-flux.md)）の、方式の
誤差を測る例。同じ定数と同じ NEM で、軸方向のメッシュを先端と AIC/B4C の境でも分けた計算（部分挿入のノードがない）を
参照にし、メッシュを分けない計算の、ADR-0127 の中性子束の重みと z の面の不連続因子、体積の重み（ADR-0127 で採らなかった
案）を比べる。格子計算の定数の正しさ（2 段階の手法の誤差、KENO との比較）は対象にしない（#0098）。

| ファイル                                                      | 内容                                                                                                                      |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `xs.toml`                                                     | 多群ライブラリ（`rods.msgpack`）。examples/reflector の核種から Ti を除き、AIC の Ag、In、Cd を足したもの。600 K だけ     |
| `assembly-out.toml`、`assembly-aic.toml`、`assembly-b4c.toml` | 制御棒の値ごとの格子計算（棒なし、VERA 2G、2H の形状と組成。600 K、0.743 g/cm³、1300 ppm）。連続の軸は 1 点ずつ           |
| `rod_table.py`                                                | 3 つのテーブルを、制御棒の軸（out、aic、b4c）を持つ 1 つのテーブルにまとめる（格子計算の制御棒の分岐 #0093 までのつなぎ） |
| `rods_cases.py`                                               | 炉心の形、台帳、サイクル、ケース（`cases/`）、`cases.yaml`、`dvc.yaml` を書く                                             |
| `compare_rods.py`                                             | 炉心の結果（`out/`）を比べる表を書く（`compare.out`）                                                                     |
| `dvc.yaml`、`dvc.lock`                                        | 段階（xs → 格子 → テーブル → 炉心のケース → 比較。ADR-0123）                                                              |

炉心は集合体1体（径方向は鏡面反射、ピッチ 21.5 cm）の燃料の列（365.76 cm）を 16 ノード（22.86 cm）に分け、z の両端は
Marshak。制御棒は VERA の棒（仕様書の表 8: 先端から AIC 101.6 cm、その上に B4C 259.08 cm、ステップ 1.5875 cm）で、0
ステップの先端を燃料の下端に置く。部分挿入のノードの細かいメッシュの幅は ADR-0127 の 0.5 cm。

```sh
dvc repro examples/core/dvc.yaml
```

## 方式の誤差と微分価値（44128b49、分岐点 d07475d3、2026-10-14）

ライブラリ、格子計算、炉心のケース、比較は 44128b49（分岐点 d07475d3）で `dvc repro examples/core/dvc.yaml` を Slurm の排他の
ジョブ 332 で流した。格子計算の k∞ は、棒なし 1.181431、AIC 0.849616、B4C 0.789519。前の値（格子計算 2c4a40b3、分岐点 a15d53b2。炉心 29c19e5d、分岐点 51eb3e73）
との差の主な原因の候補は AIC の格子の k∞（0.846870 → 0.849616）で、切り分けていない。前の格子計算は ADR-0142（AIC の棒の遮蔽）の前のコードのもので、
棒なしと B4C の k∞ は 6 桁で同じ（ADR-0156 による差は 1e-6 未満）。参照の k は最大 +67 pcm（20 ステップ）動き、中性子束の重みの
Δk は 0.01 pcm の桁で同じ。

- 中性子束の重みと z の面の不連続因子の k の差は、どの位置でも 4.3 pcm 以内（先端がノード 1 にある 20 ステップの
  −4.22 pcm が最大で、ほかは 1.2 pcm 以内）、粗いノードの核分裂率の割合の差は 0.7% 以内。体積の重みは −14〜−2932 pcm、
  5.7〜383% で、深く挿入して出力が下のノードに集まる 20 ステップでは、部分挿入のノードの吸収の過大が出力の分布そのものを
  変える
- 微分価値（ノード 8 を先端が横切る区間）は、参照が先端の位置に対して滑らかに 23.5 から 18.9 pcm/ステップに下がるのに
  対し、中性子束の重みは各区間で 0.06 pcm/ステップ以内（最大は 116〜118 の 0.052）で一致し、カスプが残らない。体積の重みは 7.1 から 35.6 pcm/ステップ
  に増え、ノードの中で傾きが逆になる（カスプ）
- 細かいメッシュの幅: 0.5 cm と 0.125 cm の k の差は 0.05 pcm 以内で、方式の誤差（最大 4.2 pcm）より 2 桁小さい。
  ADR-0127 の幅は 0.5 cm にした
- 固有値の反復の回数（116 ステップ）は、中性子束の重みが 563 回、体積の重みが 560 回、参照が 570 回で、外側の反復の
  たびに定数を作り直しても増えない（b9c48816、分岐点 b23fc2ef の手元の実行、2026-10-14。`bin/core` は fa295db1 の `dvc.lock` と同じ md5、定数は同じ段階の出力）
