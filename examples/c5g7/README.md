# C5G7（2D）

OECD/NEA の C5G7 MOX ベンチマーク（NEA/NSC/DOC(2003)16）の2次元の問題。7群の巨視的断面積が与えられ、
自己遮蔽を含まないので、格子計算の MOC（形状、トラッキング、真空境界、反復）だけを検証できる。

| ファイル          | 内容                                                                             |
| ----------------- | -------------------------------------------------------------------------------- |
| `c5g7.xs`         | 7群の巨視的断面積（仕様の Table 1。全断面積は輸送補正した値、νΣf = ν × Σf）      |
| `c5g7.inp`        | 格子の入力（51 × 51 セル。左と上は鏡面反射、右と下は真空）                       |
| `compare.py`      | ベンチマークの参照解（MCNP）と、k・最大と最小のピン出力・集合体出力を比べる      |
| `openmc_model.py` | 同じ断面積と形状を OpenMC の多群モードで解き、同じ形式のピン出力を書く（検証用） |

断面積の表は、どの物質・群でも 輸送断面積 = 吸収 + 散乱の和 を満たす。`openmc_model.py` で解くと
k = 1.18664 ± 0.00011、集合体出力は参照解と 0.15% 以内で一致し、入力（断面積の変換と配置）が正しいことを確かめた。

## 平坦線源の近似の離散化誤差

燃料と水の境目では、水の側で熱中性子束が大きく傾く。平坦線源の MOC では、ピンの周りの水と反射体を
細かく分けないと、この傾きを表せずに大きな誤差になる。

- `c5g7.inp` の分割（ピンの燃料と水を1領域ずつ、反射体のセルは分割なし）では、k が参照解より 255 pcm 低く、
  反射体に接するピンの出力が 13% 高い
- 燃料のピン2列と水のセル2列を並べた小さな問題（鏡面反射）では、最も粗い分割で k が OpenMC より 8000 pcm 高い。
  円のない均質なセルだけにして分割を 4, 10, 20, 40 と細かくすると、k は 2次で収束し、外挿した値が
  OpenMC と一致する（輸送計算そのものに誤りはない）

細かい分割の計算は、反復の加速（CMFD）とスレッドによる並列化を入れてから行う（M2 の計画の手順 2）。
