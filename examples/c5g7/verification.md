# C5G7（2D）

OECD/NEA の C5G7 MOX ベンチマーク（NEA/NSC/DOC(2003)16）の2次元の問題。7群の巨視的断面積が与えられ、
自己遮蔽を含まないので、格子計算の MOC（形状、トラッキング、真空境界、反復）だけを検証できる。

| ファイル          | 内容                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| `c5g7-xs.toml`    | 7群の巨視的断面積（仕様の Table 1。全断面積は輸送補正した値、νΣf = ν × Σf）                               |
| `c5g7.toml`       | 格子の入力（51 × 51 セル。左と上は鏡面反射、右と下は真空）。ピンの燃料と水を1領域ずつの粗い分割           |
| `c5g7-fine.toml`  | 同じ問題を細かく分けた入力（下の「離散化誤差」を参照）                                                    |
| `compare.py`      | ピン出力（`pins.msgpack`）を、ベンチマークの参照解（MCNP）と、k・最大と最小のピン出力・集合体出力を比べる |
| `openmc_model.py` | 同じ断面積と形状を OpenMC の多群モードで解き、同じ形式のピン出力を書く（検証用）                          |

断面積の表は、どの物質・群でも 輸送断面積 = 吸収 + 散乱の和 を満たす。`openmc_model.py` で 1 世代 100 万粒子、
400 世代（最初の 100 世代を捨てる）、乱数のシード 2 で解くと k = 1.186552 ± 0.000045 で、参照解の 1.186550 と
一致し、入力（断面積の変換と配置）が正しいことを確かめた（90b83b28、分岐点 fea4948a、2026-10-21。Slurm の排他のジョブ）。ピン出力の統計誤差（相対標準偏差）は中央値 0.18%、最大 0.36%。

ステージは DVC で実行する（ADR-0123）。OpenMC のツールは examples/vera/dvc.yaml の `references-shell` の出力なので、先に戻す（ADR-0130）:

```sh
dvc checkout examples/vera/dvc.yaml
~/.claude/scripts/slurm-run.sh -t 50 dvc-c5g7 'nix develop -c dvc repro examples/c5g7/dvc.yaml'
```

ステージは `lattice-coarse`（`c5g7.toml`）、`lattice-fine`（`c5g7-fine.toml`）、`openmc-model`（OpenMC のモデル model.xml と mgxs.h5）、`openmc`、`openmc-extract`（入力は `openmc-c5g7.toml`）、
`compare-coarse`、`compare-fine`（参照解の MCNP と OpenMC との比較）。

なお、1 世代 20 万粒子（同じ世代数、種 1）の結果とはピン出力が二乗平均で 0.50% 違い、そのピンの相対標準偏差
（中央値 0.41%）より少し大きい。世代間の相関で、統計誤差が小さめに見積もられるためと考えられる。

## 平坦線源の近似の離散化誤差

燃料と水の境目では、水の側で熱中性子束が大きく傾く。平坦線源の MOC では、ピンの周りの水と反射体を
細かく分けないと、この傾きを表せずに大きな誤差になる。ピンセルの四隅（内接円の外）の水も、内接円より大きい
半径の帯（セルの外周で切り取る）で分ける必要がある。分割と結果（方位角 64、16 スレッド）:

| 分割                                                                                   | k        | 参照解との差 | ピン出力の差（OpenMC、二乗平均 / 最大） | 時間 |
| -------------------------------------------------------------------------------------- | -------- | ------------ | --------------------------------------- | ---- |
| `c5g7.toml`（燃料と水を1領域ずつ、反射体は分けない。間隔 0.05 cm）                     | 1.184416 | −214 pcm     | 6.0% / +18%                             | 13 s |
| 燃料 5、水 5 リング（内接円まで）、扇形 8、反射体 20 × 20（間隔 0.05 cm）              | 1.186724 | +15 pcm      | 0.39% / +1.4%                           | 71 s |
| 上に四隅を 0.85 cm まで 3 リング                                                       | 1.186546 | 0 pcm        | 0.30% / +1.1%                           | 72 s |
| `c5g7-fine.toml`（燃料 5、水 3、四隅 0.75 cm まで 2、扇形 8、反射体 10 × 10、0.02 cm） | 1.186560 | +1 pcm       | 0.33% / +1.1%                           | 85 s |

参照解は MCNP（1.186550）、ピン出力は上の OpenMC の結果と比べた。`c5g7-fine.toml` は集合体出力も参照解と
0.04% 以内で一致する。残る差（二乗平均 0.3%）は OpenMC の統計誤差よりやや大きく、最大の差は反射体に面した
ピンにある。

細い領域はトラック間隔に見合わないと、トラックから求めた体積が解析値からずれる。`RUST_LOG=debug` で
ずれの最大の領域が出るので、分割を変えたら確かめる（`c5g7-fine.toml` で 1.8%。四隅を 0.85 cm まで分けて
間隔 0.05 cm にすると、0.85 cm より外の角の細い領域で 31%）。
