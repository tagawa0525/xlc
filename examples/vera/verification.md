参照解の側の近似:

- OpenMC は、出射エネルギーの分布が片対数（INT=4）の区間を線形として扱う（ACE から読むときに置き換える）。対象の核種
  では Sn の MF5 の連続スペクトル（MT16、17、22、28、91）が当たる。xs は補間則のとおりに扱う。被覆管の中の Sn は微量
  なので、影響は統計誤差より小さいと見込む
- NJOY の ACER は B-10 で止まるので、手元でバグを直した NJOY を使う（docs/environment.md）。直したのは荷電粒子の生成
  データの書き出しだけで、中性子の断面積は変わらない
- 565 K（2A、2Q）は温度の内挿のモード（`settings.temperature` の `"interpolation"`）で解く。OpenMC 0.15.2 のこのモードは、
  核種のデータが温度を 1 つしか持たないと、警告を出して全体を最も近い温度のモードに戻す（src/nuclide.cpp の Nuclide の
  読み込み）。そうでなければ、物質の温度を挟む 2 つの表を読み、衝突ごとに kT の比で確率的に選ぶ（同じく
  `Nuclide::calculate_xs`、S(α,β) は src/thermal.cpp の `ThermalScattering::calculate_xs`）。表の温度に等しい温度は、その温度と
  次の温度の組になり、選ぶ重みは 0 になる。HDF5 の 565 K の kT は 565.0008 K に当たり、物質の 565 K はそれより低いので、
  範囲の下に寄せて 565 K の表だけを使う。そこで燃料、被覆管、冷却材の核種は 565 K と 600 K 以上の表を持たせ（温度を 1 つ
  しか持たない核種をなくす）、565 K の表を使う。H in H2O の S(α,β) は 550 K と 573.6 K の表から重み 0.6357 で選ぶので、
  期待値は xlc（[ADR-0080](../../docs/adr/0080-interpolate-sab-in-temperature.md)）と同じ温度についての線形の内挿になる。どれかの核種が戻すと、S(α,β) の読み込みが
  最も近い温度のモードになり 565 K から 1 K 以内の表がないので止まる（核種は S(α,β) より先に読む。src/cross_sections.cpp）。
  2A と 2Q は止まらずに解けたので、戻していない
- H-1 の自由原子のデータは、OpenMC は 565 K で処理したもの、xlc は 550 K と 573.6 K の表全体の内挿を使う。同じ NJOY で
  作った OpenMC のデータで、565 K のエネルギーの格子の点ごとに比べた相対差の最大は、全断面積と弾性散乱で 4 eV 未満
  5.2e-5、4 eV 以上 5.5e-7、捕獲で 4 eV 未満 1.4e-6、4 eV 以上 6.4e-7（`compare_h1_temperatures.py`、478e2f4d、2026-10-11）。自由原子の
  弾性散乱を S(α,β) で置き換えるのは、xlc の散乱行列も OpenMC も評価済みデータの上限 10 eV 未満（[ADR-0133](../../docs/adr/0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md)）なので、
  どちらのコードでも自由原子の弾性散乱を使う範囲（10 eV 以上）と捕獲の相対差は 1e-6 以下で、k への影響は 1 pcm 未満と見込む
  （相対差に、H-1 の反応への k の感度の和として大きめに 1 を掛けた見積もり。測っていない）。xlc の UFG のポイントワイズの断面積の
  H は、4〜10 eV も自由原子のまま（ADR-0133）で、4 eV 以上の 5.5e-7 の差がそのまま入る
- 565 K の核種を足したデータの 600 K の表は、足す前（600 K だけで作ったもの）とエネルギーの格子も断面積も同じ（U-235、
  U-238、O-16、H-1、Zr-90、Fe-56、B-10、Sn-120 と、H in H2O の S(α,β) の 600 K の表を比べた。4888a4cd、2026-10-11）。600 K の問題の
  参照解は、足す前のデータのものをそのまま使う
- OpenMC は、質量比が 1 より大きい核種を 400 kT（600 K で 20.7 eV、1200 K で 41 eV）以上で静止した標的、それ未満で
  自由ガスとして扱い、H は熱中性子散乱則の範囲より上ではエネルギーによらず自由ガスとして扱う。xlc の減速計算は全核種で
  静止した標的とする。xlc の散乱行列は、H を S(α,β) の上限から 9118 eV まで自由ガス、ほかの核種を 4 eV 未満で自由ガスとする
  （ADR-0133）

## Problem 3 の参照解

3A（毒物なし、濃縮度 3.10%、ホウ素 1300 ppm、600 K）と 3B（Pyrex の棒 16 本とシンブルプラグ 8 本、濃縮度 2.619%、

### 構成

### 外周の燃料の定数の切り分け

外周の燃料のノードの定数の項（断面積、拡散係数、ADF）を 1 つずつ、単一集合体のものから反射体の格子の燃料のノードのものに
替えた試行（433f89ff の trials/p5-0086、2026-10-12、分岐点 db212cb1。ADR-0153 の前の入力で、外周の 3.10%、Pyrex なしの位置だけを替え、
Pyrex のある外周の 12 体は単一集合体の定数のまま）。断面積は total、absorption、nu_fission、fission、chi、scatter。I 型の格子は
格子の MOC の k と、3 × 3 は MOC と、5A は OpenMC と比べた。

| 外周の燃料のノードの定数             | I 型の格子の k | 3 × 3 の k、集合体 RMS | 5A の k、集合体 RMS、最大 |
| ------------------------------------ | -------------- | ---------------------- | ------------------------- |
| 単一集合体（ADR-0095 の f\* の方法） | +580.2         | +688.8、0.99%          | +97.9、4.68%、+11.5%      |
| ADF だけ格子のもの                   | +580.2         | +671.2、0.52%          | +91.8、4.52%、+11.2%      |
| 拡散係数だけ                         | +376.9         | +404.4、0.58%          | +67.5、3.83%、+9.7%       |
| 断面積だけ                           | +207.7         | +321.2、2.63%          | +48.8、2.48%、+6.5%       |
| 断面積と拡散係数                     | 0.0            | +29.8、2.22%           | +19.5、1.87%、+4.8%       |
| すべて（格子の燃料のノードの定数）   | 0.0            | +11.6、1.74%           | +13.8、1.72%、+4.5%       |

- k の差は pcm。3 × 3 は角型の隣に角型の格子の右と上の定数（`small-E`）。5A は I 型の位置と角型の位置の両方を替えた。
  片方だけでは、I 型の位置（16 体）で +62.0 pcm、3.59%、角型の位置（16 体）で +48.7 pcm、2.71%
- I 型の格子では、燃料の ADF を替えても k は変わらない（反射体側の ADF が f\* × 燃料の ADF で、面の ADF の比は燃料の ADF に
  よらない）。断面積と拡散係数を替えると、格子の MOC の k を再現する
- 誤差の大半は、外周の燃料の断面積（反射体から戻る熱中性子でスペクトルが軟らかい）と拡散係数の環境依存から来る。拡散係数の
  差には、定義の違い（単一集合体は B1、反射体の格子の燃料のノードは中性子流で重みづけした outflow。ADR-0104）も入り、
  2 つを分けることは確かめていない
- 反射体のノードの定数の燃料の種類への依存: Pyrex のある燃料に面する 12 の反射体の位置に、その燃料の I 型の格子の反射体の
  ノードの定数を置くと（20bad649 の trials/p5-0086/pairing.py、2026-10-12、分岐点 db212cb1。ADR-0153 の入力の炉心の形だけを替えた）、5A の
  OpenMC との差は k −9.2 pcm、集合体 RMS 1.73%（代表の定数では −5.7 pcm、1.66%）

## 自己遮蔽の検証

燃料の分離共鳴の範囲（4 eV〜15.03 keV）は、ピンごとに Dancoff 係数を合わせた円筒の等価なセルの超微細群の減速計算（UFG）
で解き（[ADR-0068](../../docs/adr/0068-solve-pinwise-slowing-down.md)）、多群で解いたリング間の中性子束の形が UFG と一致するよう SPH 因子を掛ける（[ADR-0071](../../docs/adr/0071-correct-with-sph-factors.md)）。
UFG は、NJOY GROUPR の flux calculator と、分離共鳴の範囲の群で 1e-3 以内で一致する（49e7082c、2026-10-07）。

この方式を選んだ根拠の比較（1B の U-238 の共鳴の群の実効吸収断面積、xlc / OpenMC − 1。d671b182、2026-10-07。k は
c4e5153e と d671b182 の記録で、どれも SPH 因子と非等方散乱を入れる前）:

| 方式                                                   | 21〜25 群   | 27 群（6.67 eV） | 1B の k の差 |
| ------------------------------------------------------ | ----------- | ---------------- | ------------ |
| ライブラリ（重みは NR 近似 φ = 1/(σt + σ0)）と等価原理 | −8〜−24%    | +14%             | +232 pcm     |
| ライブラリ（重みは UFG）と等価原理                     | +5.8〜+8.9% | +10%             | −1887 pcm    |
| ピンごとの UFG（SPH なし）                             | −0.6〜+0.8% | +0.7%            | −87 pcm      |

- ライブラリの重みを UFG で作るのは [ADR-0072](../../docs/adr/0072-weight-shielded-data-by-flux-calculator.md)。NR 近似は、U-238 自身の共鳴散乱で散乱した中性子を、
  吸収と同じく中性子束を減らすものとして扱い、遮蔽を強く見積もる（均質な無限媒質でもライブラリだけで −9〜−30%）。UFG の重みにするとライブラリの誤差は小さくなる（均質な無限媒質で
  +1.5〜+3%）が、等価原理（Dancoff 係数と Carlvik の 2 項有理近似）がそれ自体で吸収を +4〜6% 多く見積もることが現れる
- ESSM も σ0 を大きく見積もり、k は −3080 pcm（8ddb3dd3、2026-10-07）

U-238 の実効吸収断面積（共鳴の群では非弾性の断面積 = 全 − 弾性に等しい。xlc / OpenMC − 1、OpenMC は `openmc_model.py`
に xlc のライブラリを渡して求める。SPH 因子を掛けない値。78f305bb、2026-10-07）:

| 群（WIMS、1 始まり） | 共鳴    | 1B（600 K） | 1D（1200 K） |
| -------------------- | ------- | ----------- | ------------ |
| 24 群（27.7〜48 eV） | 36.7 eV | +0.8%       | +2.6%        |
| 25 群（16〜27.7 eV） | 20.9 eV | +0.3%       | +1.6%        |
| 27 群（4〜9.9 eV）   | 6.67 eV | +0.7%       | +1.0%        |
| 15〜23 群、26 群     |         | −0.6〜+0.1% | −0.7〜+0.1%  |

- 温度とともに差が大きく増えるのは、中性子幅の大きい 36.7 eV と 20.9 eV の共鳴の群。これらは 1200 K でだけ OpenMC の
  自由ガスの範囲（400 kT 未満）に入るので、温度とともに開く分は、減速計算の標的を静止として扱うことによると見込む
  （OpenMC との比較では確かめていない）。24 群は 600 K でも群全体が 400 kT より上なので、600 K の +0.8% は主に別の原因
  による。H の扱いの違い（参照解の側の近似）はどの群にも残る
- SPH 因子は k を +254〜+298 pcm 変える（1B〜1D。6b880de6、2026-10-07）
- 2B のピンごとの U-238 の実効吸収断面積（`pin_xs` の例と `compare_pin_xs.py`。a7b458aa、2026-10-07）は、共鳴の群ごとに、
  案内管の隣のピンとそれ以外のピンの平均で 0.1 ポイント以内しか違わない。群ごとの偏りはすべてのピンに共通で、ピンセルと
  同じ
- 燃料のピンの被覆管の吸収断面積は、1B の OpenMC の被覆管の中性子束で重みづけした平均で 0.009480 /cm（SPH 因子を掛けない
  値。OpenMC 0.009490 /cm）。比べた 75 eV〜9 keV の群（吸収の約半分）はどれも ±0.3%、熱群は ±0.5% 以内。UFG の範囲より
  上の 15〜110 keV の群は無限希釈のままで +2〜8% 大きいが、吸収の約 6% の範囲（e0ada416、2026-10-08）

## 結果を変えないことを確かめた変更

- 等価原理の 2 項の重みに、吸収体自身のポテンシャル散乱を入れる（[ADR-0089](../../docs/adr/0089-weight-two-terms-with-potential-scattering.md)）: k は 1B〜1D、2B（支持格子なし）で 1 pcm 以内
  （f89e222c、2026-10-08）
- 減速計算の範囲より上の散乱源をポテンシャル散乱にし、運動学のしきい値より下から始まる反応をしきい値から始める
  （[ADR-0100](../../docs/adr/0100-move-tables-to-kinematic-thresholds.md)）: ライブラリは、範囲の最も上の群の小さい σ0 で最大 2.1e-2（Zr-90 の 9 群）、U-238 は 1e-4 以内、
  散乱行列は 3e-6 b 以内しか変わらず、k は 1B〜1D、1B（支持格子あり）、2B で 6 桁まで同じ（63fcd3dc、2026-10-09）。そのあとの
  しきい値の扱いの見直しとしきい値の値を 0 にする変更では、ライブラリが 4e-13 以内と 1e-9 未満でしか変わらない
  （f46fed3c、a0882bfc）
- 減衰 1 - exp(-τ) を前もって表にせず、スイープの中で計算する（[ADR-0066](../../docs/adr/0066-compute-attenuation-per-track.md)）: 表は 2B（無限希釈の多群定数、P0）の最大メモリ
  8.0 GB のうち 7.1 GB を占めていた（994d1eff、2026-10-08）

## 支持格子の枠と構造材の自己遮蔽

支持格子は、VERA と同じく質量を保つ厚さの Zircaloy の枠（セルの外周、厚さ 0.0245 cm。入力の `frame`）にする。
OpenMC は `openmc_model.py` のセルに同じ枠を足したもので解いた。2B は方位角 32・間隔 0.05 cm（[ADR-0077](../../docs/adr/0077-keep-vera-discretization.md)）で解いた。燃料のピンの等価なセルの外にある、分離共鳴を持つ核種の
領域（枠、案内管と計装管の被覆管）は、塊ごとの Dancoff 係数と平均弦長で等価原理により遮蔽し（[ADR-0086](../../docs/adr/0086-shield-structural-lumps.md)）、燃料のピン
の等価なセルには、減速材のリングの外に枠と同じ面積の支持格子のリングを置く（[ADR-0088](../../docs/adr/0088-add-frame-ring-to-equivalent-cell.md)）。3964be55（2026-10-08）:

| 問題 | 枠       | xlc の k | OpenMC の k         | 支持格子による k の変化（xlc、OpenMC） |
| ---- | -------- | -------- | ------------------- | -------------------------------------- |
| 1B   | なし     | 1.184736 | 1.181783 ± 0.000063 |                                        |
| 1B   | 真空     | 1.175389 | 1.172224 ± 0.000094 | −935 pcm、−956 pcm                     |
| 1B   | Zircaloy | 1.162632 | 1.159280 ± 0.000094 | −2210 pcm、−2250 pcm                   |
| 2B   | なし     | 1.185802 | 1.183424 ± 0.000052 |                                        |
| 2B   | Zircaloy | 1.171017 | 1.168260 ± 0.000090 | −1479 pcm、−1516 pcm                   |

- 枠の変化の OpenMC との差は 1B で +40 pcm、2B で +38 pcm。遮蔽した枠の吸収断面積は、OpenMC の枠の中性子束で重みづけした
  平均で 0.00195 /cm（OpenMC 0.00194 /cm）、吸収の 26% を占める 149〜367 eV の群で +1.3%
- 枠を遮蔽しない（無限希釈）と、1B の枠の変化は −2613 pcm だった（1116f157、2026-10-08。等価なセルに支持格子のリングを入れる
  前の模型）
- 枠付きの 2B のピン出力の差は rms 0.16%、最大 +0.55%（角のピン）
- 仕様書の 2Q（565 K、減速材 0.743 g/cc、厚さ 0.024512 cm、方位角 30・間隔 0.03 cm）の支持格子による k の変化は、
  xlc −914 pcm、OpenMC −924 pcm（「温度と支持格子による差の変化」、e4dbc0de）
- 影の計算の全断面積は無限希釈の群平均のままにする（[ADR-0087](../../docs/adr/0087-use-dilute-totals-in-shadows.md)）。UFG の範囲の群で燃料の吸収率で重みづけした
  平均にしても、k は 1B と 2B の支持格子あり、支持格子なしで −5〜+0.4 pcm しか動かなかった（ブランチ feat/dancoff-potential で測り、
  61405ace に記録。2026-10-08。等価なセルに支持格子のリングを入れる前の模型）。1B の燃料で重みづけした Zircaloy の全断面積は、
  無限希釈と比べて 149〜367 eV で +29%（U-238 の 291.0 eV と Zr-91 の 292 eV の共鳴が重なる）、3.5〜15 keV で +2〜8%、
  367〜907 eV と 1.4〜3.5 keV で −4〜6% で、Dancoff 係数への効果は打ち消し合う。Zr の分離共鳴の範囲でポテンシャル散乱を
  使うと k は +44 pcm 動くが、Zircaloy を 4 eV〜200 keV の群で無限希釈より最大 45% 透明にする誤差による

## 散乱の次数

2B を散乱の次数を変えて解いた（方位角 32・間隔 0.05 cm、MF4 の角度分布を入れる前のライブラリ。07af7822、2026-10-08）:

| 次数 | k        | OpenMC との差 | ピン出力の差（rms、最大） |
| ---- | -------- | ------------- | ------------------------- |
| P0   | 1.183868 | +44 pcm       | 0.43%、+1.06%             |
| P1   | 1.184880 | +146 pcm      | 0.11%、+0.36%             |
| P2   | 1.184978 | +155 pcm      | 0.11%、+0.35%             |
| P3   | 1.184952 | +153 pcm      | 0.11%、+0.35%             |

P0 では、水の穴の上下左右の隣のピンで平均 +0.45%、斜めの隣で −0.16%、それ以外で −0.42% と、水の穴のそばの出力の
盛り上がりを大きく見積もる（水素の前方に偏る散乱を表せず、水の中を進む距離を短く見積もる）。P1 で偏りは消える。
P0 でピンセルより集合体の k の差が小さかったのは、水の穴への漏れを少なく見積もる誤差が、ピンセルと共通の正の差を
打ち消していたためで、P3 では集合体の差はピンセルと同じ大きさ・同じ温度の傾向になる。

弾性散乱と準位の角度分布（MF4）から作る散乱行列（2 体の反応は重心系の分布と運動学から、MF5 の放出は実験室系の分布から、
P0〜P3）は、NJOY GROUPR（Legendre の次数 3）の散乱行列と、O-16 と H-1 の弾性散乱と O-16 の第 1 準位で、どの次数も P0 の
行の和に対して 1.3e-4 以内で一致する（重心系で等方とすると O-16 の弾性散乱で 27%）。U-238 の弾性散乱は最も高い群だけ
2e-3 違い、積分の分割を 4 倍にしてもこちらの値は変わらない（#0009。d859ff9b、2026-10-08）。MF4 を入れると、k はどの問題も
+73〜+87 pcm 上がる（同じ記録）。重心系で
等方とした誤差（k を下げる向き）が、断面積の側の別の誤差（k を上げる向き）と打ち消し合っていたことになる。

## 均質な無限媒質（1B を混ぜたもの）

1B の燃料・被覆管・減速材を、ピッチの正方形の中の体積比（ギャップは真空）で混ぜた均質な無限媒質（600 K）で、xlc と
OpenMC を、核種ごと・群ごとの中性子収支で比べた。形状、等価原理、SPH を含まないので、残る差はライブラリか、混ぜた
媒質の自己遮蔽の扱いにある。xlc は `homogeneous` の例（[`crates/lattice/examples/homogeneous.rs`](../../crates/lattice/examples/homogeneous.rs)）の `--balance` で、

## k の差の内訳（1B と 2K の中性子収支）

OpenMC との k の差を、物質ごと・群ごとの正味の吸収（吸収から、(n,2n) など 2 個以上の中性子を出す反応で増える分を引いた
もの。xlc の全断面積 − 散乱行列の行の和と同じ量）に分けた。外周が鏡面反射なので、生成 1 あたりの正味の吸収の和が 1/k に
なり、k の差は −k_xlc k_OpenMC ΣΔA として物質と範囲に厳密に分かれる。xlc は `balance` の例
（[`xlc_lattice::balance`](../../crates/lattice/src/balance.rs)。対称性なし、方位角 64・間隔 0.02 cm。ピンセルの設定は [ADR-0111](../../docs/adr/0111-use-30-azimuths-for-vera-assemblies.md) で変えなかったもの）、OpenMC は `openmc_balance.py`
（1 世代 100 万粒子・250 世代、最初の 50 世代を捨てる、乱数のシード 1。世代ごとの statepoint から世代ごとの値を求める）。
1B の xlc は [ADR-0133](../../docs/adr/0133-scatter-h-in-h2o-up-to-the-evaluated-sab-limit.md) のライブラリ（a5652e6b）、OpenMC は 25bcc092、2026-10-11（OpenMC は 16 スレッドで 59 分）。

```sh
# リポジトリの直下で。openmc_balance.py は references の devShell の中で、16 スレッドで約 1 時間（Slurm で流す）
cargo run --release -p xlc-lattice --example balance -- examples/vera/p1/pincell-1B.toml xlc-1B.msgpack
python3 examples/vera/openmc_balance.py examples/vera/openmc-library/cross_sections.xml 1B references/openmc/balance-1B \
  examples/vera/vera.msgpack 1000000 250 50 1
python3 examples/vera/compare_balance.py xlc-1B.msgpack references/openmc/balance-1B/balance.msgpack \
  examples/vera/vera.msgpack 1e5 15030 9.877 4 0.625
```

σ は OpenMC の世代ごとの値の標準誤差で、同じ粒子の追跡から出る生成、吸収、中性子束の相関、規格化の生成、群の範囲の外の
項を含む（世代の間の相関は含まないので小さめに出る）。

バランスは閉じる: OpenMC のすべてのエネルギーの正味の吸収からの 1/A は 1.181810 ± 0.000044 で、k の推定値

（25bcc092 で作ったもの。k 1.184735）では、同じ OpenMC と比べて +292.6 ± 4.4 と +295.2 ± 6.3）。

- ADR-0133 で k の差は +292.6 から +57.4 pcm（1/A）になった。水の 27 群の移行の差はほぼ消え（+2.40% → −0.05%）、置き換えても

## 同じ多群定数での OpenMC との比較（輸送の検証）

断面積の違いを除き、MOC の輸送（非等方散乱、平坦線源、角度の求積）だけを確かめるため、xlc の物質の多群定数（無限希釈、
`mg_materials` の例）を OpenMC の多群モード（`openmc_mg.py`）でも解く。609d8d91（2026-10-08）。

- OpenMC は、打ち切ったルジャンドル展開の散乱角の分布が負になる部分を 0 に切って規格化し直す（`src/scattdata.cpp`）。
  水では負の部分が散乱の約 5% あり、切ると平均の P1 が P1 の打ち切りで 18%、P3 で 9% 減り、別の散乱核を解くことになる。

  作り、両方に同じものを与える（物理的な散乱核ではない）
- OpenMC 0.15.2 の多群モードは、真空のセル（ペレットと被覆管のギャップ）で核分裂の tally を数えると落ちるので、
  ギャップは断面積がすべて 0 の物質で埋める

## 離散化の誤差

### 無限希釈の多群定数

U-238 の共鳴の群で燃料が光学的に非常に厚い無限希釈の多群定数では、k がトラック間隔に対して不規則に動く。1B（P0）で方位角
64 のまま間隔を 0.012〜0.05 cm で少しずつ変えると、k は方位角 64・間隔 0.0025 cm の 0.580294 から −149〜+91 pcm の間で動く
（8e2adc7d、2026-10-08）。ずれの多くは、燃料の外周を横切るトラックの本数で説明できる:

- 平均自由行程が燃料の外側のリングの厚さやトラック間隔より短く、吸収は燃料の表面に集まる。トラックごとの減衰 Δψ は弦の
  長さによらず ψ_in − q/Σt にほぼ等しく、領域の中性子束 × 体積の表面の項 Σ w δ Δψ は、燃料を横切るトラックの本数に比例する
- 本数は格子点を数えるのと同じで、間隔に対して不規則に変わる。トラックの体積を方位角ごとに正確な面積に合わせても、
  表面の項は変わらない
- 方位角の重みを付けて足した燃料の幅の誤差は、k の動きと逆向きにそろう。間隔 16 点の k の分散のうち、燃料の表面の幅の
  誤差で 62%、燃料のリングの境界 5 つの幅の誤差で 83% を説明できる（線形の回帰）。最も低い 0.03 cm（−149 pcm）は燃料の
  表面の幅の誤差が +0.1% しかなく、この仕組みでは説明できない

自己遮蔽した断面積では、ばらつきはずっと小さい（下の節）。
