# VERA の KENO-VI（ENDF/B-VII.0）との比較を、ENDF/B-VII.0 のライブラリで行った記録

仕様書（CASL-U-2012-0131-004）の参照解は KENO-VI、ENDF/B-VII.0 である。本番のライブラリは ENDF/B-VIII.0（ADR-0020）なので、
本番での KENO-VI との差には核データの版の差が混じる（verification.md）。この記録は、同じ核種・温度・群で ENDF/B-VII.0 から作った
検証用のライブラリ（本番ではない）で同じ問題を解き、KENO-VI と核データの版を揃えて比べた結果を書く
（[ADR-0175](../../docs/adr/0175-compare-keno-with-endfb70-library.md)）。本番の結果は verification.md にある。
同じ評価済みデータでも、KENO-VI の連続エネルギーのライブラリは AMPX で処理したもので、xlc の処理（共鳴の再構成、ドップラー拡がり、
S(α,β) の温度の内挿。[ADR-0080](../../docs/adr/0080-interpolate-sab-in-temperature.md)）とは違う。残る差は手法と処理の差である。

対象は、仕様書に KENO-VI の値がある ピンセル 1B〜1D、集合体 2A〜2K、2Q、3D の 1 集合体の炉心 3A、3B。

## ライブラリの入力と段階

- 入力は `endfb70/xs.toml`。`xs.toml` と同じ核種と温度で、ENDF のディレクトリだけ `references/endf/ENDF-B-VII.0_neutrons`、
  `ENDF-B-VII.0_thermal_scatt`（取得は docs/environment.md）。xlc の xs はすべての核種で止まらなかった（コードは変えていない）。
  ファイルの違いは入力で吸収した:
  - ENDF/B-VII.0 に C-12 と C-13 のファイルはなく、天然の C（`n-006_C_000.endf`）だけがある。ADR-0079 の C-12 と C-13 の両方がこの
    ファイルを指す
  - `tsl-HinH2O.endf` に 573.6 K はなく、H-1 は 550 K と 600 K で処理する。565 K の問題（2A、2Q、3B）は lattice がこの 2 つの
    群定数を温度について線形に内挿する（ADR-0080）。KENO-VI の 3B も 550 K と 600 K の 2 つの計算から手で内挿している（k を内挿するか、
    群定数を内挿するかが違う）
  - xs の警告は VIII.0 と同じ種類（MF4 の補間則の違うグリッド、運動学の閾値）で、止まらない
- 段階は `endfb70/dvc.yaml`（ライブラリ `xs`、格子 `pincell`、`assembly`）と `endfb70/p3/dvc.yaml`（3A、3B。`p3_inputs.py
  --library-dir endfb70` が書く）。本番の側の同じ比較は `dvc.yaml` の `keno-pincell`、`keno-assembly`（本番のライブラリで同じツール）。
  格子の入力は `p1/`、`p2/` のものをコピーして使う。比較のツールは `compare_keno_lattice.py`（格子）と `compare_p3.py`（3A、3B）。

## 結果

xlc − KENO-VI は (k_xlc − k_KENO-VI) × 1e5 pcm。ENDF/B-VIII.0 の側は、本番のライブラリを同じツールで解いたもの（コミットは「計算」）
（格子。`keno-*` の段階）と、verification.md の 3A、3B の比較の JSON（`p3/compare-3?-openmc.json`）。

## 結論

結論は上の表の数値で支えられることだけを書く。

- 止まった核種はない。
- k: 15 の格子で、ENDF/B-VII.0 の xlc − KENO-VI は +115〜+270 pcm（平均 +165）、3A は +181 pcm、3B は +166 pcm。ENDF/B-VIII.0 では
  格子が +4〜+197 pcm（平均 +98）、3A が +84 pcm、3B が +193 pcm。VII.0 のほうが小さいのは 2F、2G、2J、3B だけで、1B〜1D、2A〜2D、2I、2Q と 3A では VII.0 のほうが +91〜+164 pcm 大きく、
  2E、2H、2K は +8〜+23 pcm 大きい。
- VIII.0 の xlc − OpenMC（同じ核データの手法の差。verification.md の「OpenMC との比較」の a030052d）は格子で平均 +46 pcm
  （−56〜+112）、3A が +60 pcm、3B が +69 pcm（3A と 3B は ADR-0177 の前のライブラリ）。核データの版が揃えば xlc − KENO-VI もこの大きさになると見込んだが、VII.0 の
  xlc − KENO-VI は平均で約 +119 pcm 大きい。VIII.0 では xlc − KENO-VI（平均 +98）が xlc − OpenMC（+46）と OpenMC − KENO-VI（+52）の
  和（+98）に等しいので、この食い違いは VII.0 のライブラリでの xlc の動きにある。原因は確かめていない
  （候補は xlc の VII.0 のファイルの扱い、AMPX と NJOY の処理の差、KENO-VI のモデルの解釈。[#0131](../../docs/issues/0131-endfb70-keno-offset.md)）。
  したがって「VIII.0 での KENO-VI との差の残りは核データの版の差」とは、k については言えない。
- ピン出力: 吸収体のある集合体（2E〜2H、2J、2K）で、VII.0 のライブラリの xlc − KENO-VI の RMS は VIII.0 の 0.45〜0.61 倍に下がる
  （上の表。3B のピン出力も 0.088% と 0.151%）。2B〜2D、2A、2I、2Q と 3A は両方で同じ程度。軸方向の出力の差の RMS は 3A、3B とも
  VII.0 のほうがわずかに大きい（3A 0.0032 と 0.0028、3B 0.0022 と 0.0019）。VIII.0 で残っていた吸収体のまわりのピン出力の差が下がる理由は、核データの版（B-10、Si、Ag・In・Cd など）
  が候補だが、核種を 1 つずつ替えて分けておらず、k の差の原因が未解決（#0131）で xlc の VII.0 の扱いも候補のため、確かめていない。
