# VERA Problem 1B〜1D, 2B〜2D

CASL の VERA Core Physics Benchmark Problems（CASL-U-2012-0131-004）のうち、毒物のないピンセル（1B〜1D）と
17×17 集合体（2B〜2D）。減速材と被覆管は 600 K（0.661 g/cc、ホウ素 1300 ppm）、燃料は 600, 900, 1200 K。
自己遮蔽（M2 の手順6）と集合体の計算（手順7）の検証に使う。参照解は、xs と同じ ENDF/B-VIII.0 から手元の
NJOY で作ったデータで OpenMC を動かして作る（核データの違いを比較から除くため）。

| ファイル                 | 内容                                                                                                      |
| ------------------------ | --------------------------------------------------------------------------------------------------------- |
| `openmc_library.py`      | ENDF/B-VIII.0 から OpenMC の連続エネルギーのデータを作る（燃料の核種は 600/900/1200 K、他は 600 K）       |
| `openmc_model.py`        | 1B〜1D, 2B〜2D を OpenMC で解く。2B〜2D は lattice と同じ形式のピンごとの核分裂率を書く                   |
| `openmc-2B.msgpack` など | 下の参照解のピン出力（行は上から、核分裂のあるピンの平均で 1 に規格化）                                   |
| `xs.toml`                | xlc の多群ライブラリ（`vera.msgpack`）の入力。参照解と同じ核種と温度                                      |
| `pincell-1B.toml` など   | xlc の格子計算の入力（燃料 5 リング、ギャップは真空、扇形 8、燃料は自己遮蔽）                             |
| `compare_fuel_xs.py`     | 燃料の核種ごとの実効断面積（全・弾性・非弾性・核分裂）を、xlc（`fuel_xs` の例）と OpenMC で群ごとに比べる |

組成は仕様書の表 P1-4, P2-4 の個数密度のとおり。Hf（1e-6 /(barn cm) 未満）とギャップの He は除き、
ギャップは真空とする（docs/plans/m2-assembly.md）。手順は docs/verification.md の「VERA の参照解」。

## 参照解

1B〜1D は 1 世代 100 万粒子・250 世代（最初の 50 世代を捨てる）、2B〜2D は 1 世代 100 万粒子・400 世代
（最初の 100 世代を捨てる）、乱数のシード 1。VERA の公開値は KENO-VI（ENDF/B-VII.0）で、核データの版が違うので参考とする。

| 問題 | 燃料の温度 | OpenMC（ENDF/B-VIII.0） | KENO-VI（ENDF/B-VII.0） | 差      |
| ---- | ---------- | ----------------------- | ----------------------- | ------- |
| 1B   | 600 K      | 1.181783 ± 0.000063     | 1.182149 ± 0.000068     | −37 pcm |
| 1C   | 900 K      | 1.171668 ± 0.000061     | 1.171722 ± 0.000072     | −5 pcm  |
| 1D   | 1200 K     | 1.163202 ± 0.000066     | 1.162603 ± 0.000071     | +60 pcm |
| 2B   | 600 K      | 1.183424 ± 0.000052     | 1.183360 ± 0.000024     | +6 pcm  |
| 2C   | 900 K      | 1.174214 ± 0.000052     | 1.173751 ± 0.000023     | +46 pcm |
| 2D   | 1200 K     | 1.166399 ± 0.000056     | 1.165591 ± 0.000023     | +81 pcm |

2B〜2D のピン出力の統計誤差（相対標準偏差）は中央値 0.07%、最大 0.09%。仕様書の KENO-VI の分布（1/8 の表）と、
対称な 8 本の平均で比べると、どの問題も二乗平均 0.05% 以下、最大 0.11% で一致する。

## 参照解の側の近似

- OpenMC は、出射エネルギーの分布が片対数（INT=4）の区間を線形として扱う（ACE から読むときに置き換える）。
  対象の核種では Sn の MF5 の連続スペクトル（MT16, 17, 22, 28, 91）が当たる。xs は補間則のとおりに扱う。
  被覆管の中の Sn は微量なので、影響は統計誤差より小さいと見込む
- NJOY の ACER は B-10 で止まるので、手元でバグを直した NJOY を使う（docs/verification.md）。
  直したのは荷電粒子の生成データの書き出しだけで、中性子の断面積は変わらない

## xlc の結果（自己遮蔽は Bondarenko の重みのライブラリ）

| 問題 | xlc      | OpenMC   | 差       |
| ---- | -------- | -------- | -------- |
| 1B   | 1.184102 | 1.181783 | +232 pcm |
| 1C   | 1.173032 | 1.171668 | +136 pcm |
| 1D   | 1.163637 | 1.163202 | +44 pcm  |

k の差は小さいが、群ごとの誤差が打ち消し合った結果である。燃料の U-238 の実効吸収断面積（共鳴の群では非弾性の断面積 = 全 − 弾性に等しい）
（`openmc_model.py` に xlc のライブラリを渡して求めた参照値との比）は、21〜25 群（15〜370 eV）で
−8〜−24%、27 群（4〜9.9 eV）で +14% 違う。ピンセルの組成を均質にした無限媒質でも、ライブラリを厳密な σ0 で
引いた値が同じ向きに 9〜30% 違うので、原因は等価原理ではなく、ライブラリの重み φ = 1/(σt + σ0)（NR 近似）にある。
U-238 自身の共鳴散乱でのエネルギーの損失は低い共鳴の幅と同じ程度なので、散乱した中性子は同じ共鳴に残るが、
NR 近似は散乱を吸収と同じく中性子束を減らすものとして扱い、遮蔽を強く見積もる（中性子幅の大きい 36.7 eV と
20.9 eV の共鳴で差が大きい）。超微細群の減速計算で重みを作って直す（docs/plans/m2-assembly.md）。

## UFG の重みのライブラリでの結果

ライブラリの重みを超微細群の減速計算（UFG）で作ると（docs/plans/m2-assembly.md）、U-238 の共鳴の群の
実効吸収断面積（xlc / OpenMC − 1）は次のように変わる。UFG は NJOY GROUPR の flux calculator と、分離共鳴の
範囲の群で 1e-3 以内で一致する。

| 比較                                  | 21〜25 群   | 27 群（6.67 eV） | 1B の k   |
| ------------------------------------- | ----------- | ---------------- | --------- |
| 均質な無限媒質（ライブラリだけ）、NR  | −9〜−30%    | +6%              |           |
| 均質な無限媒質（ライブラリだけ）、UFG | +1.5〜+3%   | +5.4%            |           |
| ピンセル（ライブラリと等価原理）、NR  | −8〜−24%    | +14%             | +232 pcm  |
| ピンセル（ライブラリと等価原理）、UFG | +5.8〜+8.9% | +10%             | −1887 pcm |
| ピンセル（ピンごとの UFG、SPH なし）  | −0.6〜+0.8% | +0.7%            | −87 pcm   |

ライブラリの誤差は UFG で小さくなったが、等価原理（Dancoff 係数と Carlvik の2項有理近似）がそれ自体で
吸収を +4〜6% 多く見積もることが現れた（NR のときはライブラリの誤差と打ち消し合っていた）。次に試した
ESSM も σ0 を大きく見積もった（k が −3080 pcm）ので、ピンごとの超微細群の減速計算で直接求める方式に進む
（docs/plans/m2-assembly.md）。均質な媒質で残る差（21〜25 群で +1.5〜+3%、27 群で +5.4%）の原因は、まだ
切り分けていない。OpenMC は、質量比が 1 より大きい核種を 400 kT（600 K で 20.7 eV）以上で静止した標的、それ未満で
自由ガスとして扱い、H は熱中性子散乱則（S(α,β)）の範囲より上ではエネルギーによらず自由ガスとして扱う。xlc の
減速計算は全核種で静止した標的なので、400 kT より下にかかる 25 群と 27 群の差は標的の扱いの違いを含みえ、
H の扱いの違いはどの群にも残る。

## ピンごとの UFG での結果

燃料の分離共鳴の範囲（4 eV〜15.03 keV）を、ピンごとに Dancoff 係数を合わせた円筒の等価なセルの UFG で解く
（docs/plans/m2-assembly.md）。SPH 因子はまだ入れていない。U-238 の共鳴の群（15〜27 群）の実効吸収断面積は
OpenMC と −0.6〜+0.8% で一致する（1B）。k は次のとおりで、燃料の温度が高いほど負に開く。

| 問題 | 燃料の温度 | xlc      | OpenMC   | 差       |
| ---- | ---------- | -------- | -------- | -------- |
| 1B   | 600 K      | 1.180918 | 1.181783 | −87 pcm  |
| 1C   | 900 K      | 1.169984 | 1.171668 | −168 pcm |
| 1D   | 1200 K     | 1.160652 | 1.163202 | −255 pcm |

1B と 1D の U-238 の実効吸収断面積（xlc / OpenMC − 1）を比べると、温度とともに差が大きく増えるのは、中性子幅の
大きい共鳴（36.7 eV と 20.9 eV）の群である（6.67 eV の群は +0.3 ポイントにとどまる）。400 kT は 600 K で 20.7 eV、
1200 K で 41 eV なので、これらの共鳴は 1200 K でだけ OpenMC の自由ガスの範囲に入る。温度とともに開く分は、減速計算の
標的を静止として扱うことによると見込む（OpenMC との比較では確かめていない）。600 K の差のうち 24 群の +0.8% は、群
全体が 400 kT より上で U-238 の標的は OpenMC でも静止しているので、主に別の原因によると見込む。25 群は一部が
400 kT より下にあるので、600 K の +0.3% は標的の扱いの違いも含みうる。どちらの群でも H の扱いの違い（上の段落）は
残る。

| 群（WIMS、1 始まり） | 共鳴    | 1B（600 K） | 1D（1200 K） |
| -------------------- | ------- | ----------- | ------------ |
| 24 群（27.7〜48 eV） | 36.7 eV | +0.8%       | +2.6%        |
| 25 群（16〜27.7 eV） | 20.9 eV | +0.3%       | +1.6%        |
| 27 群（4〜9.9 eV）   | 6.67 eV | +0.7%       | +1.0%        |
| 15〜23 群、26 群     |         | −0.6〜+0.1% | −0.7〜+0.1%  |

## SPH 因子を入れた結果

等価なセルを多群で解いた中性子束のリング間の形が UFG と一致するよう、UFG の範囲の群の群定数に SPH 因子を
掛ける（crates/lattice/src/sph.rs）。k は SPH なしより +254〜+298 pcm 変わる（文献で SPH なしの誤差は約
−200 pcm）。温度とともに差が負に開く傾向（1B から 1D で約 −120 pcm）は残る。

| 問題 | 燃料の温度 | xlc      | OpenMC   | 差       | SPH なし |
| ---- | ---------- | -------- | -------- | -------- | -------- |
| 1B   | 600 K      | 1.183454 | 1.181783 | +167 pcm | −87 pcm  |
| 1C   | 900 K      | 1.172753 | 1.171668 | +109 pcm | −168 pcm |
| 1D   | 1200 K     | 1.163627 | 1.163202 | +43 pcm  | −255 pcm |

## 集合体（2B〜2D）の結果

`assembly-2B.toml`〜`assembly-2D.toml` は 17×17 の集合体に、周りの水のギャップ 0.04 cm（`gap`）を付けたもの。
自己遮蔽はピンごとの UFG と SPH で、格子の対称性（1/8）で移り合うピンは1回だけ解く。ピンの核分裂率は
`compare_pins.py` で OpenMC（`openmc-2B.msgpack`〜）と比べる（燃料ピン 264 本の平均で規格化）。

| 問題 | 燃料の温度 | xlc      | OpenMC   | 差      | ピンの核分裂率の差（rms、最大） |
| ---- | ---------- | -------- | -------- | ------- | ------------------------------- |
| 2B   | 600 K      | 1.183868 | 1.183424 | +44 pcm | 0.43%、+1.06%（(3, 4)）         |
| 2C   | 900 K      | 1.174161 | 1.174214 | −5 pcm  | 0.44%、+1.05%（(3, 4)）         |
| 2D   | 1200 K     | 1.165844 | 1.166399 | −56 pcm | 0.44%、+1.14%（(3, 12)）        |

k の差は温度とともに負に開く（ピンセルと同じ傾向）。ピンの核分裂率は、案内管の隣のピンで最も大きくずれる。
OpenMC の統計誤差（ピンで 0.1% 程度）より大きい。2B の計算時間は 4.4 分（自己遮蔽 3.6 分、MOC 45 秒。16 コア）。

原因を切り分けた（2B）:

- 自己遮蔽ではない。ピンごとの U-238 の実効吸収断面積（`pin_xs` の例と `compare_pin_xs.py`、OpenMC はピンの
  メッシュの tally）の差は、共鳴の群ごとに、案内管の隣のピンとそれ以外のピンの平均で 0.1 ポイント以内しか違わない。
  群ごとの偏り（24 群 +1.0%、27 群 +0.9% など）はすべてのピンに共通で、ピンセルと同じ
- MOC のトラックでもない。方位角 32 → 64、間隔 0.05 → 0.02 cm でも、ピンの核分裂率の差は rms 0.41%、最大 +1.06%
  とほとんど変わらない（k は +20 pcm）
- 差は水の穴（案内管・計装管）の上下左右の隣のピンで平均 +0.45%、斜めの隣で −0.16%、それ以外で −0.42% で、
  水の穴のそばの出力の盛り上がりを大きく見積もる。散乱を等方（P0）とし輸送補正もしていない（M0 からの近似）ため、
  水素の前方に偏る散乱が表せず、水の中を進む距離を短く見積もることによると見込む。散乱行列の非等方性
  （P1 以上のモーメント）をライブラリに加え、MOC を非等方散乱で解いて確かめる（次の節）

## 非等方散乱の結果

ライブラリに散乱行列の P0〜P3 のモーメントを持たせ、MOC の散乱源を z 方向に対称な実の球面調和関数で展開して
解く（crates/lattice/src/moc.rs。次数は入力の `scattering-order`、省略するとライブラリの P3）。2B で次数を変えると:

| 次数 | k        | 差       | ピンの核分裂率の差（rms、最大） | MOC   | 最大メモリ |
| ---- | -------- | -------- | ------------------------------- | ----- | ---------- |
| P0   | 1.183868 | +44 pcm  | 0.43%、+1.06%                   | 46 秒 | 9.2 GB     |
| P1   | 1.184880 | +146 pcm | 0.11%、+0.36%                   | 60 秒 | 12.2 GB    |
| P2   | 1.184978 | +155 pcm | 0.11%、+0.35%                   | 64 秒 | 14.0 GB    |
| P3   | 1.184952 | +153 pcm | 0.11%、+0.35%                   | 71 秒 | 16.3 GB    |

水の穴のまわりの偏りは P1 で消え（上下左右の隣 −0.02%、斜めの隣 −0.02%、それ以外 +0.05%）、ピンの核分裂率の差は
OpenMC の統計誤差（0.1% 程度）と同じ大きさになる。P3 で 2B〜2D とピンセルを解き直すと:

| 問題 | 燃料の温度 | xlc      | OpenMC   | 差       | P0 の差  | ピンの核分裂率の差（rms、最大） |
| ---- | ---------- | -------- | -------- | -------- | -------- | ------------------------------- |
| 1B   | 600 K      | 1.183883 | 1.181783 | +210 pcm | +167 pcm |                                 |
| 1C   | 900 K      | 1.173166 | 1.171668 | +150 pcm | +109 pcm |                                 |
| 1D   | 1200 K     | 1.164025 | 1.163202 | +82 pcm  | +43 pcm  |                                 |
| 2B   | 600 K      | 1.184952 | 1.183424 | +153 pcm | +44 pcm  | 0.11%、+0.35%（(15, 1)）        |
| 2C   | 900 K      | 1.175216 | 1.174214 | +100 pcm | −5 pcm   | 0.11%、+0.29%（(15, 1)）        |
| 2D   | 1200 K     | 1.166872 | 1.166399 | +47 pcm  | −56 pcm  | 0.11%、+0.36%（(1, 1)）         |

P0 では、ピンセルより集合体で k の差が小さかった（2B で +44 pcm）のは、等方散乱で水の穴への漏れを少なく見積もる
誤差が、ピンセルと共通の正の差を打ち消していたためで、非等方散乱で集合体の差はピンセルと同じ大きさ・同じ
温度の傾向になる。残る差はピンセルと共通の原因（断面積の側。上の節）による。2B の計算時間は 4.2 分（16 コア）。

## 弾性散乱と準位の角度分布（MF4）を入れた結果

これまで、2体の反応（弾性散乱と離散準位の非弾性散乱）は重心系で等方とし、MF5 で与えられた連続的な放出の P1 以上は
0 としていた。MF4 の角度分布を読み、2体の反応は重心系の分布と運動学から、MF5 の放出は実験室系の分布から散乱行列の
P0〜P3 を作る（crates/xs/src/endf/mf4.rs、crates/xs/src/multigroup/scatter.rs）。NJOY GROUPR（Legendre の次数 3）の
散乱行列と、O-16 と H-1 の弾性散乱と O-16 の第1準位は、どの次数も P0 の行の和に対して 1.3e-4 以内で一致する
（重心系で等方のときは O-16 の弾性散乱で 27%）。U-238 の弾性散乱は最も高い群だけ 2e-3 違い、積分の分割を4倍にしても
こちらの値は変わらない。

k はどの問題も 73〜87 pcm 上がり、OpenMC との差が開く。ピンの核分裂率の差は変わらない（2B〜2D で rms 0.11%）:

| 問題 | xlc      | OpenMC   | 差       | MF4 なしの差 |
| ---- | -------- | -------- | -------- | ------------ |
| 1B   | 1.184736 | 1.181783 | +295 pcm | +210 pcm     |
| 1C   | 1.174027 | 1.171668 | +236 pcm | +150 pcm     |
| 1D   | 1.164893 | 1.163202 | +169 pcm | +82 pcm      |
| 2B   | 1.185681 | 1.183424 | +226 pcm | +153 pcm     |
| 2C   | 1.175951 | 1.174214 | +174 pcm | +100 pcm     |
| 2D   | 1.167613 | 1.166399 | +121 pcm | +47 pcm      |

OpenMC も MF4 の角度分布を使うので、重心系で等方とした誤差（k を下げる向き）が、断面積の側の別の誤差（k を上げる向き）と
打ち消し合っていたことになる。精度の目標（docs/plans/architecture.md。k の差 ±100 pcm、許容の上限 ±150 pcm、
ピン出力 rms 0.2%）に対して、ピン出力は満たし、k は 2D が目標と上限の間、ほかは上限の外にある。差はどれも正で、
燃料の温度が高いほど小さい。

## 同じ多群定数での OpenMC との比較（輸送の検証）

断面積の違いを除き、MOC の輸送（非等方散乱、平坦線源、角度の求積）だけを確かめるため、xlc の物質の多群定数
（無限希釈、`mg_materials` の例）を OpenMC の多群モード（`openmc_mg.py`）でも解く。

- OpenMC は、打ち切ったルジャンドル展開の散乱角の分布が負になる部分を 0 に切って規格化し直す
  （`src/scattdata.cpp`）。水では負の部分が散乱の約 5% あり、切ると平均の P1 が P1 の打ち切りで 18%、P3 で 9% 減り、
  別の散乱核を解くことになる。そこで `positive_library.py` で、核種・群の移行ごとに P1〜P_L のモーメントを
  負にならないところまで縮めたライブラリを作り、両方に同じものを与える（物理的な散乱核ではない）
- OpenMC 0.15.2 の多群モードは、真空のセル（ペレットと被覆管のギャップ）で核分裂の tally を数えると落ちるので、
  ギャップは断面積がすべて 0 の物質で埋める

1B（ピンセル）で、xlc を細かく（方位角 256、トラック間隔 0.0025 cm、燃料 10 リング・被覆管 3 リング・
水 11 リング）すると、OpenMC との差は −13〜−32 pcm になる（メッシュはまだ収束していない。下の段落）。
P3 による k の変化（P0 から）は xlc −72 pcm、OpenMC −62 pcm:

| 次数 | xlc（細かい） | xlc（入力のまま） | OpenMC              | 差（細かい） |
| ---- | ------------- | ----------------- | ------------------- | ------------ |
| P0   | 0.580619      | 0.579618          | 0.580843 ± 0.000116 | −22 pcm      |
| P1   | 0.578371      | 0.577386          | 0.578500 ± 0.000075 | −13 pcm      |
| P3   | 0.579899      | 0.578900          | 0.580219 ± 0.000072 | −32 pcm      |

次数による差の違い（最大 19 pcm）が OpenMC の統計誤差を超えるかは判別できない。散乱核の作り方をわずかに
変えて（xlc の k は 6 桁まで変わらない）解き直すと、OpenMC の k は P1 で +18 pcm、P3 で +8 pcm 動き、表示の
統計誤差（世代間の相関で小さめに出る）より大きくゆらぐため。

入力のまま（方位角 64、間隔 0.02 cm）では、どの次数でも細かい xlc より約 −100 pcm 低く、OpenMC との差は
−111〜−132 pcm になる。方位角 64 のまま間隔を 0.02 → 0.01 → 0.005 → 0.0025 cm と半分にしていくと
k は +41, +17, +9 pcm 動き、1 次で収束しているように見える。ただしこれは 2 の冪の間隔だけを見たためで、
間隔を 0.012〜0.05 cm で少しずつ変えると、P0 の k は 0.5788〜0.5812（方位角 64、間隔 0.0025 cm の
0.580294 から −149〜+91 pcm）の間で間隔に対して不規則に動き、0.02 cm は特に低い点に当たっていた。ずれの多くは、燃料の外周を横切るトラックの本数で説明できる:

- 無限希釈の多群定数では、U-238 の共鳴の群で燃料の全断面積が大きく、平均自由行程が燃料の外側のリングの
  厚さやトラック間隔より短い。吸収は燃料の表面に集まり、トラックごとの減衰 Δψ は弦の長さによらず
  ψ_in − q/Σt にほぼ等しい。領域の中性子束 × 体積は、平衡の値 × V に Σ w δ Δψ / Σt を足したもの
  （V はトラックから求めた体積）で、表面の項 Σ w δ Δψ は燃料を横切るトラックの本数に比例する（間隔 δ × 本数で燃料の幅を見積もるのと同じ）
- 本数は格子点を数えるのと同じで、間隔に対して不規則に変わる。トラックの体積を方位角ごとに正確な面積に
  合わせても表面の項は変わらないので、体積の補正では 0.02 cm で +30 pcm しか戻らない
- 方位角の重みを付けて足した燃料の幅の誤差は、間隔 0.05 cm で −1.7%（k は細かい間隔の値より高い）、0.02 cm で +0.9%（低い）、
  0.045 cm で +0.6%（低い）と、k の動きと逆向きにそろう。間隔 16 点の k の分散のうち、燃料の表面の幅の誤差で 62%、
  燃料のリングの境界 5 つの幅の誤差で 83% を説明できる（線形の回帰）。最も低い 0.03 cm（−149 pcm）は燃料の表面の
  幅の誤差が +0.1% しかなく、この仕組みでは説明できない（扇形の分割を 1 にしても、メッシュを細かくしても k は低いまま）

表の細かい設定では、トラックについて k は収束している。方位角 256 のまま間隔を 0.0023〜0.0027 cm で変えても、
方位角を 512 にしても、k は 1 pcm 以内でしか動かない（P0）。メッシュのリングを倍にすると +6.5 pcm 動く。
OpenMC との差は P0 で −16 pcm（表示の統計誤差 12 pcm）になる。P1 と P3 はメッシュを倍にして解いていない
（同じ +6.5 pcm 動くとすれば −6 pcm と −26 pcm）。表示の統計誤差は小さめに出る（上の段落）ので、これらの差が
有意かは判別できない。極角の求積は原因ではない。
Tabuchi–Yamamoto の 3 点の代わりに cos θ の Gauss–Legendre 12 点（半球）で解いても、細かい設定の P3 の k は
+0.7 pcm しか変わらない（Gauss–Legendre 6 点では −17 pcm で、3 点の Tabuchi–Yamamoto より粗い）。

2B（P3）では、入力のまま（方位角 32、間隔 0.05 cm）の xlc が 0.615092、OpenMC が 0.616063 ± 0.000047 で −97 pcm、
ピンの核分裂率の差は rms 0.14%、最大 +0.49% で、水の穴のまわりの偏りはない（上下左右の隣 −0.02%、斜めの隣
+0.01%、それ以外 +0.01%）。方位角 64、間隔 0.02 cm で k は +31 pcm 動く。

非等方散乱は、P3 による k の変化と水の穴のまわりのピンの核分裂率で OpenMC と合う。細かくした xlc の k と
OpenMC の差は、OpenMC の統計誤差とゆらぎで判別できない大きさ（メッシュをさらに倍にした P0 で −16 pcm）まで小さくなる。

## 離散化の誤差（自己遮蔽あり）

上の大きなばらつきは、燃料の共鳴の群が光学的に非常に厚い無限希釈の多群定数で特に大きく、自己遮蔽した断面積では
小さい。1B（P3、自己遮蔽あり）で方位角 64 のまま間隔を 0.005〜0.05 cm で変えると、k は入力の間隔 0.02 cm の値
（1.183883）から −3〜+42 pcm の幅で動き、0.03 cm（−75 pcm、無限希釈でも最も低い間隔）と 0.05 cm（−18 pcm）が
外れる。次の表の差も 1 点ずつの値なので、この程度のばらつきを含む:

| 設定                                        | k        | 入力の設定との差 |
| ------------------------------------------- | -------- | ---------------- |
| 方位角 32、間隔 0.05 cm（集合体の入力）     | 1.183373 | −51 pcm          |
| 方位角 64、間隔 0.02 cm（ピンセルの入力）   | 1.183883 |                  |
| 方位角 64、間隔 0.005 cm                    | 1.184059 | +18 pcm          |
| 方位角 128、間隔 0.01 cm                    | 1.184088 | +21 pcm          |
| 方位角 256、間隔 0.005 cm                   | 1.184149 | +27 pcm          |
| 方位角 256、間隔 0.005 cm、メッシュを細かく | 1.184465 | +58 pcm          |

トラックと角度を細かくした差（+18〜+27 pcm）は、間隔によるばらつきと同じ程度である。メッシュを細かくする
（燃料 10 リング、被覆管 3 リング、水 6 + 4 + 1 リング）と +58 pcm になるが、MOC のメッシュと一緒に自己遮蔽の
解き方（リングごとの UFG と SPH）も変わり、二つの効果は分けていない。「非等方散乱の結果」の節の OpenMC
（連続エネルギー）との差（1B で +210 pcm）が離散化でどちらに動くかは、この測定からは決められない。

集合体を細かい設定で解けるよう、減衰 1 - exp(-τ) は前もって表にせず、スイープの中で計算するようにした
（docs/plans/m2-assembly.md）。表は区間・極角・群ごとで、2B（無限希釈の多群定数、P0）の最大メモリ 8.0 GB のうち
7.1 GB を占めていた（表をやめると 0.9 GB）。区間の数は方位角の数とメッシュの細かさに比例し、間隔に反比例するので、
表のままでは方位角 128、間隔 0.01 cm で約 140 GB になり、この計算機（91 GB）に載らなかった。

表をやめたあとで 2B（P3、自己遮蔽あり）をトラックを細かくして解くと、k は +21, +5 pcm と動きが小さくなり、
ピンの核分裂率の差は OpenMC の統計誤差（中央値 0.07%）と同じ程度になる（2 の冪に近い間隔だけなので、1B と同じ
ばらつきを含みうる）:

| 設定                            | k        | 入力の設定との差 | ピンの核分裂率の差（rms、最大） | 時間   | 最大メモリ |
| ------------------------------- | -------- | ---------------- | ------------------------------- | ------ | ---------- |
| 方位角 32、間隔 0.05 cm（入力） | 1.184952 |                  | 0.11%、+0.35%                   | 4.0 分 | 9.4 GB     |
| 方位角 64、間隔 0.02 cm         | 1.185159 | +21 pcm          | 0.09%、+0.29%                   | 4.8 分 | 15.3 GB    |
| 方位角 128、間隔 0.01 cm        | 1.185209 | +26 pcm          | 0.08%、+0.27%                   | 7.1 分 | 28.6 GB    |

入力の設定は変えない（docs/plans/m2-assembly.md）。細かくすると k はトラックで集合体 +26 pcm、トラック・角度と
メッシュでピンセル +58 pcm（メッシュの分は自己遮蔽の変化を含み、まだ収束していない）動き、どれも k を低く出す向きで、
「非等方散乱の結果」の節の OpenMC との差（+47〜+210 pcm）より小さい。

方位角の数は、32 から 512 までの 2 の冪しか試していなかった。1B（P3、自己遮蔽あり、間隔 0.02 cm）で方位角の数を
12〜128 の偶数すべてで解き、方位角 256・間隔 0.005 cm の値（1.184149）との差（pcm）を見ると、方位角の数に対して
不規則に動き、2 の冪（16、32、64、128）は低い側に出やすいが、それだけが低いわけではない（28、36、68 なども低い）:

| 範囲     | 方位角の数: k の差（pcm）                                       |
| -------- | --------------------------------------------------------------- |
| 12〜20   | 12: −191、14: −67、16: −164、18: −41、20: −76                   |
| 28〜38   | 28: −55、30: −32、32: −39、34: −14、36: −53、38: 0              |
| 58〜70   | 58: −13、60: −17、62: −7、64: −27、66: −24、68: −33、70: −10    |
| 116〜128 | 116: −1、118: −1、120: −6、122: −7、124: −13、126: −4、128: −14 |

近くの数との差は、間隔を変えたときのばらつき（±25 pcm 程度）と同じ程度で、どの数が良いかの規則は見つかっていない。
方位角を増やすほど差は小さくなり、2 の冪を避けても入力の設定の誤差は大きくは変わらない。
xlc の補正後の方位角の組は、どの偶数でも 45° について対称になる（φ と π/2 − φ で nx と ny が入れ替わる）ので、
対称性では説明できない。補正で方位角ごとのトラック間隔も変わるので、方位角の数を変えると実際の間隔も変わる。
