# 濃縮度の違う集合体の 2×2 のカラーセット

ピン出力の再構成（[ADR-0096](../../docs/adr/0096-reconstruct-pin-power-analytically.md)）と 2 段階の手法（集合体ごとの格子計算 → core の
NEM → ピン出力の再構成）の誤差を、全体を xlc の MOC で解いた参照に対して分けて測る例（#0043）。誤差の分け方は #0037。

| ファイル                                  | 内容                                                                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------------- |
| `assembly-31.toml`、`assembly-21.toml`    | 3.10% と 2.11% の集合体1体（外周は鏡面反射）の、形状関数を付けた少数群定数            |
| `colorset.toml`                           | カラーセット全体の MOC。ピン出力と、集合体ごとのノードの少数群定数                    |
| `plant.toml`、`cycle*.toml`、`case*.toml` | core の入力（下の表の 3 つの core の計算）                                            |
| `assemblies*.toml`                        | core の台帳（単一集合体の定数、カラーセットのノードの定数、不連続因子を外した定数）   |
| `diffusion.py`                            | core と同じ均質化した問題を、細かいメッシュの差分の拡散で解き、同じ形のピン出力を書く |
| `without_df.py`                           | 少数群定数の ADF と CDF をすべて 1 にしたコピーを書く                                 |
| `compare.py`                              | 2 つのピン出力の差と、集合体の平均と集合体の中の形への分け方                          |

カラーセットは、左上と右下が 3.10%、右上と左下が 2.11% で、外周は鏡面反射。ノードの少数群定数は、このカラーセットの解から
集合体ごとに作る（ADF は1ノードの NEM。ADR-0094、ADR-0103）。

集合体の形と組成は VERA 2B と同じで（examples/vera/p2 の `assembly-2B.toml`）、燃料の濃縮度だけが違う（2.11% の組成は
VERA の仕様書の表 P5-4）。方位角と間隔は ADR-0111（方位角 30・間隔 0.03 cm）、自己遮蔽あり。ライブラリは examples/vera の
`vera.msgpack`。生成物（少数群定数、ピン出力、ログ）は git で追跡しない。

```sh
cd examples/colorset
../../target/release/lattice assembly-31.toml > lattice-31.log 2>&1
../../target/release/lattice assembly-21.toml > lattice-21.log 2>&1
../../target/release/lattice colorset.toml > colorset.log 2>&1     # 約 16 分（負荷の平均 約 24 のとき）、最大 17 GB
../../target/release/core case.toml > core.log 2>&1
../../target/release/core case-node.toml > core-node.log 2>&1
python3 without_df.py fg-31.msgpack fg-31-nodf.msgpack
python3 without_df.py fg-21.msgpack fg-21-nodf.msgpack
../../target/release/core case-nodf.toml > core-nodf.log 2>&1
python3 diffusion.py cycle.toml diffusion-8.msgpack 8
python3 compare.py core-pins.msgpack moc-pins.msgpack --blocks 2
```

## 測った値（02a2cd43、2026-10-10）

k の値と、集合体の平均の核分裂率（燃料のピンの平均で 1 にしたもの。左上の 3.10% と右上の 2.11%）:

| 計算                                                       | k-eff    | MOC との差 | 3.10%  | 2.11%  |
| ---------------------------------------------------------- | -------- | ---------- | ------ | ------ |
| カラーセットの MOC（参照）                                 | 1.131564 |            | 1.1261 | 0.8739 |
| core、カラーセットのノードの定数                           | 1.131567 | +0.3 pcm   | 1.1262 | 0.8738 |
| core、単一集合体の定数（2 段階の手法）                     | 1.131979 | +41.5 pcm  | 1.1321 | 0.8679 |
| core、単一集合体の定数から不連続因子を外したもの           | 1.131987 | +42.3 pcm  | 1.1323 | 0.8677 |
| 細かいメッシュの拡散、単一集合体の定数（セルあたり 8 × 8） | 1.131987 | +42.3 pcm  |        |        |

単一集合体の k∞ は 3.10% で 1.186030、2.11% で 1.068368。

ピン出力の差（燃料のピン 1056 本。相対の差 a / b − 1）。「集合体の中の形」は、集合体ごとにその平均で割った値どうしの差:

| 比べるもの（a / b）                              | RMS    | 最大    | 出力 0.8 以上の最大 | 集合体の平均（3.10%、2.11%） | 集合体の中の形（RMS、最大） |
| ------------------------------------------------ | ------ | ------- | ------------------- | ---------------------------- | --------------------------- |
| core（再構成）/ 細かいメッシュの拡散（同じ定数） | 0.176% | +0.780% | 0.780%              | −0.002%、+0.002%             | 0.176%、+0.778%             |
| core、2 段階の手法 / MOC                         | 0.952% | −1.831% | 1.831%              | +0.536%、−0.690%             | 0.735%、+2.423%             |
| core、不連続因子なし / MOC                       | 0.931% | −1.672% | 1.672%              | +0.545%、−0.703%             | 0.697%、+2.262%             |
| 細かいメッシュの拡散、単一集合体の定数 / MOC     | 0.838% | −1.246% | 1.246%              | +0.537%、−0.692%             | 0.574%、−1.774%             |

細かいメッシュの拡散は、セルを 2、4、8 個に分けて解き、4 と 8 の差がピン出力で最大 0.016%（k は 1 pcm 以内）だったので、
8 を収束した解とした。

## 誤差の分け方

- **ノード法そのもの**: カラーセットの解から作った定数（一般化等価理論）では、k の差 0.3 pcm、集合体の平均の差 0.01%。NEM の
  空間の離散化の誤差は小さい
- **再構成だけ**: 同じ定数の同じ問題を細かいメッシュの拡散で解いた解と比べると、集合体の平均はほぼ一致し（0.002%）、差は
  集合体の中の形だけ（RMS 0.18%、最大 0.78%）。最大は、4 つの集合体が接する中央の角の周りのピンで、3.10% の側で低く、
  2.11% の側で高く出る（角の中性子束を単一集合体の CDF で連続とする扱いと、角の近くの解析的な関数の形による）
- **単一集合体の定数（周りの集合体の影響）**: 2 段階の手法の誤差の大部分。k で +41.5 pcm、集合体の平均で +0.54%（3.10%）と
  −0.69%（2.11%）。同じ定数の細かいメッシュの拡散も同じ差を持つので、ノード法ではなく定数による。集合体の中の形の差
  （RMS 0.57%、最大 1.8%。拡散と MOC の比較）は、単一集合体の形状関数がカラーセットの中のスペクトルの違いを表さない分
- **不連続因子**: 単一集合体の ADF と CDF は 1 に近く（0.992〜1.001）、外しても k は 0.8 pcm、ピン出力は RMS 0.04%（最大
  0.17%）しか変わらない。この体系では、不連続因子が誤差を隠していない

2 段階の手法の誤差の最大（集合体の中の形で +2.4%）は、中央の角の周りのピンで、形状関数の誤差と角の再構成の誤差が重なる。

## 判定の閾値の案に対して

閾値の案（#0043。xlc の MOC に対してピン出力の差の RMS 1%、出力 0.8 以上のピンの相対の差の最大 3%）に対し、2 段階の
手法は RMS 0.95%、出力 0.8 以上の最大 1.8% だった。閾値はまだ決めていない（ユーザーが決める）。
