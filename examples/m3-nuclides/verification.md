# M3 の新しい核種の多群ライブラリ

VERA Problem 2E〜2K、3〜5 の物質（Pyrex、AIC、B4C、SS304、Inconel、ノズル、炉心板）に要る新しい核種の多群ライブラリ
（`xs`）を作り、NJOY と比べる例。範囲と作業の順序は [M3 の計画](../../docs/plans/m3-core-hzp.md) の手順2。

| ファイル   | 内容                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| `dvc.yaml` | 段階（`xs` だけ）                                                                                    |
| `xs.toml`  | 多群ライブラリ（`m3-nuclides.msgpack`）の入力（29 核種、4 温度、σ0 9 点）。生成物は git で追跡しない |

ライブラリは DVC のステージ `xs` で作る（ADR-0123）。NJOY との比較は `crates/xs/examples/` の比較プログラムで行い、段階にしない:

```sh
~/.claude/scripts/slurm-run.sh -t 10 dvc-m3-nuclides 'nix develop -c dvc repro examples/m3-nuclides/dvc.yaml'
```

## 核種

仕様書（CASL-U-2012-0131-004、references/vera/spec.txt）の個数密度の表から、M3 で解く物質の元素を拾った。

| 物質                   | 出典（表、ページ）                                                        | 元素・核種                                                      |
| ---------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Pyrex                  | P2-4（p. 29）、P3-3（pp. 45〜46）、P4-3（pp. 54〜55）、P5-4（pp. 67〜69） | B-10、B-11、O-16、Si-28、Si-29、Si-30                           |
| AIC                    | 同上（P2-4 は 2G）                                                        | Ag-107、Ag-109、Cd-106〜116（8 核種）、In-113、In-115           |
| B4C                    | 同上（P2-4 は 2H）                                                        | B-10、B-11、C（6000）                                           |
| SS304                  | 同上（P2-4 は 2E〜2K）                                                    | C、Si、P-31、Cr、Mn-55、Fe、Ni-58、Ni-60、Ni-61、Ni-62、Ni-64   |
| Inconel                | P3-3、P4-3、P5-4                                                          | Si、Ti-46〜50、Cr、Fe、Ni                                       |
| ノズル、炉心板         | P3-3、P4-3、P5-4                                                          | H、B、C、O、Si、P、Cr、Mn、Fe、Ni（SS304 と水を均質にしたもの） |
| 炭素鋼（Carbon Steel） | P5-4（p. 68）                                                             | C、Fe                                                           |

- SS304 は Pyrex の被覆管と内管（表 6）、制御棒の被覆管（表 8）、シンブルプラグ（表 9）、計装用シンブル（表 10）、
  バッフル（表 16）に使う
- 仕様書の Inconel（Inconel-718）は Si、Ti、Cr、Fe、Ni だけで、Nb、Mo、Al、Co は含まない
- Pyrex に実際には含まれる Na2O、Al2O3、Fe2O3、CaO、MgO、Cl は、仕様書が無視している（1.5 節、p. 8）
- 炭素鋼は圧力容器（表 16 の CS508）で、[ADR-0078](../../docs/adr/0078-put-baffle-in-reflector.md) により除く。C と Fe はどちらにしてもほかの物質に要る
- Zircaloy の Hf（1e-6 /(barn cm) 未満）は [ADR-0054](../../docs/adr/0054-model-vera-materials.md) で除く。WABA の Al-27 と、Gd、IFBA は M4

新しい核種は計画の C、Si、P、Ti、Mn、Ni、Ag、Cd、In と同じで、足りないものはない。天然の C は C-12 と C-13 に分ける
（[ADR-0079](../../docs/adr/0079-split-natural-carbon.md)）。ENDF/B-VIII.0 にはどれも同位体ごとの評価がある。

## 形式

[ADR-0021](../../docs/adr/0021-follow-njoy-processing-flow.md) のとおり、新しい形式は要らなかった。29 核種とも `xs` でエラーなく処理できる。

| 核種                           | 分離共鳴      | 非分離共鳴（LRF=2、LFW=0） | 出射分布（中性子）  |
| ------------------------------ | ------------- | -------------------------- | ------------------- |
| C-12                           | なし（LRU=0） | なし                       | MF5 LF=9、MF6 LAW=1 |
| C-13                           | なし（LRU=0） | なし                       | なし（2体反応だけ） |
| P-31                           | なし（LRU=0） | なし                       | MF5 LF=1、MF6 LAW=1 |
| Si-28〜30、Ni-58、Ni-60        | Reich-Moore   | なし                       | MF6 LAW=1, 2        |
| Ni-61、Ni-64                   | MLBW          | なし                       | MF6 LAW=1, 2        |
| Ti-48                          | Reich-Moore   | なし                       | MF6 LAW=1           |
| Ti-46、Ti-47、Ti-49、Ti-50     | MLBW          | なし                       | MF6 LAW=1           |
| Mn-55                          | Reich-Moore   | 125 keV〜1 MeV             | MF6 LAW=1           |
| Ni-62                          | MLBW          | 600 keV〜1 MeV             | MF6 LAW=1, 2        |
| Cd-106〜112、Cd-114、Cd-116    | Reich-Moore   | 2.3〜11.5 keV から 100 keV | MF5 LF=1            |
| Ag-107、Cd-113、In-113、In-115 | MLBW          | 0.6〜6.5 keV から 100 keV  | MF5 LF=1            |
| Ag-109                         | MLBW          | 7.12〜88.9 keV             | MF6 LAW=1           |

MF6 の LAW=4 は反跳核で、中性子の分布ではない。MF4 は LTT=0〜3 で、どれも読める（ADR-0081）。Si の MF6 は点の数の違う対応点の補間（INT=12）で、単位基底に切り替えて
warn を出す（[ADR-0057](../../docs/adr/0057-interpolate-outgoing-distributions-as-endf.md)）。

## 温度

S(α,β) を持たない核種なので、計算する温度そのもので作る（[ADR-0080](../../docs/adr/0080-interpolate-sab-in-temperature.md)）: HZP の 565 K（3B、4、5）、等温温度係数の
560 K と 570 K（5 の ITC）、仕様書が 600 K とする 2E〜2K と 3A（表 P2-1、P3-1）の 600 K。

## 処理（2026-10-08、770d09d）

29 核種 × 4 温度で 57 秒（AMD Ryzen 9 9950X、16 コア、核種ごとに並列。CPU 時間の和は 8.3 分）。最も重いのは
Mn-55（57 秒）。

これまでの記録が受け入れた 1e-3 を超える差は、どれも原因を確かめた。

### しきい反応（0 K、無限希釈）

表にない反応のうち、しきい反応（MT4 の準位、MT5、16、22、28、103〜107）は、しきい値を含む群で最大 1.5e-2 違う
（Cd-108 の MT104。断面積は 1e-19 b）。大きい反応では Cd-112 の MT51（MT4）が 6 群で 3.0e-3、Cd-114 の MT53 が 5 群で 7.0e-3。

- NJOY RECONR は、最初の点が運動学のしきい値 −Q (A + 1)/A より下にある反応のしきい値を上げる（Cd-112 の MT51 は
  623.0002 → 623.5708 keV）。xs はファイルのとおりに扱う。NJOY の 0 K の PENDF から xs で群平均すると、この差は消え、
  Cd-112 の MT51 の 6 群の xs の値は ENDF の表の厳密な積分（0.28245585 b）と 7 桁一致する。どちらにするかは #0023
- 残る差（最も高い群やしきい値の群で 5e-4〜3e-3）は GROUPR の積分による。NJOY の PENDF の厳密な積分は、Cd-108 の
  MT52 の 1 群で 1.2122143e-3 b（xs 1.212214e-3、NJOY 1.212848e-3）、MT58 の 4 群で 3.1836696e-5 b（xs 3.183670e-5、
  NJOY 3.174745e-5）

### 0 K の全・弾性・捕獲

全と弾性の差（最大 5.9e-4）は、0 K のポイントワイズの断面積を線形にするときの許容誤差 1e-3 の範囲の差である。NJOY の 0 K の PENDF から
xs で群平均すると、8 核種（Cd-108、Cd-112、Cd-116、Ni-62、Ni-64、Mn-55、Ag-107、Ti-50）で全と弾性は 7.2e-5 以内、捕獲は
4.2e-4 以内になる。NJOY の許容誤差を 1e-4 にしても差は縮まない（Cd-112、Ni-62 などの 6 核種）ので、主に xs の側の
線形化の誤差（許容誤差の範囲）である。

非分離共鳴の範囲の捕獲（Ni-62 の 6 群 3.3e-3、Cd-116 の 10 群 1.8e-3）は、NJOY RECONR の幅のゆらぎの Hwang の求積に
よる（[ADR-0049](../../docs/adr/0049-integrate-width-fluctuations-adaptively.md)）。Ni-62 の 0.7 MeV の点で捕獲のポイントワイズの断面積が 3.6e-3 違い、全と弾性は許容誤差の範囲で一致する。
自由度 1 の E[x/(x + Γγ/Γ̄n)] は、Hwang の 10 点の求積で Γγ/Γ̄n = 1e-4〜1e-2 のとき −5e-3〜+9e-3 ずれる（Ni-62 の s 波では
0.7 MeV で s 波 5e-4、p 波 7e-3 程度）。

### 565 K の無限希釈の捕獲（C-12、C-13、Ti-50）

C-13 の 17 群の 3.1e-2、C-12 の 12 群の 5.9e-3、Ti-50 の 13 群の 3.2e-3 は、xs の拡げた格子が粗いことによる（#0022）。
NJOY の値（C-13 で 4.8183e-6 b）は NJOY の 565 K の PENDF の厳密な積分（4.8183e-6 b）と一致し、xs の 565 K の C-13 の
捕獲は 1.5、2、4 keV の点だけで、3 keV で約 5% 大きい。0 K ではどれも 9e-4 以内で一致する。

### σ0 の表

- 小さい σ0（1、10 b）で、分離共鳴の範囲より上の群の差（Ti-48 の 6 群 1.5e-2、Ni-58 の 4 群 7.6e-3、P-31、ほかの Ni、Mn の
  3e-3〜5e-3）は、GROUPR が Bondarenko の中性子束 w/(σt + σ0) を断面積の点の間で線形に積分することによる。NJOY の
  PENDF の厳密な積分は、σ0 = 1 b で P-31 の 5 群 3.1520 b（xs 3.1514、NJOY 3.1411）、Ni-58 の 4 群 2.9483 b（xs 2.9483、
  NJOY 2.9294）、Ti-48 の 6 群 2.2742 b（xs 2.2742、NJOY 2.2401）
- 非分離共鳴の範囲の捕獲（Ni-62 の 6 群 3.7e-3、Cd-116 の 10 群 2.7e-3）は、無限希釈と同じく Hwang の求積による
- 減速計算の範囲の最も上の群は、範囲より上の散乱源を NJOY の flux calculator と同じポテンシャル散乱 σp W にして
  一致した（770d09d。下の節）

### 減速計算の範囲より上の散乱源（770d09d で直した）

直す前（e3b627c）は、減速計算の範囲より上の散乱源を、その場の弾性散乱 σs(E) と NR 近似の中性子束で作っていた。
範囲のすぐ上に散乱の共鳴があると、範囲の最も上の群の中性子束を大きく見積もり、σ0 = 1〜10 b で NJOY の flux
calculator と最大 1.2e-1（Ti-49 の 9 群）、8.6e-2（Mn-55 の 10 群、Ti-46 の 8 群）違った。NJOY はポテンシャル散乱 σp が重み
関数のスペクトルで散乱するとし（groupr.f90 の genflx）、これにそろえると Ti-49 で 6.2e-4 になる。U-238（600 K、
references/njoy-runs/sigz-ufg）では σ0 = 1 b の 14 群の捕獲が 3.0e-3 から 1.7e-3 になり、σ0 = 100 b 以上の最大値は変わらない。
これより前に作ったライブラリ（examples/vera など）の σ0 の表も変わるが、VERA の結果は再測定していない。

### 散乱行列

- 弾性散乱は、C、Si、P、Ti、Mn、Ni でどの次数も 5.2e-4 以内。Ag、Cd（Cd-106、Cd-111 を除く）、In は最も高い群（In-113 は2番目の群）
  だけ最大 4.4e-3（Cd-112 の P0。自己散乱を 0.2% 多く見積もる）で、U-238 と同じ（#0009）
- 非弾性散乱は、行の和（断面積）は上のとおり一致し、出射の分布が次の決定の分だけ違う
  - MF5 の表（LF=1）の入射エネルギーの間の補間 INT=2 を、xs はファイルのとおり、NJOY は単位基底で扱う
    （[ADR-0057](../../docs/adr/0057-interpolate-outgoing-distributions-as-endf.md)）。Ag、Cd、In の MT91 と MT16 で、しきい値を含む群の行の差が、最大で P0 の行の和の

## 運動学のしきい値から始める（2026-10-09、e694dca）

## しきい値の扱いの見直し（2026-10-09、18238fc）

2体の運動学の β² がしきい値で丸めにより負になるのを 0 で止める。
