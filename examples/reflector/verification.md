# 反射体の定数

燃料の集合体とバッフル・水を並べた格子をノードに分けて均質化し、径方向の反射体の定数を作る例（[ADR-0095](../../docs/adr/0095-make-reflector-constants-in-2d-with-normalized-adf.md)）と、
集合体の高さ全体の平板で軸方向の反射体の定数を作る例（[ADR-0128](../../docs/adr/0128-make-axial-reflector-constants-in-a-full-height-slab.md)）。
範囲と作業の順序は [M3 の計画](../../docs/plans/m3-core-hzp.md) の進め方の 5。

## I 型の格子の1ノードの問題（a1fe39d、2026-10-09）

`reflector-I.toml` の格子（49 列 × 19 行のセル、29498 領域、方位角 32、トラック間隔 0.05 cm、自己遮蔽なし）を MOC で
解き（228 秒）、集合体のノード（21.50 cm 角）と反射体のノード（21.50 cm 角）に分けて均質化した。反射体のノードの
1ノードの問題（ADR-0094）で、+x（真空の辺）の高速群の均質な面の中性子束が負になり、ADF を作れなかった（エラー）。

| ノード | 辺         | 群   | 不均質な面の中性子束 | 外向きの正味の中性子流 | 均質な面の中性子束 | ADF   |
| ------ | ---------- | ---- | -------------------- | ---------------------- | ------------------ | ----- |
| 集合体 | -x         | 高速 | 0.1621               | 0                      | 0.1768             | 0.917 |
| 集合体 | -x         | 熱   | 0.01332              | 0                      | 0.01497            | 0.890 |
| 集合体 | +x（境）   | 高速 | 0.07169              | 0.01136                | 0.04842            | 1.481 |
| 集合体 | +x（境）   | 熱   | 0.006558             | 0.000275               | 0.004434           | 1.479 |
| 反射体 | +x（真空） | 高速 | 0.001467             | 0.000927               | −0.002406          | —     |

ノード平均の中性子束は、集合体が（0.1315, 0.01118）、反射体が（0.01909, 0.01143）（高速、熱）。反射体のノードの中で
高速群の不均質な中性子束は、燃料側の面の 0.0717 から真空の面の 0.00147 まで約 50 分の 1 に下がる。ノード平均を保ち、
両方の面の正味の中性子流を合わせた4次の多項式は、この減衰を表せず、真空の面で負になる。真空の辺の J/φ_het は
（0.632, 0.541）。

反射体を幅 10.75 cm の2つのノード（内側: 隙間の水、バッフル、水 7.71 cm。外側: 水 10.75 cm）に分けても、外側の
ノードの真空の面の高速群の均質な面の中性子束は負（−7.1 × 10⁻⁵、不均質は 0.00145）だった。内側のノードの ADF は、
燃料側の面で（0.916, 0.238）、外側の面で（4.16, 8.41）と 1 から大きく離れる（同じコミット、日付。入力は列を
0.771 cm × 10 と 0.43 cm × 25 に変えたもの）。

このため、core の NEM での GET の等価性と、f* × 単一集合体の ADF の近似の誤差は測っていない（#0027）。

## ANM の反射体のノードの1ノードの問題（d48c59e、2026-10-09）

核分裂のないノードを ANM で解くようにした（ADR-0102、ADR-0103）あとも、`reflector-I.toml` の反射体のノードの1ノードの
問題の、+x（真空の辺）の高速群の均質な面の中性子束は負（−0.00214。NEM では −0.00241）で、ADF を作れなかった。MOC の
解と入力（ノード平均、面の正味の中性子流）は前の節と同じ。

反射体のノードの2群の定数は、拡散係数（0.895, 0.276）cm、全断面積（0.6215, 1.6711）、散乱（0.5956, 0.02371;
0.000806, 1.6323）/cm（νΣf は 0）。燃料のノードは拡散係数（1.099, 0.375）、MOC の k = 0.53108（自己遮蔽なし）。

y の漏れが 0（上下が鏡面反射）で上方散乱が小さいので、高速群はほぼ1群の 1D の拡散の式で、ANM の解は手で確かめられる:
φ = a cosh κx + b sinh κx（κ = √(Σr/D) = 0.1701 /cm、κh/2 = 1.829）に、両方の面の正味の中性子流（入る 0.01136、出る
0.000927）を課すと、ノード平均は 0.01874（バランスから決まる値と同じ。参照は 0.01909）で、真空の面の中性子束は
−0.00224 になる。MOC の不均質な面の中性子束は 0.00147 で正なので、均質化した拡散の式（outflow の D。ADR-0098）では、
反射体の中の高速中性子の透過（出ていく流れ / 入る流れ = 0.082）を、正の中性子束で表せない。正にするには、同じ Σr で
κ ≤ 0.1487 /cm、つまり D ≥ 1.17 cm（outflow の 0.895 cm の 1.31 倍）が要る。ノードの核（NEM か ANM）によらない。

## I 型の反射体の GET の等価性と f* の方法の誤差（2fc6a8fe、2026-10-10）

核分裂のないノードを ANM で解き（ADR-0102、ADR-0103）、反射体のノードの拡散係数を Koebke の等価理論の D、燃料のノードの
拡散係数を中性子流で重みづけした outflow の D にした（ADR-0104）うえで、`reflector-I.toml` を解いた（自動の対称性は
上下の鏡映、k = 0.53107507）。

| ノード | 拡散係数（高速、熱）cm                                    | ADF −x                | ADF +x           |
| ------ | --------------------------------------------------------- | --------------------- | ---------------- |
| 燃料   | 1.538, 0.425（中性子流の重み）                            | （0.999, 0.965）      | （0.973, 1.053） |
| 反射体 | 1.321, 1.285（等価な D。中性子流の重みでは 1.448, 0.348） | f* = （1.194, 0.282） | （1.162, 0.297） |

反射体のノードの x の2つの面の不連続因子は群ごとに等しく（−x の f* × 燃料の +x の ADF = 1.162、0.297）、均質な面の
中性子束はどの面も正（真空の +x で 0.00126、0.00288）。熱群の等価な D（1.29 cm）は、輸送の物理量としての D（0.3 cm
程度）より大きい（ADR-0104 の結果）。

同じ2つのノード（21.5 cm、−x と ±y、±z は反射、+x は真空の面で反射体の J/φ。ADR-0101）を core の NEM（燃料は NEM、
反射体は ANM）で解き（`core-I.toml`、`core-I-fstar.toml`）、MOC と比べた。k は MOC と core の最後の反復の値。ノード
平均の中性子束は、core のノード平均（`RUST_LOG=debug` の `node average flux`）× 21.5 cm（z の高さ。どちらも生成率 1 に
規格化）を、MOC の均質化のノード平均（`reflector-I.toml` の info のログの `node`）と比べる。核分裂のあるノードは
1つなので、ノードの出力は燃料のノードが 1、反射体が 0 で、どちらの計算でも同じ。

| 燃料のノードの定数      | k          | Δk/k (pcm) | 燃料のノード（高速、熱） | 反射体のノード（高速、熱） |
| ----------------------- | ---------- | ---------- | ------------------------ | -------------------------- |
| MOC                     | 0.53107507 | —          | —                        | —                          |
| I 型の格子（等価性）    | 0.53107507 | +0.0006    | −1.5 × 10⁻⁹、+7 × 10⁻¹⁰  | +8 × 10⁻⁹、+1.8 × 10⁻⁸     |
| 単一集合体（f* の方法） | 0.53038145 | −130.6     | −1.40%、+0.26%           | −0.85%、−0.55%             |

- 等価性: core は MOC の k とノード平均を、反復の判定の程度で再現する。鏡面反射の上下の辺のノードごとの正味の中性子流は、
  燃料と反射体のノードで 10⁻¹¹ 程度（`symmetry = "none"` で解いて測った）。core の上下の面は正味の中性子流が厳密に 0 なので、
  この流れが残ると参照のノードのバランスと食い違い、そのまま k の差になる（#0032）
- f*の方法: 面の条件は ADF の比だけで決まり、燃料と反射体の面の比は f* そのものなので（ADR-0095）、誤差は燃料の
  ノードの定数（単一集合体の格子の断面積と B1 の D（1.560, 0.449）cm、ADF（0.997, 0.979）、k∞ = 0.614314）が、反射体の
  隣の燃料の定数と違うことから来る
  REF1-2D の閾値の案（k ±50 pcm）より大きく、自己遮蔽なしの燃料の I 型の格子（反射体の隣に燃料1体だけで、その k は
  0.531）では、燃料のノードの中の中性子束の形が単一集合体と大きく違う。REF1-2D の 3×3 で、燃料が反射体の片側にしか
  ないときの誤差を測る

## I 型の格子のピン出力の再構成（09533683、2026-10-11）

格子のノードごとの形状関数と角の不連続因子（[ADR-0131](../../docs/adr/0131-derive-corner-factors-with-vacuum-condition-on-homogeneous-corners.md)）を付けて `reflector-I.toml` と `assembly-2B.toml` を解き、
core の2つのケースで再構成したピン出力を、`reflector-I.toml` の MOC のピン出力（`moc-pins-I.msgpack`）と比較した
（`compare_edge.py`。どちらも燃料のピンの平均で 1 に規格化）。反射体の格子の CPB の角の点の大きさ s_p は 6 つの角の点の
どれも 0.9997〜1.0003 で、CDF を作れた。MOC の k（0.531075）と core の2つのケースの k（0.531075、0.530381）は、前の節と
6 桁まで同じ。

| 燃料のノードの定数      | 燃料のピン 264 本の RMS | 最大    | 反射体に接する列（17 本、出力 0.58〜0.61）の RMS | 最大    |
| ----------------------- | ----------------------- | ------- | ------------------------------------------------ | ------- |
| I 型の格子（等価性）    | 0.080%                  | −0.315% | 0.079%                                           | +0.141% |
| 単一集合体（f* の方法） | 1.897%                  | −5.446% | 4.946%                                           | −5.446% |

- 等価性: ADR-0131 は、定数を作った体系で core が格子のセルの核分裂率を再現するように作る（lattice のテストでは相対
  10⁻⁹）。残る 0.08% の差の原因の候補は、MOC のピン出力（`pin-powers`）がトラックから推定した体積で、形状関数が解析的な
  体積で平均していること（#0041。単一集合体の 2B でも、再構成と `pin-powers` が最大 0.17% 違った。ADR-0096）。確かめて
  いない
- f* の方法: 出力 0.8 以上のピンの最大は 1.549%（`../colorset/compare.py`）。ADR-0118 の 2 段階の手法の閾値（RMS 1%、
  出力 0.8 以上の最大 3%）に照らすと、RMS が超える。反射体に接する列はどれも出力 0.8 未満で、その最大の判定から外れる。
  前の節のとおり、この格子の燃料は自己遮蔽なしで k が 0.531 と小さく、燃料のノードの中の形が単一集合体と大きく違う。
  REF1-2D の比較は #0043 に残す

## 真空の辺の角の点の大きさ（9ebcb470、2026-10-11）

## 角型の反射体の格子の角の不連続因子（9ebcb470、2026-10-11）

5-2D の外周の角に当たる角型の格子（`reflector-corner.toml`。VERA 2B の集合体の右と上に I 型と同じ反射体を置き、バッフルを

| 角の点                                     | s_p（高速、熱） | Φ_p（高速、熱）          |

| 0（左下、集合体の中心側）                  | 0.973、0.971    | 0.207、0.0162            |
| 1、3（集合体と反射体の境の、鏡面反射の辺） | 1.025、1.038    | 0.0884、0.00748          |
| 4（集合体の外側の角）                      | 1.004、0.937    | 0.0371、0.00380          |
| 2、6（鏡面反射の辺と真空の辺の角）         | 0.933、1.016    | 0.00175、0.00143         |
| 5、7（真空の辺の、反射体どうしの境）       | 0.992、1.062    | 0.00093、0.00076         |
