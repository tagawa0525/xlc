# 分岐のテーブル（VERA 2B）

VERA Problem 2B の集合体で、分岐のテーブル（[ADR-0097](../../docs/adr/0097-tabulate-branches-on-a-full-grid.md)）を
格子点の間で内挿した値と、同じ状態を直接に格子計算した値を比べる例。範囲と作業の順序は
[M3 の計画](../../docs/plans/m3-core-hzp.md)。

| ファイル                                                     | 内容                                                                                                                        |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `xs.toml`                                                    | 多群ライブラリ（`branches.msgpack`）の入力。温度は 550、560、565、570、580 K、S(α,β) を持つ H-1 は 550、573.6、600 K        |
| `assembly-2B.toml`                                           | 分岐のテーブル（`table-2B.msgpack`）。ホウ素 900、1300、1700 ppm × 減速材 550、565、580 K × 燃料 550、565、580 K の 27 状態 |
| `direct-t560.toml`、`direct-t570.toml`                       | 1300 ppm、等温 560 K と 570 K の直接の格子計算                                                                              |
| `direct-b1100.toml`、`direct-b1500.toml`                     | 565 K、1100 ppm と 1500 ppm の直接の格子計算                                                                                |
| `core-t560.toml` など                                        | 同じ状態でテーブルを内挿し、集合体1体（反射境界）の k∞ を求めるケース                                                       |
| `core-cycle.toml`、`core-plant.toml`、`core-assemblies.toml` | 集合体1体のサイクル、炉心の形、台帳（ADR-0105）                                                                             |

減速材の密度は VERA の仕様書の付録 G の表 G-2 の値（560 K は 0.75207、570 K は 0.73294 g/cm³）。生成物
（ライブラリ、少数群定数、ログ）は git で追跡しない。

```sh
cd examples/branches
../../target/release/xs xs.toml                 # 13 分（32 スレッド）
../../target/release/lattice assembly-2B.toml   # 1 時間 55 分（27 状態、1 状態 253 秒）
../../target/release/lattice direct-t560.toml   # ほかの direct-*.toml も同じ
../../target/release/core core-t560.toml        # ほかの core-*.toml も同じ
```

## 格子点の間の内挿（7693a1f、2026-10-09）

格子は 17×17、28928 領域、方位角 32、トラック間隔 0.05 cm、燃料の自己遮蔽あり（入力の既定）。反応度は ρ = 1 − 1/k（pcm）。

| 状態                 | 直接の格子計算の k | テーブルを内挿した k | 差（pcm、反応度） |
| -------------------- | ------------------ | -------------------- | ----------------- |
| 1300 ppm、等温 560 K | 1.184194           | 1.184198             | +0.29             |
| 1300 ppm、等温 570 K | 1.184882           | 1.184888             | +0.43             |
| 1100 ppm、565 K      | 1.208383           | 1.208456             | +5.00             |
| 1500 ppm、565 K      | 1.161772           | 1.161837             | +4.82             |

この2点の差から求めた係数は次のとおり。

| 量                                   | 直接    | 内挿    |
| ------------------------------------ | ------- | ------- |
| 等温温度係数（560→570 K、pcm/K）     | +4.903  | +4.918  |
| ホウ素価値（1100→1500 ppm、pcm/ppm） | −8.3005 | −8.3009 |

- 温度の向きの内挿の誤差は 0.5 pcm 以下。燃料を √T、減速材を T で線形に内挿して足りている
- ホウ素の向きは、格子点の間隔 400 ppm の中点で約 5 pcm。内挿は両方とも k を大きく見積もる（ホウ素に対して凸）。
  5 pcm は、ホウ素価値で割ると約 0.6 ppm に当たる。差がほぼ同じなので、2点の差であるホウ素価値の誤差は 0.0004 pcm/ppm
- 格子点の上（1300 ppm、565 K）では、core の k（1.184552）はテーブルの状態 13 の格子計算の k と一致した

テーブルの格子点の k から、係数がホウ素濃度で大きく変わることが分かる（参照の値と比べていないので、絶対値は
確かめていない）。

| 量                                             | 900 ppm | 1300 ppm | 1700 ppm |
| ---------------------------------------------- | ------- | -------- | -------- |
| 減速材温度係数（燃料 565 K、550→580 K、pcm/K） | −1.08   | +7.25    | +15.46   |

燃料温度係数（1300 ppm、減速材 565 K、550→580 K）は −2.45 pcm/K。減速材温度係数とホウ素濃度の交差の項が大きいので、
軸ごとに分けた分岐ではなく直積の格子（ADR-0097）が要る。

1 状態の 253 秒のうち MOC は 59 秒。残りの約 190 秒は、ほかに時間のかかる段がないので燃料の自己遮蔽と見るが、
測っていない（#0039）。ホウ素の格子点の範囲と間隔は、#0038 で決める。
